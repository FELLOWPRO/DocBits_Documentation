# 任一策略

可以有多条规则同时成立，但这些规则的结果必须相同。

**示例：**

| 规则 | 条件            | 返回组 |
| ---- | -------------------- | ------------ |
| 1    | 总金额 <= 1000 | GROUP_1     |
| 2    | 总金额 <= 2000 | GROUP_2     |
| 3    | 总金额 <= 3000 | GROUP_3     |
| 4    | 总金额 <= 4000 | GROUP_4     |
| 5    | 总金额 <= 5000 | GROUP_5     |

如果总金额为 **2500**，评估结果如下：

* **规则 1**：总金额 <= 1000（不匹配）
* **规则 2**：总金额 <= 2000（不匹配）
* **规则 3**：总金额 <= 3000（匹配）
* **规则 4**：总金额 <= 4000（匹配）
* **规则 5**：总金额 <= 5000（匹配）

要应用 **任一**，所有匹配的规则都必须返回相同的 **返回组**。由于不同规则返回的组不一致，因此结果为 **false**。
