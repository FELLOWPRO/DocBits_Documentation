# 第一条策略

应用第一个匹配的规则，之后不再评估其他规则。

**示例：**

| 规则 | 条件                 | 返回组    |
| ---- | -------------------- | ------------ |
| 1    | 总金额 <= 1000 | GROUP_1     |
| 2    | 总金额 <= 2000 | GROUP_2     |
| 3    | 总金额 <= 5000 | GROUP_5     |
| 4    | 总金额 <= 4000 | GROUP_4     |
| 5    | 总金额 <= 3000 | GROUP_3     |

如果总金额为 **1500**，则会评估以下规则：

* **规则 1**：总金额 <= 1000（不匹配）
* **规则 2**：总金额 <= 2000（匹配） → 决策树停止评估后续规则，并应用 **GROUP_2**。
