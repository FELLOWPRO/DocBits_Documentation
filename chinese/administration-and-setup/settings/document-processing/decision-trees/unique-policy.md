# 唯一策略

确保只匹配一条规则。如果匹配多条规则，决策树将返回 false。

**示例：**

| 规则 | 条件                 | 返回组   |
| ---- | -------------------- | ------------ |
| 1    | 总金额 <= 1000       | GROUP_1     |
| 2    | 总金额 <= 2000       | GROUP_2     |
| 3    | 总金额 <= 5000       | GROUP_5     |
| 4    | 总金额 <= 4000       | GROUP_4     |
| 5    | 总金额 <= 3000       | GROUP_3     |

如果总金额为 **1500**，则评估的规则如下：

* **规则 1**：总金额 <= 1000（不匹配）
* **规则 2**：总金额 <= 2000（匹配）
* **规则 3**：总金额 <= 5000（匹配）
* **规则 4**：总金额 <= 4000（匹配）
* **规则 5**：总金额 <= 3000（匹配）

由于匹配了多条规则（**规则 2**、**规则 3**、**规则 4**、**规则 5**），决策树将返回 **false**，因为 **唯一** 策略确保最多只能匹配一条规则。
