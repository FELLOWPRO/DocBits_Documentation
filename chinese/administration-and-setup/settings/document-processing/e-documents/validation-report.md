# 验证报告

当 DocBits 拒绝一张电子发票时，你可以准确了解原因。**验证报告**会以通俗易懂的语言列出所有发现，告诉你需要修正什么，并显示后续步骤。你可以从文档中打开报告，而不是从设置中打开。查找报告的页面请参阅[电子发票被拒绝时的错误页面](validation-error-screen.md)。

本页面向处理发票的人员。管理员会在[电子发票验证](validation-rules.md)页面设置规则，并为每种文档类型选择验证失败时是否阻止发票，详见[各文档类型的验证](validation-per-document-type.md)。

## 文档出现错误时

如果某种文档类型的验证已**开启**且设为**阻止**，那么存在阻止性发现的发票会被设为**错误**状态。从仪表板打开该文档。错误视图左侧显示 XML，右侧显示原因。

<figure><img src="../../../../.gitbook/assets/einvoice-error-view.png" alt="被拒绝电子发票的错误视图，左侧显示 XML，右侧显示原因"><figcaption><p>错误视图：发票的 XML，以及第一条阻止性发现和后续步骤。示例发票使用虚构名称。</p></figcaption></figure>

右侧的卡片会标明拒绝该发票的层级（例如 **L3 · 业务规则**）、规则代码（例如 `BR-CO-26`）、简短说明和**后续步骤**。选择**查看验证详情**即可打开完整报告。

## 阅读报告

<figure><img src="../../../../.gitbook/assets/einvoice-report-top.png" alt="验证报告顶部，显示文件数据、判定结果以及各级别的结果"><figcaption><p>报告顶部：文件数据、判定结果以及各级别的结果</p></figcaption></figure>

报告首先列出文件的相关信息：

| 字段 | 显示内容 |
| --- | --- |
| **参考** | 发票的文件名。 |
| **检查时间** | DocBits 执行检查的时间。已保存的报告之后不会变化。 |
| **文档类型 / 配置文件** | 发票的格式，例如 CII 和 EN 16931。 |
| **规则集** | DocBits 使用的规则集版本。 |
| **卖方** | 从 XML 中读取的卖方信息。 |
| **编号 / 日期** | 从 XML 中读取的发票编号和发票日期。 |

文件数据下方会显示**判定结果**，例如**不符合规范**，以及错误、警告和信息消息的数量。如果你的组织更改了某条规则的严重级别，第二行**组织严重级别**会显示应用组织设置后的数量。

### 各级别的结果

**各级别的结果**表格显示每项检查发现的错误、警告和信息消息数量。各项检查依次递进：

| 级别 | 检查内容 |
| --- | --- |
| **1 语法** | XML 格式正确。 |
| **2 架构** | 结构符合官方 XML 架构。 |
| **3 业务规则** | 必填字段存在且正确（规则 `BR-…`）。 |
| **4 交叉检查规则** | 字段之间相互一致，例如金额总和。 |
| **5 CIUS 规则 (XRechnung)** | 其他德国 XRechnung 规则。 |
| **其他规则** | 其他规则，例如 PEPPOL 规则。 |
| **DocBits 值检查** | DocBits 添加的检查，例如 IBAN 和 VAT ID。 |

> 对于使用 EN 16931 或 EXTENDED 配置文件的发票，XRechnung 特有规则显示为**警告**，而不是错误。

## 发现项

<figure><img src="../../../../.gitbook/assets/einvoice-report-findings.png" alt="发现项列表，显示代码、级别、通俗说明、修复方法以及“在 XML 中显示”"><figcaption><p>每项发现都包含代码、级别、易读说明以及修复提示</p></figcaption></figure>

每项发现占一行：

* **位置**和**代码**：在报告中的位置以及规则代码，例如 `BR-CO-26`。
* **级别**：**错误**、**警告**或**信息**。
* **你的组织**：应用组织设置后的级别。短横线表示你的组织未更改该级别。
* **字段和文本**：以通俗语言说明问题、指出相关字段（例如 *BT-29 卖方标识符*）、显示验证器的技术消息，并提供**如何修复**的提示。
* **行**和**在 XML 中显示**：选择**在 XML 中显示**，即可关闭报告并跳转到 XML 查看器中的对应行。

DocBits 为最常见的规则提供通俗易懂的说明。对于没有此类说明的规则，报告会显示验证器的技术消息。
