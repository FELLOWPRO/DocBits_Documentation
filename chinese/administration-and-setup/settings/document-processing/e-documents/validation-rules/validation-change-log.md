# 变更日志

**变更日志**记录验证设置的每次变更。它属于 [电子发票验证](./)。只有组织管理员可以查看。

打开 **规则和政策** 旁边的 **变更日志** 选项卡。

<figure><img src="../../../../../.gitbook/assets/einvoice-validation-change-log.png" alt="变更日志选项卡，包含 When、Who、Rule、From to To 和 Action 列"><figcaption><p>变更日志包含四条示例记录。用户名已替换为示例名称。</p></figcaption></figure>

| 列            | 显示内容                                                                                 |
| ------------- | --------------------------------------------------------------------------------------- |
| **When**      | 变更时间。                                                                               |
| **Who**       | 执行变更的用户。                                                                         |
| **Rule**      | 已变更的设置或规则。                                                                     |
| **From → To** | 旧值和新值。                                                                             |
| **Action**    | 变更类型。可打开设置向导中的记录，查看各项具体变更。                                     |

每页显示 50 条记录。

确认后，[每种文档类型的验证](validation-per-document-type.md)表中的每项变更都会创建一条记录。
