# PO 匹配度为 100% 时自动导出

### 概述

采购订单（PO）模块中的 **Auto Export if PO matched 100%** 设置，控制当前发票或文档在与 PO 完全匹配后，是否可以继续进入自动导出流程。采购订单是用于比较的依据；此设置并不导出采购订单本身。

### 工作方式

启用后，系统会检查当前文档的 PO 匹配结果。100% 匹配意味着满足这一匹配条件，但不保证立即导出。文档校验、已配置的导出流程、必要审批及待办任务仍可能阻止或延迟导出。匹配不完整时，这一条件会阻止自动导出。

### 优势

* **效率：** 对于与 PO 完全匹配且满足其他处理要求的发票，可减少人工操作。
* **控制：** 将 PO 匹配结果作为额外的导出条件。
* **处理时间：** 可加快符合条件的发票处理；实际导出时间取决于流程中的其他条件。

### 使用方法

1. **启用功能：**
   * 前往 **设置** → **文档处理** → **模块** → **采购订单**。
   * 启用 **Auto Export if PO matched 100%** 对应的滑块。
2. **监控处理：**
   * 检查当前发票的匹配、校验和导出状态。
   * 若匹配度已达 100% 但仍未导出，请检查导出配置、必要审批及待办任务。
3. **检查配置：**
   * 确认 PO 匹配条件和导出设置符合预期流程。
   * 定期检查已导出的发票和异常情况。

### 适用场景

* **大批量发票：** 大量发票可以可靠地与采购订单匹配时。
* **常规采购：** 数量、价格及其他匹配条件较为稳定时。
* **时效性处理：** 希望符合条件的发票在满足全部要求后自动继续处理时。

当该文档类型启用了采购订单匹配时，单独的 `ALLOW_AUTO_EXPORT_FOR_NON_MATCHABLE_PO_LINES` 选项还允许 `NO_MATCHABLE_PO_LINES` 状态通过此匹配检查。它并不普遍放行其他匹配不完整的状态。
