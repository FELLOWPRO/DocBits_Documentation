# EDI 结构描述文件指南

## **1. 概述**

**结构描述文件**用于定义如何将重复出现的 EDI 片段（例如 `N1`–`N4`）分组为结构化 JSON。它可确保：

* **准确解析**相关元素，并将其作为单个单元处理。
* **输出一致**，便于下游系统使用。

_如需查看包含片段详情的完整示例，请参阅_ [_结构描述示例_](edi-structure-descriptor.md)_。_

## **2. 访问与基本编辑**

#### **访问文件**

1.  **设置** → **文档类型** → \[你的文档（例如，_采购订单_）] → **电子文档。**\\

    <figure><img src="../../../../../../../.gitbook/assets/site-all-edi-list-zh.png" alt="EDI 配置中的转换、提取路径、预览及结构描述入口。"><figcaption><p>EDI 配置中的转换、提取路径、预览及结构描述入口。</p></figcaption></figure>
2. 在 **电子文档**下，选择你的格式（例如，_EDI_）。
3.  点击 **结构描述**。\\

    <figure><img src="../../../../../../../.gitbook/assets/site-all-edi-detail-zh.png" alt="已生效的结构描述版本：只读编辑器中显示 JSON 配置。"><figcaption><p>已生效的结构描述版本：只读编辑器中显示 JSON 配置。</p></figcaption></figure>

#### **草稿管理**

* **创建草稿**：点击 ✏️ 铅笔图标开始编辑。
* **删除草稿**：使用 🗑️ 垃圾桶图标删除不再使用的草稿。
* **激活更改**：点击 ✅ 勾选图标以审批并发布更改。
  * <mark style="color:red;">**注意**</mark>：激活新版本会**自动停用**之前的版本。

## 3. 预览功能（预览已解析的 XML）

**预览功能**可让你使用当前的结构描述文件测试并预览上传的 EDI 文件的解析结果。

#### 用法

* 通过标准上传流程上传一个 EDI 文件。
* 复制已上传文件的**文档 ID**。
* 前往**结构描述文件**界面。
*   打开**预览功能。**\\

    <div align="left"></div>
* 在输入框中输入**文档 ID**，然后点击**测试**。
* 系统将显示生成的**结构化 XML 输出**。

此功能特别适用于实时调试映射和验证结构分组。
