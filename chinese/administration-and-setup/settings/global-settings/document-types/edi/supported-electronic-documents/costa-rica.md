# 🇨🇷 哥斯达黎加

| 属性                 | 值                                                |
| -------------------- | ------------------------------------------------------ |
| **国家 / 地区**      | 哥斯达黎加                                             |
| **文档类型**         | 发票（Factura Electrónica）、贷项通知单、借项通知单 |
| **格式**             | XML                                                    |
| **标准**             | Factura Electrónica（Ministerio de Hacienda）           |

哥斯达黎加的电子发票系统由 Ministerio de Hacienda 监管。电子文档必须提交至 Hacienda 平台进行验证，并包含数字签名。DocBits 可以处理哥斯达黎加电子发票并提取关键字段。

## 支持状态

| 组件             | 状态      |
| ---------------- | ----------- |
| 预览             | ✅ 支持 |
| 字段提取         | ✅ 支持 |
| 转换             | N/A         |
