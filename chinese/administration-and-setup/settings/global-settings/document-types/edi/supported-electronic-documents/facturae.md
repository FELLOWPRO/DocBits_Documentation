# 🇪🇸 FACTURAE

| 属性 | 值 |
| -------------------- | ---------------------------------------- |
| **国家 / 地区** | 西班牙 |
| **文档类型** | 发票、贷项通知单、更正发票 |
| **格式** | XML |
| **标准** | Facturae |

Facturae 是西班牙的电子发票标准，通过 FACe 门户（Punto General de Entrada de Facturas Electrónicas）处理的 B2G 交易必须遵循该标准。DocBits 支持此标准的 3.2、3.2.1 和 3.2.2 版本。

## 支持状态

| 组件 | 状态 |
| ---------------- | ----------- |
| 预览 | ✅ 支持 |
| 字段提取 | ✅ 支持 |
| 转换 | ✅ 支持 |
