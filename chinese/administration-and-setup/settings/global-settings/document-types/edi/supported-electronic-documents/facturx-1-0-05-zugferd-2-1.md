# 🇫🇷 FACTURX 1.0.05 - ZUGFeRD 2.1

<!-- edocs-country-scope -->

{% hint style="info" %}
请参阅国家指南，了解版本限制、实际生效的配置和国家说明视频。 [法国](countries/france.md). XML 标记 1p0 和 Factur-X XMP Version 1.0 无法确定发布版本。版本未知时，请保留通用名称。
{% endhint %}

| 属性                 | 值                            |
| -------------------- | ----------------------------- |
| **国家/地区**        | 法国 / 德国                    |
| **文档类型**         | 发票、贷项通知单               |
| **格式**             | CII（嵌入式 PDF/A-3）           |
| **标准**             | Factur-X 1.0.05 / ZUGFeRD 2.1 |
| **基于**             | EN 16931                      |

Factur-X 1.0.05 与 ZUGFeRD 2.1 等效。该版本于 2020 年发布，是法国和德国电子发票生态系统首次联合发布的版本，建立了两者之间的全面互操作性。支持以下配置文件：Minimum、Basic WL、Basic、EN 16931、Extended。
