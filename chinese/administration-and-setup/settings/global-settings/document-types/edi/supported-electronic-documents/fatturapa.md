# 🇮🇹 FATTURAPA

| 属性                 | 值                                      |
| -------------------- | ---------------------------------------- |
| **国家 / 地区**      | 意大利                                  |
| **文档类型**         | 发票、贷项通知单、简化发票              |
| **格式**             | XML (FatturaPA 1.2.x)                    |
| **标准**             | FatturaPA (SDI)                          |

FatturaPA 是由意大利税务局（Agenzia delle Entrate）规定的意大利电子发票标准。自 2019 年 1 月起，意大利企业之间的所有发票都必须通过 Sistema di Interscambio (SDI) 传输。DocBits 可处理 FatturaPA XML 文档，并提取所有抬头和行项目字段。
