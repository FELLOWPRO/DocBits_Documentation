# 🇫🇮 FINVOICE 2.0

<!-- edocs-country-scope -->

{% hint style="info" %}
请参阅国家指南，了解版本限制、实际生效的配置和国家说明视频。 [芬兰](countries/finland.md). 选择映射之前，请检查原始文件的版本。TEAPPSXML 名称并未指明发布版本。
{% endhint %}

| 属性                   | 值                 |
| ---------------------- | ------------------ |
| **国家 / 地区**        | 芬兰               |
| **文档类型**           | 发票、贷项通知单   |
| **格式**               | XML（SOAP 信封）   |
| **标准**               | Finvoice 2.0       |

Finvoice 2.0 扩展了该标准，增强了对付款条件、交付详情和欧盟增值税申报的支持。它沿用了芬兰银行网络使用的基于 SOAP 的传输模型。
