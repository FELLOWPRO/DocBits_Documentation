| **文档类型** | 发票、贷项通知单 |
| **格式** | XML |
| **标准** | Finvoice 3.0 |

Finvoice 3.0 是芬兰当前的电子发票标准版本。它与欧洲标准 EN 16931 保持一致，同时兼容芬兰银行基础设施。该标准支持国内和跨境开票。
