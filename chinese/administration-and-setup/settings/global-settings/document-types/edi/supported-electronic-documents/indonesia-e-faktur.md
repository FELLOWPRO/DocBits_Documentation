# 🇮🇩 印度尼西亚 E-FAKTUR

| 属性                 | 值                                         |
| -------------------- | ------------------------------------------ |
| **国家 / 地区**      | 印度尼西亚                                  |
| **文档类型**         | 税务发票（Faktur Pajak）                   |
| **格式**             | XML/CSV                                    |
| **标准**             | e-Faktur（DJP - Direktorat Jenderal Pajak） |

e-Faktur 是由税务总局（DJP）运营的印度尼西亚电子税务发票系统。所有 PKP（Pengusaha Kena Pajak）纳税人都必须使用该系统，其中包含 NSFP（Nomor Seri Faktur Pajak）序列号、NPWP 税务标识号和 PPN（增值税）计算。
