# INVOIC02

| 属性                 | 值                       |
| -------------------- | ------------------------ |
| **国家 / 地区**       | 国际                     |
| **文档类型**          | 发票                     |
| **格式**              | EDIFACT                  |
| **标准**              | UN/EDIFACT INVOIC D.02B |

INVOIC02 是基于 D.02B 目录版本的 UN/EDIFACT 发票报文。EDIFACT（行政、商业和运输电子数据交换）是物流、零售和制造业广泛使用的 EDI 标准。DocBits 会解析 EDIFACT 报文段结构，并提取抬头、行项目和汇总字段。
