# 🇸🇬 INVOICENOW SG

<!-- edocs-country-scope -->

{% hint style="info" %}
请参阅国家指南，了解版本限制、实际生效的配置和国家说明视频。 [新加坡](countries/singapore.md). 请检查新加坡业务规范标识。国家业务规范与通用 Peppol BIS 可以共用 UBL 语法，但业务规则未必完全相同。
{% endhint %}

| 属性             | 值                                              |
| ---------------- | ----------------------------------------------- |
| **国家 / 地区**  | 新加坡                                         |
| **文档类型**     | 发票、贷项通知单                              |
| **格式**         | UBL 2.1 XML (Peppol)                          |
| **标准**         | InvoiceNow SG（新加坡专属 Peppol BIS）        |

InvoiceNow SG 是 Peppol BIS Billing 标准针对新加坡的本地化版本。它在 Peppol 基础模型上扩展了新加坡特定的业务规则、GST 处理方式和 UEN（唯一实体编号）识别要求。
