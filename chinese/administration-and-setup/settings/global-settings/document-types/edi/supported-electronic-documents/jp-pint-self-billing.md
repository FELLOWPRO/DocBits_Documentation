# 🇯🇵 JP PINT 自开票

| 属性                 | 值                   |
| -------------------- | -------------------- |
| **国家 / 地区**      | 日本                 |
| **文档类型**         | 自开票发票           |
| **格式**             | UBL 2.1 XML          |
| **标准**             | JP PINT Self-Billing |

JP PINT Self-Billing 是日本 Peppol 国际发票模型的自开票变体。它允许买方代表供应商开具发票，并在日本税法规定的特定条件下，采用相同的 JP PINT 结构并互换双方角色。
