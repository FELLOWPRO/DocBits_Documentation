# 🇰🇿 哈萨克斯坦 ESF

<!-- edocs-country-scope -->

{% hint style="info" %}
请参阅国家指南，了解版本限制、实际生效的配置和国家说明视频。 [哈萨克斯坦](countries/kazakhstan.md). 该名称未注明发布版本。请确认实际 XML 架构，不要根据提取支持情况推断能够向税务平台传输。
{% endhint %}

| 属性                   | 值                                                     |
| ---------------------- | ------------------------------------------------------ |
| **国家 / 地区**        | 哈萨克斯坦                                             |
| **文档类型**           | 发票                                                   |
| **格式**               | XML                                                    |
| **标准**               | ESF (Электронные счета-фактуры / 电子发票)             |

哈萨克斯坦 ESF（Электронные счета-фактуры）是由国家收入委员会运营的电子发票系统。所有已注册 VAT 的企业都必须通过 ESF 信息系统开具电子发票。文档包含 BIN/IIN 税务识别号、VAT 计算信息，并带有数字签名。
