# 🇰🇷 韩国 NTS

| 属性 | 值 |
| -------------------- | -------------------------- |
| **国家 / 地区** | 韩国 |
| **文档类型** | 税务发票、现金收据 |
| **格式** | XML |
| **标准** | NTS（National Tax Service，韩国国税厅） |

韩国 NTS 指的是范围更广的韩国国税厅电子文档系统，涵盖税务发票、现金收据及其他税务相关文档。DocBits 可处理 NTS 文档，并提取所有标准字段，包括企业注册号、供应金额和税额。

## 支持状态

| 组件 | 状态 |
| ---------------- | ----------- |
| 预览 | ✅ 支持 |
| 字段提取 | ✅ 支持 |
| 转换 | ✅ 支持 |
