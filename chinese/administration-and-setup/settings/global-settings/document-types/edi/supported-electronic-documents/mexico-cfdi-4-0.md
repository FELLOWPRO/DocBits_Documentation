# 🇲🇽 墨西哥 CFDI 4.0

<!-- edocs-country-scope -->

{% hint style="info" %}
请参阅国家指南，了解版本限制、实际生效的配置和国家说明视频。 [墨西哥](countries/mexico.md). 请检查命名空间、版本和 TipoDeComprobante。不能仅凭负金额识别贷项通知单；成功解析不代表已获 SAT 核准。
{% endhint %}

| 属性                 | 值                                                |
| -------------------- | -------------------------------------------------- |
| **国家 / 地区**      | 墨西哥                                             |
| **文档类型**         | 发票、贷项通知单、付款收据                          |
| **格式**             | XML                                                |
| **标准**             | CFDI 4.0（Comprobante Fiscal Digital por Internet） |

CFDI 4.0 是墨西哥当前版本的数字税务收据标准，自 2023 年 1 月起强制实施。该标准要求提供接收方名称和税务制度（régimen fiscal），新增出口字段，并包含更新后的数字印章和 SAT 证书链。
