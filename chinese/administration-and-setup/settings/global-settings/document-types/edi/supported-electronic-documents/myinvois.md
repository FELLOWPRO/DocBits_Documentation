# 🇲🇾 MYINVOIS

| 属性                 | 值                                                   |
| -------------------- | ---------------------------------------------------- |
| **国家 / 地区**      | 马来西亚                                             |
| **文档类型**         | 发票、贷项通知单、借项通知单、自开票发票             |
| **格式**             | UBL 2.1 XML / JSON                                   |
| **标准**             | MyInvois（LHDN - 马来西亚内陆税收局）                |

MyInvois 是由马来西亚内陆税收局（LHDN）运营的电子发票系统。该系统自 2024 年 8 月起适用于大型企业，要求所有发票提交至 MyInvois 门户进行验证并获取唯一标识符。该系统使用 UBL 2.1，并支持 XML 和 JSON 两种提交格式。
