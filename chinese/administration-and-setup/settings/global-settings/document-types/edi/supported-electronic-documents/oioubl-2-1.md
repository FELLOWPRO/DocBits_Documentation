# 🇩🇰 OIOUBL 2.1

<!-- edocs-country-scope -->

{% hint style="info" %}
请参阅国家指南，了解版本限制、实际生效的配置和国家说明视频。 [丹麦](countries/denmark.md). OIOUBL 与 Peppol BIS 是不同的业务规范。仅凭 UBL 语法无法确定国家业务规范。
{% endhint %}

| 属性 | 值 |
| -------------------- | ----------------------------------------- |
| **国家 / 地区** | 丹麦 |
| **文档类型** | 发票、贷项通知单、催款通知、对账单 |
| **格式** | UBL 2.1 XML |
| **标准** | OIOUBL 2.1 |

OIOUBL 2.1 是丹麦电子发票标准的当前版本。该标准基于 OASIS UBL 2.1，并扩展了丹麦公共部门所需的特定业务规则和代码列表。
