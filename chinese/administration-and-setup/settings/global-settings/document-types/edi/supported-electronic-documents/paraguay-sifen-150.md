# 🇵🇾 PARAGUAY SIFEN 150

<!-- edocs-country-scope -->

{% hint style="info" %}
请参阅国家指南，了解版本限制、实际生效的配置和国家说明视频。 [巴拉圭](countries/paraguay.md). 在所检查的状态中，贷项通知单分类条目缺少专用提取组件包。请验证实际生效的映射，不要将这些名称视为可互换。
{% endhint %}

| 属性                 | 值                       |
| -------------------- | ------------------------ |
| **国家 / 地区**      | 巴拉圭                   |
| **文档类型**         | 发票、贷项通知单         |
| **格式**             | XML                      |
| **标准**             | SIFEN Schema Version 150 |

SIFEN 150 指巴拉圭 SIFEN 系统的架构版本 150。此版本更新了通过 SET 平台处理的电子文档的验证规则和字段要求。
