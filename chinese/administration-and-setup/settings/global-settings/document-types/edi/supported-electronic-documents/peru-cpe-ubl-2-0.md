# 🇵🇪 秘鲁 CPE UBL 2.0

<!-- edocs-country-scope -->

{% hint style="info" %}
请参阅国家指南，了解版本限制、实际生效的配置和国家说明视频。 [秘鲁](countries/peru.md). 请选择实际的 UBL 版本和文档结构。成功处理文件不代表已被 SUNAT 接受。
{% endhint %}

| 属性 | 值 |
| -------------------- | -------------------------------- |
| **国家 / 地区** | 秘鲁 |
| **文档类型** | 发票、贷项通知单、借项通知单 |
| **格式** | UBL 2.0 XML |
| **标准** | CPE UBL 2.0 |

秘鲁 CPE UBL 2.0 是秘鲁电子发票较早采用的 UBL 格式。虽然 SUNAT 已转向 UBL 2.1，但许多现有文档仍使用此版本。DocBits 会处理这些文档，并提取所有抬头和行项目字段。

## 支持状态

| ---------------- | ----------- |
| 预览 | ✅ 支持 |
| 字段提取 | ✅ 支持 |
| 转换 | ✅ 支持 |
