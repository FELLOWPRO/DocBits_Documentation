# 🇵🇪 秘鲁 CPE

| 属性                 | 值                                   |
| -------------------- | ------------------------------------- |
| **国家 / 地区**      | 秘鲁                                  |
| **文档类型**         | 发票、贷项通知单、借项通知单          |
| **格式**             | UBL XML                               |
| **标准**             | CPE（Comprobante de Pago Electrónico） |

CPE（Comprobante de Pago Electrónico）是秘鲁的电子支付凭证标准，由 SUNAT 监管。DocBits 支持秘鲁电子发票使用的 UBL 2.0 和 2.1 版本。

## 支持状态

| 组件         | 状态       |
| ---------------- | ----------- |
| 预览         | ✅ 支持     |
| 字段提取     | ✅ 支持     |
| 转换         | ✅ 支持     |
