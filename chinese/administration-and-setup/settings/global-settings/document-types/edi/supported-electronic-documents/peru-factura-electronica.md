# 🇵🇪 PERU FACTURA ELECTRONICA

| 属性                 | 值                          |
| -------------------- | --------------------------- |
| **国家 / 地区**      | 秘鲁                        |
| **文档类型**         | 发票                        |
| **格式**             | UBL XML                     |
| **标准**             | Factura Electrónica (SUNAT) |

秘鲁 Factura Electrónica 是 SUNAT CPE 系统中的电子发票文档类型。它对应文档类型代码 01（Factura），包含 SUNAT 要求的所有必填字段，包括系列、连续编号和电子签名。

## 支持状态

| 组件         | 状态         |
| ---------------- | ----------- |
| 预览         | ✅ 支持       |
| 字段提取     | ✅ 支持       |
| 转换         | ✅ 支持       |
