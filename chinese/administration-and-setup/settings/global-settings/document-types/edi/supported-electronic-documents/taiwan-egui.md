# 🇹🇼 台湾 eGUI

| 属性                 | 值                                             |
| -------------------- | -------------------------------------------- |
| **国家 / 地区**      | 台湾                                         |
| **文档类型**         | 发票（统一发票）、贷项通知单                    |
| **格式**             | XML                                          |
| **标准**             | eGUI（电子政府统一发票）                       |

台湾 eGUI 是由财政部运营的电子政府统一发票系统。它是台湾所有商业交易的强制性电子发票标准，发票存储在政府平台上，并通过唯一的发票号码格式进行识别。

## 支持状态

| 组件             | 状态        |
| ---------------- | ----------- |
| 预览             | ✅ 支持     |
| 字段提取         | ✅ 支持     |
| 转换             | ✅ 支持     |
