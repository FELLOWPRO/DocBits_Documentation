# 🇹🇭 泰国电子税务发票

| 属性                 | 值                                           |
| -------------------- | -------------------------------------------- |
| **国家 / 地区**      | 泰国                                         |
| **文档类型**         | 税务发票、收据                               |
| **格式**             | XML（嵌入 PDF/A-3）                          |
| **标准**             | 电子税务发票和电子收据（税务局）              |

泰国电子税务发票是由税务局监管的电子税务发票和收据标准。它采用类似 ZUGFeRD 的混合格式，将结构化 XML 数据嵌入 PDF/A-3 文档中。该系统要求使用泰国认证机构 (CA) 签发的证书进行数字签名。
