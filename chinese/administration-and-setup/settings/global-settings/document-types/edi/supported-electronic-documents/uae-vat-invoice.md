# 🇦🇪 阿联酋 VAT 发票

<!-- edocs-country-scope -->

{% hint style="info" %}
请参阅国家指南，了解版本限制、实际生效的配置和国家说明视频。 [阿拉伯联合酋长国](countries/united-arab-emirates.md). 增值税发票映射并不证明支持阿联酋所有 Peppol 或 PINT 发布版本。请确认数据载荷约定和所需的送达集成。
{% endhint %}

| 属性                 | 值                                      |
| -------------------- | --------------------------------------- |
| **国家 / 地区**      | 阿拉伯联合酋长国                         |
| **文档类型**         | 税务发票、简化税务发票                   |
| **格式**             | XML/JSON                                |
| **标准**             | FTA VAT 发票（联邦税务局）               |

UAE VAT 发票是符合联邦税务局（FTA）要求的电子发票格式。虽然阿联酋尚未强制采用特定的电子发票格式，但 DocBits 支持处理符合 FTA VAT 法规的结构化 VAT 发票文档，包括 TRN（税务登记号）识别以及按 5% 计算 VAT。
