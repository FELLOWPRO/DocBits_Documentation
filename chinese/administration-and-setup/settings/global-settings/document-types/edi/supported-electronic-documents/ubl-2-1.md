# UBL 2.1

<!-- edocs-country-scope -->

{% hint style="info" %}
请参阅国家指南，了解版本限制、实际生效的配置和国家说明视频。 [国际](countries/international.md). 发票、订单、响应和发货映射相互独立。文件处理本身不提供 Peppol 接入点，也不提供与贸易伙伴的连接。
{% endhint %}

| 属性                   | 值                                           |
| -------------------- | -------------------------------------------- |
| **国家 / 地区**        | 国际                                          |
| **文档类型**           | 发票、贷项通知单、订单、发货通知                     |
| **格式**               | UBL 2.1 XML                                  |
| **标准**               | OASIS UBL 2.1（通用商业语言）                    |

UBL 2.1（通用商业语言）是 OASIS 制定的商业文档开放标准。它是许多国家电子发票标准的基础，包括 Peppol BIS、XRechnung（UBL 变体）、OIOUBL 和 SI-UBL。DocBits 可处理不符合任何特定国家标准的通用 UBL 2.1 发票。
