# 🇺🇾 乌拉圭 E-FACTURA

| 属性                   | 值                       |
| ---------------------- | ------------------------ |
| **国家 / 地区**        | 乌拉圭                   |
| **文档类型**           | 电子发票（e-Factura）    |
| **格式**               | XML                      |
| **标准**               | e-Factura（CFE 类型 111）|

乌拉圭 e-Factura 是 CFE 系统中的电子发票文档类型，类型代码为 111。它用于在已注册 RUT 的实体之间进行正式的 B2B 交易，并包含 DGI 所需的所有税务识别和计算字段。

## 支持状态
