# 🇩🇪 XRECHNUNG 1.0 CII

| 属性                   | 值                                              |
| ---------------------- | ----------------------------------------------- |
| **国家 / 地区**        | 德国                                           |
| **文档类型**           | 发票、贷项通知单                               |
| **格式**               | CII                                            |
| **标准**               | XRechnung 1.0                                  |
| **基于**               | EN 16931（UN/CEFACT 跨行业发票）               |

XRechnung 标准的早期版本。虽然已被较新版本取代，但仍支持处理旧版文档。
