# 🇩🇪 XRECHNUNG 2.1 UBL

| 属性                  | 值                       |
| --------------------- | ------------------------ |
| **国家 / 地区**       | 德国                     |
| **文档类型**          | 发票、贷项通知单         |
| **格式**              | UBL                      |
| **标准**              | XRechnung 2.1            |
| **基于**              | EN 16931 (OASIS UBL 2.1) |

XRechnung 2.1 实现了 EN 16931 核心发票标准，并扩展了德国 CIUS（核心发票使用规范）。此版本通过增强的 Schematron 规则和更严格的符合性检查，改进了验证。
