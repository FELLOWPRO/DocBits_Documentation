# 🇩🇪 XRECHNUNG 3.0.2 UBL

| 属性                 | 值                       |
| -------------------- | ------------------------ |
| **国家 / 地区**      | 德国                     |
| **文档类型**         | 发票、贷项通知单         |
| **格式**             | UBL                      |
| **标准**             | XRechnung 3.0.2          |
| **基于**             | EN 16931 (OASIS UBL 2.1) |

XRechnung 3.0.2 是德国电子发票标准的当前版本，与最新的 EN 16931 更新保持一致。这是最新的维护版本，包含更新后的业务规则和 Schematron 验证，可改进符合性测试。
