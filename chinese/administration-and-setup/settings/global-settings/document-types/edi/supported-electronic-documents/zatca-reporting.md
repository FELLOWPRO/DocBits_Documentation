# 🇸🇦 ZATCA REPORTING

| 属性                 | 值                                    |
| -------------------- | ------------------------------------- |
| **国家 / 地区**      | 沙特阿拉伯                             |
| **文档类型**         | 已报告发票                             |
| **格式**             | UBL 2.1 XML                           |
| **标准**             | ZATCA Reporting（Phase 2 集成）        |

ZATCA Reporting 指 Phase 2 集成模式，即在标准税务发票开具后 24 小时内将其报告给 ZATCA 平台。已报告的发票包含加密印章、二维码，以及由 ZATCA 的 Fatoorah 门户分配的 UUID。
