# 🇸🇦 ZATCA SIMPLIFIED

| 属性                 | 值                           |
| -------------------- | ---------------------------- |
| **国家 / 地区**      | 沙特阿拉伯                   |
| **文档类型**         | 简化税务发票                 |
| **格式**             | UBL 2.1 XML                  |
| **标准**             | ZATCA 简化税务发票           |

ZATCA 简化税务发票用于沙特阿拉伯的 B2C 交易，交易总额（含增值税）不超过 1,000 沙特里亚尔 (SAR)。与标准税务发票不同，简化发票无需提供买方身份信息，但必须包含二维码，其中以 TLV 编码卖方信息、增值税金额和时间戳。
