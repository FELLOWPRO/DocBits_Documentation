# 🇸🇦 ZATCA TAX INVOICE

<!-- edocs-country-scope -->

{% hint style="info" %}
请参阅国家指南，了解版本限制、实际生效的配置和国家说明视频。 [沙特阿拉伯](countries/saudi-arabia.md). 这些名称描述不同的流程和发票变体。成功解析不代表已完成签名、核准或通过 ZATCA 申报。
{% endhint %}

| 属性                 | 值                         |
| -------------------- | -------------------------- |
| **国家 / 地区**      | 沙特阿拉伯                 |
| **文档类型**         | 标准税务发票               |
| **格式**             | UBL 2.1 XML                |
| **标准**             | ZATCA 标准税务发票         |

ZATCA 税务发票是沙特阿拉伯电子发票系统中的标准 B2B 税务发票格式。它要求完整的买方和卖方身份信息（包括增值税登记号）、包含增值税计算的详细行项目，并且必须先通过 ZATCA 平台清算，才能分享给买方。
