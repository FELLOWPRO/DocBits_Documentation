# 🇩🇪 ZUGFERD 1.0 COMFORT

| 属性                 | 值                         |
| -------------------- | ---------------------------- |
| **国家 / 地区**      | 德国                         |
| **文档类型**         | 发票、贷项通知单             |
| **格式**             | CII（嵌入 PDF/A-3）           |
| **标准**             | ZUGFeRD 1.0，Comfort 配置文件 |
| **基于**             | ZUGFeRD 1.0 规范              |

ZUGFeRD 1.0 的 Comfort 配置文件在 Basic 配置文件的基础上，增加了付款条款、交付信息和详细税额明细等字段。它支持在无需手动录入数据的情况下全自动处理发票。

## 支持状态

| 组件             | 状态       |
| ---------------- | ----------- |
| 预览             | ✅ 支持     |
| 字段提取         | ✅ 支持     |
| 转换             | ✅ 支持     |
