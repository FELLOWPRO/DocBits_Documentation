# 🇩🇪 ZUGFERD 1.0 EXTENDED

<!-- edocs-country-scope -->

{% hint style="info" %}
请参阅国家指南，了解版本限制、实际生效的配置和国家说明视频。 [德国](countries/germany.md). 语法、发布版本和业务规范是不同的选择。不要根据共用的 1p0 标记推断 Factur-X 发布版本。
{% endhint %}

| 属性                 | 值                            |
| -------------------- | ----------------------------- |
| **国家 / 地区**      | 德国                          |
| **文档类型**         | 发票、贷项通知单                |
| **格式**             | CII（嵌入 PDF/A-3）            |
| **标准**             | ZUGFeRD 1.0，Extended 配置文件  |
| **基于**             | ZUGFeRD 1.0 规范                |

ZUGFeRD 1.0 的 Extended 配置文件是最全面的配置文件，支持贸易会计、保理和详细物流信息等其他业务场景。它包含 Basic 和 Comfort 中的所有字段，以及行业特定扩展。
