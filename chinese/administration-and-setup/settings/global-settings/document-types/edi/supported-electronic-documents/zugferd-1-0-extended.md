# 🇩🇪 ZUGFERD 1.0 EXTENDED

| 属性                 | 值                            |
| -------------------- | ----------------------------- |
| **国家 / 地区**      | 德国                          |
| **文档类型**         | 发票、贷项通知单                |
| **格式**             | CII（嵌入 PDF/A-3）            |
| **标准**             | ZUGFeRD 1.0，Extended 配置文件  |
| **基于**             | ZUGFeRD 1.0 规范                |

ZUGFeRD 1.0 的 Extended 配置文件是最全面的配置文件，支持贸易会计、保理和详细物流信息等其他业务场景。它包含 Basic 和 Comfort 中的所有字段，以及行业特定扩展。

## 支持状态

| 组件               | 状态        |
| ------------------ | ----------- |
| 预览               | ✅ 支持      |
| 字段提取           | ✅ 支持      |
| 转换               | ✅ 支持      |
