# 🇩🇪 ZUGFERD 2.3.2

<!-- edocs-country-scope -->

{% hint style="info" %}
请参阅国家指南，了解版本限制、实际生效的配置和国家说明视频。 [德国](countries/germany.md). 语法、发布版本和业务规范是不同的选择。不要根据共用的 1p0 标记推断 Factur-X 发布版本。
{% endhint %}

| 属性                 | 值                     |
| -------------------- | ---------------------- |
| **国家 / 地区**      | 德国                   |
| **文档类型**         | 发票、贷项通知单       |
| **格式**             | CII（嵌入 PDF/A-3）     |
| **标准**             | ZUGFeRD 2.3.2          |
| **基于**             | EN 16931               |

ZUGFeRD 2.3.2 于 2024 年 11 月发布，与 Factur-X 1.0.07.2 等效。此维护版本修正了 Schematron 规则，更新了代码列表，并改进了业务规则验证。
