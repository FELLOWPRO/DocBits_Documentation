# 🇩🇪 ZUGFERD 2.3

| 属性                 | 值                     |
| -------------------- | ---------------------- |
| **国家 / 地区**      | 德国                   |
| **文档类型**         | 发票、贷项通知单       |
| **格式**             | CII（嵌入 PDF/A-3）     |
| **标准**             | ZUGFeRD 2.3            |
| **基于**             | EN 16931               |

ZUGFeRD 2.3 于 2024 年 9 月发布，与 Factur-X 1.0.07 等效。它将 CII XML 更新为 D22B 规范，增加了改进后的验证规则，并引入对 XRechnung 参考配置文件的支持，以满足德国 B2G 要求。

## 支持状态

| 组件               | 状态         |
| ------------------ | ------------ |
| 预览               | ✅ 支持       |
| 字段提取           | ✅ 支持       |
| 转换               | ✅ 支持       |
