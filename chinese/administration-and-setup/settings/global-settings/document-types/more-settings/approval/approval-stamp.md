# 审批印章

启用审批印章后，审批文档时会添加审批人的姓名和日期。印章、PDF 下载以及 IDM 导出是不同环节，请在所用工作流中分别检查。

## 查找此选项

1. 使用管理员帐户打开 **设置 → 文档类型**。找到要配置的类型，例如 **发票**，然后选择该卡片上的**齿轮图标**。齿轮图标会打开该文档类型的 **更多设置**；**布局** 和 **字段** 会打开不同的编辑器。

   <figure><img src="../../../../../../.gitbook/assets/site-extra-document-types-zh.png" alt="中文文档类型页面；Standard 和 Extraction 仍为英文。文档类型激活与提取模式属于独立配置。"><figcaption><p>中文文档类型页面；Standard 和 Extraction 仍为英文。文档类型激活与提取模式属于独立配置。</p></figcaption></figure>

2. 在 **更多设置** 中展开 **审批与拒绝**。找到 **审批印章** 开关，它位于 **导出前审批**、**二次审批** 和 **审批历史记录** 旁边。截图展示设置位置，不代表文档已生成印章。

   <figure><img src="../../../../../../.gitbook/assets/site-extra-approval-settings-zh.png" alt="发票文档类型的审批与拒绝设置。界面中的“出口前批准”指“导出前审批”，并非贸易出口；审批印章与审批历史记录为独立选项。"><figcaption><p>发票文档类型的审批与拒绝设置。界面中的“出口前批准”指“导出前审批”，并非贸易出口；审批印章与审批历史记录为独立选项。</p></figcaption></figure>

3. 只有在组织内就审批和导出方式达成一致后，才启用此开关。记录更改前的设置，以便验证其对测试发票的影响。

## 验证审批印章

将此文档类型的合成发票提交到已配置的审批工作流。在 **待审批** 页面上，使用获授权的测试帐户审批该发票。当前 DocBits Web 客户端会在审批时检查 审批印章选项，并添加包含审批人姓名和日期的印章注释。重新打开已审批的文档，检查其中的注释以及工作流实际使用的下载版 PDF。如果未显示印章，请检查文档类型、审批状态、相关设置和导出配置。

审批印章与 **二次审批** 和 **审批历史记录** 相互独立。启用其中一项并不能证明其他选项也已配置。可用的仪表板下载操作和 IDM 导出格式取决于具体环境，本页面尚未验证这些内容，因此本指南不承诺特定的下载菜单标签或自动 IDM 输出。

请使用测试文档完成审批，再检查实际历史记录、印章和下载结果；配置页面本身不能证明最终处理结果。
