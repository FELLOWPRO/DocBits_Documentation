# 自动匹配和导出选项

**采购订单**卡片末尾的三项设置用于决定哪些用户可以看到 PO 匹配快捷操作，以及哪些文档在匹配后可以自行导出。每次仅适用于一种文档类型。

<figure><img src="../../../../../../.gitbook/assets/doc-type-settings-po-options.png" alt="文档类型设置中的采购订单卡片，包含所有 PO 选项"><figcaption><p>采购订单卡片。下方的三个选项是最后三行。</p></figcaption></figure>

## 允许自动导出无法匹配采购订单行的文档

采购订单匹配后，通常只有**完全匹配**的文档才能自动导出。启用此开关后，状态为**没有可匹配的采购订单行**的文档也可以自动导出。此状态表示采购订单中没有可与发票匹配的行。

* **关闭（默认）：** 只有完全匹配的文档会自动导出。
* **开启：** 完全匹配的文档以及没有可匹配采购订单行的文档都会自动导出。

只有在文档设置为自动导出时，此开关才会生效，例如使用[**采购订单 100% 匹配时自动导出**](../../../../document-processing/module/auto-export-if-po-matched-100.md)或 DocFlow 导出卡片时。它不会改变行项目的匹配方式。

## 自动匹配和导出对以下用户可见

采购订单匹配界面中有一个**自动匹配和导出**操作。该操作会匹配文档，并在匹配后立即导出。此设置用于控制哪些用户可以看到该操作：

| 值 | 谁可以看到该操作 |
| ----- | ------------------- |
| **仅管理员**（默认） | 管理员 |
| **所有用户** | 所有能够打开采购订单匹配界面的用户 |

管理员始终可以看到该操作。此设置不会启用此功能。组织必须启用[**采购订单 100% 匹配时自动导出**](../../../../document-processing/module/auto-export-if-po-matched-100.md)模块。

## 使用行项目净额计算匹配总额对以下用户可见

采购订单匹配界面可以直接使用已匹配发票行项目的**净额**计算**匹配总额**，而不是通过计算得出。此设置用于控制哪些用户可以启用该计算方式：

| 值 | 谁可以看到该开关 |
| ----- | ------------------- |
| **仅管理员**（默认） | 管理员 |
| **所有用户** | 所有能够打开采购订单匹配界面的用户 |

启用该开关后，匹配总额将直接使用已匹配发票行项目中的净额。
