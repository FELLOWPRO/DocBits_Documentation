# V2：Infor OS Portal SSO

如果贵组织通过 **Infor OS Portal V2** 启动 DocBits，请使用本指南。您需要同时拥有 Infor 和 DocBits 的管理员权限。测试 SSO 时，请保持现有的 DocBits 管理员会话处于打开状态。Infor 菜单和字段名称取决于租户的发行版本；请向您的 Infor 管理员确认。

## 1. 获取 DocBits SAML 值

在正确的 DocBits 组织中，打开 **设置 → 集成与 SSO → SSO 服务提供商设置**。复制 **Entity ID**、**SSO Url** 和 **SLO Url**。如果 Infor 服务提供商表单要求签名证书，请使用 **下载证书**。**下载元数据**是 DocBits 的*服务提供商* XML；它不是第 3 步中使用的 Infor 身份提供商元数据。Sandbox 图片中的 URL 仅属于此测试组织。

![英文 Sandbox 测试组织中当前的 DocBits Integration & SSO 屏幕，其中显示服务提供商 Entity ID、SSO Url、SLO Url 以及证书/元数据下载选项。](../../../../../../.gitbook/assets/dbdc-182-infor-v2-sso-settings-en.png)

## 2. 在 Infor 中将 DocBits 添加为服务提供商

在 Infor OS Portal 中，如果您的租户采用此路径，请打开 **OS → 安全 → 安全管理 → 服务提供商**。添加一个 SAML 服务提供商，并使用以下映射：

| Infor 字段 | DocBits 值 |
| --- | --- |
| Entity ID | Entity ID |
| SSO Endpoint | SSO Url，即断言使用者端点 |
| SLO Endpoint | SLO Url，即注销端点 |
| Signing Certificate | 下载证书（如有要求） |
| Name ID Format / Mapping | 电子邮件地址；请先确认其与 DocBits 用户匹配 |

先前的指南曾指示用户将 **SLO Url** 填入 **SSO Endpoint**。这是错误的：每个 URL 都应填入对应字段。保存服务提供商。Infor 的[服务提供商指南](https://docs.infor.com/inforos/latest/en-us/useradminlib_cloud/inforos_security/jho1449385888462.html)介绍了导航路径和所需角色；其 [SAML 字段指南](https://docs.infor.com/inforos/2026.09/en-us/useradminlib_cloud/mineeag/min1772650388038.html)说明了各端点的用途。

## 3. 导入 Infor 身份提供商元数据

在 Infor 中打开已保存的服务提供商，然后选择 **查看 → 导出 SAML 元数据**，获取 Infor 身份提供商的元数据。返回 DocBits，打开 **设置 → 集成与 SSO → 身份服务提供商设置**。输入 Infor **租户 ID**，在 **上传文件** 下选择 Infor XML，然后选择 **配置**。请与您的 Infor 管理员确认租户 ID 和元数据。请勿在此处上传第 1 步中的 DocBits 服务提供商 XML。

## 4. 在 Infor OS Portal 中添加 DocBits 磁贴

在 Infor OS Portal 中，打开 **门户 → 应用程序 → 添加应用程序**。为您的租户将 DocBits 注册为非 Infor 应用程序，提供显示名称、图标和唯一的 Logical ID，并将 **应用程序 URL** 设置为常用的 DocBits 登录或启动 URL。门户应用程序 URL 用于打开用户界面；它**不是**第 2 步中的 SAML SSO/ACS 端点。请参阅 Infor 的[非 Infor 应用程序指南](https://docs.infor.com/inforos/latest/en-us/useradminlib_cloud/inforospag/lsm1436532874794.html)，了解当前表单、导航选项和权限。授予测试用户访问门户应用程序的权限。

## 5. 使用一个用户进行验证

在单独的浏览器会话中退出登录，从 Infor 打开 DocBits 磁贴，并确认分配给该用户的电子邮件地址能解析到正确的 DocBits 账户和组织。也请检查退出登录是否正常。如果任一环节失败，请与两位管理员一起核对 Infor 元数据、SSO/SLO URL、证书、Name ID 和门户磁贴 URL。测试完成前，请保留原有的管理员会话。

**验证范围：**上方的 DocBits 屏幕截图采集自英文 Sandbox 测试组织。由于没有可用的 Infor 租户，本次更新未测试 Infor 门户菜单、元数据导入、磁贴创建和实时 SSO。旧的外部托管 Infor 图片（包括私人邮件附件）已移除；有关该界面的信息，请参阅链接的 Infor 文档并咨询您的租户管理员。
