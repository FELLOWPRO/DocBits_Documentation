# 供应商权限

### 供应商组

<figure><img src="../../../.gitbook/assets/supplier_group.png" alt="供应商组"><figcaption><p>供应商组页面</p></figcaption></figure>

管理供应商组，按类型、地区或角色对供应商进行分类。每个组都有一个 **Group API Name**（用于集成）和一个 **Group Name**（显示名称）。

点击 **+ New** 创建组。使用每行中的三点菜单进行编辑或删除。

### 用户与供应商组映射

<figure><img src="../../../.gitbook/assets/user_supplier_group_mapping.png" alt="用户与供应商组映射"><figcaption><p>用户与供应商组映射页面</p></figcaption></figure>

将用户分配到供应商组，以控制哪些员工可以访问和管理特定供应商集合。每个组均以可展开区域显示，其中列出已分配的用户及成员数量。

在组内点击 **+ New** 添加用户映射。使用三点菜单移除映射。
