# 文档训练

文档训练用于教会 DocBits 在尚未正确识别的文档中查找字段值。请分别训练文档头部字段和行项目字段。

要查看文档类型的分类训练，请打开 **设置** → **文档类型**，然后在现有文档类型卡片上选择 **模型训练**。此视图显示训练样本以及 **导入**、**训练模型** 和 **测试分类** 控件。修改前请先检查现有样本；后续训练或分类测试应使用经过批准的测试文件。

* [训练文档头部字段](training-header-fields.md): 标记日期、总金额等文档头部值在文档中的位置。
* [训练行项目字段和表格](training-line-fields-table-training/README.md): 为特定供应商定义行项目表格结构。

训练结果取决于所用的文档。在依赖这些结果之前，请使用另一份测试文档检查提取的值。
