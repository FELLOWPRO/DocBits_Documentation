## **用途：**

此工作流卡用于比较采购订单与相关文档中的物料 ID，确保包含了正确的物料。该卡会检查采购订单中的物料 ID 是否与文档中的物料 ID 匹配。如果发现差异，此比较可以触发相应操作，确保文档中的物料与采购订单一致。

## **卡片组件：**

1. **任意 / 全部：**
   * **说明**：定义该条件适用于任意还是全部物料 ID 比较实例。
   * **选项**：
     * **任意**：只要采购订单中的任意一个物料 ID 与文档中的物料 ID 匹配，条件就满足。
     * **全部**：只有采购订单中的所有物料 ID 都与文档中的物料 ID 匹配，条件才满足。
2. **运算符：**
   * **说明**：定义比较采购订单上的物料 ID 与文档上的物料 ID 时所用的条件。
   * **选项**：
     * **等于 (=)**：验证采购订单中的物料 ID 是否与文档中的物料 ID 完全匹配。
     * **不等于 (≠)**：确保采购订单中的物料 ID 与文档中的物料 ID 不匹配。

## **功能：**

* **条件评估：**系统根据所选运算符，将采购订单中的物料 ID 与文档中的物料 ID 进行比较。如果比较条件为真（例如，物料 ID 匹配或不匹配），工作流将据此继续执行。
* **执行操作：**
  * **条件为真：**如果条件评估结果为真（例如，采购订单中的物料 ID 等于文档中的物料 ID），工作流将执行为真条件设置的操作（例如审批或进一步处理）。
  * **条件为假：**如果条件评估结果为假（例如，采购订单中的物料 ID 与文档中的物料 ID 不匹配），工作流将不会继续执行。

## **设置和配置：**

* 用户通过选择采购订单和文档中的物料 ID 来配置此卡。然后，他们选择合适的运算符（Equals 或 Not Equals）来定义如何比较物料 ID。最后，用户选择比较条件适用于任意还是全部物料 ID。

## **示例场景：**

* 一张发票列出了 ID 为 "ABC123" 的物料，相关采购订单中也包含 ID 为 "ABC123" 的物料。使用 "Equals" 运算符时，此卡会比较文档中的物料 ID 与采购订单中的物料 ID。由于物料 ID 匹配，工作流将顺利继续

## **结论：**

“Item ID Comparison”工作流卡可确保文档中的物料 ID 与采购订单中的物料 ID 一致。这有助于避免物料清单出现差异，并确保根据采购订单处理正确的物料。支持按任意或全部实例进行比较，可灵活适应不同用例，提高采购工作流的准确性和效率。
