# 文档字段中的税额

<figure><img src="../../../../../.gitbook/assets/workflow_card_condition_po_operator_tax_charge_id_v2-zh-cn.png" alt="文档字段中的税额, 版本 2" width="634"><figcaption><p>版本 2</p></figcaption></figure>

## **用途：**

此工作流卡用于评估文档字段中的税额是否与采购订单中的税额相符，并根据费用 ID 考虑容差。该卡会比较这两个税额（一个来自文档字段，另一个来自采购订单），并检查它们是否符合指定条件（例如，等于、大于、小于等）。这有助于确保税额一致，并标记差异，以便在采购工作流中进一步审核或审批。

## **卡片组件：**

1. **字段名称**
   * **描述**：指定文档中包含待比较税额的字段。
   * **详细信息**：此字段必须与文档中税额的确切标识符匹配。
2. **运算符**
   * **描述**：定义文档税额与采购订单税额比较时应用的条件。
   * **选项**：
     * **等于 (=)**：检查文档字段中的税额是否与采购订单中的税额相符。
     * **不等于 (≠)**：确保文档字段中的税额与采购订单中的税额不相符。
     * **大于 (>)**：验证文档字段中的税额是否大于采购订单中的税额。
     * **大于或等于 (≥)**：检查文档字段中的税额是否大于或等于采购订单中的税额。
     * **小于 (<)**：验证文档字段中的税额是否小于采购订单中的税额。
     * **小于或等于 (≤)**：检查文档字段中的税额是否小于或等于采购订单中的税额。
3. **主数据表**
   * **描述**：包含采购订单详细信息（包括费用 ID 和税额）的表。
   * **详细信息**：此表必须引用与采购订单税额关联的费用 ID。
4. **容差金额**
   * **描述**：税额允许变化的阈值，用于处理税额计算中的细微差异。
   * **详细信息**：容差金额应为数值，用于定义税额之间允许的最大差值。
5. **容差类型**
   * **描述**：指定所应用的容差类型，可以是绝对值或百分比。
   * **选项**：
     * **数值**：容差为固定数值。
     * **百分比**：容差按税额的百分比计算。

## **功能：**

* **条件评估：**系统会根据主数据表中的费用 ID 引用，评估文档字段中的税额与采购订单中的税额比较后是否符合指定条件。评估时会考虑容差金额和类型，以允许税额计算中的细微差异。
* **执行操作：**
  * **条件为真**：如果文档字段中的税额与采购订单税额比较后符合条件（在容差金额和类型允许的范围内），工作流将继续。
  * **条件为假**：如果文档字段中的税额不符合条件（超出容差范围或比较结果不满足条件），工作流将停止。

## **设置和配置：**

* 用户必须选择包含待比较税额的文档字段。然后选择比较运算符（例如，等于、大于）。接下来，用户需要指定主数据表引用，并设置容差金额和类型，以处理税额中的细微差异。

## **示例场景：**

* 一张发票列出的税额为 $100。主数据表中对应的采购订单指定税额为 $95。系统使用“大于”运算符，将文档税额（$100）与采购订单税额（$95）进行比较，并设置容差为 $10（绝对值容差类型）。由于差额 $5 在容差范围内，工作流将继续，且不会触发任何警报。

## **结论：**

“文档字段税额比较”工作流卡可确保文档中的税额与采购订单详细信息相符，并允许指定容差范围内的细微差异。通过自动执行此检查，组织可以减少税额计算错误、简化采购流程，并减少人工干预或审批的需求。
