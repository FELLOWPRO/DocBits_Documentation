# 商品价格表中的供应商商品 ID

<figure><img src="../../../../../.gitbook/assets/workflow_card_condition_quote_supplier_item_number_exists_v2-zh-cn.png" alt="商品价格表中的供应商商品 ID, 版本 2" width="634"><figcaption><p>版本 2</p></figcaption></figure>

## 用途：

此工作流卡片用于检查文档各行上的供应商商品 ID 能否在供应商商品价格表中找到。它可用于在其他报价比较运行之前，确认 DocBits 是否持有该文档供应商针对报价中商品的价格数据，也可用于将含有未知商品的文档转交人工检查。工作流会根据结果沿着真条件或假条件继续。

## 卡片组件：

1. **任意/全部**
   * **描述：** 定义文档表格中应有一行还是每一行都满足条件。
   * **选项：**
     * **任何：** 如果至少有一行满足条件，则条件为真。
     * **全部：** 只有每一行都满足条件时，条件才为真。
2. **操作员**
   * **描述：** 定义供应商商品 ID 应在供应商商品价格表中找到，还是不应找到。
   * **选项：**
     * **是：** 如果某行的供应商商品 ID 在供应商商品价格表中，则该行满足条件。
     * **不是：** 如果某行的供应商商品 ID 不在供应商商品价格表中，则该行满足条件。

## 功能：

* **条件评估：** 卡片读取文档表格中每一行的供应商商品 ID（列 `SUPPLIER_ITEM_NUMBER`），并检查供应商商品价格表中是否有对应条目。随后，所有行的结果通过 **任何** 或 **全部** 合并。
* **有效日期：** 如果供应商商品价格表中的某个条目设有开始日期或结束日期，而文档日期不在该期间内，卡片会在工作流日志中注明。此说明不会改变卡片的结果。
* **执行操作：**
  * **条件为真：**\
    使用 **是** 时，供应商商品 ID（按所选的任何或全部）在供应商商品价格表中；使用 **不是** 时，则不在其中。工作流沿着真条件继续，例如继续进行价格比较。
  * **条件为假：**\
    如果条件不满足，工作流沿着假条件继续，例如将文档送交人工审核。
* **缺少数据：** 如果文档没有表格、有多个表格、无法从表格中读取任何行，或者文档根本没有供应商商品价格数据，卡片不会评估条件，并会在工作流日志中报告缺少的数据。如果未设置 **任意/全部** 选项，卡片会在日志中注明并使用 **全部**。
* **错误：** 如果表格中的某一行没有 `SUPPLIER_ITEM_NUMBER` 列，卡片会以错误结束。如果未设置运算符，卡片会报告设置错误。

## 设置和配置：

* 可以从 **与报价比较** 类别中添加此卡片，然后选择 **任何** 或 **全部** 以及运算符（**是** 或 **不是**）。最后设置继续条件（真或假），以决定工作流的下一步。
* 此卡片适用于恰好有一个表格且表格行包含供应商商品 ID 的文档。

## 结论：

“商品价格表中的供应商商品 ID”工作流卡片可显示文档上的商品在供应商商品价格表中是否已知。它可以作为报价工作流中的第一项检查，使后续的价格、商品编号和计量单位比较只针对商品具有价格数据的文档运行。
