# 表格日期与当前日期

<figure><img src="../../../../../.gitbook/assets/workflow_card_condition_compare_table_date_to_current_date_v2-zh-cn.png" alt="表格日期与当前日期, 版本 2" width="634"><figcaption><p>版本 2</p></figcaption></figure>

容差窗口的计算方式以及“今天或明天”等示例，详见 [日期容差](../../date-tolerances.md)。

## 用途：

此工作流卡片会将文档表格每一行中的日期（例如交货日期）与当前日期进行比较。可以设置以天为单位的容差，并选择计入的星期几，例如只使用工作日。它可用于检查文档上的日期是在过去、今天、几天之内还是在将来。工作流会根据结果沿着真条件或假条件继续。

## 卡片组件：

1. **任意/全部**
   * **描述：** 定义表格中应有一行还是每一行都满足条件。
   * **选项：**
     * **任何：** 如果至少有一行满足条件，则条件为真。
     * **全部：** 只有每一行都满足条件时，条件才为真。
2. **表名**
   * **描述：** 包含日期的文档表格的名称。
3. **列名称**
   * **描述：** 表格中包含日期的列。
4. **操作员**
   * **描述：** 在考虑容差的情况下，定义如何将表格中的日期与当前日期进行比较。
   * **选项：**
     * **等于：** 日期在当前日期前后的容差范围内。
     * **不等于：** 日期在容差范围之外。
     * **大于：** 日期在容差范围之后。
     * **大于或等于：** 日期在容差范围内或之后。
     * **少于：** 日期在容差范围之前。
     * **小于或等于：** 日期在容差范围内或之前。
5. **价值**
   * **描述：** 以天为单位的容差。
   * **详细信息：** 容差范围从当前日期往前和往后各延伸这一天数。只计入在 **允许容忍天数** 下所选的日子。如果未设置值，则使用 0 天容差，此时范围仅为当前日期。
6. **允许容忍天数**
   * **描述：** 视为可接受日期的星期几。
   * **选项：** 周一至周日，可以选择多天。

## 功能：

* **条件评估：** 卡片读取具有指定名称的第一个表格中每一行所选列的日期，并将其与当前日期（UTC 日期）进行比较。容差范围通过从当前日期往前和往后各数出指定天数来计算。未选择的星期几不计入天数，因此范围会越过这些日子延伸，而这些日子仍处于范围之内。例如，容差为 2 天、只选择周一至周五且当前日期为周五时，范围为从周三到下周二。
* **可接受的日期：** 除比较之外，每一行的日期还应落在所选的星期几之一。只有两项检查都通过时，该行才满足条件。随后，所有行的结果通过 **任何** 或 **全部** 合并。
* **执行操作：**
  * **条件为真：**\
    对于任何或全部行，日期满足所选运算符并落在可接受的日期上。工作流沿着真条件继续。
  * **条件为假：**\
    如果条件不满足，工作流沿着假条件继续，例如将文档送交人工审核。
* **缺少数据：** 如果卡片上未设置表名、列名称或可接受的日期，文档没有具有指定名称的表格，表格中的某一行没有该列，或者表格没有任何行，卡片不会评估条件，并会在工作流日志中报告缺少的数据。如果未设置 **任意/全部** 选项，卡片会在日志中注明并使用 **全部**。
* **错误：** 如果日期列中的某个值无法读取为日期，卡片会以错误结束。

## 设置和配置：

* 可以从 **桌子** 类别中添加此卡片，然后设置 **任何** 或 **全部**、表名、列名称、运算符、以天为单位的容差以及可接受的星期几。最后设置继续条件（真或假），以决定工作流的下一步。

## 结论：

“表格日期与当前日期”工作流卡片会将行项目日期与今天进行核对，其容差可以限定为工作日或任意其他星期组合。这有助于标记日期过早、过晚或落在不可接受日期上的文档。
