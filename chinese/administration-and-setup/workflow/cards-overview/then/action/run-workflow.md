# 运行工作流

<figure><img src="../../../../../.gitbook/assets/image (380).png" alt="" width="563"><figcaption></figcaption></figure>

## 用途：

**“Run Workflow”（运行工作流）**卡片允许用户从可用工作流列表中动态执行选定的工作流。此卡片适用于多个工作流相互关联的自动化流程，可帮助简化操作。

## 卡片组件：

1. **Workflow（工作流）**
   * **描述：**指定条件评估为 true 时要执行的工作流。
   * **详情：**提供包含所有可用工作流的下拉列表供用户选择。

## 功能：

* **条件评估：**只有当 **“Where”** 和 **“And Sections”** 均评估为 true 时，卡片才会执行选定的工作流。
  * 如果任一条件为 false，则不会执行任何操作，也不会触发工作流。
* **工作流执行：**
  * 满足条件时，会自动触发指定的工作流。
  * 不满足条件时，不会执行任何工作流。

## 设置和配置：

1. **选择工作流：**从可用工作流的**下拉列表**中选择要触发的工作流。
2. **定义条件：**配置 **“Where”** 和 **“And Sections”**，指定工作流执行必须满足的条件。

## 总结：

**“Run Workflow”（运行工作流）**卡片提供了一种便捷高效的工作流关联方式，可轻松实现多步骤流程自动化。确保 **“Where”** 和 **“And Sections”** 中的条件均已满足后，用户即可动态执行工作流并减少人工干预。
