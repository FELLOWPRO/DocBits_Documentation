# 为群组分配文档并创建任务/通知

<figure><img src="../../../../../.gitbook/assets/image (145).png" alt="" width="563"><figcaption></figcaption></figure>

## **用途**

“**为群组分配文档并创建任务/通知**”工作流卡会将文档分配给指定群组，创建包含可自定义详情的任务或通知，并可选择向群组发送电子邮件通知。此卡还支持为分配设置数值优先级，以确定执行顺序。

## **卡片组件**

1. **群组名称**
   * **说明：**指定接收任务或通知的群组。
   * **详情：**通过下拉菜单选择要分配文档和任务/通知的群组名称。
2. **任务/通知**
   * **说明：**指定要为群组创建的操作类型。
   * **详情：**根据所需操作，从下拉菜单中选择“Task”（任务）或“Notification”（通知）。
3. **标题**
   * **说明：**提供任务或通知的标题。
   * **详情：**填写简洁且具有描述性的任务或通知标题。
4. **描述**
   * **说明：**进一步说明任务或通知。
   * **详情：**填写有关任务用途或通知内容的其他详情。
5. **优先级**
   * **说明：**定义任务或通知的紧急程度。
   * **选项：**
     * **High（高）：**需要立即处理。
     * **Medium（中）：**重要但不紧急。
     * **Low（低）：**可以稍后处理。
6. **发送邮件**
   * **说明：**设置是否向群组发送电子邮件通知。
   * **选项：**
     * **True（是）：**发送电子邮件通知。
     * **False（否）：**不发送电子邮件。
7. **数值**
   * **说明：**设置文档分配的数值优先级。
   * **详情：**输入数值；数值越小，优先级越高。

## **功能**

* **条件评估：**\
  仅当满足已配置的工作流条件时，卡片才会执行操作。
* **文档分配和任务/通知创建：**\
  文档会分配给“群组名称”字段中指定的群组。系统会根据配置的标题、描述和优先级创建任务或通知。
* **电子邮件通知：**\
  如果“发送邮件”设置为 True，系统会向群组发送电子邮件通知，告知其有相关任务或通知。

## **设置和配置**

1. **定义群组名称：**
   * 在“群组名称”字段中输入群组名称。
2. **选择任务/通知：**
   * 在“任务/通知”下拉菜单中选择“Task”（任务）或“Notification”（通知）。
3. **设置任务/通知详情：**
   * 输入任务或通知的标题和描述。
   * 从下拉菜单中选择优先级（High、Medium 或 Low）。
4. **启用电子邮件通知：**
   * 根据是否需要发送电子邮件通知，将“发送邮件”选项设置为 True 或 False。
5. **分配数值优先级：**
   * 在“数值”字段中输入数值，以确定分配优先级；数值越小，优先级越高。
6. 保存卡片配置并启用工作流。

## **结论**

“为群组分配文档并创建任务/通知”工作流卡可确保文档分配给适当的群组，同时创建具有可自定义优先级和电子邮件通知选项的任务或通知。这有助于简化文档管理并提高工作流效率。
