# 为用户分配文档并创建任务/通知

<figure><img src="../../../../../.gitbook/assets/image (146).png" alt="" width="563"><figcaption></figcaption></figure>

## **用途**

“**为用户分配文档并创建任务/通知**”工作流卡片可将文档分配给指定用户，创建包含可配置详细信息的任务或通知，并可选择向用户发送电子邮件通知。此卡片还支持设置数值优先级，以确定执行顺序。

## **卡片组件**

1. **用户**
   * **说明：**指定接收任务或通知的用户。
   * **详细信息：**通过下拉菜单选择要将文档和任务/通知分配给的用户。
2. **任务/通知**
   * **说明：**指定要为用户创建的操作类型。
   * **详细信息：**根据预期操作，从下拉菜单中选择“任务”或“通知”。
3. **标题**
   * **说明：**任务或通知的标题。
   * **详细信息：**输入简洁且能说明内容的任务或通知标题。
4. **描述**
   * **说明：**任务或通知的补充详细信息。
   * **详细信息：**填写任务用途或为通知提供背景信息。
5. **优先级**
   * **说明：**定义任务或通知的紧急程度。
   * **选项：**
     * **高：**需要立即处理。
     * **中：**重要但不紧急。
     * **低：**可以稍后处理。
6. **发送邮件**
   * **说明：**设置是否向用户发送电子邮件通知。
   * **选项：**
     * **True：**向用户发送电子邮件通知。
     * **False：**不发送电子邮件通知。
7. **值**
   * **说明：**设置文档分配的数值优先级。
   * **详细信息：**输入数值；数值越低，优先级越高。

## **功能**

* **条件评估：**\
  只有满足已配置的工作流条件时，卡片才会执行操作。
* **文档分配与任务/通知创建：**\
  文档会分配给“用户”字段中指定的用户，并根据所提供的标题、描述和优先级创建任务或通知。
* **电子邮件通知：**\
  如果“发送邮件”设为 True，系统会向用户发送电子邮件，通知其有任务或通知。

## **设置与配置**

1. **选择用户：**
   * 从“用户”下拉菜单中选择用户。
2. **配置任务/通知详细信息：**
   * 从“任务/通知”下拉菜单中选择“任务”或“通知”。
   * 输入任务或通知的标题和描述。
   * 从下拉菜单中选择高、中或低，设置优先级。
3. **启用电子邮件通知：**
   * 根据是否需要发送电子邮件通知，将“发送邮件”设置为 True 或 False。
4. **设置数值优先级：**
   * 在“值”字段中输入数值以确定分配优先级；数值较低的项目会先处理。
5. 保存卡片配置并激活工作流。

## **结论**

“为用户分配文档并创建任务/通知”工作流卡片可确保将文档分配给相应用户，同时创建具有指定优先级的任务或通知，并可选择发送电子邮件通知。此卡片有助于简化任务分配并提高工作流效率。
