# 分配文档并创建任务/通知

<figure><img src="../../../../../.gitbook/assets/image (147).png" alt="" width="563"><figcaption></figcaption></figure>

## **用途**

“**根据决策表分配文档并创建任务/通知**”工作流卡片会分配文档，并根据可配置的详细信息创建任务或通知。受派人由决策表的返回结果确定，此卡片还支持设置优先级并发送电子邮件通知。

## **卡片组件**

1. **受派人类型**
   * **说明：**指定决策表的返回结果是将文档和任务/通知分配给用户还是群组。
   * **详情：**根据决策表的输出，将受派人类型配置为“User”或“Group”的字段。
2. **任务/通知**
   * **说明：**指定要为受派人创建的操作类型。
   * **详情：**根据工作流需要选择“Task”或“Notification”的下拉菜单。
3. **标题**
   * **说明：**任务或通知的标题。
   * **详情：**用于填写简明标题，以标识任务或通知的字段。
4. **描述**
   * **说明：**任务或通知的补充详细信息。
   * **详情：**用于说明任务或通知的用途和背景的字段。
5. **优先级**
   * **说明：**定义任务或通知的紧急程度。
   * **选项：**
     * **High：**需要立即处理。
     * **Medium：**重要但不紧急。
     * **Low：**可以稍后处理。
6. **受派人类型**
   * **说明：**此字段用于确定文档和任务/通知分配给哪种类型的受派人（用户或群组）。
   * **详情：**根据决策表的输出，通过下拉菜单选择将任务/通知分配给用户还是群组。
7. **发送邮件**
   * **说明：**配置是否向受派人发送电子邮件通知。
   * **选项：**
     * **True：**发送电子邮件通知。
     * **False：**不发送电子邮件通知。
8. **值**
   * **说明：**设置文档分配的数字优先级。
   * **详情：**用于输入数字的字段；数字越小，优先级越高。

## **功能**

* **条件评估：**\
  仅当满足工作流条件时，卡片才会执行其操作。
* **决策表评估：**\
  决策表用于确定文档和任务/通知是分配给用户还是群组。
* **文档分配和任务/通知创建：**\
  文档会分配给决策表返回的对象。系统会创建任务或通知，并应用指定的标题、描述和优先级。
* **电子邮件通知：**\
  如果“Send Mail”设置为 True，系统会向受派人发送电子邮件通知。

## **设置和配置**

1. **定义受派人类型：**
   * 根据决策表的输出，将受派人类型字段配置为“User”或“Group”。
2. **选择任务/通知：**
   * 在任务/通知下拉菜单中选择“Task”或“Notification”。
3. **设置任务/通知详细信息：**
   * 输入任务或通知的标题和描述。
   * 从下拉菜单中选择优先级（High、Medium 或 Low）。
4. **启用电子邮件通知：**
   * 根据是否需要发送电子邮件通知，将“Send Mail”选项设置为 True 或 False。
5. **设置数字优先级：**
   * 在“Value”字段中输入数字，以确定分配优先级；数字越小，处理顺序越靠前。
6. 保存卡片配置并激活工作流。

## **结论**

“根据决策表分配文档并创建任务/通知”工作流卡片可根据决策表结果，将任务或通知动态分配给合适的用户或群组。此卡片可帮助高效委派任务、自定义优先级，并选择性发送电子邮件通知，从而提升工作流响应效率。
