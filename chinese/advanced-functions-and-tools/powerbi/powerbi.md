# 通过 ClickHouse 连接

本指南将介绍如何使用 **ODBC 驱动程序**将 **ClickHouse** 连接到 **Power BI Desktop**。内容涵盖驱动程序安装、ODBC 配置、Power BI 集成以及设置数据刷新。

{% embed url="https://youtu.be/O1MtuXf_R_M" %}
{% endembed %}

#### 1. 安装 ClickHouse ODBC 驱动程序

* 从以下位置下载最新的 **ClickHouse ODBC Driver**：
  * [ClickHouse GitHub - clickhouse-odbc](https://github.com/ClickHouse/clickhouse-odbc)
* 运行安装程序并按照设置向导完成安装。

#### 2. 配置 ODBC 数据源

* 通过控制面板或 Windows 搜索打开 **ODBC 数据源管理器 (64 位)**。
* 转到 **系统 DSN** 选项卡，然后点击 **添加**。
* 从列表中选择 **ClickHouse ODBC Driver**，然后点击 **完成**。
