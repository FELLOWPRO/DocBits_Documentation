# API 凭据

## 列

* `id`：内部字段
* `org_id`：组织 ID
* `sub_org_id`：内部字段
* `title`：内部字段
* `credentials_type`：内部字段
* `credentials_json`：文本
* `created_by`：整数
* `created_on`：带时区的时间戳
* `last_modified_on`：带时区的时间戳
* `is_deleted`：布尔值
* `deleted_on`：带时区的时间戳
* `last_modified_by`：内部字段
* `deleted_by`：内部字段

## 分析与说明

```markdown
# 表文档：`public.api_credentials`

## 简介

`public.api_credentials` 表用于存储和管理 API 凭据。该表对于组织安全地处理 API 身份验证信息至关重要，可确保各种服务使用正确的凭据彼此交互。表中包含凭据类型、所属组织以及创建和修改相关的元数据。

## 字段说明

### id
- **含义**：表中每条记录的唯一标识符。
- **作用**：主键。
- **典型内容**：表示一组特定 API 凭据的通用唯一标识符（UUID）。

### org_id
- **含义**：拥有这些凭据的组织的标识符。
- **作用**：外键。
- **典型内容**：用于关联另一张表中该组织记录的 UUID。

### sub_org_id
- **含义**：主组织内子组织的标识符。
- **作用**：外键（可选）。
- **典型内容**：可能包含关联子组织的 UUID，也可能为 `None`。

### title
- **含义**：用于描述 API 凭据的标题。
- **作用**：描述性字段。
- **典型内容**：例如 "supplier_auth" 这样的字符串，用于表明凭据的用途或使用场景。

### credentials_type
- **含义**：指定所存储凭据的类型。
- **作用**：描述性字段。
- **典型内容**：例如 "ionapi" 这样的字符串，用于指明凭据采用的格式或协议。

### credentials_json
- **含义**：包含详细凭据信息的 JSON 对象。
- **作用**：技术字段。
- **典型内容**：包含多个键值对的 JSON 字符串，用于说明身份验证参数。

### created_by
- **含义**：创建凭据记录的用户 ID。
- **作用**：技术字段。
- **典型内容**：表示用户 ID 的整数。

### created_on
- **含义**：指示凭据创建时间的时间戳。
- **作用**：技术字段。
- **典型内容**：带时区的日期时间值，例如 `2024-04-08 11:54:55 UTC`。

### last_modified_on
- **含义**：指示凭据最后修改时间的时间戳。
- **作用**：技术字段。
- **典型内容**：带时区的日期时间值；如果从未修改，则为 `None`。

### is_deleted
- **含义**：指示凭据是否已标记为删除的标志。
- **作用**：技术字段。
- **典型内容**：布尔值，其中 `False` 表示凭据处于活动状态。

### deleted_on
- **含义**：指示凭据被标记为删除时间的时间戳。
- **作用**：技术字段。
- **典型内容**：带时区的日期时间值；如果未删除，则为 `None`。

### last_modified_by
- **含义**：最后修改凭据的用户标识符。
- **作用**：技术字段。
- **典型内容**：表示用户 ID 的字符字符串，也可能为 `None`。

### deleted_by
- **含义**：将凭据标记为删除的用户标识符。
- **作用**：技术字段。
- **典型内容**：表示用户 ID 的字符字符串，也可能为 `None`。
```
