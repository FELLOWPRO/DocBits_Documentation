## `public.auto_accounting` 表技术文档

### 简介

`public.auto_accounting` 表似乎用于管理和存储与不同供应商及组织相关的会计数据。该表记录财务交易信息，包括金额和分类账账户，这些信息对于财务报告和分析至关重要。

### 列说明

#### id

* **含义**：表中每条记录的唯一标识符。
* **作用**：主键。
* **典型内容**：用于唯一标识每条记录的 UUID 字符串。
* **说明**：确保每条记录都能被单独识别。

#### org\_id

* **含义**：与会计分录关联的组织标识符。
* **作用**：外键。
* **典型内容**：用于关联父表中某个组织的 UUID 字符串。
* **说明**：用于将会计分录关联到特定组织。

#### supplier\_name

* **含义**：交易涉及的供应商名称。
* **作用**：描述性字段。
* **典型内容**：表示供应商名称的文本，例如“Fellow Consulting AG”。
* **说明**：提供与交易相关的供应商信息。

#### description

* **含义**：对交易或商品的简短描述。
* **作用**：描述性字段。
* **典型内容**：描述交易的文本，例如商品名称（“苹果”或“桃子”）。
* **说明**：有助于了解交易的性质。

#### item\_number

* **含义**：交易中某个具体商品的标识符。
* **作用**：描述性字段。
* **典型内容**：可能是产品或 SKU 标识符，但未提供示例数据。
* **说明**：便于跟踪或引用具体商品。

#### line\_amount

* **含义**：交易中某个行项目的金额。
* **作用**：财务字段。
* **典型内容**：表示单个行项目金额的十进制值。
* **说明**：对于行项目级别的详细财务分析十分重要。

#### total\_amount

* **含义**：交易总金额。
* **作用**：财务字段。
* **典型内容**：表示交易总金额的十进制值。
* **说明**：表示交易中所有行金额的总和。

#### mapped\_amount

* **含义**：已分配或映射到特定账户的金额。
* **作用**：财务字段。
* **典型内容**：表示交易已分配金额的十进制值。
* **说明**：有助于了解资金如何分配到不同账户。

#### ledger\_account

* **含义**：记录交易的分类账账户编号。
* **作用**：描述性字段。
* **典型内容**：表示账户编号的文本，例如“2200”或“2500”。
* **说明**：对于跟踪交易入账账户的会计工作至关重要。

#### doc\_id

* **含义**：相关文档或记录的标识符。
* **作用**：外键或引用。
* **典型内容**：用于关联相关文档的 UUID 字符串或其他标识符。
* **说明**：有助于将交易关联到特定文档或记录，以便追溯。

本文档详细介绍了 `public.auto_accounting` 表，说明其结构以及各列的用途，帮助开发人员和数据库管理员理解并有效使用这些数据。
