## 分析与说明

```markdown
# `public.document_import_log` 表技术文档

## 简介

`public.document_import_log` 表用于记录文档导入系统的详细信息。它会记录每份文档的相关信息，包括来源、导入状态及相关元数据。此表对于跟踪文档导入活动以及诊断导入过程中可能出现的问题至关重要。

## 字段说明

### id
- **含义**：每条导入日志记录的唯一标识符。
- **作用**：主键
- **典型内容**：用于唯一标识每条记录的顺序整数值。

### org_id
- **含义**：与此次导入相关的组织标识符。
- **作用**：外键
- **典型内容**：表示组织的 UUID 或类似的唯一字符串标识符。

### sub_org_id
- **含义**：主组织内的子组织或部门标识符。
- **作用**：外键
- **典型内容**：UUID 或类似的唯一字符串标识符；如不适用，则可能为 `None`。

### original_filename
- **含义**：文档上传时的原始文件名。
- **作用**：描述性字段
- **典型内容**：表示文件名的字符串，例如 `anton_invoice-1.pdf`。

### filename
- **含义**：文档经过处理或存储到系统后使用的文件名。
- **作用**：描述性字段
- **典型内容**：表示文件名的字符串，通常与 `original_filename` 相同。

### imported_on
- **含义**：文档导入的日期和时间。
- **作用**：描述性字段
- **典型内容**：采用 ISO 8601 格式的时间戳。

### source_type
- **含义**：导入文档的来源类型。
- **作用**：描述性字段
- **典型内容**：字符串，例如 `EMAIL`，用于指示来源类型。

### source
- **含义**：有关导入来源的详细信息。
- **作用**：描述性字段
- **典型内容**：描述来源的字符串，例如 `Email:O365:demo@fellow-digital.de:Tini Test`。

### success
- **含义**：指示导入是否成功。
- **作用**：状态字段
- **典型内容**：布尔值（`True` 或 `False`）。

### created_by
- **含义**：发起导入的用户标识符。
- **作用**：外键
- **典型内容**：表示用户 ID 的整数。

### created_on
- **含义**：创建导入日志记录的日期和时间。
- **作用**：技术字段
- **典型内容**：带时区的时间戳。

### last_modified_on
- **含义**：上次修改导入日志记录的日期和时间。
- **作用**：技术字段
- **典型内容**：带时区的时间戳；未修改时可能为 `None`。

### is_deleted
- **含义**：指示导入日志记录是否已标记为删除。
- **作用**：状态字段
- **典型内容**：布尔值（`True` 或 `False`）。

### import_id
- **含义**：导入流程的唯一标识符。
- **作用**：技术字段
- **典型内容**：表示唯一流程 ID 的字符串或文本。

### extra_data
- **含义**：与导入相关的附加元数据。
- **作用**：描述性字段
- **典型内容**：包含日期、发件人、主题和数量等额外数据的 JSON 字符串。

### doc_id
- **含义**：文档标识符。
- **作用**：外键
- **典型内容**：UUID 或类似的唯一字符串标识符；也可能为 `None`。

### email_connection_id
- **含义**：导入时使用的电子邮件连接标识符。
- **作用**：外键
- **典型内容**：表示电子邮件连接 ID 的整数；也可能为 `None`。

### subject
- **含义**：导入文档所来自的电子邮件主题行。
- **作用**：描述性字段
- **典型内容**：表示电子邮件主题的字符串。

### body
- **含义**：导入文档所来自的电子邮件正文内容。
- **作用**：描述性字段
- **典型内容**：包含电子邮件正文内容的文本；也可能为 `None`。

### sender
- **含义**：文档发件人的电子邮件地址。
- **作用**：描述性字段
- **典型内容**：包含发件人电子邮件地址的字符串。

### error_resp
- **含义**：导入失败时返回的错误响应或消息。
- **作用**：状态字段
- **典型内容**：包含错误详情的字符串；也可能为 `None`。

### source_received_on
- **含义**：从来源接收到文档的日期和时间。
- **作用**：描述性字段
- **典型内容**：带时区的时间戳。

本文档详细介绍了 `public.document_import_log` 表及其字段，这些信息对于理解和管理系统中的文档导入至关重要。
```
