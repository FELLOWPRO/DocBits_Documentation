# `public.document_table_column` 的技术文档

## 简介

`public.document_table_column` 表似乎用于存储各种文档相关表（例如发票或交货单表）中字段的元数据。这些元数据包括每个字段的名称、类型和属性，以及组织标识符和技术标识符。该表支持在系统中动态生成和管理文档架构。

## 字段说明

### id
- **含义**：表中每条字段记录的唯一标识符。
- **作用**：主键。
- **说明**：通常为 UUID 字符串，用于唯一标识此表中的一行。

### document_table_id
- **含义**：指向包含该字段所属文档的表。
- **作用**：外键。
- **说明**：可能是 UUID，用于关联定义文档表的另一张表。

### table_name
- **含义**：该字段所属文档表的名称。
- **作用**：描述性字段。
- **典型内容**：如 `INVOICE_TABLE`、`DELIVERY_NOTE_TABLE` 这样的名称。
- **说明**：便于了解该字段所属的文档结构。

### org_id
- **含义**：拥有或管理该文档表的组织标识符。
- **作用**：外键。
- **说明**：通常为关联到组织实体的 UUID。

### column_name
- **含义**：该字段在其所属文档表中的技术名称。
- **作用**：描述性字段。
- **典型内容**：如 `COUNTRY_ORIGIN`、`ORDERED_QUANTITY` 这样的名称。
- **说明**：表示文档表中的实际字段名称。

### column_type
- **含义**：描述字段的数据类型。
- **作用**：描述性字段。
- **典型内容**：`STRING`、`DATE`。
- **说明**：表示该字段中存储的数据类型。

### title
- **含义**：字段的易读标题或标签。
- **作用**：描述性字段。
- **典型内容**：`COUNTRY_ORIGIN`、`Ordered Quantity`。
- **说明**：用于以便于用户理解的方式显示字段名称。

### translation_key
- **含义**：用于对字段标题进行国际化和本地化的键。
- **作用**：技术字段。
- **说明**：示例数据中目前为空，表明该字段可能为可选项。

### sort_order
- **含义**：定义字段的显示顺序。
- **作用**：描述性字段。
- **典型内容**：如 `16`、`5` 这样的整数。
- **说明**：决定文档表视图中字段的排列顺序。

### clean_field
- **含义**：指示该字段是否包含经过清理的数据。
- **作用**：布尔标记。
- **典型内容**：`True` 或 `False`。
- **说明**：用于数据验证或标记数据清理状态。

### alphanumeric_field
- **含义**：指定该字段是否应按字母数字字段处理。
- **作用**：布尔标记。
- **典型内容**：`True` 或 `False`。
- **说明**：可用于输入验证或格式设置。

### created_by
- **含义**：创建此字段记录的用户标识符。
- **作用**：外键。
- **典型内容**：如 `1`、`8` 这样的整数值。
- **说明**：关联到负责创建记录的用户或系统实体。

### created_on
- **含义**：字段记录的创建时间戳。
- **作用**：技术字段。
- **典型内容**：UTC 日期和时间值。
- **说明**：便于审计和跟踪变更。

### last_modified_on
- **含义**：字段记录最近一次修改的时间戳。
- **作用**：技术字段。
- **说明**：示例数据中目前为 `None`，表示创建后尚未发生修改。

### is_deleted
- **含义**：指示该字段记录是否已被逻辑删除。
- **作用**：布尔标记。
- **典型内容**：`True` 或 `False`。
- **说明**：便于管理软删除，而无需从物理存储中移除数据。
