### 分析与说明

## `public.fellow_kv_table_column_rule` 技术文档

### 简介

`public.fellow_kv_table_column_rule` 表似乎用于存储处理文档或从文档中提取数据时所需的规则和模式。这是根据 `docType`、`tableName`、`dlfName` 以及各种模式和坐标相关字段推断得出的。该表似乎用于将规则应用于不同类型的文档，从而支持对发票或合同等结构化文档进行模式识别和数据提取。

### 列说明

#### id

* **含义**：每条规则的唯一标识符。
* **作用**：主键。
* **典型内容**：UUID 字符串。
* **说明**：对于唯一标识每一行至关重要。

#### docType

* **含义**：该规则适用的文档类型。
* **作用**：描述性字段。
* **典型内容**：'INVOICE'、'CONTRACT' 等文档类型。
* **说明**：用于按文档类型对规则进行分类。

#### tableName

* **含义**：应用该规则的表名称。
* **作用**：描述性字段。
* **典型内容**：例如 'INVOICE\_TABLE' 这样的表名。
* **说明**：指明应用该规则的上下文。

#### dlfName

* **含义**：文档中特定字段或列的名称。
* **作用**：描述性字段。
* **典型内容**：例如 'COUNTRY\_ORIGIN' 这样的字段名。
* **说明**：指定数据提取的目标字段。

#### multi\_line

* **含义**：指示该规则是否适用于多行文本。
* **作用**：布尔标志。
* **典型内容**：`True` 或 `False`。
* **说明**：适用于处理多行文本字段。

#### filterID1, filterID2, filterID3

* **含义**：应用该规则时使用的筛选条件。
* **作用**：描述性字段或条件字段。
* **典型内容**：可能是表示筛选条件的字符串。
* **说明**：用于根据特定条件细化规则的应用范围。

#### tfidf\_doc\_id, tfidf\_id

* **含义**：与 TF-IDF 处理相关的标识符。
* **作用**：类似外键的角色或标识符。
* **典型内容**：UUID 字符串。
* **说明**：可能与文本分析和特征提取相关。

#### valuePattern

* **含义**：用于提取值的正则表达式模式。
* **作用**：模式字段。
* **典型内容**：正则表达式。
* **说明**：定义用于识别和提取值的模式。

#### coordsY0, coordsY1, coordsX0, coordsX1

* **含义**：定义提取边界框的坐标。
* **作用**：坐标字段。
* **典型内容**：表示像素位置的整数。
* **说明**：定义文档中用于数据提取的关注区域。

#### normalizedY0, normalizedY1, normalizedX0, normalizedX1

* **含义**：用于提取的归一化坐标。
* **作用**：坐标字段。
* **典型内容**：表示比例位置的数值。
* **说明**：用于定义与分辨率无关的区域。

#### width, height

* **含义**：由这些坐标定义的区域尺寸。
* **作用**：尺寸字段。
* **典型内容**：整数值。
* **说明**：帮助定义提取区域的大小。

#### patternLeft, patternRight, patternAbove, patternBelow

* **含义**：目标数据周围的上下文模式。
* **作用**：模式字段。
* **典型内容**：正则表达式。
* **说明**：提供数据相对于其他文本所在位置的上下文。

#### wordLeft, wordAbove

* **含义**：位于目标数据附近的特定词语。
* **作用**：上下文字段。
* **典型内容**：特定词语或短语。
* **说明**：根据附近的词语帮助缩小目标数据的搜索范围。

#### ruleWeight

* **含义**：规则的重要程度或优先级。
* **作用**：权重或优先级字段。
* **典型内容**：整数值。
* **说明**：较大的值可能表示更高的优先级或重要性。

#### user\_id

* **含义**：创建或修改该规则的用户标识符。
* **作用**：外键。
* **典型内容**：整数值。
* **说明**：将规则关联到特定用户。

#### org\_id

* **含义**：与该规则关联的组织标识符。
* **作用**：外键。
* **典型内容**：UUID 字符串。
* **说明**：将规则关联到某个组织。

#### created\_on

* **含义**：规则的创建时间戳。
* **作用**：技术字段。
* **典型内容**：带时区的时间戳。
* **说明**：用于追踪规则的创建历史。

#### last\_modified\_on

* **含义**：规则最后修改时间的时间戳。
* **作用**：技术字段。
* **典型内容**：带时区的时间戳或 `None`。
* **说明**：追踪规则随时间发生的变化。

#### is\_deleted

* **含义**：指示该规则是否已标记为删除。
* **作用**：布尔标志。
* **典型内容**：`True` 或 `False`。
* **说明**：用于软删除规则。

#### is\_new

* **含义**：指示该规则是否为新创建的。
* **作用**：布尔标志。
* **典型内容**：`True` 或 `False`。
* **说明**：帮助识别最近添加的规则。
