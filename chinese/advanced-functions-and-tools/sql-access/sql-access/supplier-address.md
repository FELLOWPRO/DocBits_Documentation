# `public.supplier_address` 表的技术文档

## 简介

`public.supplier_address` 表用于存储与供应商地址相关的信息。该表包含多个字段，用于记录组织 ID、客户编号和供应商编号、多行地址、联系方式、创建和修改元数据以及删除状态等详细信息。该表可能用于管理系统中的供应商信息及其对应地址，这些信息对物流、账单处理和联系供应商都可能很重要。

## 字段说明

### org_id
- **含义**：此字段存储组织的唯一标识符。
- **作用**：外键，可能关联到组织表。
- **典型内容**：表示组织的 UUID。

### customer_number
- **含义**：此字段可能存储分配给客户的唯一编号。
- **作用**：客户标识符。
- **典型内容**：表示客户编号的字母数字字符串。

### supplier_number
- **含义**：此字段存储分配给供应商的唯一编号。
- **作用**：供应商标识符。
- **典型内容**：表示供应商编号的数字字符串。

### address_id
- **含义**：此字段可能存储地址类型，例如 'Discrete' 或 'Text'。
- **作用**：用于对地址进行分类的描述性字段。
- **典型内容**：如 'Discrete'、'Text' 这样的值。

### supplier_name
- **含义**：此字段存储供应商名称。
- **作用**：用于识别供应商的描述性字段。
- **典型内容**：供应商名称，例如 "Cake Corp. GmbH Qualitätsstrawberrys"。

### address_1
- **含义**：此字段存储供应商地址的第一行。
- **作用**：用于记录地址信息的描述性字段。
- **典型内容**：街道地址，例如 "Irrweg. 42, D-12345 Blastadt"。

### address_2
- **含义**：此字段存储供应商地址的第二行（如适用）。
- **作用**：用于记录地址信息的补充字段。
- **典型内容**：其他地址详情，通常为空。

### address_3
- **含义**：此字段存储供应商地址的第三行（如适用）。
- **作用**：用于记录地址信息的补充字段。
- **典型内容**：其他地址详情，通常为空。

### address_4
- **含义**：此字段存储供应商地址的第四行（如适用）。
- **作用**：用于记录地址信息的补充字段。
- **典型内容**：其他地址详情，通常为空。

### zip_code
- **含义**：此字段存储供应商地址的邮政编码。
- **作用**：用于地理位置识别的描述性字段。
- **典型内容**：数字邮政编码，例如 "06449"。

### town_city
- **含义**：此字段存储供应商地址所在城镇或城市的名称。
- **作用**：用于地理位置识别的描述性字段。
- **典型内容**：城镇或城市名称，例如 "Aschersleben"。

### country_code
- **含义**：此字段存储供应商地址所在国家或地区的 ISO 国家代码。
- **作用**：用于识别国家或地区的描述性字段。
- **典型内容**：两位字母的国家代码，例如 "DE"。

### created_by
- **含义**：此字段存储创建该记录的用户或系统的标识符。
- **作用**：用于追踪记录创建者的技术字段。

### created_on
- **含义**：此字段存储记录的创建时间戳。
- **作用**：用于追踪记录创建时间的技术字段。

### last_modified_on
- **含义**：此字段存储记录最后一次修改的时间戳。

### is_deleted

### id

- **作用**：该表的主键。
- **典型内容**：表示记录的 UUID。
