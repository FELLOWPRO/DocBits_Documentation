# 已验证的文档

在本视频中，观众将了解 **DocBit** 的用户友好界面，重点是文档验证。本教程强调了系统的简便性，无需编写代码或使用复杂公式。

{% embed url="https://www.youtube.com/watch?v=FD9dC2_nvuw" %}

借助 AI 和 Swarm Intelligence，大多数字段都会自动提取，用户可以通过点击文档中的值轻松提取信息，详见[用户](../../../administration-and-setup/settings/global-settings/groups-users-and-permissions/)。此外，观众还将了解如何通过双击或圈选所需区域，灵活提取特定区域的信息。
