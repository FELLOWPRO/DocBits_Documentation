# 筛选文档

在仪表板中选择搜索栏最右端的**过滤器**图标（三条滑动条）。可以按**地位**（状态）、**已分配至**或**需要重新启动**限制列表。

<figure><img src="../../../.gitbook/assets/prior-i005-zh.png" alt="仪表盘中按分配和所需重新处理状态进行筛选。 “申请”按钮实际表示应用筛选。"><figcaption><p>仪表盘中按分配和所需重新处理状态进行筛选。 “申请”按钮实际表示应用筛选。</p></figcaption></figure>

选择所需状态或负责人，然后选择**申请**（应用筛选）。清除筛选器可移除限制。日期选项取决于配置和视图。解释文档数量前，请检查当前生效的筛选条件。
