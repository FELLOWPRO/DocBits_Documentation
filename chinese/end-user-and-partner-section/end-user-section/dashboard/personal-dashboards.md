# 个人仪表板

已保存的仪表板是工作列表的命名视图，包含搜索、筛选条件、文档类型、排序和可见列。打开时会同时恢复全部内容，因此重复性任务无需重新配置。仪表板只改变文档的显示方式，从不更改文档本身。

## 创建仪表板

1. 准备好要保留的视图。在搜索栏中输入搜索内容，使用字段选择器中的**智能过滤器**、**过滤器**、文档类型选项卡、表格排序和列。

2. 打开搜索框下方的视图按钮。它会显示当前视图以及当前匹配的文档数量，例如**所有文件（5986）**。

3. 选择**创建新的仪表板**。

4. 输入清晰的名称，并确定谁可以使用该视图：
   * **仅我可见**使视图保持私有。
   * **所有用户可见**使组织中的所有人都可以使用该视图。
   * **与群组和用户共享**会显示**团体**和**选择用户**两个列表，用于指定特定群组或个人。

5. 选择**节省**（保存）。视图按钮会切换到新的仪表板，并显示其名称和文档数量。

可见性决定谁可以使用该视图，但不授予文档访问权限：每个人仍然只能看到自己有权访问的文档。

## 切换或修改视图

在视图按钮中选择已保存的仪表板，或返回**默认仪表板**，即未保存的所有文档视图。重新加载页面后，最后打开的仪表板仍保持激活状态。

修改已加载的仪表板后（即使只更改列），视图按钮会提供**保存仪表板更改**。这样会以相同名称保存更改。如果没有更改，或仪表板属于其他人，该操作保持不可用；共享视图无法覆盖，请创建自己的视图。

## 重命名仪表板或重新共享

将鼠标悬停在视图按钮中自己的仪表板上，会显示**编辑**和**删除**图标。选择铅笔图标打开**编辑仪表板**，更改名称或可见性。对话框显示与创建时相同的三个选项。

## 删除仪表板

选择自己仪表板上的垃圾桶图标，并确认**删除**。删除视图不会删除它引用的文档。他人与您共享的仪表板可以打开和使用，但无法在您的账户中修改或删除。
