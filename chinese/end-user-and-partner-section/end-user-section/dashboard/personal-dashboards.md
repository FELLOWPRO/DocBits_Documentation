# 个人仪表板

将重复使用的工作列表连同筛选、排序和可见列一起保存。已保存的仪表板是现有文档的一种视图。

## 创建和共享视图

1. 设置搜索、筛选、文档类型、排序和列。
2. 打开搜索框下方的蓝色视图按钮。
3. 创建新仪表板并输入明确的名称。
4. 选择仅自己可见、所有用户可见，或指定群组和用户。
5. 选择**节省**（保存）。

可见性决定谁可以使用该视图。每个人仍然只能看到其权限允许访问的文档。

## 切换、更新或移除视图

通过视图按钮选择已保存的仪表板，或返回默认视图。修改自己的视图后，在保存操作可用时保存更改。如果没有更改，或视图由他人共享给您，该操作将不可用。

通过自己视图的编辑控件更改名称或共享设置。如需移除已保存视图，请使用删除控件并确认。移除视图不会删除文档。如需调整他人共享的视图，请创建自己的视图。
