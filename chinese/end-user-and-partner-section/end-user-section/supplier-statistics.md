# 理解供应商交付统计

使用供应商统计找出需要调查的交付表现。管理员必须启用模块，并提供相应发运数据；指标取决于组织中实际存在的记录。

## 检查供应商

1. 打开**供应商统计**。如果入口不可用，请管理员检查模块和访问权限。
2. 在表现较差的供应商列表中确认目标供应商。
3. 先比较总发运数、准时发运数和延迟发运数，再判断百分比。两次与两千次发运的样本规模不同。
4. 结合 **OTIF**、延迟比例、延迟价值和平均延迟天数分析。OTIF 指 *On Time In Full*，即准时足量；准时并不能单独证明足量交付。
5. 比较 OTIF 和延迟发运图表。通过每页供应商数量和翻页控件检查更多记录。
6. 追踪具体发运，核对承诺/实际日期、交付数量、供应商标识以及金额币种，然后再与供应商沟通。

## 解读与排查

数量帮助理解样本规模，平均延迟天数说明持续时间，延迟价值反映涉及金额。不要仅凭准时数量推算 OTIF；未约定换算时，不应直接合计不同币种的金额。

空表或零值图表不代表完美交付。先确认数据是否存在及是否已同步。摘要文字不能解释某次发运的具体原因。

发现差异时，保留供应商标识、相关发运、日期和预期计算方式，请管理员核对来源与指标输入。
