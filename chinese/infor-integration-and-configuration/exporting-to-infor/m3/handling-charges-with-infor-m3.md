# 使用 Infor M3 处理费用

## 概述

本文档详细介绍 DocBits 如何与 Infor M3 集成，以处理与发票和采购订单（PO）相关的费用。其中包括外部费用的各种场景及预期解决方案。

## 费用处理场景

| 场景 ID | 描述 | 业务案例 | 预期解决方案 |
| ----------- | ------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1 | 采购订单中没有但发票上有的外部费用（已接受） | 发票上出现了采购订单中未列出的外部费用。这些费用已被接受。 | 根据 DocBits 发送的成本要素，将费用记入会计规则 PP20-228。 |
| 2 | 采购订单中没有但发票上有的外部费用（未接受） | 发票上出现了采购订单中未列出的外部费用。这些费用未被接受或审批。 | 将发票总金额记入账目，并将未审批的费用作为抬头费用。此外，还会为这些费用创建借项通知单。 |
| 3 | 发票上的外部费用高于或低于采购订单（在容差范围内） | 发票上的外部费用高于或低于采购订单中的费用，但仍在可接受的容差范围内。 | 根据 DocBits 发送的成本要素，将额外费用记入会计规则 PP20-228。 |
| 4 | 发票上的外部费用高于采购订单（超出容差范围，未审批） | 发票上的外部费用高于采购订单中的费用，超出可接受的容差范围，且未获审批。 | 按发票总金额记录发票。将额外的未审批费用作为抬头费用，并为该额外费用创建借项通知单。 |
| 5 | 发票上的外部费用高于采购订单（超出容差范围，已在 DocBits 中审批） | 发票上的外部费用高于采购订单中的费用，超出可接受的容差范围，且已在 DocBits 中审批。 | 将额外费用记入 PP20-228。考虑以下两种方案：\<br>- 如果 APS900 容差 > DocBits，则自动记入额外费用。\<br>- 如果 APS900 容差 = DocBits，则使用采购订单中不存在的新费用要素记入额外费用。 |
| 6 | 发票上的外部费用低于采购订单（超出容差范围，未审批） | 发票上的外部费用低于采购订单中的费用，超出可接受的容差范围，且未获审批。 | 在 APS110 中将发票作为未审批发票过账。应付账款团队通过 APS110 中的发票控制选项调整费用，该选项会调用 APS360。 |
| 7 | 采购订单上有外部费用，但发票上没有费用 | 采购订单列出了外部费用，但发票上没有费用。 | 在 APS110 中将发票作为未审批发票过账。应付账款团队通过 APS110 中的发票控制选项调整费用，该选项会调用 APS360。 |

## 场景 5 示例

| 字段 | 采购订单值 | 供应商发票值 |
| -------------- | -------- | ---------------------- |
| 行 1 | $6000 | $6000 |
| 运费（E001） | $1000 | $3000 |
| **总计** | $7000 | $9000 |

**运费容差：**$100 在 M3（APS900）和 DocBits 中自动获批。发票总金额 $9000（含费用）需手动审批。

**APS451（发票行）：**

* 行类型 1（发票行）：$9000
* 行类型 5（行费用）：$1000（要素：E001，采购订单上的运费 $1000）
* 行类型 5（行费用）：$2000（要素：E101，采购订单上的运费 $0）

### DocBits 中用于处理费用的重要字段和值

| 字段 | 描述 |
| --------------------------- | -------------------------------------------------------- |
| 序列号 | 每个费用场景的唯一标识符 |
| 成本核算要素 ID | 成本核算要素的标识符 |
| 成本核算要素描述 | 成本核算要素的描述 |
| 费用类型 | 通常为“External” |
| 费用开票 | 需要确定其相关性 |
| 分摊方式 | 用于分摊费用的方式 |
| 毛重 | 如果发票上有毛重，则适用 |
| 体积 | 需要定义适用情况 |
| 净额 | 需要定义适用情况 |
| 第三方费用 | 是否出现在发票上以及相关处理要求 |
| 发票费用数量 | 需要澄清 |
| 加价 | 暂按费用与折扣之间的差额理解 |
| 费用类别 | 需要定义其相关性 |
| 成本核算运算符 | 需要定义其相关性 |
