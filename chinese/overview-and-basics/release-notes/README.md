## NOVA — 主要发布版本

### NOVA 为您的团队带来的优势

* **将原 VESTA 测试版功能作为常规 NOVA 功能使用。** 之前在 VESTA 测试版中提供的所有功能（包括规则和布局管理控件）均已包含在 NOVA 中。组织设置、文档类型开关和权限仍然适用。
* **使用验证助手解决文档阻碍。** 询问是什么阻碍了文档处理，跳转到相关字段，并在处理文档的同时查看建议的更正。
* **将重复的更正转化为经过审核的自动化改进。** 审核人员可以提交改进请求；管理员可以评估学习到的规则建议，审核受影响的文档，并在激活后衡量结果。
* **理解并处理电子发票错误。** 使用按验证级别分组的报告，审核文档类型策略及其历史记录，并以记录的原因拒绝符合条件的发票。
* **设置和控制 FTP/SFTP 导入。** 使用连接向导，遵循逐文件导入步骤，配置重试和失败通知，并可选择在成功导入后删除源文件。
* **通过更少的重复操作匹配交付行。** 首先选择文档或采购订单行，并在任一方向上进行链接。配置的导出可以保留子行详细信息，并按行值对记录进行分组。
* **将导出的工作与已完成的工作分开。** 使用 Exported 状态进行后续处理，并可选择锁定 Finished 文档以防止常规重新打开。
* **直接访问规则和布局控件。** 无需测试版链接即可打开管理面板，搜索和预览布局，并从文档中打开布局编辑器。
* **控制提取和常规管理。** 使用选定的页数重启文档，选择是否提取隐藏字段，使用额外的设置助手操作，并将通知规则限制为子组织。
