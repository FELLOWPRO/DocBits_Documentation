# Dashboard-Daten exportieren

1.  **Einstellungen öffnen**: Navigieren Sie zu **Settings → Module**.\


    <figure><img src="../../../../.gitbook/assets/image (10) (1) (2) (1).png" alt=""><figcaption></figcaption></figure>
2.  **Datenexport aktivieren**: Suchen Sie die Option **Export Dashboard Data** und aktivieren Sie sie.\


    <figure><img src="../../../../.gitbook/assets/image (11) (1) (2) (1).png" alt=""><figcaption></figcaption></figure>
3. **Dashboard-Daten exportieren**: Nach der Aktivierung erscheint im Dashboard eine Schaltfläche, mit der Sie die Daten als CSV-Datei exportieren können.

<figure><img src="../../../../.gitbook/assets/image (14) (1) (2) (1).png" alt=""><figcaption></figcaption></figure>
