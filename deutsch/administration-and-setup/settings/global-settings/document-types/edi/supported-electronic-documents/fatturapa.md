# 🇮🇹 FATTURAPA

<!-- edocs-country-scope -->

{% hint style="info" %}
Die Länderanleitung enthält Versionsgrenzen, die tatsächlich verwendete Konfiguration und das Erklärvideo zum Land. [Italien](countries/italy.md). Die Familienbezeichnung bestätigt nicht jede FatturaPA-Veröffentlichung oder die Übertragung über SDI. Prüfen Sie das Quellschema und die Anforderungen des Empfängers.
{% endhint %}

| Eigenschaft | Wert |
| ----------- | ---- |
| **Land / Region** | Italien |
| **Dokumenttypen** | Rechnung, Gutschrift, Vereinfachte Rechnung |
| **Format** | XML (FatturaPA 1.2.x) |
| **Standard** | FatturaPA (SDI) |

FatturaPA ist der italienische E-Rechnungsstandard, der von der Agenzia delle Entrate vorgeschrieben ist. Seit Januar 2019 müssen alle Rechnungen zwischen italienischen Unternehmen über das Sistema di Interscambio (SDI) übermittelt werden. DocBits verarbeitet FatturaPA-XML-Dokumente und extrahiert alle Kopf- und Positionsfelder.
