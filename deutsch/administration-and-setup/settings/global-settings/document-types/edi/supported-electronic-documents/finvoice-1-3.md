# 🇫🇮 FINVOICE 1.3

<!-- edocs-country-scope -->

{% hint style="info" %}
Die Länderanleitung enthält Versionsgrenzen, die tatsächlich verwendete Konfiguration und das Erklärvideo zum Land. [Finnland](countries/finland.md). Prüfen Sie die Version der Quelldatei, bevor Sie eine Zuordnung auswählen. Die Bezeichnung TEAPPSXML nennt keine Veröffentlichungsversion.
{% endhint %}

| Eigenschaft | Wert |
| ----------- | ---- |
| **Land / Region** | Finnland |
| **Dokumenttypen** | Rechnung |
| **Format** | XML (SOAP-Umschlag) |
| **Standard** | Finvoice 1.3 |

Finvoice 1.3 ist eine frühere Version des finnischen E-Rechnungsstandards, der von Finance Finland gepflegt wird. Sie verwendet einen SOAP-Nachrichtenumschlag und definiert ein strukturiertes XML-Format für die B2B-Rechnungsstellung zwischen finnischen Banken und ihren Firmenkunden.
