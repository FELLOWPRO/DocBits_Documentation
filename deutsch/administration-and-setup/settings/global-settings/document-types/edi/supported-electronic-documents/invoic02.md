# INVOIC02

| Eigenschaft          | Wert                    |
| -------------------- | ----------------------- |
| **Land / Region**    | International           |
| **Dokumenttypen**    | Rechnung                |
| **Format**           | EDIFACT                 |
| **Standard**         | UN/EDIFACT INVOIC D.02B |

INVOIC02 ist eine UN/EDIFACT-Rechnungsnachricht auf Basis der Verzeichnisversion D.02B. EDIFACT (Electronic Data Interchange for Administration, Commerce and Transport) ist ein weit verbreiteter EDI-Standard in Logistik, Handel und Fertigung. DocBits analysiert die EDIFACT-Segmentstruktur und extrahiert Kopf-, Positions- und Summenfelder.
