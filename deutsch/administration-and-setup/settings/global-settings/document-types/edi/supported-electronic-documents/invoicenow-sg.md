# 🇸🇬 INVOICENOW SG

| Eigenschaft          | Wert                                          |
| -------------------- | --------------------------------------------- |
| **Land / Region**    | Singapur                                      |
| **Dokumenttypen**    | Rechnung, Gutschrift                          |
| **Format**           | UBL 2.1 XML (Peppol)                          |
| **Standard**         | InvoiceNow SG (Singapore-specific Peppol BIS) |

InvoiceNow SG ist die singapurspezifische Lokalisierung des Standards Peppol BIS Billing. Sie erweitert das Peppol-Basismodell um singapurspezifische Geschäftsregeln, die GST-Behandlung und Anforderungen an die Identifikation über die UEN (Unique Entity Number).
