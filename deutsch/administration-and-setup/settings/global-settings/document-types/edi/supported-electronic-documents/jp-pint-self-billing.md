# 🇯🇵 JP PINT SELF-BILLING

<!-- edocs-country-scope -->

{% hint style="info" %}
Die Länderanleitung enthält Versionsgrenzen, die tatsächlich verwendete Konfiguration und das Erklärvideo zum Land. [Japan](countries/japan.md). Selbstfakturierung ist eine Variante des Geschäftsprozesses, keine Sprachwahl. Prüfen Sie die Anpassungskennung und die konfigurierte Variante.
{% endhint %}

| Eigenschaft          | Wert                         |
| -------------------- | ---------------------------- |
| **Land / Region**    | Japan                        |
| **Dokumenttypen**    | Selbstfakturierte Rechnung   |
| **Format**           | UBL 2.1 XML                  |
| **Standard**         | JP PINT Self-Billing         |

JP PINT Self-Billing ist die Selbstfakturierungsvariante des japanischen Peppol-International-Rechnungsmodells. Sie ermöglicht es Käufern, Rechnungen im Namen von Lieferanten auszustellen. Dabei gilt dieselbe JP-PINT-Struktur mit vertauschten Parteirollen, wie sie das japanische Steuerrecht unter bestimmten Bedingungen zulässt.
