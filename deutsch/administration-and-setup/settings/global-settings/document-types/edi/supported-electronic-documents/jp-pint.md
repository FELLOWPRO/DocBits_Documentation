# 🇯🇵 JP PINT

| Eigenschaft          | Wert                                           |
| -------------------- | ---------------------------------------------- |
| **Land / Region**    | Japan                                          |
| **Dokumenttypen**    | Rechnung                                       |
| **Format**           | UBL 2.1 XML                                    |
| **Standard**         | JP PINT (Peppol International Model for Japan) |

JP PINT ist die japanische Umsetzung des Peppol-International-Rechnungsmodells (PINT). Es passt den globalen Peppol-Standard an die japanischen Geschäftsanforderungen an, einschließlich der Unterstützung des mit dem überarbeiteten Verbrauchsteuergesetz eingeführten Qualified Invoice System (適格請求書).
