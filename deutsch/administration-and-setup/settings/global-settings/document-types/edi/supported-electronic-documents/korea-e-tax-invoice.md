# 🇰🇷 KOREA E-TAX INVOICE

<!-- edocs-country-scope -->

{% hint style="info" %}
Die Länderanleitung enthält Versionsgrenzen, die tatsächlich verwendete Konfiguration und das Erklärvideo zum Land. [Südkorea](countries/korea.md). Die Bezeichnungen nennen keine Veröffentlichungsversion. Gleichen Sie die tatsächliche XML-Struktur ab und betrachten Sie die Extraktion nicht als Nachweis einer Annahme durch die Steuerplattform.
{% endhint %}

| Eigenschaft          | Wert                               |
| -------------------- | ---------------------------------- |
| **Land / Region**    | Südkorea                           |
| **Dokumenttypen**    | Steuerrechnung                     |
| **Format**           | XML                                |
| **Standard**         | Korean E-Tax Invoice (NTS HomeTax) |

Korea E-Tax Invoice ist der Standard für elektronische Steuerrechnungen, der von der nationalen Steuerbehörde (NTS) über das System HomeTax betrieben wird. Unternehmen müssen für B2B-Transaktionen elektronische Steuerrechnungen ausstellen und an die NTS übermitteln. Das Format enthält die Unternehmensregistrierungsnummer, die Aufschlüsselung des Steuerbetrags und die NTS-Genehmigungsnummer.
