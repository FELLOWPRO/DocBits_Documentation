# 🇰🇷 KOREA NTS

| Eigenschaft          | Wert                       |
| -------------------- | -------------------------- |
| **Land / Region**    | Südkorea                   |
| **Dokumenttypen**    | Steuerrechnung, Kassenbeleg |
| **Format**           | XML                        |
| **Standard**         | NTS (National Tax Service) |

Korea NTS bezeichnet das übergreifende System für elektronische Dokumente der nationalen Steuerbehörde (National Tax Service), das Steuerrechnungen, Kassenbelege und weitere steuerrelevante Dokumente umfasst. DocBits verarbeitet NTS-Dokumente und extrahiert alle Standardfelder, darunter Unternehmensregistrierungsnummern, Lieferwerte und Steuerbeträge.
