# 🇵🇱 KSEF FA2

<!-- edocs-country-scope -->

{% hint style="info" %}
Die Länderanleitung enthält Versionsgrenzen, die tatsächlich verwendete Konfiguration und das Erklärvideo zum Land. [Polen](countries/poland.md). FA2 und FA3 verwenden unterschiedliche Strukturen. Bestätigen Sie das Quellschema und testen Sie die passende Zuordnung. Das Einlesen übermittelt keine Rechnung an KSeF.
{% endhint %}

| Eigenschaft          | Wert                        |
| -------------------- | --------------------------- |
| **Land / Region**    | Polen                       |
| **Dokumenttypen**    | Rechnung, Korrekturrechnung |
| **Format**           | XML                         |
| **Standard**         | KSeF FA(2)                  |

KSeF FA2 ist die zweite Schemaversion des polnischen nationalen E-Rechnungssystems. Sie definiert die XML-Struktur für strukturierte Rechnungen (faktury), einschließlich Verkäufer-/Käuferdaten, Positionen, Umsatzsteuersätzen und Zahlungsbedingungen, wie sie das polnische Steuerrecht verlangt.
