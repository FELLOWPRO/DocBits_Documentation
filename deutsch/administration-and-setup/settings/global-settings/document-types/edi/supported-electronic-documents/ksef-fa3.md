# 🇵🇱 KSEF FA3

| Eigenschaft          | Wert                        |
| -------------------- | --------------------------- |
| **Land / Region**    | Polen                       |
| **Dokumenttypen**    | Rechnung, Korrekturrechnung |
| **Format**           | XML                         |
| **Standard**         | KSeF FA(3)                  |

KSeF FA3 ist die neueste Schemaversion des polnischen nationalen E-Rechnungssystems. Sie unterstützt zusätzliche Dokumenttypen, bietet eine verbesserte Behandlung von Korrekturrechnungen und enthält aktualisierte Validierungsregeln, die an die aktuellen polnischen Umsatzsteuervorschriften angepasst sind.
