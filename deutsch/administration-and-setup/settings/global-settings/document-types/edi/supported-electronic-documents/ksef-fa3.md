# 🇵🇱 KSEF FA3

<!-- edocs-country-scope -->

{% hint style="info" %}
Die Länderanleitung enthält Versionsgrenzen, die tatsächlich verwendete Konfiguration und das Erklärvideo zum Land. [Polen](countries/poland.md). FA2 und FA3 verwenden unterschiedliche Strukturen. Bestätigen Sie das Quellschema und testen Sie die passende Zuordnung. Das Einlesen übermittelt keine Rechnung an KSeF.
{% endhint %}

| Eigenschaft          | Wert                        |
| -------------------- | --------------------------- |
| **Land / Region**    | Polen                       |
| **Dokumenttypen**    | Rechnung, Korrekturrechnung |
| **Format**           | XML                         |
| **Standard**         | KSeF FA(3)                  |

KSeF FA3 ist die neueste Schemaversion des polnischen nationalen E-Rechnungssystems. Sie unterstützt zusätzliche Dokumenttypen, bietet eine verbesserte Behandlung von Korrekturrechnungen und enthält aktualisierte Validierungsregeln, die an die aktuellen polnischen Umsatzsteuervorschriften angepasst sind.
