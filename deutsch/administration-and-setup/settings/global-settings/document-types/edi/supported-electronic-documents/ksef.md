# 🇵🇱 KSEF

<!-- edocs-country-scope -->

{% hint style="info" %}
Die Länderanleitung enthält Versionsgrenzen, die tatsächlich verwendete Konfiguration und das Erklärvideo zum Land. [Polen](countries/poland.md). FA2 und FA3 verwenden unterschiedliche Strukturen. Bestätigen Sie das Quellschema und testen Sie die passende Zuordnung. Das Einlesen übermittelt keine Rechnung an KSeF.
{% endhint %}

| Eigenschaft          | Wert                                     |
| -------------------- | ---------------------------------------- |
| **Land / Region**    | Polen                                    |
| **Dokumenttypen**    | Rechnung, Gutschrift, Korrekturrechnung  |
| **Format**           | XML                                      |
| **Standard**         | KSeF (Krajowy System e-Faktur)           |

KSeF ist das polnische nationale E-Rechnungssystem, das vom Finanzministerium betrieben wird. Es wird für alle in Polen umsatzsteuerlich registrierten Unternehmen verpflichtend. DocBits unterstützt für die Rechnungsverarbeitung die Schemaversionen KSeF FA2 und FA3.
