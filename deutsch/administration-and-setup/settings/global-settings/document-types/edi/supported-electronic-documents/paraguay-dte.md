# 🇵🇾 PARAGUAY DTE

| Eigenschaft          | Wert                                   |
| -------------------- | -------------------------------------- |
| **Land / Region**    | Paraguay                               |
| **Dokumenttypen**    | Rechnung, Gutschrift                   |
| **Format**           | XML                                    |
| **Standard**         | DTE (Documento Tributario Electrónico) |

Paraguay DTE ist der paraguayische Standard für elektronische Steuerdokumente, der von der Steuerbehörde Subsecretaría de Estado de Tributación (SET) geregelt wird. Er umfasst elektronische Rechnungen und Gutschriften mit paraguayischer Steuerkennung (RUC) und den entsprechenden Anforderungen an Steuerkategorien.
