# 🇪🇺 PEPPOL BIS 3.0

<!-- edocs-country-scope -->

{% hint style="info" %}
Die Länderanleitung enthält Versionsgrenzen, die tatsächlich verwendete Konfiguration und das Erklärvideo zum Land. [International](countries/international.md). Zuordnungen für Rechnungen, Bestellungen, Antworten und Versandanzeigen sind voneinander getrennt. Die Dateiverarbeitung selbst stellt weder einen Peppol-Zugangspunkt noch eine Verbindung zu Handelspartnern bereit.
{% endhint %}

| Eigenschaft          | Wert                                              |
| -------------------- | ------------------------------------------------- |
| **Land / Region**    | Europäische Union / International (40+ Länder)    |
| **Dokumenttypen**    | Rechnung, Gutschrift                              |
| **Format**           | UBL 2.1 XML                                       |
| **Standard**         | Peppol BIS Billing 3.0                            |

Peppol BIS Billing 3.0 ist der europaweite E-Rechnungsstandard des Peppol-Netzwerks. Er basiert auf OASIS UBL 2.1 und setzt die europäische Norm EN 16931 für elektronische Rechnungen um. Peppol ermöglicht den grenzüberschreitenden B2B- und B2G-Rechnungsaustausch in über 40 Ländern über zertifizierte Access Points.
