# 🇵🇪 PERU CPE UBL 2.0

| Eigenschaft          | Wert                                  |
| -------------------- | ------------------------------------- |
| **Land / Region**    | Peru                                  |
| **Dokumenttypen**    | Rechnung, Gutschrift, Belastungsanzeige |
| **Format**           | UBL 2.0 XML                           |
| **Standard**         | CPE UBL 2.0                           |

Peru CPE UBL 2.0 ist das frühere UBL-basierte Format für peruanische elektronische Rechnungen. Obwohl die SUNAT auf UBL 2.1 umgestellt hat, verwenden viele bestehende Dokumente noch diese Version. DocBits verarbeitet diese Dokumente und extrahiert alle Kopf- und Positionsfelder.
