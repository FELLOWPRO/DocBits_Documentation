# 🇵🇭 PHILIPPINES EIS

| Eigenschaft | Wert |
| ----------- | ---- |
| **Land / Region** | Philippinen |
| **Dokumenttypen** | Rechnung, Offizielle Quittung |
| **Format** | XML/JSON |
| **Standard** | EIS (Electronic Invoicing System - BIR) |

Philippines EIS ist das elektronische Rechnungssystem (Electronic Invoicing System) der Steuerbehörde Bureau of Internal Revenue (BIR). Es digitalisiert die Rechnungs- und Quittungsstellung für philippinische Unternehmen und verlangt die elektronische Übermittlung von Verkaufsdaten an das System der BIR zur Überwachung der Steuerkonformität.
