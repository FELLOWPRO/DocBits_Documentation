# SPS COMMERCE RSX 7.7.4

| Eigenschaft | Wert |
|-------------|------|
| **Land / Region** | International (vorwiegend Nordamerika) |
| **Dokumenttypen** | Rechnung (810), Bestellung (850), ASN (856) |
| **Format** | XML |
| **Standard** | SPS Commerce RSX 7.7.4 (Retail Standard XML) |

SPS Commerce RSX (Retail Standard XML) 7.7.4 ist ein Standard für die Übersetzung von EDI in XML, der in der Lieferkette des Einzelhandels verwendet wird. Er stellt gängige EDI-Transaktionen als XML dar, darunter Rechnungen (810), Bestellungen (850) und Lieferavis (Advance Ship Notice, 856). SPS Commerce ist ein führender EDI-Anbieter, der Händler mit Lieferanten verbindet.
