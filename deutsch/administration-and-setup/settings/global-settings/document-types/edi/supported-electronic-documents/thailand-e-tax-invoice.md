# 🇹🇭 THAILAND E-TAX INVOICE

| Eigenschaft | Wert |
| ----------- | ---- |
| **Land / Region** | Thailand |
| **Dokumenttypen** | Steuerrechnung, Quittung |
| **Format** | XML (in PDF/A-3 eingebettet) |
| **Standard** | e-Tax Invoice & e-Receipt (Revenue Department) |

Thailand e-Tax Invoice ist der Standard für elektronische Steuerrechnungen und Quittungen, der vom Revenue Department reguliert wird. Er verwendet ein Hybridformat ähnlich ZUGFeRD, bei dem strukturierte XML-Daten in ein PDF/A-3-Dokument eingebettet werden. Das System erfordert eine digitale Signatur mit einem Zertifikat einer thailändischen Zertifizierungsstelle (CA).
