# 🇦🇪 UAE VAT INVOICE

| Eigenschaft | Wert |
| ----------- | ---- |
| **Land / Region** | Vereinigte Arabische Emirate |
| **Dokumenttypen** | Steuerrechnung, Vereinfachte Steuerrechnung |
| **Format** | XML/JSON |
| **Standard** | FTA VAT Invoice (Federal Tax Authority) |

UAE VAT Invoice ist das elektronische Rechnungsformat, das sich an den Anforderungen der Federal Tax Authority (FTA) orientiert. Obwohl die Vereinigten Arabischen Emirate noch kein bestimmtes E-Rechnungsformat vorgeschrieben haben, unterstützt DocBits die Verarbeitung strukturierter Umsatzsteuerrechnungen, die den FTA-Umsatzsteuervorschriften entsprechen, einschließlich der Identifikation über die TRN (Tax Registration Number) und der Umsatzsteuerberechnung mit 5 %.
