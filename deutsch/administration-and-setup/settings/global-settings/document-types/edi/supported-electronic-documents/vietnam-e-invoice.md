# 🇻🇳 VIETNAM E-INVOICE

| Eigenschaft | Wert |
| ----------- | ---- |
| **Land / Region** | Vietnam |
| **Dokumenttypen** | Rechnung |
| **Format** | XML |
| **Standard** | Vietnamese E-Invoice (General Department of Taxation) |

Vietnam E-Invoice ist der Standard für elektronische Rechnungen, der von der General Department of Taxation gemäß Dekret 123/2020 und Rundschreiben 78/2021 vorgeschrieben wird. Alle Unternehmen in Vietnam müssen E-Rechnungen verwenden, die an das System der Steuerbehörde übermittelt und dort validiert werden. Jede Rechnung enthält einen eindeutigen Prüfcode.
