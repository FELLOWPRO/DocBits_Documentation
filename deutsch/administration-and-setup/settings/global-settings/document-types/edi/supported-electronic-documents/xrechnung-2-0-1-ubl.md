# 🇩🇪 XRECHNUNG 2.0.1 UBL

| Eigenschaft       | Wert                     |
| ----------------- | ------------------------ |
| **Land / Region** | Deutschland              |
| **Dokumenttypen** | Rechnung, Gutschrift     |
| **Format**        | UBL                      |
| **Standard**      | XRechnung 2.0.1          |
| **Basiert auf**   | EN 16931 (OASIS UBL 2.1) |

XRechnung 2.0.1 setzt den EN 16931 Core Invoice Standard mit den deutschen CIUS-Erweiterungen (Core Invoice Usage Specification) um. Diese Version brachte Fehlerbehebungen und Korrekturen zur Version 2.0 und verbessert Stabilität und Interoperabilität.
