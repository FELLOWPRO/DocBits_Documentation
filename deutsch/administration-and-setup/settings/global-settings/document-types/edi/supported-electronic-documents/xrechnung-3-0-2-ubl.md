# 🇩🇪 XRECHNUNG 3.0.2 UBL

| Eigenschaft       | Wert                     |
| ----------------- | ------------------------ |
| **Land / Region** | Deutschland              |
| **Dokumenttypen** | Rechnung, Gutschrift     |
| **Format**        | UBL                      |
| **Standard**      | XRechnung 3.0.2          |
| **Basiert auf**   | EN 16931 (OASIS UBL 2.1) |

XRechnung 3.0.2 ist die aktuelle Generation des deutschen E-Rechnungsstandards und entspricht den neuesten Aktualisierungen von EN 16931. Aktuellste Wartungsversion mit aktualisierten Geschäftsregeln und Schematron-Validierung für bessere Konformitätstests.
