# Abonnement-Plan

<figure><img src="../../../../.gitbook/assets/subscriptions_overview.png" alt="Abonnement-Plan"><figcaption><p>Seite „Abonnement-Plan“</p></figcaption></figure>

Die Seite **Abonnement-Plan** bietet einen vollständigen Überblick über Ihr DocBits-Abonnement an einem Ort: den Plan selbst, die für Ihre Organisation aktivierten App- und Funktions-Abonnements sowie Ihren Token-Verbrauch. Öffnen Sie sie über **Einstellungen → Organisation & Zugang → Abonnement-Plan**.

## Abonnement-Plan

Die erste Karte zeigt Ihr DocBits-Abonnement – die verbleibenden Tage sowie das Start- und Enddatum – zusammen mit aktuellen Zählungen für Ihre Organisation:

| Karte | Beschreibung |
|------|-------------|
| **DocBits** | Verbleibende Tage sowie Start- und Enddatum Ihres Abonnements. |
| **Benutzer** | Anzahl der Benutzer in Ihrer Organisation. |
| **Unterorganisation** | Anzahl der Unterorganisationen. |
| **Lieferanten** | Anzahl der Lieferanten. |

## Funktions-Abonnements

<figure><img src="../../../../.gitbook/assets/subscriptions_feature_subscriptions.png" alt="Funktions-Abonnements"><figcaption></figcaption></figure>

Dieser Abschnitt listet jede DocBits-App und -Funktion auf und zeigt, ob sie für Ihre Organisation aktiviert ist.

| Spalte | Beschreibung |
|--------|-------------|
| **App** | Die DocBits-App oder -Funktion (z. B. AI Workforce, Operator, DocFlow, AI Search, BOD Ingestion, SQL BI Connector). |
| **Abonnement** | Der abonnierte Plan für diese App. |
| **Status** | **Aktiv**, **Wird gekündigt** (bis zum Enddatum aktiv, danach beendet) oder **Keines**, wenn die App nicht abonniert ist. |
| **Start / Ende** | Der Abonnementzeitraum. |
| **Verbleibende Tage** | Tage bis zum Enddatum. |
| **Aktionen** | Aktionsmenü pro App. |

## Abonnement-Nutzung

<figure><img src="../../../../.gitbook/assets/subscriptions_usage.png" alt="Abonnement-Nutzung"><figcaption></figcaption></figure>

Überwachen Sie Ihren Token- und Workflow-Verbrauch über einen ausgewählten Zeitraum. Verwenden Sie die Schaltfläche **Auswählen**, um den Zeitraum festzulegen.

| Spalte | Beschreibung |
|--------|-------------|
| **Typ** | Die Nutzungskategorie – Dokument, Workflow, Erweiterter Workflow oder DocNet. |
| **Von / Bis** | Der Zeitraum, für den die Nutzung ausgewiesen wird. |
| **Verbrauchte Tokens** | Im Zeitraum verbrauchte Tokens. |
| **Verbleibende Tokens** | Im Zeitraum verbleibende Tokens. |
