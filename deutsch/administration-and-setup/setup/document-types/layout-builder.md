## **Auf den Layout Builder zugreifen**

Stellen Sie zunächst sicher, dass die Funktion „Layout Builder“ aktiviert ist. Navigieren Sie dazu zu Settings → Document Processing → Module → Document Type und vergewissern Sie sich, dass der Schieberegler „Layout Builder“ wie unten gezeigt aktiviert ist.

![](https://lh7-us.googleusercontent.com/I0VvFiFftKLoCB47jCAoosfTyqIQgXBoggMFp1QAeIj9xW4yiiIzyk5eIEHZ7duA251Yc4_ArUKA8e-LjDht13bckAnkAOHOvl1p5k1-Qj_UkEp2cSZwxHz_PXe8IQ4_jglzCtjAJg5pd9m_hNZEhXA)

### Layouts bearbeiten

Danach erreichen Sie den Layout Builder über Settings → Document Types. Auf dieser Seite wählen Sie einen der von Ihnen erstellten Dokumenttypen aus und klicken wie unten gezeigt auf „**Edit** **Layout**“,

![](https://lh7-us.googleusercontent.com/WMD8M0qugnc64ZuyLuEYH5P63qk-Vo86useg32-QyOsP63FJA_Xh7UzwlwmUR3K9oTd19aXexSitZqQLVEKo26-i8hYWUS9CChzwAS8TgbWoqweFucJcNIgKBruzSd0mxn8zrh9i46lPxKMNDh-YEJ8)

oder, wenn ein erstellter Dokumenttyp Untertypen hat, wählen Sie „Document Sub Types“ und anschließend „Edit Layout“ für das Layout des Untertyps, das Sie bearbeiten möchten, wie unten gezeigt.

![](https://lh7-us.googleusercontent.com/KfmM8wMGnn5tzXRxF1yT0Efm7X6v0kYeGzgNG3RihERh_P71tjEVkJh4POMwgqnsCBoE736xI7oHkmpYNUbtAShhE-wAHsnLuxljDtmhGQUyljF_PmOF2y6c0gIdIk_jUD3sVNsq5viT2sb236OBYSA)

### **Gruppen**

Gruppen können mit dem folgenden Symbol erstellt werden.

![](https://lh7-us.googleusercontent.com/eb4jnCmezPFKPwgUisJKvicBqMWuGHW69WIFdtpmQiY-_78VWmMyMD4TqKMJXwjH1XDnS5RXX0DsJ2_ur_GG62L4F7OEzkLrpgwUkiuQjZQPJqQoHIBj6WM33zY0AkYXhI3mKLjZetbEQ2AlhPJ8KV8)

Mit Gruppen können Sie in einem Layout verschiedene Abschnitte anlegen. So lassen sich unterschiedliche Daten oder Informationen voneinander trennen und ein Layout ist leichter nachzuvollziehen. Sie können für jede Gruppe einen Titel vergeben, damit Benutzer wissen, welche Informationen sie in dieser Gruppe finden.

![](https://lh7-us.googleusercontent.com/lWqIEC-TCOp4rKytTbhn2fYWY618_Yra2mjWHA9oMyWPqHXA5JKCLoZoEtM8xQHAkn4HFNTPYpbMePUYnQhQGL0KmgBfTEDWPDAMy7PjZinZl2s_kHQlsLAGjYbzSINWTme3qRO9tHLcpVaDVvS_8F4)

### **Form Elements**

![](https://lh7-us.googleusercontent.com/OFBRSGdol7loocu5uGVe4Q8URMDojvXTN0xj3TCgL-jb-wUgt1fjEqfXCyMPz_HNh94LVVmg6ifQDhxvlQsgbbChRfrw2Ohx4ICOUwHix3iiAFY9hI3BPGBfcNABiHLhgXQJVZmGvEO_niVWkIXz_6g)

Dies sind vordefinierte Standardfelder, die per Drag-and-drop in den Layout Builder gezogen werden können und Ihnen zur Erstellung Ihres gewünschten Layouts zur Verfügung stehen. Dazu gehören:

* Text – Ein Textfeld, das im Layout ein Feld erzeugt, in das auf dem Validierungsbildschirm Text eingegeben werden kann.
* Label – Ein Feld für nicht bearbeitbaren Text. Damit lassen sich auf dem Validierungsbildschirm Zwischenüberschriften oder anderer gewünschter, nicht bearbeitbarer Text erstellen.
* Checkbox – Erzeugt ein Feld vom Typ Boolean, das aktiviert oder deaktiviert werden kann.
* Multi Checkbox – Funktioniert wie die „Checkbox“, kann aber verwendet werden, wenn Sie wissen, dass Sie in einem Abschnitt mehrere Kontrollkästchen hinzufügen werden.
* Horizontal Separator – Erzeugt eine horizontale Linie im Layout, mit der Sie Abschnitte innerhalb einer Gruppe im Layout voneinander abtrennen können.
* Table of Checkboxes – Damit können Sie eine Tabelle aus Kontrollkästchen mit benutzerdefinierten Werten für die x- und y-Achse erstellen, z. B.:

![](https://lh7-us.googleusercontent.com/lMZU68H4i8ELjgenpcNXeNhJ9iwzTWGRkjNMEdV3rqdGwnaRZ_tvG9mbx2ogXQ2hMciGSp-9m1c5KS9VwGJWzuxcRiaioVDSLTLvh-csHUho4aX25LXrtjhGSfK6yTukufwrjQvZR-JliuhiaPCCxpw)

* Button – Erzeugt eine anklickbare Schaltfläche im Layout auf dem Validierungsbildschirm, der eine von drei Funktionen zugewiesen werden kann: Export, Export mit Sonderwunsch oder Reject.
* Extracted Tables – Damit können Sie im Dokumentlayout einen Bereich platzieren, der die aus dem Dokument extrahierte Tabelle darstellt. Weitere Informationen erhalten Sie hier.
* Invoice Buttons – Mit diesem Element ziehen Sie eine Gruppe von Schaltflächen ins Layout, die für Rechnungen optimiert sind. Wenn Sie auf dem Validierungsbildschirm den Rechnungstyp (entweder Kosten oder Bestellung) auswählen, verschwindet entsprechend das PO Matching oder das Auto Accounting.

![](https://lh7-us.googleusercontent.com/-w5iTr9b_pcc6Y39osFmuzKQGRa_e4tAXvQOn1zN8T4HwcuTs_FP9mFPAJJeABvYKTyiQr3xZALsRgueIDksbswhnY-E9ioT1AIaf8xwAblBckX1f8xzi5v9mLxBRRUZoViDntKK6Nd5fy5sd5Bq5LU)

* QR Code Fields – Mit diesem Element ziehen Sie einen Block ins Layout, der alle aus einem Dokument extrahierten Informationen anzeigt, wenn ein QR-Code vorhanden ist.

### **Dokumentspezifische Felder erstellen**

Benutzer können für einen Dokumenttyp eigene Gruppen und Felder erstellen. Das ist beim ursprünglichen Anlegen eines Dokumenttyps möglich, aber auch, indem Sie in den Settings auf der Seite „Document Types“ die Option „Fields“ auswählen.

![](https://lh7-us.googleusercontent.com/N9i3KnGyXATf5jLVbPQGiPEG9rlz6WqHJ5c8FZnpw3EwmaMnl2cQhMwhug3d-A82caOS6Nxc7LgAVLMtBL404hKR7i39u2RfwzCnohqn1_mbkMtjzNKThnjGu2ivaFNqKDuobzA6kUdD8gGiQ_zs3z8)

### **Leerräume**

#### **Die 100-Prozent-Regel**

![](https://lh7-us.googleusercontent.com/TwNA3gZrgzhSvZrZOGywGYz92fRkUtjIsr6sDCxEzYgWcfJ9kXuzJKkqNiFyp3H5XXoqUz76TzZ72r86YY_O3Vw_rvDKczD_hdMOIQOFWORr2bo8pGunrAtUklJ1ye7KEQJEjRNqNUNCnXM0boIICUA)

Um den oben gezeigten Leerraum im Layout zu erzeugen, muss ein „Label“ aus den Form Elements auf besondere Weise verwendet werden. Der Grund: Der Layout Manager arbeitet mit einem System von 100 Einheiten pro Zeile, wobei 1 Einheit 1 Prozent einer Zeile entspricht. Felder können also pro Zeile insgesamt nur 100 Einheiten belegen, wie unten gezeigt.

![](https://lh7-us.googleusercontent.com/YTqddzVQPWRuP5ylV6NnMc-KnEgCY0ZxZ8zn0In5d5dOxaWnwGDi4N2qohbobLNphLfVD61sMUE5QlmXJZ3e0tP7Y8no_wVRy9WTF0nWIN5Tg3t-zLJhs9M-kVYPFV3CyerRZZoK-iMXLmKGcuSY_Nw)

Das bedeutet, dass Benutzer das Layout nach dieser Regel Zeile für Zeile aufbauen müssen. Angenommen, Sie möchten die Felder „Name“ und „Date“ in derselben Zeile platzieren, das Feld „Name“ soll jedoch größer sein. Dazu ziehen Sie das Feld „Text“ aus dem Dropdown der Field Elements ins Layout und benennen die Felder „Name“ und „Date“, wie gezeigt.

![](https://lh7-us.googleusercontent.com/2ru3pj0iD3V6ADqYBjeQPqDT3uvTH_Al2MV0gpUUQ9MpX0TSFtnjYL6JN0YOkBk9afx2q2YcMo4gWE2jItUAGSEfX79O_6sFgKwP5FGa98SwzgjGgee1G-2aO6NyqZusf27SbJoWoHmzu51Hx25kVmM)

Nun besteht das Problem, dass beide Felder dieselbe Größe von 33 haben (das ist die Standardgröße aller per Drag-and-drop eingefügten Felder), das Feld „Name“ aber größer sein soll als das Feld „Date“ und beide Felder die gesamte Zeile im Layout ausfüllen sollen. Nach der 100-Prozent-Regel können Sie die Felder „Name“ und „Date“ auf eine beliebige Kombination setzen, die zusammen 100 ergibt. Das hängt natürlich davon ab, wie groß jedes einzelne Feld sein soll. In diesem Beispiel setzen wir das Feld „Name“ auf 70 und das Feld „Date“ auf 30. Das Ergebnis:

![](https://lh7-us.googleusercontent.com/m411QblkCfsQWllhX74QpANjuVEv3fgM1Nhg8cJjbkNQGcjym6v0JFHIrKyMOAu-MasQ4KH9ZPaxmqNWfhWmAuL6SOZE030NXebb7ERzYxF99hLJC6oGbM-YXp7bNdZuoTaPmsDt7EjpV5BOiflwA4g)

Dieselbe Regel gilt für alle Felder im Layout Builder.

#### **Leerräume erstellen**

Nachdem diese Regel erklärt wurde, ist das Erstellen von Leerräumen leichter zu verstehen. Wie bereits erwähnt, müssen Sie für einen Leerraum ein „Label“ aus den Form Elements verwenden.

Angenommen, Sie möchten zwischen diesen beiden Feldern einen Leerraum einfügen.

![](https://lh7-us.googleusercontent.com/jOms6aTB3wCmX3L-MiUTrOb_-q3AiFC3Y75TsHJe8QFLru10H9aZKzbE5MfHPZ0v9fqycQeddNPJp7pnRjv17crkrYUymNA8u9bF-3u9IfR6ru_duavqrLCQocommljzLA00RXs_lQA4gDH6l_QvyTs)

Im ersten Schritt ziehen Sie ein „Label“ zwischen diese beiden Felder. Anschließend klicken Sie auf das soeben hinzugefügte „Label“-Feld, und links werden die Eigenschaften des Felds angezeigt. Genauso, wie Sie zuvor den Namen eines Felds erstellt oder geändert haben, entfernen Sie nun jeden Namen aus der Eigenschaft „Label“, etwa so:

![](https://lh7-us.googleusercontent.com/0Mma4wYIIfAkOyRIFLZtjug7pbWltfaiPm3r_WgbP5fCgKe2BGD6Qf5YJ5Ns7fBBTRfJ68NlOtmOQrvcOvjyWGxk9v_XmDj-8moEQhcDUugh_VO5DdrJLYYV08ftr8YdhuhEM0otWs_ljew18j7XJFQ)

Das Ergebnis sieht dann so aus:

![](https://lh7-us.googleusercontent.com/-HqoJUAbcHRCletgSg6gcKXpn6zto1Do8I5EmcEmPWL4qUrMREh-wZdhy7ZKtnbuGjypd7p2mjcIu6LbbfdjA3c1liT2reCQXWiP1VAji08eWc_bbF_a0Dd82rJRgCuD5yjdlXL_DNheMcw-fm6pQnA)

Zwischen den beiden Feldern befindet sich nun eine Lücke. Diese Lücke lässt sich nach der zuvor beschriebenen 100-Prozent-Regel vergrößern oder verkleinern. Mit diesen Funktionen können Sie jedes gewünschte Layout erstellen.
