# Auto-Accounting

Sobald Sie das Auto-Accounting für Ihre DocBits-Umgebung konfiguriert haben, ist es sehr wichtig, dass alle Funktionen getestet werden, um einen reibungslosen Übergabeprozess sicherzustellen.&#x20;

## So aktivieren Sie Auto-Accounting

* Navigieren Sie vom Dashboard aus zu Einstellungen → Dokumentenverarbeitung → Modul.
* Auf der Registerkarte „Purchase Order / Auto Accounting" finden Sie den Schalter zum Aktivieren der Funktion sowie ein Dropdown-Feld zur Auswahl von LN oder M3

## Voraussetzungen

Damit die Auto-Accounting-Funktion funktioniert, müssen bestimmte Daten und Informationen konfiguriert werden. Um Sie bei diesem Prozess zu unterstützen oder Ihnen mitzuteilen, welche Konfiguration Ihnen fehlt, haben wir eine Schaltfläche „Validate Setup" erstellt, die wie unten gezeigt zu finden ist.

![](https://lh7-us.googleusercontent.com/zCqiu\_\_deFqdYih9yBGQhxbgXYuBvLFhSd48k-gA9sQoxoBibeyUAEc9k9HQCnmuddIU2Bws7IfK3JCuXylCo6sCdyuUNOeUHRLGGH3Jvz5MJRJU5cmsyzrH5lTo0eH\_ygFTuXc9dI3BZ\_wW-ybzHKw)

Nach dem Drücken führt DocBits eine Überprüfung Ihrer Umgebung durch, um festzustellen, ob alles korrekt konfiguriert ist.

Es erscheint ein Menü, das wie folgt aussieht

![](https://lh7-us.googleusercontent.com/v2UhbvTVO7pw29xeRb1kjWlVq8xPmYQNeoXpUZpztcvuWdpFR01u46yRaS3rKeTIhr9k0wor46wwUcoOaOwoP49CGW5VlsLI6fd15DvfnykRC9lFJkY8RN\_Y6DlHP7t4ldPROsdCqIjgg7e3dIK5J9s)

Alle Elemente mit dem grünen Häkchen davor bedeuten, dass sie konfiguriert sind und funktionieren. Das obige Bild sollte nur als Beispiel dienen und nicht Element für Element für Ihre Umgebung befolgt werden. Dies liegt daran, dass jeder Benutzer seinen eigenen Satz an Konten, Dimensionen und Dimensionsoptionen hat, wie oben kategorisiert.

Beträge aufteilen

Dies geschieht durch Klicken auf das folgende Symbol neben dem Gesamtbetrag oder einer bestimmten Position

![](https://lh7-us.googleusercontent.com/SzOTCQ8pox0UPXhlCeSLuqzeD\_gOfmFBkxzmae4Ms2JYLU\_GeQPgd5iITPiedpV12bNozVTFI8Z3cRtacEogkb5OU5OAiKJ4HV7li2HqDsZjYzES8WcCpPDWlYPjRrPfBo5LCGaxtd8uerJqUbmMQcg)

Sobald Sie das Aufteilungssymbol auswählen, erscheint ein neues Menü unterhalb des ausgewählten Elements

![](https://lh7-us.googleusercontent.com/NMyfsDFrPh7NwQNXF1FHP-oHDkBTUqoniwq48Pri7ULHiZRHuYVJ\_RTiSqt12LG1Q7ut9UTmmlQC0-y2Le5cMJ-c\_OwpWJ7s09r3kHS8I2wca75EiKfa4u2uBkYudgJ-gkEC7yK8OtweSyuqOZ2hh2Y)

Konten

Der erste Block des neuen Menüs gibt Ihnen Zugriff auf eine Dropdown-Liste, in der Sie ein Konto/eine Abteilung aus Ihren vorkonfigurierten Konten/Abteilungen auswählen können, auf die Sie den Betrag aufteilen möchten. DocBits gruppiert ähnliche Kontotypen zusammen, was es einfacher macht, bestimmte Kontoarten oder miteinander in Beziehung stehende Konten zu finden.

Beträge

Der zweite Block ermöglicht es Ihnen, die jeweiligen Beträge, auf die der übergeordnete Betrag aufgeteilt wird, manuell einzugeben.

Prozentuale Aufteilung

Der dritte und letzte Block ermöglicht es Ihnen, die prozentuale Aufteilung manuell einzugeben, in die der übergeordnete Betrag aufgeteilt werden soll. Der Anteil ist beim Aufrufen des Aufteilungsmenüs automatisch auf 50 % gesetzt, kann aber an Ihre Vorlieben angepasst werden. Wenn Sie einen Prozentwert in den Block eingeben, wird der Betrag automatisch im zweiten Block berechnet.

Beachten Sie, dass der neue Betrag erst berechnet wird, sobald Sie die „Eingabetaste" auf Ihrer Tastatur drücken, und dass die anderen Prozentsätze durch diese Änderung nicht verändert werden. Dies kann zu Beträgen führen, die nicht mit dem übergeordneten Betrag übereinstimmen. Aus diesem Grund haben wir in diesem Menü einen Zähler „Unsettled amount" (offener Betrag) erstellt, der später besprochen wird.
