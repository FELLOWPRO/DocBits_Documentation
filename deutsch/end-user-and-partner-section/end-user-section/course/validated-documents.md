# Validierte Dokumente

In diesem Video erhalten die Zuschauer eine Einführung in die benutzerfreundliche Oberfläche von **DocBits**, wobei der Schwerpunkt auf der Dokumentenvalidierung liegt. Das Tutorial betont die Einfachheit des Systems, bei dem keinerlei Programmierung oder komplexe Formeln erforderlich sind.

{% embed url="https://www.youtube.com/watch?v=FD9dC2_nvuw" %}

Dank KI und Schwarmintelligenz werden die meisten Felder automatisch extrahiert, sodass [Benutzer](../../../administration-and-setup/settings/global-settings/groups-users-and-permissions/) Informationen ganz einfach extrahieren können, indem sie auf Werte innerhalb des Dokuments klicken. Darüber hinaus erfahren die Zuschauer, wie flexibel sich bestimmte Bereiche extrahieren lassen, indem man doppelklickt oder den gewünschten Bereich umrahmt.
