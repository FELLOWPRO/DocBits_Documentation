# Dokumentenspalten ändern

**Klicken Sie im Dashboard auf das Symbol für die erweiterten Einstellungen, wie unten dargestellt:**

<figure><img src="../../../.gitbook/assets/dashboard_advanced_settings_icon.png" alt="Advanced Settings Icon"><figcaption></figcaption></figure>

Daraufhin wird das folgende Menü angezeigt:

![Advanced Settings Menu](https://lh7-us.googleusercontent.com/wWt5QbmwZf44enmOoLcofh6SvyYPiHTav9OiEog_m2xtnty6X73pFlhfdM9aglx89_pfbiACZx5BejagV-wAKwlDTuGoGNu5jgbcZ5djrZ_h1IgGp-8uaq8UHY-umjrs96hb4FZOzHFzdLasg2F_ftw)

Wählen Sie die Schaltfläche "Dashboard-Spalten für Organisation festlegen" aus, woraufhin eine Liste mit allen Spaltennamen angezeigt wird.

In diesem Menü können Sie die Spaltennamen auswählen und mit den Pfeilen die gewünschten Spalten hinzufügen oder entfernen.

![Dashboard Column Settings](https://lh7-us.googleusercontent.com/cXnnrIR-y4TRDnRE9irGvvjnmkN-HSGEQTh7FiwsjRHzXF7FNjd-_gLO-m55fLlv6lVjk-VvThgdW5JWgqIVZSm5tfk3hC7xrj68uRE5OgIPMtYIrpxOhhYzk4OMibyDBqvHQ0VZaDAysZohlH8dxm8)

<div data-full-width="true"><figure><img src="../../../.gitbook/assets/dashboard_column_ordering.png" alt="Reordering Dashboard Columns"><figcaption></figcaption></figure></div>

Sie können die Reihenfolge der Spalten festlegen, indem Sie auf die Punkte neben dem Spaltennamen klicken und diese an die gewünschte Position ziehen.

Eine weitere Option ermöglicht es Ihnen außerdem, Felder eines Dokumenttyps hinzuzufügen:

<figure><img src="../../../.gitbook/assets/add_document_type_field_button.png" alt="Add Document Type Field Button" width="243"><figcaption></figcaption></figure>

<figure><img src="../../../.gitbook/assets/select_document_type_field_window.png" alt="Select Document Type Field Window" width="563"><figcaption><p>Fenster zur Auswahl eines Dokumenttyp-Felds</p></figcaption></figure>

Hier können Sie aus den verschiedenen Dokumenttypen auswählen:

<figure><img src="../../../.gitbook/assets/document_type_selection_dropdown.png" alt="Document Type Selection Dropdown" width="254"><figcaption></figcaption></figure>

Für jeden Dokumenttyp gibt es verschiedene Felder, die Sie hinzufügen können:

<figure><img src="../../../.gitbook/assets/document_type_fields_list.png" alt="List of Available Document Type Fields" width="518"><figcaption><p>Fenster zur Auswahl eines Dokumenttyp-Felds</p></figcaption></figure>

Wählen Sie die benötigten Felder aus und klicken Sie auf "Zu sichtbaren Spalten hinzufügen". Sie werden dann in den Spalteneinstellungen angezeigt.

<figure><img src="../../../.gitbook/assets/visible_columns_after_addition.png" alt="Updated Visible Columns List" width="281"><figcaption></figcaption></figure>
