# Video-Karussell

Ein kleiner Bereich auf dem Vorbereitungs-Dashboard, der kurze Tipps zu Funktionen in DocBits abspielt — Dinge zum Ausprobieren, Stellen, an die Sie vielleicht nicht gedacht haben.

## Wo Sie es finden

Das Video-Karussell erscheint auf dem Vorbereitungs-Dashboard, während Dokumente importiert werden. Auf breiten Bildschirmen sitzt es rechts neben dem Fortschrittsbalken. Auf kleinen Bildschirmen ist es ausgeblendet.

## Verwendung

Tipps laufen nacheinander mit einer kurzen Bildunterschrift darunter. Klicken Sie auf die Punkte unter dem Video, um direkt zu einem bestimmten Tipp zu springen. Es gibt keinen Ton — lesen Sie die Bildunterschrift, um zu sehen, worum es bei jedem Tipp geht.
