# Exporting to IDM

Wenn Sie Ihr Dokument nur nach IDM bzw. Document Management in INFOR exportieren müssen, ähnelt die Konfiguration der des Exports nach IDM + LN/M3, erfordert jedoch keine BOD-Mapping-Datei, da kein Export nach LN/M3 erforderlich ist.
