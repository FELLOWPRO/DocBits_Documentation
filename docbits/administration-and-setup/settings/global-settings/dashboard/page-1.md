# Custom status filters

Use a custom status filter to choose which document statuses the Dashboard offers. This setting is separate from filtering the document list for an individual search.

## Who the setting affects

Organization administrators update the organization default. Where these controls are available to other users, the selection is saved as their personal preference instead. A personal preference takes precedence over the organization default.

## Choose the statuses

1. Open **Settings → Dashboard** and expand **Filters**.
2. Set **Status filter style** to **Custom**. The **Custom status filter** selector appears below it.
3. Open the status selector and choose the document statuses your team needs.
4. Select **Apply** to save the selected statuses. An empty selection restores **All**. Return to the Dashboard to use the configured status choices.

## Restore the standard choices

Return to **Status filter style** and choose **All**. A change to the style is saved as soon as you select it. The custom status selector and its **Apply** button disappear when **All** is selected. This restores the standard status choices; it does not change the documents themselves.
