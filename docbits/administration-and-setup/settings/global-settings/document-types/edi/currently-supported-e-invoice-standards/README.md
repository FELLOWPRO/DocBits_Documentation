# E-invoice standards overview

Use the [eDocs formats, versions and country guides](../supported-electronic-documents/README.md) as the central country overview.

It covers format families, XML syntax, publication versions, business profiles and the inspected classification, Transformation, Preview and Extraction Paths components. Open a country guide for its exact format labels and available screenshots and videos.

Catalogue entries describe available configuration. Check the effective rules in your organization and test representative source files before relying on a format. File processing, legal validation and network transmission require separate checks.
