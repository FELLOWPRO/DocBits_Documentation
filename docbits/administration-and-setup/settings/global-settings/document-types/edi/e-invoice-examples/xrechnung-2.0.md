# XRechnung 2.0

These historical examples show the invoice in external destination systems. Check the [official XRechnung version overview](https://xeinkauf.de/xrechnung/versionen-und-bundles/) and the versions supported by your recipient and installation. The language of the illustrated external ERP and IDM interfaces is separate from the DocBits interface language.
