# 🇪🇸 FACTURAE 3.2

<!-- edocs-country-scope -->

{% hint style="info" %}
Check the country guide for version limits, effective configuration and the country explainer. [Spain](countries/spain.md). Check the namespace and schema version. Extracting a signed XML file does not by itself verify its signature or its acceptance by FACe.
{% endhint %}

| Property             | Value                                    |
| -------------------- | ---------------------------------------- |
| **Country / Region** | Spain                                    |
| **Document Types**   | Invoice, Credit Note, Corrective Invoice |
| **Format**           | XML                                      |
| **Standard**         | Facturae 3.2                             |

Facturae 3.2 is a widely used version of the Spanish e-invoicing standard. It defines the XML structure for electronic invoices including seller/buyer identification, line items, tax details (IVA), and digital signature requirements.
