# PO Table in Layout Builder

This setting controls the accessibility of the **Purchase Order (PO) table** in the **Layout Builder** and the **Validation Screen**.

### **How to Enable the PO Table**

To enable this feature:

1. Go to **Settings → General Settings → Document Types → More Settings → Purchase Order Section → PO Table in Layout Builder**.
2. Enable the setting to make the **Purchase Order table** visible.

<figure><img src="../../../../../../.gitbook/assets/iScreen Shoter - Google Chrome - 250210131953.jpg" alt="More Settings page with the Purchase Order section and the PO table in layout builder toggle"><figcaption></figcaption></figure>

### **Functionality:**

* **When enabled**:
  * The **Purchase Order table** appears inside the **Table Section** in the **Layout Builder**.
  *   No notification about the module being disabled will be shown.\\

      <figure><img src="../../../../../../.gitbook/assets/image (42).png" alt="Layout Builder with the Table Section showing the cards EXTRAHIERTE TABELLE and PO-TABELLEN next to each other"><figcaption></figcaption></figure>
* **When disabled**:
  * A hint will indicate that the module is disabled.
  *   The **PO table** will not be visible in the **Validation Screen**.\\

      <figure><img src="../../../../../../.gitbook/assets/image (41).png" alt="Layout Builder Table Section with the PO-TABELLE card showing the hint Modul deaktiviert"><figcaption></figcaption></figure>

**How to Access the Layout Builder**

1. Navigate to **Settings → General Settings → Document Types → Edit Layout**.

<figure><img src="../../../../../../.gitbook/assets/iScreen Shoter - Google Chrome - 250210135142.jpg" alt="Document Types page with the Edit layout, Document Sub Types, Table columns and Fields tabs for a document type"><figcaption></figcaption></figure>

**Adding the PO Table Back to the Layout**

If the **PO table** is missing or has been removed, follow these steps:

1. Open the **Layout Builder**.
2. Under **Form Elements**, select **Extracted Tables**.
3. Add the **PO table** to your layout.

<div align="left"><figure><img src="../../../../../../.gitbook/assets/iScreen Shoter - Google Chrome - 250210135437.jpg" alt="Layout Builder side panel with Form Elements including Text, Label, Check Box, Table Of Checkboxes, Extracted Tables and Sub Group"><figcaption></figcaption></figure></div>

Once added and enabled, the **PO table** will be visible in the **Layout Builder** and the **Validation Screen** when a **purchase order** is available for an invoice.
