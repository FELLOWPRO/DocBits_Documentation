# Defining tables and columns

If a table is not recognized completely, use table training to define its area and columns. These examples use a fictional invoice. The illustrated training areas are unsaved drafts.

## Open table training

Open the document in **Field Validation**, then open **Table Extraction**. The document appears on the left and the training controls on the right.

<figure><img src="../../../../.gitbook/assets/s150-define_tables_and_columns_1.png" alt="English interface for defining tables and columns."><figcaption><p>English interface for defining tables and columns.</p></figcaption></figure>

## Enable training mode

Turn on **Training Mode** to make the table-selection and column tools available.

<figure><img src="../../../../.gitbook/assets/s150-define_tables_and_columns_2.png" alt="Table training with training mode enabled."><figcaption><p>Table training with training mode enabled.</p></figcaption></figure>

The toolbar includes automatic table detection. Check its result against the document before defining columns. This image shows the available tools; it does not demonstrate a completed automatic detection.

<figure><img src="../../../../.gitbook/assets/s150-define_tables_and_columns_3.png" alt="Table-training tools including automatic detection."><figcaption><p>Table-training tools including automatic detection.</p></figcaption></figure>

## Select the table area

For a manual selection, choose the pencil tool and drag a rectangle around the column headings and line items. Exclude totals below the table.

<figure><img src="../../../../.gitbook/assets/s150-define_tables_and_columns_4.png" alt="Unsaved table area around the fictional invoice&#x27;s line items."><figcaption><p>Unsaved table area around the fictional invoice&#x27;s line items.</p></figcaption></figure>

## Position the column separators

Choose the column tool, then place or drag vertical separators between the actual columns.

<figure><img src="../../../../.gitbook/assets/s150-define_tables_and_columns_5.png" alt="Table area in edit mode with vertical column separators."><figcaption><p>Table area in edit mode with vertical column separators.</p></figcaption></figure>

Check the separation of item, description, quantity, unit price and amount. The separators in this example follow the five columns of the invoice.

<figure><img src="../../../../.gitbook/assets/s150-define_tables_and_columns_9.png" alt="Table area with column separators positioned for the training draft."><figcaption><p>Table area with column separators positioned for the training draft.</p></figcaption></figure>

Review the complete area and column assignments before using **Save** or **Save Rules**.

<figure><img src="../../../../.gitbook/assets/s150-define_tables_and_columns_8.png" alt="Table area and column separators in an unsaved training draft."><figcaption><p>Table area and column separators in an unsaved training draft.</p></figcaption></figure>

## Check the extracted values

Compare the extracted line items with the original document. This image shows the example invoice's already automatically extracted rows in validation. They are not a result of the unsaved training draft above.

<figure><img src="../../../../.gitbook/assets/s150-define_tables_and_columns_10.png" alt="Automatically extracted line items of the fictional invoice in validation."><figcaption><p>Automatically extracted line items of the fictional invoice in validation.</p></figcaption></figure>

Use **Save Rules** when you intend to retain the training, then test it with further documents from the same supplier. One example does not establish reliable extraction for other layouts.
