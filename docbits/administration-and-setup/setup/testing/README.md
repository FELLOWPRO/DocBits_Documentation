# Testing

Check that DocBits works the way your organisation configured it.

* The **[Testing module](testing-module/README.md)** (**Settings → Testing**) runs repeatable checks in your
  own browser, by hand, from an AI assistant or from your test automation, and keeps a log of every run.
* The guides below describe manual checks of specific features after you set them up:
  [PO Matching](po-matching.md) and [Auto Accounting](auto-accounting/README.md).
