# Review what an AI agent has learned

Agent memory contains reusable lessons associated with an AI Workforce agent. Review it when an agent repeatedly follows an outdated or incorrect instruction. Memory is separate from its prompt, custom instructions, tools and approval mode.

## Inspect lessons

1. Open **AI Workforce → Agents** and select the intended agent.
2. Find **What this agent has learned** in its profile. Confirm agent and organization.
3. Read the lesson and source: user feedback, self-reflection or episodic experience. Its source does not establish correctness.
4. Review confidence, usage count and tags. High confidence or frequent use is not independent verification.
5. Filter by source where offered, or choose **Load more**. Compare a questionable lesson with the relevant mission, issue and business rule.

## Give feedback or remove a lesson

1. Choose **thumbs up** for helpful or **thumbs down** for unhelpful lessons. Wait and check the recorded feedback.
2. Before removing an incorrect lesson, retain the relevant explanation in your internal case record and confirm that you are authorized to remove it.
3. Choose that lesson's **delete** icon. This removes it; it does not open an editor. Do not assume a second confirmation appears.
4. Reload the profile and verify that the intended lesson is absent. Removal does not undo earlier agent actions or delete mission history.
5. Test behavior with a harmless new case. If the problem remains, also inspect prompt, custom instructions, tools and input data.

An empty panel can mean that no lessons exist. A loading error is different: read the message and reload before concluding that memory is empty.

See [AI Workforce](ai_workforce.md) for agent settings, missions and approvals.
