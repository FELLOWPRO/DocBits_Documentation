# Personal Dashboards

Save a recurring worklist with its filters, sort order and visible columns. A saved dashboard is a view of existing documents.

## Create and share a view

1. Set the search, filters, document type, sorting and columns you want.
2. Open the blue view badge below the search box.
3. Choose **Create New Dashboard** and enter a clear name.
4. Select private visibility, all users, or specific groups and users.
5. Choose **Save**.

The visibility setting controls who can use the view. Each person still sees only the documents their permissions allow.

## Switch, update or remove a view

Use the view badge to select a saved dashboard or return to the default view. After changing your own view, choose **Save Dashboard Changes** when that action becomes available. It is unavailable when nothing has changed or when another person shared the view with you.

Use the edit control for a view you own to change its name or sharing settings. Use its delete control and confirm only when you want to remove the saved view. Removing a view does not delete the documents. To adapt somebody else's shared view, create a new view of your own.
