# VESTA Hotfix — 11 November 2026

> **Release channel:** VESTA · **Status:** Planned · **Scheduled date:** 11 November 2026.

The next VESTA hotfix brings **all features previously available as beta in VESTA into the regular VESTA feature set**. These former beta features are already included as regular features in the [NOVA major release](nova-major-release-16-october-2026.md#former-vesta-beta-features-included-in-nova).

## What changes for your team

* **Former beta features become regular VESTA features.** Teams that have not used the VESTA beta gain access to these capabilities through this hotfix.
* **Rule and layout controls become directly available.** This includes **Manage Layouts**, **Custom Validation Rules** and **Transformation Rules** in the document type's advanced settings, without a beta link.
* **Existing configuration and permissions still apply.** Administrators continue to control organisation settings and document-type switches; users need the appropriate access rights.

| Release | Availability of the former VESTA beta features |
| --- | --- |
| **NOVA** | Included in the regular feature set now. |
| **VESTA — 11 November 2026 hotfix** | Planned introduction into the regular VESTA feature set. |

This preview announces the rollout of the former VESTA beta features. The [NOVA release notes](nova-major-release-16-october-2026.md) also describe further NOVA additions and improvements. The service versions and any additional fixes for the VESTA hotfix will be listed when the release details are finalised.
