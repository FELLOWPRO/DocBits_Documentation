# VESTA Hotfix — 11 November 2026

> **Release channel:** VESTA · **Status:** Planned · **Scheduled date:** 11 November 2026.

The next VESTA hotfix brings **all features previously available as beta in VESTA into the regular VESTA feature set**. These features are already available in the [NOVA sandbox](nova-major-release-16-october-2026.md#former-vesta-beta-features-included-in-nova); the NOVA production release is planned for **4 November 2026**.

## What changes for your team

* **Former beta features become regular VESTA features.** Teams that have not used the VESTA beta gain access to these capabilities through this hotfix.
* **Rule and layout controls become directly available.** This includes **Manage Layouts**, [**Custom Validation Rules**](../../administration-and-setup/settings/global-settings/document-types/custom-validation-rules.md) and [**Transformation Rules**](../../administration-and-setup/settings/global-settings/document-types/transformation-rules.md) in the document type's advanced settings, without a beta link.
* **Existing configuration and permissions still apply.** Administrators continue to control organisation settings and document-type switches; users need the appropriate access rights.

| Release | Availability of the former VESTA beta features |
| --- | --- |
| **NOVA** | Available in the sandbox since 16 October 2026; production release planned for 4 November 2026. |
| **VESTA — 11 November 2026 hotfix** | Planned introduction into the regular VESTA feature set. |
