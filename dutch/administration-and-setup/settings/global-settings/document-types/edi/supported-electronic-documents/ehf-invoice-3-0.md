# 🇳🇴 EHF INVOICE 3.0

| Eigenschap | Waarde |
|------------|--------|
| **Land / Regio** | Noorwegen |
| **Documenttypen** | Factuur, Creditnota |
| **Formaat** | UBL 2.1 XML |
| **Standaard** | EHF Invoice 3.0 (gebaseerd op Peppol BIS Billing 3.0) |

EHF (Elektronisk Handelsformat) Invoice 3.0 is de Noorse e-factureringsstandaard, beheerd door het Agency for Public Management and eGovernment (Difi). Versie 3.0 is afgestemd op Peppol BIS Billing 3.0, waardoor Noorse e-facturen interoperabel zijn binnen het Europese Peppol-netwerk.
