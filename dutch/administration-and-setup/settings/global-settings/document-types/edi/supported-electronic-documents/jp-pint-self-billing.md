# 🇯🇵 JP PINT SELF-BILLING

<!-- edocs-country-scope -->

{% hint style="info" %}
Raadpleeg de landengids voor versiebeperkingen, de daadwerkelijk gebruikte configuratie en de uitlegvideo voor het land. [Japan](countries/japan.md). Selfbilling is een variant van een bedrijfsproces, geen taalkeuze. Controleer de aanpassingsidentificatie en de geconfigureerde variant.
{% endhint %}

| Eigenschap | Waarde |
|------------|--------|
| **Land / Regio** | Japan |
| **Documenttypen** | Zelffactuur (door de koper opgesteld) |
| **Formaat** | UBL 2.1 XML |
| **Standaard** | JP PINT Self-Billing |

JP PINT Self-Billing is de zelffactureringsvariant van het Japanse Peppol International-factuurmodel. Hiermee kunnen kopers namens leveranciers facturen opstellen, volgens dezelfde JP PINT-structuur met omgekeerde partijrollen, zoals onder specifieke voorwaarden is toegestaan in de Japanse belastingwetgeving.
