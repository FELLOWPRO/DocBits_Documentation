# 🇵🇾 PARAGUAY SIFEN 150

| Eigenschap           | Waarde                   |
| -------------------- | ------------------------ |
| **Land / Regio**     | Paraguay                 |
| **Documenttypen**    | Factuur, Creditnota      |
| **Formaat**          | XML                      |
| **Standaard**        | SIFEN-schemaversie 150   |

SIFEN 150 verwijst naar schemaversie 150 van het Paraguayaanse SIFEN-systeem. Deze versie introduceerde bijgewerkte validatieregels en veldvereisten voor elektronische documenten die via het SET-platform worden verwerkt.
