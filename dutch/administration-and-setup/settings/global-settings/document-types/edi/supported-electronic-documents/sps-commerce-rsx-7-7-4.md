# SPS COMMERCE RSX 7.7.4

| Eigenschap | Waarde |
|----------|-------|
| **Land / Regio** | Internationaal (voornamelijk Noord-Amerika) |
| **Documenttypen** | Factuur (810), Inkooporder (850), ASN (856) |
| **Formaat** | XML |
| **Standaard** | SPS Commerce RSX 7.7.4 (Retail Standard XML) |

SPS Commerce RSX (Retail Standard XML) 7.7.4 is een EDI-naar-XML-vertaalstandaard die wordt gebruikt in de retailtoeleveringsketen. Het biedt XML-weergaven van veelvoorkomende EDI-transacties, waaronder facturen (810), inkooporders (850) en verzendberichten (856, Advance Ship Notice). SPS Commerce is een toonaangevende EDI-aanbieder die retailers met leveranciers verbindt.
