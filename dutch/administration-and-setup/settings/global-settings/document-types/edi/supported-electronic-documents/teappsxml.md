# 🇫🇮 TEAPPSXML

| Eigenschap | Waarde |
| ---------- | ------ |
| **Land / Regio** | Finland |
| **Documenttypen** | Factuur, Creditnota |
| **Formaat** | XML |
| **Standaard** | TEAPPSXML 3.0 |

TEAPPSXML is een Fins e-factuurformaat dat door Tieto (nu TietoEVRY) wordt gebruikt voor de uitwisseling van facturen. Het wordt op de Finse markt vaak naast Finvoice gebruikt, met name door organisaties die werken met op Tieto gebaseerde ERP- en financiële systemen.
