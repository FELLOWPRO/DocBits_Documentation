# 🇺🇾 URUGUAY E-FACTURA

| Eigenschap | Waarde |
| ---------- | ------ |
| **Land / Regio** | Uruguay |
| **Documenttypen** | e-Factuur (e-Factura) |
| **Formaat** | XML |
| **Standaard** | e-Factura (CFE-type 111) |

Uruguay e-Factura is het elektronische factuurdocumenttype binnen het CFE-systeem, geïdentificeerd door typecode 111. Het wordt gebruikt voor formele B2B-transacties tussen entiteiten met een RUT-registratie en bevat alle belastingidentificatie- en berekeningsvelden die de DGI vereist.
