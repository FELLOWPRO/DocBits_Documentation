# 🇩🇪 XRECHNUNG 3.0.1 UBL

| Eigenschap           | Waarde                   |
| -------------------- | ------------------------ |
| **Land / Regio**     | Duitsland                |
| **Documenttypen**    | Factuur, Creditnota      |
| **Formaat**          | UBL                      |
| **Standaard**        | XRechnung 3.0.1          |
| **Gebaseerd op**     | EN 16931 (OASIS UBL 2.1) |

XRechnung 3.0.1 is de huidige generatie van de Duitse e-factureringsstandaard en sluit aan op de nieuwste EN 16931-updates. Onderhoudsrelease met correcties van validatie-artefacten en verduidelijkingen in de technische documentatie.
