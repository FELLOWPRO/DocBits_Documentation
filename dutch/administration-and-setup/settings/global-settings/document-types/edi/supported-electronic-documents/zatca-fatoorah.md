# 🇸🇦 ZATCA FATOORAH

| Eigenschap           | Waarde                                                    |
| -------------------- | --------------------------------------------------------- |
| **Land / Regio**     | Saoedi-Arabië                                             |
| **Documenttypen**    | Factuur (Fatoorah)                                        |
| **Formaat**          | UBL 2.1 XML                                               |
| **Standaard**        | ZATCA FATOORAH (ZATCA - Zakat, Tax and Customs Authority) |

ZATCA Fatoorah is de Saoedi-Arabische standaard voor elektronische facturering, beheerd door de Zakat, Tax and Customs Authority. Fase 1 (generatie) werd in december 2022 verplicht, en fase 2 (integratie) vereist realtime rapportage aan het ZATCA-platform. Fatoorah is het standaardformaat voor belastingfacturen bij B2B-transacties boven SAR 1.000.
