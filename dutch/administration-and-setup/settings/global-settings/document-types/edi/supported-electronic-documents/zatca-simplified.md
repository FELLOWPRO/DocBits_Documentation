# 🇸🇦 ZATCA SIMPLIFIED

| Eigenschap | Waarde |
| ---------- | ------ |
| **Land / Regio** | Saudi-Arabië |
| **Documenttypen** | Vereenvoudigde btw-factuur |
| **Formaat** | UBL 2.1 XML |
| **Standaard** | ZATCA Simplified Tax Invoice |

ZATCA Simplified Tax Invoice wordt gebruikt voor B2C-transacties in Saudi-Arabië waarbij het totaalbedrag (inclusief btw) niet hoger is dan SAR 1.000. In tegenstelling tot standaard btw-facturen vereisen vereenvoudigde facturen geen identificatie van de koper, maar moeten ze een QR-code bevatten met de TLV-gecodeerde verkopersgegevens, het btw-bedrag en het tijdstempel.
