# 🇩🇪 ZUGFERD 1.0 EXTENDED

<!-- edocs-country-scope -->

{% hint style="info" %}
Raadpleeg de landengids voor versiebeperkingen, de daadwerkelijk gebruikte configuratie en de uitlegvideo voor het land. [Duitsland](countries/germany.md). Syntaxis, publicatieversie en profiel zijn verschillende keuzes. Leid geen Factur-X-publicatie af uit de gedeelde 1p0-markering.
{% endhint %}

| Eigenschap | Waarde |
| ---------- | ------ |
| **Land / Regio** | Duitsland |
| **Documenttypen** | Factuur, Creditnota |
| **Formaat** | CII (PDF/A-3 ingebed) |
| **Standaard** | ZUGFeRD 1.0, Extended-profiel |
| **Gebaseerd op** | ZUGFeRD 1.0-specificatie |

Het Extended-profiel van ZUGFeRD 1.0 is het meest uitgebreide profiel en ondersteunt aanvullende bedrijfsscenario's zoals handelsboekhouding, factoring en gedetailleerde logistieke informatie. Het bevat alle velden van Basic en Comfort, plus branchespecifieke uitbreidingen.
