# 🇩🇪 ZUGFERD 1.0

| Eigenschap | Waarde |
| ---------- | ------ |
| **Land / Regio** | Duitsland |
| **Documenttypen** | Factuur, Creditnota |
| **Formaat** | CII (PDF/A-3 ingebed) |
| **Standaard** | ZUGFeRD 1.0 |
| **Gebaseerd op** | ZUGFeRD 1.0-specificatie |

ZUGFeRD 1.0 was de oorspronkelijke Duitse hybride factuurstandaard, uitgebracht in 2014. Het sluit een CII-XML-bestand (ZUGFeRD-invoice.xml) in een PDF/A-3-document in. Deze versie is ouder dan de Europese norm EN 16931 en gebruikt een eigen profielsysteem.
