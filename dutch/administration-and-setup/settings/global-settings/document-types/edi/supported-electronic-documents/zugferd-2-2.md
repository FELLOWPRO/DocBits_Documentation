# 🇩🇪 ZUGFERD 2.2

| Eigenschap | Waarde |
| ---------- | ------ |
| **Land / Regio** | Duitsland |
| **Documenttypen** | Factuur, Creditnota |
| **Formaat** | CII (PDF/A-3 ingebed) |
| **Standaard** | ZUGFeRD 2.2 |
| **Gebaseerd op** | EN 16931 |

ZUGFeRD 2.2, uitgebracht in 2022, sluit aan bij de Europese norm EN 16931 en is gelijkwaardig aan Factur-X 1.0.06. Het gebruikt de CII D16B-XML-syntaxis en ondersteunt vijf conformiteitsprofielen: Minimum, Basic WL, Basic, EN 16931 (Comfort) en Extended.
