# 🇩🇪 ZUGFERD 2.3

<!-- edocs-country-scope -->

{% hint style="info" %}
Raadpleeg de landengids voor versiebeperkingen, de daadwerkelijk gebruikte configuratie en de uitlegvideo voor het land. [Duitsland](countries/germany.md). Syntaxis, publicatieversie en profiel zijn verschillende keuzes. Leid geen Factur-X-publicatie af uit de gedeelde 1p0-markering.
{% endhint %}

| Eigenschap | Waarde |
| ---------- | ------ |
| **Land / Regio** | Duitsland |
| **Documenttypen** | Factuur, Creditnota |
| **Formaat** | CII (PDF/A-3 ingebed) |
| **Standaard** | ZUGFeRD 2.3 |
| **Gebaseerd op** | EN 16931 |

ZUGFeRD 2.3, uitgebracht in september 2024, is gelijkwaardig aan Factur-X 1.0.07. Het werkt de CII-XML bij naar de D22B-specificatie, voegt verbeterde validatieregels toe en introduceert ondersteuning voor het XRechnung-referentieprofiel om aan de Duitse B2G-vereisten te voldoen.
