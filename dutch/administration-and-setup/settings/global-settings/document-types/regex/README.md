# Reguliere expressies (Regex)

De oude directe Regex-koppeling op de documenttypekaart is niet beschikbaar in de huidige interface.

Controleer vóór het wijzigen van een expressie welke configuratieroute uw versie ondersteunt. Bewaar de bestaande expressie en bereid geldige, onvolledige en niet-overeenkomende invoer voor. Vergelijk na iedere wijziging de daadwerkelijke overeenkomsten. Sla de bedoelde configuratie pas na controle op en test representatieve documenten voordat u de expressie op andere facturen toepast.
