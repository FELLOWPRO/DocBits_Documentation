# Cards

Kaarten zijn de bouwstenen van elke workflow. U combineert ze in de **When / And / Then**-groepen om te beschrijven wanneer een workflow wordt uitgevoerd en wat hij doet. Dit gedeelte legt de beschikbare kaarten uit en wat elke kaart doet.

<figure><img src="../../../.gitbook/assets/workflow_add_card_picker.png" alt="Add Card-bibliotheek gegroepeerd per categorie"><figcaption><p>De <strong>Add Card</strong>-bibliotheek — kaarten zijn gegroepeerd per categorie.</p></figcaption></figure>

## Kaartgroepen

* **When** — de triggerkaarten die een workflow starten (bijv. documenttype, documenttype is een van).
* **And** — voorwaardekaarten die ook waar moeten zijn voordat de acties worden uitgevoerd. Hiertoe behoren _Compare with Purchase Order_ (PO-matching), _Document Field_-vergelijkingen, _Date & Time_, _Logic_, _Status_, _Table_ en _Assignee_-voorwaarden.
* **Then** — actiekaarten die het werk doen: velden instellen, goedkeuren/afkeuren, status wijzigen, exporteren, taken aanmaken, documenten toewijzen, tabellen bewerken en acties uitvoeren (Call API, Send HTTPS request, Run Workflow, AI-berekeningen).

## Kaart-referentiegidsen

Voor een volledige referentie van elke kaart en de bijbehorende opties raadpleegt u de _complete guide_-pagina's in dit gedeelte (Condition Cards, PO Matching Cards, Assignment & User Cards, Task Cards, Field & Table Cards en de Action-kaarten).
