# System Licenses

<figure><img src="../../.gitbook/assets/system_licenses.png" alt="System Licenses"><figcaption><p>Página System Licenses</p></figcaption></figure>

La página System Licenses (también denominada API Licenses) muestra todos los paquetes de software de terceros que utiliza DocBits, incluidos sus números de versión y las licencias de código abierto asociadas. Esta información se proporciona con fines de cumplimiento normativo y transparencia.
