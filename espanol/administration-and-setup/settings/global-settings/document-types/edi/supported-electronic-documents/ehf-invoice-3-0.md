# 🇳🇴 EHF INVOICE 3.0

| Propiedad              | Valor                                             |
| ---------------------- | ------------------------------------------------- |
| **País / Región**      | Noruega                                           |
| **Tipos de documento** | Factura, Nota de crédito                          |
| **Formato**            | UBL 2.1 XML                                       |
| **Estándar**           | EHF Invoice 3.0 (basado en Peppol BIS Billing 3.0) |

EHF (Elektronisk Handelsformat) Invoice 3.0 es el estándar noruego de facturación electrónica mantenido por la Agencia de Gestión Pública y Administración Electrónica (Difi). La versión 3.0 está alineada con Peppol BIS Billing 3.0, lo que hace que las facturas electrónicas noruegas sean interoperables en toda la red europea Peppol.

## Estado de compatibilidad

| Componente             | Estado          |
| ---------------------- | --------------- |
| Vista previa           | ✅ Compatible    |
| Extracción de campos   | ✅ Compatible    |
| Transformación         | ✅ Compatible    |
