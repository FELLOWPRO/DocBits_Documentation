# 🇪🇸 FACTURAE 3.2.1

| Propiedad              | Valor                                       |
| ---------------------- | ------------------------------------------- |
| **País / Región**      | España                                      |
| **Tipos de documento** | Factura, Nota de crédito, Factura rectificativa |
| **Formato**            | XML                                         |
| **Estándar**           | Facturae 3.2.1                              |

Facturae 3.2.1 es una actualización de mantenimiento que introdujo correcciones en el esquema XML, reglas de validación mejoradas y compatibilidad con categorías de impuestos adicionales exigidas por la normativa fiscal española.

## Estado de compatibilidad

| Componente             | Estado          |
| ---------------------- | --------------- |
| Vista previa           | ✅ Compatible    |
| Extracción de campos   | ✅ Compatible    |
| Transformación         | ✅ Compatible    |
