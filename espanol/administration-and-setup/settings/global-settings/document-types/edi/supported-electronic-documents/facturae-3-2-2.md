# 🇪🇸 FACTURAE 3.2.2

| Propiedad              | Valor                                       |
| ---------------------- | ------------------------------------------- |
| **País / Región**      | España                                      |
| **Tipos de documento** | Factura, Nota de crédito, Factura rectificativa |
| **Formato**            | XML                                         |
| **Estándar**           | Facturae 3.2.2                              |

Facturae 3.2.2 es la versión más reciente del estándar español de facturación electrónica. Incluye un tratamiento fiscal actualizado para la compatibilidad con el SII (Suministro Inmediato de Información) y una mejor compatibilidad con las facturas rectificativas.

## Estado de compatibilidad

| Componente             | Estado          |
| ---------------------- | --------------- |
| Vista previa           | ✅ Compatible    |
| Extracción de campos   | ✅ Compatible    |
| Transformación         | ✅ Compatible    |
