# 🇫🇷 FACTURX 1.0.05 - ZUGFERD 2.1

| Propiedad              | Valor                         |
| ---------------------- | ----------------------------- |
| **País / Región**      | Francia / Alemania            |
| **Tipos de documento** | Factura, Nota de crédito      |
| **Formato**            | CII (incrustado en PDF/A-3)   |
| **Estándar**           | Factur-X 1.0.05 / ZUGFeRD 2.1 |
| **Basado en**          | EN 16931                      |

Factur-X 1.0.05 equivale a ZUGFeRD 2.1. Publicada en 2020, fue la primera versión publicada conjuntamente que estableció la plena interoperabilidad entre los ecosistemas de facturación electrónica francés y alemán. Admite los perfiles: Minimum, Basic WL, Basic, EN 16931, Extended.

## Estado de compatibilidad

| Componente             | Estado          |
| ---------------------- | --------------- |
| Vista previa           | ✅ Compatible    |
| Extracción de campos   | ✅ Compatible    |
| Transformación         | ✅ Compatible    |
