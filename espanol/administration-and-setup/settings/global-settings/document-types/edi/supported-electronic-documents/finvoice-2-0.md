# 🇫🇮 FINVOICE 2.0

| Propiedad              | Valor                    |
| ---------------------- | ------------------------ |
| **País / Región**      | Finlandia                |
| **Tipos de documento** | Factura, Nota de crédito |
| **Formato**            | XML (envoltorio SOAP)    |
| **Estándar**           | Finvoice 2.0             |

Finvoice 2.0 amplió el estándar con una mejor compatibilidad con las condiciones de pago, los datos de entrega y la declaración de IVA de la UE. Mantuvo el modelo de transporte basado en SOAP utilizado por las redes bancarias finlandesas.

## Estado de compatibilidad

| Componente             | Estado          |
| ---------------------- | --------------- |
| Vista previa           | ✅ Compatible    |
| Extracción de campos   | ✅ Compatible    |
| Transformación         | ✅ Compatible    |
