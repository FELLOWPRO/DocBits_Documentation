# 🇸🇬 INVOICENOW SG

| Propiedad              | Valor                                         |
| ---------------------- | --------------------------------------------- |
| **País / Región**      | Singapur                                      |
| **Tipos de documento** | Factura, Nota de crédito                      |
| **Formato**            | UBL 2.1 XML (Peppol)                          |
| **Estándar**           | InvoiceNow SG (Peppol BIS específico de Singapur) |

InvoiceNow SG es la localización para Singapur del estándar Peppol BIS Billing. Amplía el modelo base de Peppol con reglas de negocio específicas de Singapur, el tratamiento del GST y los requisitos de identificación mediante UEN (Unique Entity Number).

## Estado de compatibilidad

| Componente             | Estado          |
| ---------------------- | --------------- |
| Vista previa           | ✅ Compatible    |
| Extracción de campos   | ✅ Compatible    |
| Transformación         | ✅ Compatible    |
