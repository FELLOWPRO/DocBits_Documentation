# 🇰🇿 KAZAKHSTAN ESF

| Propiedad              | Valor                                                |
| ---------------------- | ---------------------------------------------------- |
| **País / Región**      | Kazajistán                                           |
| **Tipos de documento** | Factura                                              |
| **Formato**            | XML                                                  |
| **Estándar**           | ESF (Электронные счета-фактуры / Factura electrónica) |

Kazakhstan ESF (Электронные счета-фактуры) es el sistema de facturas electrónicas gestionado por el Comité de Ingresos Estatales. Todas las empresas registradas a efectos de IVA deben emitir facturas electrónicas a través del sistema de información ESF. Los documentos incluyen la identificación fiscal BIN/IIN y los cálculos de IVA, y están firmados digitalmente.
