# 🇵🇾 PARAGUAY SIFEN 150

| Propiedad              | Valor                    |
| ---------------------- | ------------------------ |
| **País / Región**      | Paraguay                 |
| **Tipos de documento** | Factura, Nota de crédito |
| **Formato**            | XML                      |
| **Estándar**           | SIFEN Schema Version 150 |

SIFEN 150 hace referencia a la versión 150 del esquema del sistema paraguayo SIFEN. Esta versión introdujo reglas de validación y requisitos de campos actualizados para los documentos electrónicos procesados a través de la plataforma de la SET.

## Estado de compatibilidad

| Componente             | Estado          |
| ---------------------- | --------------- |
| Vista previa           | ✅ Compatible    |
| Extracción de campos   | ✅ Compatible    |
| Transformación         | ✅ Compatible    |
