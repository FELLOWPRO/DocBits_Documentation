# 🇪🇺 PEPPOL BIS 3.0

<!-- edocs-country-scope -->

{% hint style="info" %}
Consulte la guía del país para conocer los límites de versión, la configuración que se está utilizando y el vídeo explicativo del país. [Internacional](countries/international.md). Las asignaciones de facturas, pedidos, respuestas y avisos de expedición son diferentes. El procesamiento de archivos no proporciona por sí mismo un punto de acceso Peppol ni conectividad con socios comerciales.
{% endhint %}

| Propiedad              | Valor                                             |
| ---------------------- | ------------------------------------------------- |
| **País / Región**      | Unión Europea / Internacional (más de 40 países)  |
| **Tipos de documento** | Factura, Nota de crédito                          |
| **Formato**            | UBL 2.1 XML                                       |
| **Estándar**           | Peppol BIS Billing 3.0                            |

Peppol BIS Billing 3.0 es el estándar paneuropeo de facturación electrónica utilizado en toda la red Peppol. Se basa en OASIS UBL 2.1 e implementa la norma europea EN 16931 de facturación electrónica. Peppol permite el intercambio transfronterizo de facturas B2B y B2G en más de 40 países a través de Access Points certificados.
