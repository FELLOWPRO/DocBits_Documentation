# 🇵🇪 PERU CPE

| Propiedad              | Valor                                    |
| ---------------------- | ---------------------------------------- |
| **País / Región**      | Perú                                     |
| **Tipos de documento** | Factura, Nota de crédito, Nota de débito |
| **Formato**            | UBL XML                                  |
| **Estándar**           | CPE (Comprobante de Pago Electrónico)    |

CPE (Comprobante de Pago Electrónico) es el estándar peruano de comprobante de pago electrónico regulado por la SUNAT. DocBits admite las versiones UBL 2.0 y 2.1 utilizadas para la facturación electrónica en Perú.

## Estado de compatibilidad

| Componente             | Estado          |
| ---------------------- | --------------- |
| Vista previa           | ✅ Compatible    |
| Extracción de campos   | ✅ Compatible    |
| Transformación         | ✅ Compatible    |
