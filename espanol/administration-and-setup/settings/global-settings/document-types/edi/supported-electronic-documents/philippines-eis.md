# 🇵🇭 PHILIPPINES EIS

| Propiedad              | Valor                                   |
| ---------------------- | --------------------------------------- |
| **País / Región**      | Filipinas                               |
| **Tipos de documento** | Factura, Recibo oficial                 |
| **Formato**            | XML/JSON                                |
| **Estándar**           | EIS (Electronic Invoicing System - BIR) |

Philippines EIS es el Sistema de Facturación Electrónica de la Oficina de Impuestos Internos (BIR). Su objetivo es digitalizar la facturación y la emisión de recibos de las empresas filipinas, y exige la transmisión electrónica de los datos de ventas al sistema de la BIR para supervisar el cumplimiento fiscal.
