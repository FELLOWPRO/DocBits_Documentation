# 🇸🇪 SVEFAKTURA 1.0

| Propiedad              | Valor          |
| ---------------------- | -------------- |
| **País / Región**      | Suecia         |
| **Tipos de documento** | Factura        |
| **Formato**            | UBL XML        |
| **Estándar**           | Svefaktura 1.0 |

Svefaktura 1.0 es el formato sueco de facturación electrónica basado en UBL, mantenido por la Asociación Sueca de Autoridades Locales y Regiones (SFTI). Aunque la facturación electrónica sueca más reciente ha pasado a Peppol BIS, Svefaktura 1.0 sigue en uso y se admite para el procesamiento de documentos heredados.

## Estado de compatibilidad

| Componente             | Estado          |
| ---------------------- | --------------- |
| Vista previa           | ✅ Compatible    |
| Extracción de campos   | ✅ Compatible    |
| Transformación         | ✅ Compatible    |
