# 🇹🇷 TURKEY E-ARSIV

| Propiedad            | Valor                                         |
| -------------------- | --------------------------------------------- |
| **País / Región**    | Turquía                                       |
| **Tipos de documento** | Factura de archivo                          |
| **Formato**          | XML UBL-TR                                    |
| **Estándar**         | e-Arşiv Fatura (GİB - Administración Tributaria) |

Turkey e-Arşiv (e-Archive) es el formato de factura electrónica utilizado para las facturas emitidas a destinatarios que no están registrados en el sistema turco e-Fatura. Las facturas e-Arşiv se almacenan en la plataforma de la GİB (Gelir İdaresi Başkanlığı) y pueden entregarse a los destinatarios en PDF o en papel. DocBits procesa el formato XML UBL-TR.
