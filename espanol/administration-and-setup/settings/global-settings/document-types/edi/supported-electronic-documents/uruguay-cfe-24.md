# 🇺🇾 URUGUAY CFE 24

| Propiedad            | Valor                  |
| -------------------- | ---------------------- |
| **País / Región**    | Uruguay                |
| **Tipos de documento** | e-Factura, Nota de crédito |
| **Formato**          | XML                    |
| **Estándar**         | CFE, versión de esquema 24 |

Uruguay CFE 24 hace referencia a la versión 24 del esquema del sistema CFE uruguayo. Esta versión es utilizada por muchos documentos electrónicos existentes e incluye todos los campos necesarios para el cumplimiento de la DGI, incluido el CAE (Código de Autorización Electrónico).

## Estado de soporte

| Componente           | Estado        |
| -------------------- | ------------- |
| Vista previa         | ✅ Compatible |
| Extracción de campos | ✅ Compatible |
| Transformación       | ✅ Compatible |
