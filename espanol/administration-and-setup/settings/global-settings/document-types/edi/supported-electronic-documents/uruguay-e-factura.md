# 🇺🇾 URUGUAY E-FACTURA

<!-- edocs-country-scope -->

{% hint style="info" %}
Consulte la guía del país para conocer los límites de versión, la configuración que se está utilizando y el vídeo explicativo del país. [Uruguay](countries/uruguay.md). Las entradas de notas de crédito carecen de paquetes de extracción dedicados en el estado inspeccionado. Confirme la versión CFE y la asignación de factura o nota de crédito utilizada.
{% endhint %}

| Propiedad            | Valor                    |
| -------------------- | ------------------------ |
| **País / Región**    | Uruguay                  |
| **Tipos de documento** | e-Factura              |
| **Formato**          | XML                      |
| **Estándar**         | e-Factura (CFE tipo 111) |

Uruguay e-Factura es el tipo de documento de factura electrónica dentro del sistema CFE, identificado con el código de tipo 111. Se utiliza en las transacciones B2B formales entre entidades registradas con RUT e incluye todos los campos de identificación fiscal y de cálculo exigidos por la DGI.
