# 🇩🇪 XRECHNUNG 2.2 CII

<!-- edocs-country-scope -->

{% hint style="info" %}
Consulte la guía del país para conocer los límites de versión, la configuración que se está utilizando y el vídeo explicativo del país. [Alemania](countries/germany.md). La sintaxis, la versión de publicación y el perfil son opciones diferentes. No deduzca una publicación de Factur-X a partir del marcador compartido 1p0.
{% endhint %}

| Propiedad            | Valor                                       |
| -------------------- | ------------------------------------------- |
| **País / Región**    | Alemania                                    |
| **Tipos de documento** | Factura, Nota de crédito                  |
| **Formato**          | CII                                         |
| **Estándar**         | XRechnung 2.2                               |
| **Basado en**        | EN 16931 (UN/CEFACT Cross Industry Invoice) |

XRechnung 2.2 implementa el estándar de factura básica EN 16931 con las extensiones alemanas CIUS (Core Invoice Usage Specification). Esta versión introdujo reglas de negocio adicionales y una mayor compatibilidad con escenarios de facturación complejos.
