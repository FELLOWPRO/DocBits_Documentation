# 🇩🇪 XRECHNUNG 3.0.1 UBL

| Propiedad            | Valor                    |
| -------------------- | ------------------------ |
| **País / Región**    | Alemania                 |
| **Tipos de documento** | Factura, Nota de crédito |
| **Formato**          | UBL                      |
| **Estándar**         | XRechnung 3.0.1          |
| **Basado en**        | EN 16931 (OASIS UBL 2.1) |

XRechnung 3.0.1 es la generación actual del estándar alemán de facturación electrónica y se alinea con las últimas actualizaciones de EN 16931. Versión de mantenimiento con correcciones en los artefactos de validación y aclaraciones en la documentación técnica.
