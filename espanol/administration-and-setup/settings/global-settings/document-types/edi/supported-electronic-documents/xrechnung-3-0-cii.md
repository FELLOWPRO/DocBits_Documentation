# 🇩🇪 XRECHNUNG 3.0 CII

| Propiedad            | Valor                                       |
| -------------------- | ------------------------------------------- |
| **País / Región**    | Alemania                                    |
| **Tipos de documento** | Factura, Nota de crédito                  |
| **Formato**          | CII                                         |
| **Estándar**         | XRechnung 3.0                               |
| **Basado en**        | EN 16931 (UN/CEFACT Cross Industry Invoice) |

XRechnung 3.0 es la generación actual del estándar alemán de facturación electrónica y se alinea con las últimas actualizaciones de EN 16931. Versión principal con reglas de validación reestructuradas y mayor compatibilidad con la facturación transfronteriza dentro de la Unión Europea.
