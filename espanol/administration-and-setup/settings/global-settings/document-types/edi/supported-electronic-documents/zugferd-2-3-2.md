# 🇩🇪 ZUGFERD 2.3.2

| Propiedad                | Valor                       |
| ------------------------ | --------------------------- |
| **País / Región**        | Alemania                    |
| **Tipos de documento**   | Factura, Nota de crédito    |
| **Formato**              | CII (incrustado en PDF/A-3) |
| **Estándar**             | ZUGFeRD 2.3.2               |
| **Basado en**            | EN 16931                    |

ZUGFeRD 2.3.2, publicado en noviembre de 2024, equivale a Factur-X 1.0.07.2. Esta versión de mantenimiento incluye correcciones en las reglas Schematron, listas de códigos actualizadas y validaciones de reglas de negocio refinadas.

## Estado de compatibilidad

| Componente                 | Estado        |
| -------------------------- | ------------- |
| Vista previa               | ✅ Compatible |
| Extracción de campos       | ✅ Compatible |
| Transformación             | ✅ Compatible |
