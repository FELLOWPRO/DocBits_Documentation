# Activación y gestión de scripts

## A continuación se presenta una guía sobre cómo activar, desactivar y gestionar los scripts existentes en DocBits para adaptarlos a sus necesidades de procesamiento actuales:

**Inicio de sesión en DocBits:**

* Abra su navegador web e inicie sesión en DocBits con sus credenciales.

<figure><img src="../../../../../.gitbook/assets/image (137).png" alt=""><figcaption></figcaption></figure>

**Navegue a la gestión de scripts:**

* Busque la opción para gestionar scripts en la interfaz de DocBits.
* Esto puede variar según su configuración y la de DocBits.

<figure><img src="../../../../../.gitbook/assets/Bildschirmfoto 2024-05-23 um 16.06.10.png" alt=""><figcaption></figcaption></figure>

**Visualización de los scripts existentes:**

* Una vez que se encuentre en la interfaz de gestión de scripts, verá una lista de todos los scripts existentes.
* Aquí puede desplazarse por la lista para encontrar el script que desea activar, desactivar o editar.

<figure><img src="../../../../../.gitbook/assets/image (138).png" alt=""><figcaption></figcaption></figure>

**Activación o desactivación de un script:**

* Para activar o desactivar un script, localice el script correspondiente en la lista y actívelo o desactívelo.
* Asegúrese de guardar los cambios después de realizar sus selecciones.

<figure><img src="../../../../../.gitbook/assets/Bildschirmfoto 2024-05-23 um 16.16.36.png" alt=""><figcaption></figcaption></figure>

**Edición de un script:**

* Si necesita editar un script existente, busque en la interfaz de gestión de scripts el botón que permite editarlo.

<figure><img src="../../../../../.gitbook/assets/Bildschirmfoto 2024-05-23 um 16.23.19.png" alt="" width="123"><figcaption></figcaption></figure>

* Haga clic en él para abrir el editor, donde puede modificar el código del script.
* Después de realizar sus cambios, vuelva a guardar el script.

<figure><img src="../../../../../.gitbook/assets/image (139).png" alt=""><figcaption></figcaption></figure>

**Revisión y pruebas:**

* Antes de realizar cambios en un script, revise con atención el código existente y considere qué impacto podrían tener sus cambios.
* Pruebe el script en un entorno de pruebas para asegurarse de que funciona como se espera.

<figure><img src="../../../../../.gitbook/assets/image (140).png" alt=""><figcaption></figcaption></figure>

**Documentación:**

* No olvide documentar sus cambios.
* Anote qué cambios realizó y por qué, para que otros usuarios del equipo puedan comprender cómo funciona el script y qué impacto podrían tener sus cambios.

**Publicación de los cambios:**

* Cuando esté satisfecho con sus cambios, vuelva a publicar el script en el entorno de producción de DocBits para que la versión actualizada surta efecto.

Estos pasos le permiten activar, desactivar y gestionar los scripts existentes en DocBits para adaptarlos a las necesidades de procesamiento actuales y garantizar que sus procesos de documentación se ejecuten de forma eficiente y correcta.
