# Plan de suscripción

<figure><img src="../../../../.gitbook/assets/subscriptions_overview.png" alt="Plan de suscripción"><figcaption><p>Página Plan de suscripción</p></figcaption></figure>

La página **Plan de suscripción** ofrece una visión general completa de su suscripción de DocBits en un solo lugar: el plan en sí, las suscripciones de aplicaciones y funciones habilitadas para su organización y el uso de tokens. Ábrala desde **Configuración → Organización y acceso → Plan de suscripción**.

## Plan de suscripción

La primera tarjeta muestra su suscripción de DocBits —los días restantes y las fechas de inicio y fin— junto con recuentos en tiempo real de su organización:

| Tarjeta | Descripción |
|------|-------------|
| **DocBits** | Días restantes y fechas de inicio y fin de su suscripción. |
| **Usuarios** | Número de usuarios de su organización. |
| **Suborganización** | Número de suborganizaciones. |
| **Proveedores** | Número de proveedores. |

## Suscripciones de funciones

<figure><img src="../../../../.gitbook/assets/subscriptions_feature_subscriptions.png" alt="Suscripciones de funciones"><figcaption></figcaption></figure>

Esta sección enumera cada aplicación y función de DocBits e indica si está habilitada para su organización.

| Columna | Descripción |
|--------|-------------|
| **Aplicación** | La aplicación o función de DocBits (p. ej., AI Workforce, Operator, DocFlow, AI Search, BOD Ingestion, SQL BI Connector). |
| **Suscripción** | El plan suscrito para esa aplicación. |
| **Estado** | **Activo**, **Cancelando** (activo hasta la fecha de fin y luego finaliza) o **Ninguno** cuando la aplicación no está suscrita. |
| **Inicio / Fin** | El período de la suscripción. |
| **Días restantes** | Días hasta la fecha de fin. |
| **Acciones** | Menú de acciones por aplicación. |

## Uso de la suscripción

<figure><img src="../../../../.gitbook/assets/subscriptions_usage.png" alt="Uso de la suscripción"><figcaption></figcaption></figure>

Supervise el uso de tokens y de flujos de trabajo durante un período seleccionado. Use el botón **Seleccionar** para elegir el rango de fechas.

| Columna | Descripción |
|--------|-------------|
| **Tipo** | La categoría de uso: Documento, Flujo de trabajo, Flujo de trabajo avanzado o DocNet. |
| **Desde / Hasta** | El período del que se informa el uso. |
| **Tokens usados** | Tokens consumidos en el período. |
| **Tokens restantes** | Tokens disponibles para el período. |
