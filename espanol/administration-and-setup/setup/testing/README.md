# Pruebas

Compruebe que DocBits funciona tal como lo configuró su organización.

* El **[módulo Testing](testing-module/README.md)** (**Configuración → Testing**) ejecuta comprobaciones repetibles en su
  propio navegador, de forma manual, desde un asistente de IA o desde su automatización de pruebas, y conserva un registro de cada ejecución.
* Las guías siguientes describen las comprobaciones manuales de funciones concretas una vez configuradas:
  [Conciliación con órdenes de compra](po-matching.md) y [Contabilidad Automática](auto-accounting/README.md).
