# Búsqueda Rápida Global

La Búsqueda Rápida Global es un lanzador accesible por teclado que encuentra páginas, configuraciones, paneles y funciones dentro de páginas desde cualquier punto de DocBits. Reemplaza el navegar por la barra lateral cuando ya sabe a dónde quiere ir.

## Cómo acceder

Pulse <kbd>Cmd</kbd> + <kbd>K</kbd> en macOS o <kbd>Ctrl</kbd> + <kbd>K</kbd> en Windows y Linux. El atajo funciona desde cualquier pantalla.

## Búsqueda

Empiece a escribir para filtrar el catálogo de páginas y funciones. La Búsqueda Rápida usa coincidencia difusa, por lo que palabras parciales y errores menores aún encuentran la entrada correcta. Se muestran los ocho resultados principales ordenados por relevancia.

Cada resultado muestra:

* El nombre de la función o página.
* La categoría a la que pertenece (Configuración, Panel, Validación y demás).
* Una pequeña insignia que indica el tipo de entrada — Página, Diálogo, Barra lateral, Panel, Menú o Acción.

Use las teclas de flecha arriba y abajo para resaltar un resultado y luego pulse <kbd>Enter</kbd> para abrirlo. Pulse <kbd>Esc</kbd> para cerrar la ventana.

<mark>Solo aparecen en la lista de resultados las entradas para las que tiene permiso. Las entradas reservadas a administradores están ocultas para usuarios sin ese rol.</mark>

## Búsquedas recientes

Cuando el campo de búsqueda está vacío, la Búsqueda Rápida muestra sus cinco consultas más recientes para regresar a destinos habituales con una sola pulsación. Las búsquedas recientes se guardan por navegador y no se sincronizan entre dispositivos.

## Modo selector para documentos

Algunos destinos necesitan información adicional — por ejemplo "Abrir documento por ID" necesita el identificador antes de poder navegar. Al elegir una entrada de este tipo, la Búsqueda Rápida pasa a **modo selector**:

* Para identificadores de documento, escriba o pegue el ID y pulse <kbd>Enter</kbd>.
* Para tipos de documento, elija el tipo en la lista incrustada.

El modo selector respeta los permisos de estado del panel, por lo que solo verá documentos que tiene permitido abrir.

## Ver todos los resultados

Si los ocho resultados visibles no son suficientes, haga clic en el enlace **Ver todos los resultados** del pie para abrir la [Sitemap](sitemap.md) prefiltrada con su búsqueda actual.

## Referencia de teclado

| Tecla | Acción |
|---|---|
| <kbd>Cmd</kbd>/<kbd>Ctrl</kbd> + <kbd>K</kbd> | Abrir la Búsqueda Rápida desde cualquier lugar |
| <kbd>↑</kbd> / <kbd>↓</kbd> | Moverse entre los resultados |
| <kbd>Enter</kbd> | Abrir el resultado resaltado |
| <kbd>Esc</kbd> | Cerrar la ventana |
