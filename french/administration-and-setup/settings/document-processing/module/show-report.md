# Show Report

### Aperçu

Le paramètre **Show Report** ajoute une entrée **Report** au menu de navigation principal. Il donne à votre équipe un accès en un clic à la page de rapports, où vous pouvez consulter les informations sur votre traitement des documents.

Ce paramètre est **désactivé par défaut**.

### Que fait ce paramètre ?

* **Activé** — Un élément **Report** apparaît dans le menu latéral, renvoyant à la page de rapports. Les utilisateurs peuvent l'ouvrir pour consulter le rapport.
* **Désactivé** — L'élément Report est retiré du menu.

### Avantages

* **Aperçu** : Accédez aux rapports sur votre traitement des documents directement depuis le menu.
* **Accès rapide** : Le rapport est à un clic lorsque vous en avez besoin.
* **Interface épurée** : Gardez le menu ciblé en masquant le rapport pour les équipes qui ne l'utilisent pas.

### Utilisation

1. Allez dans **Paramètres**.
2. Sélectionnez **Traitement des documents**.
3. Sélectionnez **Module**.
4. Ouvrez la section **Type de document**.
5. Repérez **Show Report** et activez le commutateur.
6. Une entrée **Report** apparaît alors dans le menu de navigation de l'organisation.

### Quand utiliser cette fonction

* **Suivi et supervision** : Lorsque les responsables ou administrateurs veulent un accès rapide aux rapports.
* **Examens réguliers** : Lorsque le rapport fait partie de la routine de votre équipe.
* **Laissez-le désactivé** si personne n'a besoin du rapport, pour garder la navigation ciblée.
