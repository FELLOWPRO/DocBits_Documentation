# 🇪🇸 FACTURAE 3.2.2

<!-- edocs-country-scope -->

{% hint style="info" %}
Consultez le guide du pays pour connaître les limites de version, la configuration effectivement utilisée et la vidéo explicative du pays. [Espagne](countries/spain.md). Vérifiez l’espace de noms et la version du schéma. L’extraction d’un fichier XML signé ne vérifie pas, à elle seule, sa signature ni son acceptation par FACe.
{% endhint %}

| Propriété              | Valeur                                   |
| ---------------------- | ---------------------------------------- |
| **Pays / Région**      | Espagne                                  |
| **Types de documents** | Facture, Avoir, Facture rectificative    |
| **Format**             | XML                                      |
| **Norme**              | Facturae 3.2.2                           |

Facturae 3.2.2 est la dernière version de la norme espagnole de facturation électronique. Elle inclut un traitement fiscal mis à jour pour la compatibilité avec le SII (Suministro Inmediato de Información) et une meilleure prise en charge des factures rectificatives.
