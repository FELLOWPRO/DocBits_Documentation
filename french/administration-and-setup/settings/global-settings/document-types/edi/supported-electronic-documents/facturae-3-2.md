# 🇪🇸 FACTURAE 3.2

| Propriété              | Valeur                                   |
| ---------------------- | ---------------------------------------- |
| **Pays / Région**      | Espagne                                  |
| **Types de documents** | Facture, Avoir, Facture rectificative    |
| **Format**             | XML                                      |
| **Norme**              | Facturae 3.2                             |

Facturae 3.2 est une version très répandue de la norme espagnole de facturation électronique. Elle définit la structure XML des factures électroniques, y compris l'identification du vendeur et de l'acheteur, les lignes de facture, les détails fiscaux (IVA) et les exigences en matière de signature numérique.
