# 🇪🇸 FACTURAE

<!-- edocs-country-scope -->

{% hint style="info" %}
Consultez le guide du pays pour connaître les limites de version, la configuration effectivement utilisée et la vidéo explicative du pays. [Espagne](countries/spain.md). Vérifiez l’espace de noms et la version du schéma. L’extraction d’un fichier XML signé ne vérifie pas, à elle seule, sa signature ni son acceptation par FACe.
{% endhint %}

| Propriété              | Valeur                                   |
| ---------------------- | ---------------------------------------- |
| **Pays / Région**      | Espagne                                  |
| **Types de documents** | Facture, Avoir, Facture rectificative    |
| **Format**             | XML                                      |
| **Norme**              | Facturae                                 |

Facturae est la norme espagnole de facturation électronique, obligatoire pour les transactions B2G via le portail FACe (Punto General de Entrada de Facturas Electrónicas). DocBits prend en charge les versions 3.2, 3.2.1 et 3.2.2 de la norme.

## Statut de prise en charge

| Composant             | Statut           |
| --------------------- | ---------------- |
| Aperçu                | ✅ Pris en charge |
| Extraction des champs | ✅ Pris en charge |
| Transformation        | ✅ Pris en charge |
