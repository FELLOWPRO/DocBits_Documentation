# 🇫🇷 FACTURX 1.0.05 - ZUGFERD 2.1

<!-- edocs-country-scope -->

{% hint style="info" %}
Consultez le guide du pays pour connaître les limites de version, la configuration effectivement utilisée et la vidéo explicative du pays. [France](countries/france.md). Le marqueur XML 1p0 et Factur-X XMP Version 1.0 n’identifient pas une version de publication. Conservez le libellé générique lorsque la publication est inconnue.
{% endhint %}

| Propriété              | Valeur                        |
| ---------------------- | ----------------------------- |
| **Pays / Région**      | France / Allemagne            |
| **Types de documents** | Facture, Avoir                |
| **Format**             | CII (intégré en PDF/A-3)      |
| **Norme**              | Factur-X 1.0.05 / ZUGFeRD 2.1 |
| **Basée sur**          | EN 16931                      |

Factur-X 1.0.05 est équivalent à ZUGFeRD 2.1. Publiée en 2020, cette version a été la première publication conjointe à établir une interopérabilité complète entre les écosystèmes français et allemand de facturation électronique. Elle prend en charge les profils : Minimum, Basic WL, Basic, EN 16931, Extended.
