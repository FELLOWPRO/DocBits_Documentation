# 🇫🇮 FINVOICE 2.0

<!-- edocs-country-scope -->

{% hint style="info" %}
Consultez le guide du pays pour connaître les limites de version, la configuration effectivement utilisée et la vidéo explicative du pays. [Finlande](countries/finland.md). Vérifiez la version source avant de choisir une correspondance. Le libellé TEAPPSXML ne précise pas de version.
{% endhint %}

| Propriété              | Valeur                    |
| ---------------------- | ------------------------- |
| **Pays / Région**      | Finlande                  |
| **Types de documents** | Facture, Avoir            |
| **Format**             | XML (enveloppe SOAP)      |
| **Norme**              | Finvoice 2.0              |

Finvoice 2.0 a étendu la norme avec une meilleure prise en charge des conditions de paiement, des détails de livraison et de la déclaration de TVA de l'UE. Elle a conservé le modèle de transport basé sur SOAP utilisé par les réseaux bancaires finlandais.
