# 🇸🇬 INVOICENOW SG

| Propriété              | Valeur                                            |
| ---------------------- | ------------------------------------------------- |
| **Pays / Région**      | Singapour                                         |
| **Types de documents** | Facture, Note de crédit                           |
| **Format**             | XML UBL 2.1 (Peppol)                              |
| **Norme**              | InvoiceNow SG (Peppol BIS spécifique à Singapour) |

InvoiceNow SG est la localisation singapourienne de la norme Peppol BIS Billing. Elle étend le modèle Peppol de base avec des règles métier propres à Singapour, la gestion de la GST et des exigences d'identification par UEN (Unique Entity Number).
