# 🇰🇷 KOREA E-TAX INVOICE

| Propriété | Valeur |
| --------- | ------ |
| **Pays / Région** | Corée du Sud |
| **Types de documents** | Facture fiscale |
| **Format** | XML |
| **Norme** | Korean E-Tax Invoice (NTS HomeTax) |

Korea E-Tax Invoice est la norme de facture fiscale électronique exploitée par le National Tax Service (NTS) via le système HomeTax. Les entreprises doivent émettre des factures fiscales électroniques pour les transactions B2B et les transmettre au NTS. Le format comprend le numéro d'enregistrement de l'entreprise, le détail des montants de taxe et le numéro d'approbation du NTS.
