# 🇰🇷 KOREA NTS

<!-- edocs-country-scope -->

{% hint style="info" %}
Consultez le guide du pays pour connaître les limites de version, la configuration effectivement utilisée et la vidéo explicative du pays. [Corée du Sud](countries/korea.md). Les libellés ne précisent pas de version. Faites correspondre la structure XML réelle et ne considérez pas l’extraction comme une preuve d’acceptation par la plateforme fiscale.
{% endhint %}

| Propriété | Valeur |
| --------- | ------ |
| **Pays / Région** | Corée du Sud |
| **Types de documents** | Facture fiscale, Reçu de caisse |
| **Format** | XML |
| **Norme** | NTS (National Tax Service) |

Korea NTS désigne le système plus large de documents électroniques du National Tax Service, qui englobe les factures fiscales, les reçus de caisse et d'autres documents fiscaux. DocBits traite les documents NTS et extrait tous les champs standard, notamment les numéros d'enregistrement des entreprises, les valeurs de fourniture et les montants de taxe.

## Statut de prise en charge

| Composant | Statut |
| --------- | ------ |
| Aperçu | ✅ Pris en charge |
| Extraction des champs | ✅ Pris en charge |
| Transformation | ✅ Pris en charge |
