# 🇵🇱 KSEF FA3

<!-- edocs-country-scope -->

{% hint style="info" %}
Consultez le guide du pays pour connaître les limites de version, la configuration effectivement utilisée et la vidéo explicative du pays. [Pologne](countries/poland.md). FA2 et FA3 utilisent des structures différentes. Confirmez le schéma source et testez la correspondance appropriée ; l’analyse d’une facture ne la soumet pas à KSeF.
{% endhint %}

| Propriété | Valeur |
| --------- | ------ |
| **Pays / Région** | Pologne |
| **Types de documents** | Facture, Facture rectificative |
| **Format** | XML |
| **Norme** | KSeF FA(3) |

KSeF FA3 est la dernière version du schéma du système national polonais de facturation électronique. Elle ajoute la prise en charge de types de documents supplémentaires, une meilleure gestion des factures rectificatives et des règles de validation mises à jour, alignées sur la réglementation polonaise la plus récente en matière de TVA.
