# 🇩🇰 OIOUBL 2.1

| Propriété | Valeur |
| --------- | ------ |
| **Pays / Région** | Danemark |
| **Types de documents** | Facture, Note de crédit, Relance, Relevé |
| **Format** | XML UBL 2.1 |
| **Norme** | OIOUBL 2.1 |

OIOUBL 2.1 est la version actuelle de la norme danoise de facturation électronique. Fondée sur OASIS UBL 2.1, elle étend la norme internationale avec des règles métier et des listes de codes propres au Danemark, exigées par le secteur public danois.
