# 🇪🇺 PEPPOL BIS 3.0

<!-- edocs-country-scope -->

{% hint style="info" %}
Consultez le guide du pays pour connaître les limites de version, la configuration effectivement utilisée et la vidéo explicative du pays. [International](countries/international.md). | Propriété | Valeur |
| --------- | ------ |
| **Pays / Région** | Union européenne / International (plus de 40 pays) |
| **Types de documents** | Facture, Note de crédit |
| **Format** | XML UBL 2.1 |
| **Norme** | Peppol BIS Billing 3.0 |

Peppol BIS Billing 3.0 est la norme paneuropéenne de facturation électronique utilisée sur l'ensemble du réseau Peppol. Elle repose sur OASIS UBL 2.1 et met en œuvre la norme européenne EN 16931 relative à la facturation électronique. Peppol permet l'échange transfrontalier de factures B2B et B2G dans plus de 40 pays via des points d'accès certifiés.
