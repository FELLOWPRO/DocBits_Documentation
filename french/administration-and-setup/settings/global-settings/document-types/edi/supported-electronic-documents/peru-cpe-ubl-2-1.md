# 🇵🇪 PERU CPE UBL 2.1

<!-- edocs-country-scope -->

{% hint style="info" %}
Consultez le guide du pays pour connaître les limites de version, la configuration effectivement utilisée et la vidéo explicative du pays. [Pérou](countries/peru.md). Sélectionnez la version UBL et la structure réelles du document. Le traitement d’un fichier ne prouve pas son acceptation par la SUNAT.
{% endhint %}

| Propriété | Valeur |
| --------- | ------ |
| **Pays / Région** | Pérou |
| **Types de documents** | Facture, Note de crédit, Note de débit |
| **Format** | XML UBL 2.1 |
| **Norme** | CPE UBL 2.1 |

Peru CPE UBL 2.1 est le format actuel des factures électroniques péruviennes soumises à la SUNAT. Il utilise la norme OASIS UBL 2.1 avec des extensions péruviennes pour l'identification RUC, les calculs de taxe IGV (TVA) et les mécanismes de retenue detracción/retención.
