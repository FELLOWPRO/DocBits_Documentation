# 🇹🇼 TAIWAN EGUI

| Propriété              | Valeur                                       |
| ---------------------- | -------------------------------------------- |
| **Pays / Région**      | Taïwan                                       |
| **Types de documents** | Facture (Uniform Invoice), Note de crédit    |
| **Format**             | XML                                          |
| **Norme**              | eGUI (Electronic Government Uniform Invoice) |

Taiwan eGUI est le système de facture électronique uniforme du gouvernement (Electronic Government Uniform Invoice), exploité par le ministère des Finances. Il s'agit d'une norme de facturation électronique obligatoire pour toutes les transactions commerciales à Taïwan ; les factures sont conservées sur la plateforme gouvernementale et identifiées par un format de numéro de facture unique.
