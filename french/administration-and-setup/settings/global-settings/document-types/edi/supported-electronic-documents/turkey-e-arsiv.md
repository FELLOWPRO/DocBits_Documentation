| Propriété              | Valeur                                        |
| ---------------------- | --------------------------------------------- |
| **Pays / Région**      | Turquie                                       |
| **Types de documents** | Facture d'archive                             |
| **Format**             | UBL-TR XML                                    |
| **Norme**              | e-Arşiv Fatura (GİB - Revenue Administration) |

Turkey e-Arşiv (e-Archive) est le format de facture électronique utilisé pour les factures émises à des destinataires qui ne sont pas enregistrés dans le système turc e-Fatura. Les factures e-Arşiv sont conservées sur la plateforme de la GİB (Gelir İdaresi Başkanlığı) et peuvent être remises aux destinataires au format PDF ou sur papier. DocBits traite le format UBL-TR XML.
