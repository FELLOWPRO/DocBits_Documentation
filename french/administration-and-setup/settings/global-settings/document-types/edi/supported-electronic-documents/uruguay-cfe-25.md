# 🇺🇾 URUGUAY CFE 25

| Propriété              | Valeur                      |
| ---------------------- | --------------------------- |
| **Pays / Région**      | Uruguay                     |
| **Types de documents** | e-Facture, Note de crédit   |
| **Format**             | XML                         |
| **Norme**              | CFE Schema Version 25       |

Uruguay CFE 25 est la dernière version du schéma du système uruguayen CFE. Elle comprend des règles de validation et des exigences de champs mises à jour pour les documents électroniques soumis à la DGI.
