# 🇺🇾 URUGUAY CFE

| Propriété              | Valeur                                                   |
| ---------------------- | -------------------------------------------------------- |
| **Pays / Région**      | Uruguay                                                  |
| **Types de documents** | e-Facture, e-Ticket, Note de crédit, Note de débit       |
| **Format**             | XML                                                      |
| **Norme**              | CFE (Comprobante Fiscal Electrónico)                     |

CFE (Comprobante Fiscal Electrónico) est la norme uruguayenne de document fiscal électronique, réglementée par la DGI (Dirección General Impositiva). Elle couvre plusieurs types de documents, dont l'e-Factura (111), l'e-Ticket (101) et leurs variantes de note de crédit et de débit.
