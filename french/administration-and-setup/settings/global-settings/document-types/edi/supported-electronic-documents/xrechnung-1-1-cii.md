# 🇩🇪 XRECHNUNG 1.1 CII

| Propriété              | Valeur                                      |
| ---------------------- | ------------------------------------------- |
| **Pays / Région**      | Allemagne                                   |
| **Types de documents** | Facture, Note de crédit                     |
| **Format**             | CII                                         |
| **Norme**              | XRechnung 1.1                               |
| **Basé sur**           | EN 16931 (UN/CEFACT Cross Industry Invoice) |

Version initiale de la norme XRechnung. Remplacée par des versions plus récentes, mais toujours prise en charge pour le traitement des documents historiques.
