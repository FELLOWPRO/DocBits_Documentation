# 🇩🇪 XRECHNUNG 2.2 CII

| Propriété              | Valeur                                      |
| ---------------------- | ------------------------------------------- |
| **Pays / Région**      | Germany                                     |
| **Types de documents** | Invoice, Credit Note                        |
| **Format**             | CII                                         |
| **Norme**              | XRechnung 2.2                               |
| **Basé sur**           | EN 16931 (UN/CEFACT Cross Industry Invoice) |

XRechnung 2.2 met en œuvre la norme EN 16931 Core Invoice avec les extensions du CIUS (Core Invoice Usage Specification) allemand. Cette version a introduit des règles métier supplémentaires et une prise en charge étendue des scénarios de facturation complexes.
