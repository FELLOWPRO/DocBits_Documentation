# 🇩🇪 XRECHNUNG 2.3 UBL

<!-- edocs-country-scope -->

{% hint style="info" %}
Consultez le guide du pays pour connaître les limites de version, la configuration effectivement utilisée et la vidéo explicative du pays. [Allemagne](countries/germany.md). | Propriété              | Valeur                   |
| ---------------------- | ------------------------ |
| **Pays / Région**      | Germany                  |
| **Types de documents** | Invoice, Credit Note     |
| **Format**             | UBL                      |
| **Norme**              | XRechnung 2.3            |
| **Basé sur**           | EN 16931 (OASIS UBL 2.1) |

XRechnung 2.3 met en œuvre la norme EN 16931 Core Invoice avec les extensions du CIUS (Core Invoice Usage Specification) allemand. Cette version a introduit l'alignement sur Peppol afin d'assurer une intégration fluide avec le réseau Pan-European Public Procurement Online.
