# 🇩🇪 ZUGFERD 1.0 EXTENDED

<!-- edocs-country-scope -->

{% hint style="info" %}
Consultez le guide du pays pour connaître les limites de version, la configuration effectivement utilisée et la vidéo explicative du pays. [Allemagne](countries/germany.md). La syntaxe, la version de publication et le profil sont des choix distincts. Ne déduisez pas une publication Factur-X du marqueur commun 1p0.
{% endhint %}

| Propriété              | Valeur                        |
| ---------------------- | ----------------------------- |
| **Pays / Région**      | Germany                       |
| **Types de documents** | Invoice, Credit Note          |
| **Format**             | CII (PDF/A-3 embedded)        |
| **Norme**              | ZUGFeRD 1.0, Extended profile |
| **Basé sur**           | ZUGFeRD 1.0 specification     |

Le profil Extended de ZUGFeRD 1.0 est le plus complet : il prend en charge des scénarios métier supplémentaires tels que la comptabilité commerciale, l'affacturage et les informations logistiques détaillées. Il inclut tous les champs des profils Basic et Comfort, ainsi que des extensions propres à certains secteurs.
