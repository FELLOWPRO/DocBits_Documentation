# 🇩🇪 ZUGFERD 2.3.2

| Propriété | Valeur |
| -------------------- | ------------------------- |
| **Pays / Région** | Germany |
| **Types de documents** | Invoice, Credit Note |
| **Format** | CII (PDF/A-3 embedded) |
| **Norme** | ZUGFeRD 2.3.2 |
| **Basé sur** | EN 16931 |

ZUGFeRD 2.3.2, publiée en novembre 2024, équivaut à Factur-X 1.0.07.2. Cette version de maintenance comprend des corrections des règles Schematron, des listes de codes mises à jour et des validations de règles métier affinées.
