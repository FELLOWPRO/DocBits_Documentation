# Utiliser l'aperçu du modèle

## L'aperçu du modèle est un outil extrêmement utile pour vérifier et ajuster les paramètres de mise en page en temps réel avant de modifier un document ou un modèle.

### Voici comment utiliser l'aperçu du modèle :

<figure><img src="../../../../../.gitbook/assets/image (152).png" alt=""><figcaption></figcaption></figure>

#### Ouvrir l'aperçu du modèle :

* Vous trouvez généralement l'option d'aperçu du modèle dans l'interface de l'éditeur de modèles.

<figure><img src="../../../../../.gitbook/assets/image (153).png" alt=""><figcaption></figcaption></figure>

#### Sélectionner le modèle :

* Sélectionnez le modèle dont vous souhaitez vérifier la mise en page.
* Il peut s'agir d'un modèle existant que vous voulez modifier ou d'un nouveau modèle que vous souhaitez créer.

<figure><img src="../../../../../.gitbook/assets/Bildschirmfoto 2024-05-24 um 12.31.04.png" alt="" width="186"><figcaption></figcaption></figure>

#### Ajuster les paramètres de mise en page :

* Modifiez les paramètres de mise en page selon vos besoins. Cela peut inclure l'ajout, la suppression ou l'ajustement de groupes, de champs, de colonnes, de lignes, de polices, etc.

<figure><img src="../../../../../.gitbook/assets/image (155).png" alt="" width="271"><figcaption></figcaption></figure>

#### Aperçu en temps réel :

* Lorsque vous modifiez les paramètres de mise en page, l'aperçu se met à jour en temps réel.
* Vous voyez immédiatement l'effet de vos modifications sur l'apparence et la structure du modèle.

#### Personnalisation interactive :

* Profitez de la possibilité de personnaliser la mise en page de manière interactive, en déplaçant, en redimensionnant ou en ajustant les éléments tout en vérifiant les effets en temps réel dans l'aperçu.

#### Tester différentes configurations :

* Expérimentez différentes configurations de mise en page pour trouver la meilleure conception pour vos besoins.
* Utilisez l'aperçu du modèle pour voir comment chaque modification affecte le rendu final.

#### Enregistrer et valider les modifications :

* Une fois que la mise en page vous convient, enregistrez vos modifications.
* Selon le logiciel, vous pouvez également trouver l'option permettant de valider vos modifications directement afin de mettre à jour le modèle pour l'utiliser dans d'autres documents ou processus.

L'aperçu du modèle vous permet de vous assurer que votre mise en page répond aux besoins souhaités avant de valider les modifications. Vous pouvez ainsi personnaliser efficacement la conception et la structure de vos documents et vous assurer qu'ils respectent les normes visuelles et fonctionnelles souhaitées.
