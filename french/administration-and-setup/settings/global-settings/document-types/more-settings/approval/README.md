# Approbation

Utilisez les options d'approbation pour décider comment un document est vérifié avant de quitter DocBits. Les options se configurent pour chaque type de document, commencez donc par le type utilisé par votre équipe, par exemple **Facture**.

1. Ouvrez **Paramètres** → **Types de documents**.
2. Sélectionnez le type de document et ouvrez **Plus de paramètres**.
3. Faites défiler jusqu'à **Approbation et rejet**. Passez en revue les quatre interrupteurs avant d'en modifier un.

<figure><img src="../../../../../../.gitbook/assets/dbdc224-approval-options-fr-20261009.png" alt="Options d'Approbation et rejet en français dans le type de document Facture de la Sandbox"><figcaption>Vue actuelle de la Sandbox en français pour Facture dans la documentation DocBits. Les quatre interrupteurs sont désactivés dans cet exemple.</figcaption></figure>

| Option | À quoi elle sert |
| --- | --- |
| **Approuver avant l'exportation** | Exiger une décision d'approbation avant d'exporter le document. |
| **Deuxième approbation avant l'exportation** | Ajouter une autre étape d'approbation lorsqu'une seule décision ne suffit pas pour votre processus. |
| **Cachet d'approbation** | Ajouter une marque d'approbation à un document approuvé. Voir [Cachet d'approbation](approval-stamp.md) pour la configuration et les options de téléchargement. |
| **Historique de l'approbation** | Conserver un enregistrement des décisions d'approbation. Voir [Historique de l'approbation](approval-history.md) pour le paramètre et la consultation de l'historique. |

Choisissez les options requises par votre propre processus. Utilisez ensuite un document de test sans client réel et les rôles de réviseur prévus pour vérifier le circuit d'approbation avant de l'appliquer à des documents réels. La capture montre les paramètres disponibles ; aucun flux d'approbation ni exportation n'a été effectué lors de ce contrôle de la documentation.
