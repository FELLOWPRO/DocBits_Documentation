# Activation et gestion des scripts

## Voici un guide expliquant comment activer, désactiver et gérer les scripts existants dans DocBits afin de les adapter à vos besoins de traitement actuels :

**Connexion à DocBits :**

* Ouvrez votre navigateur web et connectez-vous à DocBits avec vos identifiants.

<figure><img src="../../../../../.gitbook/assets/image (137).png" alt=""><figcaption></figcaption></figure>

**Accéder à la gestion des scripts :**

* Recherchez l'option de gestion des scripts dans l'interface de DocBits.
* Elle peut varier selon votre configuration de DocBits.

<figure><img src="../../../../../.gitbook/assets/Bildschirmfoto 2024-05-23 um 16.06.10.png" alt=""><figcaption></figcaption></figure>

**Afficher les scripts existants :**

* Une fois dans l'interface de gestion des scripts, vous voyez la liste de tous les scripts existants.
* Vous pouvez y parcourir la liste pour trouver le script que vous souhaitez activer, désactiver ou modifier.

<figure><img src="../../../../../.gitbook/assets/image (138).png" alt=""><figcaption></figcaption></figure>

**Activer ou désactiver un script :**

* Pour activer ou désactiver un script, repérez le script concerné dans la liste puis activez-le ou désactivez-le.
* Pensez à enregistrer les modifications après avoir effectué vos sélections.

<figure><img src="../../../../../.gitbook/assets/Bildschirmfoto 2024-05-23 um 16.16.36.png" alt=""><figcaption></figcaption></figure>

**Modifier un script :**

* Si vous devez modifier un script existant, recherchez dans l'interface de gestion des scripts le bouton permettant de le modifier.

<figure><img src="../../../../../.gitbook/assets/Bildschirmfoto 2024-05-23 um 16.23.19.png" alt="" width="123"><figcaption></figcaption></figure>

* Cliquez dessus pour ouvrir l'éditeur dans lequel vous pouvez modifier le code du script.
* Une fois vos modifications effectuées, enregistrez à nouveau le script.

<figure><img src="../../../../../.gitbook/assets/image (139).png" alt=""><figcaption></figcaption></figure>

**Vérifier et tester :**

* Avant de modifier un script, examinez attentivement le code existant et réfléchissez à l'impact que vos modifications pourraient avoir.
* Testez le script dans un environnement de test pour vous assurer qu'il fonctionne comme prévu.

<figure><img src="../../../../../.gitbook/assets/image (140).png" alt=""><figcaption></figcaption></figure>

**Documentation :**

* N'oubliez pas de documenter vos modifications.
* Notez les modifications effectuées et leurs raisons afin que les autres membres de l'équipe puissent comprendre le fonctionnement du script et l'impact possible de vos changements.

**Publier les modifications :**

* Lorsque vous êtes satisfait de vos modifications, publiez à nouveau le script dans l'environnement de production de DocBits pour que la version mise à jour prenne effet.

Ces étapes vous permettent d'activer, de désactiver et de gérer les scripts existants dans DocBits afin de les adapter aux besoins de traitement actuels et de garantir que vos processus de documentation s'exécutent de manière efficace et correcte.
