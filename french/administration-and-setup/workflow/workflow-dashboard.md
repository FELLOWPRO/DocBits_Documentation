# Dashboard

Le **Workflow Dashboard** est la page d'accueil de la zone des workflows. Il montre les performances de vos workflows — totaux d'exécutions, taux de réussite et d'échec, graphique des exécutions dans le temps et activité récente — et vous donne accès à la liste des workflows, au Test Manager et au Card SDK.

## Onglets

* **Dashboard** — indicateurs d'exécution et activité récente (affichés ci-dessus).
* **Workflow List** — chaque workflow avec son type, son ordre d'exécution et son déclencheur. Créez-en un nouveau avec **New Workflow**.
* **Test Manager List** — scénarios de test qui valident vos workflows ; exécutez-les avec **Run All Tests**.
* **License** — informations sur la licence des workflows.
* **Card SDK** — créez et téléversez des cartes de workflow personnalisées (voir [Card SDK](card-sdk.md)).

La barre d'outils propose également **Templates**, qui ouvre la bibliothèque [Workflow Templates](standard-workflow-builder/#workflow-templates), et **Import Workflow**, qui importe un workflow à partir d'un fichier JSON.

Le **Test Manager** vous permet d'enregistrer des scénarios de test par workflow et de les exécuter ensemble, afin de confirmer que vos workflows se comportent toujours correctement après des modifications :

<figure><img src="../../.gitbook/assets/workflow_test_manager.png" alt="Test Manager List des workflows avec les scénarios de test et Run All Tests"><figcaption><p>La Test Manager List — chaque scénario affiche un résultat réussite/échec ; utilisez <strong>Run All Tests</strong> pour les réexécuter tous.</p></figcaption></figure>
