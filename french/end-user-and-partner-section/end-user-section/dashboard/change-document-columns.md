# Modifier les colonnes de document

1. Sélectionnez l’engrenage **Paramètres avancés** à droite de la barre de recherche du tableau de bord.
2. Sélectionnez le bouton **Paramètres de colonnes** dans le menu.
3. Recherchez dans les listes masquées ou visibles. Sélectionnez les colonnes et déplacez-les avec les flèches.
4. Faites glisser les poignées des colonnes visibles pour les ordonner.
5. Ajoutez éventuellement des champs d’un type de document en choisissant le type et les champs utiles.
6. Cliquez sur **Terminé** pour appliquer la configuration.

Dans votre propre tableau de bord enregistré, enregistrez aussi les changements avant de demander un export. Les colonnes exportées proviennent de la vue enregistrée. Fermez ou annulez la boîte de dialogue pour quitter sans appliquer les modifications. Les colonnes disponibles dépendent du type de document et de la configuration de l’organisation.
