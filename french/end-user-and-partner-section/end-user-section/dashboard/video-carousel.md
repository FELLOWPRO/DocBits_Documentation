# Carrousel Vidéo

Une petite zone du Tableau de Bord de Préparation qui diffuse de courtes astuces sur les fonctionnalités de DocBits — des choses utiles à essayer, des endroits où vous n'avez peut-être pas regardé.

## Où le trouver

Le Carrousel Vidéo apparaît sur le Tableau de Bord de Préparation pendant l'import des documents. Sur les écrans larges, il se place à droite de la barre de progression. Il est masqué sur les petits écrans.

## Utilisation

Les astuces se jouent les unes après les autres avec une courte légende en dessous. Cliquez sur les points sous la vidéo pour aller à une astuce précise. Il n'y a pas de son — lisez la légende pour savoir de quoi parle chaque astuce.
