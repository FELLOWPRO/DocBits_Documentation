# Stream pour les clients cloud

#### Pour activer les paramètres Stream dans DocBits <a href="#to-enable-stream-settings-in-docbits" id="to-enable-stream-settings-in-docbits"></a>

Accédez à _Settings → Module → BOD Connection Stream_

<figure><img src="../../.gitbook/assets/image (223).png" alt=""><figcaption></figcaption></figure>

L'activation de cette option génère automatiquement un nom de Stream. Rendez-vous ensuite dans Infor _→ OS  → ION  → Data Flows._ Vous devez y configurer un nouveau flux de données (data flow). Il devrait ressembler à ceci :
