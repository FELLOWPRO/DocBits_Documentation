# Panoramica degli standard di fatturazione elettronica

Utilizzare [Formati eDocs, versioni e guide per paese](../supported-electronic-documents/README.md) come panoramica centrale per paese.

Comprende famiglie di formati, sintassi XML, versioni di pubblicazione, profili aziendali e i componenti esaminati di classificazione, Transformation, Preview ed Extraction Paths. Aprire la guida di un paese per consultare le etichette esatte e le schermate e i video disponibili.

Le voci del catalogo descrivono la configurazione disponibile. Controllare le regole effettive della propria organizzazione e provare file di origine rappresentativi prima di fare affidamento su un formato. Elaborazione dei file, validazione legale e trasmissione di rete richiedono verifiche separate.
