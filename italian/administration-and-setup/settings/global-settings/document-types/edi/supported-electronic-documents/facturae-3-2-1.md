# 🇪🇸 FACTURAE 3.2.1

| Proprietà             | Valore                                   |
| --------------------- | ---------------------------------------- |
| **Paese / Regione**   | Spagna                                   |
| **Tipi di documento** | Fattura, nota di credito, fattura rettificativa |
| **Formato**           | XML                                      |
| **Standard**          | Facturae 3.2.1                           |

Facturae 3.2.1 è un aggiornamento di manutenzione che ha introdotto correzioni allo schema XML, regole di convalida migliorate e il supporto per ulteriori categorie fiscali richieste dalla normativa fiscale spagnola.

## Stato del supporto

| Componente           | Stato         |
| -------------------- | ------------- |
| Anteprima            | ✅ Supportato |
| Estrazione dei campi | ✅ Supportato |
| Trasformazione       | ✅ Supportato |
