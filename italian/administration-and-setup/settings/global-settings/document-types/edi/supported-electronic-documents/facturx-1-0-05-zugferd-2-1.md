# 🇫🇷 FACTURX 1.0.05 - ZUGFERD 2.1

| Proprietà             | Valore                        |
| --------------------- | ----------------------------- |
| **Paese / Regione**   | Francia / Germania            |
| **Tipi di documento** | Fattura, nota di credito      |
| **Formato**           | CII (incorporato in PDF/A-3)  |
| **Standard**          | Factur-X 1.0.05 / ZUGFeRD 2.1 |
| **Basato su**         | EN 16931                      |

Factur-X 1.0.05 equivale a ZUGFeRD 2.1. Pubblicata nel 2020, è stata la prima versione pubblicata congiuntamente a stabilire la piena interoperabilità tra gli ecosistemi di fatturazione elettronica francese e tedesco. Supporta i profili: Minimum, Basic WL, Basic, EN 16931, Extended.

| Estrazione dei campi | ✅ Supportato |
