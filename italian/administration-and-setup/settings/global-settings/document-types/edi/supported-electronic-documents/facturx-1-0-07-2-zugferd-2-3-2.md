# 🇫🇷 FACTURX 1.0.07.2 - ZUGFERD 2.3.2

| Proprietà             | Valore                            |
| --------------------- | --------------------------------- |
| **Paese / Regione**   | Francia / Germania                |
| **Tipi di documento** | Fattura, nota di credito          |
| **Formato**           | CII (incorporato in PDF/A-3)      |
| **Standard**          | Factur-X 1.0.07.2 / ZUGFeRD 2.3.2 |
| **Basato su**         | EN 16931                          |

Factur-X 1.0.07.2 equivale a ZUGFeRD 2.3.2, pubblicata a novembre 2024. Questa versione include correzioni e aggiornamenti alle regole di business, una convalida Schematron migliorata e l'allineamento con l'ultima specifica CII D22B.
