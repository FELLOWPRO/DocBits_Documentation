# 🇩🇰 OIOUBL 2.1

| Proprietà             | Valore                                    |
| --------------------- | ----------------------------------------- |
| **Paese / Regione**   | Danimarca                                 |
| **Tipi di documento** | Invoice, Credit Note, Reminder, Statement |
| **Formato**           | UBL 2.1 XML                               |
| **Standard**          | OIOUBL 2.1                                |

OIOUBL 2.1 è la versione attuale dello standard danese per la fatturazione elettronica. Basato su OASIS UBL 2.1, estende lo standard internazionale con regole di business specifiche per la Danimarca e le liste di codici richieste dal settore pubblico danese.

## Stato del supporto

| Componente         | Stato       |
| ------------------ | ----------- |
| Anteprima          | ✅ Supported |
| Estrazione campi   | ✅ Supported |
| Trasformazione     | ✅ Supported |
