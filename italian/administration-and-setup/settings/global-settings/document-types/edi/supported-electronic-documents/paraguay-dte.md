# 🇵🇾 PARAGUAY DTE

| Proprietà             | Valore                                 |
| --------------------- | -------------------------------------- |
| **Paese / Regione**   | Paraguay                               |
| **Tipi di documento** | Invoice, Credit Note                   |
| **Formato**           | XML                                    |
| **Standard**          | DTE (Documento Tributario Electrónico) |

Paraguay DTE è lo standard paraguaiano di documento fiscale elettronico, regolamentato dalla Subsecretaría de Estado de Tributación (SET). Copre le fatture elettroniche e le note di credito con i requisiti paraguaiani di identificazione fiscale (RUC) e di categoria fiscale.

## Stato del supporto

| Componente         | Stato       |
| ------------------ | ----------- |
| Anteprima          | ✅ Supported |
| Estrazione campi   | ✅ Supported |
| Trasformazione     | ✅ Supported |
