# 🇳🇱 SI-UBL 2.0

| Proprietà             | Valore                               |
| --------------------- | ------------------------------------ |
| **Paese / Regione**   | Paesi Bassi                          |
| **Tipi di documento** | Fattura, Nota di credito             |
| **Formato**           | UBL 2.1 XML                          |
| **Standard**          | SI-UBL 2.0 (Standaard Invoice - UBL) |

SI-UBL 2.0 è lo standard olandese di fatturazione elettronica basato su OASIS UBL 2.1. È gestito da NLCIUS (Netherlands Core Invoice Usage Specification) ed è allineato alla norma EN 16931. SI-UBL è ampiamente utilizzato nelle transazioni B2G e B2B olandesi, in particolare tramite la rete Peppol.
