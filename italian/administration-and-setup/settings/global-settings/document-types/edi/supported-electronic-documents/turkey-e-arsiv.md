# 🇹🇷 TURKEY E-ARSIV

<!-- edocs-country-scope -->

{% hint style="info" %}
Consultate la guida del paese per i limiti delle versioni, la configurazione effettivamente utilizzata e il video esplicativo del paese. [Turchia](countries/turkey.md). Verificate il profilo sorgente e la struttura del documento. L’etichetta della famiglia non identifica ogni versione UBL-TR né dimostra la consegna tramite la piattaforma fiscale.
{% endhint %}

| Proprietà             | Valore                                        |
| --------------------- | --------------------------------------------- |
| **Paese / Regione**   | Turchia                                       |
| **Tipi di documento** | Fattura di archivio                           |
| **Formato**           | UBL-TR XML                                    |
| **Standard**          | e-Arşiv Fatura (GİB - Revenue Administration) |

Turkey e-Arşiv (e-Archive) è il formato di fattura elettronica utilizzato per le fatture emesse a destinatari non registrati nel sistema turco e-Fatura. Le fatture e-Arşiv sono archiviate sulla piattaforma GİB (Gelir İdaresi Başkanlığı) e possono essere consegnate ai destinatari in formato PDF o cartaceo. DocBits elabora il formato UBL-TR XML.
