# UBL 2.1

| Proprietà             | Valore                                       |
| --------------------- | -------------------------------------------- |
| **Paese / Regione**   | Internazionale                               |
| **Tipi di documento** | Fattura, Nota di credito, Ordine, Avviso di spedizione |
| **Formato**           | UBL 2.1 XML                                  |
| **Standard**          | OASIS UBL 2.1 (Universal Business Language)  |

UBL 2.1 (Universal Business Language) è lo standard aperto OASIS per i documenti commerciali. Costituisce la base di molti standard nazionali di fatturazione elettronica, tra cui Peppol BIS, XRechnung (variante UBL), OIOUBL e SI-UBL. DocBits elabora le fatture UBL 2.1 generiche che non corrispondono a nessuno standard specifico di un paese.
