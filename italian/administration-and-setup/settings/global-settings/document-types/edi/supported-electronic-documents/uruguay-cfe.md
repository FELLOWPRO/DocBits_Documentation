# 🇺🇾 URUGUAY CFE

| Proprietà             | Valore                                                 |
| --------------------- | ------------------------------------------------------ |
| **Paese / Regione**   | Uruguay                                                |
| **Tipi di documento** | e-Fattura, e-Ticket, Nota di credito, Nota di debito   |
| **Formato**           | XML                                                    |
| **Standard**          | CFE (Comprobante Fiscal Electrónico)                   |

CFE (Comprobante Fiscal Electrónico) è lo standard uruguaiano del documento fiscale elettronico regolamentato dalla DGI (Dirección General Impositiva). Copre diversi tipi di documento, tra cui e-Factura (111), e-Ticket (101) e le relative varianti di nota di credito/debito.
