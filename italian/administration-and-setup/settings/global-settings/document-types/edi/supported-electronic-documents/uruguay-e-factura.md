# 🇺🇾 URUGUAY E-FACTURA

<!-- edocs-country-scope -->

{% hint style="info" %}
Consultate la guida del paese per i limiti delle versioni, la configurazione effettivamente utilizzata e il video esplicativo del paese. [Uruguay](countries/uruguay.md). Le voci per le note di credito non hanno insiemi di componenti di estrazione dedicati nello stato esaminato. Confermate la versione CFE e la mappatura effettivamente utilizzata per fatture o note di credito.
{% endhint %}

| Proprietà             | Valore                   |
| --------------------- | ------------------------ |
| **Paese / Regione**   | Uruguay                  |
| **Tipi di documento** | e-Fattura (e-Factura)    |
| **Formato**           | XML                      |
| **Standard**          | e-Factura (CFE Type 111) |

Uruguay e-Factura è il tipo di documento fattura elettronica all'interno del sistema CFE, identificato dal codice di tipo 111. Viene utilizzata per le transazioni B2B formali tra entità registrate con RUT e include tutti i campi di identificazione fiscale e di calcolo richiesti dalla DGI.
