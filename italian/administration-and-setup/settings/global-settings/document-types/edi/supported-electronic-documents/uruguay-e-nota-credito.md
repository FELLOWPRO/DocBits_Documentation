# 🇺🇾 URUGUAY E-NOTA CREDITO

<!-- edocs-country-scope -->

{% hint style="info" %}
Consultate la guida del paese per i limiti delle versioni, la configurazione effettivamente utilizzata e il video esplicativo del paese. [Uruguay](countries/uruguay.md). Le voci per le note di credito non hanno insiemi di componenti di estrazione dedicati nello stato esaminato. Confermate la versione CFE e la mappatura effettivamente utilizzata per fatture o note di credito.
{% endhint %}

| Proprietà             | Valore                           |
| --------------------- | -------------------------------- |
| **Paese / Regione**   | Uruguay                          |
| **Tipi di documento** | Nota di credito (e-Nota de Crédito) |
| **Formato**           | XML                              |
| **Standard**          | e-Nota de Crédito (CFE Type 112) |

Uruguay e-Nota de Crédito è il tipo di documento nota di credito elettronica all'interno del sistema CFE, identificato dal codice di tipo 112. Viene utilizzata per rettificare o annullare e-Factura emesse in precedenza e deve fare riferimento al documento originale.
