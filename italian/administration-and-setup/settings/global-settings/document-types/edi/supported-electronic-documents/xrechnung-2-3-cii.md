# 🇩🇪 XRECHNUNG 2.3 CII

| Proprietà             | Valore                                      |
| --------------------- | ------------------------------------------- |
| **Paese / Regione**   | Germania                                    |
| **Tipi di documento** | Fattura, Nota di credito                    |
| **Formato**           | CII                                         |
| **Standard**          | XRechnung 2.3                               |
| **Basato su**         | EN 16931 (UN/CEFACT Cross Industry Invoice) |

XRechnung 2.3 implementa lo standard EN 16931 Core Invoice con le estensioni tedesche CIUS (Core Invoice Usage Specification). Questa versione ha introdotto l'allineamento a Peppol per garantire un'integrazione senza interruzioni con la rete Pan-European Public Procurement Online.
