# 🇩🇪 XRECHNUNG 3.0.1 CII

| Proprietà             | Valore                                      |
| --------------------- | ------------------------------------------- |
| **Paese / Regione**   | Germania                                    |
| **Tipi di documento** | Fattura, Nota di credito                    |
| **Formato**           | CII                                         |
| **Standard**          | XRechnung 3.0.1                             |
| **Basato su**         | EN 16931 (UN/CEFACT Cross Industry Invoice) |

XRechnung 3.0.1 è l'attuale generazione dello standard tedesco di fatturazione elettronica, allineata agli ultimi aggiornamenti della EN 16931. Release di manutenzione con correzioni agli artefatti di validazione e chiarimenti alla documentazione tecnica.
