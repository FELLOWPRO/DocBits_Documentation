# Test

Verificare che DocBits funzioni come configurato dalla propria organizzazione.

* Il **[modulo Testing](testing-module/README.md)** (**Impostazioni → Testing**) esegue verifiche ripetibili nel proprio
  browser, manualmente, da un assistente AI o dalla propria automazione dei test, e registra ogni esecuzione in un log.
* Le guide seguenti descrivono le verifiche manuali di singole funzionalità dopo la loro configurazione:
  [Abbinamento degli ordini di acquisto](po-matching.md) e [Contabilità Automatica](auto-accounting/README.md).
