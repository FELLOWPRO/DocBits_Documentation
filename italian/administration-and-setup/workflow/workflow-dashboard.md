# Dashboard

La **Workflow Dashboard** è la home dell'area workflow. Mostra come stanno andando i tuoi workflow — totali delle esecuzioni, tassi di successo e di fallimento, un grafico delle esecuzioni nel tempo e l'attività recente — e ti dà accesso all'elenco dei workflow, al test manager e al Card SDK.

<figure><img src="../../.gitbook/assets/workflow_dashboard.png" alt="Workflow Dashboard con totali delle esecuzioni, tassi di successo e fallimento, il grafico delle esecuzioni e l&#x27;attività recente"><figcaption><p>La Workflow Dashboard — totali delle esecuzioni, tassi di successo/fallimento e attività recente per ogni workflow.</p></figcaption></figure>

## Schede

* **Dashboard** — metriche delle esecuzioni e attività recente (mostrate sopra).
* **Workflow List** — ogni workflow con il suo tipo, l'ordine di esecuzione e il trigger. Creane uno nuovo con **New Workflow**.
* **Test Manager List** — scenari di test che validano i tuoi workflow; eseguili con **Run All Tests**.
* **License** — informazioni sulla licenza dei workflow.
* **Card SDK** — crea e carica schede workflow personalizzate (vedi [Card SDK](card-sdk.md)).

La barra degli strumenti offre anche **Templates**, che apre la libreria [Workflow Templates](standard-workflow-builder/#workflow-templates), e **Import Workflow**, che importa un workflow da un file JSON.

Il **Test Manager** ti permette di salvare scenari di test per ogni workflow e di eseguirli insieme, così puoi verificare che i tuoi workflow si comportino ancora correttamente dopo le modifiche:

<figure><img src="../../.gitbook/assets/workflow_test_manager.png" alt="Workflow Test Manager List con scenari di test e Run All Tests"><figcaption><p>La Test Manager List — ogni scenario mostra un risultato superato/fallito; usa <strong>Run All Tests</strong> per rieseguirli tutti.</p></figcaption></figure>
