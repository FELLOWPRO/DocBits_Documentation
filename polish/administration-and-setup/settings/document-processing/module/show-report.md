# Show Report

### Przegląd

Ustawienie **Show Report** dodaje pozycję **Report** do głównego menu nawigacji. Daje Twojemu zespołowi dostęp jednym kliknięciem do strony raportów, na której możesz przeglądać raportowanie dotyczące przetwarzania dokumentów.

To ustawienie jest **domyślnie wyłączone**.

### Co robi to ustawienie?

* **Włączone** — W menu bocznym pojawia się pozycja **Report** prowadząca do strony raportów. Użytkownicy mogą ją otworzyć, aby wyświetlić raport.
* **Wyłączone** — Pozycja Report jest usuwana z menu.

### Korzyści

* **Wgląd**: Docieraj do raportów dotyczących przetwarzania dokumentów bezpośrednio z menu.
* **Szybki dostęp**: Raport jest o jedno kliknięcie, gdy go potrzebujesz.
* **Uporządkowany interfejs**: Utrzymaj przejrzyste menu, ukrywając raport przed zespołami, które z niego nie korzystają.

### Jak używać

1. Przejdź do **Ustawienia**.
2. Wybierz **Przetwarzanie dokumentów**.
3. Wybierz **Moduł**.
4. Otwórz sekcję **Typ dokumentu**.
5. Znajdź **Show Report** i włącz przełącznik.
6. W menu nawigacji organizacji pojawia się wtedy pozycja **Report**.

### Kiedy używać tej funkcji

* **Monitorowanie i nadzór**: Gdy przełożeni lub administratorzy chcą szybkiego dostępu do raportów.
* **Regularne przeglądy**: Gdy raport jest częścią rutyny Twojego zespołu.
* **Pozostaw wyłączone**, jeśli nikt nie potrzebuje raportu, aby zachować przejrzystość nawigacji.
