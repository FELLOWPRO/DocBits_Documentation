# 🇳🇴 EHF INVOICE 3.0

<!-- edocs-country-scope -->

{% hint style="info" %}
Sprawdź w przewodniku krajowym ograniczenia wersji, faktycznie używaną konfigurację i film objaśniający dla kraju. [Norwegia](countries/norway.md). Wybierz mapowanie dla rzeczywistego dokumentu biznesowego. Zamówienie ani awizo wysyłki nie są fakturą.
{% endhint %}

| Właściwość           | Wartość                                           |
| -------------------- | ------------------------------------------------- |
| **Kraj / Region**    | Norwegia                                          |
| **Typy dokumentów**  | Faktura, nota kredytowa                           |
| **Format**           | UBL 2.1 XML                                       |
| **Standard**         | EHF Invoice 3.0 (oparty na Peppol BIS Billing 3.0) |

EHF (Elektronisk Handelsformat) Invoice 3.0 to norweski standard e-fakturowania, utrzymywany przez Agencję ds. Zarządzania Publicznego i e-Administracji (Difi). Wersja 3.0 jest zgodna z Peppol BIS Billing 3.0, dzięki czemu norweskie e-faktury są interoperacyjne w europejskiej sieci Peppol.
