# 🇪🇸 FACTURAE

<!-- edocs-country-scope -->

{% hint style="info" %}
Sprawdź w przewodniku krajowym ograniczenia wersji, faktycznie używaną konfigurację i film objaśniający dla kraju. [Hiszpania](countries/spain.md). Sprawdź przestrzeń nazw i wersję schematu. Wyodrębnienie danych z podpisanego pliku XML samo w sobie nie weryfikuje podpisu ani akceptacji przez FACe.
{% endhint %}

| Właściwość           | Wartość                                  |
| -------------------- | ---------------------------------------- |
| **Kraj / Region**    | Hiszpania                                |
| **Typy dokumentów**  | Faktura, nota kredytowa, faktura korygująca |
| **Format**           | XML                                      |
| **Standard**         | Facturae                                 |

Facturae to hiszpański standard fakturowania elektronicznego, obowiązkowy w transakcjach B2G za pośrednictwem portalu FACe (Punto General de Entrada de Facturas Electrónicas). DocBits obsługuje wersje 3.2, 3.2.1 i 3.2.2 standardu.
