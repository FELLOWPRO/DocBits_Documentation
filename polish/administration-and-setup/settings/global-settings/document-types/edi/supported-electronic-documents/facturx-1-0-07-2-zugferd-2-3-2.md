# 🇫🇷 FACTURX 1.0.07.2 - ZUGFERD 2.3.2

| Właściwość           | Wartość                           |
| -------------------- | --------------------------------- |
| **Kraj / Region**    | Francja / Niemcy                  |
| **Typy dokumentów**  | Faktura, nota kredytowa           |
| **Format**           | CII (osadzony w PDF/A-3)          |
| **Standard**         | Factur-X 1.0.07.2 / ZUGFeRD 2.3.2 |
| **Oparty na**        | EN 16931                          |

Factur-X 1.0.07.2 jest odpowiednikiem ZUGFeRD 2.3.2, wydanego w listopadzie 2024 roku. Ta wersja zawiera poprawki i aktualizacje reguł biznesowych, ulepszoną walidację Schematron oraz dostosowanie do najnowszej specyfikacji CII D22B.
