# 🇫🇮 FINVOICE 1.3

<!-- edocs-country-scope -->

{% hint style="info" %}
Sprawdź w przewodniku krajowym ograniczenia wersji, faktycznie używaną konfigurację i film objaśniający dla kraju. [Finlandia](countries/finland.md). Sprawdź wersję źródłową przed wybraniem mapowania. Oznaczenie TEAPPSXML nie podaje wydania.

| Właściwość           | Wartość                  |
| -------------------- | ------------------------ |
| **Kraj / Region**    | Finlandia                |
| **Typy dokumentów**  | Faktura                  |
| **Format**           | XML (koperta SOAP)       |
| **Standard**         | Finvoice 1.3             |

Finvoice 1.3 to wcześniejsza wersja fińskiego standardu e-fakturowania, utrzymywanego przez Finance Finland. Używa koperty wiadomości SOAP i definiuje ustrukturyzowany format XML dla fakturowania B2B między fińskimi bankami a ich klientami korporacyjnymi.
