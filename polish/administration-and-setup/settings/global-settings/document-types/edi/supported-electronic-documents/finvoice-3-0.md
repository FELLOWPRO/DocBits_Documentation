# 🇫🇮 FINVOICE 3.0

<!-- edocs-country-scope -->

{% hint style="info" %}
Sprawdź w przewodniku krajowym ograniczenia wersji, faktycznie używaną konfigurację i film objaśniający dla kraju. [Finlandia](countries/finland.md). Sprawdź wersję źródłową przed wybraniem mapowania. Oznaczenie TEAPPSXML nie podaje wydania.
{% endhint %}

| Właściwość           | Wartość                       |
| -------------------- | ----------------------------- |
| **Kraj / Region**    | Finlandia                     |
| **Typy dokumentów**  | Faktura, Nota kredytowa       |
| **Format**           | XML                           |
| **Standard**         | Finvoice 3.0                  |

Finvoice 3.0 to aktualna wersja fińskiego standardu e-fakturowania. Wprowadza zgodność z normą europejską EN 16931, zachowując wsteczną kompatybilność z fińską infrastrukturą bankową. Obsługuje zarówno fakturowanie krajowe, jak i transgraniczne.
