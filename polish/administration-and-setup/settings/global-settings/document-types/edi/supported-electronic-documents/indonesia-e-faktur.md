# 🇮🇩 INDONESIA E-FAKTUR

<!-- edocs-country-scope -->

{% hint style="info" %}
Sprawdź w przewodniku krajowym ograniczenia wersji, faktycznie używaną konfigurację i film objaśniający dla kraju. [Indonezja](countries/indonesia.md). Wpis nie podaje numeru wydania. Potwierdź rzeczywistą zawartość XML; drukowana faktura ani obraz kodu QR nie potwierdzają obsługi XML.
{% endhint %}

| Właściwość           | Wartość                                    |
| -------------------- | ------------------------------------------ |
| **Kraj / Region**    | Indonezja                                  |
| **Typy dokumentów**  | Faktura podatkowa (Faktur Pajak)           |
| **Format**           | XML/CSV                                    |
| **Standard**         | e-Faktur (DJP - Direktorat Jenderal Pajak) |

e-Faktur to indonezyjski system elektronicznych faktur podatkowych prowadzony przez Dyrekcję Generalną ds. Podatków (DJP). Jest obowiązkowy dla wszystkich podatników PKP (Pengusaha Kena Pajak) i obejmuje numer seryjny NSFP (Nomor Seri Faktur Pajak), identyfikatory podatkowe NPWP oraz obliczenia PPN (VAT).
