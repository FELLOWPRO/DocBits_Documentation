# 🇸🇬 INVOICENOW SG

| Właściwość          | Wartość                                              |
| ------------------- | ---------------------------------------------------- |
| **Kraj / Region**   | Singapur                                             |
| **Typy dokumentów** | Faktura, Nota kredytowa                              |
| **Format**          | UBL 2.1 XML (Peppol)                                 |
| **Standard**        | InvoiceNow SG (Peppol BIS specyficzny dla Singapuru) |

InvoiceNow SG to lokalizacja standardu Peppol BIS Billing dla Singapuru. Rozszerza bazowy model Peppol o singapurskie reguły biznesowe, obsługę podatku GST oraz wymogi identyfikacji numerem UEN (Unique Entity Number).
