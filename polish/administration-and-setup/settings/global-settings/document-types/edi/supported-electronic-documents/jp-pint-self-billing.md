# 🇯🇵 JP PINT SELF-BILLING

| Właściwość           | Wartość                       |
| -------------------- | ----------------------------- |
| **Kraj / Region**    | Japonia                       |
| **Typy dokumentów**  | Faktura wystawiona przez nabywcę (self-billing) |
| **Format**           | UBL 2.1 XML                   |
| **Standard**         | JP PINT Self-Billing          |

JP PINT Self-Billing to wariant japońskiego modelu faktury Peppol International oparty na samofakturowaniu. Umożliwia nabywcom wystawianie faktur w imieniu dostawców, według tej samej struktury JP PINT z odwróconymi rolami stron, co jest dozwolone w określonych warunkach przez japońskie prawo podatkowe.
