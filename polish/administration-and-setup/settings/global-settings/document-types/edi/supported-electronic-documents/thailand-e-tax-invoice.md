# 🇹🇭 THAILAND E-TAX INVOICE

| Właściwość | Wartość |
| ---------- | ------- |
| **Kraj/Region** | Tajlandia |
| **Typy dokumentów** | Faktura podatkowa, Pokwitowanie |
| **Format** | XML (osadzony w PDF/A-3) |
| **Standard** | e-Tax Invoice & e-Receipt (Revenue Department) |

Thailand e-Tax Invoice to standard elektronicznej faktury podatkowej i pokwitowania regulowany przez Revenue Department (urząd skarbowy). Wykorzystuje format hybrydowy podobny do ZUGFeRD, w którym ustrukturyzowane dane XML są osadzone w dokumencie PDF/A-3. System wymaga podpisu cyfrowego za pomocą certyfikatu wydanego przez tajskie centrum certyfikacji (CA).
