# 🇩🇪 ZUGFERD 1.0 COMFORT

<!-- edocs-country-scope -->

{% hint style="info" %}
Sprawdź w przewodniku krajowym ograniczenia wersji, faktycznie używaną konfigurację i film objaśniający dla kraju. [Niemcy](countries/germany.md). Składnia, wersja publikacji i profil to różne wybory. Nie wnioskuj o publikacji Factur-X na podstawie wspólnego znacznika 1p0.
{% endhint %}

| Właściwość           | Wartość                      |
| -------------------- | ---------------------------- |
| **Kraj/Region**      | Niemcy                       |
| **Typy dokumentów**  | Faktura, Nota kredytowa      |
| **Format**           | CII (osadzony w PDF/A-3)     |
| **Standard**         | ZUGFeRD 1.0, profil Comfort  |
| **Oparty na**        | Specyfikacja ZUGFeRD 1.0     |

Profil Comfort standardu ZUGFeRD 1.0 rozszerza profil Basic o dodatkowe pola dotyczące warunków płatności, informacji o dostawie oraz szczegółowego podziału podatków. Umożliwia w pełni zautomatyzowane przetwarzanie faktur bez ręcznego wprowadzania danych.
