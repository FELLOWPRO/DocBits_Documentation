# 🇩🇪 ZUGFERD 1.0 EXTENDED

| Właściwość           | Wartość                       |
| -------------------- | ----------------------------- |
| **Kraj/Region**      | Niemcy                        |
| **Typy dokumentów**  | Faktura, Nota kredytowa       |
| **Format**           | CII (osadzony w PDF/A-3)      |
| **Standard**         | ZUGFeRD 1.0, profil Extended  |
| **Oparty na**        | Specyfikacja ZUGFeRD 1.0      |

Profil Extended standardu ZUGFeRD 1.0 jest najbardziej rozbudowanym profilem i obsługuje dodatkowe scenariusze biznesowe, takie jak rachunkowość handlowa, factoring oraz szczegółowe informacje logistyczne. Zawiera wszystkie pola profili Basic i Comfort oraz rozszerzenia branżowe.
