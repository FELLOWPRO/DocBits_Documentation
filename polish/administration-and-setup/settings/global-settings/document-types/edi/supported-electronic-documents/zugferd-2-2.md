# 🇩🇪 ZUGFERD 2.2

<!-- edocs-country-scope -->

{% hint style="info" %}
Sprawdź w przewodniku krajowym ograniczenia wersji, faktycznie używaną konfigurację i film objaśniający dla kraju. [Niemcy](countries/germany.md). Składnia, wersja publikacji i profil to różne wybory. Nie wnioskuj o publikacji Factur-X na podstawie wspólnego znacznika 1p0.
{% endhint %}

| Właściwość           | Wartość                  |
| -------------------- | ------------------------ |
| **Kraj/Region**      | Niemcy                   |
| **Typy dokumentów**  | Faktura, Nota kredytowa  |
| **Format**           | CII (osadzony w PDF/A-3) |
| **Standard**         | ZUGFeRD 2.2              |
| **Oparty na**        | EN 16931                 |

ZUGFeRD 2.2, wydany w 2022 roku, jest zgodny z europejskim standardem EN 16931 i odpowiada Factur-X 1.0.06. Wykorzystuje składnię XML CII D16B i obsługuje pięć profili zgodności: Minimum, Basic WL, Basic, EN 16931 (Comfort) oraz Extended.
