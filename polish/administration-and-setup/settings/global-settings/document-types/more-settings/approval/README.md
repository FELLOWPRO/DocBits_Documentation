# Zatwierdzenie

Użyj opcji zatwierdzania, aby zdecydować, jak dokument jest sprawdzany, zanim opuści DocBits. Opcje konfiguruje się dla każdego typu dokumentu, więc zacznij od typu używanego przez Twój zespół, na przykład **Faktura**.

1. Otwórz **Ustawienia** → **Typy Dokumentów**.
2. Wybierz typ dokumentu i otwórz **Więcej Ustawień**.
3. Przewiń do sekcji **Zatwierdzenie i odrzucenie**. Przeanalizuj cztery przełączniki, zanim którykolwiek z nich zmienisz.

W tym przykładzie wszystkie cztery przełączniki są wyłączone.</figcaption></figure>

| Opcja | Do czego służy |
| --- | --- |
| **Zatwierdź przed eksportem** | Wymaga decyzji o zatwierdzeniu przed wyeksportowaniem dokumentu. |
| **Drugie zatwierdzenie** | Dodaje kolejny krok zatwierdzania, gdy jedna decyzja to za mało dla Twojego procesu. |
| **Pieczęć zatwierdzenia** | Dodaje oznakę zatwierdzenia do zatwierdzonego dokumentu. Zobacz [Pieczęć zatwierdzenia](approval-stamp.md), aby poznać konfigurację i opcje pobierania. |
| **Historia zatwierdzeń** | Zachowuje rejestr decyzji o zatwierdzeniu. Zobacz [Historia zatwierdzeń](approval-history.md), aby poznać ustawienie i sposób sprawdzania historii. |

Wybierz opcje wymagane przez Twój proces. Następnie użyj dokumentu testowego niezawierającego danych rzeczywistego klienta oraz przewidzianych ról recenzentów, aby sprawdzić ścieżkę zatwierdzania, zanim zastosujesz ją do rzeczywistych dokumentów. Zrzut ekranu pokazuje dostępne ustawienia; podczas tej weryfikacji dokumentacji nie wykonano żadnego obiegu zatwierdzania ani eksportu.
