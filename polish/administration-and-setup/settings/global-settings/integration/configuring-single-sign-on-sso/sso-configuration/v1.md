# V1: SSO w Infor Ming.le Portal

Ten przewodnik dotyczy **Infor Ming.le Portal V1** z LN lub starszym interfejsem M3. Jeśli Twój tenant korzysta z nowszego Infor OS Portal, zapytaj administratora Infor, jaka procedura federacji obowiązuje, zanim zastosujesz te kroki. Potrzebujesz dostępu administratora zarówno do tenanta Infor, jak i do organizacji DocBits. Zachowaj dostępne dotychczasowe logowanie administratora, dopóki użytkownik testowy nie zaloguje się pomyślnie przez SSO.

## 1. Pobierz wartości dostawcy usług DocBits

Zaloguj się do właściwego środowiska i organizacji DocBits. Otwórz **Settings → Integration & SSO → SSO Service Provider Settings**. Skopiuj **Entity ID**, **SSO Url** i **SLO Url** za pomocą przycisków obok każdej wartości. Użyj **Download Certificate**, jeśli Infor wymaga certyfikatu podpisującego DocBits. **Download Metadata** eksportuje metadane _dostawcy usług_ DocBits. Adresy URL Sandbox w tym przykładzie są specyficzne dla organizacji testowej; nie kopiuj ich do innego tenanta.

![Aktualne ustawienia dostawcy usług SSO DocBits w angielskiej organizacji testowej Sandbox, z Entity ID, SSO Url, SLO Url i przyciskami pobierania.](../../../../../../.gitbook/assets/dbdc-182-infor-v2-sso-settings-en.png)

## 2. Zarejestruj DocBits w Infor

W swoim tenancie **Infor Ming.le Portal V1** otwórz **User Management → Security Administration → Service Provider**, a następnie dodaj dostawcę usług SAML dla DocBits. Administrator Infor powinien potwierdzić, że jest to właściwy ekran i typ aplikacji dla Twojego tenanta. Przypisz wartości w następujący sposób:

| Pole dostawcy usług Infor | Wartość z DocBits                                                                                   |
| ------------------------- | --------------------------------------------------------------------------------------------------- |
| Entity ID                 | Entity ID                                                                                           |
| SSO Endpoint              | SSO Url (punkt końcowy konsumenta asercji)                                                          |
| SLO Endpoint              | SLO Url (punkt końcowy wylogowania)                                                                 |
| Signing Certificate       | Certyfikat z Download Certificate, jeśli jest wymagany                                              |
| Name ID Format / Mapping  | Adres e-mail, po upewnieniu się, że identyfikator użytkownika Infor odpowiada użytkownikowi DocBits |

**Nie wklejaj SLO Url do SSO Endpoint.** To różne punkty końcowe. Zapisz dostawcę usług. [Przewodnik konfiguracji dostawcy usług](https://docs.infor.com/inforos/2026.09/en-us/useradminlib_cloud/minceag_cloud_osm/vxs1562872848076.html) Infor opisuje role pól oraz akcję **Export SAML Metadata**. Menu i uprawnienia Infor mogą różnić się w zależności od tenanta i wydania.

## 3. Zaimportuj metadane dostawcy tożsamości Infor do DocBits

W Infor otwórz zapisanego dostawcę usług DocBits, wybierz **View** przy **Identity Provider Information**, a następnie **Export SAML Metadata**. Ten plik zawiera dane _dostawcy tożsamości Infor_. Różni się od metadanych dostawcy usług DocBits pobranych w kroku 1.

W DocBits wróć do **Settings → Integration & SSO → Identity Service Provider Settings**. Wprowadź **Tenant ID** Infor, wybierz plik XML z metadanymi Infor w polu **Upload file**, a następnie kliknij **Configure**. Przed zapisaniem potwierdź identyfikator tenanta i plik XML u administratora Infor; zrzut ekranu Sandbox nie odzwierciedla Twojego tenanta produkcyjnego.

## 4. Sprawdź logowanie

Przypisz odpowiedniego użytkownika Infor do aplikacji DocBits w Ming.le i przetestuj logowanie tym użytkownikiem. Sprawdź, czy identyfikator e-mail użytkownika odpowiada użytkownikowi DocBits. Podczas testów pozostaw otwartą pierwotną sesję administratora. Jeśli logowanie lub wylogowanie nie działa, porównaj z obydwoma administratorami punkty końcowe dostawcy usług, metadane Infor, certyfikat i mapowanie Name ID.

**Zakres weryfikacji:** Ekran DocBits i nawigacja opisane powyżej zostały sprawdzone w angielskiej organizacji testowej Sandbox. Na potrzeby tej aktualizacji nie był dostępny żaden tenant Infor, dlatego ekrany Infor, wymiana metadanych i rzeczywiste logowanie nie były testowane. Poprzednie zrzuty ekranu Infor zostały usunięte, ponieważ nie można było zweryfikować ich aktualnego stanu; skorzystaj z podlinkowanej dokumentacji Infor i administratora swojego tenanta, aby poznać jego aktualny interfejs.
