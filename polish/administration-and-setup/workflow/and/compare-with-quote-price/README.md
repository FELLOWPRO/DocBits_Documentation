# Porównaj z ceną z oferty

Karty tej kategorii w bibliotece **Add Card** w Workflow Builder:

Karty tej kategorii porównują pozycje dokumentu z danymi cen pozycji dostawcy, które DocBits znalazł dla dostawcy dokumentu i jego identyfikatorów pozycji dostawcy. W zależności od karty może to być identyfikator pozycji dostawcy, numer pozycji, cena zarządzana lub ostatnia zapłacona cena, jednostka miary albo typ dostawcy. Wersja 3 karty Unit of Measure może również porównywać z pozycjami dopasowanego zamówienia zakupu.
