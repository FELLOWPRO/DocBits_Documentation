# Scalanie dokumentów

1. Zaznacz od dwóch do pięciu powiązanych dokumentów polami wyboru, w odpowiedniej kolejności.
2. Otwórz menu działań zbiorczych w nagłówku tabeli i wybierz scalanie, jeśli jest dostępne.
3. Przeczytaj potwierdzenie: pierwszy wybrany dokument jest główny. Pozostałe zostaną do niego dołączone w kolejności wyboru. Anuluj, jeśli wybór lub kolejność są nieprawidłowe.
4. Potwierdź tylko dokumenty, które należą do jednej całości. Sprawdź wynik po odświeżeniu listy.

Scalanie zmienia dokumenty i wymaga praw edycji. Używaj go dla części jednego dokumentu. Zachowaj osobno niezależne faktury; scalanie nie tworzy zestawienia księgowego.

Wyszukiwanie, działania i widoki opisuje [przewodnik po pulpicie](README.md).
