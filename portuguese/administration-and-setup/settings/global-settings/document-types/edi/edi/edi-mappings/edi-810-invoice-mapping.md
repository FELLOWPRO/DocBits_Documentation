# Mapeamento EDI 810 (Fatura)

Estas são referências exemplificativas a campos de origem X12 004010, não um mapeamento ativo do DocBits verificado. Antes de configurar a extração, verifique o guia do parceiro, os ciclos de segmentos, qualificadores, estado, moeda, unidades e base do preço. Os montantes N2 têm duas casas decimais implícitas. Multiplicar quantidade pelo preço unitário não adiciona impostos; aplique separadamente as regras acordadas de impostos e descontos.
