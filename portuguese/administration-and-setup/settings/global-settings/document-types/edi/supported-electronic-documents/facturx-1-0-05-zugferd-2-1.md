# 🇫🇷 FACTURX 1.0.05 - ZUGFERD 2.1

| Propriedade | Valor |
| --- | --- |
| **País / Região** | França / Alemanha |
| **Tipos de documento** | Fatura, nota de crédito |
| **Formato** | CII (PDF/A-3 incorporado) |
| **Padrão** | Factur-X 1.0.05 / ZUGFeRD 2.1 |
| **Baseado em** | EN 16931 |

O Factur-X 1.0.05 é equivalente ao ZUGFeRD 2.1. Lançado em 2020, foi a primeira versão publicada em conjunto que estabeleceu a plena interoperabilidade entre os ecossistemas franceses e alemães de fatura eletrônica. Suporta os perfis: Minimum, Basic WL, Basic, EN 16931, Extended.
