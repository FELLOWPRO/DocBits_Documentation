# 🇰🇷 KOREA NTS

| Propriedade          | Valor                                  |
| -------------------- | -------------------------------------- |
| **País / Região**    | Coreia do Sul                          |
| **Tipos de documento** | Fatura fiscal, Recibo de caixa       |
| **Formato**          | XML                                    |
| **Padrão**           | NTS (Serviço Nacional de Impostos)     |

O Korea NTS refere-se ao sistema mais amplo de documentos eletrônicos do Serviço Nacional de Impostos, que abrange faturas fiscais, recibos de caixa e outros documentos fiscais. O DocBits processa os documentos NTS e extrai todos os campos padrão, incluindo os números de registro comercial, os valores de fornecimento e os montantes de imposto.
