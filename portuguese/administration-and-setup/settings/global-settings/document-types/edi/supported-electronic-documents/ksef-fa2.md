# 🇵🇱 KSEF FA2

| Propriedade          | Valor                       |
| -------------------- | --------------------------- |
| **País / Região**    | Polónia                     |
| **Tipos de documento** | Fatura, Fatura retificativa |
| **Formato**          | XML                         |
| **Padrão**           | KSeF FA(2)                  |

O KSeF FA2 é a segunda versão do esquema do Sistema Nacional de Faturação Eletrônica polaco. Define a estrutura XML das faturas estruturadas (faktury), incluindo os dados do vendedor e do comprador, as linhas de itens, as taxas de IVA e as condições de pagamento exigidas pela legislação fiscal polaca.
