# 🇲🇽 MEXICO CFDI 4.0

<!-- edocs-country-scope -->

{% hint style="info" %}
Consulte o guia do país para conhecer os limites das versões, a configuração efetiva e o vídeo explicativo. [México](countries/mexico.md). Verifique o espaço de nomes, a versão e TipoDeComprobante. Um documento de nota de crédito não é identificado apenas por um montante negativo; analisar o ficheiro não certifica a aprovação pelo SAT.
{% endhint %}

| Propriedade          | Valor                                              |
| -------------------- | -------------------------------------------------- |
| **País / Região**    | México                                             |
| **Tipos de documento** | Fatura, Nota de crédito, Recibo de pagamento     |
| **Formato**          | XML                                                |
| **Padrão**           | CFDI 4.0 (Comprobante Fiscal Digital por Internet) |

O CFDI 4.0 é a versão atual do padrão mexicano de comprovativo fiscal digital, obrigatória desde janeiro de 2023. Exige o nome do destinatário e o seu regime fiscal (régimen fiscal), acrescenta o campo de exportação e inclui o selo digital atualizado e a cadeia de certificados do SAT.
