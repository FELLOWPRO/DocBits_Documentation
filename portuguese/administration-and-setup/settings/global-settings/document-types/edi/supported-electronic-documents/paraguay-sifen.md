# 🇵🇾 PARAGUAY SIFEN

{% hint style="info" %}

| Propriedade          | Valor                                                         |
| -------------------- | ------------------------------------------------------------- |
| **País / Região**    | Paraguai                                                      |
| **Tipos de documento** | Fatura, Nota de crédito, Nota de débito, Retenção           |
| **Formato**          | XML                                                           |
| **Padrão**           | SIFEN (Sistema Integrado de Facturación Electrónica Nacional) |

O SIFEN é o sistema nacional integrado de faturação eletrônica do Paraguai, operado pela SET. Todos os documentos eletrônicos têm de ser submetidos ao SIFEN para validação e recebem um identificador único CDC (Código de Control Digital).
