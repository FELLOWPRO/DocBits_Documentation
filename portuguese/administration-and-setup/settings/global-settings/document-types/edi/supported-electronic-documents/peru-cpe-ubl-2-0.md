# 🇵🇪 PERU CPE UBL 2.0

| Propriedade          | Valor                            |
| -------------------- | -------------------------------- |
| **País / Região**    | Peru                             |
| **Tipos de documento** | Fatura, Nota de crédito, Nota de débito |
| **Formato**          | UBL 2.0 XML                      |
| **Padrão**           | CPE UBL 2.0                      |

O Peru CPE UBL 2.0 é o formato anterior, baseado em UBL, das faturas eletrônicas peruanas. Embora a SUNAT tenha passado para o UBL 2.1, muitos documentos existentes ainda utilizam esta versão. O DocBits processa estes documentos e extrai todos os campos de cabeçalho e de linhas de itens.
