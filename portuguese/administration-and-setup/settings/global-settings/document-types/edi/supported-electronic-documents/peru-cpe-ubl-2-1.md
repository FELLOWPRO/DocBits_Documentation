# 🇵🇪 PERU CPE UBL 2.1

| Propriedade          | Valor                                       |
| -------------------- | ------------------------------------------- |
| **País / Região**    | Peru                                        |
| **Tipos de documento** | Fatura, Nota de crédito, Nota de débito   |
| **Formato**          | UBL 2.1 XML                                 |
| **Padrão**           | CPE UBL 2.1                                 |

O Peru CPE UBL 2.1 é o formato atual das faturas eletrônicas peruanas enviadas à SUNAT. Ele usa o padrão OASIS UBL 2.1 com extensões peruanas para identificação por RUC, cálculos do imposto IGV (IVA) e mecanismos de retenção de detracción/retención.
