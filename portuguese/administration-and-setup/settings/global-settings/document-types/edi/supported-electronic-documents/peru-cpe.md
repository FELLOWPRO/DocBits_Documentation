# 🇵🇪 PERU CPE

| Propriedade          | Valor                                   |
| -------------------- | --------------------------------------- |
| **País / Região**    | Peru                                    |
| **Tipos de documento** | Fatura, Nota de crédito, Nota de débito |
| **Formato**          | UBL XML                                 |
| **Padrão**           | CPE (Comprobante de Pago Electrónico)   |

O CPE (Comprobante de Pago Electrónico) é o padrão peruano de comprovante de pagamento eletrônico regulamentado pela SUNAT. O DocBits suporta as versões UBL 2.0 e 2.1 usadas na emissão de faturas eletrônicas no Peru.
