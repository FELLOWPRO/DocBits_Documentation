# 🇹🇭 THAILAND E-TAX INVOICE

| Propriedade          | Valor                                          |
| -------------------- | ---------------------------------------------- |
| **País / Região**    | Tailândia                                      |
| **Tipos de documento** | Fatura fiscal, Recibo                        |
| **Formato**          | XML (incorporado em PDF/A-3)                   |
| **Padrão**           | e-Tax Invoice & e-Receipt (Revenue Department) |

O Thailand e-Tax Invoice é o padrão de fatura fiscal e recibo eletrônicos regulamentado pelo Revenue Department. Usa um formato híbrido semelhante ao ZUGFeRD, incorporando dados XML estruturados em um documento PDF/A-3. O sistema exige assinatura digital com um certificado emitido por uma autoridade certificadora (CA) tailandesa.
