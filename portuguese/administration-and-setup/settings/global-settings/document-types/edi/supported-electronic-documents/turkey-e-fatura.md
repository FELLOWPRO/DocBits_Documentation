| Propriedade          | Valor                                   |
| -------------------- | --------------------------------------- |
| **País / Região**    | Turquia                                 |
| **Tipos de documento** | Fatura, Nota de crédito               |
| **Formato**          | UBL-TR 1.2 XML                          |
| **Padrão**           | e-Fatura (GİB - Revenue Administration) |

O Turkey e-Fatura é o principal padrão de fatura eletrônica exigido pela GİB (Revenue Administration) para transações B2B entre contribuintes registrados. As faturas são trocadas por meio de integradores registrados e da plataforma da GİB. O formato usa o UBL-TR, a versão localizada do UBL na Turquia, com campos específicos turcos para a identificação fiscal por TCKN/VKN.
