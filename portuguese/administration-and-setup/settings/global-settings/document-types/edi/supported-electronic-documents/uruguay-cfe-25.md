# 🇺🇾 URUGUAY CFE 25

<!-- edocs-country-scope -->

{% hint style="info" %}
Consulte o guia do país para conhecer os limites das versões, a configuração efetiva e o vídeo explicativo. [Uruguai](countries/uruguay.md). As entradas de notas de crédito não têm conjuntos de extração dedicados no estado examinado. Confirme a versão CFE e o mapeamento efetivo de fatura ou nota de crédito.
{% endhint %}

| Propriedade          | Valor                        |
| -------------------- | ---------------------------- |
| **País / Região**    | Uruguai                      |
| **Tipos de documento** | e-Fatura, Nota de crédito  |
| **Formato**          | XML                          |
| **Padrão**           | CFE, versão de esquema 25    |

O Uruguay CFE 25 é a versão mais recente do esquema do sistema uruguaio CFE. Inclui regras de validação e requisitos de campos atualizados para os documentos eletrônicos enviados à DGI.
