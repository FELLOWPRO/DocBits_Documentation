# 🇺🇾 URUGUAY CFE

<!-- edocs-country-scope -->

{% hint style="info" %}
Consulte o guia do país para conhecer os limites das versões, a configuração efetiva e o vídeo explicativo. [Uruguai](countries/uruguay.md). As entradas de notas de crédito não têm conjuntos de extração dedicados no estado examinado. Confirme a versão CFE e o mapeamento efetivo de fatura ou nota de crédito.
{% endhint %}

| Propriedade          | Valor                                                   |
| -------------------- | ------------------------------------------------------- |
| **País / Região**    | Uruguai                                                 |
| **Tipos de documento** | e-Fatura, e-Ticket, Nota de crédito, Nota de débito   |
| **Formato**          | XML                                                     |
| **Padrão**           | CFE (Comprobante Fiscal Electrónico)                    |

O CFE (Comprobante Fiscal Electrónico) é o padrão uruguaio de documento fiscal eletrônico regulamentado pela DGI (Dirección General Impositiva). Abrange vários tipos de documento, entre eles e-Factura (111), e-Ticket (101) e suas variantes de nota de crédito e de débito.
