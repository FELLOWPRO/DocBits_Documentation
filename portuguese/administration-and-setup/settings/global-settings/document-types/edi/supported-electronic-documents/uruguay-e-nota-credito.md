# 🇺🇾 URUGUAY E-NOTA CREDITO

| Propriedade          | Valor                              |
| -------------------- | ---------------------------------- |
| **País / Região**    | Uruguai                            |
| **Tipos de documento** | Nota de crédito (e-Nota de Crédito) |
| **Formato**          | XML                                |
| **Padrão**           | e-Nota de Crédito (CFE tipo 112)   |

A Uruguay e-Nota de Crédito é o tipo de documento de nota de crédito eletrônica dentro do sistema CFE, identificado pelo código de tipo 112. É usada para ajustar ou cancelar e-Facturas emitidas anteriormente e deve fazer referência ao documento original.
