# 🇩🇪 XRECHNUNG 1.1 UBL

| Propriedade          | Valor                    |
| -------------------- | ------------------------ |
| **País / Região**    | Alemanha                 |
| **Tipos de documento** | Fatura, Nota de crédito |
| **Formato**          | UBL                      |
| **Padrão**           | XRechnung 1.1            |
| **Baseado em**       | EN 16931 (OASIS UBL 2.1) |

Versão inicial do padrão XRechnung. Foi substituída por versões mais recentes, mas continua suportada para o processamento de documentos legados.
