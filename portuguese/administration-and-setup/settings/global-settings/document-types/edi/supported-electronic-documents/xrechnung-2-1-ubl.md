# 🇩🇪 XRECHNUNG 2.1 UBL

{% hint style="info" %}
Consulte o guia do país para conhecer os limites das versões, a configuração efetiva e o vídeo explicativo. [Alemanha](countries/germany.md). A sintaxe, a versão da publicação e o perfil são escolhas diferentes. Não deduza uma edição Factur-X a partir do marcador partilhado 1p0.

| Propriedade | Valor |
| --- | --- |
| **País / Região** | Alemanha |
| **Tipos de documento** | Fatura, Nota de crédito |
| **Formato** | UBL |
| **Padrão** | XRechnung 2.1 |
| **Baseado em** | EN 16931 (OASIS UBL 2.1) |

O XRechnung 2.1 implementa o padrão EN 16931 Core Invoice com as extensões da CIUS (Core Invoice Usage Specification) alemã. Esta versão introduziu uma validação melhorada, com regras Schematron reforçadas e verificações de conformidade mais rigorosas.
