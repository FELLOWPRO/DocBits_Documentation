# 🇩🇪 XRECHNUNG 3.0 UBL

| Propriedade | Valor |
| --- | --- |
| **País / Região** | Alemanha |
| **Tipos de documento** | Fatura, Nota de crédito |
| **Formato** | UBL |
| **Padrão** | XRechnung 3.0 |
| **Baseado em** | EN 16931 (OASIS UBL 2.1) |

O XRechnung 3.0 é a geração atual do padrão alemão de faturação eletrônica, alinhada com as atualizações mais recentes da EN 16931. Versão principal com regras de validação reestruturadas e suporte reforçado para faturação transfronteiriça na União Europeia.
