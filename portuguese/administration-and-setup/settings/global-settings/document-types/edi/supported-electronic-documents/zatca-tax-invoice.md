# 🇸🇦 ZATCA TAX INVOICE

| Propriedade            | Valor                      |
| ---------------------- | -------------------------- |
| **País / Região**      | Arábia Saudita             |
| **Tipos de documento** | Fatura fiscal padrão       |
| **Formato**            | XML UBL 2.1                |
| **Padrão**             | Fatura fiscal padrão ZATCA |

A fatura fiscal ZATCA é o formato padrão de fatura fiscal B2B no sistema de fatura eletrônica da Arábia Saudita. Exige a identificação completa do comprador e do vendedor (incluindo os números de registro de IVA), itens detalhados com cálculos de IVA e deve ser autorizada (clearance) na plataforma ZATCA antes de ser compartilhada com o comprador.
