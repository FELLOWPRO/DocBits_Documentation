# Solução de problemas

## Solução de problemas comuns&#x20;

### Os campos não correspondem aos documentos digitalizados:

* Verifique a configuração dos campos no Layout Manager e certifique-se de que eles correspondem aos campos reais nos documentos digitalizados.&#x20;
* Verifique se as posições e as dimensões dos campos no layout estão corretas e se cobrem todas as informações relevantes.&#x20;

### Os dados não são extraídos corretamente:

* Verifique as regras de validação e as configurações de formato dos campos afetados para garantir que os dados esperados possam ser capturados corretamente.&#x20;
* Certifique-se de que o OCR (Reconhecimento Óptico de Caracteres) ou outras tecnologias de captura de dados estejam configurados e calibrados corretamente para garantir a extração precisa dos dados.&#x20;

### Validação de dados com falhas:

* Verifique as regras de validação dos campos para garantir que sejam adequadas e estejam configuradas corretamente.&#x20;
* Ajuste as regras de validação, se necessário, para garantir que atendam aos requisitos e aos formatos dos dados capturados.&#x20;

### Os layouts de documentos são confusos ou ineficientes:

* Revise o layout para melhorar a estrutura e a organização dos campos e garantir que as informações importantes sejam de fácil acesso.
* Realize testes com usuários para obter feedback sobre a usabilidade do layout e faça ajustes para aumentar a eficiência.



Ao aplicar essas boas práticas e a solução de problemas conforme necessário, você pode criar layouts de documentos eficientes e precisos que permitem uma captura e um processamento de dados sem complicações.
