# Usando a pré-visualização do modelo

## A pré-visualização do modelo é uma ferramenta extremamente útil para verificar e ajustar as configurações de layout em tempo real antes de fazer alterações em um documento ou modelo.

### Veja como você pode usar a pré-visualização do modelo:

<figure><img src="../../../../../.gitbook/assets/image (152).png" alt=""><figcaption></figcaption></figure>

#### Abrir a pré-visualização do modelo:

* Normalmente, você encontra a opção de pré-visualização do modelo na interface do editor de modelos.

<figure><img src="../../../../../.gitbook/assets/image (153).png" alt=""><figcaption></figcaption></figure>

#### Selecionar o modelo:

* Selecione o modelo cujo layout você quer verificar.
* Pode ser um modelo existente que você quer alterar ou um novo modelo que você quer criar.

<figure><img src="../../../../../.gitbook/assets/Bildschirmfoto 2024-05-24 um 12.31.04.png" alt="" width="186"><figcaption></figcaption></figure>

#### Ajustar as configurações de layout:

* Altere as configurações de layout conforme necessário. Isso pode incluir adicionar, remover ou ajustar grupos, campos, colunas, linhas, fontes etc.

<figure><img src="../../../../../.gitbook/assets/image (155).png" alt="" width="271"><figcaption></figcaption></figure>

#### Pré-visualização em tempo real:

* Conforme você altera as configurações de layout, a pré-visualização é atualizada em tempo real.
* Você vê imediatamente como as alterações afetam a aparência e a estrutura do modelo.

#### Personalização interativa:

* Aproveite a possibilidade de personalizar o layout de forma interativa, movendo, redimensionando ou fazendo outros ajustes nos elementos enquanto verifica os efeitos em tempo real na pré-visualização.

#### Testar diferentes configurações:

* Experimente diferentes configurações de layout para encontrar o melhor design para as suas necessidades.
* Use a pré-visualização do modelo para ver como cada alteração afeta o resultado final.

#### Salvar e confirmar as alterações:

* Quando estiver satisfeito com o layout, salve as suas alterações.
* Dependendo do software, você também pode encontrar a opção de confirmar as alterações diretamente para atualizar o modelo e usá-lo em outros documentos ou processos.

A pré-visualização do modelo permite garantir que o layout atenda às necessidades desejadas antes de confirmar as alterações. Assim, você personaliza com eficiência o design e a estrutura dos seus documentos e garante que eles atendam aos padrões visuais e funcionais desejados.
