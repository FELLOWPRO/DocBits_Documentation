# Expressões regulares (Regex)

A antiga ligação direta Regex no cartão do tipo de documento não está disponível na interface atual.

Antes de alterar uma expressão, verifique o caminho de configuração suportado pela sua versão. Preserve a expressão existente e prepare entradas válidas, incompletas e sem correspondência. Compare as correspondências reais após cada alteração. Guarde a configuração pretendida apenas depois da verificação e teste documentos representativos antes de a aplicar a outras faturas.
