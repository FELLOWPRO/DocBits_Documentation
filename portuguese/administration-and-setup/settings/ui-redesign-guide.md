# Orientação no Novo Layout

Esta página é uma orientação rápida ao layout atual do DocBits — onde encontrar as coisas, como funciona a navegação e como usar as novas ajudas. Use como referência se uma tela parecer diferente do que você lembra ou se não conseguir encontrar uma configuração imediatamente.

## A barra lateral

A barra lateral principal lista cada seção do DocBits para a qual você tem permissão. Duas formas de controlá-la:

* **Modo mini** — clique no botão no topo da barra lateral para reduzi-la a apenas ícones. Passe o cursor sobre qualquer ícone para ler o rótulo. A barra se lembra se você a deixou expandida ou recolhida da última vez.
* **Personalizar** — no final da barra expandida há uma entrada **Personalizar**. Use-a para reorganizar o menu, ocultar entradas que você não usa ou fixar no topo as que abre com mais frequência.

Para a explicação completa de reordenar, ocultar e fixar, veja [Barra Lateral Personalizável](../../end-user-and-partner-section/end-user-section/customizable-sidebar.md).

## Onde as configurações ficam agora

O menu Configurações está agrupado por intenção, e não por modelo de dados. Se você lembra de uma configuração mas não consegue encontrá-la, tente o grupo correspondente abaixo:

| Você procura… | Abra Configurações → |
|---|---|
| Nome da empresa, logotipo, fuso horário, cor do app | Empresa e Usuários → Informações da Empresa |
| Usuários, grupos, permissões | Empresa e Usuários → Grupos, Usuários e Permissões |
| Chaves de API, conexões ERP, configurações de exportação | Integração |
| Tipos de documento, campos, scripts, EDI, treinamento de modelo | Tipos de Documento |
| Configurações OCR, árvores de decisão, listas de valores, gerenciador de regras | Processamento de Documentos |
| Auditoria de acesso, analítica, índice de texto completo, log de eventos | Logs e Pesquisa |
| Portal do fornecedor, Watchdog | Configuração |

Dentro de cada grupo, as páginas mais usadas ficam no topo.

## Páginas de configurações longas — navegação por âncoras

As páginas de configurações com muitas seções (como Configurações Globais ou a configuração de um Tipo de Documento) agora exibem uma lista de links de âncora no cabeçalho. Clique em uma âncora para saltar até aquela seção. A URL é atualizada conforme você rola, então o link para uma seção específica pode ser compartilhado ou favoritado.

## Encontrando documentação enquanto trabalha — ícones de ajuda

A maioria das páginas de configurações, diálogos e telas de ferramentas agora exibe um pequeno ícone **?** no cabeçalho.

<figure><img src="../../.gitbook/assets/ui-redesign-help-icon.png" alt="Ícone de ajuda no cabeçalho de uma página"><figcaption><p>O ícone de ajuda abre a página de documentação correspondente em uma nova aba.</p></figcaption></figure>

Um clique abre a página correspondente em `docs.docbits.com` em uma nova aba — sem precisar pesquisar a documentação. O ícone respeita o idioma da interface e abre a documentação traduzida quando existe; caso contrário, recorre ao inglês.

## Entrando

A tela de login, a redefinição de senha e os pontos de entrada SSO (Microsoft 365, Google, Infor OS) compartilham o mesmo layout do restante do DocBits. Os erros aparecem diretamente sob o campo que os gerou; a redefinição de senha e o link de ajuda ficam ao final do formulário. O fluxo é o mesmo de antes — apenas a aparência foi atualizada.

## Se algo parecer faltar

Se uma página ou configuração parece ter se mudado e você não encontra:

1. Abra a [Pesquisa Rápida Global](../../end-user-and-partner-section/end-user-section/global-quick-search.md) com <kbd>Cmd</kbd>/<kbd>Ctrl</kbd>+<kbd>K</kbd> e digite o nome da funcionalidade — a Pesquisa Rápida indexa cada página da aplicação.
2. Abra o [Mapa do Site](../../end-user-and-partner-section/end-user-section/sitemap.md) em `/sitemap` para o catálogo completo e filtrável.
3. Use o ícone de ajuda na tela mais próxima para cair direto na documentação.
