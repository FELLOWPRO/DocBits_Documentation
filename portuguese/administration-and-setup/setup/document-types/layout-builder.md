# Construtor de Layouts

Tutorial do Construtor de Layouts do DocBits: criar layouts de documentos personalizados para uma validação mais rápida e clara

Neste vídeo, aprenderá a utilizar o Construtor de Layouts do DocBits para criar layouts personalizados. Os layouts organizam os campos numa estrutura clara, aceleram a validação e facilitam a revisão dos documentos pela equipa.

**O que irá aprender:**
*   O que é o Construtor de Layouts e quando o utilizar
*   Onde o encontrar nas configurações do DocBits
*   Como criar um layout e escolher o tipo de documento
*   Como colocar e organizar campos e secções para facilitar a validação
*   Como manter layouts consistentes entre equipas e variantes de documentos
*   Como guardar e aplicar o layout no fluxo de trabalho

## **Aceder ao Construtor de Layouts**

Confirme primeiro que o Construtor de Layouts está ativo em Configurações → Processamento de documentos → Módulo → Tipo de documento. O respetivo interruptor deve estar ativo, como no exemplo abaixo.

![](https://lh7-us.googleusercontent.com/I0VvFiFftKLoCB47jCAoosfTyqIQgXBoggMFp1QAeIj9xW4yiiIzyk5eIEHZ7duA251Yc4\_ArUKA8e-LjDht13bckAnkAOHOvl1p5k1-Qj\_UkEp2cSZwxHz\_PXe8IQ4\_jglzCtjAJg5pd9m\_hNZEhXA)

Depois, abra Configurações → Tipos de documento. Selecione um tipo de documento existente e escolha «Edit Layout» (editar layout), como no exemplo abaixo.

![](https://lh7-us.googleusercontent.com/WMD8M0qugnc64ZuyLuEYH5P63qk-Vo86useg32-QyOsP63FJA\_Xh7UzwlwmUR3K9oTd19aXexSitZqQLVEKo26-i8hYWUS9CChzwAS8TgbWoqweFucJcNIgKBruzSd0mxn8zrh9i46lPxKMNDh-YEJ8)

Se o tipo de documento tiver subtipos, escolha «Document Sub Types» (subtipos de documento) e depois «Edit Layout» no subtipo cujo layout pretende editar.

![](https://lh7-us.googleusercontent.com/KfmM8wMGnn5tzXRxF1yT0Efm7X6v0kYeGzgNG3RihERh\_P71tjEVkJh4POMwgqnsCBoE736xI7oHkmpYNUbtAShhE-wAHsnLuxljDtmhGQUyljF\_PmOF2y6c0gIdIk\_jUD3sVNsq5viT2sb236OBYSA)

### **Elementos de formulário**

![](https://lh7-us.googleusercontent.com/OFBRSGdol7loocu5uGVe4Q8URMDojvXTN0xj3TCgL-jb-wUgt1fjEqfXCyMPz\_HNh94LVVmg6ifQDhxvlQsgbbChRfrw2Ohx4ICOUwHix3iiAFY9hI3BPGBfcNABiHLhgXQJVZmGvEO\_niVWkIXz\_6g)

Os campos padrão podem ser arrastados para o Construtor de Layouts. Incluem:

* Text (texto) — cria um campo onde é possível introduzir texto no ecrã de validação.
* Label (rótulo) — cria texto que não pode ser editado no ecrã de validação, como subtítulos.
* Checkbox (caixa de seleção) — cria um campo booleano que pode ser marcado ou desmarcado.
* Multi Checkbox (várias caixas de seleção) — funciona como Checkbox, mas facilita a criação de várias caixas na mesma secção.
* Horizontal Separator (separador horizontal) — cria uma linha horizontal para separar secções de um grupo.
* Table of Checkboxes (tabela de caixas de seleção) — cria uma tabela de caixas de seleção com valores personalizados nos eixos x e y, por exemplo:

![](https://lh7-us.googleusercontent.com/lMZU68H4i8ELjgenpcNXeNhJ9iwzTWGRkjNMEdV3rqdGwnaRZ\_tvG9mbx2ogXQ2hMciGSp-9m1c5KS9VwGJWzuxcRiaioVDSLTLvh-csHUho4aX25LXrtjhGSfK6yTukufwrjQvZR-JliuhiaPCCxpw)

* Button (botão) — cria um botão no ecrã de validação com uma de três funções: Export, Export mit Sonderwunsch ou Reject.
* Extracted Tables (tabelas extraídas) — coloca no layout uma área que apresenta a tabela extraída do documento. Clique aqui para obter mais informação.
* Invoice Buttons (botões de fatura) — adiciona um conjunto de botões para faturas. No ecrã de validação, ao escolher o tipo de fatura, de custo ou de compra, o botão PO Matching ou Auto Accounting é ocultado consoante o tipo.

![](https://lh7-us.googleusercontent.com/-w5iTr9b\_pcc6Y39osFmuzKQGRa\_e4tAXvQOn1zN8T4HwcuTs\_FP9mFPAJJeABvYKTyiQr3xZALsRgueIDksbswhnY-E9ioT1AIaf8xwAblBckX1f8xzi5v9mLxBRRUZoViDntKK6Nd5fy5sd5Bq5LU)

* QR Code Fields (campos de código QR) — adiciona um bloco que apresenta os dados extraídos do código QR do documento.

### **Espaços em branco**

#### **A regra dos 100 por cento**

![](https://lh7-us.googleusercontent.com/TwNA3gZrgzhSvZrZOGywGYz92fRkUtjIsr6sDCxEzYgWcfJ9kXuzJKkqNiFyp3H5XXoqUz76TzZ72r86YY\_O3Vw\_rvDKczD\_hdMOIQOFWORr2bo8pGunrAtUklJ1ye7KEQJEjRNqNUNCnXM0boIICUA)

Para criar o espaço acima, é necessário utilizar um elemento «Label» de forma específica. O Gestor de Layouts atribui 100 unidades a cada linha: cada unidade corresponde a 1% da largura. Assim, a soma das larguras dos campos numa linha não pode exceder 100.

![](https://lh7-us.googleusercontent.com/YTqddzVQPWRuP5ylV6NnMc-KnEgCY0ZxZ8zn0In5d5dOxaWnwGDi4N2qohbobLNphLfVD61sMUE5QlmXJZ3e0tP7Y8no\_wVRy9WTF0nWIN5Tg3t-zLJhs9M-kVYPFV3CyerRZZoK-iMXLmKGcuSY\_Nw)

Construa o layout linha a linha de acordo com esta regra. Por exemplo, para colocar os campos «Name» e «Date» na mesma linha, arraste dois elementos Text e atribua-lhes esses nomes.

![](https://lh7-us.googleusercontent.com/2ru3pj0iD3V6ADqYBjeQPqDT3uvTH\_Al2MV0gpUUQ9MpX0TSFtnjYL6JN0YOkBk9afx2q2YcMo4gWE2jItUAGSEfX79O\_6sFgKwP5FGa98SwzgjGgee1G-2aO6NyqZusf27SbJoWoHmzu51Hx25kVmM)

Inicialmente, ambos têm largura 33, o valor padrão dos campos adicionados por arrastar e largar. Para que «Name» seja mais largo e ambos preencham a linha, distribua os 100% entre eles. Neste exemplo, defina 70 para «Name» e 30 para «Date». O resultado é:

![](https://lh7-us.googleusercontent.com/m411QblkCfsQWllhX74QpANjuVEv3fgM1Nhg8cJjbkNQGcjym6v0JFHIrKyMOAu-MasQ4KH9ZPaxmqNWfhWmAuL6SOZE030NXebb7ERzYxF99hLJC6oGbM-YXp7bNdZuoTaPmsDt7EjpV5BOiflwA4g)

A mesma regra aplica-se a todos os campos do Construtor de Layouts.

#### **Criar espaços em branco**

Para criar um espaço em branco, utilize um elemento «Label» dos elementos de formulário, respeitando a regra anterior.

Por exemplo, suponha que pretende criar um espaço entre estes dois campos.

![](https://lh7-us.googleusercontent.com/jOms6aTB3wCmX3L-MiUTrOb\_-q3AiFC3Y75TsHJe8QFLru10H9aZKzbE5MfHPZ0v9fqycQeddNPJp7pnRjv17crkrYUymNA8u9bF-3u9IfR6ru\_duavqrLCQocommljzLA00RXs\_lQA4gDH6l\_QvyTs)

Arraste um elemento «Label» para o espaço entre os campos. Selecione-o para abrir as propriedades à esquerda. Remova o texto da propriedade «Label», tal como faria ao alterar o nome de um campo.

![](https://lh7-us.googleusercontent.com/0Mma4wYIIfAkOyRIFLZtjug7pbWltfaiPm3r\_WgbP5fCgKe2BGD6Qf5YJ5Ns7fBBTRfJ68NlOtmOQrvcOvjyWGxk9v\_XmDj-8moEQhcDUugh\_VO5DdrJLYYV08ftr8YdhuhEM0otWs\_ljew18j7XJFQ)

O resultado será:

![](https://lh7-us.googleusercontent.com/-HqoJUAbcHRCletgSg6gcKXpn6zto1Do8I5EmcEmPWL4qUrMREh-wZdhy7ZKtnbuGjypd7p2mjcIu6LbbfdjA3c1liT2reCQXWiP1VAji08eWc\_bbF\_a0Dd82rJRgCuD5yjdlXL\_DNheMcw-fm6pQnA)

Passa a existir um espaço entre os campos. Pode aumentar ou reduzir a sua largura segundo a regra dos 100 por cento para construir o layout pretendido.
