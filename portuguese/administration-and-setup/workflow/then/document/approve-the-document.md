# Approve the Document



<figure><img src="../../../../.gitbook/assets/image (281).png" alt="" width="563"><figcaption></figcaption></figure>

## **Propósito:**

O cartão de fluxo de trabalho **"Approve the Document"** é utilizado para marcar um documento como aprovado. Permite que o documento avance para a fase seguinte do fluxo de trabalho, possibilitando a execução de fluxos de processamento ou aprovação automatizados. Este cartão ajuda a simplificar os processos de gestão de documentos, assegurando que apenas os documentos aprovados avançam para ações adicionais.

## **Componentes do cartão:**

1. **Approval Status**
   * **Descrição**: Este componente marca o documento como aprovado.
   * **Detalhe**: Quando este cartão é acionado, o estado de aprovação do documento é atualizado para indicar a aprovação. Esta ação pode ser definida com base nas condições definidas nas secções **"Where"** e **"And Sections."**

## **Funcionalidade:**

* **Avaliação da condição**: O sistema avalia as condições definidas nas secções **"Where"** e **"And Sections"**.
  * Se **ambas as condições forem verdadeiras**, o documento será marcado como aprovado.
  * Se **alguma das condições for falsa**, o cartão não será executado e o estado de aprovação do documento permanecerá inalterado.
* **Execução da ação**: Quando as condições são cumpridas, o documento é aprovado. Esta alteração reflete-se no estado do documento, permitindo-lhe continuar no fluxo de trabalho.

## **Conclusão:**

O cartão de fluxo de trabalho **"Approve the Document"** é um componente fundamental para automatizar a aprovação de documentos nos fluxos de trabalho de negócio. Ao assegurar que apenas os documentos que cumprem critérios específicos são aprovados, ajuda a manter a consistência, reduz a supervisão manual e permite um processamento de documentos mais fluido.
