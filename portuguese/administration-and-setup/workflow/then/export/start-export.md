# Start Export

<figure><img src="../../../../.gitbook/assets/image (285).png" alt="" width="563"><figcaption></figcaption></figure>

## **Propósito:**

O cartão de fluxo de trabalho **"Start Export"** foi concebido para iniciar o processo de exportação de um documento. Este cartão funciona como um gatilho dentro do fluxo de trabalho para iniciar de forma transparente a operação de exportação assim que as condições das secções anteriores forem cumpridas.

## **Componentes do cartão:**

1. **Action**
   1. **Descrição**: Inicia o processo de exportação do documento.
   2. **Detalhe**: O cartão utiliza as definições de exportação configuradas no sistema para processar e exportar o documento.

## **Funcionalidade:**

* **Avaliação da condição**: O sistema avalia as condições definidas nas secções **"Where"** e **"And Sections"** do fluxo de trabalho. Se todas as condições forem verdadeiras, o processo de exportação começa.
* **Exportação do documento**: O documento é processado e exportado utilizando a configuração de exportação predefinida ou previamente definida.

## **Configuração:**

Este cartão não requer uma configuração específica, uma vez que utiliza as definições de exportação já definidas no sistema. Os utilizadores precisam de assegurar que:

1. As condições das secções **"Where"** e **"And Sections"** estão configuradas corretamente, uma vez que o cartão só é executado se estas condições forem avaliadas como verdadeiras.
2. Está associada ao documento uma configuração de exportação válida no sistema.

## **Conclusão:**

O cartão de fluxo de trabalho **"Start Export"** oferece uma forma simplificada e automatizada de acionar o processo de exportação. Ao basear-se em definições pré-configuradas e em avaliações condicionais, assegura um processamento de documentos eficiente e preciso.
