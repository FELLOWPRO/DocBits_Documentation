# Carrossel de Vídeos

Uma pequena área no Painel de Preparação que reproduz dicas curtas sobre funcionalidades do DocBits — coisas úteis para experimentar, lugares onde talvez você não tenha olhado.

## Onde encontrar

O Carrossel de Vídeos aparece no Painel de Preparação enquanto os documentos estão sendo importados. Em telas amplas, fica à direita da barra de progresso. Em telas pequenas, fica oculto.

## Como usar

As dicas tocam uma após a outra com uma breve legenda abaixo. Clique nos pontos sob o vídeo para saltar para uma dica específica. Não há som — leia a legenda para saber sobre o que é cada dica.
