# Pesquisa Rápida Global

A Pesquisa Rápida Global é um lançador acessível pelo teclado que encontra páginas, configurações, painéis e funcionalidades dentro das páginas a partir de qualquer lugar do DocBits. Substitui a navegação pela barra lateral quando já sabe para onde quer ir.

## Como acessar

Pressione <kbd>Cmd</kbd> + <kbd>K</kbd> no macOS ou <kbd>Ctrl</kbd> + <kbd>K</kbd> no Windows e Linux. O atalho funciona em qualquer tela.

## Pesquisando

Comece a digitar para filtrar o catálogo de páginas e funcionalidades. A Pesquisa Rápida usa correspondência aproximada, então palavras parciais e pequenos erros de digitação ainda encontram a entrada correta. Os oito melhores resultados são exibidos por ordem de relevância.

Cada resultado mostra:

* O nome da funcionalidade ou página.
* A categoria à qual pertence (Configurações, Painel, Validação e assim por diante).
* Uma pequena etiqueta indicando o tipo de entrada — Página, Diálogo, Barra lateral, Painel, Menu ou Ação.

Use as teclas de seta para cima e para baixo para destacar um resultado e pressione <kbd>Enter</kbd> para abri-lo. Pressione <kbd>Esc</kbd> para fechar a janela.

<mark>Apenas as entradas para as quais você tem permissão aparecem na lista de resultados. Entradas restritas a administradores ficam ocultas para outros usuários.</mark>

## Pesquisas recentes

Quando o campo de pesquisa está vazio, a Pesquisa Rápida exibe suas cinco pesquisas mais recentes para você voltar a destinos comuns com um único toque. As pesquisas recentes são salvas por navegador e não são sincronizadas entre dispositivos.

## Modo seletor para documentos

Alguns destinos precisam de informações adicionais — por exemplo "Abrir documento por ID" precisa do identificador antes de navegar. Quando escolhe esse tipo de entrada, a Pesquisa Rápida muda para o **modo seletor**:

* Para identificadores de documento, digite ou cole o ID e pressione <kbd>Enter</kbd>.
* Para tipos de documento, escolha o tipo na lista incorporada.

O modo seletor respeita as permissões de status do painel, portanto só vê os documentos que tem permissão para abrir.

## Ver todos os resultados

Se os oito resultados visíveis não forem suficientes, clique no link **Ver todos os resultados** no rodapé para abrir o [Mapa do Site](sitemap.md) pré-filtrado com sua pesquisa atual.

## Referência de teclado

| Tecla | Ação |
|---|---|
| <kbd>Cmd</kbd>/<kbd>Ctrl</kbd> + <kbd>K</kbd> | Abrir a Pesquisa Rápida de qualquer lugar |
| <kbd>↑</kbd> / <kbd>↓</kbd> | Mover entre os resultados |
| <kbd>Enter</kbd> | Abrir o resultado destacado |
| <kbd>Esc</kbd> | Fechar a janela |
