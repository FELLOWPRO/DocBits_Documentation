# Painel de Pedidos de Envio

Esta seção oferece uma visão detalhada de todos os pedidos de envio. Inclui uma barra de pesquisa com vários filtros que você pode selecionar para rapidamente restringir seus resultados. Além disso, você pode personalizar a disposição dos cabeçalhos das colunas usando a funcionalidade de arrastar e soltar para uma experiência de visualização mais personalizada.

## Vídeo: pesquisar envios e verificar os seus dados

Neste vídeo em português, um administrador pesquisa uma linha de exemplo pelo ID do artigo, compara as referências da encomenda e da entrega e verifica a quantidade enviada, o estado e o armazém. Depois limpa a pesquisa e volta a carregar a lista.

{% embed url="https://docbits-videos.fra1.cdn.digitaloceanspaces.com/settings-assistant/shipment-order-search-admin/v1/pt.mp4" %}
Demonstração em português com um administrador sintético e a verdadeira interface de teste do DocBits.
{% endembed %}

[Abrir o vídeo com legendas em português e transcrição](https://docbits-videos.fra1.cdn.digitaloceanspaces.com/settings-assistant/shipment-order-search-admin/v1/pt.html).

As três linhas contêm dados fictícios criados para esta demonstração. A pesquisa por **DEMO-INSERT-40** mostra a entrega **DEMO-9F2416-DL-102**, a referência de encomenda **DEMO-9F2416-PO-202**, a quantidade enviada **600** e o armazém **DEMO-WH-9F2416**. Os estados provêm dos dados de exemplo importados. A quantidade enviada, por si só, não confirma a receção completa. O vídeo demonstra a pesquisa e verificação de dados de envio existentes; não cria um ASN, não abre uma encomenda de compra associada nem regista uma receção de mercadorias.
