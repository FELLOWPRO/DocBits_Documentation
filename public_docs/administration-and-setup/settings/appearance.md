# Appearance

**Appearance** 让管理员为组织的 DocBits 赋予自己的外观：颜色、圆角、密度和字体。组织内所有人在下次重新加载后都能看到结果——浅色和深色模式均是如此。它从不改变布局或功能的行为，只改变绘制方式。

> **访问：** Appearance 是仅限管理员的页面。打开 **Settings → Organization & Access → Appearance**。

<!-- screenshot: /settings/appearance light -->

## 谁可以更改

只有组织管理员可以打开 **Settings → Appearance** 并保存或重置主题。组织内的其他成员只能看到结果。

## 页面内容

页面分为左侧的编辑器和右侧的实时预览。

| 区域 | 包含内容 |
|---|---|
| **General** | 主题名称、字体、圆角和密度。 |
| **Colors** | Light 和 Dark 选项卡，每种颜色一个取色器加一个十六进制字段，分为 Surfaces、Brand、Neutrals、Status 和 Charts 几组。下方只读的「Derived colours」面板显示 DocBits 根据上方颜色为您计算出的颜色（悬停状态、焦点环等）。 |
| **Advanced overrides** | 每个条目一行 `--token: value`，用于上方颜色、圆角、密度和字体控件无法覆盖的少见情况——参见 [Advanced overrides](#advanced-overrides)。 |

### 更改颜色

每种颜色都有一个色块（点击可打开浏览器的取色器），旁边有一个十六进制字段，可直接输入或粘贴。将颜色留空即可保留该 token 的 DocBits 默认值——此时色块显示虚线边框。通过颜色列表上方的 **Light** / **Dark** 选项卡切换另一模式；在深色模式下未设置的颜色会保留其自身的 DocBits 深色默认值，而不会复制浅色值。

{% hint style="info" %}
颜色以十六进制输入（`#2388ae` 或带 alpha 的 `#2388aeaa`）。不支持颜色名称或 `rgb()` 输入。
{% endhint %}

### 圆角、密度和字体

* **Corner radius** — `None`、`Small`、`Medium`（默认）、`Large` 或 `Extra large`。控制整个应用中卡片、按钮、输入框和对话框的圆角程度。
* **Density** — `Compact`、`Comfortable`（默认）或 `Spacious`。控制按钮、输入框和表格行的高度，以及基础文字大小。
* **Font** — 一小部分内置字体列表（Geist 是 DocBits 默认字体；还有 Inter、Roboto、IBM Plex Sans、Source Sans 3、Nunito Sans、Manrope、Kanit，或访问者自己的系统字体）。所有字体都已内置，无需上传任何内容。

### Advanced overrides

对于上方控件没有直接提供的设计 token（例如特定的表格行高），在 **Advanced overrides** 下添加一行：

```
--table-row-h: 30px
```

每行一个覆盖，格式为 `--token: value`。无效的行——未知 token、无法自定义的 token，或与该 token 期望不匹配的值——会在输入框下方列为错误并且不会被应用；页面上的其他内容仍会正常保存。

## 预览

您的每次更改都会立即更新右侧的 **Preview** 面板，不会影响其他人看到的内容——它从不触及运行中的应用或已保存的主题。预览有自己的选项卡：先是一个同时显示浅色和深色的总览，然后是按钮、表单字段、表面和状态指示器的专门页面，以便您在界面对颜色最敏感的部分检查对比度和可读性。

<!-- screenshot: /settings/appearance dark -->

如果某项更改使主题无效（见下文），预览会继续显示最后一个有效版本，而不会出错。

## 保存与重置

* **Save** 为整个组织写入主题。只有当确实有更改且主题有效时才会启用。
* **Reset** 会请求确认，然后完全移除组织的主题，让所有人回到 DocBits 默认主题。此操作无法从页面撤销——如果组织想恢复这些颜色，必须手动重新输入（或重新导入，见下文）。
* 保存或重置失败时（例如出现校验问题），会在编辑器上方列出问题，页面保持不变；不会应用任何内容。

保存前没有对比度检查——参见下方的[提示](#提示)。

## 导出与导入

* **Export** 将编辑器中当前显示的主题（无论是否已保存）下载为 `.json` 文件，文件名取自主题名称。
* **Import** 读取 `.json` 主题文件并加载到编辑器中。仍需审阅并保存才能生效——仅导入不会改变任何人看到的内容。无效或过大的文件（超过 32 KB）会被拒绝并报错，不会发生任何更改。

导出是在试验前备份主题的便捷方式，也可用于将一个组织的外观复制到另一个组织。

## 用户看到的内容

保存后，主题会应用于整个应用——每个页面、浅色和深色模式——对组织的每位成员生效，但在他们下次重新加载后（不会立即影响其他已打开的会话）。从未加载过该组织的用户会看到 DocBits 默认外观，直到组织设置加载过一次，之后主题生效。

重置会让所有人在下次重新加载后回到 DocBits 默认外观，就好像从未设置过组织主题一样。

## 提示

* **在两种模式下都检查对比度。** 编辑器不会警告低对比度组合（例如浅色品牌色配浅色文字）。保存前使用预览的浅色和深色面板检查文字是否仍然可读。
* **除非有理由，否则不要更改状态颜色。** Destructive（错误）、success、warning 和 info 在整个应用中保持其含义——更改它们可能让错误一眼看去像是成功。请只更改品牌色，并将状态色保留为默认值，除非组织需要的颜色超出常规的红/绿/琥珀/蓝。
* **从完整调色板开始。** 导出当前主题或从 DocBits 默认值开始，可以为每个基础颜色提供可编辑的值，而不必猜测存在哪些 token。
* **主题更改会让组织内每个用户在下次重新加载时立即看到。** 没有只向部分用户预览的步骤；在告诉团队已经完成之前，请自己分别在浅色和深色下测试结果。
