# 案例 6：数量在容差内，单价低于允许下限（已拒绝）

以下场景用于说明一种已配置的映射，并不代表已核实部署的默认模板。实际输出、金额、正负号和文档类型取决于当前生效的 `conflict_resolution` 规则与表达式、导出映射及审批决定。下文提到的借项通知单或贷项通知单均以这些配置为前提；示例不保证自动开具，也不保证符合法律要求。

## 场景

数量在容差范围内，但发票单价低于允许范围，且该价格偏差未获审批。

## 示例操作

如果映射配置为在拒绝偏差后使用 PO 价格，则会保留数量，并将发票单价替换为 PO 单价。差额是否产生调整、借项通知单、贷项通知单，或不产生单独文档，取决于生效的映射及审批决定。额外的表头费用仅在明确配置时适用。

## 示例

* **采购订单（PO）：**
  * 数量：100 件
  * 单价：每件 $10.00
  * 总金额：$1,000.00
* **收到的发票：**
  * 数量：100 件——实际数量偏差为 0%，在已配置的 ±2% 容差内。
  * 单价：$9.00——实际价格偏差为 -10%，超出已配置的 ±1% 容差；偏差已拒绝。
  * 总金额：$900.00
* **已配置的容差：**
  * 数量：±2%
  * 单价：±1%

在此示例映射中：

1. 拒绝发票上的 $9.00 单价，因为价格偏差超出容差且未获审批。
2. 使用 PO 单价 $10.00。
3. 重新计算示例总金额：**100 件 × $10.00 = $1,000.00**。
4. 按“发票总金额减去重新计算的总金额”计算带正负号的差额：**$900.00 - $1,000.00 = -$100.00**。
5. 应用已配置的导出映射及审批结果。-$100.00 是带正负号的差额，并非无条件开具贷项通知单的指令。任何调整的金额、正负号及文档类型均由映射决定。

不要将此示例理解为贷项通知单会自动冲销少收金额。使用该规则前，请在生效的导出映射中确认预期的会计处理方式。
