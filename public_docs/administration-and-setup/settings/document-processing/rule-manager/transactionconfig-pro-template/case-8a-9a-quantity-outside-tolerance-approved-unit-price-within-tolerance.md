# 案例 8a、9a：数量超出容差（已批准），单价在容差范围内

以下场景用于说明一种已配置的映射，并不代表已核实部署的默认模板。实际输出、金额、正负号和文档类型取决于当前生效的 `conflict_resolution` 规则与表达式、导出映射及审批决定。下文提到的借项通知单或贷项通知单均以这些配置为前提；示例不保证自动开具，也不保证符合法律要求。

## 场景：

发票上的数量超出了可接受的容差范围，但已获批准；单价仍在容差范围内。

## 操作：

系统接受已批准的数量和发票上的单价，并据此处理交易。

## 示例：

* **采购订单 (PO)：**
  * 数量：150 件
  * 单价：每件 $12.00
  * 总金额：$1,800.00
* **收到的发票：**
  * 数量：160 件（超出 6.67% 的容差，但已获批准）
  * 单价：每件 $12.00（在容差范围内）
  * 总金额：$1,920.00
* **容差级别：**
  * 数量容差：±5%
  * 单价容差：±2%

由于数量（160 件）超出了可接受的容差上限，但已获批准；而单价（$12.00）在可接受范围内，系统将：

1. **接受已批准的数量：**系统确认该数量已获批准，尽管它超出了常规容差范围。
2. **接受单价：**每件 $12.00 的单价在可接受的容差范围内，因此按发票所列单价接受。
3. **处理交易：**系统使用已批准的数量和单价计算总金额：
   * **总金额 = 数量 × 单价**
   * **总金额 = 160 件 × 每件 $12.00 = $1,920.00**
4. **完成发票处理：**系统按总金额 $1,920.00 处理发票，该金额反映了已批准的数量和接受的单价。

这种处理方式允许系统接受已批准的数量差异，同时确保单价保持在预期范围内，从而顺利处理交易。
