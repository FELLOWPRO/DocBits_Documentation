# 激活或停用文档类型

管理员可以选择组织可使用哪些文档类型。您可以在 **文档类型** 页面更改此设置，而无需删除该类型或其配置。

1. 打开 **Settings → Document Types**。
2. 在 **默认文档类型** 或 **自定义文档类型** 下找到该文档类型，例如 **发票**。
3. 使用该类型卡片上的 **激活** 开关。彩色开关表示该类型已激活；灰色开关表示该类型未激活。离开页面前，请等待确认消息。此开关没有单独的 Save 按钮。

<figure><img src="../../../../.gitbook/assets/prior-t019-zh.png" alt="文档类型及启用选项。 “Standard”和“Extraction”仍是当前界面保留的英文标签。"><figcaption><p>文档类型及启用选项。 “Standard”和“Extraction”仍是当前界面保留的英文标签。</p></figcaption></figure>

**激活** 旁边的 **提取** 开关是另一项设置，用于选择提取模式（Flex 或 Fix）；它不会激活或停用文档类型。齿轮图标可打开该类型的更多设置。类型名称下方的链接可打开其布局、字段、表格、脚本和其他可用配置区域。

DocBits 提供无法删除的默认文档类型。您也可以创建和管理自定义类型。有关后续设置步骤，请参阅[添加和编辑文档类型](adding-editing-document-types.md)；有关配置提取的行项目，请参阅[表格列](table-columns/README.md)。
