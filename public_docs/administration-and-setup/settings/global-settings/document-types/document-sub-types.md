# Podtypy dokumentów

Podtypy rozróżniają kategorie w obrębie typu dokumentu. Otwórz typy dokumentów w ustawieniach i wybierz łącze do podtypów właściwego typu.

<figure><img src="../../../../.gitbook/assets/s150-docbits_document_sub_types_overview-pl.png" alt="Przegląd podtypów dokumentów. Nagłówek Name pozostaje w języku angielskim."><figcaption><p>Przegląd podtypów dokumentów. Nagłówek Name pozostaje w języku angielskim.</p></figcaption></figure>

Lista pokazuje skonfigurowane podtypy. Niektóre nagłówki kolumn produktu mogą pozostać w języku angielskim.

<figure><img src="../../../../.gitbook/assets/s150-docbits_document_sub_types_list-pl.png" alt="Lista podtypów dokumentów w ustawieniach. Nagłówek Name pozostaje w języku angielskim."><figcaption><p>Lista podtypów dokumentów w ustawieniach. Nagłówek Name pozostaje w języku angielskim.</p></figcaption></figure>

Przy tworzeniu podtypu sprawdź nazwę i konfigurację przed zapisaniem. Przykłady przedstawiają przegląd i listę; nie potwierdzają utworzenia podtypu ani zapisania ustawień.
