# 复制自定义验证规则

当某条规则适合作为起点，而你希望单独创建一个副本时，请使用 **复制**。DocBits 会复制该规则的定义；新规则的名称和键由你选择。原规则仍会保留在列表中。

1. 前往 **Settings → Document Types**，打开要配置的文档类型，然后选择 **自定义验证规则**。页面会在规则卡片上方显示所选文档类型。有关此处其他可用设置，请参阅[文档类型](README.md)。
2. 找到源规则。如果列表较长，可使用搜索框或范围和状态筛选器。打开该规则的三点操作菜单，然后选择 **复制**。系统默认规则和自定义规则都可以复制。
3. 在 **规则名称** 中保留建议名称末尾的“Copy”，或输入更清晰的名称。系统会根据名称生成 **规则键**。如果需要自行编辑键，请选择铅笔图标。
4. 选择 **复制** 创建单独的规则。保存后，DocBits 会刷新列表。选择 **取消** 可关闭对话框而不创建副本。

**复制** 按钮需要同时填写名称和键。如果保存失败，DocBits 会显示错误；请更正名称或键，然后重试。激活或更改新规则前，请先检查该规则，因为副本会沿用源规则的定义。
