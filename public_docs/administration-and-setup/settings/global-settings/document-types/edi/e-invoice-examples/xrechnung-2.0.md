# XRechnung 2.0

Questi esempi storici mostrano la fattura nei sistemi di destinazione esterni. Consulta il [riepilogo ufficiale delle versioni di XRechnung](https://xeinkauf.de/xrechnung/versionen-und-bundles/) e verifica le versioni supportate dal destinatario e dalla tua installazione. La lingua delle interfacce ERP e IDM esterne illustrate è indipendente dalla lingua dell’interfaccia DocBits.
