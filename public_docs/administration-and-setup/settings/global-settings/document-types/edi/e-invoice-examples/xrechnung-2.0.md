# XRechnung 2.0

Te historyczne przykłady pokazują fakturę w zewnętrznych systemach docelowych. Sprawdź [oficjalny wykaz wersji XRechnung](https://xeinkauf.de/xrechnung/versionen-und-bundles/) oraz wersje obsługiwane przez odbiorcę i swoją instalację. Język przedstawionych zewnętrznych interfejsów ERP i IDM jest niezależny od języka interfejsu DocBits.
