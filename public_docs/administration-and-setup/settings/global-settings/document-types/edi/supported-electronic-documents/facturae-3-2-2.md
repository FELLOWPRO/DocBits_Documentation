# 🇪🇸 FACTURAE 3.2.2

<!-- edocs-country-scope -->

{% hint style="info" %}
Die Länderanleitung enthält Versionsgrenzen, die tatsächlich verwendete Konfiguration und das Erklärvideo zum Land. [Spanien](countries/spain.md). Prüfen Sie den Namespace und die Schemaversion. | Eigenschaft | Wert |
| ----------- | ---- |
| **Land / Region** | Spanien |
| **Dokumenttypen** | Rechnung, Gutschrift, Berichtigungsrechnung |

Facturae 3.2.2 ist die aktuellste Version des spanischen E-Rechnungsstandards. Sie enthält eine aktualisierte Steuerbehandlung für die Kompatibilität mit SII (Suministro Inmediato de Información) und eine verbesserte Unterstützung für Berichtigungsrechnungen.
