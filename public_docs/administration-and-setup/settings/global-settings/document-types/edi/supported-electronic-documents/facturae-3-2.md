# 🇪🇸 FACTURAE 3.2

| Propriedade | Valor |
| --- | --- |
| **País / Região** | Espanha |
| **Tipos de documento** | Fatura, nota de crédito, fatura retificativa |
| **Formato** | XML |
| **Padrão** | Facturae 3.2 |

O Facturae 3.2 é uma versão amplamente utilizada do padrão espanhol de fatura eletrônica. Ele define a estrutura XML das faturas eletrônicas, incluindo a identificação de vendedor/comprador, itens de linha, detalhes de impostos (IVA) e requisitos de assinatura digital.
