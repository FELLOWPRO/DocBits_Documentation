# 🇪🇸 FACTURAE

<!-- edocs-country-scope -->

{% hint style="info" %}
Consultate la guida del paese per i limiti delle versioni, la configurazione effettivamente utilizzata e il video esplicativo del paese. [Spagna](countries/spain.md). Verificate lo spazio dei nomi e la versione dello schema. L’estrazione di un file XML firmato non verifica, di per sé, la firma o l’accettazione da parte di FACe.
{% endhint %}

| Proprietà             | Valore                                   |
| --------------------- | ---------------------------------------- |
| **Paese / Regione**   | Spagna                                   |
| **Tipi di documento** | Fattura, nota di credito, fattura rettificativa |
| **Formato**           | XML                                      |
| **Standard**          | Facturae                                 |

Facturae è lo standard spagnolo di fatturazione elettronica obbligatorio per le transazioni B2G tramite il portale FACe (Punto General de Entrada de Facturas Electrónicas). DocBits supporta le versioni 3.2, 3.2.1 e 3.2.2 dello standard.

## Stato del supporto

| Componente           | Stato         |
| -------------------- | ------------- |
| Anteprima            | ✅ Supportato |
| Estrazione dei campi | ✅ Supportato |
| Trasformazione       | ✅ Supportato |
