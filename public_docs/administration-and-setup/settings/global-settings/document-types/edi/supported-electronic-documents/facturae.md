# 🇪🇸 FACTURAE

<!-- edocs-country-scope -->

{% hint style="info" %}
Raadpleeg de landengids voor versiebeperkingen, de daadwerkelijk gebruikte configuratie en de uitlegvideo voor het land. [Spanje](countries/spain.md). Controleer de naamruimte en schemaversie. Gegevensextractie uit een ondertekend XML-bestand verifieert op zichzelf niet de handtekening of acceptatie door FACe.
{% endhint %}

| Eigenschap | Waarde |
|------------|--------|
| **Land / Regio** | Spanje |
| **Documenttypen** | Factuur, Creditnota, Correctiefactuur |
| **Formaat** | XML |
| **Standaard** | Facturae |

Facturae is de Spaanse standaard voor elektronische facturering, verplicht voor B2G-transacties via het FACe-portaal (Punto General de Entrada de Facturas Electrónicas). DocBits ondersteunt de versies 3.2, 3.2.1 en 3.2.2 van de standaard.
