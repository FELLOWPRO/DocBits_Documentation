# 🇫🇮 FINVOICE 1.3

<!-- edocs-country-scope -->

{% hint style="info" %}

| Propriedade | Valor |
| --- | --- |
| **País / Região** | Finlândia |
| **Tipos de documento** | Fatura |
| **Formato** | XML (envelope SOAP) |
| **Padrão** | Finvoice 1.3 |

O Finvoice 1.3 é uma versão anterior do padrão finlandês de fatura eletrônica, mantido pela Finance Finland. Ele usa um envelope de mensagem SOAP e define um formato XML estruturado para o faturamento B2B entre bancos finlandeses e seus clientes corporativos.
