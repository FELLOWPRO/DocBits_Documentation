# 🇫🇮 FINVOICE 2.0

<!-- edocs-country-scope -->

{% hint style="info" %}
Sprawdź w przewodniku krajowym ograniczenia wersji, faktycznie używaną konfigurację i film objaśniający dla kraju. [Finlandia](countries/finland.md). Sprawdź wersję źródłową przed wybraniem mapowania. Oznaczenie TEAPPSXML nie podaje wydania.
{% endhint %}

| Właściwość           | Wartość                       |
| -------------------- | ----------------------------- |
| **Kraj / Region**    | Finlandia                     |
| **Typy dokumentów**  | Faktura, Nota kredytowa       |
| **Format**           | XML (koperta SOAP)            |
| **Standard**         | Finvoice 2.0                  |

Finvoice 2.0 rozszerzył standard o lepszą obsługę warunków płatności, szczegółów dostawy i raportowania VAT w UE. Zachował model transportu oparty na SOAP, stosowany w fińskich sieciach bankowych.
