# 🇮🇩 INDONESIA E-FAKTUR

<!-- edocs-country-scope -->

{% hint style="info" %}

| Eigenschaft | Wert |
| ----------- | ---- |
| **Land / Region** | Indonesien |
| **Dokumenttypen** | Steuerrechnung (Faktur Pajak) |
| **Format** | XML/CSV |
| **Standard** | e-Faktur (DJP - Direktorat Jenderal Pajak) |

e-Faktur ist das indonesische elektronische Steuerrechnungssystem der Steuerbehörde (Directorate General of Taxes, DJP). Es ist für alle PKP-Steuerpflichtigen (Pengusaha Kena Pajak) verpflichtend und umfasst die Seriennummer NSFP (Nomor Seri Faktur Pajak), die Steuerkennungen NPWP sowie PPN-Berechnungen (Umsatzsteuer).
