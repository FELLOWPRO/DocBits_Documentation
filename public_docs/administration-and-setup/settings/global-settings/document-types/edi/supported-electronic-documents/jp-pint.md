# 🇯🇵 JP PINT

<!-- edocs-country-scope -->

{% hint style="info" %}
Raadpleeg de landengids voor versiebeperkingen, de daadwerkelijk gebruikte configuratie en de uitlegvideo voor het land. [Japan](countries/japan.md). Selfbilling is een variant van een bedrijfsproces, geen taalkeuze. Controleer de aanpassingsidentificatie en de geconfigureerde variant.
{% endhint %}

| Eigenschap | Waarde |
|------------|--------|
| **Land / Regio** | Japan |
| **Documenttypen** | Factuur |
| **Formaat** | UBL 2.1 XML |
| **Standaard** | JP PINT (Peppol International Model for Japan) |

JP PINT is de Japanse implementatie van het Peppol International (PINT) factuurmodel. Het past de wereldwijde Peppol-standaard aan op de Japanse zakelijke vereisten, waaronder ondersteuning voor het Qualified Invoice System (適格請求書) dat is ingevoerd onder de herziene Consumption Tax Act.
