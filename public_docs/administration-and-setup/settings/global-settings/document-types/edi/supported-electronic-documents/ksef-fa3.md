# 🇵🇱 KSEF FA3

<!-- edocs-country-scope -->

{% hint style="info" %}
Consultate la guida del paese per i limiti delle versioni, la configurazione effettivamente utilizzata e il video esplicativo del paese. [Polonia](countries/poland.md). FA2 e FA3 usano strutture diverse. Confermate lo schema sorgente e provate la mappatura appropriata; l’analisi del file non invia una fattura a KSeF.
{% endhint %}

| Proprietà             | Valore                      |
| --------------------- | --------------------------- |
| **Paese / Regione**   | Polonia                     |
| **Tipi di documento** | Invoice, Corrective Invoice |
| **Formato**           | XML                         |
| **Standard**          | KSeF FA(3)                  |

KSeF FA3 è l'ultima versione dello schema del Sistema nazionale polacco di fatturazione elettronica. Aggiunge il supporto per ulteriori tipi di documento, una gestione migliorata delle fatture rettificative e regole di convalida aggiornate in linea con le più recenti disposizioni polacche in materia di IVA.

## Stato del supporto
