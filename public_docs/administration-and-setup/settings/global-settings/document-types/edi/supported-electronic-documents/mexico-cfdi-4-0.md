# 🇲🇽 MEXICO CFDI 4.0

<!-- edocs-country-scope -->

{% hint style="info" %}
Die Länderanleitung enthält Versionsgrenzen, die tatsächlich verwendete Konfiguration und das Erklärvideo zum Land. [Mexiko](countries/mexico.md). Prüfen Sie Namespace, Version und TipoDeComprobante. Ein negativer Betrag allein identifiziert keine Gutschrift. Das Einlesen bestätigt keine Freigabe durch SAT.
{% endhint %}

| Eigenschaft          | Wert                                               |
| -------------------- | -------------------------------------------------- |
| **Land / Region**    | Mexiko                                             |
| **Dokumenttypen**    | Rechnung, Gutschrift, Zahlungsbeleg                |
| **Format**           | XML                                                |
| **Standard**         | CFDI 4.0 (Comprobante Fiscal Digital por Internet) |

CFDI 4.0 ist die aktuelle Version des mexikanischen Standards für digitale Steuerbelege und seit Januar 2023 verpflichtend. Sie verlangt den Namen und das Steuerregime (régimen fiscal) des Empfängers, ergänzt das Exportfeld und enthält das aktualisierte digitale Siegel sowie die SAT-Zertifikatskette.
