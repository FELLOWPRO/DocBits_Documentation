# 🇩🇰 OIOUBL 2.1

<!-- edocs-country-scope -->

{% hint style="info" %}
Raadpleeg de landengids voor versiebeperkingen, de daadwerkelijk gebruikte configuratie en de uitlegvideo voor het land. [Denemarken](countries/denmark.md). OIOUBL en Peppol BIS zijn verschillende profielen. Alleen UBL-syntaxis identificeert het nationale profiel niet.
{% endhint %}

| Eigenschap           | Waarde                                         |
| -------------------- | ---------------------------------------------- |
| **Land / Regio**     | Denemarken                                     |
| **Documenttypen**    | Factuur, Creditnota, Aanmaning, Rekeningoverzicht |
| **Formaat**          | UBL 2.1 XML                                    |
| **Standaard**        | OIOUBL 2.1                                     |

OIOUBL 2.1 is de huidige versie van de Deense e-factureringsstandaard. Gebaseerd op OASIS UBL 2.1 breidt deze de internationale standaard uit met Deense bedrijfsregels en codelijsten die door de Deense overheid worden vereist.
