# 🇩🇰 OIOUBL 2.1

<!-- edocs-country-scope -->

{% hint style="info" %}
Consulte la guía del país para conocer los límites de versión, la configuración que se está utilizando y el vídeo explicativo del país. [Dinamarca](countries/denmark.md). OIOUBL y Peppol BIS son perfiles distintos. La sintaxis UBL por sí sola no identifica el perfil nacional.
{% endhint %}

| Propiedad              | Valor                                              |
| ---------------------- | -------------------------------------------------- |
| **País / Región**      | Dinamarca                                          |
| **Tipos de documento** | Factura, Nota de crédito, Recordatorio, Extracto   |
| **Formato**            | UBL 2.1 XML                                        |
| **Estándar**           | OIOUBL 2.1                                         |

OIOUBL 2.1 es la versión actual del estándar danés de facturación electrónica. Basado en OASIS UBL 2.1, amplía el estándar internacional con reglas de negocio y listas de códigos específicas de Dinamarca, exigidas por el sector público danés.

## Estado de compatibilidad

| Componente             | Estado          |
| ---------------------- | --------------- |
| Vista previa           | ✅ Compatible    |
| Extracción de campos   | ✅ Compatible    |
| Transformación         | ✅ Compatible    |
