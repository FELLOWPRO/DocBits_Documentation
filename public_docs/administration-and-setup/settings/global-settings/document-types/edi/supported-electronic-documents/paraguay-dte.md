# 🇵🇾 PARAGUAY DTE

<!-- edocs-country-scope -->

{% hint style="info" %}
Consultate la guida del paese per i limiti delle versioni, la configurazione effettivamente utilizzata e il video esplicativo del paese. [Paraguay](countries/paraguay.md). Le voci di classificazione delle note di credito non hanno insiemi di componenti di estrazione dedicati nello stato esaminato. Verificate la mappatura effettivamente utilizzata e non considerate le etichette intercambiabili.
{% endhint %}

| Proprietà             | Valore                                 |
| --------------------- | -------------------------------------- |
| **Paese / Regione**   | Paraguay                               |
| **Tipi di documento** | Invoice, Credit Note                   |
| **Formato**           | XML                                    |
| **Standard**          | DTE (Documento Tributario Electrónico) |

Paraguay DTE è lo standard paraguaiano di documento fiscale elettronico, regolamentato dalla Subsecretaría de Estado de Tributación (SET). Copre le fatture elettroniche e le note di credito con i requisiti paraguaiani di identificazione fiscale (RUC) e di categoria fiscale.
