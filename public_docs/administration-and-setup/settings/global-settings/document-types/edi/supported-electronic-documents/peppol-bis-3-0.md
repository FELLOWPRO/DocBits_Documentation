# 🇪🇺 PEPPOL BIS 3.0

<!-- edocs-country-scope -->

{% hint style="info" %}
请参阅国家指南，了解版本限制、实际生效的配置和国家说明视频。 [国际](countries/international.md). 发票、订单、响应和发货映射相互独立。文件处理本身不提供 Peppol 接入点，也不提供与贸易伙伴的连接。

| 属性                 | 值                                             |
| -------------------- | ---------------------------------------------- |
| **国家 / 地区**      | 欧盟 / 国际（40 多个国家）                      |

| **格式**             | UBL 2.1 XML                                    |
| **标准**             | Peppol BIS Billing 3.0                         |

Peppol BIS Billing 3.0 是泛欧电子发票标准，在 Peppol 网络中广泛使用。它基于 OASIS UBL 2.1，并实施了电子发票欧洲标准 EN 16931。通过经过认证的接入点，Peppol 支持 40 多个国家/地区之间的跨境企业对企业（B2B）和企业对政府（B2G）发票交换。
