# 🇵🇪 秘鲁 CPE

<!-- edocs-country-scope -->

{% hint style="info" %}
请参阅国家指南，了解版本限制、实际生效的配置和国家说明视频。 [秘鲁](countries/peru.md). 请选择实际的 UBL 版本和文档结构。成功处理文件不代表已被 SUNAT 接受。
{% endhint %}

| 属性                 | 值                                   |
| -------------------- | ------------------------------------- |
| **国家 / 地区**      | 秘鲁                                  |
| **文档类型**         | 发票、贷项通知单、借项通知单          |
| **格式**             | UBL XML                               |
| **标准**             | CPE（Comprobante de Pago Electrónico） |

CPE（Comprobante de Pago Electrónico）是秘鲁的电子支付凭证标准，由 SUNAT 监管。DocBits 支持秘鲁电子发票使用的 UBL 2.0 和 2.1 版本。

| 转换         | ✅ 支持     |
