# 🇵🇪 PERU CPE

<!-- edocs-country-scope -->

{% hint style="info" %}
Consultez le guide du pays pour connaître les limites de version, la configuration effectivement utilisée et la vidéo explicative du pays. [Pérou](countries/peru.md). Sélectionnez la version UBL et la structure réelles du document. Le traitement d’un fichier ne prouve pas son acceptation par la SUNAT.
{% endhint %}

| Propriété | Valeur |
| --------- | ------ |
| **Pays / Région** | Pérou |
| **Types de documents** | Facture, Note de crédit, Note de débit |
| **Format** | XML UBL |
| **Norme** | CPE (Comprobante de Pago Electrónico) |

CPE (Comprobante de Pago Electrónico) est la norme péruvienne de justificatif de paiement électronique, réglementée par la SUNAT. DocBits prend en charge les versions UBL 2.0 et 2.1 utilisées pour la facturation électronique au Pérou.

## Statut de prise en charge

| Composant | Statut |
| --------- | ------ |
| Aperçu | ✅ Pris en charge |
| Extraction des champs | ✅ Pris en charge |
| Transformation | ✅ Pris en charge |
