# 🇵🇭 菲律宾 EIS

请参阅国家指南，了解版本限制、实际生效的配置和国家说明视频。 [菲律宾](countries/philippines.md). 该名称未指明发布版本。在依赖通用 EIS 名称之前，请检查数据载荷架构和适用的文档类型。

| 属性                 | 值                                      |
| -------------------- | --------------------------------------- |
| **国家 / 地区**      | 菲律宾                                  |
| **文档类型**         | 发票、正式收据                          |
| **格式**             | XML/JSON                                |
| **标准**             | EIS（电子发票系统 - BIR）               |

菲律宾 EIS 是菲律宾国内税务局（BIR）推出的电子发票系统。该系统旨在推动菲律宾企业的发票和收据数字化，要求将销售数据以电子方式传输至 BIR 系统，以便进行税务合规监控。
