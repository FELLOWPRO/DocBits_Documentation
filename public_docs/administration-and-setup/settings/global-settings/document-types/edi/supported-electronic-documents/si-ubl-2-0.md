# 🇳🇱 SI-UBL 2.0

<!-- edocs-country-scope -->

{% hint style="info" %}
Consultez le guide du pays pour connaître les limites de version, la configuration effectivement utilisée et la vidéo explicative du pays. [Pays-Bas](countries/netherlands.md). Un fichier UBL n’est pas automatiquement SI-UBL 2.0. Vérifiez son identifiant de personnalisation et la correspondance nationale associée.
{% endhint %}

| Propriété | Valeur |
| --------- | ------ |
| **Pays / Région** | Pays-Bas |
| **Types de documents** | Facture, Note de crédit |
| **Format** | XML UBL 2.1 |
| **Norme** | SI-UBL 2.0 (Standaard Invoice - UBL) |

SI-UBL 2.0 est la norme néerlandaise de facturation électronique fondée sur OASIS UBL 2.1. Elle est maintenue par le NLCIUS (Netherlands Core Invoice Usage Specification) et s'aligne sur EN 16931. SI-UBL est largement utilisée dans les transactions B2G et B2B néerlandaises, notamment via le réseau Peppol.
