# 🇫🇮 TEAPPSXML

<!-- edocs-country-scope -->

{% hint style="info" %}
Raadpleeg de landengids voor versiebeperkingen, de daadwerkelijk gebruikte configuratie en de uitlegvideo voor het land. [Finland](countries/finland.md). Controleer de bronversie voordat u een toewijzing kiest. Het TEAPPSXML-label vermeldt geen versie.
{% endhint %}

| Eigenschap | Waarde |
| ---------- | ------ |
| **Land / Regio** | Finland |
| **Documenttypen** | Factuur, Creditnota |
| **Formaat** | XML |
| **Standaard** | TEAPPSXML 3.0 |

TEAPPSXML is een Fins e-factuurformaat dat door Tieto (nu TietoEVRY) wordt gebruikt voor de uitwisseling van facturen. Het wordt op de Finse markt vaak naast Finvoice gebruikt, met name door organisaties die werken met op Tieto gebaseerde ERP- en financiële systemen.
