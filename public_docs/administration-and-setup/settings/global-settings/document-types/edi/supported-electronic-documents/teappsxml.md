# 🇫🇮 TEAPPSXML

<!-- edocs-country-scope -->

{% hint style="info" %}
Consulte la guía del país para conocer los límites de versión, la configuración que se está utilizando y el vídeo explicativo del país. [Finlandia](countries/finland.md). Compruebe la versión del archivo de origen antes de elegir una asignación. La etiqueta TEAPPSXML no indica una versión de publicación.
{% endhint %}

| Propiedad              | Valor                    |
| ---------------------- | ------------------------ |
| **País / Región**      | Finlandia                |
| **Tipos de documento** | Factura, Nota de crédito |
| **Formato**            | XML                      |
| **Estándar**           | TEAPPSXML 3.0            |

TEAPPSXML es un formato finlandés de facturación electrónica utilizado por Tieto (ahora TietoEVRY) para el intercambio de facturas. Se utiliza habitualmente junto con Finvoice en el mercado finlandés, en particular por organizaciones que emplean sistemas ERP y financieros basados en Tieto.
