# 🇹🇷 TURKEY E-FATURA

<!-- edocs-country-scope -->

{% hint style="info" %}
Consultate la guida del paese per i limiti delle versioni, la configurazione effettivamente utilizzata e il video esplicativo del paese. [Turchia](countries/turkey.md). Verificate il profilo sorgente e la struttura del documento. L’etichetta della famiglia non identifica ogni versione UBL-TR né dimostra la consegna tramite la piattaforma fiscale.
{% endhint %}

| Proprietà             | Valore                                  |
| --------------------- | --------------------------------------- |
| **Paese / Regione**   | Turchia                                 |
| **Tipi di documento** | Fattura, Nota di credito                |
| **Formato**           | UBL-TR 1.2 XML                          |
| **Standard**          | e-Fatura (GİB - Revenue Administration) |

Turkey e-Fatura è il principale standard di fattura elettronica imposto dalla GİB (Revenue Administration) per le transazioni B2B tra contribuenti registrati. Le fatture vengono scambiate tramite integratori registrati e la piattaforma GİB. Il formato utilizza UBL-TR, la versione localizzata di UBL per la Turchia, con campi specifici turchi per l'identificazione fiscale TCKN/VKN.
