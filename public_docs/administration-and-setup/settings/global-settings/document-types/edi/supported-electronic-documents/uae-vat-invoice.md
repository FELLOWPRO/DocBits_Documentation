# 🇦🇪 UAE VAT INVOICE

<!-- edocs-country-scope -->

{% hint style="info" %}
Sprawdź w przewodniku krajowym ograniczenia wersji, faktycznie używaną konfigurację i film objaśniający dla kraju. [Zjednoczone Emiraty Arabskie](countries/united-arab-emirates.md). Mapowanie faktury VAT nie potwierdza obsługi każdego wydania UAE Peppol lub PINT. Potwierdź kontrakt danych i wymaganą integrację dostarczania.
{% endhint %}

| Właściwość | Wartość |
| ---------- | ------- |
| **Kraj/Region** | Zjednoczone Emiraty Arabskie |
| **Typy dokumentów** | Faktura podatkowa, Uproszczona faktura podatkowa |
| **Format** | XML/JSON |
| **Standard** | FTA VAT Invoice (Federal Tax Authority) |

UAE VAT Invoice to format faktury elektronicznej zgodny z wymogami Federal Tax Authority (FTA). Chociaż Zjednoczone Emiraty Arabskie nie wprowadziły jeszcze obowiązkowego formatu e-fakturowania, DocBits obsługuje przetwarzanie ustrukturyzowanych faktur VAT zgodnych z przepisami FTA dotyczącymi VAT, w tym identyfikację numerem TRN (Tax Registration Number) i naliczanie VAT według stawki 5%.
