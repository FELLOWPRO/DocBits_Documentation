# UBL 2.1

<!-- edocs-country-scope -->

{% hint style="info" %}
Consultez le guide du pays pour connaître les limites de version, la configuration effectivement utilisée et la vidéo explicative du pays. [International](countries/international.md). Les correspondances de facture, de commande, de réponse et d’expédition sont distinctes. Le traitement des fichiers ne fournit pas, à lui seul, de point d’accès Peppol ni de connexion aux partenaires commerciaux.
{% endhint %}

| Propriété              | Valeur                                                          |
| ---------------------- | --------------------------------------------------------------- |
| **Pays / Région**      | International                                                   |
| **Types de documents** | Facture, Note de crédit, Commande, Avis d'expédition            |
| **Format**             | UBL 2.1 XML                                                     |
| **Norme**              | OASIS UBL 2.1 (Universal Business Language)                     |

UBL 2.1 (Universal Business Language) est la norme ouverte OASIS pour les documents commerciaux. Il sert de base à de nombreuses normes nationales de facturation électronique, dont Peppol BIS, XRechnung (variante UBL), OIOUBL et SI-UBL. DocBits traite les factures UBL 2.1 génériques qui ne correspondent à aucune norme propre à un pays.
