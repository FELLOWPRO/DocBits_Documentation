# UBL 2.1

<!-- edocs-country-scope -->

{% hint style="info" %}
Consulte o guia do país para conhecer os limites das versões, a configuração efetiva e o vídeo explicativo. [Internacional](countries/international.md). Os mapeamentos de faturas, encomendas, respostas e expedições são distintos. O processamento de ficheiros, por si só, não disponibiliza um ponto de acesso Peppol nem conectividade com parceiros comerciais.
{% endhint %}

| Propriedade          | Valor                                                    |
| -------------------- | -------------------------------------------------------- |
| **País / Região**    | Internacional                                            |
| **Tipos de documento** | Fatura, Nota de crédito, Pedido, Aviso de expedição    |
| **Formato**          | UBL 2.1 XML                                              |
| **Padrão**           | OASIS UBL 2.1 (Universal Business Language)              |

O UBL 2.1 (Universal Business Language) é o padrão aberto da OASIS para documentos comerciais. Serve de base para muitos padrões nacionais de faturamento eletrônico, incluindo Peppol BIS, XRechnung (variante UBL), OIOUBL e SI-UBL. O DocBits processa faturas UBL 2.1 genéricas que não correspondem a nenhum padrão específico de um país.
