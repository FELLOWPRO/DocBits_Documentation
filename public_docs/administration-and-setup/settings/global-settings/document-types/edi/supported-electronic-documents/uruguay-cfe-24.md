# 🇺🇾 URUGUAY CFE 24

<!-- edocs-country-scope -->

{% hint style="info" %}
Consulte la guía del país para conocer los límites de versión, la configuración que se está utilizando y el vídeo explicativo del país. [Uruguay](countries/uruguay.md). Las entradas de notas de crédito carecen de paquetes de extracción dedicados en el estado inspeccionado. Confirme la versión CFE y la asignación de factura o nota de crédito utilizada.

| Propiedad            | Valor                  |
| -------------------- | ---------------------- |
| **País / Región**    | Uruguay                |
| **Tipos de documento** | e-Factura, Nota de crédito |
| **Formato**          | XML                    |
| **Estándar**         | CFE, versión de esquema 24 |

Uruguay CFE 24 hace referencia a la versión 24 del esquema del sistema CFE uruguayo. Esta versión es utilizada por muchos documentos electrónicos existentes e incluye todos los campos necesarios para el cumplimiento de la DGI, incluido el CAE (Código de Autorización Electrónico).

## Estado de soporte

| Componente           | Estado        |
| -------------------- | ------------- |
| Vista previa         | ✅ Compatible |
| Extracción de campos | ✅ Compatible |
| Transformación       | ✅ Compatible |
