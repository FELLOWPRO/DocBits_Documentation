# 🇺🇾 URUGUAY CFE

<!-- edocs-country-scope -->

{% hint style="info" %}
Die Länderanleitung enthält Versionsgrenzen, die tatsächlich verwendete Konfiguration und das Erklärvideo zum Land. [Uruguay](countries/uruguay.md). Für Gutschrifteinträge sind im geprüften Status keine eigenen Extraktionspakete ausgewiesen. Bestätigen Sie die CFE-Version und die tatsächlich verwendete Rechnungs- oder Gutschriftzuordnung.
{% endhint %}

| Eigenschaft | Wert |
| ----------- | ---- |
| **Land / Region** | Uruguay |
| **Dokumenttypen** | e-Rechnung, e-Ticket, Gutschrift, Belastungsanzeige |
| **Format** | XML |
| **Standard** | CFE (Comprobante Fiscal Electrónico) |

CFE (Comprobante Fiscal Electrónico) ist der uruguayische Standard für elektronische Steuerdokumente, der von der DGI (Dirección General Impositiva) reguliert wird. Er deckt mehrere Dokumenttypen ab, darunter e-Factura (111), e-Ticket (101) sowie deren Gutschrifts- und Belastungsvarianten.
