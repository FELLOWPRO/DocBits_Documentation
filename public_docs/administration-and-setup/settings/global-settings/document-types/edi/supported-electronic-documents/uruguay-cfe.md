# 🇺🇾 URUGUAY CFE

<!-- edocs-country-scope -->

{% hint style="info" %}
Consulte la guía del país para conocer los límites de versión, la configuración que se está utilizando y el vídeo explicativo del país. [Uruguay](countries/uruguay.md). Las entradas de notas de crédito carecen de paquetes de extracción dedicados en el estado inspeccionado. Confirme la versión CFE y la asignación de factura o nota de crédito utilizada.
{% endhint %}

| Propiedad            | Valor                                        |
| -------------------- | -------------------------------------------- |
| **País / Región**    | Uruguay                                      |
| **Tipos de documento** | e-Factura, e-Ticket, Nota de crédito, Nota de débito |
| **Formato**          | XML                                          |
| **Estándar**         | CFE (Comprobante Fiscal Electrónico)         |

CFE (Comprobante Fiscal Electrónico) es el estándar uruguayo de documento tributario electrónico, regulado por la DGI (Dirección General Impositiva). Abarca varios tipos de documento, entre ellos e-Factura (111), e-Ticket (101) y sus variantes de nota de crédito y de débito.
