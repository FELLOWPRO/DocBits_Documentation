# 🇺🇾 URUGUAY E-FACTURA

<!-- edocs-country-scope -->

{% hint style="info" %}
Consultez le guide du pays pour connaître les limites de version, la configuration effectivement utilisée et la vidéo explicative du pays. [Uruguay](countries/uruguay.md). Les entrées d’avoir n’ont pas d’ensembles d’extraction dédiés dans l’état examiné. Confirmez la version CFE et la correspondance de facture ou d’avoir effectivement utilisée.
{% endhint %}

| Propriété              | Valeur                    |
| ---------------------- | ------------------------- |
| **Pays / Région**      | Uruguay                   |
| **Types de documents** | e-Facture (e-Factura)     |
| **Format**             | XML                       |
| **Norme**              | e-Factura (CFE Type 111)  |

Uruguay e-Factura est le type de document de facture électronique du système CFE, identifié par le code de type 111. Il est utilisé pour les transactions B2B formelles entre entités enregistrées au RUT et comprend tous les champs d'identification fiscale et de calcul requis par la DGI.
