# 🇺🇾 URUGUAY E-NOTA CREDITO

<!-- edocs-country-scope -->

{% hint style="info" %}
Consulte la guía del país para conocer los límites de versión, la configuración que se está utilizando y el vídeo explicativo del país. [Uruguay](countries/uruguay.md). Las entradas de notas de crédito carecen de paquetes de extracción dedicados en el estado inspeccionado. Confirme la versión CFE y la asignación de factura o nota de crédito utilizada.
{% endhint %}

| Propiedad            | Valor                            |
| -------------------- | -------------------------------- |
| **País / Región**    | Uruguay                          |
| **Tipos de documento** | Nota de crédito (e-Nota de Crédito) |
| **Formato**          | XML                              |
| **Estándar**         | e-Nota de Crédito (CFE tipo 112) |

Uruguay e-Nota de Crédito es el tipo de documento de nota de crédito electrónica dentro del sistema CFE, identificado con el código de tipo 112. Se utiliza para ajustar o anular e-Facturas emitidas previamente y debe hacer referencia al documento original.
