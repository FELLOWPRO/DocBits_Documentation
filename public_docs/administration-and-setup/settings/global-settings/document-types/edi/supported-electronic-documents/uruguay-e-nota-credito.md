# 🇺🇾 URUGUAY E-NOTA CREDITO

<!-- edocs-country-scope -->

{% hint style="info" %}
Raadpleeg de landengids voor versiebeperkingen, de daadwerkelijk gebruikte configuratie en de uitlegvideo voor het land. [Uruguay](countries/uruguay.md). Creditnotavermeldingen hebben in de onderzochte status geen eigen extractiebundels. Bevestig de CFE-versie en de daadwerkelijk gebruikte toewijzing voor facturen of creditnota’s.
{% endhint %}

| Eigenschap | Waarde |
| ---------- | ------ |
| **Land / Regio** | Uruguay |
| **Documenttypen** | Creditnota (e-Nota de Crédito) |
| **Formaat** | XML |
| **Standaard** | e-Nota de Crédito (CFE-type 112) |

Uruguay e-Nota de Crédito is het elektronische creditnotadocumenttype binnen het CFE-systeem, geïdentificeerd door typecode 112. Het wordt gebruikt om eerder uitgegeven e-Facturas te corrigeren of te annuleren en moet verwijzen naar het oorspronkelijke document.
