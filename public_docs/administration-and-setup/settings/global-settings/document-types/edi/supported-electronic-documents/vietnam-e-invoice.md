# 🇻🇳 越南电子发票

<!-- edocs-country-scope -->

{% hint style="info" %}
请参阅国家指南，了解版本限制、实际生效的配置和国家说明视频。 [越南](countries/vietnam.md). 该名称未指明发布版本。请检查原始命名空间和架构，不要假定所有税务平台导出文件都具有相同结构。
{% endhint %}

| 属性 | 值 |
| -------------------- | ----------------------------------------------------- |
| **国家 / 地区** | 越南 |
| **文档类型** | 发票 |
| **格式** | XML |
| **标准** | 越南电子发票（税务总局） |

越南电子发票是税务总局根据第 123/2020 号法令和第 78/2021 号通知规定的电子开票标准。越南所有企业都必须使用电子发票，并将其传输至税务机关系统进行验证。每张发票都包含一个唯一的验证码。
