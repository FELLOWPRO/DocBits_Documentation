# 🇩🇪 XRECHNUNG 3.0.2 CII

<!-- edocs-country-scope -->

{% hint style="info" %}
请参阅国家指南，了解版本限制、实际生效的配置和国家说明视频。 [德国](countries/germany.md). 语法、发布版本和业务规范是不同的选择。不要根据共用的 1p0 标记推断 Factur-X 发布版本。
{% endhint %}

| 属性                   | 值                                         |
| ---------------------- | ------------------------------------------ |
| **国家/地区**           | 德国                                       |
| **文档类型**            | 发票、贷项通知单                            |
| **格式**                | CII                                        |
| **标准**                | XRechnung 3.0.2                            |
| **基于**                | EN 16931（UN/CEFACT 跨行业发票）            |

XRechnung 3.0.2 是德国电子发票标准的当前版本，与最新的 EN 16931 更新保持一致。该维护版本更新了业务规则和 Schematron 验证，以改进符合性测试。
