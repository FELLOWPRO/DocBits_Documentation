# 🇸🇦 ZATCA FATOORAH

<!-- edocs-country-scope -->

{% hint style="info" %}
Consultez le guide du pays pour connaître les limites de version, la configuration effectivement utilisée et la vidéo explicative du pays. [Arabie saoudite](countries/saudi-arabia.md). | Propriété              | Valeur                                                    |
| ---------------------- | --------------------------------------------------------- |
| **Pays / Région**      | Saudi Arabia                                              |
| **Types de documents** | Invoice (Fatoorah)                                        |
| **Format**             | UBL 2.1 XML                                               |
| **Norme**              | ZATCA FATOORAH (ZATCA - Zakat, Tax and Customs Authority) |

ZATCA Fatoorah est la norme saoudienne de facturation électronique, exploitée par la Zakat, Tax and Customs Authority. La phase 1 (génération) est obligatoire depuis décembre 2022, et la phase 2 (intégration) exige une déclaration en temps réel à la plateforme ZATCA. Fatoorah est le format de facture fiscale standard utilisé pour les transactions B2B supérieures à 1 000 SAR.
