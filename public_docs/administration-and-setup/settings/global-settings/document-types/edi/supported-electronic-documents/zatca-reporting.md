# 🇸🇦 ZATCA REPORTING

<!-- edocs-country-scope -->

{% hint style="info" %}
Consultate la guida del paese per i limiti delle versioni, la configurazione effettivamente utilizzata e il video esplicativo del paese. [Arabia Saudita](countries/saudi-arabia.md). Queste etichette descrivono processi e varianti di fattura diversi. L’analisi del file non dimostra la firma, l’autorizzazione fiscale o la comunicazione tramite ZATCA.
{% endhint %}

| Proprietà               | Valore                                |
| ----------------------- | ------------------------------------- |
| **Paese / Regione**     | Arabia Saudita                        |
| **Tipi di documento**   | Fattura comunicata                    |
| **Formato**             | XML UBL 2.1                           |
| **Standard**            | ZATCA Reporting (Integrazione Fase 2) |

ZATCA Reporting indica la modalità di integrazione della Fase 2, in cui le fatture fiscali standard vengono comunicate alla piattaforma ZATCA entro 24 ore dall'emissione. La fattura comunicata include un sigillo crittografico, un codice QR e un UUID assegnato dal portale Fatoorah di ZATCA.
