# 🇸🇦 ZATCA SIMPLIFIED

<!-- edocs-country-scope -->

{% hint style="info" %}
Consultate la guida del paese per i limiti delle versioni, la configurazione effettivamente utilizzata e il video esplicativo del paese. [Arabia Saudita](countries/saudi-arabia.md). Queste etichette descrivono processi e varianti di fattura diversi. L’analisi del file non dimostra la firma, l’autorizzazione fiscale o la comunicazione tramite ZATCA.
{% endhint %}

| Proprietà               | Valore                       |
| ----------------------- | ---------------------------- |
| **Paese / Regione**     | Arabia Saudita               |
| **Tipi di documento**   | Fattura fiscale semplificata |
| **Formato**             | XML UBL 2.1                  |
| **Standard**            | ZATCA Simplified Tax Invoice |

ZATCA Simplified Tax Invoice viene utilizzata per le transazioni B2C in Arabia Saudita il cui importo totale (IVA inclusa) non supera 1.000 SAR. A differenza delle fatture fiscali standard, le fatture semplificate non richiedono l'identificazione dell'acquirente, ma devono includere un codice QR con i dati del venditore codificati in TLV, l'importo dell'IVA e il timestamp.
