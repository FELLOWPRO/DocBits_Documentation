# 🇩🇪 ZUGFERD 1.0 BASIC

<!-- edocs-country-scope -->

{% hint style="info" %}
Sprawdź w przewodniku krajowym ograniczenia wersji, faktycznie używaną konfigurację i film objaśniający dla kraju. [Niemcy](countries/germany.md). Składnia, wersja publikacji i profil to różne wybory. Nie wnioskuj o publikacji Factur-X na podstawie wspólnego znacznika 1p0.
{% endhint %}

| Właściwość           | Wartość                    |
| -------------------- | -------------------------- |
| **Kraj/Region**      | Niemcy                     |
| **Typy dokumentów**  | Faktura, Nota kredytowa    |
| **Format**           | CII (osadzony w PDF/A-3)   |
| **Standard**         | ZUGFeRD 1.0, profil Basic  |
| **Oparty na**        | Specyfikacja ZUGFeRD 1.0   |

Profil Basic standardu ZUGFeRD 1.0 zawiera podstawowe pola faktury, takie jak numer faktury, data, sprzedawca/nabywca, pozycje oraz sumy podatkowe. Dostarcza wystarczająco dużo ustrukturyzowanych danych do automatycznego księgowania w większości systemów ERP.
