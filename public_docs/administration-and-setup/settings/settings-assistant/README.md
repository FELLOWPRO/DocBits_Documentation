# Dokumentation mit dem Settings Assistant finden

Der Settings Assistant hilft Ihnen, die richtige DocBits-Hilfeseite zu finden, während Sie in **Settings** arbeiten. Sie können nach der Seite fragen, die Sie gerade sehen, oder nach einer anderen Einstellung. Seine Antworten können Links auf die passende Dokumentation enthalten, damit Sie die vollständigen Anweisungen selbst prüfen können.

{% hint style="info" %}
Der Assistent erscheint nur, wenn er für Ihre Organisation aktiviert wurde. Wenn Sie ihn nicht sehen, fragen Sie Ihren DocBits-Administrator.
{% endhint %}

## Nach einer Einstellung fragen

1. Öffnen Sie **Settings** und gehen Sie in den Bereich, für den Sie Hilfe brauchen.
2. Ist der Assistent ausgeblendet, wählen Sie **Show Assistant** in der Seitenleiste der Einstellungen.
3. Wählen Sie eine der vorgeschlagenen Fragen für die aktuelle Seite oder schreiben Sie Ihre eigene Frage in das Nachrichtenfeld und senden Sie sie. Zum Beispiel: „Wo kann ich die Validierungsregeln für Rechnungen ändern?“
4. Lesen Sie die Antwort und öffnen Sie ihren Dokumentationslink für das vollständige Vorgehen. Eine verlinkte Seite kann Screenshots und weitere Schritte enthalten.

Wenn Sie bereits chatten, fragt **Help with this page** nach der aktuell geöffneten Einstellungsseite. Sie können zu einer anderen Einstellungsseite wechseln und die Funktion erneut nutzen, ohne eine neue Unterhaltung zu beginnen. Schließen Sie das Panel mit seiner Schließen-Schaltfläche oder <kbd>Esc</kbd>, wenn Sie mehr Platz brauchen.

## Eine hilfreiche Antwort bekommen

Nennen Sie die Einstellung oder die Aufgabe, die Sie abschließen möchten. Zum Beispiel:

* „Wie füge ich dieser Organisation einen Benutzer hinzu?“
* „Wo konfiguriere ich den E-Mail-Import für Rechnungen?“
* „Was ändert diese Dokumenttyp-Einstellung?“

Hat eine Antwort keine brauchbare Quelle, versuchen Sie eine genauere Frage oder suchen Sie direkt in der [DocBits Documentation](https://docs.docbits.com). Für Hilfe mit der Konfiguration Ihrer Organisation wenden Sie sich an Ihren Administrator oder an den DocBits-Support.

Der Assistent durchsucht **öffentliche DocBits-Hilfeseiten**. Er durchsucht nicht die in Ihrer Organisation hochgeladenen Rechnungen oder andere Geschäftsdokumente. Für deren Suche siehe [Fulltext Search](../document-processing/module/fulltext-search.md).

Mehr dazu, [wie die Dokumentationssuche aktuell bleibt](documentation-search.md).
