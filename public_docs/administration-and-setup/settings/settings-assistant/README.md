# Trouver la documentation avec le Settings Assistant

Le Settings Assistant vous aide à trouver la bonne page d'aide DocBits pendant que vous travaillez dans **Settings**. Vous pouvez poser une question sur la page que vous consultez ou sur un autre paramètre. Ses réponses peuvent contenir des liens vers la documentation pertinente, afin que vous puissiez vérifier vous-même les instructions complètes.

{% hint style="info" %}
L'assistant n'apparaît que s'il a été activé pour votre organisation. Si vous ne le voyez pas, demandez à votre administrateur DocBits.
{% endhint %}

## Poser une question sur un paramètre

1. Ouvrez **Settings** et allez dans la zone pour laquelle vous avez besoin d'aide.
2. Si l'assistant est masqué, sélectionnez **Show Assistant** dans la barre latérale des paramètres.
3. Sélectionnez l'une des questions suggérées pour la page actuelle, ou saisissez votre propre question dans le champ de message et envoyez-la. Par exemple : « Où puis-je modifier les règles de validation des factures ? »
4. Lisez la réponse et ouvrez son lien de documentation pour la procédure complète. Une page liée peut contenir des captures d'écran et des étapes associées.

Si vous êtes déjà en conversation, **Help with this page** porte sur la page de paramètres actuellement ouverte. Vous pouvez passer à une autre page de paramètres et le réutiliser sans commencer une nouvelle conversation. Fermez le panneau avec son contrôle de fermeture ou <kbd>Esc</kbd> lorsque vous avez besoin de plus de place.

## Obtenir une réponse utile

Mentionnez le paramètre ou la tâche que vous voulez accomplir. Par exemple :

* « Comment ajouter un utilisateur à cette organisation ? »
* « Où configurer l'import d'e-mails pour les factures ? »
* « Qu'est-ce que ce paramètre de type de document change ? »

Si une réponse n'a pas de source utile, essayez une question plus précise ou recherchez directement dans la [DocBits Documentation](https://docs.docbits.com). Pour de l'aide sur la configuration de votre organisation, contactez votre administrateur ou le support DocBits.

L'assistant recherche dans les **pages d'aide publiques de DocBits**. Il ne recherche pas dans les factures ou autres documents métier téléversés par votre organisation. Pour ces recherches, voir [Fulltext Search](../document-processing/module/fulltext-search.md).

En savoir plus sur [la manière dont la recherche dans la documentation reste à jour](documentation-search.md).
