# 通过 Settings Assistant 查找文档

Settings Assistant 会在您使用 **Settings** 时帮助您找到正确的 DocBits 帮助页面。您可以询问当前正在查看的页面，也可以询问其他设置。它的回答可以包含指向相关文档的链接，方便您自行核对完整说明。

{% hint style="info" %}
只有当助手已为您的组织启用时才会出现。如果没有显示，请询问您的 DocBits 管理员。
{% endhint %}

## 询问某项设置

1. 打开 **Settings**，进入需要帮助的区域。
2. 如果助手已隐藏，请在设置侧边栏中选择 **Show Assistant**。
3. 选择当前页面的一个建议问题，或在消息字段中输入您自己的问题并发送。例如：「我在哪里可以更改发票校验规则？」
4. 阅读回答，并打开其中的文档链接查看完整步骤。链接的页面可能包含截图和相关步骤。

如果您已经在对话中，**Help with this page** 询问的是当前打开的设置页面。您可以切换到另一个设置页面并再次使用，而无需开始新的对话。需要更多空间时，可用关闭控件或 <kbd>Esc</kbd> 关闭面板。

## 获得有用的回答

请说明您想完成的设置或任务。例如：

* 「如何向该组织添加用户？」
* 「我在哪里配置发票的电子邮件导入？」
* 「这个文档类型设置会改变什么？」

如果回答没有有用的来源，请尝试更具体的问题，或直接在 [DocBits Documentation](https://docs.docbits.com) 中搜索。如需组织配置方面的帮助，请联系您的管理员或 DocBits 支持。

助手搜索的是**公开的 DocBits 帮助页面**，不会搜索您组织上传的发票或其他业务文档。要搜索这些内容，请参见 [Fulltext Search](../document-processing/module/fulltext-search.md)。
