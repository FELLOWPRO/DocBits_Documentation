# Encontrar documentação com o Settings Assistant

O Settings Assistant ajuda-o a encontrar a página de ajuda do DocBits certa enquanto trabalha em **Settings**. Pode perguntar sobre a página que está a ver ou sobre outra definição. As respostas podem incluir ligações para a documentação relevante, para que possa verificar as instruções completas.

{% hint style="info" %}
O assistente só aparece quando foi ativado para a sua organização. Se não o vir, pergunte ao seu administrador do DocBits.
{% endhint %}

## Perguntar sobre uma definição

1. Abra **Settings** e vá à área para a qual precisa de ajuda.
2. Se o assistente estiver oculto, selecione **Show Assistant** na barra lateral das definições.
3. Selecione uma das perguntas sugeridas para a página atual ou escreva a sua própria pergunta no campo de mensagem e envie-a. Por exemplo: «Onde posso alterar as regras de validação das faturas?»
4. Leia a resposta e abra a respetiva ligação para a documentação, para ver o procedimento completo. Uma página ligada pode conter capturas de ecrã e passos relacionados.

Se já estiver numa conversa, **Help with this page** refere-se à página de definições aberta nesse momento. Pode passar para outra página de definições e utilizá-lo novamente sem iniciar uma nova conversa. Feche o painel com o respetivo controlo de fecho ou com <kbd>Esc</kbd> quando precisar de mais espaço.

## Obter uma resposta útil

Mencione a definição ou a tarefa que pretende concluir. Por exemplo:

* «Como adiciono um utilizador a esta organização?»
* «Onde configuro a importação de e-mail para faturas?»
* «O que altera esta definição do tipo de documento?»

Se uma resposta não tiver uma fonte útil, tente uma pergunta mais específica ou pesquise diretamente na [DocBits Documentation](https://docs.docbits.com). Para ajuda com a configuração da sua organização, contacte o seu administrador ou o suporte do DocBits.

O assistente pesquisa nas **páginas de ajuda públicas do DocBits**. Não pesquisa nas faturas nem noutros documentos de negócio carregados pela sua organização. Para pesquisar nesses, consulte [Fulltext Search](../document-processing/module/fulltext-search.md).

Saiba mais sobre [como a pesquisa na documentação se mantém atual](documentation-search.md).
