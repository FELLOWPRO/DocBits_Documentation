# Encontrar documentación con el Settings Assistant

El Settings Assistant le ayuda a encontrar la página de ayuda de DocBits adecuada mientras trabaja en **Settings**. Puede preguntar por la página que está viendo o por otra opción. Sus respuestas pueden incluir enlaces a la documentación relevante, para que pueda comprobar las instrucciones completas usted mismo.

{% hint style="info" %}
El asistente solo aparece cuando se ha activado para su organización. Si no lo ve, pregunte a su administrador de DocBits.
{% endhint %}

## Preguntar por una opción

1. Abra **Settings** y vaya al área en la que necesita ayuda.
2. Si el asistente está oculto, seleccione **Show Assistant** en la barra lateral de ajustes.
3. Seleccione una de las preguntas sugeridas para la página actual o escriba su propia pregunta en el campo de mensaje y envíela. Por ejemplo: «¿Dónde puedo cambiar las reglas de validación de facturas?».
4. Lea la respuesta y abra su enlace de documentación para ver el procedimiento completo. Una página enlazada puede contener capturas de pantalla y pasos relacionados.

Si ya está en una conversación, **Help with this page** pregunta por la página de ajustes abierta en ese momento. Puede pasar a otra página de ajustes y usarlo de nuevo sin iniciar una conversación nueva. Cierre el panel con su control de cierre o con <kbd>Esc</kbd> cuando necesite más espacio.

## Obtener una respuesta útil

Mencione la opción o la tarea que quiere completar. Por ejemplo:

* «¿Cómo añado un usuario a esta organización?»
* «¿Dónde configuro la importación de correo para facturas?»
* «¿Qué cambia esta opción del tipo de documento?»

Si una respuesta no tiene una fuente útil, pruebe una pregunta más concreta o busque directamente en la [DocBits Documentation](https://docs.docbits.com). Para ayuda con la configuración de su organización, contacte con su administrador o con el soporte de DocBits.

El asistente busca en **páginas de ayuda públicas de DocBits**. No busca en las facturas ni en otros documentos de negocio que haya subido su organización. Para buscarlos, consulte [Fulltext Search](../document-processing/module/fulltext-search.md).

Más información sobre [cómo se mantiene actualizada la búsqueda en la documentación](documentation-search.md).
