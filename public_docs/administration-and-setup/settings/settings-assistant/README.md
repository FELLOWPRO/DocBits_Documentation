# Znajdowanie dokumentacji za pomocą Settings Assistant

Settings Assistant pomaga znaleźć właściwą stronę pomocy DocBits podczas pracy w **Settings**. Możesz zapytać o stronę, którą widzisz, lub o inne ustawienie. Odpowiedzi mogą zawierać linki do odpowiedniej dokumentacji, abyś mógł samodzielnie sprawdzić pełne instrukcje.

{% hint style="info" %}
Asystent pojawia się tylko wtedy, gdy został włączony dla Twojej organizacji. Jeśli go nie widzisz, zapytaj administratora DocBits.
{% endhint %}

## Pytanie o ustawienie

1. Otwórz **Settings** i przejdź do obszaru, w którym potrzebujesz pomocy.
2. Jeśli asystent jest ukryty, wybierz **Show Assistant** na pasku bocznym ustawień.
3. Wybierz jedno z sugerowanych pytań dla bieżącej strony albo wpisz własne pytanie w polu wiadomości i wyślij je. Na przykład: „Gdzie mogę zmienić reguły walidacji faktur?”
4. Przeczytaj odpowiedź i otwórz jej link do dokumentacji, aby poznać pełną procedurę. Połączona strona może zawierać zrzuty ekranu i powiązane kroki.

Jeśli już prowadzisz rozmowę, **Help with this page** dotyczy aktualnie otwartej strony ustawień. Możesz przejść na inną stronę ustawień i użyć go ponownie bez rozpoczynania nowej rozmowy. Zamknij panel jego przyciskiem zamykania lub klawiszem <kbd>Esc</kbd>, gdy potrzebujesz więcej miejsca.

## Uzyskanie użytecznej odpowiedzi

Wskaż ustawienie lub zadanie, które chcesz wykonać. Na przykład:

* „Jak dodać użytkownika do tej organizacji?”
* „Gdzie skonfigurować import e-mail dla faktur?”
* „Co zmienia to ustawienie typu dokumentu?”

Jeśli odpowiedź nie ma użytecznego źródła, spróbuj bardziej szczegółowego pytania lub wyszukaj bezpośrednio w [DocBits Documentation](https://docs.docbits.com). Aby uzyskać pomoc dotyczącą konfiguracji organizacji, skontaktuj się z administratorem lub z pomocą techniczną DocBits.

Asystent przeszukuje **publiczne strony pomocy DocBits**. Nie przeszukuje faktur ani innych dokumentów biznesowych przesłanych przez Twoją organizację. Aby je przeszukiwać, zobacz [Fulltext Search](../document-processing/module/fulltext-search.md).

Więcej o tym, [jak wyszukiwanie w dokumentacji pozostaje aktualne](documentation-search.md).
