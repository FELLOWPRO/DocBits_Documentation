# 文档搜索的工作方式

Settings Assistant 会在 [docs.docbits.com](https://docs.docbits.com) 的公开页面中查找相关信息。结果可能包含页面标题、简短段落和指向来源页面的链接。需要完整说明或截图时，请打开该链接。

## 找到正确的页面

搜索同时使用词语匹配和语义匹配。当您的问题使用的词语与页面标题不同时，这会有帮助。助手还可能使用您当前正在查看的设置页面，使回答更相关。

如果语义搜索暂时不可用，文档搜索仍可使用词语匹配。带有设置名称的具体问题是最好的重试方式。

## 语言

文档搜索目前使用**英语**和**德语**帮助页面索引。当您的 DocBits 界面使用其他语言时，助手会回退到英语文档结果。链接的页面显示其自身语言；在执行步骤或比较截图之前，请先确认该语言。

## 更改何时可被搜索

当英语或德语文档的更改从文档仓库发布时，搜索索引会刷新。定期核对还会移除指向已不在文档导航中的页面的链接。新发布的页面可能需要一些时间才会出现在助手中。

### 管理员技术概览

已发布的帮助页面会被拆分为章节，并按每种受支持的语言存储在专用的 **OpenSearch documentation index** 中。该索引与组织上传文档所使用的索引相互独立。页面更改时，未更改的章节可以跳过，更改的章节会重新索引。已移除的页面会从文档索引中删除。

对于一个问题，服务会将关键词匹配与向量相似度结合起来，然后对最相关的段落排序。如果嵌入服务不可用，关键词搜索仍然可用。Settings Assistant 从该文档搜索中获取来源链接和简短段落；它不会为此目的读取组织的文档索引。

如果找不到页面，请直接在 [docs.docbits.com](https://docs.docbits.com) 中搜索，尝试更精确的问题，或联系 DocBits 支持。
