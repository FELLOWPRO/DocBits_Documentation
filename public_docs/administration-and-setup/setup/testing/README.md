# Testes

Verifique se o DocBits funciona da forma como a sua organização o configurou.

* O **[módulo Testing](testing-module/README.md)** (**Configurações → Testing**) executa verificações repetíveis no seu
  próprio navegador, manualmente, a partir de um assistente de IA ou da sua automação de testes, e mantém um registro de cada execução.
* Os guias abaixo descrevem verificações manuais de funcionalidades específicas depois de você configurá-las:
  [Correspondência de pedidos de compra](po-matching.md) e [Contabilidade automática](auto-accounting/README.md).
