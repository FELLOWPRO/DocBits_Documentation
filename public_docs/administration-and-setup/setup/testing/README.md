* Poniższe przewodniki opisują ręczne sprawdzanie konkretnych funkcji po ich skonfigurowaniu:
  [Dopasowanie zamówień zakupu](po-matching.md) i [Testowanie automatycznego rozliczania](auto-accounting/README.md).
