# Testen

Controleer of DocBits werkt zoals uw organisatie het heeft geconfigureerd.

* De **[Testing-module](testing-module/README.md)** (**Instellingen → Testing**) voert herhaalbare controles uit in uw
  eigen browser, handmatig, vanuit een AI-assistent of vanuit uw testautomatisering, en bewaart een logboek van elke run.
* De onderstaande handleidingen beschrijven handmatige controles van specifieke functies nadat u ze hebt ingesteld:
  [Inkoopordermatching](po-matching.md) en [Automatische boeking](auto-accounting/README.md).
