# 故障排查

## 在设置中找不到 Testing

只有组织管理员才能看到该页面。请联系贵组织的组织管理员。

## 页面提示 Testing 已关闭

组织管理员必须开启页面顶部的 **为组织启用 Testing**。
在此之前，任何测试都不会运行，AI 助手或外部发起的测试同样不会运行。

## 我的运行失败了

在 **日志** 标签页中打开日志，查看第一个失败的步骤及其错误代码：

| 您看到的内容 | 通常意味着 | 处理方法 |
|---|---|---|
| 未找到元素或元素不可见 | 页面在您的组织中的外观不同，或加载缓慢 | 亲自打开该页面进行检查；调整您自己的模板，或检查输入值 |
| 字段或状态不匹配 | 文档的值与输入所期望的不同 | 检查该文档；在输入中更正预期值 |
| 无法打开页面 | 文档 ID 错误，或没有权限 | 检查输入中的 ID，以及启动该标签页的用户的权限 |
| 超时 | 该步骤或整个测试耗时过长 | 重新运行；如果再次出现，请检查页面性能 |
| 被环境阻止 | 测试在客户环境中写入数据 | 确认启动，或在测试环境中运行 |

## 我的运行显示“已阻止”

无法对该次运行作出判断：部分步骤被跳过（例如浏览器无法执行的截屏步骤），
或者缺少确认。已阻止的运行绝不会被计为通过。请从您自己的模板中删除该步骤，或
在带确认的情况下重新启动。

## “请先注册浏览器会话再开始” / 没有标签页接受启动

从 AI 助手或外部启动需要一个已开启 **允许从外部启动** 的浏览器标签页。请在会保持打开的标签页中打开
“输入”标签页，开启该选项，并使用其会话 ID。重新加载会结束注册。

## 运行已停止，或显示已取消 / 无法投递

运行测试的标签页被重新加载、关闭或断开了连接，或者没有标签页及时响应。请保持该标签页打开并
位于前台，直到运行结束，然后重新启动。如果页面没有在大约两分钟内恢复，包含 **重新加载页面** 步骤的测试也会以这种方式结束
（请参阅[重新加载与继续](reload-and-resume.md)）。

## “暂时无法在此处启动 Playwright 模板”

**执行器** 为 **Playwright** 的模板由您的测试自动化运行。您可以为它们保存输入，但
不能从此页面启动它们。

## 我无法删除模板

只能删除贵组织自己的模板（**自定义**）。内置模板和默认模板无法删除；请使用
**编辑副本** 来获得您自己的版本。
