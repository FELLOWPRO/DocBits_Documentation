# Confronta con Prezzo dell'Offerta

Le schede di questa categoria nel selettore **Add Card** del Workflow Builder:

Le schede di questa categoria confrontano le righe di un documento con i dati di prezzo degli articoli del fornitore che DocBits ha trovato per il fornitore del documento e per i relativi ID articolo fornitore. A seconda della scheda, può trattarsi dell'ID articolo fornitore, del codice articolo, del prezzo gestito o dell'ultimo prezzo pagato, dell'unità di misura o del tipo di fornitore. La versione 3 della scheda Unit of Measure può inoltre effettuare il confronto con le righe dell'ordine di acquisto abbinato.
