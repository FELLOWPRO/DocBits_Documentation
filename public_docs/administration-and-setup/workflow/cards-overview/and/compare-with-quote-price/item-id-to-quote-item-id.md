# 商品 ID 与报价商品 ID

<figure><img src="../../../../../.gitbook/assets/workflow_card_condition_quotes_item_number_comparison_v2-zh-cn.png" alt="商品 ID 与报价商品 ID, 版本 2" width="634"><figcaption><p>版本 2</p></figcaption></figure>

## 用途：

此工作流卡片会将文档每一行上的商品编号与供应商商品价格表中为同一供应商商品存储的商品编号进行比较。它可用于发现文档所列商品与价格数据所指商品不同的行。工作流会根据结果沿着真条件或假条件继续。

## 卡片组件：

1. **任意/全部**
   * **描述：** 定义文档表格中应有一个还是每一个参与比较的行都满足条件。
   * **选项：**
     * **任何：** 如果至少有一个参与比较的行满足条件，则条件为真。
     * **全部：** 只有每个参与比较的行都满足条件时，条件才为真。
2. **操作员**
   * **描述：** 定义如何将供应商商品价格表中的商品编号与文档行上的商品编号进行比较。
   * **选项：**
     * **等于：** 商品编号相同。如果两个商品编号都能读取为数字，则按数字比较（例如 "007" 和 "7" 相等）；否则按文本比较，不区分大小写。
     * **不等于：** 商品编号不同。如果两个商品编号都能读取为数字，则按数字比较；否则按文本比较，此时区分大小写。
     * **大于、大于或等于、少于、小于或等于：** 卡片同样提供这些运算符。使用这些运算符时，商品编号始终按文本逐字符比较，因此例如 "10" 会被视为小于 "9"。

## 功能：

* **条件评估：** 对于文档表格中的每一行，卡片会在供应商商品价格表中查找该行的供应商商品 ID（列 `SUPPLIER_ITEM_NUMBER`），并将其中存储的商品编号与该行的商品编号（列 `ITEM_NUMBER`）进行比较。随后，所有参与比较的行的结果通过 **任何** 或 **全部** 合并。
* **跳过的行：** 如果供应商商品价格表中没有该行供应商商品 ID 的条目，或该条目没有商品编号，则该行不参与比较。每个被跳过的行都会记录在工作流日志中。
* **有效日期：** 如果供应商商品价格表中的某个条目设有开始日期或结束日期，而文档日期不在该期间内，卡片会在工作流日志中注明。此说明不会改变卡片的结果。
* **执行操作：**
  * **条件为真：**\
    对于任何或全部参与比较的行，商品编号满足所选运算符。工作流沿着真条件继续。
  * **条件为假：**\
    如果条件不满足，工作流沿着假条件继续，例如将文档送交人工审核。如果由于供应商商品价格表中没有任何行的商品编号而导致所有行都无法比较，也会使用假条件。
* **缺少数据：** 如果文档没有表格、有多个表格，或无法从表格中读取任何行，卡片不会评估条件，并会在工作流日志中报告缺少的数据。如果未设置 **任意/全部** 选项，卡片会在日志中注明并使用 **全部**。

## 设置和配置：

* 可以从 **与报价比较** 类别中添加此卡片，然后选择 **任何** 或 **全部** 以及运算符。如需检查商品编号是否一致，通常选择 **等于** 或 **不等于**。最后设置继续条件（真或假），以决定工作流的下一步。
* 此卡片适用于恰好有一个表格且表格行包含供应商商品 ID 和商品编号的文档。

## 结论：

“商品 ID 与报价商品 ID”工作流卡片可确保文档上的商品与供应商商品价格表所指的商品一致。没有价格数据的行会被跳过，而不会被计为差异，因此结果只反映实际可以比较的行。
