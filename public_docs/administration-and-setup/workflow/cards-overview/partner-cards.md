# 合作伙伴卡：自定义扩展

**合作伙伴卡是客户或合作伙伴使用 Card SDK 自行创建的工作流卡片。** 其功能、输入参数和版本取决于安装的扩展包；不同组织中可用的卡片可能不同。

这些卡片可能出现在**且**条件或**则**操作的合作伙伴卡类别中。客户或合作伙伴的具体自定义卡片不属于这些页面介绍的标准卡范围。有关具体功能、配置和示例，请参阅卡片创建者提供的文档。

名称相同的卡片（例如 **My Action**）可能采用不同的实现。不要仅凭名称就认为它们执行相同的操作或接受相同的设置。

有关创建和管理自定义卡片的信息，请参阅 [Card SDK](../card-sdk.md)。
