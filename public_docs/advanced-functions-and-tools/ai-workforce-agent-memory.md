# 检查 AI 智能体学到的内容

智能体记忆保存 AI Workforce 智能体可复用的经验。反复出现过时或错误行为时，可检查此处。记忆与系统提示词、附加指令、工具及批准模式分别管理。

## 检查经验

1. 打开 **AI Workforce → 智能体**，选择目标智能体。
2. 在详情页找到已学习内容，确认智能体和组织正确。
3. 阅读经验及来源：用户反馈、自我反思或情境经验。来源标签不能保证内容正确。
4. 查看置信度、使用次数和标签。置信度高或频繁使用都不能替代独立验证。
5. 按可用来源筛选或加载更多记录，将可疑经验与任务、问题记录和业务规则对照。

## 反馈或删除

1. 用**赞**标记有帮助，用**踩**标记无帮助。等待请求完成并核对反馈结果。
2. 删除错误经验前，在内部记录中保留依据并确认自己有权限。
3. 选择该条目的**删除图标**。它执行删除，不会打开编辑器；不要假定还会有第二次确认。
4. 刷新详情页，确认正确条目已移除。删除记忆不会撤销先前动作，也不会删除任务历史。
5. 用新的无害案例测试行为。如果问题仍存在，还需检查提示词、附加指令、工具与输入数据。

空面板可能表示尚未形成经验。加载失败是另一种情况：先阅读错误并重新加载，不要直接判断为没有记忆。

智能体配置、任务和批准详见 [AI Workforce](ai_workforce.md)。
