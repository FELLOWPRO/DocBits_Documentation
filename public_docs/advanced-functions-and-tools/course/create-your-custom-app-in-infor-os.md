# Utwórz własną aplikację w Infor OS

{% hint style="warning" %}
Gdy Twoja własna aplikacja importuje specyfikację API DocBits, użyj specyfikacji **Swagger 2.0** (`/openapi-swagger2.json`), a nie OpenAPI 3.0. Starszy swagger-ui w Infor OS wymaga dialektu 2.0, aby poprawnie budować przesyłanie plików — w przeciwnym razie przesyłanie kończy się błędem `400 — Missing boundary in multipart`. Pełne wyjaśnienie i sposób skopiowania adresu URL znajdziesz w artykule [Infor OS z integracją API DocBits](infor-os-with-docbits-api-integration.md).
{% endhint %}
