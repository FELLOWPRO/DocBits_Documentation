# Administration with Claude

Start with the job you need to do, even when you do not know the setting name. Ask Claude to find the relevant configuration and explain its current value.

[Open the video player](https://docbits-videos.fra1.cdn.digitaloceanspaces.com/settings-assistant/mcp-administration-feature/v2/en.html)

## Try this question

> Where can I enable QR-code extraction? Show me the current setting, explain its effect, and tell me what I should check before changing it.

Follow up with:

> Show me the available PO-matching configuration and explain how it affects this process.

The example shows configuration reads and explanations. Use an account with the required permissions; review the proposed change before applying it.
