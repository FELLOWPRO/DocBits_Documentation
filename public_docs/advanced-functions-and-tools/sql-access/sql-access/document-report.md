# 文档报告

## 列

* `id`：内部字段
* `org_id`：组织 ID
* `doc_id`：内部字段
* `doc_type`：文档类型
* `sub_doc_type`：内部字段
* `time_spent`：内部字段
* `fields_total`：整数
* `fields_correct`：整数
* `checkbox_fields_total`：整数
* `checkbox_fields_correct`：整数
* `table_values_total`：整数
* `table_values_correct`：整数
* `detail_report`：文本
* `created_on`：带时区的时间戳
* `last_modified_on`：带时区的时间戳
* `is_deleted`：布尔值
* `validated_by`：整数
* `sub_org_id`：内部字段

## 分析与描述

```markdown
# 文档报告表文档

## 简介
`public.document_report` 表用于存储文档处理报告的详细信息，具体涉及发票等文档中字段的验证和提取。该表记录文档元数据、处理指标和验证结果，可用于审计、跟踪并改进文档处理工作流。

## 字段说明

### id
- **含义**：每条文档报告记录的唯一标识符。
- **作用**：主键
- **典型内容**：表示唯一文档报告的 UUID。

### org_id
- **含义**：与该文档关联的组织标识符。
- **作用**：外键
- **典型内容**：用于关联组织的 UUID。

### doc_id
- **含义**：所报告的特定文档的标识符。
- **作用**：外键
- **典型内容**：表示唯一文档的 UUID。

### doc_type
- **含义**：正在处理的文档类型，例如发票。
- **作用**：描述性字段
- **典型内容**：例如 `INVOICE`。

### sub_doc_type
- **含义**：文档子类型，用于进一步分类。
- **作用**：描述性字段
- **典型内容**：可以是 `null`，也可以是 "Cost Invoice" 等特定子类型。

### time_spent
- **含义**：对该文档进行验证所用的时间。
- **作用**：指标字段
- **典型内容**：通常为 '0'，时间以预定义单位计量。

### fields_total
- **含义**：从文档中提取的字段总数。
- **作用**：指标字段
- **典型内容**：表示字段总数的整数，例如 13。

### fields_correct
- **含义**：正确提取并验证的字段数。
- **作用**：指标字段
- **典型内容**：表示已正确处理字段数的整数，例如 12。

### checkbox_fields_total
- **含义**：已处理的复选框字段总数。
- **作用**：指标字段
- **典型内容**：通常为 `0`，表示已处理的复选框字段数。

### checkbox_fields_correct
- **含义**：已正确验证的复选框字段数。
- **作用**：指标字段
- **典型内容**：通常为 `0`，表示已正确验证的复选框字段数。

### table_values_total
- **含义**：从文档中提取的表格值总数。
- **作用**：指标字段
- **典型内容**：通常为 `0`，表示已处理的表格值总数。

### table_values_correct
- **含义**：已正确验证的表格值数。
- **作用**：指标字段
- **典型内容**：通常为 `0`，表示已正确验证的表格值数。

### detail_report
- **含义**：提供文档字段及其验证状态详细报告的 JSON 内容。
- **作用**：描述性/技术性字段
- **典型内容**：包含详细字段信息的 JSON 字符串。

### created_on
- **含义**：创建文档报告记录时的时间戳。
- **作用**：技术字段
- **典型内容**：UTC 时间戳，例如 `2025-03-10 08:07:24+00`。

### last_modified_on
- **含义**：文档报告最后一次修改的时间戳。
- **作用**：技术字段
- **典型内容**：UTC 时间戳，表示最后更新时间。

### is_deleted
- **含义**：指示该文档报告是否已标记为删除。
- **作用**：技术字段
- **典型内容**：布尔值；未删除时为 `False`。

### validated_by
- **含义**：验证该文档的用户标识符。
- **作用**：外键
- **典型内容**：表示验证者 ID 的整数，例如 `1`。

### sub_org_id
- **含义**：与该文档相关的子组织标识符。
- **作用**：外键
- **典型内容**：用于关联子组织的 UUID。
```
