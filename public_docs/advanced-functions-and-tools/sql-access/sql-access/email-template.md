* `doc_type`：文档类型

## 分析与说明

```markdown
# `public.email_template` 表技术文档

## 简介

`public.email_template` 表用于存储系统中使用的电子邮件模板。这些模板与不同的组织相关联，可能用于发送标准化的电子邮件通信。该表包含模板的元数据，包括创建和修改信息，同时还会记录模板是否已被删除。

## 字段说明

### id
- **含义**：每个电子邮件模板的唯一标识符。
- **作用**：主键。
- **典型内容**：UUID 字符串，例如 `da34c6ed-e659-4392-91ea-3c89f9602198`。
- **说明**：作为模板记录的主要标识符。

### org_id
- **含义**：与电子邮件模板关联的组织标识符。
- **作用**：外键。
- **典型内容**：UUID 字符串。
- **说明**：将模板关联到特定组织。

### name
- **含义**：电子邮件模板的名称。
- **作用**：描述性字段。
- **典型内容**：描述性文本，例如 `Supplier Magic Link Email`。
- **说明**：用于标识模板的用途。

### email_type
- **含义**：电子邮件模板的类型或类别。
- **作用**：描述性字段。
- **典型内容**：字符串，例如 `supplier_invite`。
- **说明**：表示模板的上下文或用途。

### value
- **含义**：电子邮件模板的内容，通常采用 HTML 格式。
- **作用**：内容字段。
- **典型内容**：包含电子邮件布局和内容的 HTML 字符串。
- **说明**：这是电子邮件中实际使用的模板。

### created_by
- **含义**：创建模板的用户标识符。
- **作用**：元数据字段。
- **典型内容**：表示用户 ID 的整数。
- **说明**：记录模板的创建者。

### created_on
- **含义**：模板的创建时间戳。
- **作用**：元数据字段。
- **典型内容**：时间戳，例如 `2024-07-18 13:29:59 UTC`。
- **说明**：记录创建日期和时间。

### last_modified_on
- **含义**：模板最后修改的时间戳。
- **作用**：元数据字段。
- **典型内容**：时间戳。
- **说明**：记录模板最近一次更新的时间。

### is_deleted
- **含义**：表示模板是否标记为已删除。
- **作用**：技术字段。
- **典型内容**：布尔值，`True` 或 `False`。
- **说明**：用于软删除模板。

### deleted_on
- **含义**：模板被标记为已删除的时间戳。
- **作用**：元数据字段。
- **典型内容**：时间戳；如果未删除，则为 `None`。
- **说明**：记录模板被删除的时间。

### subject
- **含义**：电子邮件模板的主题行。
- **作用**：内容字段。
- **典型内容**：文本，例如 `Welcome to Testing Ruiz Foods Supplier Portal. Let's help you get set up`。
- **说明**：发送模板时用作电子邮件主题。

### last_modified_by
- **含义**：最后修改模板的用户标识符。
- **作用**：元数据字段。
- **典型内容**：用户标识符。
- **说明**：记录最后修改模板的用户。

### deleted_by
- **含义**：将模板标记为已删除的用户标识符。
- **作用**：元数据字段。
- **典型内容**：用户标识符。
- **说明**：记录删除模板的用户。

### doc_type
- **含义**：与模板相关的文档类型或格式。
- **作用**：描述性字段。
- **典型内容**：表示文档类型的字符串。
- **说明**：可能与电子邮件内容的格式或类别有关。
```
