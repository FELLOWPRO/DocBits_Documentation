## 分析与说明

```markdown
# FTP 导入配置表文档

## 简介

`public.ftp_import_configurations` 表用于存储 FTP 导入流程的配置详情。此表包含连接 FTP 服务器、管理身份验证和处理文件导入所需的信息。该表支持 FTP 和 SFTP 协议，并包含 FTP 服务器详情、身份验证凭据以及操作设置等字段，例如导入后是否移动文件，以及是否包含子文件夹中的内容。

## 字段说明

### id
- **含义**：每条 FTP 导入配置记录的唯一标识符。
- **作用**：主键。
- **典型内容**：UUID 格式，例如 `9862d8c6-bb61-4373-9616-d5f8c125eeb8`。

### org_id
- **含义**：与此配置关联的组织标识符。
- **作用**：外键。
- **典型内容**：UUID 格式。

### sub_org_id
- **含义**：子组织的标识符（如适用）。
- **作用**：外键。
- **典型内容**：UUID 格式；如不适用，则为 `null`。

### server_url
- **含义**：FTP 服务器的 URL 或 IP 地址。
- **作用**：描述性字段。
- **典型内容**：域名或 IP 地址，例如 `sftp.it.doxee.com`。

### username
- **含义**：用于向 FTP 服务器进行身份验证的用户名。
- **作用**：描述性字段。
- **典型内容**：纯文本用户名。

### password
- **含义**：用于向 FTP 服务器进行身份验证的密码。
- **作用**：描述性字段。
- **典型内容**：加密后的密码字符串。

### is_active
- **含义**：指示该配置当前是否处于活动状态。
- **作用**：状态标志。
- **典型内容**：`True` 或 `False`。

### created_by
- **含义**：创建此配置的用户标识符。
- **作用**：外键。
- **典型内容**：表示用户 ID 的整数。

### created_on
- **含义**：创建此配置时的时间戳。
- **作用**：审计字段。
- **典型内容**：包含时区信息的日期时间。

### last_modified_on
- **含义**：此配置最后一次修改时的时间戳。
- **作用**：审计字段。
- **典型内容**：包含时区信息的日期时间。

### is_deleted
- **含义**：指示此配置是否已标记为已删除。
- **作用**：状态标志。
- **典型内容**：`True` 或 `False`。

### deleted_on
- **含义**：此配置被标记为已删除时的时间戳。
- **作用**：审计字段。
- **典型内容**：包含时区信息的日期时间，或未删除记录使用的默认日期。

### port
- **含义**：连接 FTP 服务器时使用的端口号。
- **作用**：描述性字段。
- **典型内容**：整数，例如 SFTP 使用的 `22`。

### default_directory
- **含义**：FTP 服务器上的默认目录路径。
- **作用**：描述性字段。
- **典型内容**：目录路径字符串。

### ftp_type
- **含义**：使用的 FTP 协议类型（例如 FTP、SFTP）。
- **作用**：描述性字段。
- **典型内容**：`FTP` 或 `SFTP`。

### token
- **含义**：用于额外身份验证或标识的安全令牌。
- **作用**：描述性字段。
- **典型内容**：加密或编码后的字符串。

### file_name_matching_patterns
- **含义**：用于匹配待导入文件名的模式。
- **作用**：描述性字段。
- **典型内容**：模式字符串或 `null`。

### last_mtime
- **含义**：文件的最后修改时间，用于筛选导入文件。
- **作用**：描述性字段。
- **典型内容**：表示时间戳的字符串或 `null`。

### auth_failed_count
- **含义**：身份验证失败次数计数器。
- **作用**：描述性字段。
- **典型内容**：整数，例如 `0` 或 `5`。

### auth_message
- **含义**：描述最近一次身份验证尝试结果的消息。
- **作用**：描述性字段。
- **典型内容**：文本消息或 `null`。

### ignore_certificate
- **含义**：指示是否应忽略 SSL 证书验证。
- **作用**：状态标志。
- **典型内容**：`True` 或 `False`。

### move_after_import
- **含义**：指示导入完成后是否应移动文件。
- **作用**：状态标志。
- **典型内容**：`True` 或 `False`。

### destination_directory
- **含义**：导入后用于移动文件的目标目录路径。
- **作用**：描述性字段。
- **典型内容**：目录路径字符串或 `null`。

### import_directory
- **含义**：导入文件所在的目录路径。
- **作用**：描述性字段。
- **典型内容**：目录路径字符串或 `null`。

### include_subfolder_content
- **含义**：指示导入时是否应包含子文件夹中的内容。
- **作用**：状态标志。
- **典型内容**：`True` 或 `False`。
```
