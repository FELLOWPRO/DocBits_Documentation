# 表 `public.organisation_document_type` 的技术文档

## 简介

`public.organisation_document_type` 表用于管理和存储与组织相关的各种文档类型信息，包括文档类型键、区域设置、分类方法以及文档类型的状态（启用、已删除等）。该表似乎用于建立组织与其使用或管理的文档类型之间的映射，并存储这些文档类型的元数据。

## 字段说明

### id
- **含义**：表中每条记录的唯一标识符。
- **作用**：主键。
- **典型内容**：唯一标识一个文档类型条目的 UUID 字符串。
- **说明**：对于区分每条记录至关重要。

### org_id
- **含义**：与该文档类型相关的组织标识符。
- **作用**：外键，可能引用组织表。
- **典型内容**：UUID 字符串。
- **说明**：将文档类型关联到特定组织。

### document_type_id
- **含义**：文档类型的标识符。
- **作用**：外键，可能关联到文档类型参考表。
- **典型内容**：UUID 字符串。
- **说明**：用于映射到特定文档类型。

### document_type_key
- **含义**：表示文档类型的键或代码。
- **作用**：用于文档类型分类的描述性字段。
- **典型内容**：用作文档类型标识符或标签的字符串。
- **说明**：用于以便于人理解的形式识别文档类型。

### document_locale
- **含义**：文档类型的区域设置或语言设置。
- **作用**：用于指定区域设置的描述性字段。
- **典型内容**：字符串，通常为 'auto'，表示自动确定区域设置。
- **说明**：有助于实现国际化和本地化。

### classification_method
- **含义**：用于对文档类型进行分类的方法。
- **作用**：说明文档如何分类的描述性字段。
- **典型内容**：字符串，通常为 'auto'，表示自动分类。
- **说明**：对于了解分类流程很重要。

### is_active
- **含义**：表示文档类型是否启用的状态。
- **作用**：布尔状态字段。
- **典型内容**：`True` 或 `False`。
- **说明**：决定该文档类型当前是否在使用。

### extraction_type
- **含义**：用于该文档的提取方法类型。
- **作用**：描述提取流程的字段。
- **典型内容**：例如 'FIX_COORDINATES'、'FLEX_COORDINATES' 或 `None` 等字符串。
- **说明**：用于了解如何从文档中提取数据。

### created_by
- **含义**：创建该记录的用户标识符。
- **作用**：用于审计的技术字段。
- **典型内容**：表示用户 ID 的整数。
- **说明**：有助于跟踪变更和明确责任。

### created_on
- **含义**：记录的创建时间戳。
- **作用**：用于审计的技术字段。
- **典型内容**：带时区的时间戳。
- **说明**：对于跟踪记录的创建日期和时间很重要。

### last_modified_on
- **含义**：记录最后修改的时间戳。
- **作用**：用于审计的技术字段。
- **典型内容**：带时区的时间戳。
- **说明**：有助于跟踪记录的更新和变更。

### is_deleted
- **含义**：表示记录是否已标记为删除的状态。
- **作用**：布尔状态字段。
- **典型内容**：`True` 或 `False`。
- **说明**：有助于实现软删除功能。

### sub_org_id

- **作用**：可能是外键，用于补充组织层级结构。
- **典型内容**：UUID 字符串或 `None`。
- **说明**：提供有关组织结构的更多上下文。
