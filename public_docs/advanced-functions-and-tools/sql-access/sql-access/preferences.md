* `id`：内部字段
* `org_id`：组织 ID
* `pref_key`：内部字段
* `pref_value`：文本
* `created_by`：整数
* `created_on`：带时区的时间戳
* `last_modified_on`：带时区的时间戳
* `deleted_on`：带时区的时间戳
* `is_deleted`：布尔值
* `user_id`：整数
* `sub_org_id`：内部字段

## 分析与描述

```markdown
# `public.preferences` 表技术文档

## 简介
`public.preferences` 表用于存储系统中各种组织实体的配置设置和偏好。表中的每条记录代表一个特定的偏好键及其对应的值，并关联到某个组织或子组织。这些配置数据可能包括增值税号、提取设置、模块激活状态等相关设置。

## 字段说明

### id
- **含义**：此字段存储每条偏好记录的唯一标识符。
- **作用**：主键。
- **典型内容**：用于唯一标识每一行的 UUID 字符串，例如 `23f3d697-7411-4c95-981d-faf089d266be`。

### org_id
- **含义**：此字段存储与该偏好关联的组织标识符。
- **作用**：外键。
- **典型内容**：与某个组织对应的 UUID 字符串，例如 `23f3d697-7411-4c95-981d-faf089d266be`。

### pref_key
- **含义**：此字段表示偏好设置的键或名称。
- **作用**：描述性字段。
- **典型内容**：表示配置键的字符串，例如 `VAT_NUMBERS`、`TABLE_EXTRACTION_SETTING`。

### pref_value
- **含义**：此字段包含与 `pref_key` 对应的偏好值。
- **作用**：描述性字段。
- **典型内容**：内容因 `pref_key` 而异，例如以逗号分隔的增值税号，或 `true`、`false` 等布尔值。

### created_by
- **含义**：此字段表示创建该偏好记录的用户 ID。
- **作用**：描述性字段。
- **典型内容**：表示用户 ID 的整数，例如 `1`。

### created_on
- **含义**：此字段记录偏好创建时的时间戳。
- **作用**：技术字段。
- **典型内容**：带时区的时间戳，例如 `2021-11-09 11:04:18+00`。

### last_modified_on
- **含义**：此字段记录偏好的最后修改时间戳。
- **作用**：技术字段。
- **典型内容**：表示最后更新时间的带时区时间戳，例如 `2023-12-04 10:10:26+00`。

### deleted_on
- **含义**：此字段记录偏好被标记为已删除时的时间戳。
- **作用**：技术字段。
- **典型内容**：通常为 `null`，除非该行被标记为删除。

### is_deleted
- **含义**：此字段表示该偏好是否已被标记为删除。
- **作用**：技术字段。
- **典型内容**：布尔值，通常为 `false`。

### user_id
- **含义**：此字段存储与该偏好关联的用户 ID。
- **作用**：描述性字段，可能是外键。
- **典型内容**：整数；如果不适用，则为 `null`。

### sub_org_id
- **含义**：此字段标识与该偏好关联的子组织。
- **作用**：外键。
- **典型内容**：UUID 字符串；如果不适用，则为 `null`。

`public.preferences` 表提供了一种灵活而全面的方式，用于管理不同组织实体的配置设置，确保可以动态调整偏好并随时间进行跟踪。
```
