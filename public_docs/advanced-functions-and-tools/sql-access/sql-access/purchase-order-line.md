### 分析与说明

## `public.purchase_order_line` 表技术文档

### 简介

`public.purchase_order_line` 表用于存储采购订单中每个行项目的详细信息。它记录采购订单行的各种属性，例如商品详情、数量、价格和状态。此表对于在组织范围内管理和跟踪采购订单及其履行状态至关重要。

### 列说明

#### id

* **含义**：每个采购订单行项目的唯一标识符。
* **作用**：主键。
* **典型内容**：用于唯一标识采购订单行的 UUID 字符串。

#### org\_id

* **含义**：与采购订单关联的组织标识符。
* **作用**：外键。
* **典型内容**：引用某个组织的 UUID 字符串。

#### purchase\_order\_id

* **含义**：行项目所属采购订单的标识符。
* **作用**：外键。
* **典型内容**：引用某个采购订单的 UUID 字符串。

#### purchase\_order\_number

* **含义**：分配给采购订单的编号。
* **作用**：描述性字段。
* **典型内容**：表示采购订单编号的字符串。

#### line\_number

* **含义**：商品在采购订单中的行号。
* **作用**：描述性字段。
* **典型内容**：表示采购订单中行项目顺序的字符串。

#### item\_id

* **含义**：所订购商品的标识符。
* **作用**：外键。
* **典型内容**：表示商品代码的字符串。

#### supplier\_item\_id

* **含义**：供应商特定的商品标识符。
* **作用**：描述性字段。
* **典型内容**：字符串；如果供应商未提供，则可能为 null。

#### description

* **含义**：商品说明。
* **作用**：描述性字段。
* **典型内容**：商品的文本说明。

#### quantity

* **含义**：订购的数量。
* **作用**：描述性字段。
* **典型内容**：表示订购数量的数值。

#### unit\_code

* **含义**：表示商品计量单位的代码。
* **作用**：描述性字段。
* **典型内容**：表示计量单位的字符串，例如表示“每件”的 'EA'。

#### unit\_price

* **含义**：商品的单价。
* **作用**：描述性字段。
* **典型内容**：表示单价的数值。

#### total\_amount

* **含义**：行项目的总金额（数量 \* 单价）。
* **作用**：描述性字段。
* **典型内容**：表示总金额的数值。

#### currency

* **含义**：采购所用的货币。
* **作用**：描述性字段。
* **典型内容**：表示货币代码的字符串，例如 'USD'。

#### status

* **含义**：采购订单行的当前状态。
* **作用**：描述性字段。
* **典型内容**：表示状态的字符串，例如 'Received'（已收货）、'Invoiced'（已开票）。

#### created\_by

* **含义**：创建此条目的用户标识符。
* **作用**：外键。
* **典型内容**：表示用户 ID 的整数。

#### created\_on

* **含义**：条目的创建时间戳。
* **作用**：技术字段。
* **典型内容**：带时区信息的时间戳。

#### last\_modified\_on

* **含义**：最近一次修改的时间戳。
* **作用**：技术字段。
* **典型内容**：带时区信息的时间戳；如果从未修改，则可能为 null。

#### deleted\_on

* **含义**：条目标记为已删除的时间戳。
* **作用**：技术字段。
* **典型内容**：带时区信息的时间戳；如果未删除，则可能为 null。

#### is\_deleted

* **含义**：指示条目是否已标记为删除。
* **作用**：技术字段。
* **典型内容**：布尔值（true/false）。

#### open\_quantity

* **含义**：尚未收货或开票的数量。
* **作用**：描述性字段。
* **典型内容**：数值；全部收货时通常为零。

#### received\_quantity

* **含义**：已收货的数量。
* **作用**：描述性字段。
* **典型内容**：表示已收货数量的数值。

#### confirmed\_quantity

* **含义**：供应商确认的数量。
* **作用**：描述性字段。
* **典型内容**：数值；如果尚未确认，则可能为 null。

#### note

* **含义**：有关采购订单行的补充备注。
* **作用**：描述性字段。
* **典型内容**：文本，可能包含特殊说明或评论。

#### sub\_org\_id

* **含义**：与采购订单行关联的子组织标识符。
* **作用**：外键。
* **典型内容**：字符串；如果不适用，则可能为 null。

#### sub\_line\_number

* **含义**：采购订单中的子行号。
* **作用**：描述性字段。
* **典型内容**：表示子行顺序的字符串。

#### unit\_price\_per

* **含义**：商品的基本单价。
* **作用**：描述性字段。
* **典型内容**：表示基本单价的数值。

#### buyer\_id

* **含义**：负责采购的买方标识符。
* **作用**：外键。
* **典型内容**：表示买方 ID 的字符串。

#### buyer\_name

* **含义**：负责采购的买方姓名。
* **作用**：描述性字段。
* **典型内容**：表示买方姓名的字符串。

#### unit\_code\_price

* **含义**：与定价相关的单位代码。
* **作用**：描述性字段。
* **典型内容**：与 unit\_code 类似的字符串。

#### geo\_code

* **含义**：用于配送的地理代码。
* **作用**：描述性字段。
* **典型内容**：表示地理位置的字符串。

#### promised\_delivery\_date

* **含义**：承诺的交货日期。
* **作用**：描述性字段。
* **典型内容**：带时区信息的时间戳。

#### delivery\_method

* **含义**：采购订单行的交付方式。
* **作用**：描述性字段。
* **典型内容**：表示交付方式的字符串。

#### requested\_ship\_date

* **含义**：要求的发货日期。
* **作用**：描述性字段。
* **典型内容**：日期值。

#### received\_base\_mou\_quantity

* **含义**：按基本计量单位计算的已收货数量。
* **作用**：描述性字段。
* **典型内容**：表示已收货基本计量单位数量的数值。

#### extended\_amount

* **含义**：行项目的扩展金额。
* **作用**：描述性字段。
* **典型内容**：表示扩展金额的数值；如果没有折扣或额外费用，可能等于 total\_amount。
