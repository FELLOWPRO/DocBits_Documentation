# 仪表板

在这份全面的视频指南中，观众将了解 **DocBits** 仪表板及其多种功能。教程将逐步介绍如何筛选和管理未处理的文档，以及如何通过电子邮件、扫描仪或 API 等多种渠道导入附件。

{% embed url="https://youtu.be/y2zpTl8e3VE" %}

视频重点介绍了主要功能，包括如何按状态或受派人筛选文档、查找发票编号等具体信息，以及如何更改单个文档的受派人。教程展示了系统的便捷性和高效性，并强调了它为[用户](../../../administration-and-setup/settings/global-settings/groups-users-and-permissions/)提供的控制能力和自定义选项。教程还为深入了解 **DocBits** 中的[文档验证](../validation-screen/)奠定了基础。
