# Dobre praktyki

- Zapisz osobisty widok dla powtarzalnych zadań.
- Przed działaniem sprawdź organizację, przypisaną osobę i status.
- Udostępniaj widoki tylko właściwym osobom; uprawnienia do dokumentów nadal obowiązują.
- Sprawdź wybór przed działaniami zbiorczymi i odśwież listę przed powtórzeniem działania.

Wyszukiwanie, działania i widoki opisuje [przewodnik po pulpicie](README.md).
