# Aanbevolen werkwijze

- Sla een persoonlijke weergave op voor terugkerend werk.
- Controleer organisatie, toegewezen persoon en status voordat u handelt.
- Deel weergaven alleen met de bedoelde personen; documentrechten blijven gelden.
- Controleer de selectie voor bulkacties en vernieuw de lijst voordat u een actie herhaalt.

De [dashboardhandleiding](README.md) beschrijft zoeken, documentacties en opgeslagen weergaven.
