# Bewährte Vorgehensweisen

- Speichern Sie für wiederkehrende Arbeit eine persönliche Ansicht.
- Prüfen Sie vor Aktionen Organisation, zuständige Person und Status.
- Teilen Sie Ansichten nur mit dem vorgesehenen Personenkreis; Dokumentberechtigungen gelten weiterhin.
- Prüfen Sie die Auswahl vor Sammelaktionen und aktualisieren Sie die Liste, bevor Sie eine Aktion wiederholen.

Suche, Dokumentaktionen und gespeicherte Ansichten erklärt die [Dashboard-Anleitung](README.md).
