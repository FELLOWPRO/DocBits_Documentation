# Buenas prácticas

- Guarde una vista personal para tareas recurrentes.
- Compruebe organización, responsable y estado antes de actuar.
- Comparta vistas solo con los destinatarios previstos; se mantienen los permisos de documentos.
- Revise la selección antes de acciones en lote y actualice la lista antes de repetir una acción.

Consulte búsqueda, acciones y vistas guardadas en la [guía del panel](README.md).
