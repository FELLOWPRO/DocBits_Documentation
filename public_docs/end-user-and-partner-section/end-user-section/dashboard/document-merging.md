# Unire documenti

1. Seleziona da due a cinque documenti correlati con le caselle, nell’ordine desiderato.
2. Apri il menu delle azioni collettive nell’intestazione e scegli l’unione, se disponibile.
3. Leggi la conferma: il primo documento selezionato è il principale. Gli altri vengono uniti a esso nell’ordine di selezione. Annulla se la selezione o l’ordine sono errati.
4. Conferma solo se i documenti appartengono allo stesso insieme. Controlla il risultato dopo il ricaricamento della lista.

L’unione modifica i documenti e richiede permessi di modifica. Usala per parti dello stesso documento. Mantieni separate le fatture indipendenti: l’unione non crea un riepilogo contabile.

La [guida alla dashboard](README.md) descrive ricerca, azioni e viste salvate.
