# Combinar documentos

1. Seleccione entre dos y cinco documentos relacionados, con las casillas y en el orden deseado.
2. Abra el menú de acciones en lote del encabezado y elija combinar, si está disponible.
3. Lea la confirmación: el primer documento seleccionado es el principal. Los demás se combinan con él en el orden de selección. Cancele si la selección o el orden no son correctos.
4. Confirme solo si los documentos pertenecen al mismo conjunto. Compruebe el resultado al actualizarse la lista.

Combinar modifica documentos y requiere permisos de edición. Úselo para partes de un mismo documento. Mantenga separadas las facturas independientes; combinar no crea un resumen contable.

Consulte búsqueda, acciones y vistas guardadas en la [guía del panel](README.md).
