# Documenten samenvoegen

1. Selecteer twee tot vijf bij elkaar horende documenten via de selectievakjes, in de gewenste volgorde.
2. Open het menu voor bulkacties in de tabelkop en kies samenvoegen als dit beschikbaar is.
3. Lees de bevestiging: het eerst geselecteerde document is het primaire document. De andere worden in selectievolgorde hierin samengevoegd. Annuleer bij een verkeerde selectie of volgorde.
4. Bevestig alleen als de documenten bij elkaar horen. Controleer het resultaat nadat de lijst is vernieuwd.

Samenvoegen wijzigt documenten en vereist bewerkingsrechten. Gebruik het voor delen van één document. Houd onafhankelijke facturen apart; samenvoegen maakt geen boekhoudkundig overzicht.

De [dashboardhandleiding](README.md) beschrijft zoeken, documentacties en opgeslagen weergaven.
