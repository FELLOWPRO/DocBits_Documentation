# Smart Search Ranking 智能搜索排序

智能搜索排序会把您真正要找的文档排在仪表板搜索结果的最前面。关键词搜索会找到所有包含该词的文档；智能搜索排序多做一步：AI 阅读靠前的结果，把真正与您的搜索相关的文档排在最前。精确匹配——发票号、订单号、供应商名称——始终排在最前面。

## 有什么变化

| | 关键词顺序 | 启用智能搜索排序 |
| --- | --- | --- |
| 找到哪些文档 | 相同 | 相同 |
| 结果的顺序 | 按关键词匹配 | 与您的搜索真正相关的文档排在最前 |
| 精确匹配（发票号、订单号、供应商） | 最前 | 最前 |
| 按列排序、`ocr:` 搜索和字段搜索 | 不变 | 不变——它们保持各自的顺序 |

## 示例

假设多张发票都包含同一个词，例如“螺丝”：不锈钢螺丝、一套螺丝刀、一台锁螺丝机的维护、螺丝椒、螺丝面。关键词搜索会把它们全部找出来，顺序只取决于关键词匹配；启用智能搜索排序后，真正关于螺丝的发票会排在前面，而搜索“螺丝刀”时，螺丝刀套装会排在前面。

## 适用范围

* 仪表板的[快速搜索](quick-search.md)中的普通文本搜索（不包括 `字段:` 字段芯片）。
* 只重新排列结果列表的前部；较长的结果列表在后面保持关键词顺序。
* 如果排序服务未在时限内响应，搜索会显示正常的关键词顺序。不会隐藏任何内容，也不会删除任何结果。

## 如何开启

智能搜索排序由 DocBits 按组织开启。请联系您的 DocBits 联系人开启。开启后一分钟内对组织内所有用户生效，搜索方式不会有任何变化。
