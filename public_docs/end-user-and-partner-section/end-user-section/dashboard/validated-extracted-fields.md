# Extrahierte Felder validieren

Öffnen Sie eine Dokumentzeile, um zur Validierung zu wechseln. Vergleichen Sie extrahierte Felder mit dem Original und korrigieren Sie Werte, soweit Ihre Rechte dies erlauben. Schließen Sie die Validierung erst nach Prüfung der Pflichtfelder und Hinweise ab. Verfügbare Felder und Aktionen hängen von Dokumenttyp, Verarbeitungsstand und Konfiguration ab.

Suche, Dokumentaktionen und gespeicherte Ansichten erklärt die [Dashboard-Anleitung](README.md).
