# Validar campos extraídos

Abra una fila para entrar en la validación. Compare los campos extraídos con el documento original y corrija valores si sus permisos lo permiten. Complete la validación después de comprobar campos obligatorios y mensajes. Los campos y acciones dependen del tipo de documento, estado y configuración.

Consulte búsqueda, acciones y vistas guardadas en la [guía del panel](README.md).
