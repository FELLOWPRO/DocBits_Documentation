# Validar campos extraídos

Abra uma linha para aceder à validação. Compare os campos extraídos com o documento original e corrija valores se as suas permissões o permitirem. Termine a validação depois de verificar campos obrigatórios e mensagens. Os campos e ações dependem do tipo de documento, estado e configuração.

O [guia do painel](README.md) descreve pesquisa, ações e vistas guardadas.
