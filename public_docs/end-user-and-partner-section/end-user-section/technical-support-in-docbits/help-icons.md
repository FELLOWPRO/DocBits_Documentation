# Icônes d'aide

Des icônes d'aide ont été placées tout autour de DocBits afin de vous aider à apprendre et comprendre ce que fait vraiment une fonctionnalité et comment elle peut vous aider dans le traitement de vos documents. Il s'agit de la petite icône en forme de point d'interrogation, à l'extrémité droite de la barre d'outils d'une page, à côté d'un réglage isolé ou dans une boîte de dialogue.

Ces icônes d'aide ressemblent à ceci

<figure><img src="../../../.gitbook/assets/help-icon-toolbar-fr.png" alt="L'icône d'aide à l'extrémité droite de la barre d'outils — ici sur la page Plan du Site"><figcaption><p>L'icône d'aide à l'extrémité droite de la barre d'outils — ici sur la page Plan du Site</p></figcaption></figure>

Cliquez sur une icône d'aide : la page correspondante de cette documentation s'ouvre dans un nouvel onglet, sans que vous ayez à chercher le bon article. L'icône suit la langue dans laquelle vous utilisez DocBits et revient à l'anglais lorsqu'une traduction n'est pas encore publiée.

{% hint style="info" %}
Tous les écrans n'affichent pas d'icône d'aide. Si le vôtre n'en a pas, ouvrez le [Plan du Site](../../end-user-section/sitemap.md) ou utilisez la [Recherche Rapide Globale](../../end-user-section/global-quick-search.md) (<kbd>Cmd</kbd>/<kbd>Ctrl</kbd>+<kbd>K</kbd>) pour trouver l'article.
{% endhint %}
