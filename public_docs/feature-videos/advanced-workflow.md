## Van factuur naar de volgende actie

Een binnenkomende factuur start het voorbeeld. Een totaalbedrag boven 1.000 volgt de route Approval; 1.000 of minder volgt Standard. Daarna toont de video echte tests met 1.500 en 500 in de DocBits-designer, inclusief de resultaten.

## Drie manieren om de stroom te sturen

| Functie | In de praktijk |
| --- | --- |
| **De route bepalen** | Verbind Start of When met een voorwaarde. Success, Failed Condition en Error hebben afzonderlijke uitgangen. |
| **Verbonden resultaten samenvoegen** | Wait ANY vereist minstens één passende verbonden bron. Wait ALL vereist van elke bron een passend verbonden resultaat. Geen van beide annuleert andere acties. |
| **De volgende actie verbinden** | Gebruik foutpaden, Call API en notities om systemen te verbinden en het ontwerp toe te lichten. Notities voeren geen acties uit. |
