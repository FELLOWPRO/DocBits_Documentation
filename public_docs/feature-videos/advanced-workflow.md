# DocBits Advanced Workflow

Créez des workflows documentaires avec des cartes reliées. Orientez les documents selon des conditions, regroupez les résultats et prévoyez un chemin pour les erreurs, tout en gardant une vue d’ensemble.

## De la facture à l’action suivante

Une facture entrante lance l’exemple. Un montant total supérieur à 1 000 suit la route Approval ; 1 000 ou moins suit Standard. La vidéo montre ensuite de vrais tests avec 1 500 et 500 dans le concepteur DocBits, ainsi que leurs résultats.

## Trois façons de piloter le flux

| Fonction | En pratique |
| --- | --- |
| **Choisir la route** | Reliez Start ou When à une condition. Success, Failed Condition et Error disposent de sorties distinctes. |
| **Regrouper les résultats connectés** | Wait ANY exige au moins une source connectée correspondante. Wait ALL exige un résultat connecté correspondant pour chaque source. Aucun n’annule les autres actions. |
| **Relier l’action suivante** | Utilisez les chemins d’erreur, Call API et les notes pour relier vos systèmes et expliquer le schéma. Les notes n’exécutent aucune action. |
