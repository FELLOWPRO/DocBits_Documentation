## De la factura a la siguiente acción

Una factura entrante inicia el ejemplo. Un importe total superior a 1.000 sigue la ruta Approval; 1.000 o menos sigue Standard. Después, el vídeo muestra pruebas reales con 1.500 y 500 en el diseñador de DocBits y sus resultados.

## Tres formas de controlar el flujo

| Función | En la práctica |
| --- | --- |
| **Elegir la ruta** | Conecta Start o When con una condición. Success, Failed Condition y Error tienen salidas distintas. |
| **Reunir resultados conectados** | Wait ANY requiere al menos una fuente conectada coincidente. Wait ALL requiere un resultado conectado coincidente de cada fuente. Ninguno cancela otras acciones. |
| **Conectar la siguiente acción** | Utiliza rutas de error, Call API y notas para conectar sistemas y explicar el diseño. Las notas no ejecutan acciones. |
