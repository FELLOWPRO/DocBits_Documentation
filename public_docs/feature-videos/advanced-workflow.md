## Dalla fattura all’azione successiva

Una fattura in ingresso avvia l’esempio. Un importo totale superiore a 1.000 segue il percorso Approval; 1.000 o meno segue Standard. Il video mostra poi test reali con 1.500 e 500 nel designer DocBits, con i relativi risultati.

## Tre modi per controllare il flusso

| Funzione | In pratica |
| --- | --- |
| **Scegliere il percorso** | Collega Start o When a una condizione. Success, Failed Condition ed Error hanno uscite distinte. |
| **Riunire i risultati collegati** | Wait ANY richiede almeno una sorgente collegata corrispondente. Wait ALL richiede un risultato collegato corrispondente da ogni sorgente. Nessuno annulla le altre azioni. |
| **Collegare l’azione successiva** | Usa percorsi di errore, Call API e note per collegare i sistemi e spiegare il progetto. Le note non eseguono azioni. |
