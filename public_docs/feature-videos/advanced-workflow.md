# DocBits Advanced Workflow

Dokumentenworkflows mit verbundenen Karten aufbauen. Bedingungen steuern die Route, Ergebnisse werden zusammengeführt und Fehler erhalten einen eigenen Pfad — mit dem gesamten Prozess im Blick.

## Von der Rechnung zur nächsten Aktion

Eine eingehende Rechnung startet das Beispiel. Ein Gesamtbetrag über 1.000 führt zur Route Approval; 1.000 oder weniger führt zu Standard. Anschließend zeigt der Film echte Testläufe mit 1.500 und 500 im DocBits-Designer samt Ergebnissen.

## Drei Möglichkeiten, den Ablauf zu steuern

| Funktion | In der Praxis |
| --- | --- |
| **Die Route bestimmen** | Start oder When mit einer Bedingung verbinden. Success, Failed Condition und Error haben getrennte Ausgänge. |
| **Verbundene Ergebnisse zusammenführen** | Wait ANY benötigt mindestens eine passende verbundene Quelle. Wait ALL benötigt einen passenden verbundenen Ausgang jeder Quelle. Beide brechen andere Aktionen nicht ab. |
| **Die nächste Aktion verbinden** | Fehlerpfade, Call API und Notizen verbinden Systeme und erklären den Aufbau. Notizen führen keine Aktionen aus. |
