# 备用导出

## **步骤 1：创建新的导出**

1. 前往 **设置** > **文档处理** > **导出**。
2. 点击 **创建新导出**，以定义新的导出配置。
3. 保存配置，并确保导出处于**禁用**状态。

### **步骤 2：启用备用导出**

1. 打开**设置 → 文档类型**，在目标文档类型卡片上点击齿轮按钮打开设置。
2. 展开**导出设置**，找到**替代导出**并按需要开启。更改会影响文档处理，请先检查目标配置。
3. 配置以下内容：
   * **文档状态**：指定文档处于哪个状态时提供此替代导出；这不是导出完成后要写入的状态。
   * **导出配置**：选择要用于备用导出的新建导出配置。

## 使用备用导出

**在 PO 匹配界面中**

* 启用备用导出后，你可以直接在 **PO 匹配** 界面中选择备用导出。

**使用工作流卡片**

* 也可以使用 **备用导出** 工作流卡片自动执行此流程。根据需要配置该卡片，将备用导出逻辑应用于工作流。
