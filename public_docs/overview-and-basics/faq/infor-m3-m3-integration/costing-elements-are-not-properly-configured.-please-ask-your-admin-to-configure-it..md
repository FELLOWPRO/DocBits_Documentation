# 成本要素配置不正确。请联系管理员进行配置。

如果您遇到错误消息 **“成本要素配置不正确。请联系管理员进行配置”**，可能是由以下原因之一导致的：

1. **意外启用：** **成本要素表格提取** 设置可能被意外打开。
   * 要解决此问题，请前往 **设置 → 文档处理 → 分类和提取**，并关闭 **成本要素表格提取** 设置。
2. **缺少配置：** 尚未配置成本要素。
   * 在这种情况下，请前往配置页面并设置所需的成本要素。
