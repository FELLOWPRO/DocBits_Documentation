# DocBits 的主要功能

DocBits 是一款基于云的文档捕获解决方案，利用人工智能（AI）和机器学习（ML）的能力，高效识别、分类、分析和提取各种格式文档中的信息。下面详细介绍其主要功能：

<figure><img src="../../.gitbook/assets/napkin-selection.svg" alt="DocBits 的主要功能"><figcaption><p>DocBits 的主要功能</p></figcaption></figure>

* 文档识别\_:\_ DocBits 使用 AI 算法准确识别文档，无论文档是纸质形式还是电子文件。
* 文档分类：将文档划分为相关类别，便于整理和检索。
* 数据提取：DocBits 从文档中提取关键数据，将非结构化信息转换为结构化数据，以便集成到工作流中。
* 机器学习：系统会通过处理的每份文档持续学习并提高识别准确率，随着时间推移变得更加熟练。
* 群体智能：DocBits 利用群体智能增强学习能力，构建能够自我改进的系统。
