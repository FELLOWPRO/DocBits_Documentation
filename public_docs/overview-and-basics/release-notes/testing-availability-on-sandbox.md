## **如何在沙盒环境中测试**

1. **访问沙盒环境**：
   * 使用现有凭据登录沙盒环境。
   * 确认使用的是正确的沙盒 URL。
2. **测试指南**：
   * 按照各项功能或修复对应的步骤进行操作。
   * 通过 [support.fellowpro.com](https://support.fellowpro.com) 报告任何问题、异常行为或反馈。
3. **测试日志**：
   * 查看系统日志，了解相关测试结果或错误。
   * 记录测试过程和结果，以供审核。
