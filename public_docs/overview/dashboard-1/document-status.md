# Status dokumentu

Jeśli korzystasz z oprogramowania DocBits do przetwarzania dokumentów, ważne jest, aby rozumieć różne statusy, które mogą mieć Twoje pliki. Oto pełna lista wszystkich możliwych statusów dokumentów w DocBits:

* WatchDog Start: Moduł Watchdog jest uruchamiany.
* WatchDog Split: Dokument jest dzielony w module Watchdog.
* WatchDog Upload: Dokument jest przesyłany w module Watchdog.
* Upload: Dokument jest przesyłany.
* OCR: Na dokumencie aktualnie działa optyczne rozpoznawanie znaków (OCR).
* Classification: Dokument jest klasyfikowany.
* Zugferd import: Dokument Zugferd jest importowany.
* Ready for Validation: Dokument jest gotowy do walidacji.
* Zugferd export: Dokument Zugferd jest eksportowany.
* Workflow: Na tym dokumencie aktualnie działa przepływ pracy.
* Pending approval: Dokument wymaga zatwierdzenia.
* Pending second approval: Dokument wymaga drugiego zatwierdzenia.
* Auto Accounting: Trwa automatyczne księgowanie.
* Export: Dokument jest eksportowany.
* Error: W dokumencie wystąpił błąd.
