# Zwalidowane wyodrębnione pola

Ekran walidacji pozwala sprawdzać, edytować i walidować wszystkie zaimportowane dokumenty. Możesz zobaczyć nazwę dokumentu, z ilu stron się składa, datę jego zaimportowania oraz jego status. Przycisk akcji umożliwia przypisanie, ponowne uruchomienie, walidację lub usunięcie dokumentu.
