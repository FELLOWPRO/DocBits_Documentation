**Use Folder**

Se você estiver usando uma pasta diferente da caixa de entrada, insira o nome da pasta após ativar o controle deslizante.

**Use Shared Mailbox**

Se você quiser que a importação de e-mail acesse uma caixa de entrada ou uma pasta de uma caixa de correio compartilhada, insira o endereço de e-mail aqui após ativar o controle deslizante.

**Move imported emails to trash**

Se você quiser importar todos os e-mails, não apenas os não lidos, e movê-los para a lixeira, ative esta opção. Caso contrário, ela verificará apenas os e-mails não lidos, importará os documentos, marcará o e-mail como lido e o deixará em seu local atual.

Caso você receba uma mensagem de erro indicando que não tem permissão para estabelecer essa conexão, alguém com direitos de administrador no Azure precisará autorizar essa conexão. Para mais informações, acesse a seguinte página: https://learn.microsoft.com/en-us/entra/identity/enterprise-apps/grant-admin-consent?pivots=portal#grant-tenant-wide-admin-consent-in-enterprise-apps
