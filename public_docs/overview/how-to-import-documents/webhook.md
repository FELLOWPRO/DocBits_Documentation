# Webhook

Dzięki interfejsowi API Webhook udostępnionemu poniżej możesz łatwo przesyłać dokumenty bezpośrednio do DocBits za pomocą prostego żądania POST. To API zostało zaprojektowane tak, aby uprościć proces przesyłania plików do DocBits, a wszystkie niezbędne parametry są już za Ciebie wypełnione.

Aby rozpocząć, po prostu przejdź na następującą stronę (w zależności od używanego środowiska):

PROD: https://api.docbits.com/docs#/document/process\_documents\_document\_process\_documents\_post

SANDBOX: https://sandbox.api.docbits.com/docs#/document/process\_documents\_document\_process\_documents\_post

STAGE: https://stage.api.docbits.com/docs#/document/process\_documents\_document\_process\_documents\_post

Wykonaj wywołanie API przy użyciu swojego klucza API. Możesz również dołączyć plik, który chcesz przesłać, jako parametr wywołania.
