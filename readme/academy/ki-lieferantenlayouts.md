# Dieselbe Tabellenlogik für unterschiedliche Lieferantenlayouts

**Zielgruppe:** Buchhaltung und Key User · **Schwierigkeit:** Mittel · **Übungsdauer:** 10–20 Minuten

**Lernziel:** Sie möchten eine gemeinsame Feldstruktur verwenden, obwohl Lieferanten ihre Rechnungen unterschiedlich gestalten.

## Problem

Sie möchten eine gemeinsame Feldstruktur verwenden, obwohl Lieferanten ihre Rechnungen unterschiedlich gestalten.

## Beispieldokument

{% file src="../.gitbook/assets/academy-de-v1/rechnung-spaltenreihenfolge.pdf" %}

## Konfiguration

Richten Sie gemeinsame fachliche Spalten ein und prüfen Sie pro Lieferant die verwendete KI-Stufe beziehungsweise vorhandene klassische Regeln. Eine gemeinsame Logik garantiert keine identische Erkennungsqualität für alle Layouts.

## Ausführung

1. Vergleichen Sie rechnung-preisabweichung.pdf mit der Variante rechnung-spaltenreihenfolge.pdf aus dem Übungspaket.
2. Prüfen Sie beide Layouts unter getrennten Trainingslieferanten und vergleichen Sie dieselben drei Artikel.
3. Dokumentieren Sie die Spaltenzuordnung und alle lieferantenspezifischen Anweisungen getrennt.
4. Für 50 Lieferanten führen Sie eine Prüfliste je Layout mit mehreren Belegen, Grenzfällen und bestandenem Sollvergleich. Übernehmen Sie eine gemeinsame Vorgabe erst nach dieser Stichprobe.

## Ergebnis

Die beiden Übungsvarianten liefern fachlich dieselben drei Positionen und 1.325 EUR netto. Ein Ergebnis für zwei Varianten belegt noch keine Abnahme von 50 Lieferanten.

## Fehlerbehebung

Wenn nur ein Lieferant abweicht, dessen Regeln, Modell und Belegqualität prüfen. Eine erfolgreiche Korrektur nicht ungeprüft auf alle Lieferanten übertragen.
