# Tabellen ohne sichtbare Rahmenlinien

**Zielgruppe:** Buchhaltung und Key User · **Schwierigkeit:** Mittel · **Übungsdauer:** 10–20 Minuten

**Lernziel:** Rechnungspositionen sind nur durch Abstände ausgerichtet.

## Problem

Rechnungspositionen sind nur durch Abstände ausgerichtet.

## Beispieldokument

{% file src="../.gitbook/assets/academy-de-v1/rechnung-ohne-linien.pdf" %}
Synthetischer Übungsbeleg. Weitere Formate und Sollwerte im Übungspaket.
{% endfile %}

## Konfiguration

Verwenden Sie den isolierten Trainingslieferanten mit aktiver KI-Tabellenextraktion. Eine Rahmenlinie ist kein notwendiges Kriterium für eine Artikelposition.

## Ausführung

1. Importieren Sie die PDF und öffnen Sie KI Extrahierte Tabelle.
2. Vergleichen Sie ART-A, ART-B und ART-C mit dem Original. Prüfen Sie Menge, Einzelpreis und Nettobetrag einzeln.
3. Blenden Sie nicht zugeordnete Spalten ein und korrigieren Sie die fachliche Zuordnung bei Bedarf.
4. Kontrollieren Sie drei Zeilen und 1.325,00 EUR netto. Speichern Sie und prüfen Sie die Werte erneut.

## Ergebnis

Genau drei Positionen mit 500,00, 525,00 und 300,00 EUR netto.

## Fehlerbehebung

Bei zusammengefassten Texten prüfen Sie die tatsächlichen Zeilengrenzen. Geben Sie unter Anweisungen für die KI einen konkreten Hinweis und verwenden Sie Änderung testen; vergleichen Sie anschließend alle drei Positionen.
