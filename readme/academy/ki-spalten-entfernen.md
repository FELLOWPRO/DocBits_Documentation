# Nicht benötigte Spalten entfernen

**Zielgruppe:** Buchhaltung und Key User · **Schwierigkeit:** Mittel · **Übungsdauer:** 10–20 Minuten

**Lernziel:** Zusätzliche oder unzugeordnete Spalten verdecken die benötigten Rechnungswerte.

## Problem

Zusätzliche oder unzugeordnete Spalten verdecken die benötigten Rechnungswerte.

## Beispieldokument

{% file src="../.gitbook/assets/academy-de-v1/rechnung-spaltenreihenfolge.pdf" %}
Synthetischer Übungsbeleg. Weitere Formate und Sollwerte im Übungspaket.
{% endfile %}

## Konfiguration

Klären Sie vor dem Ausblenden, welche Spalten Validierung und Export benötigen. Ausblenden und fachliches Löschen eines Datenbedarfs sind unterschiedliche Dinge.

## Ausführung

1. Blenden Sie Nicht zugeordnete Spalten anzeigen ein und prüfen Sie die Werte.
2. Öffnen Sie bei einer entbehrlichen Spalte das Menü und wählen Sie Spalte löschen. Prüfen Sie den Bestätigungsdialog.
3. Verwenden Sie Tabellenspalte wiederherstellen, um die Spalte zurückzuholen.
4. Vergleichen Sie anschließend die erforderlichen Werte von ART-A, ART-B und ART-C.

## Ergebnis

Die Ansicht ist übersichtlich; alle benötigten Werte und Zuordnungen sind weiterhin geprüft. Der Nettobetrag bleibt 1.325 EUR.

## Fehlerbehebung

Fehlt eine Pflichtspalte, wiederherstellen beziehungsweise Leere gemappte Spalten hinzufügen prüfen. Nicht zugeordnete Spalten ausblenden korrigiert keine falsche Zuordnung.
