# Fehlerhafte Zeilen und Spalten korrigieren

**Zielgruppe:** Buchhaltung und Key User · **Schwierigkeit:** Mittel · **Übungsdauer:** 10–20 Minuten

**Lernziel:** Eine Tabelle enthält doppelte Zeilen, fehlende Werte oder falsch zugeordnete Spalten.

## Problem

Eine Tabelle enthält doppelte Zeilen, fehlende Werte oder falsch zugeordnete Spalten.

## Beispieldokument

{% file src="../.gitbook/assets/academy-de-v1/rechnung-30-positionen.pdf" %}
Synthetischer Übungsbeleg. Weitere Formate und Sollwerte im Übungspaket.
{% endfile %}

## Konfiguration

Verwenden Sie einen Beleg mit einer tatsächlich festgestellten Abweichung zum Original und bearbeiten Sie keine freigegebenen oder exportierten Belege. Ist die Tabelle bereits vollständig und richtig, bestätigen Sie dieses Ergebnis. Erzeugen Sie keinen Erkennungsfehler, um eine Korrektur vorzuführen.

## Ausführung

1. Vergleichen Sie Zeilen anhand Artikelnummer und PDF-Seite. Erfassen Sie den konkreten Fehler vor der Korrektur.
2. Nutzen Sie Neue Tabellenzeile hinzufügen für eine tatsächlich fehlende Position und entfernen Sie nur eine nachgewiesene zusätzliche Zeile.
3. Ordnen Sie eine falsche Spalte über den Spaltennamen zu. Prüfen Sie Formatierung und Preiseinheit.
4. Speichern und öffnen Sie erneut. Prüfen Sie exakt 30 Positionen und 3.005 EUR netto.

## Ergebnis

Es fehlen keine Artikel; doppelt erfasste Zeilen sind entfernt. Nach erneutem Öffnen bleiben Werte und Zuordnungen korrekt.

## Fehlerbehebung

Eine richtige Gesamtsumme kann fehlende und doppelte Zeilen verdecken. Vergleichen Sie zusätzlich jede Artikelnummer. Ein gesperrtes Dokument benötigt die passende Bearbeitungsberechtigung beziehungsweise Klärung der Sperre.
