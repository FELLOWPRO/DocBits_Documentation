# 供应商诊断与问题集群

点击队列中的供应商即可打开其诊断页面。

<figure><img src="../../../.gitbook/assets/touchless-supplier-detail.png" alt="供应商诊断页面，包含结果概览卡片、趋势图和两个问题集群"><figcaption><p>供应商诊断页面：结果概览卡片、带时间范围选择器的趋势图，以及按预期提升幅度排序的两个问题集群。示例组织使用演示数据；供应商名称均为虚构。</p></figcaption></figure>

页面显示：

* **六个结果概览卡片**（纯自动处理、应付账款自动处理、应付账款辅助处理、流程异常、处理中、不符合条件），每个卡片都链接到相关文档。
* **趋势图**及其独立的时间范围选择器：30 天、90 天、6 个月、1 年或自定义范围（最长两年）。这只会更改图表。
* **问题集群**（见下文）。
* **变更历史**：你为该供应商应用的变更及其影响。
* **近期示例**：示例文档分为两个选项卡：**需要关注**和**已实现自动处理**。
* **使用 AI 诊断供应商**：分析该供应商的所有集群（管理员）。

简短说明会解释页面为空的原因，例如：_该供应商的 5 份文档仍在处理中，尚无分析结果。_ 或 _该供应商已完成的 40 份文档均实现了自动处理：没有需要诊断的问题。_

### 问题集群

**集群**会将某个供应商因**相同的首要原因**而停止处理的文档归为一组。你看到的是“3 个问题”，而不是 40 个单独的问题。

<figure><img src="../../../.gitbook/assets/touchless-issue-cluster.png" alt="已展开的问题集群卡片，显示首要阻碍因素、变更建议和变更提案"><figcaption><p>已展开的集群卡片：首要阻碍因素、<strong>要更改的内容</strong>以及包含风险、范围和待解问题的<strong>变更提案</strong>。此处的集群涵盖 58 份文档，预期提升幅度为 +18.7 个百分点。示例组织使用演示数据；供应商名称均为虚构。</p></figcaption></figure>

**集群示例（仅供说明）。**

* **标题**：阶段 _字段验证_ 中的 _缺少必填字段_
* **受影响**：28 份文档。**可挽回**：28 份文档。**预期提升幅度**：+2.8 个百分点
* **疑似原因**：供应商将采购订单编号打印在表格下方，提取时不会查看该位置
* **要更改的内容**：_主数据变更_：添加该供应商的版式。点击 **打开** 可前往相应的设置页面
* **负责人**：顾问。**置信度**：中。**来源**：假设

集群卡片显示的内容：

| 部分 | 含义 |
| ------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **首要阻碍因素**和**阶段** | 文档停止处理的原因及其所在的流水线阶段。原因超过 30 种，例如 _未识别供应商_、_未找到采购订单_、_单价超出采购订单容差_、_被 ERP 拒绝_、_电子发票验证失败_ |
| **受影响 / 可挽回 / 预期提升幅度** | 受影响的文档数量、能够挽回的文档数量，以及可带来的百分点提升幅度 |
| **疑似原因 / 已确认原因** | DocBits 推测的原因（或人员确认的原因） |
| **证据**和**缺失证据** | 该发现的依据，以及 DocBits **无法**确认的内容。请先阅读**缺失证据**，再决定是否采信其余内容 |
| **要更改的内容** | 具体步骤及指向相关设置的**打开**链接。标签会说明类型：_配置变更_、_主数据变更_、_供应商模板变更_、_流程变更_、_需要供应商采取操作_、_无法修复_ |
| **负责人** | DocBits、客户、顾问、供应商或未分配 |
| **示例文档** | 可供查看的集群实际文档 |

**可在 DocBits 中修复**和**仅需供应商采取操作**会分组显示。对于_仅需供应商采取操作_的情况，DocBits 中的任何变更都不会改变结果：供应商必须更正文档并重新发送。

### 建议的来源

每个原因都会显示其**来源**，以便你区分推导出的发现和猜测：

| 来源 | 含义 |
| ---------------------------------- | ------------------------------------------------------------------------------------------------------ |
| **确定性** / **基于规则** | 根据记录的流水线证据推导出的规则。未使用语言模型 |
| **假设** | 语言模型根据集群证据提出的建议。请将其视为线索，并在采取行动前核实 |
| **已确认** | 人员审查证据后确认了原因 |

AI 文本使用你所在组织的语言。如果某个集群使用其他语言进行了分析，请使用**使用此语言分析**。

## 采购订单匹配集群

如果集群的首要阻碍因素属于采购订单匹配原因（例如_采购订单行项目不匹配_或_未找到采购订单_），集群卡片会显示 DocBits 如何尝试将发票与采购订单匹配。请参阅[采购订单匹配诊断](touchless-po-matching-diagnosis.md)。
