# Página de Relatórios

{% embed url="https://www.youtube.com/watch?v=ar9jXYJo_AM" %}

### 1. Como ativar a página de relatórios

Acesse **Settings** → **Document Processing** → **Module** → **Document Type** → **Show Report** e ative o botão para habilitar esta configuração.

![Enable Report Page Setting](https://raw.githubusercontent.com/Fellow-Consulting-AG/docbits/refs/heads/main/readme/.gitbook/assets/enable_report_page_setting.png)

### 2. **Como acessar a página de relatórios**

Siga estas etapas para acessar a **Report Page** no DocBits:

1. **Faça login no DocBits**
   * Abra o DocBits e faça login com suas credenciais.
2. **Clique no ícone de relatório**
   * Na barra lateral esquerda, localize e clique no ícone **Report** (representado por um gráfico).

![Report Icon in Sidebar](https://raw.githubusercontent.com/Fellow-Consulting-AG/docbits/refs/heads/main/readme/.gitbook/assets/image%20%28311%29.png)

### **3. Usar o filtro de unidade de tempo**

*   Na parte superior da página, você pode ajustar o filtro **Time Unit** para selecionar o período do relatório:

    * **Last 30 Days**
    * **Last 7 Days**
    * **Custom Time Frame** (intervalo de datas personalizado)

    ![Time Unit Filter](https://raw.githubusercontent.com/Fellow-Consulting-AG/docbits/refs/heads/main/readme/.gitbook/assets/time_unit_filter.png)

### **4. Exibição de novos documentos**

* Ao lado do filtro **Time Unit**, há uma exibição de informações chamada **New Documents**. Ela mostra o número de novos documentos importados no período selecionado.

![New Documents Display](https://raw.githubusercontent.com/Fellow-Consulting-AG/docbits/refs/heads/main/readme/.gitbook/assets/new_documents_display.png)

### **5. Exibição do tempo médio do sistema**

* Após o rótulo **New Documents**, você encontrará a exibição **Average System Time**. Ela mostra o tempo médio, em segundos, que o sistema levou para processar um novo documento no período selecionado.

![Average System Time Display](https://raw.githubusercontent.com/Fellow-Consulting-AG/docbits/refs/heads/main/readme/.gitbook/assets/average_system_time_display.png)

### **6. Seção de campos alterados**

* Abaixo das informações relacionadas ao tempo, você encontrará a seção **Changed Fields**. Ela exibe um diagrama que mostra com que frequência cada campo do documento foi modificado manualmente pelos usuários no período selecionado.
* Cada campo é exibido com o número correspondente de alterações, representado por barras no diagrama.

![Changed Fields Diagram](https://raw.githubusercontent.com/Fellow-Consulting-AG/docbits/refs/heads/main/readme/.gitbook/assets/image%20%28321%29.png)

* **Opções de download do diagrama**
  * No lado direito do diagrama **Changed Fields**, há um pequeno menu que permite baixar o diagrama em vários formatos. Você pode baixar o diagrama como:
    * **SVG**
    * **PNG**
    * **CSV**
  * Para baixar o diagrama, clique no menu e selecione o formato de arquivo desejado.

### **7. Seções adicionais do relatório**

Abaixo da seção **Changed Fields**, você encontrará quatro botões adicionais que fornecem informações mais detalhadas. Cada botão se expande para mostrar mais informações quando clicado.

1.  **Total Documents per Type**

    * Este botão exibe o número total de documentos de cada tipo de documento (por exemplo, fatura, pedido de compra etc.) no período selecionado.
    * Ao clicar no botão, ele se expande e mostra uma lista dos tipos de documento com a quantidade de documentos de cada tipo processados no período selecionado.

    ![Total Documents per Type Report](https://raw.githubusercontent.com/Fellow-Consulting-AG/docbits/refs/heads/main/readme/.gitbook/assets/total_documents_per_type_report.png)
2.  **Daily Average per Doctype**

    * Este botão mostra a média diária de documentos processados, categorizados por tipo de documento.
    * Ao clicar no botão, ele se expande e mostra os tipos de documento com a respectiva média diária.

    ![Daily Average per Doctype Report](https://raw.githubusercontent.com/Fellow-Consulting-AG/docbits/refs/heads/main/readme/.gitbook/assets/image%20%28324%29.png)
3.  **Status Statistic**

    * Este botão mostra a distribuição de status para cada tipo de documento (por exemplo, fatura, pedido de compra etc.). Ao clicar, ele se expande e exibe o status dos documentos de cada tipo, mostrando quantos documentos estão em cada categoria de status.

    ![Status Statistic Report](https://raw.githubusercontent.com/Fellow-Consulting-AG/docbits/refs/heads/main/readme/.gitbook/assets/status_statistic_report.png)
4.  **Export Statistic**

    * Este botão permite visualizar as estatísticas de exportação dos seus documentos. Ao clicar, ele se expande e fornece dados relacionados às exportações, como o número de exportações, as taxas de sucesso/falha e outras informações relevantes.

    ![Export Statistic Report](https://raw.githubusercontent.com/Fellow-Consulting-AG/docbits/refs/heads/main/readme/.gitbook/assets/export_statistic_report.png)
