# Licenças do Sistema

<figure><img src="../../.gitbook/assets/system_licenses.png" alt="Licenças do Sistema"><figcaption><p>Página Licenças do Sistema</p></figcaption></figure>

A página Licenças do Sistema (também chamada de Licenças da API) exibe todos os pacotes de software de terceiros utilizados pelo DocBits, incluindo seus números de versão e as licenças de código aberto associadas. Essas informações são fornecidas para fins de conformidade e transparência.
