# Systeemlicenties

<figure><img src="../../.gitbook/assets/system_licenses.png" alt="Systeemlicenties"><figcaption><p>Pagina Systeemlicenties</p></figcaption></figure>

De pagina Systeemlicenties (ook wel API-licenties genoemd) toont alle softwarepakketten van derden die door DocBits worden gebruikt, inclusief hun versienummers en de bijbehorende opensourcelicenties. Deze informatie wordt verstrekt voor naleving en transparantie.
