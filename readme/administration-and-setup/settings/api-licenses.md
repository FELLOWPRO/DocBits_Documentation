# System Licenses

<figure><img src="../../.gitbook/assets/system_licenses.png" alt="Licences système"><figcaption><p>Page des licences système</p></figcaption></figure>

La page System Licenses (également appelée API Licenses) affiche tous les packages logiciels tiers utilisés par DocBits, avec leurs numéros de version et les licences open source associées. Ces informations sont fournies à des fins de conformité et de transparence.
