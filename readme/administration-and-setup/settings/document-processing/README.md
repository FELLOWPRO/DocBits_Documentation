# Document Processing

Document processing settings determine how DocBits reads, checks, and exports documents. Start with the step where you see a problem instead of changing several settings at once.

| What you want to check | Guide |
| --- | --- |
| Text is missing or read incorrectly | [OCR Settings](ocr-settings.md) |
| A value should be compared with reference data | [Master Data Lookup](master-data-lookup.md) or [List Of Values](list-of-values.md) |
| A due date is unexpected | [Due Date Calculation](due-date-calculation.md) |
| A document should leave DocBits | [Export](export.md) |
| A rule should route or change a document | [Decision Trees](decision-trees.md) |

To reach the current settings, open the gear icon and use the **Document Processing** section in the left menu. Select the setting that matches your task. Check a change with a synthetic document before applying it to live processing. No OCR or export result was produced for this overview.
