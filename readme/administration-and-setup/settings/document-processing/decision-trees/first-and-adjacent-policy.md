# 首条及相邻规则策略

选择紧邻首条符合条件规则的规则所返回的结果。

**示例：**

| 规则 | 条件 | 返回组 |
| ---- | -------------------- | ------------ |
| 1    | 总金额 <= 1000 | GROUP_1     |
| 2    | 总金额 <= 2000 | GROUP_2     |
| 3    | 总金额 <= 3000 | GROUP_3     |
| 4    | 总金额 <= 4000 | GROUP_4     |
| 5    | 总金额 <= 5000 | GROUP_5     |

如果总金额为 **1500**，则会按以下顺序评估规则：

* **规则 1**：总金额 <= 1000（不符合）
* **规则 2**：总金额 <= 2000（符合）

由于 **规则 2** 是首条符合条件的规则，**首条及相邻规则**策略将应用 **规则 3** 的结果：**GROUP_3**。
