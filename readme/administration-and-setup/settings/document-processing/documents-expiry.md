# 文档过期时间

<figure><img src="../../../.gitbook/assets/site-complete-document-expiry-zh.png" alt="中文文档保留期限设置，包含一般文档和已完成文档两个独立选项；图示值仅为当前测试配置，未作更改。"><figcaption><p>中文文档保留期限设置，包含一般文档和已完成文档两个独立选项；图示值仅为当前测试配置，未作更改。</p></figcaption></figure>

在**设置 → 文档处理 → 文件到期**中，为一般文档和已完成文档分别设置自动删除的保留期限。更改前请确认组织的数据保留要求及所选文档范围。

## 两个独立选项

| 选项 | 用途 |
| --- | --- |
| **删除文档** | 设置一般文档的自动删除期限。 |
| **删除完成的文档** | 单独设置已完成文档的自动删除期限。 |

## 可选期限

| 选项 | 含义 |
| --- | --- |
| **默认** | 使用系统的默认期限，不设置自定义覆盖。 |
| **48 小时** | 选择 48 小时的期限。 |
| **1 周** | 选择一周的期限。 |
| **2 周** | 选择两周的期限。 |
| **4 周** | 选择四周的期限。 |

截图中的期限是测试环境的当前值，不是适用于所有组织的推荐值。请根据实际保留策略选择，随后使用测试文档检查处理结果。
