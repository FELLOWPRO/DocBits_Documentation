# List of Values

<figure><img src="../../../../.gitbook/assets/list_of_values.png" alt="List of Values"><figcaption><p>Página de List of Values</p></figcaption></figure>

List of Values le permite crear y gestionar listas de valores predefinidos que se utilizan en listas desplegables y en la validación de datos en todo DocBits. Estas listas garantizan una entrada de datos coherente y se pueden vincular a campos del documento.

## Tipos de listas

Existen dos tipos de listas:

* **System Lists** (icono de carpeta azul): listas preconfiguradas proporcionadas por DocBits (p. ej., ISO Currency, Invoice Type, Invoice Sub Type). No se pueden eliminar.
* **Custom Lists** (icono de carpeta oscura): listas que usted crea según sus necesidades (p. ej., centros de coste, códigos de impuestos). Se pueden editar y eliminar mediante el menú de acciones (tres puntos).

El número de la insignia junto a cada lista indica cuántos valores contiene.

## Ver una lista

Haga clic en cualquier lista del panel izquierdo para ver sus valores en el panel derecho. Cada entrada de valor muestra:

* **Value**: el valor real almacenado.
* **Display Name**: la etiqueta que se muestra a los usuarios en las listas desplegables.
* **Description**: una descripción opcional como referencia.

## Crear una lista nueva

1. Haga clic en **+ New** en la parte superior del panel izquierdo.
2. Introduzca un **List Name**.
3. Haga clic en **Save** para crear la lista vacía.
4. Seleccione la nueva lista y añada valores con el botón **Add** del panel derecho.

## Gestionar valores

* **Add**: haga clic en **Add** para insertar un nuevo valor en la lista seleccionada.
* **Edit**: haga clic en un valor existente para modificarlo.
* **Delete**: elimine valores individuales de una lista.
* **Import**: algunas listas admiten la importación masiva mediante CSV.

## Casos de uso

* **ISO Currency**: lista desplegable para seleccionar la moneda (EUR, USD, CHF, etc.).
* **Invoice Type / Sub Type**: categoriza las facturas por tipo.
* **Cost Centers**: asigna las líneas de los documentos a centros de coste.
* **Tax Codes**: selecciones predefinidas de códigos de impuestos para la contabilidad.
