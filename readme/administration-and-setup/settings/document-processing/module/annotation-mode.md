# Modalità annotazione

## Panoramica

L'impostazione **Annotation Mode** consente agli utenti di creare e gestire annotazioni direttamente su PDF. Se un documento contiene annotazioni, queste verranno incluse durante l'esportazione da **a IDM**.

## Posizione

Puoi trovare questa impostazione in: **Impostazioni → Elaborazione documenti → Modulo → Tipo documento → Modalità annotazione**

## Come usare la modalità annotazione

### 1. Attivazione della modalità annotazione

* Passare alla **Schermata di convalida**.
* Fai clic sull'icona **fumetto** a destra per accedere alla modalità Annotazione.

<div align="center"><figure><img src="../../../../.gitbook/assets/iScreen Shoter - Google Chrome - 250224105047.jpg" alt="Schermata di validazione in DocBits con l'icona del fumetto nella barra degli strumenti a destra per attivare la modalità di annotazione"><figcaption></figcaption></figure></div>

### 2. Creazione di un’annotazione

* Seleziona un'area su PDF in cui desideri inserire un'annotazione.
* Fare clic sull'icona **pen** per scrivere il testo.
* Fare clic sull'icona **document** per salvare l'annotazione.
* Fare clic sull'icona **cestino** per eliminare l'annotazione.

<div align="left"><figure><img src="../../../../.gitbook/assets/iScreen Shoter - Google Chrome - 250224105556.jpg" alt="Schermata di validazione con un PDF e l'annotazione Here is a annotation oltre alle icone di penna, salvataggio ed eliminazione"><figcaption></figcaption></figure></div>

*   Personalizza il testo utilizzando:

    * **Size** adjustment
    * **Bold**
    * _**Italic**_
    * <mark style="color:purple;">**Color**</mark>
    * **Font selection**

    <div align="left"><figure><img src="../../../../.gitbook/assets/iScreen Shoter - Google Chrome - 250224105351.jpg" alt="Finestra di dialogo Create/Edit Annotation con il tipo di carattere Helvetica, dimensione 12, grassetto, corsivo, Text-Color e il campo Annotation-Text"><figcaption></figcaption></figure></div>

### 3. Gestione delle annotazioni

* **Sposta un'annotazione** facendo clic e tenendo premuto il pulsante sinistro del mouse.
* **Crea più annotazioni** all'interno dello stesso documento.
* **Le annotazioni sono visibili solo** quando la modalità Annotazione è abilitata.
* Le annotazioni **saranno incluse** quando si esporta il documento in **IDM.**
* Se un documento contiene annotazioni, l'icona del fumetto  mostrerà un piccolo punto esclamativo  per indicarne la presenza.

<figure><img src="../../../../.gitbook/assets/iScreen Shoter - Google Chrome - 250224105935.jpg" alt="Barra degli strumenti destra della schermata di validazione con l'icona del fumetto e punto esclamativo che indica annotazioni esistenti"><figcaption></figcaption></figure>

*

<mark style="color:red;">**Nota:**</mark> Le annotazioni possono anche essere visualizzate, aggiunte e modificate direttamente nella **Schermata di approvazione**, consentendo agli utenti di apportare le modifiche necessarie durante il processo di approvazione.

### 4. Scaricamento dei PDF con o senza annotazioni

* Se un documento ha annotazioni, puoi scegliere di scaricare PDF con o senza annotazioni.
* Per fare ciò, vai su **Dashboard**.
* Clicca sui **tre punti** nella colonna **Azione**.
* Seleziona una delle due opzioni di download disponibili:
  * **Scarica con annotazioni**
  * **Scarica senza annotazioni**

<figure><img src="../../../../.gitbook/assets/iScreen Shoter - Google Chrome - 250224115302.jpg" alt="Menu delle azioni della dashboard in DocBits aperto con le opzioni Download, Download annotated PDF, Document Logs e Workflow Logs"><figcaption></figcaption></figure>

Abilitando e utilizzando la modalità Annotazione, gli utenti possono aggiungere, modificare e gestire in modo efficiente le annotazioni direttamente sui PDF, migliorando la collaborazione e la revisione dei documenti.
