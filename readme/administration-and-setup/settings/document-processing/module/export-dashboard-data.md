# Exportar dados do painel

1.  **Abrir as configurações**: aceda a **Configurações → Módulo**.\


    <figure><img src="../../../../.gitbook/assets/image (10) (1) (2) (1).png" alt=""><figcaption></figcaption></figure>
2.  **Ativar a exportação de dados do painel**: localize e ative **Export Dashboard Data**.\


    <figure><img src="../../../../.gitbook/assets/image (11) (1) (2) (1).png" alt=""><figcaption></figcaption></figure>
3. **Exportar o painel**: depois de ativar a opção, aparece um botão no painel que permite exportar os dados em CSV.
