# Esportare i dati della dashboard

1.  **Vai a Impostazioni**: Vai a **Impostazioni → Modulo**.\


    <figure><img src="../../../../.gitbook/assets/image (10) (1) (2) (1).png" alt="Pagina delle impostazioni con la navigazione Elaborazione documenti e la tabella di esportazione che mostra le colonne Tipo, Sotto-Organizzazioni, Titolo e Metodo Di Esportazione"><figcaption></figcaption></figure>
2.  **Abilita esportazione dati dashboard**: individua e attiva l'opzione **Esporta dati dashboard**.\


    <figure><img src="../../../../.gitbook/assets/image (11) (1) (2) (1).png" alt="Pagina delle impostazioni con la navigazione Elaborazione documenti e la tabella di esportazione che mostra le colonne Tipo, Sotto-Organizzazioni, Titolo e Metodo Di Esportazione"><figcaption></figcaption></figure>
3. **Esporta dashboard**: una volta abilitato, sulla dashboard verrà visualizzato un pulsante che consente di esportare i dati come file CSV.

<figure><img src="../../../../.gitbook/assets/image (14) (1) (2) (1).png" alt="Pagina delle impostazioni con la navigazione Elaborazione documenti e la tabella di esportazione che mostra le colonne Tipo, Sotto-Organizzazioni, Titolo e Metodo Di Esportazione"><figcaption></figcaption></figure>
