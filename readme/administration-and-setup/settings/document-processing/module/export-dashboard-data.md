# Exportar datos del panel

1.  **Navegue a Configuración**: Vaya a **Configuración → Módulo**.\


    <figure><img src="../../../../.gitbook/assets/image (10) (1) (2) (1).png" alt=""><figcaption></figcaption></figure>
2.  **Habilitar Exportar datos del panel**: Ubique y active la opción **Exportar datos del panel**.\


    <figure><img src="../../../../.gitbook/assets/image (11) (1) (2) (1).png" alt=""><figcaption></figcaption></figure>
3. **Exportar panel**: una vez habilitado, aparecerá un botón en el panel que le permitirá exportar los datos como un archivo CSV.
