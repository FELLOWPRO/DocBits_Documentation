# Eksport danych panelu

1.  **Przejdź do Ustawień**: Przejdź do **Ustawienia → Moduł**.\


    <figure><img src="../../../../.gitbook/assets/image (10) (1) (2) (1).png" alt=""><figcaption></figcaption></figure>
2.  **Włącz eksport danych panelu kontrolnego**: Znajdź i aktywuj opcję **Eksportuj dane panelu kontrolnego**.\


    <figure><img src="../../../../.gitbook/assets/image (11) (1) (2) (1).png" alt=""><figcaption></figcaption></figure>
3. **Eksportuj panel kontrolny**: Po włączeniu na panelu kontrolnym pojawi się przycisk umożliwiający eksport danych jako plik CSV.
