# 模型与标签

### 概述

启用 **模型与标签** 设置后，DocBits 中会显示 **AI 模型**区域。启用后，**分类与提取**设置页面会新增 **AI 模型**选项卡，您可以在此管理用于识别和提取文档数据的自定义 AI 模型。

此设置默认**关闭**。

### 有什么作用？

* **已启用** — **分类与提取**页面（设置 → 文档处理 → 分类与提取）会显示 **AI 模型**选项卡。您可以在此查看和管理组织的自定义模型。
* **已禁用** — **AI 模型**选项卡会隐藏，无法管理自定义模型。

{% hint style="info" %}
此设置用于控制对**自定义 AI 模型管理**的访问，适用于训练或维护自有提取模型的组织。
{% endhint %}

### 优势

* **自定义提取**：管理针对您自己的文档类型定制的 AI 模型。
* **持续提升识别效果**：维护驱动字段检测的模型。
* **按需显示**：只有需要此功能的组织才会看到 **AI 模型**选项卡。

### 如何使用

1. 转到 **设置**。
2. 选择 **文档处理**。
3. 选择 **模块**。
4. 打开 **文档类型**部分。
5. 找到 **模型与标签**，并打开开关。
6. 随后，**分类与提取**页面会显示 **AI 模型**选项卡，您可以在此管理自定义模型。

### 何时使用此功能

* **自定义 AI 模型**：组织使用自行训练的模型进行分类或提取时。
* **高级配置**：团队在文档处理过程中维护和调优模型时。
* 对于仅使用内置模型的标准配置，**请保持关闭**。
