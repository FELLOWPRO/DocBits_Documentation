# Show Report

### Descripción general

La opción **Show Report** añade una entrada **Report** al menú de navegación principal. Da a su equipo acceso con un clic a la página de informes, donde puede revisar la información sobre su procesamiento de documentos.

Esta opción está **desactivada de forma predeterminada**.

### ¿Qué hace?

* **Activada** — Aparece un elemento **Report** en el menú lateral, que enlaza con la página de informes. Los usuarios pueden abrirla para ver el informe.
* **Desactivada** — El elemento Report se elimina del menú.

### Beneficios

* **Información**: Acceda a los informes sobre su procesamiento de documentos directamente desde el menú.
* **Acceso rápido**: El informe está a un clic cuando se necesita.
* **Interfaz ordenada**: Mantenga el menú enfocado ocultando el informe para los equipos que no lo usan.

### Cómo usarla

1. Vaya a **Configuración**.
2. Seleccione **Procesamiento de documentos**.
3. Seleccione **Módulo**.
4. Abra la sección **Tipo de documento**.
5. Busque **Show Report** y active el interruptor.
6. Entonces aparece una entrada **Report** en el menú de navegación de la organización.

### Cuándo usar esta función

* **Supervisión y control**: Cuando los responsables o administradores quieren acceso rápido a los informes.
* **Revisiones periódicas**: Cuando el informe forma parte de la rutina de su equipo.
* **Déjela desactivada** si nadie necesita el informe, para mantener la navegación enfocada.
