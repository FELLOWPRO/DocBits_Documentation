# Show Report

### Visão geral

A configuração **Show Report** adiciona uma entrada **Report** ao menu de navegação principal. Ela dá à sua equipe acesso com um clique à página de relatórios, onde você pode revisar os relatórios sobre o processamento dos seus documentos.

Esta configuração está **desativada por padrão**.

### O que faz?

* **Ativada** — Um item **Report** aparece no menu lateral, com link para a página de relatórios. Os usuários podem abri-la para visualizar o relatório.
* **Desativada** — O item Report é removido do menu.

### Benefícios

* **Informação**: Acesse os relatórios sobre o processamento dos seus documentos diretamente pelo menu.
* **Acesso rápido**: O relatório está a um clique quando necessário.
* **Interface organizada**: Mantenha o menu focado ocultando o relatório para equipes que não o utilizam.

### Como usar

1. Vá para **Configurações**.
2. Selecione **Processamento de Documentos**.
3. Selecione **Módulo**.
4. Abra a seção **Tipo de Documento**.
5. Encontre **Show Report** e ligue o botão.
6. Uma entrada **Report** aparece então no menu de navegação da organização.

### Quando usar este recurso

* **Monitoramento e supervisão**: Quando supervisores ou administradores querem acesso rápido aos relatórios.
* **Revisões regulares**: Quando o relatório faz parte da rotina da sua equipe.
* **Deixe desativado** se ninguém precisar do relatório, para manter a navegação focada.
