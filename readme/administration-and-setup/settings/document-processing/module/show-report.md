# Show Report

### Überblick

Die Einstellung **Show Report** fügt dem Hauptnavigationsmenü einen Eintrag **Report** hinzu. Sie gibt Ihrem Team mit einem Klick Zugriff auf die Reporting-Seite, auf der Sie Auswertungen zu Ihrer Dokumentverarbeitung einsehen können.

Diese Einstellung ist **standardmäßig deaktiviert**.

### Was bewirkt die Einstellung?

* **Aktiviert** — Im Seitenmenü erscheint ein Eintrag **Report**, der zur Reporting-Seite führt. Benutzer können ihn öffnen, um die Auswertung anzusehen.
* **Deaktiviert** — Der Eintrag Report wird aus dem Menü entfernt.

### Vorteile

* **Einblick**: Erreichen Sie Auswertungen zu Ihrer Dokumentverarbeitung direkt aus dem Menü.
* **Schneller Zugriff**: Der Report ist bei Bedarf nur einen Klick entfernt.
* **Aufgeräumte Oberfläche**: Halten Sie das Menü übersichtlich, indem Sie den Report für Teams ausblenden, die ihn nicht nutzen.

### Verwendung

1. Gehen Sie zu **Einstellungen**.
2. Wählen Sie **Dokumentverarbeitung**.
3. Wählen Sie **Modul**.
4. Öffnen Sie den Abschnitt **Dokumenttyp**.
5. Finden Sie **Show Report** und schalten Sie den Schalter ein.
6. Im Navigationsmenü der Organisation erscheint dann ein Eintrag **Report**.

### Wann diese Funktion nutzen

* **Überwachung und Kontrolle**: Wenn Vorgesetzte oder Admins schnellen Zugriff auf Auswertungen wünschen.
* **Regelmäßige Überprüfungen**: Wenn der Report Teil der Routine Ihres Teams ist.
* **Ausgeschaltet lassen**, wenn niemand den Report benötigt, um die Navigation übersichtlich zu halten.
