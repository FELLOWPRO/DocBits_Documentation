# 任务和通知

### 概述

**任务和通知**设置可启用 DocBits 内置的任务管理功能。启用后，团队成员可以创建任务、将文档分配给彼此（例如用于验证、更正或审批），并接收相关通知。

此设置默认**禁用**。启用后，其下方会再显示四个选项：

* **仪表板任务计数**：在仪表板上标示哪些文档有未完成的任务。
* **允许非管理员用户使用“全部”筛选器**：允许非管理员用户查看所有任务。
* **非管理员任务删除**：决定非管理员用户可以删除哪些任务。
* **非管理员完成任务**：决定非管理员用户可以关闭哪些任务。

组织管理员始终不受这些选项的限制。

### 有什么作用？

* **已启用** — DocBits 中的任务和通知功能将变为可用。用户可以分配任务、跟踪任务状态，并在有事项需要处理时收到通知。
* **已禁用** — 任务分配及相关通知将关闭。关闭此设置也会关闭**仪表板任务计数**。

### 仪表板任务计数

**仪表板任务计数**用于控制仪表板是否标示哪些文档有未完成的任务。它不是一个计数器，而是在每个相关文档旁显示一个图标。

* **已启用** — 如果某个文档有状态为**未结**或**进行中**的任务，仪表板列表中该文档会显示一个任务图标。将鼠标悬停在图标上，会显示该文档未完成任务的数量，例如“2 未完成任务”。已完成、已拒绝或已删除的任务不计入其中。
* **已禁用** — 图标将隐藏。任务仍可正常使用。

{% hint style="info" %}
**仪表板任务计数**依赖于**任务和通知**。如果关闭任务和通知，仪表板任务计数也会随之关闭。
{% endhint %}

### 允许非管理员用户使用“全部”筛选器

任务概览中有一个**已分配至**筛选器，包含**全部**和**分配给我**两个选项。管理员始终可以使用这两个选项。

* **已启用** — 非管理员用户也可以选择**全部**，查看组织内的所有任务。
* **已禁用**（默认）— 非管理员用户只能选择**分配给我**，因此任务概览只显示分配给他们的任务。

### 非管理员任务删除

**非管理员任务删除**决定非管理员用户可以删除哪些任务和通知。管理员始终可以删除所有任务。

| 选项 | 非管理员用户可以删除 |
| --- | --- |
| **无** | 不能删除任何任务。 |
| **仅创建的任务** | 自己创建的任务。 |
| **创建的和分配的任务** | 自己创建的任务，以及分配给自己或自己所在某个组的任务。如果从未更改过此选项，则适用此行为。 |
| **所有任务** | 所有任务。 |

除选择**无**外，用户始终可以删除自己创建的任务。因此，未分配给任何人的任务只能由创建该任务的用户或管理员删除，或在选择**所有任务**时删除。未记录创建者的任务（例如由系统创建的任务）只能由被分配了该任务的用户（选择**创建的和分配的任务**时）或管理员删除，或在选择**所有任务**时删除。

{% hint style="warning" %}
删除任务会将其从任务列表中移除，而不会留下任何决定。如果任务只能通过决定来关闭，请将**非管理员任务删除**设置为**无**，并将**非管理员完成任务**（见下文）设置为**仅限管理员**。
{% endhint %}

### 非管理员完成任务
**非管理员完成任务**决定哪些非管理员用户可以关闭任务，即将任务设置为**完毕**或**被拒绝**。无论此处如何选择，管理员始终可以关闭任务。

| 选项 | 谁可以关闭任务 |
| --- | --- |
| **默认行为** | 此设置不增加任何限制。用户可以关闭分配给自己或自己所在某个组的任务，与此设置推出之前相同。如果从未更改过此选项，则适用此行为。 |
| **管理员和指定用户** | 管理员，以及直接或通过所在组被分配了该任务的用户。分配给其他人或未分配给任何人的任务，其他用户无法关闭。通过 API 更改任务时，DocBits 也会进行此项检查。 |
| **仅限管理员** | 仅管理员。 |

选择**管理员和指定用户**或**仅限管理员**时，无权关闭某个任务的用户：

* 在任务页面上看不到绿色的**完毕**按钮，且状态列表只提供**未结**和**进行中**；
* 无法点击文档任务面板中该任务的状态圆圈。将鼠标悬停在上面时，会显示“您无权将此任务标记为已完成或已拒绝。”；
* 在任务列表中看不到该任务的**标记为完成**；只要选中了此类任务，针对所选任务的**标记为完成**也会隐藏；
* 无法将任务拖到任务看板的**完毕**或**被拒绝**列中。卡片会回到原来的列，并显示同样的消息。

此设置只限制关闭任务。用户保留之前拥有的所有其他权限：被分配了任务的用户仍然可以编辑、保存该任务，在**未结**和**进行中**之间移动它，并在任务完成后重新打开它。未被分配该任务的用户之前就无法更改其状态，现在仍然无法更改。

对于启用了**批准历史**的文档类型，无论此处如何选择，**批准**仍会完成该文档的未完成任务：分配给审批人或其所在某个组的任务，以及未分配给任何人的任务。如果审批人是管理员，则该文档的所有未完成任务都会被完成。

#### 退回验证的文档上的任务

由于在**管理员和指定用户**或**仅限管理员**下用户无法自行关闭任务，当等待审批的文档被退回验证时，DocBits 会自动处理该文档的未完成任务：

* 审批界面上的**重新启动工作流程**：该文档的所有未完成任务都会被拒绝。
* **拒绝并纠正**：该文档的所有未完成任务都会被拒绝。
* **批准并更正**：**批准**会完成的任务（见上文）会被完成，仅适用于启用了**批准历史**的文档类型。其余所有未完成任务都会被拒绝。

这些未完成任务会在文档返回验证之前被处理。随后，在状态变更时运行的工作流可以为仍需处理的事项创建新任务。

选择**默认行为**时，文档被退回后，未完成任务仍保持未完成状态，与以前相同。

### 优势

* **职责明确**：可以将文档分配给合适的人员，无需依赖电子邮件。
* **不遗漏任何事项**：通知会提醒用户处理需要他们跟进的文档。
* **未完成工作一目了然**：使用仪表板任务计数后，仪表板会标示哪些文档仍有未完成的任务。
* **决定可追溯**：借助删除和完成选项，任务只能通过决定或由管理员移出队列。

### 如何使用

1. 前往**设置**。
2. 选择**文档处理**。
3. 选择**模块**。
4. 打开**文档类型**部分。
5. 打开**任务和通知**。
6. （可选）打开**仪表板任务计数**，在仪表板上显示任务图标。
7. （可选）如果所有用户都应能查看所有任务，请打开**允许非管理员用户使用“全部”筛选器**。
8. （可选）在**非管理员任务删除**中选择用户可以删除哪些任务。
9. （可选）在**非管理员完成任务**中选择谁可以关闭任务。

删除和完成选项在您选择值后会立即保存。

### 何时使用此功能

* **需要协同处理文档的团队**：如果多人需要验证或审批文档，并需要互相交接工作，请启用此功能。
* **查看工作量**：如果团队需要在仪表板上看到哪些文档仍有未完成的任务，也请启用仪表板任务计数。
* **只能由管理员或通过决定关闭的任务**：如果用户不得移除并未真正完成的任务，请将**非管理员完成任务**设置为**仅限管理员**或**管理员和指定用户**，并将**非管理员任务删除**设置为**无**。
* **单用户或全自动化设置**：如果无需任何人分配文档或跟踪任务，可以保持关闭。
