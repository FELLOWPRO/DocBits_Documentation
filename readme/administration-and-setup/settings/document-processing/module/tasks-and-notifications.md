# Tâches et notifications

### Aperçu

Le paramètre **Tâches et notifications** (Tasks & Notifications) active la gestion des tâches intégrée à DocBits. Lorsqu'il est activé, les membres de l'équipe peuvent créer des tâches, s'attribuer des documents (par exemple pour la validation, la correction ou l'approbation) et recevoir des notifications à leur sujet. Il déverrouille également l'option **Compteur de tâches du tableau de bord** décrite ci-dessous.

Ce paramètre est **désactivé par défaut**.

### Que fait ce paramètre ?

* **Activé** — Les fonctions Tâches et notifications deviennent disponibles dans DocBits. Les utilisateurs peuvent attribuer des tâches, suivre leur statut et être notifiés lorsqu'un élément requiert leur attention.
* **Désactivé** — L'attribution des tâches et les notifications associées sont désactivées. (La désactivation désactive également automatiquement le **Compteur de tâches du tableau de bord**.)

### Compteur de tâches du tableau de bord

Le **Compteur de tâches du tableau de bord** (Dashboard Tasks Count) est une option supplémentaire qui n'apparaît que lorsque **Tâches et notifications** est activé. Il contrôle l'affichage d'un **compteur de tâches** sur le tableau de bord.

* **Activé** — Le tableau de bord indique combien de documents sont en attente (par exemple dans votre file d'attente et prêts pour la validation), de sorte que l'équipe voit d'un coup d'œil la quantité de travail en cours.
* **Désactivé** — Le compteur est masqué. Les tâches fonctionnent normalement ; seul le nombre sur le tableau de bord n'est pas affiché.

{% hint style="info" %}
Le **Compteur de tâches du tableau de bord** dépend de **Tâches et notifications**. Si vous désactivez Tâches et notifications, le compteur de tâches est également désactivé.
{% endhint %}

### Avantages

* **Responsabilités claires** : Les documents peuvent être attribués à la bonne personne au lieu de s'appuyer sur les e-mails.
* **Rien n'est oublié** : Les notifications rappellent aux utilisateurs les documents qui nécessitent leur action.
* **Charge de travail en un coup d'œil** : Avec le Compteur de tâches du tableau de bord, l'équipe voit immédiatement combien de documents restent ouverts.

### Utilisation

1. Allez dans **Paramètres**.
2. Sélectionnez **Traitement des documents**.
3. Sélectionnez **Module**.
4. Ouvrez la section **Type de document**.
5. Activez **Tâches et notifications**.
6. (Facultatif) Une fois activé, le commutateur **Compteur de tâches du tableau de bord** apparaît en dessous — activez-le pour afficher le compteur de tâches sur le tableau de bord.

### Quand utiliser cette fonction

* **Équipes qui partagent le travail sur les documents** : Activez-la lorsque plusieurs personnes valident ou approuvent des documents et doivent se transmettre le travail.
* **Visibilité de la charge de travail** : Activez également le Compteur de tâches du tableau de bord lorsque les responsables souhaitent voir le travail en cours directement sur le tableau de bord.
* **Configurations mono-utilisateur ou entièrement automatisées** : Vous pouvez la laisser désactivée si personne n'a besoin d'attribuer des documents ni de suivre des tâches.
