# Aufgaben & Benachrichtigungen

### Überblick

Die Einstellung **Aufgaben & Benachrichtigungen** (Tasks & Notifications) aktiviert die integrierte Aufgabenverwaltung von DocBits. Wenn sie aktiviert ist, können Teammitglieder Aufgaben erstellen, sich gegenseitig Dokumente zuweisen (z. B. zur Validierung, Korrektur oder Genehmigung) und Benachrichtigungen dazu erhalten. Außerdem schaltet sie die unten beschriebene Option **Dashboard-Aufgabenzähler** frei.

Diese Einstellung ist **standardmäßig deaktiviert**.

### Was bewirkt die Einstellung?

* **Aktiviert** — Die Funktionen für Aufgaben & Benachrichtigungen werden in DocBits verfügbar. Benutzer können Aufgaben zuweisen, ihren Status verfolgen und benachrichtigt werden, wenn etwas ihre Aufmerksamkeit erfordert.
* **Deaktiviert** — Aufgabenzuweisung und die zugehörigen Benachrichtigungen sind ausgeschaltet. (Das Ausschalten schaltet auch den **Dashboard-Aufgabenzähler** automatisch aus.)

### Dashboard-Aufgabenzähler

Der **Dashboard-Aufgabenzähler** (Dashboard Tasks Count) ist eine zusätzliche Option, die nur erscheint, wenn **Aufgaben & Benachrichtigungen** aktiviert ist. Er steuert, ob im Dashboard ein **Aufgabenzähler** angezeigt wird.

* **Aktiviert** — Das Dashboard zeigt, wie viele Dokumente warten (z. B. in Ihrer Warteschlange und bereit zur Validierung), sodass das Team auf einen Blick sieht, wie viel Arbeit offen ist.
* **Deaktiviert** — Der Zähler wird ausgeblendet. Aufgaben funktionieren weiterhin normal; nur die Zahl im Dashboard wird nicht angezeigt.

{% hint style="info" %}
Der **Dashboard-Aufgabenzähler** hängt von **Aufgaben & Benachrichtigungen** ab. Wenn Sie Aufgaben & Benachrichtigungen ausschalten, wird auch der Aufgabenzähler ausgeschaltet.
{% endhint %}

### Vorteile

* **Klare Zuständigkeiten**: Dokumente können der richtigen Person zugewiesen werden, statt sich auf E-Mails zu verlassen.
* **Nichts wird vergessen**: Benachrichtigungen erinnern Benutzer an Dokumente, die ihr Handeln erfordern.
* **Arbeitslast auf einen Blick**: Mit dem Dashboard-Aufgabenzähler sieht das Team sofort, wie viele Dokumente noch offen sind.

### Verwendung

1. Gehen Sie zu **Einstellungen**.
2. Wählen Sie **Dokumentverarbeitung**.
3. Wählen Sie **Modul**.
4. Öffnen Sie den Abschnitt **Dokumenttyp**.
5. Schalten Sie **Aufgaben & Benachrichtigungen** ein.
6. (Optional) Sobald es aktiviert ist, erscheint darunter der Schalter **Dashboard-Aufgabenzähler** — schalten Sie ihn ein, um den Aufgabenzähler im Dashboard anzuzeigen.

### Wann diese Funktion nutzen

* **Teams, die sich Dokumentarbeit teilen**: Aktivieren Sie sie, wenn mehrere Personen Dokumente validieren oder genehmigen und Arbeit aneinander übergeben müssen.
* **Sichtbarkeit der Arbeitslast**: Aktivieren Sie zusätzlich den Dashboard-Aufgabenzähler, wenn Vorgesetzte offene Arbeit direkt im Dashboard sehen möchten.
* **Einzelnutzer- oder vollautomatische Setups**: Sie können sie ausgeschaltet lassen, wenn niemand Dokumente zuweisen oder Aufgaben verfolgen muss.
