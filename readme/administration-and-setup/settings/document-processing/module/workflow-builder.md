# Workflow Builder

### Przegląd

Ustawienie **Workflow Builder** aktywuje **DocFlow** dla Twojej organizacji. DocFlow to silnik przepływów pracy, który automatyzuje to, co dzieje się z Twoimi dokumentami — kierowanie, kroki zatwierdzania, warunki i działania następcze. Gdy to ustawienie jest włączone, projektant przepływów pracy DocFlow staje się dostępny, a dokumenty przechodzą przez tworzone przez Ciebie przepływy.

Jest to funkcja **oparta na subskrypcji** i **domyślnie wyłączona**.

### Co robi to ustawienie?

Włączenie przełącznika nie tylko zmienia ustawienie — uruchamia **subskrypcję DocFlow**. Pojawia się okno dialogowe, w którym wybierasz swój plan DocFlow (DocFlow Standard oraz opcjonalnie DocFlow Advanced). Ustawienie jest aktywowane dopiero po potwierdzeniu subskrypcji.

* **Włączone** — DocFlow jest aktywowany dla organizacji. Dokumenty są kierowane przez Twoje przepływy pracy, a projektant Workflow Builder jest dostępny do ich tworzenia i edycji.
* **Wyłączone** — DocFlow zostaje wyłączony, a powiązana subskrypcja anulowana. Dokumenty nie przechodzą już przez przepływy pracy.

{% hint style="info" %}
**Workflow Builder to główny przełącznik, który włącza lub wyłącza DocFlow dla całej organizacji.** Ponieważ zarządza subskrypcją, włączenie go otwiera okno wyboru planu, a wyłączenie anuluje aktywną subskrypcję DocFlow.
{% endhint %}

### Korzyści

* **Automatyzacja**: Zastąp ręczne przekazywanie zautomatyzowanymi krokami (kierowanie, zatwierdzenia, warunki).
* **Spójność**: Każdy dokument przechodzi przez ten sam zdefiniowany proces.
* **Widoczność**: Przepływy pracy są projektowane i zarządzane w jednym miejscu.

### Jak używać

1. Przejdź do **Ustawienia**.
2. Wybierz **Przetwarzanie dokumentów**.
3. Wybierz **Moduł**.
4. Otwórz sekcję **Typ dokumentu**.
5. Znajdź **Workflow Builder** i włącz przełącznik.
6. W oknie dialogowym wybierz swój plan DocFlow (Standard, opcjonalnie Advanced) i potwierdź. DocFlow zostaje aktywowany po utworzeniu subskrypcji.
7. Następnie zaprojektuj swoje przepływy pracy dla dokumentów w DocFlow — zobacz sekcję [Workflow](../../../workflow/README.md), jak je tworzyć.

### Kiedy używać tej funkcji

* **Zautomatyzowane procesy dokumentowe**: Gdy dokumenty muszą przechodzić przez zdefiniowane kroki, takie jak przegląd, zatwierdzenie lub kierowanie.
* **Przepływy pracy zespołu**: Gdy w obsłudze dokumentu uczestniczy kilka osób lub ról.
* **Pozostaw wyłączone**, jeśli Twoja organizacja nie korzysta z DocFlow / przepływów pracy dokumentów (wyłączenie anuluje również subskrypcję DocFlow).
