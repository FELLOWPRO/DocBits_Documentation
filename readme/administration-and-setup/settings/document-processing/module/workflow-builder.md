# Workflow Builder

### Visão geral

A configuração **Workflow Builder** ativa o **DocFlow** para a sua organização. O DocFlow é o mecanismo de fluxos de trabalho que automatiza o que acontece com os seus documentos — roteamento, etapas de aprovação, condições e ações de acompanhamento. Quando esta configuração está ativada, o designer de fluxos de trabalho do DocFlow fica disponível e os documentos passam pelos fluxos que você cria.

É um recurso **baseado em assinatura** e está **desativado por padrão**.

### O que faz?

Ligar o botão não apenas altera uma configuração — ele inicia uma **assinatura do DocFlow**. Aparece uma caixa de diálogo onde você escolhe o seu plano DocFlow (DocFlow Standard e, opcionalmente, DocFlow Advanced). A configuração só é ativada após a confirmação da assinatura.

* **Ativada** — O DocFlow é ativado para a organização. Os documentos são roteados pelos seus fluxos de trabalho e o designer do Workflow Builder fica disponível para criá-los e editá-los.
* **Desativada** — O DocFlow é desligado e a assinatura correspondente é cancelada. Os documentos não passam mais pelos fluxos de trabalho.

{% hint style="info" %}
**O Workflow Builder é o interruptor principal que liga ou desliga o DocFlow para toda a organização.** Como ele gerencia uma assinatura, ativá-lo abre uma caixa de seleção de plano e desativá-lo cancela a assinatura ativa do DocFlow.
{% endhint %}

### Benefícios

* **Automação**: Substitua as transferências manuais por etapas automatizadas (roteamento, aprovações, condições).
* **Consistência**: Cada documento segue o mesmo processo definido.
* **Visibilidade**: Os fluxos de trabalho são projetados e gerenciados em um só lugar.

### Como usar

1. Vá para **Configurações**.
2. Selecione **Processamento de Documentos**.
3. Selecione **Módulo**.
4. Abra a seção **Tipo de Documento**.
5. Encontre **Workflow Builder** e ligue o botão.
6. Na caixa de diálogo, escolha o seu plano DocFlow (Standard, opcionalmente Advanced) e confirme. O DocFlow é ativado assim que a assinatura é criada.
7. Depois, projete os seus fluxos de trabalho de documentos no DocFlow — consulte a seção [Workflow](../../../workflow/README.md) para saber como criá-los.

### Quando usar este recurso

* **Processos de documentos automatizados**: Quando os documentos precisam passar por etapas definidas, como revisão, aprovação ou roteamento.
* **Fluxos de trabalho em equipe**: Quando várias pessoas ou funções estão envolvidas no tratamento de um documento.
* **Deixe desativado** se a sua organização não usa o DocFlow / fluxos de trabalho de documentos (desativá-lo também cancela a assinatura do DocFlow).
