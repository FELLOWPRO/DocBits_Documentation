# Workflow Builder

### Überblick

Die Einstellung **Workflow Builder** aktiviert **DocFlow** für Ihre Organisation. DocFlow ist die Workflow-Engine, die automatisiert, was mit Ihren Dokumenten geschieht — Weiterleitung, Genehmigungsschritte, Bedingungen und Folgeaktionen. Wenn diese Einstellung aktiviert ist, wird der DocFlow-Workflow-Designer verfügbar und Dokumente durchlaufen die von Ihnen erstellten Workflows.

Dies ist eine **abonnementbasierte** Funktion und **standardmäßig deaktiviert**.

### Was bewirkt die Einstellung?

Das Einschalten des Schalters legt nicht nur einen Schalter um — es startet ein **DocFlow-Abonnement**. Es erscheint ein Dialog, in dem Sie Ihren DocFlow-Plan auswählen (DocFlow Standard und optional DocFlow Advanced). Die Einstellung wird erst nach Bestätigung des Abonnements aktiviert.

* **Aktiviert** — DocFlow ist für die Organisation aktiviert. Dokumente werden durch Ihre Workflows geleitet und der Workflow-Builder-Designer steht zum Erstellen und Bearbeiten zur Verfügung.
* **Deaktiviert** — DocFlow wird abgeschaltet und das zugehörige Abonnement gekündigt. Dokumente durchlaufen keine Workflows mehr.

{% hint style="info" %}
**Der Workflow Builder ist der Hauptschalter, der DocFlow für die gesamte Organisation ein- oder ausschaltet.** Da er ein Abonnement verwaltet, öffnet das Aktivieren einen Plan-Auswahldialog, und das Deaktivieren kündigt das aktive DocFlow-Abonnement.
{% endhint %}

### Vorteile

* **Automatisierung**: Ersetzen Sie manuelle Übergaben durch automatisierte Schritte (Weiterleitung, Genehmigungen, Bedingungen).
* **Einheitlichkeit**: Jedes Dokument folgt demselben definierten Prozess.
* **Übersicht**: Workflows werden an einem Ort entworfen und verwaltet.

### Verwendung

1. Gehen Sie zu **Einstellungen**.
2. Wählen Sie **Dokumentverarbeitung**.
3. Wählen Sie **Modul**.
4. Öffnen Sie den Abschnitt **Dokumenttyp**.
5. Finden Sie **Workflow Builder** und schalten Sie den Schalter ein.
6. Wählen Sie im Dialog Ihren DocFlow-Plan (Standard, optional Advanced) und bestätigen Sie. DocFlow wird aktiviert, sobald das Abonnement erstellt ist.
7. Entwerfen Sie anschließend Ihre Dokument-Workflows in DocFlow — siehe den Abschnitt [Workflow](../../../workflow/README.md), wie Sie sie erstellen.

### Wann diese Funktion nutzen

* **Automatisierte Dokumentprozesse**: Wenn Dokumente definierte Schritte wie Prüfung, Genehmigung oder Weiterleitung durchlaufen müssen.
* **Team-Workflows**: Wenn mehrere Personen oder Rollen an der Bearbeitung eines Dokuments beteiligt sind.
* **Ausgeschaltet lassen**, wenn Ihre Organisation kein DocFlow / keine Dokument-Workflows nutzt (das Ausschalten kündigt auch das DocFlow-Abonnement).
