# 案例 15：明细费用的单位费用超出容差（已拒绝）

以下场景用于说明一种已配置的映射，并不代表已核实部署的默认模板。实际输出、金额、正负号和文档类型取决于当前生效的 `conflict_resolution` 规则与表达式、导出映射及审批决定。下文提到的借项通知单或贷项通知单均以这些配置为前提；示例不保证自动开具，也不保证符合法律要求。

## 场景

费用明细中的单位费用超出容差，且偏差未获审批。此案例涉及明细费用，而非表头费用。

## 示例操作

如果映射配置为在拒绝偏差后使用 PO 费用，则会将发票上的单位费用替换为 PO 值。任何单独调整、借项通知单或贷项通知单均取决于导出映射及审批决定。

## 示例

* **采购订单（PO）：**
  * 明细单位费用：$4.00
  * 数量：1,500 件
  * 明细费用总额：$6,000.00
* **收到的发票：**
  * 明细单位费用：$5.00——比 PO 值高 25%，超出已配置的 ±5% 容差；偏差已拒绝。
  * 数量：1,500 件
  * 明细费用总额：$7,500.00
* **已配置的容差：** 单位费用 ±5%。

在此示例映射中：

1. 拒绝发票上的 $5.00 单位费用，因为 25% 的偏差超出 ±5% 容差且未获审批。
2. 使用 PO 单位费用 $4.00。
3. 重新计算明细费用总额：**1,500 件 × $4.00 = $6,000.00**。
4. 计算多收的金额：**$7,500.00 - $6,000.00 = $1,500.00**。
5. 按配置处理差额。开具 $1,500.00 的贷项通知单是映射可能产生的结果之一，并非系统保证执行的操作。金额、正负号、文档类型及是否开具，均取决于生效的规则、导出映射和审批结果。

在生产环境使用此场景前，请验证明细费用映射及其生成的会计文档。
