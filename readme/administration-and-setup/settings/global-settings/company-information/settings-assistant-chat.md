# 设置助手：聊天功能介绍

## 概述

**设置助手**的聊天功能可以解答有关设置的问题，在导入停止工作时向你发出警告，并在你确认后代你更改设置。使用前，管理员必须[开启助手](settings-assistant.md)。

### 功能介绍

| 你的需求 | 示例 | 助手会提供 |
| --- | --- | --- |
| 查找设置 | “在哪里可以找到电子邮件导入设置？” | 设置路径（例如“设置 / 导入”），以及可跳转到设置并突出显示该设置的**打开设置**按钮 |
| 了解设置 | “如何启用条码检测？” | 对每项匹配设置的简短说明：何时应启用、何时应保持关闭 |
| 检查配置 | “为什么 PO 匹配没有启用？” | 组织中每项相关设置的当前值（**当前：开启**或**当前：关闭**），以及阻止该功能的设置 |
| 发现导入故障 | 面板顶部的红色卡片 | 出现故障的邮箱或 FTP 连接、故障频率以及可能的原因 |
| 安全地更改设置 | 在发现卡片中对故障邮箱点击**关闭** | 更改预览。确认前不会保存任何内容。每项更改都可以撤销。 |
| 了解页面 | **观看视频说明** | 当前页面的简短视频（部分页面提供） |

{% hint style="info" %}
助手使用 **Fast** AI 层级。组织设置中无法选择其他模型。
{% endhint %}

## 提问

在底部的输入框（“询问有关设置的问题……”）中输入问题，然后按 **Enter**。助手会显示当前操作（“正在读取配置……”“正在搜索文档……”“正在撰写答案……”），你随时可以点击 **停止**来中止。

### 面板会识别你所在的页面

在设置页面打开面板时，助手会针对**当前页面**向你问候，并提供三个相关问题。以下是真实示例：

| 页面 | 示例问题 |
| --- | --- |
| 公司信息 | “如何更改公司地址？”、“在哪里上传徽标？”、“为我们的组织注册了哪些域名？” |
| 导入 | “我们是否启用了电子邮件导入？”、“应该将文档发送到哪个电子邮件地址？”、“如何设置 FTP 或 SFTP 导入？” |
| 分类与提取 | “提取使用的是哪个 AI 模型？”、“我们是否启用了按条码拆分文档？”、“能否为某个供应商使用不同的 AI 模型？” |
| 用户 | “如何邀请新用户？”、“如何将用户设为管理员？”、“如何停用用户？” |
| 设置概览 | “如何启用条码检测？”、“为什么 PO 匹配没有启用？”、“在哪里可以找到电子邮件导入设置？” |

点击某个问题后，问题会立即发送。三个问题下方还会显示 *我也可以帮助你了解其他设置，随时提问。* 在对话过程中，面板底部会一直显示 **帮助了解此页面**按钮，提示“我可以在此页面配置什么？”

### 示例 1：查找设置

你询问：**“如何更改公司地址？”**

<figure><img src="../../../../.gitbook/assets/settings-assistant-answer-company-address.png" alt="助手回答了公司地址所在的路径，并提供了一个打开设置按钮"><figcaption><p>答案会指出设置所在位置，卡片则会提供准确路径和<strong>打开设置</strong>按钮。</p></figcaption></figure>

答案会说明地址所在的位置。下方的卡片会显示路径（**设置 / 公司设置**）和**打开设置**按钮。点击该按钮，DocBits 会打开相应页面，滚动到该设置并将其突出显示几秒钟。

### 示例 2：了解名称相近的设置

你询问：**“如何启用条码检测？”**

<figure><img src="../../../../.gitbook/assets/settings-assistant-answer-barcode.png" alt="助手说明了三项条码设置以及各自的启用时机"><figcaption><p>当一个词对应多项设置时，助手会逐项列出，并说明<strong>适合启用的情况</strong>和<strong>适合关闭的情况</strong>。</p></figcaption></figure>

“条码检测”可能指三项不同的设置，因此助手会询问：*你指的是：QR 码提取、条码分配，还是按条码拆分文档？* 并逐项说明：

* **QR 码提取**：在处理过程中自动读取支持的条码和 QR 码。如果文档包含有用的编码，请启用此项。
* **条码分配**：允许审核人员在验证期间手动将解码后的条码值分配给字段。此功能需要先通过提取检测到编码，并且不会让处理流程变为无人值守。
* **按条码拆分文档**：在分隔页处将一个上传文件拆分为多个文档。仅当分隔编码可靠时使用此项。

### 示例 3：了解某项功能为何没有生效

你询问：**“为什么 PO 匹配没有启用？”**

<figure><img src="../../../../.gitbook/assets/settings-assistant-answer-po-matching.png" alt="助手显示了每项 PO 匹配设置的当前值"><figcaption><p>对于“为什么”类问题，助手会读取你的配置，并显示每项设置的<strong>当前</strong>值。</p></figcaption></figure>

助手会读取组织的设置并报告结果。在此示例中，四种文档类型的 PO 匹配均为**开启**，而**如果 PO 匹配度为 100%，则自动导出**设置为**关闭**，因此不会执行自动匹配和导出。每张卡片都会显示**当前：开启 / 关闭**和**打开设置**按钮，方便你立即修复。

### 示例 4：PO 匹配

你打开**设置 → 文档类型**并询问：**“发票是否启用了 PO 匹配？”**（此问题也是该页面提供的三个建议问题之一。）

<figure><img src="../../../../.gitbook/assets/settings-assistant-in-document-types-po-matching.png" alt="设置中的文档类型页面，右侧打开了设置助手。助手回答发票已启用 PO 匹配，并显示了三项相关设置"><figcaption><p>右侧打开了助手的<strong>文档类型</strong>页面。答案显示<strong>你的组织已为发票启用 PO 匹配</strong>，并列出三项相关设置：<strong>PO 匹配</strong>（当前：开启）、<strong>PO 匹配规则</strong>以及<strong>如果 PO 匹配度为 100%，则自动导出</strong>（当前：关闭）。</p></figcaption></figure>

助手会读取该文档类型的设置，并补充与之相关的其他设置。在此示例中，匹配已开启，但匹配度达到 100% 后自动导出已关闭，因此匹配成功的发票仍需等待人工处理。每张卡片都带有**打开设置**按钮。

* 有关**匹配规则和容差**，请参阅[采购订单匹配规则](../document-types/more-settings/purchase-order/purchase-order-matching-rules.md)。
* 若要查看**供应商的文档为何未匹配**，请打开[无接触式智能：PO 匹配诊断](../../../touchless-po-matching-diagnosis.md)。此页面会显示原因、受影响的文档和决策流程。

### 示例 5：字段验证（自定义验证规则）

在**设置 → 文档类型 → 自定义验证规则**页面，面板会针对当前页面向你问候，并建议三个问题。

<figure><img src="../../../../.gitbook/assets/settings-assistant-in-custom-validation-rules.png" alt="设置中的自定义验证规则页面，中间显示规则列表，右侧的设置助手提供了三个建议问题"><figcaption><p>右侧打开了助手的<strong>自定义验证规则</strong>页面。规则列表位于中间，面板提供的三个建议问题是：<strong>此文档类型有哪些验证规则？</strong>、<strong>如何创建新的验证规则？</strong>以及<strong>验证规则失败时会发生什么？</strong></p></figcaption></figure>

你可以在此使用助手来**查找**相关设置并了解规则的作用。若要**创建或更改**规则，请直接在此页面操作：请参阅[自定义验证规则](../document-types/custom-validation-rules.md)和[复制自定义验证规则](../document-types/duplicate-a-custom-validation-rule.md)。如果助手为你创建规则，该规则始终处于**未激活**状态，需要你手动启用。

{% hint style="info" %}
请勿混淆**自定义验证规则**（文档类型字段的规则）和**电子发票验证**（对 XRechnung、ZUGFeRD 和 Factur-X 文件的检查）。这是两个不同的页面。
{% endhint %}

### 示例 6：还可以尝试这些问题

* “提取使用的是哪个 AI 模型？”
* “我们是否启用了按条码拆分文档？”
* “如何停用用户？”
* “在哪里设置文档的保留时长？”
* “哪些设置会影响无接触率？”
* “给我看看供应商门户设置的屏幕截图。”

{% hint style="info" %}
如果问题不属于设置范围，或者助手无法从它掌握的 DocBits 信息中找到相关内容，它会如实告知。例如，如果你询问的内容不是设置，助手会回复 *在此处提供的 DocBits 信息中找不到有关……的内容*，并附上最接近的页面链接。它不会猜测。
{% endhint %}

### 答案中的链接和屏幕截图

* 答案可以包含**查看文档**链接。这些链接只会指向 docs.docbits.com，并在新标签页中打开。如果你的环境支持文档搜索，答案中才会显示文档链接。
* 答案可以显示文档中的**屏幕截图**。点击缩略图即可放大。
* **复制答案**（答案旁边的小型复制图标）可以复制文本。

## 发现项：助手会向你发出警告 <a id="findings-the-assistant-warns-you"></a>

当设置中的某项内容停止工作时，面板顶部会出现一张**红色卡片**。你不必主动提问。每次打开面板以及返回浏览器标签页时，助手都会重新检查。

<figure><img src="../../../../.gitbook/assets/settings-assistant-finding-expanded.png" alt="展开的发现卡片显示一个邮箱在连续三次尝试失败后已关闭"><figcaption><p>展开的发现项会显示邮箱、状态（<strong>已关闭</strong>）、失败次数和原因。</p></figcaption></figure>

目前有两项检查：

| 检查项 | 卡片标题 | 统计内容 |
| --- | --- | --- |
| 电子邮件导入 | “电子邮件导入：1 个邮箱受影响” / “电子邮件导入：3 个邮箱受影响” | 登录失败的邮箱 |
| FTP 导入 | “FTP 导入：1 个连接受影响” / “FTP 导入：2 个连接受影响” | 连接或登录尝试失败的连接 |

每张卡片都有三个按钮：

* **显示错误**（随后显示**隐藏**）：最多列出十个受影响的邮箱或连接，并显示其状态（**已关闭**或**正在重试**）、失败次数和原因。
* **打开导入设置**：打开**设置 → 导入**。
* **帮助我修复**：开始聊天。助手会主动询问“我的电子邮件导入停止工作了。你能帮我修复吗？”，并引导你了解原因。

摘要行会说明故障程度：

| 摘要行 | 含义 |
| --- | --- |
| *已关闭：此处没有任何内容正在导入。* | 所有受影响的邮箱均已关闭。不会收到任何内容。 |
| *仍在重试，但导入可能一直失败。* | DocBits 会继续尝试，但登录失败。 |
| *1 个已关闭，2 个仍在重试。* | 两种情况都有。 |

### 你可能看到的原因

助手会将技术错误转换为以下某种原因：

| 显示的原因 | 处理方法 |
| --- | --- |
| 策略阻止登录（例如，已禁用基本身份验证，或需要应用密码/MFA） | 向邮件管理员申请应用密码，或将邮箱切换为新式身份验证 |
| 登录遭拒（请检查用户名和密码） | 密码已更改。请在导入设置中输入新密码 |
| 找不到邮箱或路径 | 邮箱已重命名或删除。请检查地址或文件夹 |
| 无法连接到服务器 | 检查服务器名称和防火墙 |
| 连接超时 | 服务器响应缓慢或连接遭到阻止。请稍后重试 |
| 证书或 TLS 连接失败 | 检查加密设置和服务器证书 |
| 无法确定原因 | 打开导入设置并测试连接 |

### 关闭或删除故障连接

在展开的行中，你可以点击**关闭**（仅当连接仍处于开启状态时显示）或**删除**。两者都采用相同的安全流程：

1. 点击按钮。助手会询问 *关闭（名称）？此邮箱将停止导入，直到重新开启。* 或 *删除（名称）？该连接将被永久删除，且无法撤销。*
2. 点击**是，关闭**或**是，删除**进行确认，也可以点击**取消**。
3. 随后会显示结果行：*（名称）已关闭。*，并附有**撤销**按钮。已删除的连接没有**撤销**按钮，因为删除操作是永久性的。

如果其他人期间更改了该邮箱，你会看到 *此邮箱期间已被更改。请检查后重试。* 不会进行任何更改。

## 安全地更改设置

助手绝不会自行更改设置。每项更改都遵循以下四个步骤：

1. **预览**：查看设置、适用范围（**组织**）以及**当前值 → 建议值**。此时尚未保存。
2. **确认**：点击**确认**（或**是**）。只有组织管理员可以执行此操作。
3. **结果行**：聊天中会显示**已更改：（设置）→（值）**。
4. **撤销**：带倒计时的按钮（“还剩 14 分钟”）可让你撤销更改。系统也会将更改记录在日志中。

**示例（仅供说明）。** 对于助手可以写入的设置，建议卡片会在**打开设置**旁边显示**应用**按钮。假设卡片涉及**如果 PO 匹配度为 100%，则自动导出**。你点击**应用**后，会出现**应用此更改？**对话框，其中显示 *当前：关闭 → 建议值：开启*。点击**确认**后，会显示**设置已更新。**消息，并附有**撤销**按钮。如果你在大约 15 分钟内发现错误，可以点击**撤销**恢复旧值。没有**应用**按钮的卡片仅用于导航：使用**打开设置**，然后自行更改值。

如果自打开对话框后该值发生了变化，你会看到 *此设置在你打开对话框后已发生更改。请重新预览。* 不会应用任何更改。

### 助手可以执行的更改

| 更改 | 示例请求（仅供说明） |
| --- | --- |
| 单项组织设置（对建议点击**应用**） | “开启自动 PO 匹配和导出” |
| 启用或停用文档类型 | “停用文档类型‘交货单’” |
| 重命名访问组 | “将‘买方’组重命名为‘采购’” |
| 更改查找字段的搜索模式（自动或手动） | “将供应商搜索改为手动，而非自动” |
| 删除字段 | “删除‘成本中心’字段” |
| 从目录创建未激活的验证规则 | 打开**自定义验证规则**页面并描述要执行的检查 |
| 创建未激活的转换规则 | “创建一条规则，删除供应商增值税号中的连字符” |
| 关闭或删除导入连接 | 使用发现卡片中的按钮 |

### 规则草稿

如果你要求创建**转换规则**，助手会先显示**规则预览**：

* 规则名称和简单说明（“删除供应商增值税号中的连字符”）；
* 目标（文档头部字段、表格列、表格行、文档属性）；
* 对样本文档进行测试，显示：**适用于 5 个样本中的 4 个**，并为每份文档标记**适用**、**不适用**或**适用，无更改**。

点击**创建规则**即可保存。规则创建后处于**未激活**状态：检查后由你自行启用。你可以在 **15 分钟内**撤销创建操作。超过此时间后，请在规则列表中删除该规则。通过助手每小时最多可创建 **10 条规则**。

## 视频说明

在部分页面（目前包括**布局**、**用户**和**子组织**）上，助手会提供**观看视频说明**。视频会在面板中播放，提供字幕和文字稿（**显示文字稿**）；如果有对应版本，会使用你的语言。

## 限制和提示信息

| 提示信息 | 含义 |
| --- | --- |
| 请求过多。请稍候。 | 你在短时间内发送了许多问题。短暂等待后，**重试**按钮会启用。 |
| 仅管理员可用。 | 你的账户不是组织管理员。 |
| 助手暂时不可用。 | 请几分钟后重试。 |
| 助手响应时间过长。 | 未能及时开始生成答案。点击**重试**。 |
| 出现错误。请重试。 | 一般性错误。你可以复制**错误 ID**以联系支持人员。 |
| 助手正在设置中 | 此功能在你的环境中尚不可用。 |
| 你已切换组织，此回复不再适用。 | 生成答案或打开更改时，你切换了组织。 |

对话会在浏览器中保留最近 50 轮。每个问题最多可包含 4000 个字符。

## 提示

* **一次询问一件事**。“电子邮件导入在哪里？它是否已启用？”最好拆成两个问题。
* 使用**页面问候语**。这三个问题是针对当前页面编写的，是最快的开始方式。
* **说明你想实现什么**，而非设置名称。“我希望发票无需人工查看即可导出”有助于找到合适的设置。
* 确认前请检查**预览**，尤其是**当前值 → 建议值**。
* 不确定时，使用**打开设置**查看页面。助手不会隐瞒设置的位置。
