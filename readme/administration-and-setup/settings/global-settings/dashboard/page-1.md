# Filtry Niestandardowe

Przejdź do USTAWIENIA → Pulpit nawigacyjny

**Dostosuj swój filtr**

Przejdź do sekcji Filtry

![Panel ustawień Dashboard pokazujący opcje resetowania filtrów dla przesyłania dokumentów, ponownego uruchomienia i eksportu oraz styl filtra statusu ustawiony na Custom](https://lh7-us.googleusercontent.com/aEOmeKPrkuBe0aSRJKDi5QZ1UBaTjuq0xdfRkJWv78k6XZ42QKYccjaTRXVjrNPmn86-vTeKSNWmWuReYvn-ieD3A6aMoi_sVKTKSKMy992Dz-YXVmOSIHRsTTHeU50b4nwyLbwVWlG9F_3D6fO-GPU)

Aby utworzyć Filtr Niestandardowy, wybierz NIESTANDARDOWY w "Stylu filtra statusu"

Poniżej możesz wybrać różne statusy, w których może znajdować się dokument, aby utworzyć swój filtr niestandardowy. Po naciśnięciu ZASTOSUJ, ten filtr niestandardowy będzie aktywny na Pulpicie nawigacyjnym.

**Pulpit nawigacyjny**

Wybierz USTAWIENIA ZAAWANSOWANE

![Dashboard w DocBits z otwartym sterowaniem Advanced Settings na pasku filtra statusu](https://lh7-us.googleusercontent.com/ORDZuJttHObIzK1BTo-r6rxM1nvU7ChKXcLrZbLKmy5NL5NBWC6CWt3NmIFpjSFGsxBKltta-_nlmDwHOfjgZVF3FeDcryyv4QtN2cgA6FktJOSG1aU3lfPuxD78PkPOsDG4-OEwTEW73QCCCw4vDtw)
