# Filtros Personalizados

Navegue a CONFIGURACIÓN → Panel de Control

![Menú de ajustes en DocBits con Dashboard seleccionado bajo Global Settings y opciones como Workflow, Company Information y Groups, Users and Permissions](https://lh7-us.googleusercontent.com/q2frPTJ74a2SgSFOB5JBUXgpQ0mk62I6piZL0Lz0T_LuJqx1XmRs6il99mInCjvfNdz6FgdxDmUE4gONmiEydB2PXxvhw73toOUa0dK1GQftZGk2LRDoFRlqNvTfhj5K9cZHhWcWktpfXv5LaHfIy24)

**Personalice su filtro**

Navegue a la sección Filtros

![Panel de ajustes de Dashboard que muestra opciones de restablecimiento de filtros para carga de documentos, reinicio y exportación, además del estilo de filtro de estado establecido en Custom](https://lh7-us.googleusercontent.com/aEOmeKPrkuBe0aSRJKDi5QZ1UBaTjuq0xdfRkJWv78k6XZ42QKYccjaTRXVjrNPmn86-vTeKSNWmWuReYvn-ieD3A6aMoi_sVKTKSKMy992Dz-YXVmOSIHRsTTHeU50b4nwyLbwVWlG9F_3D6fO-GPU)

Para crear un Filtro Personalizado, seleccione PERSONALIZADO en el "Estilo de filtro de estado"

Debajo de eso, puede seleccionar los diversos estados en los que puede estar un documento para crear su filtro personalizado. Una vez que presione APLICAR, este filtro personalizado estará activo en el Panel de Control.

**Panel de Control**

Seleccione CONFIGURACIÓN AVANZADA

![Dashboard en DocBits con el control Advanced Settings abierto en la barra de filtro de estado](https://lh7-us.googleusercontent.com/ORDZuJttHObIzK1BTo-r6rxM1nvU7ChKXcLrZbLKmy5NL5NBWC6CWt3NmIFpjSFGsxBKltta-_nlmDwHOfjgZVF3FeDcryyv4QtN2cgA6FktJOSG1aU3lfPuxD78PkPOsDG4-OEwTEW73QCCCw4vDtw)

Los Filtros Personalizados se pueden acceder seleccionando la opción MÁS CONFIGURACIÓN.

![Menú de filtro de estado del Dashboard en DocBits con la opción More Settings abierta](https://lh7-us.googleusercontent.com/L1QNlzUWbWmz4EzRZ5MBk_WYV_lUtghtN4QbvLL04r8CpTZebadNSRwgeRJX4KlB7JMPNOP0lgZUohJ5JZOMYaFt6zz91-sRv1PD4LXt0e3ayf7997FDhxNPLLZJx6-1ni3BXVNsTB2Gd8wx8dCphSI)
