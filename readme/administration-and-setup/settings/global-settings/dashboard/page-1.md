# 自定义筛选器

导航至 SETTINGS → Dashboard

![DocBits中的Dashboard视图，显示FELLOWPRO DEV工作区、All documents列表以及文档名称、页数、状态、指派对象和发票日期等列](https://lh7-us.googleusercontent.com/Umkm01cQlm0cHDj7fFtPKCEqXcwB0l-vTBUt68v5IyNruzkxRHbqwqfU9PvvsdpKJxq1SA2YVQW9DPmt30dbEMq87ZkIvpsvGl-YltMAo8k0S4D8NCQ2uuTv7aGnpuPXU3JhtOHnNoXFDfL0MNI4exc)

![DocBits的设置菜单，在Global Settings下选中Dashboard，选项包括Workflow、Company Information以及Groups, Users and Permissions等](https://lh7-us.googleusercontent.com/q2frPTJ74a2SgSFOB5JBUXgpQ0mk62I6piZL0Lz0T_LuJqx1XmRs6il99mInCjvfNdz6FgdxDmUE4gONmiEydB2PXxvhw73toOUa0dK1GQftZGk2LRDoFRlqNvTfhj5K9cZHhWcWktpfXv5LaHfIy24)

**自定义筛选器**

导航至 Filters 部分

![Dashboard设置面板，显示文档上传、重启和导出的重置筛选选项，以及设置为Custom的状态筛选样式](https://lh7-us.googleusercontent.com/aEOmeKPrkuBe0aSRJKDi5QZ1UBaTjuq0xdfRkJWv78k6XZ42QKYccjaTRXVjrNPmn86-vTeKSNWmWuReYvn-ieD3A6aMoi_sVKTKSKMy992Dz-YXVmOSIHRsTTHeU50b4nwyLbwVWlG9F_3D6fO-GPU)

若要创建自定义筛选器，请在“Status filter style”中选择 CUSTOM。

随后，您可以选择文档可能处于的各种状态，以创建自定义筛选器。点击 APPLY 后，此自定义筛选器将在 Dashboard 上启用。

**Dashboard**

选择 ADVANCED SETTINGS

![DocBits中的Dashboard，状态筛选栏上的Advanced Settings控件已展开](https://lh7-us.googleusercontent.com/ORDZuJttHObIzK1BTo-r6rxM1nvU7ChKXcLrZbLKmy5NL5NBWC6CWt3NmIFpjSFGsxBKltta-_nlmDwHOfjgZVF3FeDcryyv4QtN2cgA6FktJOSG1aU3lfPuxD78PkPOsDG4-OEwTEW73QCCCw4vDtw)

随后，您可以通过选择 MORE SETTINGS 选项访问自定义筛选器。

![DocBits中Dashboard的状态筛选菜单，已展开More Settings选项](https://lh7-us.googleusercontent.com/L1QNlzUWbWmz4EzRZ5MBk_WYV_lUtghtN4QbvLL04r8CpTZebadNSRwgeRJX4KlB7JMPNOP0lgZUohJ5JZOMYaFt6zz91-sRv1PD4LXt0e3ayf7997FDhxNPLLZJx6-1ni3BXVNsTB2Gd8wx8dCphSI)
