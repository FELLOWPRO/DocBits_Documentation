# Wygasanie dokumentów

<figure><img src="../../../.gitbook/assets/document_expiry_settings_overview.png" alt="Ustawienia wygasania dokumentów"><figcaption><p>Ustawienia wygasania dokumentów</p></figcaption></figure>

W sekcji **Przetwarzanie dokumentów → Wygasanie dokumentów** określasz, jak długo DocBits przechowuje Twoje dokumenty, zanim zostaną automatycznie usunięte. Pomaga to zarządzać przestrzenią dyskową, egzekwować zasady przechowywania danych oraz przestrzegać przepisów prawnych lub wymogów organizacyjnych dotyczących okresu przechowywania dokumentów.

Dwa ustawienia kontrolują automatyczne usuwanie:

| Ustawienie | Co kontroluje |
|------------|---------------|
| **Usuń dokument po** | Jak długo przetworzony dokument jest przechowywany przed automatycznym usunięciem. |
| **Usuń ukończony dokument po** | Jak długo ukończony (w pełni przetworzony i wyeksportowany) dokument jest przechowywany przed automatycznym usunięciem. |

Dla każdego ustawienia wybierz przedział czasu z listy rozwijanej:

<figure><img src="../../../.gitbook/assets/document_expiry_options.png" alt="Dostępne okresy przechowywania"><figcaption><p>Dostępne okresy przechowywania</p></figcaption></figure>

| Opcja | Znaczenie |
|-------|-----------|
| **Domyślnie** | Użyj domyślnego okresu przechowywania systemu (bez własnego nadpisania). |
| **48 godzin** | Usuń 48 godzin po przetworzeniu. |
| **1 tydzień** | Usuń po tygodniu. |
| **2 tygodnie** | Usuń po dwóch tygodniach. |
| **4 tygodnie** | Usuń po czterech tygodniach. |

Oba ustawienia zapewniają, że dokumenty nie są przechowywane dłużej niż to konieczne — pozwala to uniknąć niepotrzebnego zużycia przestrzeni dyskowej i utrzymuje przejrzystość przepływu pracy z dokumentami. Są szczególnie ważne dla organizacji, które muszą spełniać określone wymogi prawne dotyczące przechowywania dokumentów.
