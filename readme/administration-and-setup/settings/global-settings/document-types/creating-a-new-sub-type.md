# 创建新的子类型

当某一类文档需要使用独立的字段设置、验证布局或脚本时，请创建文档子类型。你需要有权访问 **设置 → 文档类型**。

## 1. 打开文档类型

打开 **设置 → 文档类型**。在相关文档类型的卡片中，选择 **文档子类型**（文档子类型）。以下示例使用 **发票**；请选择与你的文档相匹配的类型。卡片中的其他链接用于配置整个文档类型的设置。

<figure><img src="../../../../.gitbook/assets/site-extra-document-types-zh.png" alt="中文文档类型页面；Standard 和 Extraction 仍为英文。文档类型激活与提取模式属于独立配置。"><figcaption><p>中文文档类型页面；Standard 和 Extraction 仍为英文。文档类型激活与提取模式属于独立配置。</p></figcaption></figure>

## 2. 新建子类型

在 **文档子类型**（文档子类型） 页面中，选择 **+ 新建**。现有子类型会显示在列表中；三点 **Actions** 菜单适用于已有行。如果鼠标点击 **+ 新建** 按钮没有响应，请使用键盘将焦点移至该按钮，然后按 **Enter**。

<figure><img src="../../../../.gitbook/assets/site-complete-subtypes-overview-zh.png" alt="中文文档子类型列表，当前显示“未找到记录！”；可使用“新的”创建子类型，没有示例记录被添加。"><figcaption><p>中文文档子类型列表，当前显示“未找到记录！”；可使用“新的”创建子类型，没有示例记录被添加。</p></figcaption></figure>

## 3. 命名并保存

使用字母和下划线输入 **名称**，然后输入描述性的 **标题**。这两个字段都是必填项。截图展示空白表单。选择 **保存** 创建子类型，或选择 **取消** 离开且不创建。

<figure><img src="../../../../.gitbook/assets/site-complete-subtype-new-dialog-zh.png" alt="中文新建子文档类型对话框；名称和标题为空，未保存。名称只接受字符和下划线。"><figcaption><p>中文新建子文档类型对话框；名称和标题为空，未保存。名称只接受字符和下划线。</p></figcaption></figure>

保存后，新子类型会显示在列表中。要设置其字段、布局或脚本，请打开它的 **Actions** 菜单，并按照[配置子类型](configure-subtypes.md)中的说明操作。这些设置需要在创建后进行，而不是在 **+ 新建** 对话框中完成。
