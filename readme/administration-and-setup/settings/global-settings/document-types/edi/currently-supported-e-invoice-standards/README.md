# Resumen de estándares de factura electrónica

Utilice [Formatos, versiones y guías por país de eDocs](../supported-electronic-documents/README.md) como vista general central por país.

Incluye familias de formatos, sintaxis XML, versiones de publicación, perfiles de negocio y los componentes inspeccionados de clasificación, Transformation, Preview y Extraction Paths. Abra la guía de un país para consultar las etiquetas exactas y las capturas y los vídeos disponibles.

Las entradas del catálogo describen la configuración disponible. Compruebe las reglas efectivas de su organización y pruebe archivos de origen representativos antes de depender de un formato. El procesamiento de archivos, la validación legal y la transmisión por red requieren comprobaciones independientes.
