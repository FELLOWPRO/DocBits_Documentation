# Übersicht der E-Rechnungsstandards

Verwenden Sie [eDocs-Formate, Versionen und Länderanleitungen](../supported-electronic-documents/README.md) als zentrale Länderübersicht.

Sie behandelt Formatfamilien, XML-Syntax, Veröffentlichungsversionen, Geschäftsprofile sowie die geprüften Komponenten Klassifizierung, Transformation, Preview und Extraction Paths. Öffnen Sie eine Länderanleitung für die genauen Formatbezeichnungen und verfügbaren Screenshots und Videos.

Katalogeinträge beschreiben verfügbare Konfiguration. Prüfen Sie die wirksamen Regeln Ihrer Organisation und testen Sie repräsentative Quelldateien, bevor Sie sich auf ein Format verlassen. Dateiverarbeitung, rechtliche Validierung und Netzwerkübertragung erfordern separate Prüfungen.
