# Vue d’ensemble des normes de facturation électronique

Utilisez [Formats eDocs, versions et guides par pays](../supported-electronic-documents/README.md) comme vue d’ensemble centrale par pays.

Elle couvre les familles de formats, la syntaxe XML, les versions de publication, les profils métier et les composants examinés de classification, Transformation, Preview et Extraction Paths. Ouvrez un guide national pour consulter les libellés exacts et les captures et vidéos disponibles.

Les entrées du catalogue décrivent la configuration disponible. Vérifiez les règles effectives de votre organisation et testez des fichiers sources représentatifs avant de vous appuyer sur un format. Le traitement des fichiers, la validation légale et la transmission réseau nécessitent des vérifications distinctes.
