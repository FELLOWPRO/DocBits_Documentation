# Visão geral dos padrões de faturação eletrónica

Utilize [Formatos, versões e guias por país para eDocs](../supported-electronic-documents/README.md) como visão geral central por país.

Abrange famílias de formatos, sintaxe XML, versões de publicação, perfis de negócio e os componentes examinados de classificação, Transformation, Preview e Extraction Paths. Abra o guia de um país para consultar as designações exatas e as capturas de ecrã e os vídeos disponíveis.

As entradas do catálogo descrevem a configuração disponível. Verifique as regras efetivas da sua organização e teste ficheiros de origem representativos antes de depender de um formato. O processamento de ficheiros, a validação legal e a transmissão em rede exigem verificações separadas.
