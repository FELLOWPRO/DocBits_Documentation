# 路线图

**Chorus Pro（法国）**

  •  **范围：**法国用于 B2G 开票的平台，同时也与 PEPPOL BIS 和 Factur-X 保持一致。

  •  **说明：**Chorus Pro 更像是一个平台，而非一种格式；不过，支持其数据结构和验证规则，可能有助于处理法国公共机构的业务。

**Svefaktura（瑞典）**

  •  **范围：**瑞典的一种旧版电子发票格式。

  •  **基础：**基于 UBL，历史上用于瑞典的 B2G 开票。

  •  **常见版本：**Svefaktura 1.0（目前大部分已由 PEPPOL BIS 取代）

  •  **说明：**尽管正逐步被 PEPPOL BIS 取代，但在一些旧版场景中仍会出现。

**OIOUBL（丹麦）**

  •  **范围：**广泛用于丹麦的 B2G 开票。

  •  **基础：**基于 UBL 的格式，符合丹麦国家要求。

  •  **常见版本：**OIOUBL Invoice/2.02（及后续更新版本）

  •  **说明：**这是当前基于 EN 16931 的格式的前身；丹麦实体可能仍在使用。

**EHF（挪威）**

  •  **范围：**挪威的国家电子发票标准。

  •  **基础：**符合 PEPPOL BIS Billing 3.0；EHF（Elektronisk Handelsformat）本质上是本地化配置文件。

  •  **常见版本：**EHF Invoice and Credit Note 3.0

  •  **说明：**这是挪威公共部门发票的标准格式，与 PEPPOL 密切相关。
