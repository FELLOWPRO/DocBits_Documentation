# 其他格式与传输要求

有关已检查的格式和版本范围，请参阅[国家概览](../supported-electronic-documents/README.md)。以下格式系列已有目录条目和国家指南，不应将其理解为未来支持承诺：

- [瑞典 — Svefaktura 1.0](../supported-electronic-documents/countries/sweden.md)
- [丹麦 — OIOUBL 2.1](../supported-electronic-documents/countries/denmark.md)
- [挪威 — EHF Invoice 3.0](../supported-electronic-documents/countries/norway.md)
- [法国 — Factur-X](../supported-electronic-documents/countries/france.md)

Chorus Pro 是传输平台。能够处理 Factur-X 或 Peppol XML，并不能证明已连接 Chorus Pro 或获得税务批准。请单独确认所需的连接器、环境和传输流程。

如有其他要求，请保留原始样例，并确定其格式、语法、版本、业务规范和业务文档类型。将其与国家指南进行比较，然后在组织中测试所需的提取和导出功能。
