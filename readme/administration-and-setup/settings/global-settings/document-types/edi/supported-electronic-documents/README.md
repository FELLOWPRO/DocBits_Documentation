# Documenti elettronici supportati

DocBits supporta **120+ standard di fatturazione elettronica e documenti** in **30+ paesi**. Ogni formato viene rilevato automaticamente, analizzato e i suoi campi vengono estratti per un'elaborazione fluida dei documenti.

## Come funzionano i documenti elettronici in DocBits

1. **Caricamento** — Carica un file XML/EDI o ricevilo tramite API/email
2. **Rilevamento automatico** — DocBits identifica lo standard esatto e la versione
3. **Anteprima** — Viene generata un'anteprima HTML leggibile
4. **Estrazione dei campi** — I campi chiave (numero fattura, importi, voci di riga) vengono estratti
5. **Validazione ed esportazione** — I dati vengono validati ed esportati nel tuo sistema ERP

{% hint style="info" %}
Per la configurazione dettagliata, vedere [Impostazioni EDI](../README.md). Per approfondimenti su Peppol, XRechnung e ZUGFeRD, vedere le pagine dedicate di seguito.
{% endhint %}
