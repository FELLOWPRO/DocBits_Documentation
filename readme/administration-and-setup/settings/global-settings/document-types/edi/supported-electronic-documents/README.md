# Ondersteunde elektronische documenten

DocBits ondersteunt **120+ elektronische factuur- en documentstandaarden** in **30+ landen**. Elk formaat wordt automatisch gedetecteerd, verwerkt en de velden worden geëxtraheerd voor naadloze documentverwerking.

## Hoe elektronische documenten werken in DocBits

1. **Uploaden** — Zet een XML/EDI-bestand neer of ontvang het via API/e-mail
2. **Automatische detectie** — DocBits identificeert de exacte standaard en versie
3. **Voorbeeld** — Een leesbare HTML-weergave wordt gegenereerd
4. **Veldextractie** — Sleutelvelden (factuurnummer, bedragen, regelitems) worden geëxtraheerd
5. **Validatie & Export** — Gegevens worden gevalideerd en geëxporteerd naar uw ERP-systeem

{% hint style="info" %}
Voor gedetailleerde configuratie, zie [EDI-instellingen](../README.md). Voor Peppol, XRechnung en ZUGFeRD verdiepingen, zie de toegewijde pagina's hieronder.
{% endhint %}
