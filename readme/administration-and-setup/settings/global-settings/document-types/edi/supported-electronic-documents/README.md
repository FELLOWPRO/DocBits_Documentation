# Desteklenen Elektronik Belgeler

DocBits, **30'dan fazla ülkede 120'den fazla elektronik fatura ve belge standardını** destekler. Her format otomatik olarak tespit edilir, ayrıştırılır ve alanları sorunsuz belge işleme için çıkarılır.

## DocBits'te Elektronik Belgeler Nasıl Çalışır?

1. **Yükleme** — Bir XML/EDI dosyası bırakın veya API/e-posta yoluyla alın
2. **Otomatik Tespit** — DocBits tam standardı ve sürümü tanımlar
3. **Önizleme** — İnsan tarafından okunabilir bir HTML önizlemesi oluşturulur
4. **Alan Çıkarımı** — Temel alanlar (fatura numarası, tutarlar, kalem satırları) çıkarılır
5. **Doğrulama ve Dışa Aktarma** — Veriler doğrulanır ve ERP sisteminize aktarılır

{% hint style="info" %}
Ayrıntılı yapılandırma için bkz. [EDI Ayarları](../README.md).
{% endhint %}
