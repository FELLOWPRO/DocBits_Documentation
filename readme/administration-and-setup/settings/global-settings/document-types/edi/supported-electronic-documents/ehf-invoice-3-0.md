# 🇳🇴 EHF INVOICE 3.0

<!-- edocs-country-scope -->

{% hint style="info" %}
Consultez le guide du pays pour connaître les limites de version, la configuration effectivement utilisée et la vidéo explicative du pays. [Norvège](countries/norway.md). Choisissez la correspondance du document métier réel. Une commande ou un avis d’expédition n’est pas une facture.
{% endhint %}

| Propriété              | Valeur                                            |
| ---------------------- | ------------------------------------------------- |
| **Pays / Région**      | Norvège                                           |
| **Types de documents** | Facture, Avoir                                    |
| **Format**             | UBL 2.1 XML                                       |
| **Norme**              | EHF Invoice 3.0 (basée sur Peppol BIS Billing 3.0) |

EHF (Elektronisk Handelsformat) Invoice 3.0 est la norme norvégienne de facturation électronique, maintenue par l'Agence pour la gestion publique et le gouvernement électronique (Difi). La version 3.0 est alignée sur Peppol BIS Billing 3.0, ce qui rend les factures électroniques norvégiennes interopérables sur l'ensemble du réseau européen Peppol.
