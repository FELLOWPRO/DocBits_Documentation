# 🇳🇴 EHF INVOICE 3.0

| Propriedade | Valor |
| --- | --- |
| **País / Região** | Noruega |
| **Tipos de documento** | Fatura, nota de crédito |
| **Formato** | UBL 2.1 XML |
| **Padrão** | EHF Invoice 3.0 (baseado no Peppol BIS Billing 3.0) |

O EHF (Elektronisk Handelsformat) Invoice 3.0 é o padrão norueguês de fatura eletrônica, mantido pela Agency for Public Management and eGovernment (Difi). A versão 3.0 está alinhada ao Peppol BIS Billing 3.0, o que torna as faturas eletrônicas norueguesas interoperáveis em toda a rede europeia Peppol.
