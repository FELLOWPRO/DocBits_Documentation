# 🇳🇴 EHF INVOICE 3.0

| Proprietà             | Valore                                            |
| --------------------- | ------------------------------------------------- |
| **Paese / Regione**   | Norvegia                                          |
| **Tipi di documento** | Fattura, nota di credito                          |
| **Formato**           | UBL 2.1 XML                                       |
| **Standard**          | EHF Invoice 3.0 (basato su Peppol BIS Billing 3.0) |

EHF (Elektronisk Handelsformat) Invoice 3.0 è lo standard norvegese di fatturazione elettronica, mantenuto dall'Agenzia per la gestione pubblica e l'eGovernment (Difi). La versione 3.0 è allineata a Peppol BIS Billing 3.0, il che rende le fatture elettroniche norvegesi interoperabili nell'intera rete europea Peppol.
