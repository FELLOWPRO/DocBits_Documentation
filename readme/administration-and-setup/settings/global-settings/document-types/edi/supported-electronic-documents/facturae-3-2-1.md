# 🇪🇸 FACTURAE 3.2.1

| 属性                 | 值                                       |
| -------------------- | ---------------------------------------- |
| **国家/地区**         | 西班牙                                   |
| **文档类型**          | 发票、贷项通知单、更正发票               |
| **格式**              | XML                                      |
| **标准**              | Facturae 3.2.1                           |

Facturae 3.2.1 是一项维护更新，修正了 XML 架构、改进了验证规则，并增加了对西班牙税务法规要求的其他税种类别的支持。

| 预览               | ✅ 支持     |
| 字段提取           | ✅ 支持     |
| 转换               | ✅ 支持     |
