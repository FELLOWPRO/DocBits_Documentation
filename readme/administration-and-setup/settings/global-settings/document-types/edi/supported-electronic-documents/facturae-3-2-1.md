# 🇪🇸 FACTURAE 3.2.1

| Propriété              | Valeur                                   |
| ---------------------- | ---------------------------------------- |
| **Pays / Région**      | Espagne                                  |
| **Types de documents** | Facture, Avoir, Facture rectificative    |
| **Format**             | XML                                      |
| **Norme**              | Facturae 3.2.1                           |

Facturae 3.2.1 est une mise à jour de maintenance qui a apporté des corrections au schéma XML, amélioré les règles de validation et ajouté la prise en charge de catégories de taxes supplémentaires exigées par la réglementation fiscale espagnole.
