# 🇪🇸 FACTURAE 3.2.2

| Propriedade | Valor |
| --- | --- |
| **País / Região** | Espanha |
| **Tipos de documento** | Fatura, nota de crédito, fatura retificativa |
| **Formato** | XML |
| **Padrão** | Facturae 3.2.2 |

O Facturae 3.2.2 é a versão mais recente do padrão espanhol de fatura eletrônica. Inclui um tratamento de impostos atualizado para compatibilidade com o SII (Suministro Inmediato de Información) e suporte aprimorado a faturas retificativas.

| Visualização | ✅ Suportado |
