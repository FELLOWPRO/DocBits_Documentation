# 🇪🇸 FACTURAE 3.2

| Proprietà             | Valore                                   |
| --------------------- | ---------------------------------------- |
| **Paese / Regione**   | Spagna                                   |
| **Tipi di documento** | Fattura, nota di credito, fattura rettificativa |
| **Formato**           | XML                                      |
| **Standard**          | Facturae 3.2                             |

Facturae 3.2 è una versione molto diffusa dello standard spagnolo di fatturazione elettronica. Definisce la struttura XML delle fatture elettroniche, compresi l'identificazione di venditore e acquirente, le righe articolo, i dettagli fiscali (IVA) e i requisiti della firma digitale.
