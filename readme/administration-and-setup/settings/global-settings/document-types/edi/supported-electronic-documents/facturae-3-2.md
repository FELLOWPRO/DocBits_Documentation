# 🇪🇸 FACTURAE 3.2

| Właściwość           | Wartość                                  |
| -------------------- | ---------------------------------------- |
| **Kraj / Region**    | Hiszpania                                |
| **Typy dokumentów**  | Faktura, nota kredytowa, faktura korygująca |
| **Format**           | XML                                      |
| **Standard**         | Facturae 3.2                             |

Facturae 3.2 to szeroko stosowana wersja hiszpańskiego standardu e-fakturowania. Definiuje strukturę XML faktur elektronicznych, w tym identyfikację sprzedawcy i nabywcy, pozycje faktury, szczegóły podatkowe (IVA) oraz wymagania dotyczące podpisu cyfrowego.
