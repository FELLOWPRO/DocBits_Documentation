# 🇪🇸 FACTURAE

<!-- edocs-country-scope -->

{% hint style="info" %}
Consulte la guía del país para conocer los límites de versión, la configuración que se está utilizando y el vídeo explicativo del país. [España](countries/spain.md). Compruebe el espacio de nombres y la versión del esquema. Extraer datos de un XML firmado no verifica por sí solo su firma ni su aceptación por FACe.
{% endhint %}

| Propiedad              | Valor                                       |
| ---------------------- | ------------------------------------------- |
| **País / Región**      | España                                      |
| **Tipos de documento** | Factura, Nota de crédito, Factura rectificativa |
| **Formato**            | XML                                         |
| **Estándar**           | Facturae                                    |

Facturae es el estándar español de facturación electrónica obligatorio para las operaciones B2G a través del portal FACe (Punto General de Entrada de Facturas Electrónicas). DocBits admite las versiones 3.2, 3.2.1 y 3.2.2 del estándar.

## Estado de compatibilidad

| Componente             | Estado          |
| ---------------------- | --------------- |
| Vista previa           | ✅ Compatible    |
| Extracción de campos   | ✅ Compatible    |
| Transformación         | ✅ Compatible    |
