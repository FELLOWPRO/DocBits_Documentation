# 🇪🇸 FACTURAE

| **Padrão** | Facturae |

O Facturae é o padrão espanhol de fatura eletrônica, obrigatório para transações B2G por meio do portal FACe (Punto General de Entrada de Facturas Electrónicas). O DocBits oferece suporte às versões 3.2, 3.2.1 e 3.2.2 do padrão.
