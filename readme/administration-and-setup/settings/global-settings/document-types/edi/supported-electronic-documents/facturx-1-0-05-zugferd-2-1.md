# 🇫🇷 FACTURX 1.0.05 - ZUGFERD 2.1

| Właściwość           | Wartość                       |
| -------------------- | ----------------------------- |
| **Kraj / Region**    | Francja / Niemcy              |
| **Typy dokumentów**  | Faktura, nota kredytowa       |
| **Format**           | CII (osadzony w PDF/A-3)      |
| **Standard**         | Factur-X 1.0.05 / ZUGFeRD 2.1 |
| **Oparty na**        | EN 16931                      |

Factur-X 1.0.05 jest odpowiednikiem ZUGFeRD 2.1. Wydana w 2020 roku, była pierwszą wspólnie opublikowaną wersją zapewniającą pełną interoperacyjność między francuskim a niemieckim ekosystemem e-fakturowania. Obsługuje profile: Minimum, Basic WL, Basic, EN 16931, Extended.
