Factur-X 1.0.05 entspricht ZUGFeRD 2.1. Die 2020 veröffentlichte Version war die erste gemeinsam herausgegebene Fassung, die die volle Interoperabilität zwischen dem französischen und dem deutschen E-Rechnungs-Ökosystem herstellte. Unterstützte Profile: Minimum, Basic WL, Basic, EN 16931, Extended.
