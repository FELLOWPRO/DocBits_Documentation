# 🇫🇷 FACTURX 1.0.05 - ZUGFERD 2.1

| Eigenschap | Waarde |
|------------|--------|
| **Land / Regio** | Frankrijk / Duitsland |
| **Documenttypen** | Factuur, Creditnota |
| **Formaat** | CII (ingesloten in PDF/A-3) |
| **Standaard** | Factur-X 1.0.05 / ZUGFeRD 2.1 |
| **Gebaseerd op** | EN 16931 |

Factur-X 1.0.05 is gelijkwaardig aan ZUGFeRD 2.1. Deze versie, uitgebracht in 2020, was de eerste gezamenlijk gepubliceerde versie die volledige interoperabiliteit tussen het Franse en het Duitse e-factureringsecosysteem tot stand bracht. Ondersteunde profielen: Minimum, Basic WL, Basic, EN 16931, Extended.
