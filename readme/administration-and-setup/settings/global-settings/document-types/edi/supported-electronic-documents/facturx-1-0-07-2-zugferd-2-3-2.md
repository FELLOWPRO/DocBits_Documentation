# 🇫🇷 FACTURX 1.0.07.2 - ZUGFERD 2.3.2

<!-- edocs-country-scope -->

{% hint style="info" %}
请参阅国家指南，了解版本限制、实际生效的配置和国家说明视频。 [法国](countries/france.md). XML 标记 1p0 和 Factur-X XMP Version 1.0 无法确定发布版本。版本未知时，请保留通用名称。
{% endhint %}

| 属性 | 值 |

| **国家 / 地区** | 法国 / 德国 |
| **文档类型** | 发票、贷项通知单 |
| **格式** | CII（嵌入式 PDF/A-3） |
| **标准** | Factur-X 1.0.07.2 / ZUGFeRD 2.3.2 |

Factur-X 1.0.07.2 与 ZUGFeRD 2.3.2 等效，于 2024 年 11 月发布。此版本包含对业务规则的修正和更新、改进后的 Schematron 验证，以及与最新 CII D22B 规范的对齐。
