# 🇫🇷 FACTURX 1.0.07.2 - ZUGFERD 2.3.2

| Eigenschap | Waarde |
|------------|--------|
| **Land / Regio** | Frankrijk / Duitsland |
| **Documenttypen** | Factuur, Creditnota |
| **Formaat** | CII (ingesloten in PDF/A-3) |
| **Standaard** | Factur-X 1.0.07.2 / ZUGFeRD 2.3.2 |
| **Gebaseerd op** | EN 16931 |

Factur-X 1.0.07.2 is gelijkwaardig aan ZUGFeRD 2.3.2, uitgebracht in november 2024. Deze versie bevat correcties en updates van de bedrijfsregels, verbeterde Schematron-validatie en een afstemming op de nieuwste CII D22B-specificatie.
