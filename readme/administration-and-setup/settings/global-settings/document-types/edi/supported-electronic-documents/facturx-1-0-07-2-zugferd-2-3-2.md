# 🇫🇷 FACTURX 1.0.07.2 - ZUGFERD 2.3.2

| Propiedad              | Valor                             |
| ---------------------- | --------------------------------- |
| **País / Región**      | Francia / Alemania                |
| **Tipos de documento** | Factura, Nota de crédito          |
| **Formato**            | CII (incrustado en PDF/A-3)       |
| **Estándar**           | Factur-X 1.0.07.2 / ZUGFeRD 2.3.2 |
| **Basado en**          | EN 16931                          |

Factur-X 1.0.07.2 equivale a ZUGFeRD 2.3.2, publicada en noviembre de 2024. Esta versión incluye correcciones y actualizaciones de las reglas de negocio, una validación Schematron mejorada y la alineación con la especificación CII D22B más reciente.

## Estado de compatibilidad

| Componente             | Estado          |
| ---------------------- | --------------- |
| Vista previa           | ✅ Compatible    |
| Extracción de campos   | ✅ Compatible    |
| Transformación         | ✅ Compatible    |
