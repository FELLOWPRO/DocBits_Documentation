# 🇫🇷 FACTURX 1.0.07.2 - ZUGFERD 2.3.2

{% hint style="info" %}
Consultez le guide du pays pour connaître les limites de version, la configuration effectivement utilisée et la vidéo explicative du pays. [France](countries/france.md). Factur-X 1.0.07.2 est équivalent à ZUGFeRD 2.3.2, publié en novembre 2024. Cette version comprend des corrections et des mises à jour des règles métier, une validation Schematron améliorée et un alignement sur la dernière spécification CII D22B.
