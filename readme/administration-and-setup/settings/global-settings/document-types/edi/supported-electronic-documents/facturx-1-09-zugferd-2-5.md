# 🇫🇷 Factur-X 1.09 / ZUGFeRD 2.5

| Eigenschaft | Wert |
|----------|-------|
| **Land / Region** | Frankreich / Deutschland |
| **Dokumenttypen** | Rechnung, Gutschrift |
| **Format** | CII (in PDF/A-3 eingebettet) |
| **Standard** | Factur-X 1.09 / ZUGFeRD 2.5 |
| **Basierend auf** | EN 16931 |

Factur-X 1.09 ist die französische Veröffentlichung, die ZUGFeRD 2.5 entspricht (gemeinsame Veröffentlichung von FeRD/FNFE-MPE, Juni 2026). Sein CII-XML nutzt die UN/CEFACT-Basis D22B, die abwärtskompatibel zu D16B ist, daher gilt der vollständige Extraktions- und Transformationsvertrag von Factur-X 1.08 / ZUGFeRD 2.4 weiter. Das Profil EXTENDED ergänzt neue Felder für Zahlungsmittel und BIC, einen Drittempfänger (Faktor) sowie den Steuerbefreiungsgrund für Nachlässe/Zuschläge.

Alle fünf Profile werden unterstützt: MINIMUM, BASIC WL, BASIC, EN 16931 (COMFORT) und EXTENDED.
