# 🇫🇷 FACTURX 1.09 - ZUGFERD 2.5

| Özellik | Değer |
|-----------|-------|
| **Ülke/Bölge** | Fransa / Almanya |
| **Belge türleri** | Fatura, Kredi notu |
| **Biçim** | CII (PDF/A-3 gömülü) |
| **Standart** | Factur-X 1.09 / ZUGFeRD 2.5 |
| **Temel aldığı standart** | EN 16931 |

Factur-X 1.09, ZUGFeRD 2.5'in Fransız yayınına eşdeğerdir (FeRD/FNFE-MPE ortak yayını, Haziran 2026). CII XML'i, D16B ile geriye dönük uyumlu olan UN/CEFACT D22B tabanını kullanır; bu nedenle Factur-X 1.08 / ZUGFeRD 2.4'ün tüm çıkarma ve dönüştürme sözleşmesi geçerliliğini korur. EXTENDED profili; ödeme araçları ve BIC için yeni alanlar, üçüncü taraf lehtar (faktör) ve indirim/artırım için vergi muafiyeti nedeni alanlarını ekler.

Beş profilin tamamı desteklenir: MINIMUM, BASIC WL, BASIC, EN 16931 (COMFORT) ve EXTENDED.
