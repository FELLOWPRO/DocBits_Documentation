# 🇫🇷 FACTURX

| Eigenschap | Waarde |
|------------|--------|
| **Land / Regio** | Frankrijk / Duitsland |
| **Documenttypen** | Factuur, Creditnota |
| **Formaat** | CII (ingesloten in PDF/A-3) |
| **Standaard** | Factur-X |
| **Gebaseerd op** | EN 16931 |

Factur-X is de Franse implementatie van de Frans-Duitse hybride factuurstandaard. Deze sluit gestructureerde CII-XML-gegevens in een PDF/A-3-document in, zodat facturering zowel voor mensen leesbaar als machinaal verwerkbaar is. DocBits herkent de Factur-X-versie en het profiel automatisch aan de ingesloten XML.
