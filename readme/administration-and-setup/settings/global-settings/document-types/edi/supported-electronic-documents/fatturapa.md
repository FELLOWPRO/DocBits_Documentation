# 🇮🇹 FATTURAPA

| Propriedade | Valor |
| --- | --- |
| **País / Região** | Itália |
| **Tipos de documento** | Fatura, nota de crédito, fatura simplificada |
| **Formato** | XML (FatturaPA 1.2.x) |
| **Padrão** | FatturaPA (SDI) |

A FatturaPA é o padrão italiano de fatura eletrônica, exigido pela Agenzia delle Entrate. Desde janeiro de 2019, todas as faturas entre empresas italianas devem ser transmitidas por meio do Sistema di Interscambio (SDI). O DocBits processa documentos XML FatturaPA e extrai todos os campos de cabeçalho e de itens de linha.
