# 🇮🇹 FATTURAPA

| Eigenschap | Waarde |
|------------|--------|
| **Land / Regio** | Italië |
| **Documenttypen** | Factuur, Creditnota, Vereenvoudigde factuur |
| **Formaat** | XML (FatturaPA 1.2.x) |
| **Standaard** | FatturaPA (SDI) |

FatturaPA is de Italiaanse standaard voor elektronische facturering, verplicht gesteld door de Agenzia delle Entrate. Sinds januari 2019 moeten alle facturen tussen Italiaanse bedrijven via het Sistema di Interscambio (SDI) worden verzonden. DocBits verwerkt FatturaPA-XML-documenten en extraheert alle header- en factuurregelvelden.
