# 🇮🇹 FATTURAPA

| Proprietà             | Valore                                   |
| --------------------- | ---------------------------------------- |
| **Paese / Regione**   | Italia                                   |
| **Tipi di documento** | Fattura, nota di credito, fattura semplificata |
| **Formato**           | XML (FatturaPA 1.2.x)                    |
| **Standard**          | FatturaPA (SDI)                          |

FatturaPA è lo standard italiano di fatturazione elettronica reso obbligatorio dall'Agenzia delle Entrate. Da gennaio 2019 tutte le fatture tra operatori economici italiani devono essere trasmesse tramite il Sistema di Interscambio (SDI). DocBits elabora i documenti XML FatturaPA ed estrae tutti i campi di testata e di riga.
