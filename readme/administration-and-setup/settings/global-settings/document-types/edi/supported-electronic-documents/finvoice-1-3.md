# 🇫🇮 FINVOICE 1.3

| Propriété              | Valeur                    |
| ---------------------- | ------------------------- |
| **Pays / Région**      | Finlande                  |
| **Types de documents** | Facture                   |
| **Format**             | XML (enveloppe SOAP)      |
| **Norme**              | Finvoice 1.3              |

Finvoice 1.3 est une ancienne version de la norme finlandaise de facturation électronique, maintenue par Finance Finland. Elle utilise une enveloppe de message SOAP et définit un format XML structuré pour la facturation B2B entre les banques finlandaises et leurs clients entreprises.
