# 🇫🇮 FINVOICE 1.3

| Propiedad              | Valor                         |
| ---------------------- | ----------------------------- |
| **País / Región**      | Finlandia                     |
| **Tipos de documento** | Factura                       |
| **Formato**            | XML (envoltorio SOAP)         |
| **Estándar**           | Finvoice 1.3                  |

Finvoice 1.3 es una versión anterior del estándar finlandés de facturación electrónica mantenido por Finance Finland. Utiliza un envoltorio de mensajes SOAP y define un formato XML estructurado para la facturación B2B entre los bancos finlandeses y sus clientes corporativos.

## Estado de compatibilidad

| Componente             | Estado          |
| ---------------------- | --------------- |
| Vista previa           | ✅ Compatible    |
| Extracción de campos   | ✅ Compatible    |
| Transformación         | ✅ Compatible    |
