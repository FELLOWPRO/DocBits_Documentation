# 🇫🇮 FINVOICE 1.3

| 属性                 | 值                    |
| -------------------- | ------------------- |
| **国家 / 地区**      | 芬兰                |
| **文档类型**         | 发票                |
| **格式**             | XML（SOAP 信封）    |
| **标准**             | Finvoice 1.3        |

Finvoice 1.3 是芬兰电子发票标准的早期版本，由 Finance Finland 维护。它采用 SOAP 消息信封，并定义了一种结构化 XML 格式，用于芬兰银行与其企业客户之间的 B2B 发票处理。
