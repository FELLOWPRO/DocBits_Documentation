# 🇫🇮 FINVOICE 1.3

| Proprietà             | Valore              |
| --------------------- | ------------------- |
| **Paese / Regione**   | Finlandia           |
| **Tipi di documento** | Invoice             |
| **Formato**           | XML (busta SOAP)    |
| **Standard**          | Finvoice 1.3        |

Finvoice 1.3 è una versione precedente dello standard finlandese per la fatturazione elettronica, gestito da Finance Finland. Utilizza una busta di messaggio SOAP e definisce un formato XML strutturato per la fatturazione B2B tra le banche finlandesi e i loro clienti aziendali.

## Stato del supporto

| Componente         | Stato       |
| ------------------ | ----------- |
| Anteprima          | ✅ Supported |
| Estrazione campi   | ✅ Supported |
| Trasformazione     | ✅ Supported |
