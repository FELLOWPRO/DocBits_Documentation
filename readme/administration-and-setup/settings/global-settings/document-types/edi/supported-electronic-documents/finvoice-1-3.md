# 🇫🇮 FINVOICE 1.3

<!-- edocs-country-scope -->

{% hint style="info" %}
Consultez le guide du pays pour connaître les limites de version, la configuration effectivement utilisée et la vidéo explicative du pays. [Finlande](countries/finland.md). Vérifiez la version source avant de choisir une correspondance. Le libellé TEAPPSXML ne précise pas de version.
{% endhint %}

| Propriété              | Valeur                    |
| ---------------------- | ------------------------- |
| **Pays / Région**      | Finlande                  |
| **Types de documents** | Facture                   |
| **Format**             | XML (enveloppe SOAP)      |
| **Norme**              | Finvoice 1.3              |

Finvoice 1.3 est une ancienne version de la norme finlandaise de facturation électronique, maintenue par Finance Finland. Elle utilise une enveloppe de message SOAP et définit un format XML structuré pour la facturation B2B entre les banques finlandaises et leurs clients entreprises.
