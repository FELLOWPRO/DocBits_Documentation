# 🇫🇮 FINVOICE 2.0

<!-- edocs-country-scope -->

{% hint style="info" %}
Die Länderanleitung enthält Versionsgrenzen, die tatsächlich verwendete Konfiguration und das Erklärvideo zum Land. [Finnland](countries/finland.md). Prüfen Sie die Version der Quelldatei, bevor Sie eine Zuordnung auswählen. Die Bezeichnung TEAPPSXML nennt keine Veröffentlichungsversion.
{% endhint %}

| Eigenschaft | Wert |
| ----------- | ---- |
| **Land / Region** | Finnland |
| **Dokumenttypen** | Rechnung, Gutschrift |
| **Format** | XML (SOAP-Umschlag) |
| **Standard** | Finvoice 2.0 |

Finvoice 2.0 erweiterte den Standard um eine verbesserte Unterstützung für Zahlungsbedingungen, Lieferdetails und die EU-Umsatzsteuermeldung. Das SOAP-basierte Transportmodell der finnischen Banknetzwerke blieb erhalten.
