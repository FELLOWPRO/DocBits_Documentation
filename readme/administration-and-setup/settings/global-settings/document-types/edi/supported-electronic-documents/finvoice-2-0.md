# 🇫🇮 FINVOICE 2.0

| Propriedade          | Valor                      |
| -------------------- | -------------------------- |
| **País / Região**    | Finlândia                  |
| **Tipos de documento** | Fatura, Nota de crédito  |
| **Formato**          | XML (envelope SOAP)        |
| **Padrão**           | Finvoice 2.0               |

O Finvoice 2.0 alargou o padrão com melhor suporte para condições de pagamento, detalhes de entrega e relatórios de IVA da UE. Manteve o modelo de transporte baseado em SOAP utilizado pelas redes bancárias finlandesas.
