# 🇫🇮 FINVOICE 2.0

| Eigenschap | Waarde |
|------------|--------|
| **Land / Regio** | Finland |
| **Documenttypen** | Factuur, Creditnota |
| **Formaat** | XML (SOAP-envelop) |
| **Standaard** | Finvoice 2.0 |

Finvoice 2.0 breidde de standaard uit met verbeterde ondersteuning voor betalingsvoorwaarden, leveringsgegevens en EU-btw-rapportage. Het op SOAP gebaseerde transportmodel van de Finse banknetwerken bleef behouden.
