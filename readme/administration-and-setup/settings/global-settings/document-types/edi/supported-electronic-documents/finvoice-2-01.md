# 🇫🇮 FINVOICE 2.01

| Eigenschap | Waarde |
|------------|--------|
| **Land / Regio** | Finland |
| **Documenttypen** | Factuur, Creditnota |
| **Formaat** | XML (SOAP-envelop) |
| **Standaard** | Finvoice 2.01 |

Finvoice 2.01 is een onderhoudsrelease die schemaproblemen uit versie 2.0 corrigeerde en ondersteuning toevoegde voor extra verwijzingen naar factuurbijlagen en voor scenario's waarin de koper de facturering initieert.
