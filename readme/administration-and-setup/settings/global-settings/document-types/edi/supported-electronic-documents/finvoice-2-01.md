# 🇫🇮 FINVOICE 2.01

| Propriété              | Valeur                    |
| ---------------------- | ------------------------- |
| **Pays / Région**      | Finlande                  |
| **Types de documents** | Facture, Avoir            |
| **Format**             | XML (enveloppe SOAP)      |
| **Norme**              | Finvoice 2.01             |

Finvoice 2.01 est une version de maintenance qui a corrigé des problèmes de schéma de la version 2.0 et ajouté la prise en charge de références supplémentaires de pièces jointes de facture et de scénarios de facturation initiée par l'acheteur.

| --------------------- | ---------------- |
| Aperçu                | ✅ Pris en charge |
| Extraction des champs | ✅ Pris en charge |
