# 🇫🇮 FINVOICE 2.01

<!-- edocs-country-scope -->

{% hint style="info" %}
Consultate la guida del paese per i limiti delle versioni, la configurazione effettivamente utilizzata e il video esplicativo del paese. [Finlandia](countries/finland.md). Verificate la versione sorgente prima di scegliere una mappatura. L’etichetta TEAPPSXML non indica una versione.
{% endhint %}

| Proprietà             | Valore               |
| --------------------- | -------------------- |
| **Paese / Regione**   | Finlandia            |
| **Tipi di documento** | Invoice, Credit Note |
| **Formato**           | XML (busta SOAP)     |
| **Standard**          | Finvoice 2.01        |

Finvoice 2.01 è una versione di manutenzione che ha corretto i problemi di schema della versione 2.0 e ha aggiunto il supporto per ulteriori riferimenti agli allegati della fattura e per gli scenari di fatturazione avviata dall'acquirente.

## Stato del supporto

| Componente         | Stato       |
| ------------------ | ----------- |
| Anteprima          | ✅ Supported |
| Estrazione campi   | ✅ Supported |
| Trasformazione     | ✅ Supported |
