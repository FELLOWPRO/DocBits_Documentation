# 🇫🇮 FINVOICE 2.01

<!-- edocs-country-scope -->

{% hint style="info" %}
Consulte la guía del país para conocer los límites de versión, la configuración que se está utilizando y el vídeo explicativo del país. [Finlandia](countries/finland.md). Compruebe la versión del archivo de origen antes de elegir una asignación. La etiqueta TEAPPSXML no indica una versión de publicación.
{% endhint %}

| Propiedad              | Valor                    |
| ---------------------- | ------------------------ |
| **País / Región**      | Finlandia                |
| **Tipos de documento** | Factura, Nota de crédito |
| **Formato**            | XML (envoltorio SOAP)    |
| **Estándar**           | Finvoice 2.01            |

Finvoice 2.01 es una versión de mantenimiento que corrigió problemas del esquema de la versión 2.0 y añadió compatibilidad con referencias adicionales a adjuntos de facturas y con escenarios de facturación iniciada por el comprador.

## Estado de compatibilidad

| Componente             | Estado          |
| ---------------------- | --------------- |
| Vista previa           | ✅ Compatible    |
| Extracción de campos   | ✅ Compatible    |
| Transformación         | ✅ Compatible    |
