# 🇫🇮 FINVOICE 3.0

| Eigenschap | Waarde |
|------------|--------|
| **Land / Regio** | Finland |
| **Documenttypen** | Factuur, Creditnota |
| **Formaat** | XML |
| **Standaard** | Finvoice 3.0 |

Finvoice 3.0 is de huidige versie van de Finse e-factureringsstandaard. Deze sluit aan op de Europese norm EN 16931 en blijft achterwaarts compatibel met de Finse bankinfrastructuur. Zowel binnenlandse als grensoverschrijdende facturering wordt ondersteund.
