# 🇫🇮 FINVOICE 3.0

| Proprietà             | Valore               |
| --------------------- | -------------------- |
| **Paese / Regione**   | Finlandia            |
| **Tipi di documento** | Invoice, Credit Note |
| **Formato**           | XML                  |
| **Standard**          | Finvoice 3.0         |

Finvoice 3.0 è la versione attuale dello standard finlandese per la fatturazione elettronica. Introduce l'allineamento alla norma europea EN 16931 mantenendo la retrocompatibilità con l'infrastruttura bancaria finlandese. Supporta sia la fatturazione nazionale sia quella transfrontaliera.

## Stato del supporto

| Componente         | Stato       |
| ------------------ | ----------- |
| Anteprima          | ✅ Supported |
| Estrazione campi   | ✅ Supported |
| Trasformazione     | ✅ Supported |
