# 🇫🇮 FINVOICE 3.0

<!-- edocs-country-scope -->

{% hint style="info" %}
Die Länderanleitung enthält Versionsgrenzen, die tatsächlich verwendete Konfiguration und das Erklärvideo zum Land. [Finnland](countries/finland.md). Prüfen Sie die Version der Quelldatei, bevor Sie eine Zuordnung auswählen. Die Bezeichnung TEAPPSXML nennt keine Veröffentlichungsversion.
{% endhint %}

| Eigenschaft | Wert |
| ----------- | ---- |
| **Land / Region** | Finnland |
| **Dokumenttypen** | Rechnung, Gutschrift |
| **Format** | XML |
| **Standard** | Finvoice 3.0 |

Finvoice 3.0 ist die aktuelle Version des finnischen E-Rechnungsstandards. Sie führt eine Angleichung an die Europäische Norm EN 16931 ein und bleibt dabei abwärtskompatibel mit der finnischen Bankeninfrastruktur. Sie unterstützt sowohl inländische als auch grenzüberschreitende Rechnungsstellung.
