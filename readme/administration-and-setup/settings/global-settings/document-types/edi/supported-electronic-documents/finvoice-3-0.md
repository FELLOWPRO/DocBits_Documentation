# 🇫🇮 FINVOICE 3.0

| Propiedad              | Valor                    |
| ---------------------- | ------------------------ |
| **País / Región**      | Finlandia                |
| **Tipos de documento** | Factura, Nota de crédito |
| **Formato**            | XML                      |
| **Estándar**           | Finvoice 3.0             |

Finvoice 3.0 es la versión actual del estándar finlandés de facturación electrónica. Introduce la alineación con la norma europea EN 16931 y mantiene la retrocompatibilidad con la infraestructura bancaria finlandesa. Admite tanto la facturación nacional como la transfronteriza.

## Estado de compatibilidad

| Componente             | Estado          |
| ---------------------- | --------------- |
| Vista previa           | ✅ Compatible    |
| Extracción de campos   | ✅ Compatible    |
| Transformación         | ✅ Compatible    |
