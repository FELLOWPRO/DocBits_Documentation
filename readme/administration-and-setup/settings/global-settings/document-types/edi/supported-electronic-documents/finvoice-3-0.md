# 🇫🇮 FINVOICE 3.0

<!-- edocs-country-scope -->

{% hint style="info" %}
Consultez le guide du pays pour connaître les limites de version, la configuration effectivement utilisée et la vidéo explicative du pays. [Finlande](countries/finland.md). Vérifiez la version source avant de choisir une correspondance. Le libellé TEAPPSXML ne précise pas de version.

| Propriété              | Valeur                    |
| ---------------------- | ------------------------- |
| **Pays / Région**      | Finlande                  |
| **Types de documents** | Facture, Avoir            |
| **Format**             | XML                       |
| **Norme**              | Finvoice 3.0              |

Finvoice 3.0 est la version actuelle de la norme finlandaise de facturation électronique. Elle introduit un alignement sur la norme européenne EN 16931 tout en maintenant la rétrocompatibilité avec l'infrastructure bancaire finlandaise. Elle prend en charge la facturation nationale comme transfrontalière.
