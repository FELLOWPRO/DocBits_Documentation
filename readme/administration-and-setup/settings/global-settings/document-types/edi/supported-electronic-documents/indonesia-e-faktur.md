# 🇮🇩 INDONESIA E-FAKTUR

<!-- edocs-country-scope -->

{% hint style="info" %}
Consulte o guia do país para conhecer os limites das versões, a configuração efetiva e o vídeo explicativo. [Indonésia](countries/indonesia.md). A entrada não indica um número de edição. Confirme o conteúdo XML real; uma fatura impressa ou uma imagem de código QR não comprovam o suporte de XML.
{% endhint %}

| Propriedade          | Valor                                      |
| -------------------- | ------------------------------------------ |
| **País / Região**    | Indonésia                                  |
| **Tipos de documento** | Fatura fiscal (Faktur Pajak)             |
| **Formato**          | XML/CSV                                    |
| **Padrão**           | e-Faktur (DJP - Direktorat Jenderal Pajak) |

O e-Faktur é o sistema indonésio de fatura fiscal eletrônica operado pela Direção-Geral de Impostos (DJP). É obrigatório para todos os contribuintes PKP (Pengusaha Kena Pajak) e inclui o número de série NSFP (Nomor Seri Faktur Pajak), os identificadores fiscais NPWP e os cálculos de PPN (IVA).
