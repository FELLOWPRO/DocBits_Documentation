# 🇮🇩 INDONESIA E-FAKTUR

<!-- edocs-country-scope -->

{% hint style="info" %}
Consulte la guía del país para conocer los límites de versión, la configuración que se está utilizando y el vídeo explicativo del país. [Indonesia](countries/indonesia.md). La entrada no indica un número de publicación. Confirme el contenido XML real. Una factura impresa o una imagen QR no demuestra la compatibilidad con XML.
{% endhint %}

| Propiedad              | Valor                                      |
| ---------------------- | ------------------------------------------ |
| **País / Región**      | Indonesia                                  |
| **Tipos de documento** | Factura fiscal (Faktur Pajak)              |
| **Formato**            | XML/CSV                                    |
| **Estándar**           | e-Faktur (DJP - Direktorat Jenderal Pajak) |

e-Faktur es el sistema indonesio de facturas fiscales electrónicas gestionado por la Dirección General de Impuestos (DJP). Es obligatorio para todos los contribuyentes PKP (Pengusaha Kena Pajak) e incluye el número de serie NSFP (Nomor Seri Faktur Pajak), los identificadores fiscales NPWP y los cálculos de PPN (IVA).
