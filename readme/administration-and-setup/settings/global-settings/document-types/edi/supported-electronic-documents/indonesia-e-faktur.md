# 🇮🇩 INDONESIA E-FAKTUR

| Proprietà             | Valore                                     |
| --------------------- | ------------------------------------------ |
| **Paese / Regione**   | Indonesia                                  |
| **Tipi di documento** | Tax Invoice (Faktur Pajak)                 |
| **Formato**           | XML/CSV                                    |
| **Standard**          | e-Faktur (DJP - Direktorat Jenderal Pajak) |

e-Faktur è il sistema indonesiano di fattura fiscale elettronica gestito dalla Direzione generale delle imposte (DJP). È obbligatorio per tutti i contribuenti PKP (Pengusaha Kena Pajak) e include il numero di serie NSFP (Nomor Seri Faktur Pajak), gli identificativi fiscali NPWP e i calcoli del PPN (IVA).
