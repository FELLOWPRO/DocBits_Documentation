# 🇸🇬 INVOICENOW SG

<!-- edocs-country-scope -->

{% hint style="info" %}
Consultate la guida del paese per i limiti delle versioni, la configurazione effettivamente utilizzata e il video esplicativo del paese. [Singapore](countries/singapore.md). Verificate gli identificatori del profilo di Singapore. Un profilo nazionale e Peppol BIS generico possono condividere la sintassi UBL senza condividere tutte le regole aziendali.
{% endhint %}

| Proprietà             | Valore                                        |
| --------------------- | --------------------------------------------- |
| **Paese / Regione**   | Singapore                                     |
| **Tipi di documento** | Invoice, Credit Note                          |
| **Formato**           | UBL 2.1 XML (Peppol)                          |
| **Standard**          | InvoiceNow SG (Singapore-specific Peppol BIS) |

InvoiceNow SG è la localizzazione specifica per Singapore dello standard Peppol BIS Billing. Estende il modello Peppol di base con regole di business specifiche per Singapore, la gestione della GST e i requisiti di identificazione tramite UEN (Unique Entity Number).
