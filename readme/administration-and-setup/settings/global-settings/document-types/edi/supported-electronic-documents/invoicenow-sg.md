# 🇸🇬 INVOICENOW SG

<!-- edocs-country-scope -->

{% hint style="info" %}
Consulte o guia do país para conhecer os limites das versões, a configuração efetiva e o vídeo explicativo. [Singapura](countries/singapore.md). Verifique os identificadores do perfil de Singapura. Um perfil nacional e Peppol BIS genérico podem partilhar a sintaxe UBL sem partilhar todas as regras de negócio.
{% endhint %}

| Propriedade          | Valor                                         |
| -------------------- | --------------------------------------------- |
| **País / Região**    | Singapura                                     |
| **Tipos de documento** | Fatura, Nota de crédito                     |
| **Formato**          | UBL 2.1 XML (Peppol)                          |
| **Padrão**           | InvoiceNow SG (Peppol BIS específico de Singapura) |

O InvoiceNow SG é a localização do padrão Peppol BIS Billing específica de Singapura. Alarga o modelo Peppol base com regras de negócio específicas de Singapura, o tratamento do GST e requisitos de identificação por UEN (Unique Entity Number).
