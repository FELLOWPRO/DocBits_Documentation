# 🇸🇬 INVOICENOW SG

<!-- edocs-country-scope -->

{% hint style="info" %}
Raadpleeg de landengids voor versiebeperkingen, de daadwerkelijk gebruikte configuratie en de uitlegvideo voor het land. [Singapore](countries/singapore.md). Controleer de Singaporese profielidentificaties. Een nationaal profiel en algemeen Peppol BIS kunnen dezelfde UBL-syntaxis gebruiken zonder alle bedrijfsregels te delen.
{% endhint %}

| Eigenschap | Waarde |
|------------|--------|
| **Land / Regio** | Singapore |
| **Documenttypen** | Factuur, Creditnota |
| **Formaat** | UBL 2.1 XML (Peppol) |
| **Standaard** | InvoiceNow SG (Singapore-specifieke Peppol BIS) |

InvoiceNow SG is de Singapore-specifieke lokalisatie van de Peppol BIS Billing-standaard. Deze breidt het basis-Peppol-model uit met Singapore-specifieke bedrijfsregels, GST-afhandeling en identificatievereisten via het UEN (Unique Entity Number).
