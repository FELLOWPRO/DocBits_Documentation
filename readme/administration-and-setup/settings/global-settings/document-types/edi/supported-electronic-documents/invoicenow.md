# 🇸🇬 INVOICENOW

| Propiedad              | Valor                    |
| ---------------------- | ------------------------ |
| **País / Región**      | Singapur                 |
| **Tipos de documento** | Factura, Nota de crédito |
| **Formato**            | UBL 2.1 XML (Peppol)     |
| **Estándar**           | InvoiceNow (IMDA)        |

InvoiceNow es la iniciativa nacional de facturación electrónica de Singapur, construida sobre la red Peppol y liderada por la IMDA (Infocomm Media Development Authority). Permite a las empresas intercambiar facturas electrónicas estructuradas a través de Peppol Access Points mediante el formato UBL 2.1.

## Estado de compatibilidad

| Componente             | Estado          |
| ---------------------- | --------------- |
| Vista previa           | ✅ Compatible    |
| Extracción de campos   | ✅ Compatible    |
| Transformación         | ✅ Compatible    |
