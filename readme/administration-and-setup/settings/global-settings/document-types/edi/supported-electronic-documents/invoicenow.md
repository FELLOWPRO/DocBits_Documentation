# 🇸🇬 INVOICENOW

| Proprietà             | Valore               |
| --------------------- | -------------------- |
| **Paese / Regione**   | Singapore            |
| **Tipi di documento** | Invoice, Credit Note |
| **Formato**           | UBL 2.1 XML (Peppol) |
| **Standard**          | InvoiceNow (IMDA)    |

InvoiceNow è l'iniziativa nazionale di Singapore per la fatturazione elettronica, basata sulla rete Peppol e guidata dall'IMDA (Infocomm Media Development Authority). Consente alle aziende di scambiare fatture elettroniche strutturate tramite i Peppol Access Point utilizzando il formato UBL 2.1.

## Stato del supporto

| Componente         | Stato       |
| ------------------ | ----------- |
| Anteprima          | ✅ Supported |
| Estrazione campi   | ✅ Supported |
