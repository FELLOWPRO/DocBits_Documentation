# 🇸🇬 INVOICENOW

<!-- edocs-country-scope -->

{% hint style="info" %}
请参阅国家指南，了解版本限制、实际生效的配置和国家说明视频。 [新加坡](countries/singapore.md). 请检查新加坡业务规范标识。国家业务规范与通用 Peppol BIS 可以共用 UBL 语法，但业务规则未必完全相同。
{% endhint %}

| 属性                 | 值                     |
| -------------------- | ---------------------- |
| **国家 / 地区**      | 新加坡                 |
| **文档类型**         | 发票、贷项通知单       |
| **格式**             | UBL 2.1 XML (Peppol)   |
| **标准**             | InvoiceNow (IMDA)      |

InvoiceNow 是新加坡基于 Peppol 网络构建的国家级电子发票计划，由 IMDA（资讯通信媒体发展局）主导。企业可通过 Peppol 接入点使用 UBL 2.1 格式交换结构化电子发票。
