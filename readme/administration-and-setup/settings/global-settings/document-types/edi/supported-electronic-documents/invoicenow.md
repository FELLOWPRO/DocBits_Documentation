# 🇸🇬 INVOICENOW

| Eigenschap | Waarde |
|------------|--------|
| **Land / Regio** | Singapore |
| **Documenttypen** | Factuur, Creditnota |
| **Formaat** | UBL 2.1 XML (Peppol) |
| **Standaard** | InvoiceNow (IMDA) |

InvoiceNow is het nationale e-factureringsinitiatief van Singapore, gebouwd op het Peppol-netwerk en geleid door de IMDA (Infocomm Media Development Authority). Het stelt bedrijven in staat gestructureerde elektronische facturen uit te wisselen via Peppol Access Points in het UBL 2.1-formaat.
