# 🇸🇬 INVOICENOW

| Eigenschaft          | Wert                 |
| -------------------- | -------------------- |
| **Land / Region**    | Singapur             |
| **Dokumenttypen**    | Rechnung, Gutschrift |
| **Format**           | UBL 2.1 XML (Peppol) |
| **Standard**         | InvoiceNow (IMDA)    |

InvoiceNow ist Singapurs nationale E-Invoicing-Initiative auf Basis des Peppol-Netzwerks, geleitet von der IMDA (Infocomm Media Development Authority). Sie ermöglicht Unternehmen den Austausch strukturierter elektronischer Rechnungen im UBL-2.1-Format über Peppol Access Points.
