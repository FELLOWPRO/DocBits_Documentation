# 🇸🇬 INVOICENOW

| 属性                 | 值                     |
| -------------------- | ---------------------- |
| **国家 / 地区**      | 新加坡                 |
| **文档类型**         | 发票、贷项通知单       |
| **格式**             | UBL 2.1 XML (Peppol)   |
| **标准**             | InvoiceNow (IMDA)      |

InvoiceNow 是新加坡基于 Peppol 网络构建的国家级电子发票计划，由 IMDA（资讯通信媒体发展局）主导。企业可通过 Peppol 接入点使用 UBL 2.1 格式交换结构化电子发票。

## 支持状态
