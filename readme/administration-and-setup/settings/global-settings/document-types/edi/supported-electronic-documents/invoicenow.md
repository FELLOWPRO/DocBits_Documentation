# 🇸🇬 INVOICENOW

<!-- edocs-country-scope -->

{% hint style="info" %}
Consultez le guide du pays pour connaître les limites de version, la configuration effectivement utilisée et la vidéo explicative du pays. [Singapour](countries/singapore.md). Vérifiez les identifiants du profil singapourien. Un profil national et Peppol BIS générique peuvent partager la syntaxe UBL sans partager toutes les règles métier.
{% endhint %}

| Propriété | Valeur |
| --------- | ------ |
| **Pays / Région** | Singapour |
| **Types de documents** | Facture, Note de crédit |
| **Format** | XML UBL 2.1 (Peppol) |
| **Norme** | InvoiceNow (IMDA) |

InvoiceNow est l'initiative nationale singapourienne de facturation électronique, construite sur le réseau Peppol et pilotée par l'IMDA (Infocomm Media Development Authority). Elle permet aux entreprises d'échanger des factures électroniques structurées via des points d'accès Peppol au format UBL 2.1.
