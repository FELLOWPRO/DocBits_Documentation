# 🇸🇬 INVOICENOW

<!-- edocs-country-scope -->

{% hint style="info" %}
Die Länderanleitung enthält Versionsgrenzen, die tatsächlich verwendete Konfiguration und das Erklärvideo zum Land. [Singapur](countries/singapore.md). Prüfen Sie die Profilkennungen für Singapur. Ein nationales Profil und generisches Peppol BIS können dieselbe UBL-Syntax verwenden, ohne alle Geschäftsregeln zu teilen.
{% endhint %}

| Eigenschaft          | Wert                 |
| -------------------- | -------------------- |
| **Land / Region**    | Singapur             |
| **Dokumenttypen**    | Rechnung, Gutschrift |
| **Format**           | UBL 2.1 XML (Peppol) |
| **Standard**         | InvoiceNow (IMDA)    |

InvoiceNow ist Singapurs nationale E-Invoicing-Initiative auf Basis des Peppol-Netzwerks, geleitet von der IMDA (Infocomm Media Development Authority). Sie ermöglicht Unternehmen den Austausch strukturierter elektronischer Rechnungen im UBL-2.1-Format über Peppol Access Points.
