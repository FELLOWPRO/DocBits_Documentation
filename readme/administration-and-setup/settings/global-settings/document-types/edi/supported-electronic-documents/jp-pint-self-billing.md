# 🇯🇵 JP PINT SELF-BILLING

| Propiedad              | Valor                  |
| ---------------------- | ---------------------- |
| **País / Región**      | Japón                  |
| **Tipos de documento** | Autofactura            |
| **Formato**            | UBL 2.1 XML            |
| **Estándar**           | JP PINT Self-Billing   |

JP PINT Self-Billing es la variante de autofacturación del modelo japonés de factura internacional de Peppol. Permite a los compradores emitir facturas en nombre de los proveedores, siguiendo la misma estructura de JP PINT con los roles de las partes invertidos, tal como se permite en determinadas condiciones de la legislación fiscal japonesa.

## Estado de compatibilidad

| Componente             | Estado          |
| ---------------------- | --------------- |
| Vista previa           | ✅ Compatible    |
| Extracción de campos   | ✅ Compatible    |
| Transformación         | ✅ Compatible    |
