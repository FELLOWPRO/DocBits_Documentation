O JP PINT Self-Billing é a variante de autofaturação do modelo japonês de fatura internacional Peppol (PINT). Permite aos compradores emitir faturas em nome dos fornecedores, seguindo a mesma estrutura JP PINT com os papéis das partes invertidos, conforme permitido em condições específicas pela legislação fiscal japonesa.
