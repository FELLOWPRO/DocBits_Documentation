# 🇯🇵 JP PINT SELF-BILLING

| Propriété | Valeur |
| --------- | ------ |
| **Pays / Région** | Japon |
| **Types de documents** | Facture d'autofacturation |
| **Format** | XML UBL 2.1 |
| **Norme** | JP PINT Self-Billing |

JP PINT Self-Billing est la variante d'autofacturation du modèle de facture japonais Peppol International. Elle permet aux acheteurs d'émettre des factures au nom des fournisseurs, selon la même structure JP PINT avec les rôles des parties inversés, comme l'autorise le droit fiscal japonais dans certaines conditions.
