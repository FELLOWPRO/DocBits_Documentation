# 🇯🇵 JP PINT

| Właściwość           | Wartość                                        |
| -------------------- | ---------------------------------------------- |
| **Kraj / Region**    | Japonia                                        |
| **Typy dokumentów**  | Faktura                                        |
| **Format**           | UBL 2.1 XML                                    |
| **Standard**         | JP PINT (Peppol International Model for Japan) |

JP PINT to japońskie wdrożenie międzynarodowego modelu faktury Peppol (PINT). Dostosowuje globalny standard Peppol do japońskich wymogów biznesowych, w tym do obsługi systemu faktur kwalifikowanych (適格請求書) wprowadzonego na mocy znowelizowanej ustawy o podatku konsumpcyjnym.
