| Propriété | Valeur |
| --------- | ------ |
| **Pays / Région** | Japon |
| **Types de documents** | Facture |
| **Format** | XML UBL 2.1 |
| **Norme** | JP PINT (Peppol International Model for Japan) |

JP PINT est l'implémentation japonaise du modèle de facture Peppol International (PINT). Elle adapte la norme Peppol mondiale aux exigences commerciales japonaises, notamment la prise en charge du système de factures qualifiées (適格請求書) introduit par la révision de la loi sur la taxe de consommation.
