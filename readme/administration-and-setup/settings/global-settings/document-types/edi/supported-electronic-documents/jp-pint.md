| -------------------- | ---------------------------------------------- |
| **País / Região**    | Japão                                          |
| **Tipos de documento** | Fatura                                       |

| **Padrão**           | JP PINT (Peppol International Model for Japan) |

O JP PINT é a implementação japonesa do modelo de fatura Peppol International (PINT). Adapta o padrão global Peppol aos requisitos empresariais japoneses, incluindo o suporte para o Sistema de Faturas Qualificadas (適格請求書) introduzido pela revisão da Lei do Imposto sobre o Consumo.
