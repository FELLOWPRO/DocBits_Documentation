# 🇯🇵 JP PINT

<!-- edocs-country-scope -->

{% hint style="info" %}
Consulte la guía del país para conocer los límites de versión, la configuración que se está utilizando y el vídeo explicativo del país. [Japón](countries/japan.md). | Propiedad              | Valor                                          |
| ---------------------- | ---------------------------------------------- |
| **País / Región**      | Japón                                          |
| **Tipos de documento** | Factura                                        |
| **Formato**            | UBL 2.1 XML                                    |
| **Estándar**           | JP PINT (Peppol International Model for Japan) |

JP PINT es la implementación japonesa del modelo de factura Peppol International (PINT). Adapta el estándar global de Peppol a los requisitos empresariales de Japón, incluida la compatibilidad con el sistema de facturas cualificadas (適格請求書) introducido por la Ley del Impuesto sobre el Consumo revisada.

## Estado de compatibilidad

| Componente             | Estado          |
| ---------------------- | --------------- |
| Vista previa           | ✅ Compatible    |
| Extracción de campos   | ✅ Compatible    |
| Transformación         | ✅ Compatible    |
