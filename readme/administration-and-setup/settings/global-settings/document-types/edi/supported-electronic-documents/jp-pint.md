# 🇯🇵 JP PINT

<!-- edocs-country-scope -->

{% hint style="info" %}
Consultate la guida del paese per i limiti delle versioni, la configurazione effettivamente utilizzata e il video esplicativo del paese. [Giappone](countries/japan.md). La fatturazione da parte del cliente è una variante del processo aziendale, non una scelta di lingua. Verificate l’identificatore di personalizzazione e la variante configurata.
{% endhint %}

| Proprietà             | Valore                                         |
| --------------------- | ---------------------------------------------- |
| **Paese / Regione**   | Giappone                                       |
| **Tipi di documento** | Invoice                                        |
| **Formato**           | UBL 2.1 XML                                    |
| **Standard**          | JP PINT (Peppol International Model for Japan) |

JP PINT è l'implementazione giapponese del modello di fattura Peppol International (PINT). Adatta lo standard Peppol globale alle esigenze commerciali giapponesi, incluso il supporto per il sistema delle fatture qualificate (適格請求書) introdotto con la revisione della legge sull'imposta sui consumi.
