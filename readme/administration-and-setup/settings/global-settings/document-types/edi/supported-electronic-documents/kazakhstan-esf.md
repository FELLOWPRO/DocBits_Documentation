O Kazakhstan ESF (Электронные счета-фактуры) é o sistema de faturas eletrônicas operado pelo Comité de Receitas do Estado. Todas as empresas registadas para efeitos de IVA têm de emitir faturas eletrônicas através do sistema de informação ESF. Os documentos incluem a identificação fiscal BIN/IIN, os cálculos de IVA e são assinados digitalmente.
