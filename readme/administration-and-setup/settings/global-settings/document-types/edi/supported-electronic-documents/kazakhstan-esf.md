# 🇰🇿 KAZAKHSTAN ESF

| Proprietà             | Valore                                               |
| --------------------- | ---------------------------------------------------- |
| **Paese / Regione**   | Kazakistan                                           |
| **Tipi di documento** | Invoice                                              |
| **Formato**           | XML                                                  |
| **Standard**          | ESF (Электронные счета-фактуры / Electronic Invoice) |

Kazakhstan ESF (Электронные счета-фактуры) è il sistema di fatturazione elettronica gestito dal Comitato delle entrate statali. Tutte le imprese registrate ai fini IVA devono emettere fatture elettroniche tramite il sistema informativo ESF. I documenti includono l'identificazione fiscale BIN/IIN e i calcoli dell'IVA, e sono firmati digitalmente.
