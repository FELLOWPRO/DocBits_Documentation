# 🇰🇿 KAZAKHSTAN ESF

<!-- edocs-country-scope -->

{% hint style="info" %}
Raadpleeg de landengids voor versiebeperkingen, de daadwerkelijk gebruikte configuratie en de uitlegvideo voor het land. [Kazachstan](countries/kazakhstan.md). Het label vermeldt geen versie. Controleer het werkelijke XML-schema en leid verzending naar het belastingplatform niet af uit ondersteuning voor extractie.
{% endhint %}

| **Documenttypen**    | Factuur                                              |
| **Formaat**          | XML                                                  |
| **Standaard**        | ESF (Электронные счета-фактуры / Elektronische factuur) |

Kazakhstan ESF (Электронные счета-фактуры) is het elektronische factuursysteem dat wordt beheerd door het Comité voor Staatsinkomsten. Alle btw-plichtige bedrijven moeten elektronische facturen uitgeven via het ESF-informatiesysteem. De documenten bevatten de BIN/IIN-belastingidentificatie en de btw-berekeningen en zijn digitaal ondertekend.
