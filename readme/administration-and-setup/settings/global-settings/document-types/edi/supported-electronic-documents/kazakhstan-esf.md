# 🇰🇿 KAZAKHSTAN ESF

| Eigenschaft          | Wert                                                 |
| -------------------- | ---------------------------------------------------- |
| **Land / Region**    | Kasachstan                                           |
| **Dokumenttypen**    | Rechnung                                             |
| **Format**           | XML                                                  |
| **Standard**         | ESF (Электронные счета-фактуры / Electronic Invoice) |

Kazakhstan ESF (Электронные счета-фактуры) ist das elektronische Rechnungssystem des Komitees für Staatseinnahmen. Alle umsatzsteuerlich registrierten Unternehmen müssen elektronische Rechnungen über das Informationssystem ESF ausstellen. Die Dokumente enthalten die Steueridentifikation BIN/IIN und Umsatzsteuerberechnungen und sind digital signiert.
