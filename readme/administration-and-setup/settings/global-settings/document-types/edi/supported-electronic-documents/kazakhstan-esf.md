# 🇰🇿 KAZAKHSTAN ESF

| Propriété | Valeur |
| --------- | ------ |
| **Pays / Région** | Kazakhstan |
| **Types de documents** | Facture |
| **Format** | XML |
| **Norme** | ESF (Электронные счета-фактуры / Facture électronique) |

Kazakhstan ESF (Электронные счета-фактуры) est le système de facturation électronique exploité par le Comité des recettes de l'État. Toutes les entreprises assujetties à la TVA doivent émettre leurs factures électroniques via le système d'information ESF. Les documents comportent l'identification fiscale BIN/IIN, les calculs de TVA et sont signés numériquement.
