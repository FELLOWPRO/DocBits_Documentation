# 🇰🇷 KOREA E-TAX INVOICE

{% hint style="info" %}
Consulte o guia do país para conhecer os limites das versões, a configuração efetiva e o vídeo explicativo. [Coreia do Sul](countries/korea.md). As designações não indicam uma edição. Faça corresponder a estrutura XML real e não considere a extração como prova de aceitação pela plataforma fiscal.

| Propriedade          | Valor                              |
| -------------------- | ---------------------------------- |
| **País / Região**    | Coreia do Sul                      |
| **Tipos de documento** | Fatura fiscal                    |
| **Formato**          | XML                                |
| **Padrão**           | Korean E-Tax Invoice (NTS HomeTax) |

A Korea E-Tax Invoice é o padrão de fatura fiscal eletrônica operado pelo Serviço Nacional de Impostos (NTS) através do sistema HomeTax. As empresas têm de emitir faturas fiscais eletrônicas nas transações B2B e transmiti-las ao NTS. O formato inclui o número de registro comercial, a discriminação do imposto e o número de aprovação do NTS.
