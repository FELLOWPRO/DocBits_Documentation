# 🇰🇷 KOREA E-TAX INVOICE

| Propiedad              | Valor                              |
| ---------------------- | ---------------------------------- |
| **País / Región**      | Corea del Sur                      |
| **Tipos de documento** | Factura fiscal                     |
| **Formato**            | XML                                |
| **Estándar**           | Korean E-Tax Invoice (NTS HomeTax) |

Korea E-Tax Invoice es el estándar de factura fiscal electrónica gestionado por el Servicio Nacional de Impuestos (NTS) a través del sistema HomeTax. Las empresas deben emitir facturas fiscales electrónicas en las operaciones B2B y transmitirlas al NTS. El formato incluye el número de registro mercantil, el desglose del importe de impuestos y el número de aprobación del NTS.
