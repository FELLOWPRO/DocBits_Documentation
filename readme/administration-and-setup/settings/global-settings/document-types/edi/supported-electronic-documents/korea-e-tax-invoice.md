# 🇰🇷 韩国电子税务发票

| 属性 | 值 |
| -------------------- | ---------------------------------- |
| **国家 / 地区** | 韩国 |
| **文档类型** | 税务发票 |
| **格式** | XML |
| **标准** | 韩国电子税务发票（NTS HomeTax） |

韩国电子税务发票是由韩国国税厅（NTS）通过 HomeTax 系统实施的电子税务发票标准。企业必须为 B2B 交易开具电子税务发票，并将其传送至 NTS。该格式包含企业注册号、税额明细和 NTS 批准号。
