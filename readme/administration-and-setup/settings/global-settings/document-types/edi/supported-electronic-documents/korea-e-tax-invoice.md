# 🇰🇷 KOREA E-TAX INVOICE

| Właściwość           | Wartość                            |
| -------------------- | ---------------------------------- |
| **Kraj / Region**    | Korea Południowa                   |
| **Typy dokumentów**  | Faktura podatkowa                  |
| **Format**           | XML                                |
| **Standard**         | Korean E-Tax Invoice (NTS HomeTax) |

Korea E-Tax Invoice to standard elektronicznych faktur podatkowych prowadzony przez Krajową Służbę Podatkową (NTS) za pośrednictwem systemu HomeTax. Firmy muszą wystawiać elektroniczne faktury podatkowe w transakcjach B2B i przesyłać je do NTS. Format obejmuje numer rejestracyjny przedsiębiorstwa, rozbicie kwoty podatku oraz numer zatwierdzenia NTS.
