# 🇰🇷 KOREA NTS

| Propiedad              | Valor                                |
| ---------------------- | ------------------------------------ |
| **País / Región**      | Corea del Sur                        |
| **Tipos de documento** | Factura fiscal, Recibo de caja       |
| **Formato**            | XML                                  |
| **Estándar**           | NTS (Servicio Nacional de Impuestos) |

Korea NTS hace referencia al sistema más amplio de documentos electrónicos del Servicio Nacional de Impuestos, que abarca facturas fiscales, recibos de caja y otros documentos de carácter fiscal. DocBits procesa los documentos NTS y extrae todos los campos estándar, incluidos los números de registro mercantil, los valores de suministro y los importes de impuestos.

## Estado de compatibilidad

| Componente             | Estado          |
| ---------------------- | --------------- |
| Vista previa           | ✅ Compatible    |
| Extracción de campos   | ✅ Compatible    |
| Transformación         | ✅ Compatible    |
