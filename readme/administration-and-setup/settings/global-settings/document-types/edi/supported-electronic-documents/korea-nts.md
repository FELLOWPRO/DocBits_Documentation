# 🇰🇷 KOREA NTS

| Właściwość           | Wartość                                   |
| -------------------- | ----------------------------------------- |
| **Kraj / Region**    | Korea Południowa                          |
| **Typy dokumentów**  | Faktura podatkowa, Paragon gotówkowy      |
| **Format**           | XML                                       |
| **Standard**         | NTS (Krajowa Służba Podatkowa)            |

Korea NTS oznacza szerszy system dokumentów elektronicznych Krajowej Służby Podatkowej, obejmujący faktury podatkowe, paragony gotówkowe i inne dokumenty podatkowe. DocBits przetwarza dokumenty NTS i wyodrębnia wszystkie standardowe pola, w tym numery rejestracyjne przedsiębiorstw, wartości dostaw i kwoty podatku.
