# 🇰🇷 KOREA NTS

<!-- edocs-country-scope -->

{% hint style="info" %}
Raadpleeg de landengids voor versiebeperkingen, de daadwerkelijk gebruikte configuratie en de uitlegvideo voor het land. [Zuid-Korea](countries/korea.md). De labels noemen geen versie. Stem af op de werkelijke XML-structuur en beschouw extractie niet als bewijs van acceptatie door het belastingplatform.
{% endhint %}

| Eigenschap           | Waarde                          |
| -------------------- | ------------------------------- |
| **Land / Regio**     | Zuid-Korea                      |
| **Documenttypen**    | Belastingfactuur, Kassabon      |
| **Formaat**          | XML                             |
| **Standaard**        | NTS (National Tax Service)      |

Korea NTS verwijst naar het bredere elektronische documentensysteem van de National Tax Service, dat belastingfacturen, kassabonnen en andere belastinggerelateerde documenten omvat. DocBits verwerkt NTS-documenten en extraheert alle standaardvelden, waaronder bedrijfsregistratienummers, leveringswaarden en belastingbedragen.
