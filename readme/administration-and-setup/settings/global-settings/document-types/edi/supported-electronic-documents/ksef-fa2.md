# 🇵🇱 KSEF FA2

| Eigenschap           | Waarde                        |
| -------------------- | ----------------------------- |
| **Land / Regio**     | Polen                         |
| **Documenttypen**    | Factuur, Correctiefactuur     |
| **Formaat**          | XML                           |
| **Standaard**        | KSeF FA(2)                    |

KSeF FA2 is de tweede schemaversie van het Poolse nationale e-factuursysteem. Het definieert de XML-structuur voor gestructureerde facturen (faktury), inclusief verkoper- en kopergegevens, factuurregels, btw-tarieven en betalingsvoorwaarden zoals vereist door de Poolse belastingwetgeving.
