# 🇵🇱 KSEF FA2

<!-- edocs-country-scope -->

{% hint style="info" %}
Consultez le guide du pays pour connaître les limites de version, la configuration effectivement utilisée et la vidéo explicative du pays. [Pologne](countries/poland.md). FA2 et FA3 utilisent des structures différentes. Confirmez le schéma source et testez la correspondance appropriée ; l’analyse d’une facture ne la soumet pas à KSeF.
{% endhint %}

| Propriété | Valeur |
| --------- | ------ |
| **Pays / Région** | Pologne |
| **Types de documents** | Facture, Facture rectificative |
| **Format** | XML |
| **Norme** | KSeF FA(2) |

KSeF FA2 est la deuxième version du schéma du système national polonais de facturation électronique. Elle définit la structure XML des factures structurées (faktury), y compris les données du vendeur et de l'acheteur, les lignes, les taux de TVA et les conditions de paiement exigés par le droit fiscal polonais.
