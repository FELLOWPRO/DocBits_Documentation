# 🇵🇱 KSEF FA2

<!-- edocs-country-scope -->

{% hint style="info" %}
Consultate la guida del paese per i limiti delle versioni, la configurazione effettivamente utilizzata e il video esplicativo del paese. [Polonia](countries/poland.md). FA2 e FA3 usano strutture diverse. Confermate lo schema sorgente e provate la mappatura appropriata; l’analisi del file non invia una fattura a KSeF.
{% endhint %}

| Proprietà             | Valore                      |
| --------------------- | --------------------------- |
| **Paese / Regione**   | Polonia                     |
| **Tipi di documento** | Invoice, Corrective Invoice |
| **Formato**           | XML                         |
| **Standard**          | KSeF FA(2)                  |

KSeF FA2 è la seconda versione dello schema del Sistema nazionale polacco di fatturazione elettronica. Definisce la struttura XML delle fatture strutturate (faktury), inclusi i dati di venditore e acquirente, le righe, le aliquote IVA e le condizioni di pagamento, come richiesto dalla normativa fiscale polacca.
