# 🇵🇱 KSEF FA3

| 属性                 | 值                         |
| -------------------- | --------------------------- |
| **国家 / 地区**      | 波兰                        |
| **文档类型**         | 发票、更正发票               |
| **格式**             | XML                         |
| **标准**             | KSeF FA(3)                  |

KSeF FA3 是波兰国家电子发票系统的最新架构版本。它支持更多文档类型，改进了更正发票的处理方式，并更新了验证规则，以符合最新的波兰增值税法规。
