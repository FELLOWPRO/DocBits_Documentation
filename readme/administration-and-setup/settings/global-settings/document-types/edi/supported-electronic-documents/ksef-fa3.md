# 🇵🇱 KSEF FA3

| Właściwość           | Wartość                         |
| -------------------- | ------------------------------- |
| **Kraj / Region**    | Polska                          |
| **Typy dokumentów**  | Faktura, Faktura korygująca     |
| **Format**           | XML                             |
| **Standard**         | KSeF FA(3)                      |

KSeF FA3 to najnowsza wersja schematu Krajowego Systemu e-Faktur. Dodaje obsługę dodatkowych typów dokumentów, ulepszoną obsługę faktur korygujących oraz zaktualizowane reguły walidacji zgodne z najnowszymi polskimi przepisami o VAT.
