# 🇵🇱 KSEF FA3

| Propriedade          | Valor                       |
| -------------------- | --------------------------- |
| **País / Região**    | Polónia                     |
| **Tipos de documento** | Fatura, Fatura retificativa |
| **Formato**          | XML                         |
| **Padrão**           | KSeF FA(3)                  |

O KSeF FA3 é a versão de esquema mais recente do Sistema Nacional de Faturação Eletrônica polaco. Acrescenta suporte para tipos de documento adicionais, um tratamento melhorado das faturas retificativas e regras de validação atualizadas, alinhadas com a mais recente regulamentação polaca do IVA.
