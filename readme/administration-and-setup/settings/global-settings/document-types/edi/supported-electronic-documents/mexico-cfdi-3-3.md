# 🇲🇽 MEXICO CFDI 3.3

| Propriedade          | Valor                                              |
| -------------------- | -------------------------------------------------- |
| **País / Região**    | México                                             |
| **Tipos de documento** | Fatura, Nota de crédito, Recibo de pagamento     |
| **Formato**          | XML                                                |
| **Padrão**           | CFDI 3.3 (Comprobante Fiscal Digital por Internet) |

O CFDI 3.3 é a geração anterior do padrão mexicano de comprovativo fiscal digital emitido pelo SAT (Servicio de Administración Tributaria). Embora tenha sido substituído pelo CFDI 4.0, muitas faturas históricas ainda utilizam esta versão. Inclui o UUID (folio fiscal), os identificadores RFC e os cálculos de impostos IEPS/IVA.
