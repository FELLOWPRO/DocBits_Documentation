# 🇲🇽 MEXICO CFDI 3.3

| Eigenschap           | Waarde                                             |
| -------------------- | -------------------------------------------------- |
| **Land / Regio**     | Mexico                                             |
| **Documenttypen**    | Factuur, Creditnota, Betalingsbewijs               |
| **Formaat**          | XML                                                |
| **Standaard**        | CFDI 3.3 (Comprobante Fiscal Digital por Internet) |

CFDI 3.3 is de vorige generatie van de Mexicaanse standaard voor digitale belastingbewijzen, uitgegeven door de SAT (Servicio de Administración Tributaria). Hoewel deze is vervangen door CFDI 4.0, gebruiken veel historische facturen nog steeds deze versie. De standaard bevat de UUID (folio fiscal), RFC-identificaties en IEPS/IVA-belastingberekeningen.
