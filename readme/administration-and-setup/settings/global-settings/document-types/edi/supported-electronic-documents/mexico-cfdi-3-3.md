# 🇲🇽 MEXICO CFDI 3.3

| Eigenschaft          | Wert                                               |
| -------------------- | -------------------------------------------------- |
| **Land / Region**    | Mexiko                                             |
| **Dokumenttypen**    | Rechnung, Gutschrift, Zahlungsbeleg                |
| **Format**           | XML                                                |
| **Standard**         | CFDI 3.3 (Comprobante Fiscal Digital por Internet) |

CFDI 3.3 ist die frühere Generation des mexikanischen Standards für digitale Steuerbelege, herausgegeben von der SAT (Servicio de Administración Tributaria). Obwohl er durch CFDI 4.0 abgelöst wurde, verwenden viele historische Rechnungen noch diese Version. Sie enthält die UUID (folio fiscal), RFC-Kennungen sowie IEPS-/IVA-Steuerberechnungen.
