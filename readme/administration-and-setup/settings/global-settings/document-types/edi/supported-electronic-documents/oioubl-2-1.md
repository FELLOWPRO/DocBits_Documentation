# 🇩🇰 OIOUBL 2.1

<!-- edocs-country-scope -->

{% hint style="info" %}
Consulte o guia do país para conhecer os limites das versões, a configuração efetiva e o vídeo explicativo. [Dinamarca](countries/denmark.md). OIOUBL e Peppol BIS são perfis distintos. A sintaxe UBL, por si só, não identifica o perfil nacional.
{% endhint %}

| Propriedade          | Valor                                          |
| -------------------- | ---------------------------------------------- |
| **País / Região**    | Dinamarca                                      |
| **Tipos de documento** | Fatura, Nota de crédito, Aviso de pagamento, Extrato |
| **Formato**          | UBL 2.1 XML                                    |
| **Padrão**           | OIOUBL 2.1                                     |

O OIOUBL 2.1 é a versão atual do padrão dinamarquês de faturação eletrônica. Baseado no OASIS UBL 2.1, alarga o padrão internacional com regras de negócio e listas de códigos específicas da Dinamarca, exigidas pelo setor público dinamarquês.
