# 🇩🇰 OIOUBL 2.1

<!-- edocs-country-scope -->

{% hint style="info" %}
Die Länderanleitung enthält Versionsgrenzen, die tatsächlich verwendete Konfiguration und das Erklärvideo zum Land. [Dänemark](countries/denmark.md). OIOUBL und Peppol BIS sind unterschiedliche Profile. Die UBL-Syntax allein identifiziert das nationale Profil nicht.
{% endhint %}

| Eigenschaft          | Wert                                      |
| -------------------- | ----------------------------------------- |
| **Land / Region**    | Dänemark                                  |
| **Dokumenttypen**    | Rechnung, Gutschrift, Mahnung, Kontoauszug |
| **Format**           | UBL 2.1 XML                               |
| **Standard**         | OIOUBL 2.1                                |

OIOUBL 2.1 ist die aktuelle Version des dänischen E-Rechnungsstandards. Er basiert auf OASIS UBL 2.1 und erweitert den internationalen Standard um dänische Geschäftsregeln und Codelisten, die vom dänischen öffentlichen Sektor gefordert werden.
