# 🇵🇾 PARAGUAY DTE

| Propiedad              | Valor                                  |
| ---------------------- | -------------------------------------- |
| **País / Región**      | Paraguay                               |
| **Tipos de documento** | Factura, Nota de crédito               |
| **Formato**            | XML                                    |
| **Estándar**           | DTE (Documento Tributario Electrónico) |

Paraguay DTE es el estándar paraguayo de documento tributario electrónico regulado por la Subsecretaría de Estado de Tributación (SET). Abarca las facturas y notas de crédito electrónicas con la identificación fiscal (RUC) y los requisitos de categoría fiscal específicos de Paraguay.

## Estado de compatibilidad

| Componente             | Estado          |
| ---------------------- | --------------- |
| Vista previa           | ✅ Compatible    |
| Extracción de campos   | ✅ Compatible    |
| Transformación         | ✅ Compatible    |
