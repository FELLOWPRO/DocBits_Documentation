# 🇵🇾 PARAGUAY DTE

| Propriété | Valeur |
| --------- | ------ |
| **Pays / Région** | Paraguay |
| **Types de documents** | Facture, Note de crédit |
| **Format** | XML |
| **Norme** | DTE (Documento Tributario Electrónico) |

Paraguay DTE est la norme paraguayenne de document fiscal électronique, réglementée par la Subsecretaría de Estado de Tributación (SET). Elle couvre les factures et notes de crédit électroniques, avec l'identification fiscale paraguayenne (RUC) et les exigences de catégories de taxes propres au pays.
