# 🇵🇾 巴拉圭 DTE

| 属性                 | 值                                     |
| -------------------- | -------------------------------------- |
| **国家 / 地区**      | 巴拉圭                                 |
| **文档类型**         | 发票、贷项通知单                       |
| **格式**             | XML                                    |
| **标准**             | DTE（Documento Tributario Electrónico） |

巴拉圭 DTE 是由税务国务副秘书处（Subsecretaría de Estado de Tributación，SET）监管的巴拉圭电子税务文档标准。该标准涵盖电子发票和贷项通知单，并要求使用巴拉圭特有的税务识别号（RUC）和税务类别。
