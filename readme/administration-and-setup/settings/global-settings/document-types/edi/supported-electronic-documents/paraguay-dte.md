# 🇵🇾 PARAGUAY DTE

<!-- edocs-country-scope -->

{% hint style="info" %}
Consulte o guia do país para conhecer os limites das versões, a configuração efetiva e o vídeo explicativo. [Paraguai](countries/paraguay.md). As entradas de classificação de notas de crédito não têm conjuntos de extração dedicados no estado examinado. Verifique o mapeamento efetivo e não trate as designações como equivalentes.
{% endhint %}

| Propriedade          | Valor                                  |
| -------------------- | -------------------------------------- |
| **País / Região**    | Paraguai                               |
| **Tipos de documento** | Fatura, Nota de crédito              |
| **Formato**          | XML                                    |
| **Padrão**           | DTE (Documento Tributario Electrónico) |

O Paraguay DTE é o padrão paraguaio de documento fiscal eletrônico, regulamentado pela Subsecretaría de Estado de Tributación (SET). Abrange faturas e notas de crédito eletrônicas com os requisitos paraguaios de identificação fiscal (RUC) e de categoria fiscal.
