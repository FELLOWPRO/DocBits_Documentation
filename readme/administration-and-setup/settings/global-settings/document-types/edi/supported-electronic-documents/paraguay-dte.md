# 🇵🇾 PARAGUAY DTE

| Właściwość           | Wartość                                |
| -------------------- | -------------------------------------- |
| **Kraj / Region**    | Paragwaj                               |
| **Typy dokumentów**  | Faktura, Nota kredytowa                |
| **Format**           | XML                                    |
| **Standard**         | DTE (Documento Tributario Electrónico) |

Paraguay DTE to paragwajski standard elektronicznych dokumentów podatkowych, regulowany przez Subsecretaría de Estado de Tributación (SET). Obejmuje faktury elektroniczne i noty kredytowe z uwzględnieniem paragwajskiego numeru identyfikacji podatkowej (RUC) oraz wymogów dotyczących kategorii podatkowych.
