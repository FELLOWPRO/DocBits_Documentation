# 🇵🇾 PARAGUAY SIFEN 150

<!-- edocs-country-scope -->

{% hint style="info" %}
Sprawdź w przewodniku krajowym ograniczenia wersji, faktycznie używaną konfigurację i film objaśniający dla kraju. [Paragwaj](countries/paraguay.md). Wpisy klasyfikacji not kredytowych nie mają dedykowanych pakietów ekstrakcji w sprawdzonym stanie. Zweryfikuj faktycznie używane mapowanie i nie traktuj tych oznaczeń jako zamiennych.
{% endhint %}

| Właściwość           | Wartość                  |
| -------------------- | ------------------------ |
| **Kraj / Region**    | Paragwaj                 |
| **Typy dokumentów**  | Faktura, Nota kredytowa  |
| **Format**           | XML                      |
| **Standard**         | SIFEN Schema Version 150 |

SIFEN 150 oznacza wersję 150 schematu paragwajskiego systemu SIFEN. Wersja ta wprowadziła zaktualizowane reguły walidacji i wymagania dotyczące pól dla dokumentów elektronicznych przetwarzanych przez platformę SET.
