# 🇵🇾 PARAGUAY SIFEN 150

| Propriété | Valeur |
| --------- | ------ |
| **Pays / Région** | Paraguay |
| **Types de documents** | Facture, Note de crédit |
| **Format** | XML |
| **Norme** | SIFEN, version de schéma 150 |

SIFEN 150 désigne la version 150 du schéma du système paraguayen SIFEN. Cette version a introduit des règles de validation et des exigences de champs mises à jour pour les documents électroniques traités via la plateforme de la SET.
