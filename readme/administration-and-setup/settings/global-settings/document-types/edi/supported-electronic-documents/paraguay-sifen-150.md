| Propriedade          | Valor                    |
| -------------------- | ------------------------ |
| **País / Região**    | Paraguai                 |
| **Tipos de documento** | Fatura, Nota de crédito |
| **Formato**          | XML                      |
| **Padrão**           | SIFEN Schema Version 150 |

O SIFEN 150 refere-se à versão 150 do esquema do sistema paraguaio SIFEN. Esta versão introduziu regras de validação e requisitos de campos atualizados para os documentos eletrônicos processados através da plataforma da SET.
