# 🇵🇾 PARAGUAY SIFEN

| Właściwość           | Wartość                                                       |
| -------------------- | ------------------------------------------------------------- |
| **Kraj / Region**    | Paragwaj                                                      |
| **Typy dokumentów**  | Faktura, Nota kredytowa, Nota debetowa, Zatrzymanie podatku u źródła |
| **Format**           | XML                                                           |
| **Standard**         | SIFEN (Sistema Integrado de Facturación Electrónica Nacional) |

SIFEN to krajowy zintegrowany system e-fakturowania Paragwaju, prowadzony przez SET. Wszystkie dokumenty elektroniczne muszą być przesyłane do SIFEN w celu walidacji i otrzymują unikalny identyfikator CDC (Código de Control Digital).
