# 🇵🇾 PARAGUAY SIFEN

| Eigenschap           | Waarde                                                        |
| -------------------- | ------------------------------------------------------------- |
| **Land / Regio**     | Paraguay                                                      |
| **Documenttypen**    | Factuur, Creditnota, Debetnota, Bronheffing                   |
| **Formaat**          | XML                                                           |
| **Standaard**        | SIFEN (Sistema Integrado de Facturación Electrónica Nacional) |

SIFEN is het nationale geïntegreerde e-factureringssysteem van Paraguay, beheerd door de SET. Alle elektronische documenten moeten ter validatie bij SIFEN worden ingediend en ontvangen een unieke CDC-identificatie (Código de Control Digital).
