# 🇵🇾 PARAGUAY SIFEN

<!-- edocs-country-scope -->

{% hint style="info" %}
Consultate la guida del paese per i limiti delle versioni, la configurazione effettivamente utilizzata e il video esplicativo del paese. [Paraguay](countries/paraguay.md). Le voci di classificazione delle note di credito non hanno insiemi di componenti di estrazione dedicati nello stato esaminato. Verificate la mappatura effettivamente utilizzata e non considerate le etichette intercambiabili.
{% endhint %}

| Proprietà            | Valore                                                        |
| -------------------- | ------------------------------------------------------------- |
| **Paese / Regione**  | Paraguay                                                      |
| **Tipi di documento** | Fattura, Nota di credito, Nota di debito, Ritenuta d'acconto |
| **Formato**          | XML                                                           |
| **Standard**         | SIFEN (Sistema Integrado de Facturación Electrónica Nacional) |

SIFEN è il sistema nazionale integrato di fatturazione elettronica del Paraguay, gestito dalla SET. Tutti i documenti elettronici devono essere trasmessi a SIFEN per la convalida e ricevono un identificativo univoco CDC (Código de Control Digital).
