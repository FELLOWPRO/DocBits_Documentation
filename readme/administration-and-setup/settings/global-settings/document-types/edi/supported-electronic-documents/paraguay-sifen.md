# 🇵🇾 PARAGUAY SIFEN

| Eigenschaft          | Wert                                                          |
| -------------------- | ------------------------------------------------------------- |
| **Land / Region**    | Paraguay                                                      |
| **Dokumenttypen**    | Rechnung, Gutschrift, Belastungsanzeige, Quellensteuerbeleg   |
| **Format**           | XML                                                           |
| **Standard**         | SIFEN (Sistema Integrado de Facturación Electrónica Nacional) |

SIFEN ist Paraguays nationales integriertes E-Rechnungssystem, das von der SET betrieben wird. Alle elektronischen Dokumente müssen zur Validierung an SIFEN übermittelt werden und erhalten eine eindeutige CDC-Kennung (Código de Control Digital).
