# 🇵🇾 PARAGUAY SIFEN

| Propriété | Valeur |
| --------- | ------ |
| **Pays / Région** | Paraguay |
| **Types de documents** | Facture, Note de crédit, Note de débit, Retenue à la source |
| **Format** | XML |
| **Norme** | SIFEN (Sistema Integrado de Facturación Electrónica Nacional) |

SIFEN est le système national intégré de facturation électronique du Paraguay, exploité par la SET. Tous les documents électroniques doivent être soumis à SIFEN pour validation et reçoivent un identifiant unique CDC (Código de Control Digital).
