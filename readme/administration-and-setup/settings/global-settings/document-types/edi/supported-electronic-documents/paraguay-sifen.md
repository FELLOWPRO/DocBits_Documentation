# 🇵🇾 PARAGUAY SIFEN

<!-- edocs-country-scope -->

{% hint style="info" %}
Consultez le guide du pays pour connaître les limites de version, la configuration effectivement utilisée et la vidéo explicative du pays. [Paraguay](countries/paraguay.md). Les entrées de classification des avoirs n’ont pas d’ensembles d’extraction dédiés dans l’état examiné. Vérifiez la correspondance effectivement utilisée et ne considérez pas ces libellés comme interchangeables.
{% endhint %}

| Propriété | Valeur |
| --------- | ------ |
| **Pays / Région** | Paraguay |
| **Types de documents** | Facture, Note de crédit, Note de débit, Retenue à la source |
| **Format** | XML |
| **Norme** | SIFEN (Sistema Integrado de Facturación Electrónica Nacional) |

SIFEN est le système national intégré de facturation électronique du Paraguay, exploité par la SET. Tous les documents électroniques doivent être soumis à SIFEN pour validation et reçoivent un identifiant unique CDC (Código de Control Digital).
