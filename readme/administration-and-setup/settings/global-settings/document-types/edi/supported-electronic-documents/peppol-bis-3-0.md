# 🇪🇺 PEPPOL BIS 3.0

| **Standard** | Peppol BIS Billing 3.0 |

Peppol BIS Billing 3.0 to ogólnoeuropejski standard e-fakturowania stosowany w całej sieci Peppol. Opiera się na OASIS UBL 2.1 i implementuje europejską normę EN 16931 dotyczącą faktur elektronicznych. Peppol umożliwia transgraniczną wymianę faktur B2B i B2G w ponad 40 krajach za pośrednictwem certyfikowanych punktów dostępu (Access Points).
