# 🇪🇺 PEPPOL BIS 3.0

| Proprietà             | Valore                                          |
| --------------------- | ----------------------------------------------- |
| **Paese / Regione**   | Unione Europea / Internazionale (oltre 40 paesi) |
| **Tipi di documento** | Fattura, Nota di credito                        |
| **Formato**           | UBL 2.1 XML                                     |
| **Standard**          | Peppol BIS Billing 3.0                          |

Peppol BIS Billing 3.0 è lo standard paneuropeo di fatturazione elettronica utilizzato nella rete Peppol. Si basa su OASIS UBL 2.1 e implementa la norma europea EN 16931 per la fatturazione elettronica. Peppol consente lo scambio transfrontaliero di fatture B2B e B2G in oltre 40 paesi tramite Access Point certificati.
