# 🇪🇺 PEPPOL BIS 3.0

<!-- edocs-country-scope -->

{% hint style="info" %}
Raadpleeg de landengids voor versiebeperkingen, de daadwerkelijk gebruikte configuratie en de uitlegvideo voor het land. [Internationaal](countries/international.md). Toewijzingen voor facturen, orders, antwoorden en verzendberichten staan los van elkaar. Bestandsverwerking biedt op zichzelf geen Peppol-toegangspunt of verbinding met handelspartners.
{% endhint %}

| Eigenschap           | Waarde                                            |
| -------------------- | ------------------------------------------------- |
| **Land / Regio**     | Europese Unie / Internationaal (40+ landen)       |
| **Documenttypen**    | Factuur, Creditnota                               |
| **Formaat**          | UBL 2.1 XML                                       |
| **Standaard**        | Peppol BIS Billing 3.0                            |

Peppol BIS Billing 3.0 is de pan-Europese e-factureringsstandaard die in het hele Peppol-netwerk wordt gebruikt. Deze is gebaseerd op OASIS UBL 2.1 en implementeert de Europese norm EN 16931 voor elektronische facturering. Peppol maakt grensoverschrijdende B2B- en B2G-factuuruitwisseling mogelijk in meer dan 40 landen via gecertificeerde Access Points.
