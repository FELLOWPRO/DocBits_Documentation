# 🇵🇪 PERU CPE UBL 2.0

| Proprietà             | Valore                                |
| --------------------- | ------------------------------------- |
| **Paese / Regione**   | Perù                                  |
| **Tipi di documento** | Fattura, Nota di credito, Nota di debito |
| **Formato**           | UBL 2.0 XML                           |
| **Standard**          | CPE UBL 2.0                           |

Peru CPE UBL 2.0 è il formato precedente basato su UBL per le fatture elettroniche peruviane. Sebbene la SUNAT sia passata a UBL 2.1, molti documenti esistenti utilizzano ancora questa versione. DocBits elabora questi documenti ed estrae tutti i campi di intestazione e di riga.

## Stato del supporto

| Componente       | Stato        |
| ---------------- | ------------ |
| Anteprima        | ✅ Supportato |
| Estrazione campi | ✅ Supportato |
| Trasformazione   | ✅ Supportato |
