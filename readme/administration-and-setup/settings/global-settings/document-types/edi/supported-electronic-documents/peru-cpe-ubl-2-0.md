# 🇵🇪 PERU CPE UBL 2.0

<!-- edocs-country-scope -->

{% hint style="info" %}
Raadpleeg de landengids voor versiebeperkingen, de daadwerkelijk gebruikte configuratie en de uitlegvideo voor het land. [Peru](countries/peru.md). Selecteer de werkelijke UBL-versie en documentstructuur. Het verwerken van een bestand bewijst geen acceptatie door SUNAT.
{% endhint %}

| Eigenschap           | Waarde                           |
| -------------------- | -------------------------------- |
| **Land / Regio**     | Peru                             |
| **Documenttypen**    | Factuur, Creditnota, Debetnota   |
| **Formaat**          | UBL 2.0 XML                      |
| **Standaard**        | CPE UBL 2.0                      |

Peru CPE UBL 2.0 is het oudere, op UBL gebaseerde formaat voor Peruaanse elektronische facturen. Hoewel de SUNAT is overgestapt op UBL 2.1, gebruiken veel bestaande documenten nog steeds deze versie. DocBits verwerkt deze documenten en extraheert alle header- en regelvelden.
