# 🇵🇪 PERU CPE UBL 2.0

| Właściwość | Wartość |
| ---------- | ------- |
| **Kraj/Region** | Peru |
| **Typy dokumentów** | Faktura, Nota kredytowa, Nota debetowa |
| **Format** | UBL 2.0 XML |
| **Standard** | CPE UBL 2.0 |

Peru CPE UBL 2.0 to wcześniejszy format oparty na UBL dla peruwiańskich faktur elektronicznych. Chociaż SUNAT przeszedł na UBL 2.1, wiele istniejących dokumentów nadal korzysta z tej wersji. DocBits przetwarza takie dokumenty i ekstrahuje wszystkie pola nagłówka oraz pozycji.
