# 🇵🇪 PERU CPE UBL 2.1

| Właściwość | Wartość |
| ---------- | ------- |
| **Kraj/Region** | Peru |
| **Typy dokumentów** | Faktura, Nota kredytowa, Nota debetowa |
| **Format** | UBL 2.1 XML |
| **Standard** | CPE UBL 2.1 |

Peru CPE UBL 2.1 to aktualny format peruwiańskich faktur elektronicznych przesyłanych do SUNAT. Wykorzystuje standard OASIS UBL 2.1 z peruwiańskimi rozszerzeniami dla identyfikacji RUC, obliczeń podatku IGV (VAT) oraz mechanizmów potrąceń detracción/retención.
