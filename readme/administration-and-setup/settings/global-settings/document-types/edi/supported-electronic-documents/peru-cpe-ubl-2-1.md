# 🇵🇪 PERU CPE UBL 2.1

<!-- edocs-country-scope -->

{% hint style="info" %}
Consulte la guía del país para conocer los límites de versión, la configuración que se está utilizando y el vídeo explicativo del país. [Perú](countries/peru.md). Seleccione la versión UBL y la estructura de documento reales. Procesar un archivo no demuestra su aceptación por SUNAT.
{% endhint %}

| Propiedad              | Valor                                    |
| ---------------------- | ---------------------------------------- |
| **País / Región**      | Perú                                     |
| **Tipos de documento** | Factura, Nota de crédito, Nota de débito |
| **Formato**            | UBL 2.1 XML                              |
| **Estándar**           | CPE UBL 2.1                              |

Peru CPE UBL 2.1 es el formato actual de las facturas electrónicas peruanas enviadas a la SUNAT. Utiliza el estándar OASIS UBL 2.1 con extensiones peruanas para la identificación mediante RUC, los cálculos del impuesto IGV (IVA) y los mecanismos de retención de detracción/retención.

## Estado de compatibilidad

| Componente             | Estado          |
| ---------------------- | --------------- |
| Vista previa           | ✅ Compatible    |
| Extracción de campos   | ✅ Compatible    |
| Transformación         | ✅ Compatible    |
