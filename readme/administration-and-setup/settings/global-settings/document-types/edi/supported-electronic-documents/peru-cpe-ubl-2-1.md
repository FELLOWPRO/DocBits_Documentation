# 🇵🇪 PERU CPE UBL 2.1

<!-- edocs-country-scope -->

{% hint style="info" %}
Consultate la guida del paese per i limiti delle versioni, la configurazione effettivamente utilizzata e il video esplicativo del paese. [Perù](countries/peru.md). Selezionate la versione UBL e la struttura effettive del documento. L’elaborazione di un file non dimostra l’accettazione da parte di SUNAT.
{% endhint %}

| Proprietà             | Valore                                   |
| --------------------- | ---------------------------------------- |
| **Paese / Regione**   | Perù                                     |
| **Tipi di documento** | Fattura, Nota di credito, Nota di debito |
| **Formato**           | UBL 2.1 XML                              |
| **Standard**          | CPE UBL 2.1                              |

Peru CPE UBL 2.1 è il formato attuale per le fatture elettroniche peruviane inviate alla SUNAT. Utilizza lo standard OASIS UBL 2.1 con estensioni peruviane per l'identificazione tramite RUC, il calcolo dell'imposta IGV (IVA) e i meccanismi di ritenuta di detracción/retención.
