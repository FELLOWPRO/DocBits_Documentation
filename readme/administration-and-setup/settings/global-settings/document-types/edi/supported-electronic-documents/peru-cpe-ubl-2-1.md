# 🇵🇪 PERU CPE UBL 2.1

<!-- edocs-country-scope -->

{% hint style="info" %}
Die Länderanleitung enthält Versionsgrenzen, die tatsächlich verwendete Konfiguration und das Erklärvideo zum Land. [Peru](countries/peru.md). Wählen Sie die tatsächliche UBL-Version und Dokumentstruktur aus. Die Verarbeitung einer Datei belegt keine Annahme durch SUNAT.

| Eigenschaft          | Wert                                  |
| -------------------- | ------------------------------------- |
| **Land / Region**    | Peru                                  |
| **Dokumenttypen**    | Rechnung, Gutschrift, Belastungsanzeige |
| **Format**           | UBL 2.1 XML                           |
| **Standard**         | CPE UBL 2.1                           |

Peru CPE UBL 2.1 ist das aktuelle Format für peruanische elektronische Rechnungen, die bei der SUNAT eingereicht werden. Es verwendet den OASIS-Standard UBL 2.1 mit peruanischen Erweiterungen für die RUC-Identifikation, IGV-Steuerberechnungen (Umsatzsteuer) sowie die Einbehaltsmechanismen detracción/retención.
