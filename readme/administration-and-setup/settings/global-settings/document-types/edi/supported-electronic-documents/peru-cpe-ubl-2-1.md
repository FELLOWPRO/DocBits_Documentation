# 🇵🇪 秘鲁 CPE UBL 2.1

<!-- edocs-country-scope -->

{% hint style="info" %}
请参阅国家指南，了解版本限制、实际生效的配置和国家说明视频。 [秘鲁](countries/peru.md). 请选择实际的 UBL 版本和文档结构。成功处理文件不代表已被 SUNAT 接受。
{% endhint %}

| 属性                 | 值                               |
| -------------------- | -------------------------------- |
| **国家 / 地区**      | 秘鲁                             |
| **文档类型**         | 发票、贷项通知单、借项通知单     |
| **格式**             | UBL 2.1 XML                      |
| **标准**             | CPE UBL 2.1                      |

秘鲁 CPE UBL 2.1 是提交给 SUNAT 的秘鲁电子发票现行格式。它采用 OASIS UBL 2.1 标准，并扩展支持 RUC 标识、IGV（增值税）计算以及 detracción/retención 预扣机制。
