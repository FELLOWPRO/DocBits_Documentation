# 🇵🇪 PERU CPE

| Eigenschaft          | Wert                                  |
| -------------------- | ------------------------------------- |
| **Land / Region**    | Peru                                  |
| **Dokumenttypen**    | Rechnung, Gutschrift, Belastungsanzeige |
| **Format**           | UBL XML                               |
| **Standard**         | CPE (Comprobante de Pago Electrónico) |

CPE (Comprobante de Pago Electrónico) ist der peruanische Standard für elektronische Zahlungsbelege, der von der SUNAT geregelt wird. DocBits unterstützt sowohl die Versionen UBL 2.0 als auch UBL 2.1, die in Peru für die elektronische Rechnungsstellung verwendet werden.
