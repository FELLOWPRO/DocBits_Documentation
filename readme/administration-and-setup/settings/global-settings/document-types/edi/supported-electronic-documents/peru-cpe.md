# 🇵🇪 PERU CPE

| Proprietà             | Valore                                   |
| --------------------- | ---------------------------------------- |
| **Paese / Regione**   | Perù                                     |
| **Tipi di documento** | Fattura, Nota di credito, Nota di debito |
| **Formato**           | UBL XML                                  |
| **Standard**          | CPE (Comprobante de Pago Electrónico)    |

CPE (Comprobante de Pago Electrónico) è lo standard peruviano del documento di pagamento elettronico regolamentato dalla SUNAT. DocBits supporta entrambe le versioni UBL 2.0 e 2.1 utilizzate per la fatturazione elettronica in Perù.

## Stato del supporto

| Componente       | Stato        |
| ---------------- | ------------ |
| Anteprima        | ✅ Supportato |
| Estrazione campi | ✅ Supportato |
| Trasformazione   | ✅ Supportato |
