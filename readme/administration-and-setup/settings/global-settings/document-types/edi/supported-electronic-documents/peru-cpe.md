# 🇵🇪 PERU CPE

| Eigenschap           | Waarde                                |
| -------------------- | ------------------------------------- |
| **Land / Regio**     | Peru                                  |
| **Documenttypen**    | Factuur, Creditnota, Debetnota        |
| **Formaat**          | UBL XML                               |
| **Standaard**        | CPE (Comprobante de Pago Electrónico) |

CPE (Comprobante de Pago Electrónico) is de Peruaanse standaard voor elektronische betalingsbewijzen, gereguleerd door de SUNAT. DocBits ondersteunt zowel de UBL 2.0- als de UBL 2.1-versie die voor elektronische facturering in Peru worden gebruikt.
