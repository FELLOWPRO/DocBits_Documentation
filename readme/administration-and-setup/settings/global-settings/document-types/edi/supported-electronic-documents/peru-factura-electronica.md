# 🇵🇪 PERU FACTURA ELECTRONICA

<!-- edocs-country-scope -->

{% hint style="info" %}
Consulte o guia do país para conhecer os limites das versões, a configuração efetiva e o vídeo explicativo. [Peru](countries/peru.md). Selecione a versão UBL e a estrutura de documento reais. Processar um ficheiro não comprova a aceitação pela SUNAT.
{% endhint %}

| Propriedade          | Valor                       |
| -------------------- | --------------------------- |
| **País / Região**    | Peru                        |
| **Tipos de documento** | Fatura                    |
| **Formato**          | UBL XML                     |
| **Padrão**           | Factura Electrónica (SUNAT) |

A Peru Factura Electrónica é o tipo de documento de fatura eletrônica dentro do sistema CPE da SUNAT. Corresponde ao código de tipo de documento 01 (Factura) e inclui todos os campos obrigatórios exigidos pela SUNAT, entre eles a série, o número correlativo e a assinatura eletrônica.
