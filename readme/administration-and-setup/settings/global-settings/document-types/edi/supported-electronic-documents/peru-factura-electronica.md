# 🇵🇪 PERU FACTURA ELECTRONICA

| Eigenschap           | Waarde                      |
| -------------------- | --------------------------- |
| **Land / Regio**     | Peru                        |
| **Documenttypen**    | Factuur                     |
| **Formaat**          | UBL XML                     |
| **Standaard**        | Factura Electrónica (SUNAT) |

Peru Factura Electrónica is het documenttype elektronische factuur binnen het SUNAT CPE-systeem. Het komt overeen met documenttypecode 01 (Factura) en bevat alle verplichte velden die de SUNAT vereist, waaronder serie, correlatief nummer en elektronische handtekening.
