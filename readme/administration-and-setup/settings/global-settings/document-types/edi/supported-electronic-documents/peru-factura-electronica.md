# 🇵🇪 PERU FACTURA ELECTRONICA

<!-- edocs-country-scope -->

{% hint style="info" %}
Consultez le guide du pays pour connaître les limites de version, la configuration effectivement utilisée et la vidéo explicative du pays. [Pérou](countries/peru.md). Sélectionnez la version UBL et la structure réelles du document. Le traitement d’un fichier ne prouve pas son acceptation par la SUNAT.
{% endhint %}

| Propriété | Valeur |
| --------- | ------ |
| **Pays / Région** | Pérou |
| **Types de documents** | Facture |
| **Format** | XML UBL |
| **Norme** | Factura Electrónica (SUNAT) |

Peru Factura Electrónica est le type de document de facture électronique au sein du système CPE de la SUNAT. Il correspond au code de type de document 01 (Factura) et comprend tous les champs obligatoires exigés par la SUNAT, notamment la série, le numéro corrélatif et la signature électronique.

## Statut de prise en charge

| Composant | Statut |
| --------- | ------ |
