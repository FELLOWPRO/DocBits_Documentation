# 🇵🇪 PERU FACTURA ELECTRONICA

| Proprietà             | Valore                      |
| --------------------- | --------------------------- |
| **Paese / Regione**   | Perù                        |
| **Tipi di documento** | Fattura                     |
| **Formato**           | UBL XML                     |
| **Standard**          | Factura Electrónica (SUNAT) |

Peru Factura Electrónica è il tipo di documento fattura elettronica all'interno del sistema CPE della SUNAT. Corrisponde al codice di tipo documento 01 (Factura) e include tutti i campi obbligatori richiesti dalla SUNAT, tra cui serie, numero progressivo e firma elettronica.

| Componente       | Stato        |
