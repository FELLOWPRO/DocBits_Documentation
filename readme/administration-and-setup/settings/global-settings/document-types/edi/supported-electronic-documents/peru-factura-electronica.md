# 🇵🇪 PERU FACTURA ELECTRONICA

| Eigenschaft          | Wert                        |
| -------------------- | --------------------------- |
| **Land / Region**    | Peru                        |
| **Dokumenttypen**    | Rechnung                    |
| **Format**           | UBL XML                     |
| **Standard**         | Factura Electrónica (SUNAT) |

Peru Factura Electrónica ist der Dokumenttyp für elektronische Rechnungen innerhalb des SUNAT-CPE-Systems. Er entspricht dem Dokumenttypcode 01 (Factura) und enthält alle von der SUNAT vorgeschriebenen Pflichtfelder, darunter Serie, fortlaufende Nummer und elektronische Signatur.
