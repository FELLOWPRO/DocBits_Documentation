# 🇵🇪 PERU FACTURA ELECTRONICA

| Propiedad              | Valor                       |
| ---------------------- | --------------------------- |
| **País / Región**      | Perú                        |
| **Tipos de documento** | Factura                     |
| **Formato**            | UBL XML                     |
| **Estándar**           | Factura Electrónica (SUNAT) |

Peru Factura Electrónica es el tipo de documento de factura electrónica dentro del sistema CPE de la SUNAT. Corresponde al código de tipo de documento 01 (Factura) e incluye todos los campos obligatorios exigidos por la SUNAT, entre ellos la serie, el número correlativo y la firma electrónica.

## Estado de compatibilidad

| Componente             | Estado          |
| ---------------------- | --------------- |
| Vista previa           | ✅ Compatible    |
| Extracción de campos   | ✅ Compatible    |
| Transformación         | ✅ Compatible    |
