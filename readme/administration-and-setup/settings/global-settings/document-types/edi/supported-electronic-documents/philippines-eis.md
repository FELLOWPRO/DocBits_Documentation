# 🇵🇭 PHILIPPINES EIS

| Właściwość | Wartość |
| ---------- | ------- |
| **Kraj/Region** | Filipiny |
| **Typy dokumentów** | Faktura, Pokwitowanie urzędowe |
| **Format** | XML/JSON |
| **Standard** | EIS (Electronic Invoicing System - BIR) |

Philippines EIS to System Fakturowania Elektronicznego (Electronic Invoicing System) działający pod nadzorem Bureau of Internal Revenue (BIR). Jego celem jest cyfryzacja fakturowania i wystawiania pokwitowań dla filipińskich przedsiębiorstw, co wymaga elektronicznego przesyłania danych sprzedaży do systemu BIR w celu monitorowania zgodności podatkowej.
