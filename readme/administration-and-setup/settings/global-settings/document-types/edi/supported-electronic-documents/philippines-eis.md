# 🇵🇭 PHILIPPINES EIS

| Eigenschap           | Waarde                                  |
| -------------------- | --------------------------------------- |
| **Land / Regio**     | Filipijnen                              |
| **Documenttypen**    | Factuur, Officieel ontvangstbewijs      |
| **Formaat**          | XML/JSON                                |
| **Standaard**        | EIS (Electronic Invoicing System - BIR) |

Philippines EIS is het Electronic Invoicing System van het Bureau of Internal Revenue (BIR). Het beoogt het factureren en het uitgeven van ontvangstbewijzen voor Filipijnse bedrijven te digitaliseren en vereist dat verkoopgegevens elektronisch naar het systeem van de BIR worden verzonden voor toezicht op de naleving van de belastingregels.
