# 🇵🇭 PHILIPPINES EIS

| Propriedade          | Valor                                   |
| -------------------- | --------------------------------------- |
| **País / Região**    | Filipinas                               |
| **Tipos de documento** | Fatura, Recibo oficial                |
| **Formato**          | XML/JSON                                |
| **Padrão**           | EIS (Electronic Invoicing System - BIR) |

O Philippines EIS é o Sistema de Faturamento Eletrônico (Electronic Invoicing System) do Bureau of Internal Revenue (BIR). Seu objetivo é digitalizar a emissão de faturas e recibos das empresas filipinas, exigindo a transmissão eletrônica dos dados de vendas ao sistema do BIR para o monitoramento da conformidade fiscal.
