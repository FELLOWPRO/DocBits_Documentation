# 🇵🇭 PHILIPPINES EIS

<!-- edocs-country-scope -->

{% hint style="info" %}
Consultate la guida del paese per i limiti delle versioni, la configurazione effettivamente utilizzata e il video esplicativo del paese. [Filippine](countries/philippines.md). L’etichetta non indica una versione. Verificate lo schema del contenuto e il tipo di documento pertinente prima di fare affidamento su un’etichetta EIS generica.
{% endhint %}

| Proprietà             | Valore                                  |
| --------------------- | --------------------------------------- |
| **Paese / Regione**   | Filippine                               |
| **Tipi di documento** | Fattura, Ricevuta ufficiale             |
| **Formato**           | XML/JSON                                |
| **Standard**          | EIS (Electronic Invoicing System - BIR) |

Philippines EIS è il sistema di fatturazione elettronica (Electronic Invoicing System) gestito dal Bureau of Internal Revenue (BIR). Mira a digitalizzare la fatturazione e il rilascio di ricevute per le imprese filippine e richiede la trasmissione elettronica dei dati di vendita al sistema del BIR per il monitoraggio della conformità fiscale.
