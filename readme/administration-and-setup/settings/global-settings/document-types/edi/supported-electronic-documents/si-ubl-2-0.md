# 🇳🇱 SI-UBL 2.0

| Propriedade          | Valor                                |
| -------------------- | ------------------------------------ |
| **País / Região**    | Países Baixos                        |
| **Tipos de documento** | Fatura, Nota de crédito            |
| **Formato**          | UBL 2.1 XML                          |
| **Padrão**           | SI-UBL 2.0 (Standaard Invoice - UBL) |

O SI-UBL 2.0 é o padrão holandês de faturamento eletrônico baseado no OASIS UBL 2.1. É mantido pelo NLCIUS (Netherlands Core Invoice Usage Specification) e está alinhado à norma EN 16931. O SI-UBL é amplamente usado em transações B2G e B2B nos Países Baixos, especialmente por meio da rede Peppol.
