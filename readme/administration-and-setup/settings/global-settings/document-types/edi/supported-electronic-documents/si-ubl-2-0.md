# 🇳🇱 SI-UBL 2.0

| Eigenschaft | Wert |
| ----------- | ---- |
| **Land / Region** | Niederlande |
| **Dokumenttypen** | Rechnung, Gutschrift |
| **Format** | UBL 2.1 XML |
| **Standard** | SI-UBL 2.0 (Standaard Invoice - UBL) |

SI-UBL 2.0 ist der niederländische E-Rechnungsstandard auf Basis von OASIS UBL 2.1. Er wird von NLCIUS (Netherlands Core Invoice Usage Specification) gepflegt und ist an EN 16931 angelehnt. SI-UBL wird im niederländischen B2G- und B2B-Geschäftsverkehr breit eingesetzt, insbesondere über das Peppol-Netzwerk.
