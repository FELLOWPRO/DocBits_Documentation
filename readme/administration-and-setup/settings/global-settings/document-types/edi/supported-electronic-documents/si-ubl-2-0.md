# 🇳🇱 SI-UBL 2.0

<!-- edocs-country-scope -->

{% hint style="info" %}
Raadpleeg de landengids voor versiebeperkingen, de daadwerkelijk gebruikte configuratie en de uitlegvideo voor het land. [Nederland](countries/netherlands.md). Een UBL-bestand is niet automatisch SI-UBL 2.0. Controleer de aanpassingsidentificatie en de bijbehorende nationale toewijzing.
{% endhint %}

| Eigenschap           | Waarde                               |
| -------------------- | ------------------------------------ |
| **Land / Regio**     | Nederland                            |
| **Documenttypen**    | Factuur, Creditnota                  |
| **Formaat**          | UBL 2.1 XML                          |
| **Standaard**        | SI-UBL 2.0 (Standaard Invoice - UBL) |

SI-UBL 2.0 is de Nederlandse e-factureringsstandaard op basis van OASIS UBL 2.1. Deze wordt onderhouden door NLCIUS (Netherlands Core Invoice Usage Specification) en sluit aan op EN 16931. SI-UBL wordt veel gebruikt in Nederlandse B2G- en B2B-transacties, met name via het Peppol-netwerk.
