# 🇳🇱 SI-UBL 2.0

| Propiedad              | Valor                                |
| ---------------------- | ------------------------------------ |
| **País / Región**      | Países Bajos                         |
| **Tipos de documento** | Factura, Nota de crédito             |
| **Formato**            | UBL 2.1 XML                          |
| **Estándar**           | SI-UBL 2.0 (Standaard Invoice - UBL) |

SI-UBL 2.0 es el estándar neerlandés de facturación electrónica basado en OASIS UBL 2.1. Lo mantiene NLCIUS (Netherlands Core Invoice Usage Specification) y está alineado con EN 16931. SI-UBL se utiliza ampliamente en las operaciones B2G y B2B neerlandesas, especialmente a través de la red Peppol.

## Estado de compatibilidad

| Componente             | Estado          |
| ---------------------- | --------------- |
| Vista previa           | ✅ Compatible    |
| Extracción de campos   | ✅ Compatible    |
| Transformación         | ✅ Compatible    |
