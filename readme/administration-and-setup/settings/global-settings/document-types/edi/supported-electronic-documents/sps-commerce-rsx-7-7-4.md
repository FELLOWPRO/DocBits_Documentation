# SPS COMMERCE RSX 7.7.4

| Propriedade | Valor |
|----------|-------|
| **País / Região** | Internacional (principalmente América do Norte) |
| **Tipos de documento** | Fatura (810), Pedido de compra (850), ASN (856) |
| **Formato** | XML |
| **Padrão** | SPS Commerce RSX 7.7.4 (Retail Standard XML) |

O SPS Commerce RSX (Retail Standard XML) 7.7.4 é um padrão de tradução de EDI para XML usado na cadeia de suprimentos do varejo. Ele fornece representações em XML de transações EDI comuns, incluindo faturas (810), pedidos de compra (850) e avisos antecipados de expedição (856). A SPS Commerce é uma das principais provedoras de EDI, conectando varejistas e fornecedores.
