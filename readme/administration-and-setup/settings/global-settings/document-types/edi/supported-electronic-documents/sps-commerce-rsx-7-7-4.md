# SPS COMMERCE RSX 7.7.4

| Propriété | Valeur |
|----------|-------|
| **Pays / Région** | International (principalement Amérique du Nord) |
| **Types de documents** | Facture (810), Bon de commande (850), ASN (856) |
| **Format** | XML |
| **Norme** | SPS Commerce RSX 7.7.4 (Retail Standard XML) |

SPS Commerce RSX (Retail Standard XML) 7.7.4 est une norme de traduction EDI vers XML utilisée dans la chaîne d'approvisionnement du commerce de détail. Elle fournit des représentations XML des transactions EDI courantes, notamment les factures (810), les bons de commande (850) et les avis d'expédition anticipés (856). SPS Commerce est un fournisseur EDI de premier plan qui met en relation les détaillants et leurs fournisseurs.
