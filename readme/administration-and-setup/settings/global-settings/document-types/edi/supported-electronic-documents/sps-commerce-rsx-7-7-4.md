# SPS COMMERCE RSX 7.7.4

| Właściwość | Wartość |
|----------|-------|
| **Kraj/Region** | Międzynarodowo (głównie Ameryka Północna) |
| **Typy dokumentów** | Faktura (810), Zamówienie zakupu (850), ASN (856) |
| **Format** | XML |
| **Standard** | SPS Commerce RSX 7.7.4 (Retail Standard XML) |

SPS Commerce RSX (Retail Standard XML) 7.7.4 to standard tłumaczenia EDI na XML stosowany w łańcuchu dostaw handlu detalicznego. Zapewnia reprezentacje XML typowych transakcji EDI, w tym faktur (810), zamówień zakupu (850) i awizo dostawy (856, Advance Ship Notice). SPS Commerce jest wiodącym dostawcą EDI łączącym sieci handlowe z dostawcami.
