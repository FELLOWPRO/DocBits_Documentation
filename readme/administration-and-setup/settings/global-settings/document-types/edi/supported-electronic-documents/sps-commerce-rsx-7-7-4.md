# SPS COMMERCE RSX 7.7.4

{% hint style="info" %}

| Propiedad | Valor |
|----------|-------|
| **País / Región** | Internacional (principalmente Norteamérica) |
| **Tipos de documento** | Factura (810), Orden de compra (850), ASN (856) |
| **Formato** | XML |
| **Estándar** | SPS Commerce RSX 7.7.4 (Retail Standard XML) |

SPS Commerce RSX (Retail Standard XML) 7.7.4 es un estándar de traducción de EDI a XML utilizado en la cadena de suministro del comercio minorista. Proporciona representaciones XML de las transacciones EDI más habituales, como facturas (810), órdenes de compra (850) y avisos de envío anticipado (856). SPS Commerce es un proveedor líder de EDI que conecta a minoristas con proveedores.
