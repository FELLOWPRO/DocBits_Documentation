# SPS COMMERCE RSX 7.7.4

<!-- edocs-country-scope -->

{% hint style="info" %}
Consultate la guida del paese per i limiti delle versioni, la configurazione effettivamente utilizzata e il video esplicativo del paese. [Internazionale](countries/international.md). Le mappature per fatture, ordini, risposte e avvisi di spedizione sono distinte. L’elaborazione dei file non fornisce, di per sé, un punto di accesso Peppol o la connettività con i partner commerciali.
{% endhint %}

| Proprietà | Valore |
|----------|-------|
| **Paese / Regione** | Internazionale (principalmente Nord America) |
| **Tipi di documento** | Fattura (810), Ordine di acquisto (850), ASN (856) |
| **Formato** | XML |
| **Standard** | SPS Commerce RSX 7.7.4 (Retail Standard XML) |

SPS Commerce RSX (Retail Standard XML) 7.7.4 è uno standard di traduzione da EDI a XML utilizzato nella catena di fornitura del retail. Fornisce rappresentazioni XML delle più comuni transazioni EDI, tra cui fatture (810), ordini di acquisto (850) e avvisi di spedizione anticipati (856). SPS Commerce è un importante fornitore EDI che collega i rivenditori con i fornitori.
