# 🇸🇪 SVEFAKTURA 1.0

| Eigenschap | Waarde |
| ---------- | ------ |
| **Land / Regio** | Zweden |
| **Documenttypen** | Factuur |
| **Formaat** | UBL XML |
| **Standaard** | Svefaktura 1.0 |

Svefaktura 1.0 is het Zweedse e-factuurformaat op basis van UBL, beheerd door de Zweedse vereniging van lokale overheden en regio's (SFTI). Hoewel de Zweedse e-facturering inmiddels is overgestapt op Peppol BIS, blijft Svefaktura 1.0 in gebruik en wordt het ondersteund voor de verwerking van oudere documenten.
