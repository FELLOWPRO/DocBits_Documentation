# 🇸🇪 SVEFAKTURA 1.0

| 属性                 | 值             |
| -------------------- | -------------- |
| **国家 / 地区**      | 瑞典           |
| **文档类型**         | 发票           |
| **格式**             | UBL XML        |
| **标准**             | Svefaktura 1.0 |

Svefaktura 1.0 是基于 UBL 的瑞典电子发票格式，由瑞典地方政府与地区协会（SFTI）维护。虽然瑞典较新的电子发票已转向 Peppol BIS，但 Svefaktura 1.0 仍在使用中，DocBits 继续支持处理旧版文档。

## 支持状态

| 组件             | 状态          |
| ---------------- | ----------- |
| 预览             | ✅ 支持       |
| 字段提取         | ✅ 支持       |
| 转换             | ✅ 支持       |
