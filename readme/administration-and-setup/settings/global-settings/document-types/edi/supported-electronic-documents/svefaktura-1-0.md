# 🇸🇪 SVEFAKTURA 1.0

| Propriedade          | Valor          |
| -------------------- | -------------- |
| **País / Região**    | Suécia         |
| **Tipos de documento** | Fatura       |
| **Formato**          | UBL XML        |
| **Padrão**           | Svefaktura 1.0 |

O Svefaktura 1.0 é o formato sueco de faturamento eletrônico baseado em UBL, mantido pela Associação Sueca de Autoridades Locais e Regiões (SFTI). Embora o faturamento eletrônico sueco mais recente tenha migrado para o Peppol BIS, o Svefaktura 1.0 continua em uso e é suportado para o processamento de documentos legados.
