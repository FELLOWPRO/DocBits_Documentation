# 🇸🇪 SVEFAKTURA 1.0

<!-- edocs-country-scope -->

{% hint style="info" %}
Consultez le guide du pays pour connaître les limites de version, la configuration effectivement utilisée et la vidéo explicative du pays. [Suède](countries/sweden.md). Distinguez cette famille historique de Peppol BIS Billing 3.0. Vérifiez le profil attendu par le destinataire.
{% endhint %}

| Propriété            | Valeur         |
| -------------------- | -------------- |
| **Pays / Région**    | Suède          |
| **Types de documents** | Facture      |
| **Format**           | UBL XML        |
| **Norme**            | Svefaktura 1.0 |

Svefaktura 1.0 est le format suédois de facturation électronique basé sur UBL, géré par l'Association suédoise des autorités locales et des régions (SFTI). Bien que la facturation électronique suédoise plus récente se soit tournée vers Peppol BIS, Svefaktura 1.0 reste utilisé et pris en charge pour le traitement des documents historiques.
