# 🇸🇪 SVEFAKTURA 1.0

| Właściwość | Wartość |
| ---------- | ------- |
| **Kraj/Region** | Szwecja |
| **Typy dokumentów** | Faktura |
| **Format** | UBL XML |
| **Standard** | Svefaktura 1.0 |

Svefaktura 1.0 to szwedzki format e-fakturowania oparty na UBL, utrzymywany przez Szwedzkie Stowarzyszenie Władz Lokalnych i Regionów (SFTI). Chociaż nowsze szwedzkie e-fakturowanie przeszło na Peppol BIS, Svefaktura 1.0 nadal jest używana i obsługiwana przy przetwarzaniu starszych dokumentów.
