# 🇸🇪 SVEFAKTURA 1.0

<!-- edocs-country-scope -->

{% hint style="info" %}
Consultate la guida del paese per i limiti delle versioni, la configurazione effettivamente utilizzata e il video esplicativo del paese. [Svezia](countries/sweden.md). Distinguete questa famiglia precedente da Peppol BIS Billing 3.0. Verificate quale profilo si aspetta il destinatario.
{% endhint %}

| Proprietà             | Valore         |
| --------------------- | -------------- |
| **Paese / Regione**   | Svezia         |
| **Tipi di documento** | Fattura        |
| **Formato**           | UBL XML        |
| **Standard**          | Svefaktura 1.0 |

Svefaktura 1.0 è il formato svedese di fatturazione elettronica basato su UBL, gestito dall'Associazione svedese delle autorità locali e delle regioni (SFTI). Sebbene la più recente fatturazione elettronica svedese sia passata a Peppol BIS, Svefaktura 1.0 rimane in uso ed è supportato per l'elaborazione di documenti legacy.
