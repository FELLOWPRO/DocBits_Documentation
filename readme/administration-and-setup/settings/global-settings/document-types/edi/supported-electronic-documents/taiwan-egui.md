# 🇹🇼 TAIWAN EGUI

| Propiedad              | Valor                                        |
| ---------------------- | -------------------------------------------- |
| **País / Región**      | Taiwán                                       |
| **Tipos de documento** | Factura (Uniform Invoice), Nota de crédito   |
| **Formato**            | XML                                          |
| **Estándar**           | eGUI (Electronic Government Uniform Invoice) |

Taiwan eGUI es el sistema electrónico de factura uniforme gubernamental (Government Uniform Invoice) gestionado por el Ministerio de Finanzas. Es un estándar de facturación electrónica obligatorio para todas las transacciones comerciales en Taiwán, con facturas almacenadas en la plataforma gubernamental e identificadas mediante un formato único de número de factura.
