| -------------------- | -------------------------------------------- |
| **País / Região**    | Taiwan                                       |
| **Tipos de documento** | Fatura (Fatura uniforme), Nota de crédito  |
| **Formato**          | XML                                          |
| **Padrão**           | eGUI (Electronic Government Uniform Invoice) |

O Taiwan eGUI é o sistema eletrônico de Fatura Uniforme Governamental (Government Uniform Invoice) operado pelo Ministério das Finanças. É um padrão obrigatório de faturamento eletrônico para todas as transações comerciais em Taiwan, com as faturas armazenadas na plataforma do governo e identificadas por um formato de número de fatura exclusivo.
