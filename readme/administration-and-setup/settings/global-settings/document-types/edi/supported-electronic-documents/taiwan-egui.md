# 🇹🇼 TAIWAN EGUI

<!-- edocs-country-scope -->

{% hint style="info" %}

| Eigenschap | Waarde |
| ---------- | ------ |
| **Land / Regio** | Taiwan |
| **Documenttypen** | Factuur (Uniform Invoice), Creditnota |
| **Formaat** | XML |
| **Standaard** | eGUI (Electronic Government Uniform Invoice) |

Taiwan eGUI is het elektronische Government Uniform Invoice-systeem dat wordt beheerd door het ministerie van Financiën. Het is een verplichte e-factuurstandaard voor alle zakelijke transacties in Taiwan, waarbij facturen op het overheidsplatform worden opgeslagen en worden geïdentificeerd aan de hand van een uniek factuurnummerformaat.
