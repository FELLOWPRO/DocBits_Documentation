# 🇹🇼 TAIWAN EGUI

| Właściwość | Wartość |
| ---------- | ------- |
| **Kraj/Region** | Tajwan |
| **Typy dokumentów** | Faktura (Uniform Invoice), Nota kredytowa |
| **Format** | XML |
| **Standard** | eGUI (Electronic Government Uniform Invoice) |

Taiwan eGUI to elektroniczny system jednolitych faktur rządowych (Government Uniform Invoice) prowadzony przez Ministerstwo Finansów. Jest obowiązkowym standardem e-fakturowania dla wszystkich transakcji biznesowych na Tajwanie, a faktury są przechowywane na platformie rządowej i identyfikowane przez unikalny format numeru faktury.
