| Proprietà             | Valore                                       |
| --------------------- | -------------------------------------------- |
| **Paese / Regione**   | Taiwan                                       |
| **Tipi di documento** | Fattura (Uniform Invoice), Nota di credito   |
| **Formato**           | XML                                          |
| **Standard**          | eGUI (Electronic Government Uniform Invoice) |

Taiwan eGUI è il sistema elettronico della fattura uniforme governativa (Government Uniform Invoice) gestito dal Ministero delle Finanze. È uno standard di fatturazione elettronica obbligatorio per tutte le transazioni commerciali a Taiwan, con fatture archiviate sulla piattaforma governativa e identificate da un formato di numero fattura univoco.
