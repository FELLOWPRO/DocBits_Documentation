# 🇫🇮 TEAPPSXML

| Propriedade          | Valor                   |
| -------------------- | ----------------------- |
| **País / Região**    | Finlândia               |
| **Tipos de documento** | Fatura, Nota de crédito |
| **Formato**          | XML                     |
| **Padrão**           | TEAPPSXML 3.0           |

O TEAPPSXML é um formato finlandês de faturamento eletrônico usado pela Tieto (hoje TietoEVRY) para a troca de faturas. É comumente usado junto com o Finvoice no mercado finlandês, especialmente por organizações que utilizam sistemas ERP e financeiros baseados na Tieto.
