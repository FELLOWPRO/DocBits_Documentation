# 🇫🇮 TEAPPSXML

| Propriété              | Valeur                  |
| ---------------------- | ----------------------- |
| **Pays / Région**      | Finlande                |
| **Types de documents** | Facture, Note de crédit |
| **Format**             | XML                     |
| **Norme**              | TEAPPSXML 3.0           |

TEAPPSXML est un format finlandais de facturation électronique utilisé par Tieto (aujourd'hui TietoEVRY) pour l'échange de factures. Il est couramment employé aux côtés de Finvoice sur le marché finlandais, en particulier par les organisations qui utilisent des systèmes ERP et financiers basés sur Tieto.
