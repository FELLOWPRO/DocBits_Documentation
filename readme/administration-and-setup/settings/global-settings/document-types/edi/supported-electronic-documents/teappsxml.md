# 🇫🇮 TEAPPSXML

| Właściwość | Wartość |
| ---------- | ------- |
| **Kraj/Region** | Finlandia |
| **Typy dokumentów** | Faktura, Nota kredytowa |
| **Format** | XML |
| **Standard** | TEAPPSXML 3.0 |

TEAPPSXML to fiński format e-fakturowania używany przez firmę Tieto (obecnie TietoEVRY) do wymiany faktur. Na fińskim rynku jest powszechnie stosowany obok Finvoice, zwłaszcza przez organizacje korzystające z systemów ERP i finansowych opartych na rozwiązaniach Tieto.
