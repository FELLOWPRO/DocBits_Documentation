# 🇫🇮 TEAPPSXML

<!-- edocs-country-scope -->

{% hint style="info" %}
Die Länderanleitung enthält Versionsgrenzen, die tatsächlich verwendete Konfiguration und das Erklärvideo zum Land. [Finnland](countries/finland.md). Prüfen Sie die Version der Quelldatei, bevor Sie eine Zuordnung auswählen. Die Bezeichnung TEAPPSXML nennt keine Veröffentlichungsversion.
{% endhint %}

| Eigenschaft | Wert |
| ----------- | ---- |
| **Land / Region** | Finnland |
| **Dokumenttypen** | Rechnung, Gutschrift |
| **Format** | XML |
| **Standard** | TEAPPSXML 3.0 |

TEAPPSXML ist ein finnisches E-Rechnungsformat, das von Tieto (heute TietoEVRY) für den Rechnungsaustausch verwendet wird. Es kommt auf dem finnischen Markt häufig zusammen mit Finvoice zum Einsatz, insbesondere bei Organisationen, die ERP- und Finanzsysteme auf Tieto-Basis nutzen.
