# 🇫🇮 TEAPPSXML

| 属性                 | 值                   |
| -------------------- | -------------------- |
| **国家 / 地区**      | 芬兰                 |
| **文档类型**         | 发票、贷项通知单     |
| **格式**             | XML                  |
| **标准**             | TEAPPSXML 3.0        |

TEAPPSXML 是一种芬兰电子发票格式，由 Tieto（现为 TietoEVRY）用于发票交换。在芬兰市场中，它通常与 Finvoice 一起使用，尤其常见于采用基于 Tieto 的 ERP 和财务系统的组织。

## 支持状态

| 组件             | 状态        |
| ---------------- | ----------- |
| 预览             | ✅ 支持     |
| 字段提取         | ✅ 支持     |
| 转换             | ✅ 支持     |
