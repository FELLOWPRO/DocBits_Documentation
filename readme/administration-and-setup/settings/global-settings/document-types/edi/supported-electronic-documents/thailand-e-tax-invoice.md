# 🇹🇭 THAILAND E-TAX INVOICE

| Propriété              | Valeur                                         |
| ---------------------- | ---------------------------------------------- |
| **Pays / Région**      | Thaïlande                                      |
| **Types de documents** | Facture fiscale, Reçu                          |
| **Format**             | XML (intégré dans un PDF/A-3)                  |
| **Norme**              | e-Tax Invoice & e-Receipt (Revenue Department) |

Thailand e-Tax Invoice est la norme de facture fiscale et de reçu électroniques réglementée par le Revenue Department (administration fiscale thaïlandaise). Elle utilise un format hybride semblable à ZUGFeRD, qui intègre des données XML structurées dans un document PDF/A-3. Le système exige une signature numérique à l'aide d'un certificat délivré par une autorité de certification thaïlandaise.
