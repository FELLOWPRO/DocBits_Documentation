# 🇹🇭 THAILAND E-TAX INVOICE

| Proprietà             | Valore                                         |
| --------------------- | ---------------------------------------------- |
| **Paese / Regione**   | Thailandia                                     |
| **Tipi di documento** | Fattura fiscale, Ricevuta                      |
| **Formato**           | XML (incorporato in PDF/A-3)                   |
| **Standard**          | e-Tax Invoice & e-Receipt (Revenue Department) |

Thailand e-Tax Invoice è lo standard di fattura fiscale e ricevuta elettronica regolamentato dal Revenue Department. Utilizza un formato ibrido simile a ZUGFeRD, che incorpora dati XML strutturati in un documento PDF/A-3. Il sistema richiede la firma digitale con un certificato rilasciato da una CA thailandese.
