# 🇹🇷 土耳其 E-ARSIV

| 属性                 | 值                                            |
| -------------------- | --------------------------------------------- |
| **国家 / 地区**      | 土耳其                                        |
| **文档类型**         | 存档发票                                      |
| **格式**             | UBL-TR XML                                    |
| **标准**             | e-Arşiv Fatura（GİB - 税务管理局）             |

土耳其 e-Arşiv（电子存档）是用于向未在土耳其 e-Fatura 系统注册的接收方开具发票的电子发票格式。e-Arşiv 发票存储在 GİB（Gelir İdaresi Başkanlığı）平台上，并可通过 PDF 或纸质形式交付给接收方。DocBits 处理 UBL-TR XML 格式。
