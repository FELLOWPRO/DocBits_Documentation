| Propriedade          | Valor                                         |
| -------------------- | --------------------------------------------- |
| **País / Região**    | Turquia                                       |
| **Tipos de documento** | Fatura de arquivo                           |
| **Formato**          | UBL-TR XML                                    |
| **Padrão**           | e-Arşiv Fatura (GİB - Revenue Administration) |

O Turkey e-Arşiv (e-Archive) é o formato de fatura eletrônica usado para faturas emitidas a destinatários que não estão registrados no sistema turco e-Fatura. As faturas e-Arşiv são armazenadas na plataforma da GİB (Gelir İdaresi Başkanlığı) e podem ser entregues aos destinatários em PDF ou em papel. O DocBits processa o formato UBL-TR XML.
