# 🇹🇷 TURKEY E-ARSIV

| Właściwość | Wartość |
| ---------- | ------- |
| **Kraj/Region** | Turcja |
| **Typy dokumentów** | Faktura archiwalna |
| **Format** | UBL-TR XML |
| **Standard** | e-Arşiv Fatura (GİB - Revenue Administration) |

Turkey e-Arşiv (e-Archive) to format faktury elektronicznej używany dla faktur wystawianych odbiorcom niezarejestrowanym w tureckim systemie e-Fatura. Faktury e-Arşiv są przechowywane na platformie GİB (Gelir İdaresi Başkanlığı) i mogą być dostarczane odbiorcom w formie PDF lub papierowej. DocBits przetwarza format UBL-TR XML.
