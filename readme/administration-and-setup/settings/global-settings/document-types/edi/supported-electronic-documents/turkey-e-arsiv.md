# 🇹🇷 TURKEY E-ARSIV

| Eigenschap | Waarde |
| ---------- | ------ |
| **Land / Regio** | Turkije |
| **Documenttypen** | Archieffactuur |
| **Formaat** | UBL-TR XML |
| **Standaard** | e-Arşiv Fatura (GİB - Belastingdienst) |

Turkey e-Arşiv (e-Archive) is het elektronische factuurformaat voor facturen die worden uitgegeven aan ontvangers die niet zijn geregistreerd in het Turkse e-Fatura-systeem. e-Arşiv-facturen worden opgeslagen op het platform van de GİB (Gelir İdaresi Başkanlığı) en kunnen als PDF of op papier aan ontvangers worden geleverd. DocBits verwerkt het UBL-TR XML-formaat.
