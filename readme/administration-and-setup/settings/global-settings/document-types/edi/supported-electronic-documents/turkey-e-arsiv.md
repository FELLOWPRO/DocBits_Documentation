# 🇹🇷 TURKEY E-ARSIV

{% hint style="info" %}

| Eigenschaft | Wert |
| ----------- | ---- |
| **Land / Region** | Türkei |
| **Dokumenttypen** | Archivrechnung |
| **Format** | UBL-TR XML |
| **Standard** | e-Arşiv Fatura (GİB - Revenue Administration) |

Turkey e-Arşiv (e-Archive) ist das elektronische Rechnungsformat für Rechnungen an Empfänger, die nicht im türkischen e-Fatura-System registriert sind. e-Arşiv-Rechnungen werden auf der Plattform der GİB (Gelir İdaresi Başkanlığı) gespeichert und können den Empfängern als PDF oder in Papierform zugestellt werden. DocBits verarbeitet das UBL-TR-XML-Format.
