# 🇹🇷 TURKEY E-FATURA

| Propiedad            | Valor                                   |
| -------------------- | --------------------------------------- |
| **País / Región**    | Turquía                                 |
| **Tipos de documento** | Factura, Nota de crédito              |
| **Formato**          | XML UBL-TR 1.2                          |
| **Estándar**         | e-Fatura (GİB - Administración Tributaria) |

Turkey e-Fatura es el estándar principal de factura electrónica exigido por la GİB (Administración Tributaria) para las transacciones B2B entre contribuyentes registrados. Las facturas se intercambian a través de integradores registrados y de la plataforma de la GİB. El formato utiliza UBL-TR, la versión localizada de UBL para Turquía, con campos específicos turcos para la identificación fiscal TCKN/VKN.
