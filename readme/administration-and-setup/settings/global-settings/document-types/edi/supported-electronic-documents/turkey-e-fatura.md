# 🇹🇷 土耳其 E-FATURA

| 属性 | 值 |
| -------------------- | --------------------------------------- |
| **国家 / 地区** | 土耳其 |
| **文档类型** | 发票、贷项通知单 |
| **格式** | UBL-TR 1.2 XML |
| **标准** | e-Fatura（GİB - 税务管理局） |

土耳其 e-Fatura 是 GİB（税务管理局）针对已注册纳税人之间 B2B 交易规定的主要电子发票标准。发票通过注册的集成商和 GİB 平台交换。该格式采用 UBL-TR，这是土耳其本地化版本的 UBL，并包含用于 TCKN/VKN 纳税人识别的土耳其专用字段。
