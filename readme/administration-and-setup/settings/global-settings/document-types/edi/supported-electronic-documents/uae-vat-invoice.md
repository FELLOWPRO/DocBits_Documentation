# 🇦🇪 UAE VAT INVOICE

<!-- edocs-country-scope -->

{% hint style="info" %}
Consulte la guía del país para conocer los límites de versión, la configuración que se está utilizando y el vídeo explicativo del país. [Emiratos Árabes Unidos](countries/united-arab-emirates.md). Una asignación de facturas con IVA no demuestra la compatibilidad con todas las publicaciones Peppol o PINT de los EAU. Confirme el contrato del contenido y la integración de entrega necesaria.

| Propiedad            | Valor                                   |
| -------------------- | --------------------------------------- |
| **País / Región**    | Emiratos Árabes Unidos                  |
| **Tipos de documento** | Factura fiscal, Factura fiscal simplificada |
| **Formato**          | XML/JSON                                |
| **Estándar**         | FTA VAT Invoice (Autoridad Tributaria Federal) |

UAE VAT Invoice es el formato de factura electrónica alineado con los requisitos de la Autoridad Tributaria Federal (FTA). Aunque los Emiratos Árabes Unidos todavía no han impuesto un formato específico de facturación electrónica, DocBits admite el procesamiento de documentos estructurados de factura de IVA que cumplen la normativa de IVA de la FTA, incluida la identificación mediante TRN (Tax Registration Number, número de registro fiscal) y los cálculos de IVA al 5 %.
