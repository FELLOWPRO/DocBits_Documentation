# UBL 2.1

<!-- edocs-country-scope -->

{% hint style="info" %}
Die Länderanleitung enthält Versionsgrenzen, die tatsächlich verwendete Konfiguration und das Erklärvideo zum Land. [International](countries/international.md). Zuordnungen für Rechnungen, Bestellungen, Antworten und Versandanzeigen sind voneinander getrennt. Die Dateiverarbeitung selbst stellt weder einen Peppol-Zugangspunkt noch eine Verbindung zu Handelspartnern bereit.
{% endhint %}

| Eigenschaft | Wert |
| ----------- | ---- |
| **Land / Region** | International |
| **Dokumenttypen** | Rechnung, Gutschrift, Bestellung, Lieferavis |
| **Format** | UBL 2.1 XML |
| **Standard** | OASIS UBL 2.1 (Universal Business Language) |

UBL 2.1 (Universal Business Language) ist der offene OASIS-Standard für Geschäftsdokumente. Er bildet die Grundlage vieler nationaler E-Rechnungsstandards, darunter Peppol BIS, XRechnung (UBL-Variante), OIOUBL und SI-UBL. DocBits verarbeitet generische UBL-2.1-Rechnungen, die keinem länderspezifischen Standard entsprechen.
