# UBL 2.1

| Eigenschap | Waarde |
| ---------- | ------ |
| **Land / Regio** | Internationaal |
| **Documenttypen** | Factuur, Creditnota, Order, Verzendbericht |
| **Formaat** | UBL 2.1 XML |
| **Standaard** | OASIS UBL 2.1 (Universal Business Language) |

UBL 2.1 (Universal Business Language) is de open OASIS-standaard voor zakelijke documenten. Het vormt de basis voor veel nationale e-factuurstandaarden, waaronder Peppol BIS, XRechnung (UBL-variant), OIOUBL en SI-UBL. DocBits verwerkt generieke UBL 2.1-facturen die niet overeenkomen met een landspecifieke standaard.
