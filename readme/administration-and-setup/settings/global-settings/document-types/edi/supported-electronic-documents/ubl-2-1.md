# UBL 2.1

<!-- edocs-country-scope -->

{% hint style="info" %}
Consulte la guía del país para conocer los límites de versión, la configuración que se está utilizando y el vídeo explicativo del país. [Internacional](countries/international.md). Las asignaciones de facturas, pedidos, respuestas y avisos de expedición son diferentes. El procesamiento de archivos no proporciona por sí mismo un punto de acceso Peppol ni conectividad con socios comerciales.
{% endhint %}

| Propiedad            | Valor                                        |
| -------------------- | -------------------------------------------- |
| **País / Región**    | Internacional                                |
| **Tipos de documento** | Factura, Nota de crédito, Pedido, Aviso de expedición |
| **Formato**          | XML UBL 2.1                                  |
| **Estándar**         | OASIS UBL 2.1 (Universal Business Language)  |

UBL 2.1 (Universal Business Language) es el estándar abierto de OASIS para documentos comerciales. Sirve de base para muchos estándares nacionales de facturación electrónica, entre ellos Peppol BIS, XRechnung (variante UBL), OIOUBL y SI-UBL. DocBits procesa facturas UBL 2.1 genéricas que no coinciden con ningún estándar específico de un país.
