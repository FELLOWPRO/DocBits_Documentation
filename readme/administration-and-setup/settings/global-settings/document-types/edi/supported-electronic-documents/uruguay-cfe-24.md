# 🇺🇾 URUGUAY CFE 24

<!-- edocs-country-scope -->

{% hint style="info" %}
Consultate la guida del paese per i limiti delle versioni, la configurazione effettivamente utilizzata e il video esplicativo del paese. [Uruguay](countries/uruguay.md). Le voci per le note di credito non hanno insiemi di componenti di estrazione dedicati nello stato esaminato. Confermate la versione CFE e la mappatura effettivamente utilizzata per fatture o note di credito.
{% endhint %}

| Proprietà             | Valore                            |
| --------------------- | --------------------------------- |
| **Paese / Regione**   | Uruguay                           |
| **Tipi di documento** | e-Fattura, Nota di credito        |
| **Formato**           | XML                               |
| **Standard**          | CFE Schema Version 24             |

Uruguay CFE 24 si riferisce alla versione 24 dello schema del sistema CFE uruguaiano. Questa versione è utilizzata da molti documenti elettronici esistenti e include tutti i campi richiesti per la conformità alla DGI, incluso il CAE (Código de Autorización Electrónico).
