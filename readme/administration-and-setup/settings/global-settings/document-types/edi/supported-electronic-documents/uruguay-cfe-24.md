# 🇺🇾 URUGUAY CFE 24

<!-- edocs-country-scope -->

{% hint style="info" %}
Consultez le guide du pays pour connaître les limites de version, la configuration effectivement utilisée et la vidéo explicative du pays. [Uruguay](countries/uruguay.md). Les entrées d’avoir n’ont pas d’ensembles d’extraction dédiés dans l’état examiné. Confirmez la version CFE et la correspondance de facture ou d’avoir effectivement utilisée.
{% endhint %}

| Propriété              | Valeur                      |
| ---------------------- | --------------------------- |
| **Pays / Région**      | Uruguay                     |
| **Types de documents** | e-Facture, Note de crédit   |
| **Format**             | XML                         |
| **Norme**              | CFE Schema Version 24       |

Uruguay CFE 24 désigne la version 24 du schéma du système uruguayen CFE. Cette version est utilisée par de nombreux documents électroniques existants et comprend tous les champs requis pour la conformité à la DGI, y compris le CAE (Código de Autorización Electrónico).
