# 🇺🇾 乌拉圭 CFE 24

| 属性                 | 值                     |
| -------------------- | ---------------------- |
| **国家 / 地区**      | 乌拉圭                 |
| **文档类型**         | 电子发票、贷项通知单   |
| **格式**             | XML                    |
| **标准**             | CFE 架构版本 24        |

乌拉圭 CFE 24 指乌拉圭 CFE 系统的第 24 版架构。许多现有电子文档都使用此版本，其中包含符合 DGI 要求的所有必需字段，包括 CAE（电子授权代码）。
