# 🇺🇾 URUGUAY CFE 24

| Eigenschaft | Wert |
| ----------- | ---- |
| **Land / Region** | Uruguay |
| **Dokumenttypen** | e-Rechnung, Gutschrift |
| **Format** | XML |
| **Standard** | CFE-Schema Version 24 |

Uruguay CFE 24 bezeichnet die Schema-Version 24 des uruguayischen CFE-Systems. Diese Version wird von vielen bestehenden elektronischen Dokumenten verwendet und enthält alle für die DGI-Konformität erforderlichen Felder, einschließlich des CAE (Código de Autorización Electrónico).
