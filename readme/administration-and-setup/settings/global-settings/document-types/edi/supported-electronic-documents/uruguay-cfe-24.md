# 🇺🇾 URUGUAY CFE 24

| Propriété              | Valeur                      |
| ---------------------- | --------------------------- |
| **Pays / Région**      | Uruguay                     |
| **Types de documents** | e-Facture, Note de crédit   |
| **Format**             | XML                         |
| **Norme**              | CFE Schema Version 24       |

Uruguay CFE 24 désigne la version 24 du schéma du système uruguayen CFE. Cette version est utilisée par de nombreux documents électroniques existants et comprend tous les champs requis pour la conformité à la DGI, y compris le CAE (Código de Autorización Electrónico).
