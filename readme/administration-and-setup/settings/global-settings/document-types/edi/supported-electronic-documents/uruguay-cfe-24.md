# 🇺🇾 URUGUAY CFE 24

| Eigenschap | Waarde |
| ---------- | ------ |
| **Land / Regio** | Uruguay |
| **Documenttypen** | e-Factuur, Creditnota |
| **Formaat** | XML |
| **Standaard** | CFE-schemaversie 24 |

Uruguay CFE 24 verwijst naar schemaversie 24 van het Uruguayaanse CFE-systeem. Deze versie wordt gebruikt door veel bestaande elektronische documenten en bevat alle vereiste velden voor naleving van de DGI-regels, waaronder het CAE (Código de Autorización Electrónico).
