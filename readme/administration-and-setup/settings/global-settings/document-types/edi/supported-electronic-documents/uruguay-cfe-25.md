# 🇺🇾 URUGUAY CFE 25

<!-- edocs-country-scope -->

{% hint style="info" %}
Die Länderanleitung enthält Versionsgrenzen, die tatsächlich verwendete Konfiguration und das Erklärvideo zum Land. [Uruguay](countries/uruguay.md). Für Gutschrifteinträge sind im geprüften Status keine eigenen Extraktionspakete ausgewiesen. Bestätigen Sie die CFE-Version und die tatsächlich verwendete Rechnungs- oder Gutschriftzuordnung.
{% endhint %}

| Eigenschaft | Wert |
| ----------- | ---- |
| **Land / Region** | Uruguay |
| **Dokumenttypen** | e-Rechnung, Gutschrift |
| **Format** | XML |
| **Standard** | CFE-Schema Version 25 |

Uruguay CFE 25 ist die neueste Schema-Version des uruguayischen CFE-Systems. Sie enthält aktualisierte Validierungsregeln und Feldanforderungen für elektronische Dokumente, die bei der DGI eingereicht werden.
