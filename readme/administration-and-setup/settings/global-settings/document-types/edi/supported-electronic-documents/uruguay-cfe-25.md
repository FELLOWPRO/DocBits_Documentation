# 🇺🇾 URUGUAY CFE 25

| Proprietà             | Valore                            |
| --------------------- | --------------------------------- |
| **Paese / Regione**   | Uruguay                           |
| **Tipi di documento** | e-Fattura, Nota di credito        |
| **Formato**           | XML                               |
| **Standard**          | CFE Schema Version 25             |

Uruguay CFE 25 è l'ultima versione dello schema del sistema CFE uruguaiano. Include regole di convalida e requisiti sui campi aggiornati per i documenti elettronici inviati alla DGI.

## Stato del supporto

| Componente       | Stato        |
| ---------------- | ------------ |
| Anteprima        | ✅ Supportato |
| Estrazione campi | ✅ Supportato |
| Trasformazione   | ✅ Supportato |
