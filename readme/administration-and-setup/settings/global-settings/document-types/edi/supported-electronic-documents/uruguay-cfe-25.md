# 🇺🇾 URUGUAY CFE 25

<!-- edocs-country-scope -->

{% hint style="info" %}
Consultez le guide du pays pour connaître les limites de version, la configuration effectivement utilisée et la vidéo explicative du pays. [Uruguay](countries/uruguay.md). Les entrées d’avoir n’ont pas d’ensembles d’extraction dédiés dans l’état examiné. Confirmez la version CFE et la correspondance de facture ou d’avoir effectivement utilisée.
{% endhint %}

| Propriété              | Valeur                      |
| ---------------------- | --------------------------- |
| **Pays / Région**      | Uruguay                     |
| **Types de documents** | e-Facture, Note de crédit   |
| **Format**             | XML                         |
| **Norme**              | CFE Schema Version 25       |

Uruguay CFE 25 est la dernière version du schéma du système uruguayen CFE. Elle comprend des règles de validation et des exigences de champs mises à jour pour les documents électroniques soumis à la DGI.
