# 🇺🇾 URUGUAY CFE 25

<!-- edocs-country-scope -->

{% hint style="info" %}
Raadpleeg de landengids voor versiebeperkingen, de daadwerkelijk gebruikte configuratie en de uitlegvideo voor het land. [Uruguay](countries/uruguay.md). Creditnotavermeldingen hebben in de onderzochte status geen eigen extractiebundels. Bevestig de CFE-versie en de daadwerkelijk gebruikte toewijzing voor facturen of creditnota’s.
{% endhint %}

| Eigenschap | Waarde |
| ---------- | ------ |
| **Land / Regio** | Uruguay |
| **Documenttypen** | e-Factuur, Creditnota |
| **Formaat** | XML |
| **Standaard** | CFE-schemaversie 25 |

Uruguay CFE 25 is de nieuwste schemaversie van het Uruguayaanse CFE-systeem. Deze bevat bijgewerkte validatieregels en veldvereisten voor elektronische documenten die bij de DGI worden ingediend.
