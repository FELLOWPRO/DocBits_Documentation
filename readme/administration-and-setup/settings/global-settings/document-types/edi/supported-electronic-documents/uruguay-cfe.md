# 🇺🇾 URUGUAY CFE

| Właściwość | Wartość |
| ---------- | ------- |
| **Kraj/Region** | Urugwaj |
| **Typy dokumentów** | e-Faktura, e-Paragon (e-Ticket), Nota kredytowa, Nota debetowa |
| **Format** | XML |
| **Standard** | CFE (Comprobante Fiscal Electrónico) |

CFE (Comprobante Fiscal Electrónico) to urugwajski standard elektronicznego dokumentu podatkowego regulowany przez DGI (Dirección General Impositiva). Obejmuje wiele typów dokumentów, w tym e-Factura (111), e-Ticket (101) oraz ich warianty not kredytowych i debetowych.
