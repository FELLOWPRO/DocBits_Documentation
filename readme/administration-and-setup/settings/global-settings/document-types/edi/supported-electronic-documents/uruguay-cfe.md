# 🇺🇾 URUGUAY CFE

<!-- edocs-country-scope -->

{% hint style="info" %}
Raadpleeg de landengids voor versiebeperkingen, de daadwerkelijk gebruikte configuratie en de uitlegvideo voor het land. [Uruguay](countries/uruguay.md). Creditnotavermeldingen hebben in de onderzochte status geen eigen extractiebundels. Bevestig de CFE-versie en de daadwerkelijk gebruikte toewijzing voor facturen of creditnota’s.
{% endhint %}

| Eigenschap | Waarde |
| ---------- | ------ |
| **Land / Regio** | Uruguay |
| **Documenttypen** | e-Factuur, e-Ticket, Creditnota, Debetnota |
| **Formaat** | XML |
| **Standaard** | CFE (Comprobante Fiscal Electrónico) |

CFE (Comprobante Fiscal Electrónico) is de Uruguayaanse standaard voor elektronische belastingdocumenten, gereguleerd door de DGI (Dirección General Impositiva). De standaard omvat meerdere documenttypen, waaronder e-Factura (111), e-Ticket (101) en de bijbehorende credit- en debetnotavarianten.
