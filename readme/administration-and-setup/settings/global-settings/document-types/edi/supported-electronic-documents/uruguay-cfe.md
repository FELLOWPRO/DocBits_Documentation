# 🇺🇾 URUGUAY CFE

<!-- edocs-country-scope -->

{% hint style="info" %}
Sprawdź w przewodniku krajowym ograniczenia wersji, faktycznie używaną konfigurację i film objaśniający dla kraju. [Urugwaj](countries/uruguay.md). Wpisy not kredytowych nie mają dedykowanych pakietów ekstrakcji w sprawdzonym stanie. Potwierdź wersję CFE i faktycznie używane mapowanie faktur lub not kredytowych.

| Właściwość | Wartość |
| ---------- | ------- |
| **Kraj/Region** | Urugwaj |
| **Typy dokumentów** | e-Faktura, e-Paragon (e-Ticket), Nota kredytowa, Nota debetowa |
| **Format** | XML |
| **Standard** | CFE (Comprobante Fiscal Electrónico) |

CFE (Comprobante Fiscal Electrónico) to urugwajski standard elektronicznego dokumentu podatkowego regulowany przez DGI (Dirección General Impositiva). Obejmuje wiele typów dokumentów, w tym e-Factura (111), e-Ticket (101) oraz ich warianty not kredytowych i debetowych.
