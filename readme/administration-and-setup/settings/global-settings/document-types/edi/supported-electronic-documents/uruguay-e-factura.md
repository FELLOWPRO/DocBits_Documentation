# 🇺🇾 URUGUAY E-FACTURA

| Propriedade          | Valor                      |
| -------------------- | -------------------------- |
| **País / Região**    | Uruguai                    |
| **Tipos de documento** | e-Fatura (e-Factura)     |
| **Formato**          | XML                        |
| **Padrão**           | e-Factura (CFE tipo 111)   |

A Uruguay e-Factura é o tipo de documento de fatura eletrônica dentro do sistema CFE, identificado pelo código de tipo 111. É usada em transações B2B formais entre entidades registradas no RUT e inclui todos os campos de identificação fiscal e de cálculo exigidos pela DGI.
