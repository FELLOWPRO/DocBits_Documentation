# 🇺🇾 URUGUAY E-FACTURA

| Propriété              | Valeur                    |
| ---------------------- | ------------------------- |
| **Pays / Région**      | Uruguay                   |
| **Types de documents** | e-Facture (e-Factura)     |
| **Format**             | XML                       |
| **Norme**              | e-Factura (CFE Type 111)  |

Uruguay e-Factura est le type de document de facture électronique du système CFE, identifié par le code de type 111. Il est utilisé pour les transactions B2B formelles entre entités enregistrées au RUT et comprend tous les champs d'identification fiscale et de calcul requis par la DGI.
