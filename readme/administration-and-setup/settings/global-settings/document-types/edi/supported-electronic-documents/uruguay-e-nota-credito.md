# 🇺🇾 URUGUAY E-NOTA CREDITO

| Właściwość | Wartość |
| ---------- | ------- |
| **Kraj/Region** | Urugwaj |
| **Typy dokumentów** | Nota kredytowa (e-Nota de Crédito) |
| **Format** | XML |
| **Standard** | e-Nota de Crédito (CFE Type 112) |

Uruguay e-Nota de Crédito to typ elektronicznej noty kredytowej w systemie CFE, identyfikowany kodem typu 112. Służy do korygowania lub anulowania wcześniej wystawionych e-Factur i musi odwoływać się do dokumentu pierwotnego.
