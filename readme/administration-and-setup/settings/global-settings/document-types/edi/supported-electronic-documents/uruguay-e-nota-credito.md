# 🇺🇾 URUGUAY E-NOTA CREDITO

<!-- edocs-country-scope -->

{% hint style="info" %}
Die Länderanleitung enthält Versionsgrenzen, die tatsächlich verwendete Konfiguration und das Erklärvideo zum Land. [Uruguay](countries/uruguay.md). Für Gutschrifteinträge sind im geprüften Status keine eigenen Extraktionspakete ausgewiesen. Bestätigen Sie die CFE-Version und die tatsächlich verwendete Rechnungs- oder Gutschriftzuordnung.
{% endhint %}

| Eigenschaft | Wert |
| ----------- | ---- |
| **Land / Region** | Uruguay |
| **Dokumenttypen** | Gutschrift (e-Nota de Crédito) |
| **Format** | XML |
| **Standard** | e-Nota de Crédito (CFE-Typ 112) |

Uruguay e-Nota de Crédito ist der Dokumenttyp für elektronische Gutschriften innerhalb des CFE-Systems und wird über den Typcode 112 identifiziert. Er dient dazu, zuvor ausgestellte e-Facturas zu korrigieren oder zu stornieren, und muss auf das ursprüngliche Dokument verweisen.
