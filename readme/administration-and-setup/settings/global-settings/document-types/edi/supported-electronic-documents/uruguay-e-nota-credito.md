# 🇺🇾 URUGUAY E-NOTA CREDITO

<!-- edocs-country-scope -->

{% hint style="info" %}
Consultez le guide du pays pour connaître les limites de version, la configuration effectivement utilisée et la vidéo explicative du pays. [Uruguay](countries/uruguay.md). Les entrées d’avoir n’ont pas d’ensembles d’extraction dédiés dans l’état examiné. Confirmez la version CFE et la correspondance de facture ou d’avoir effectivement utilisée.
{% endhint %}

| Propriété              | Valeur                              |
| ---------------------- | ----------------------------------- |
| **Pays / Région**      | Uruguay                             |
| **Types de documents** | Note de crédit (e-Nota de Crédito)  |
| **Format**             | XML                                 |
| **Norme**              | e-Nota de Crédito (CFE Type 112)    |

Uruguay e-Nota de Crédito est le type de document de note de crédit électronique du système CFE, identifié par le code de type 112. Il sert à corriger ou à annuler des e-Facturas émises précédemment et doit faire référence au document d'origine.
