# 🇺🇾 URUGUAY E-NOTA CREDITO

| Propiedad            | Valor                            |
| -------------------- | -------------------------------- |
| **País / Región**    | Uruguay                          |
| **Tipos de documento** | Nota de crédito (e-Nota de Crédito) |
| **Formato**          | XML                              |
| **Estándar**         | e-Nota de Crédito (CFE tipo 112) |

Uruguay e-Nota de Crédito es el tipo de documento de nota de crédito electrónica dentro del sistema CFE, identificado con el código de tipo 112. Se utiliza para ajustar o anular e-Facturas emitidas previamente y debe hacer referencia al documento original.

## Estado de soporte

| Componente           | Estado        |
| -------------------- | ------------- |
| Vista previa         | ✅ Compatible |
| Extracción de campos | ✅ Compatible |
| Transformación       | ✅ Compatible |
