| -------------------- | ----------------------------------------------------- |
| **Paese / Regione**  | Vietnam                                               |
| **Tipi di documento** | Fattura                                              |
| **Formato**          | XML                                                   |
| **Standard**         | Vietnamese E-Invoice (General Department of Taxation) |

Vietnam E-Invoice è lo standard di fatturazione elettronica prescritto dal General Department of Taxation ai sensi del Decreto 123/2020 e della Circolare 78/2021. Tutte le aziende in Vietnam devono utilizzare le fatture elettroniche, che vengono trasmesse al sistema dell'autorità fiscale e da questo validate. Ogni fattura include un codice di verifica univoco.
