# 🇩🇪 XRECHNUNG 1.1 CII

| Propiedad            | Valor                                       |
| -------------------- | ------------------------------------------- |
| **País / Región**    | Alemania                                    |
| **Tipos de documento** | Factura, Nota de crédito                  |
| **Formato**          | CII                                         |
| **Estándar**         | XRechnung 1.1                               |
| **Basado en**        | EN 16931 (UN/CEFACT Cross Industry Invoice) |

Versión temprana del estándar XRechnung. Ha sido sustituida por versiones más recientes, pero sigue siendo compatible para el procesamiento de documentos heredados.
