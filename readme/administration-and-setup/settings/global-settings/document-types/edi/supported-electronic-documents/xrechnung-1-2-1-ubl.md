# 🇩🇪 XRECHNUNG 1.2.1 UBL

| Property             | Value                    |
| -------------------- | ------------------------ |
| **Country / Region** | Germany                  |
| **Document Types**   | Invoice, Credit Note     |
| **Format**           | UBL                      |
| **Standard**         | XRechnung 1.2.1          |
| **Based On**         | EN 16931 (OASIS UBL 2.1) |
