# 🇩🇪 XRECHNUNG 1.2.2 CII

| Eigenschaft       | Wert                                        |
| ----------------- | ------------------------------------------- |
| **Land / Region** | Deutschland                                 |
| **Dokumenttypen** | Rechnung, Gutschrift                        |
| **Format**        | CII                                         |
| **Standard**      | XRechnung 1.2.2                             |
| **Basiert auf**   | EN 16931 (UN/CEFACT Cross Industry Invoice) |
