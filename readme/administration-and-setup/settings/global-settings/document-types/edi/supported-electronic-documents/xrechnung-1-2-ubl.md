# 🇩🇪 XRECHNUNG 1.2 UBL

| Propriété            | Valeur                   |
| -------------------- | ------------------------ |
| **Pays / Région**    | Germany                  |
| **Types de documents** | Invoice, Credit Note   |
| **Format**           | UBL                      |
| **Norme**            | XRechnung 1.2            |
| **Basé sur**         | EN 16931 (OASIS UBL 2.1) |

Première version de la norme XRechnung. Remplacée par des versions plus récentes, mais toujours prise en charge pour le traitement des documents hérités.
