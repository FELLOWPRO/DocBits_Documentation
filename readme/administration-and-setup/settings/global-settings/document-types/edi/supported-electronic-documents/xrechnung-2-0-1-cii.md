# 🇩🇪 XRECHNUNG 2.0.1 CII

| Właściwość           | Wartość                                     |
| -------------------- | ------------------------------------------- |
| **Kraj/Region**      | Niemcy                                      |
| **Typy dokumentów**  | Faktura, Nota kredytowa                     |
| **Format**           | CII                                         |
| **Standard**         | XRechnung 2.0.1                             |
| **Oparty na**        | EN 16931 (UN/CEFACT Cross Industry Invoice) |

XRechnung 2.0.1 implementuje standard EN 16931 Core Invoice wraz z niemieckimi rozszerzeniami CIUS (Core Invoice Usage Specification). Ta wersja wprowadziła poprawki błędów i korekty do wydania 2.0, zwiększając stabilność i interoperacyjność.
