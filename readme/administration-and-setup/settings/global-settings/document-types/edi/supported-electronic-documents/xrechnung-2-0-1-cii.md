# 🇩🇪 XRECHNUNG 2.0.1 CII

<!-- edocs-country-scope -->

{% hint style="info" %}
请参阅国家指南，了解版本限制、实际生效的配置和国家说明视频。 [德国](countries/germany.md). 语法、发布版本和业务规范是不同的选择。不要根据共用的 1p0 标记推断 Factur-X 发布版本。
{% endhint %}

| 属性 | 值 |
| -------------------- | ------------------------------------------- |
| **国家/地区** | 德国 |
| **文档类型** | 发票、贷项通知单 |
| **格式** | CII |
| **标准** | XRechnung 2.0.1 |
| **基于** | EN 16931（UN/CEFACT 跨行业发票） |

XRechnung 2.0.1 实现了 EN 16931 核心发票标准，并包含德国 CIUS（核心发票使用规范）扩展。此版本修复并更正了 2.0 版本中的问题，提升了稳定性和互操作性。
