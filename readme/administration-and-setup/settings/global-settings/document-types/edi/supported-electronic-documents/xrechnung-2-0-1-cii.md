# 🇩🇪 XRECHNUNG 2.0.1 CII

| Propriété              | Valeur                                      |
| ---------------------- | ------------------------------------------- |
| **Pays / Région**      | Germany                                     |
| **Types de documents** | Invoice, Credit Note                        |
| **Format**             | CII                                         |
| **Norme**              | XRechnung 2.0.1                             |
| **Basé sur**           | EN 16931 (UN/CEFACT Cross Industry Invoice) |

XRechnung 2.0.1 met en œuvre la norme EN 16931 Core Invoice avec les extensions du CIUS (Core Invoice Usage Specification) allemand. Cette version a apporté des correctifs et des corrections à la version 2.0, améliorant la stabilité et l'interopérabilité.
