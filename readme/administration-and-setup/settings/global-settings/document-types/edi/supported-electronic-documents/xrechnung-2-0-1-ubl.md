# 🇩🇪 XRECHNUNG 2.0.1 UBL

| Propiedad            | Valor                    |
| -------------------- | ------------------------ |
| **País / Región**    | Alemania                 |
| **Tipos de documento** | Factura, Nota de crédito |
| **Formato**          | UBL                      |
| **Estándar**         | XRechnung 2.0.1          |
| **Basado en**        | EN 16931 (OASIS UBL 2.1) |

XRechnung 2.0.1 implementa el estándar de factura básica EN 16931 con las extensiones alemanas CIUS (Core Invoice Usage Specification). Esta versión introdujo correcciones de errores y ajustes respecto a la versión 2.0, lo que mejora la estabilidad y la interoperabilidad.

## Estado de soporte

| -------------------- | ------------- |

| Extracción de campos | ✅ Compatible |
