# 🇩🇪 XRECHNUNG 2.0.1 UBL

| Eigenschap           | Waarde                   |
| -------------------- | ------------------------ |
| **Land / Regio**     | Duitsland                |
| **Documenttypen**    | Factuur, Creditnota      |
| **Formaat**          | UBL                      |
| **Standaard**        | XRechnung 2.0.1          |
| **Gebaseerd op**     | EN 16931 (OASIS UBL 2.1) |

XRechnung 2.0.1 implementeert de EN 16931 Core Invoice-standaard met Duitse CIUS-extensies (Core Invoice Usage Specification). Deze versie bracht bugfixes en correcties ten opzichte van release 2.0, wat de stabiliteit en interoperabiliteit verbetert.
