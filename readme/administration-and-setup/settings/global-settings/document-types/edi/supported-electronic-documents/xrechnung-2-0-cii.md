# 🇩🇪 XRECHNUNG 2.0 CII

| Proprietà             | Valore                                      |
| --------------------- | ------------------------------------------- |
| **Paese / Regione**   | Germania                                    |
| **Tipi di documento** | Fattura, Nota di credito                    |
| **Formato**           | CII                                         |
| **Standard**          | XRechnung 2.0                               |
| **Basato su**         | EN 16931 (UN/CEFACT Cross Industry Invoice) |

XRechnung 2.0 implementa lo standard EN 16931 Core Invoice con le estensioni tedesche CIUS (Core Invoice Usage Specification). Questa versione ha introdotto una profonda ristrutturazione dello standard, con regole di validazione aggiornate e una migliore conformità alla norma europea.
