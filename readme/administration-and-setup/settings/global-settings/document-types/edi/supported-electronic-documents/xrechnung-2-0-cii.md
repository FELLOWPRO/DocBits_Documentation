# 🇩🇪 XRECHNUNG 2.0 CII

| Właściwość           | Wartość                                     |
| -------------------- | ------------------------------------------- |
| **Kraj/Region**      | Niemcy                                      |
| **Typy dokumentów**  | Faktura, Nota kredytowa                     |
| **Format**           | CII                                         |
| **Standard**         | XRechnung 2.0                               |
| **Oparty na**        | EN 16931 (UN/CEFACT Cross Industry Invoice) |

XRechnung 2.0 implementuje standard EN 16931 Core Invoice wraz z niemieckimi rozszerzeniami CIUS (Core Invoice Usage Specification). Ta wersja wprowadziła gruntowną restrukturyzację standardu ze zaktualizowanymi regułami walidacji i lepszą zgodnością z normą europejską.
