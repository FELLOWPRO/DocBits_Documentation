# 🇩🇪 XRECHNUNG 2.0 CII

| 属性                 | 值                                       |
| -------------------- | ------------------------------------------- |
| **国家 / 地区**       | 德国                                     |
| **文档类型**         | 发票、贷项通知单                        |
| **格式**             | CII                                         |
| **标准**             | XRechnung 2.0                               |
| **基于**             | EN 16931（UN/CEFACT 跨行业发票） |

XRechnung 2.0 实现了 EN 16931 核心发票标准，并扩展了德国 CIUS（核心发票使用规范）。此版本对标准进行了重大重构，更新了验证规则，并提升了对欧洲标准的符合性。
