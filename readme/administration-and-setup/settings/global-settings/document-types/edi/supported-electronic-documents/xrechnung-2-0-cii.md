# 🇩🇪 XRECHNUNG 2.0 CII

| Propiedad            | Valor                                       |
| -------------------- | ------------------------------------------- |
| **País / Región**    | Alemania                                    |
| **Tipos de documento** | Factura, Nota de crédito                  |
| **Formato**          | CII                                         |
| **Estándar**         | XRechnung 2.0                               |
| **Basado en**        | EN 16931 (UN/CEFACT Cross Industry Invoice) |

XRechnung 2.0 implementa el estándar de factura básica EN 16931 con las extensiones alemanas CIUS (Core Invoice Usage Specification). Esta versión introdujo una reestructuración importante del estándar, con reglas de validación actualizadas y un mejor cumplimiento de la norma europea.
