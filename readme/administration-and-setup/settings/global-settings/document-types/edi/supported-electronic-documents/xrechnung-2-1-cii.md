# 🇩🇪 XRECHNUNG 2.1 CII

| 属性                 | 值                                         |
| -------------------- | ------------------------------------------- |
| **国家 / 地区**      | 德国                                       |
| **文档类型**         | 发票、贷项通知单                           |
| **格式**             | CII                                        |
| **标准**             | XRechnung 2.1                              |
| **基于**             | EN 16931（UN/CEFACT 跨行业发票）            |

XRechnung 2.1 实施了 EN 16931 核心发票标准，并包含德国 CIUS（核心发票使用规范）扩展。此版本通过增强 Schematron 规则和更严格的符合性检查改进了验证。
