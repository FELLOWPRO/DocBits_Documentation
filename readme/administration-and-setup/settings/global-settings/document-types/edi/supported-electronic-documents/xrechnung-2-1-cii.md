# 🇩🇪 XRECHNUNG 2.1 CII

| Eigenschap           | Waarde                                      |
| -------------------- | ------------------------------------------- |
| **Land / Regio**     | Duitsland                                   |
| **Documenttypen**    | Factuur, Creditnota                         |
| **Formaat**          | CII                                         |
| **Standaard**        | XRechnung 2.1                               |
| **Gebaseerd op**     | EN 16931 (UN/CEFACT Cross Industry Invoice) |

XRechnung 2.1 implementeert de EN 16931 Core Invoice-standaard met Duitse CIUS-extensies (Core Invoice Usage Specification). Deze versie bracht verbeterde validatie met uitgebreidere Schematron-regels en strengere conformiteitscontroles.
