# 🇩🇪 XRECHNUNG 2.2 UBL

| Property             | Value                    |
| -------------------- | ------------------------ |
| **Country / Region** | Germany                  |
| **Document Types**   | Invoice, Credit Note     |
| **Format**           | UBL                      |
| **Standard**         | XRechnung 2.2            |
| **Based On**         | EN 16931 (OASIS UBL 2.1) |

XRechnung 2.2 implements the EN 16931 Core Invoice standard with German CIUS (Core Invoice Usage Specification) extensions. This version introduced additional business rules and extended support for complex invoicing scenarios.
