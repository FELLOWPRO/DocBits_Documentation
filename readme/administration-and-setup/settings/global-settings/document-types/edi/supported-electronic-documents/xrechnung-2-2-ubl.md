# 🇩🇪 XRECHNUNG 2.2 UBL

<!-- edocs-country-scope -->

{% hint style="info" %}
Raadpleeg de landengids voor versiebeperkingen, de daadwerkelijk gebruikte configuratie en de uitlegvideo voor het land. [Duitsland](countries/germany.md). Syntaxis, publicatieversie en profiel zijn verschillende keuzes. Leid geen Factur-X-publicatie af uit de gedeelde 1p0-markering.
{% endhint %}

| Eigenschap           | Waarde                   |
| -------------------- | ------------------------ |
| **Land / Regio**     | Duitsland                |
| **Documenttypen**    | Factuur, Creditnota      |
| **Formaat**          | UBL                      |
| **Standaard**        | XRechnung 2.2            |
| **Gebaseerd op**     | EN 16931 (OASIS UBL 2.1) |

XRechnung 2.2 implementeert de EN 16931 Core Invoice-standaard met Duitse CIUS-extensies (Core Invoice Usage Specification). Deze versie bracht aanvullende bedrijfsregels en uitgebreide ondersteuning voor complexe factureringsscenario's.
