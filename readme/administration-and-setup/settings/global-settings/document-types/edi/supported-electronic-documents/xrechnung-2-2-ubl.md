# 🇩🇪 XRECHNUNG 2.2 UBL

| Propriedade | Valor |
| --- | --- |
| **País / Região** | Alemanha |
| **Tipos de documento** | Fatura, Nota de crédito |
| **Formato** | UBL |
| **Padrão** | XRechnung 2.2 |
| **Baseado em** | EN 16931 (OASIS UBL 2.1) |

O XRechnung 2.2 implementa o padrão EN 16931 Core Invoice com as extensões da CIUS (Core Invoice Usage Specification) alemã. Esta versão introduziu regras de negócio adicionais e suporte alargado para cenários de faturação complexos.
