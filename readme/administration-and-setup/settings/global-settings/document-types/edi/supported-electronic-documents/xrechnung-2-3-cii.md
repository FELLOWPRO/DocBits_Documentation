# 🇩🇪 XRECHNUNG 2.3 CII

<!-- edocs-country-scope -->

{% hint style="info" %}
Sprawdź w przewodniku krajowym ograniczenia wersji, faktycznie używaną konfigurację i film objaśniający dla kraju. [Niemcy](countries/germany.md). Składnia, wersja publikacji i profil to różne wybory. Nie wnioskuj o publikacji Factur-X na podstawie wspólnego znacznika 1p0.
{% endhint %}

| Właściwość           | Wartość                                     |
| -------------------- | ------------------------------------------- |
| **Kraj/Region**      | Niemcy                                      |
| **Typy dokumentów**  | Faktura, Nota kredytowa                     |
| **Format**           | CII                                         |
| **Standard**         | XRechnung 2.3                               |
| **Oparty na**        | EN 16931 (UN/CEFACT Cross Industry Invoice) |

XRechnung 2.3 implementuje standard EN 16931 Core Invoice wraz z niemieckimi rozszerzeniami CIUS (Core Invoice Usage Specification). Ta wersja wprowadziła dostosowanie do Peppol, aby zapewnić bezproblemową integrację z paneuropejską siecią Pan-European Public Procurement Online.
