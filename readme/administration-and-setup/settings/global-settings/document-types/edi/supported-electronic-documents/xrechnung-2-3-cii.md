# 🇩🇪 XRECHNUNG 2.3 CII

| Propriedade | Valor |
| --- | --- |
| **País / Região** | Alemanha |
| **Tipos de documento** | Fatura, Nota de crédito |
| **Formato** | CII |
| **Padrão** | XRechnung 2.3 |
| **Baseado em** | EN 16931 (UN/CEFACT Cross Industry Invoice) |

O XRechnung 2.3 implementa o padrão EN 16931 Core Invoice com as extensões da CIUS (Core Invoice Usage Specification) alemã. Esta versão introduziu o alinhamento com o Peppol, para garantir uma integração fluida com a rede Pan-European Public Procurement Online.
