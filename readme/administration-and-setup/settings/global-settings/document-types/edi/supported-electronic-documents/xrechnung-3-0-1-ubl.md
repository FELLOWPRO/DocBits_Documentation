# 🇩🇪 XRECHNUNG 3.0.1 UBL

| Właściwość           | Wartość                  |
| -------------------- | ------------------------ |
| **Kraj/Region**      | Niemcy                   |
| **Typy dokumentów**  | Faktura, Nota kredytowa  |
| **Format**           | UBL                      |
| **Standard**         | XRechnung 3.0.1          |
| **Oparty na**        | EN 16931 (OASIS UBL 2.1) |

XRechnung 3.0.1 to obecna generacja niemieckiego standardu e-faktur, zgodna z najnowszymi zmianami EN 16931. Wydanie konserwacyjne z poprawkami artefaktów walidacyjnych i wyjaśnieniami w dokumentacji technicznej.
