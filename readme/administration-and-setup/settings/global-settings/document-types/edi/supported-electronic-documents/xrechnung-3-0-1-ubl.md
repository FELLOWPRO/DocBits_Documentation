# 🇩🇪 XRECHNUNG 3.0.1 UBL

| Propriété              | Valeur                   |
| ---------------------- | ------------------------ |
| **Pays / Région**      | Germany                  |
| **Types de documents** | Invoice, Credit Note     |
| **Format**             | UBL                      |
| **Norme**              | XRechnung 3.0.1          |
| **Basé sur**           | EN 16931 (OASIS UBL 2.1) |

XRechnung 3.0.1 est la génération actuelle de la norme allemande de facturation électronique, alignée sur les dernières évolutions de la norme EN 16931. Version de maintenance comprenant des corrections des artefacts de validation et des clarifications de la documentation technique.
