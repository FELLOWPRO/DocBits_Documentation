# 🇩🇪 XRECHNUNG 3.0.2 CII

<!-- edocs-country-scope -->

Consultez le guide du pays pour connaître les limites de version, la configuration effectivement utilisée et la vidéo explicative du pays. [Allemagne](countries/germany.md). | Propriété              | Valeur                                      |
| ---------------------- | ------------------------------------------- |
| **Pays / Région**      | Germany                                     |
| **Types de documents** | Invoice, Credit Note                        |
| **Format**             | CII                                         |
| **Norme**              | XRechnung 3.0.2                             |
| **Basé sur**           | EN 16931 (UN/CEFACT Cross Industry Invoice) |

XRechnung 3.0.2 est la génération actuelle de la norme allemande de facturation électronique, alignée sur les dernières évolutions de la norme EN 16931. Dernière version de maintenance, avec des règles métier mises à jour et une validation Schematron améliorée pour de meilleurs tests de conformité.
