# 🇩🇪 XRECHNUNG 3.0 UBL

<!-- edocs-country-scope -->

{% hint style="info" %}
Consultate la guida del paese per i limiti delle versioni, la configurazione effettivamente utilizzata e il video esplicativo del paese. [Germania](countries/germany.md). Sintassi, versione di pubblicazione e profilo sono scelte diverse. Non deducete una pubblicazione Factur-X dal marcatore condiviso 1p0.
{% endhint %}

| Proprietà               | Valore                   |
| ----------------------- | ------------------------ |
| **Paese / Regione**     | Germania                 |
| **Tipi di documento**   | Fattura, Nota di credito |
| **Formato**             | UBL                      |
| **Standard**            | XRechnung 3.0            |
| **Basato su**           | EN 16931 (OASIS UBL 2.1) |

XRechnung 3.0 è l'attuale generazione dello standard tedesco di fatturazione elettronica, allineata agli ultimi aggiornamenti della norma EN 16931. Versione principale con regole di convalida ristrutturate e supporto migliorato per la fatturazione transfrontaliera all'interno dell'Unione Europea.
