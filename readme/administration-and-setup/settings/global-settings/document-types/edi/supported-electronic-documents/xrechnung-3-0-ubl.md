# 🇩🇪 XRECHNUNG 3.0 UBL

| Właściwość           | Wartość                  |
| -------------------- | ------------------------ |
| **Kraj/Region**      | Niemcy                   |
| **Typy dokumentów**  | Faktura, Nota kredytowa  |
| **Format**           | UBL                      |
| **Standard**         | XRechnung 3.0            |
| **Oparty na**        | EN 16931 (OASIS UBL 2.1) |

XRechnung 3.0 to aktualna generacja niemieckiego standardu e-faktur, zgodna z najnowszymi aktualizacjami EN 16931. Jest to wydanie główne z przebudowanymi regułami walidacji i rozszerzoną obsługą fakturowania transgranicznego w Unii Europejskiej.
