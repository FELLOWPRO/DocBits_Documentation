# 🇩🇪 XRECHNUNG 3.0 UBL

| 属性                 | 值                       |
| -------------------- | ------------------------ |
| **国家 / 地区**      | 德国                     |
| **文档类型**         | 发票、贷项通知单         |
| **格式**             | UBL                      |
| **标准**             | XRechnung 3.0            |
| **基于**             | EN 16931（OASIS UBL 2.1） |

XRechnung 3.0 是德国电子发票标准的当前版本，与最新的 EN 16931 更新保持一致。这个主要版本重新构建了验证规则，并增强了对欧盟境内跨境开票的支持。
