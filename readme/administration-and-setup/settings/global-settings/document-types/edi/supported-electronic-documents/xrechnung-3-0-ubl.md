# 🇩🇪 XRECHNUNG 3.0 UBL

| Propriété              | Valeur                   |
| ---------------------- | ------------------------ |
| **Pays / Région**      | Germany                  |
| **Types de documents** | Invoice, Credit Note     |
| **Format**             | UBL                      |
| **Norme**              | XRechnung 3.0            |
| **Basé sur**           | EN 16931 (OASIS UBL 2.1) |

XRechnung 3.0 est la génération actuelle de la norme allemande de facturation électronique, alignée sur les dernières évolutions de la norme EN 16931. Version majeure avec des règles de validation restructurées et une prise en charge renforcée de la facturation transfrontalière au sein de l'Union européenne.
