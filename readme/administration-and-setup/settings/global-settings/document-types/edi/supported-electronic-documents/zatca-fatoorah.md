# 🇸🇦 ZATCA FATOORAH

<!-- edocs-country-scope -->

{% hint style="info" %}
Consultate la guida del paese per i limiti delle versioni, la configurazione effettivamente utilizzata e il video esplicativo del paese. [Arabia Saudita](countries/saudi-arabia.md). Queste etichette descrivono processi e varianti di fattura diversi. L’analisi del file non dimostra la firma, l’autorizzazione fiscale o la comunicazione tramite ZATCA.
{% endhint %}

| Proprietà               | Valore                                                    |
| ----------------------- | --------------------------------------------------------- |
| **Paese / Regione**     | Arabia Saudita                                            |
| **Tipi di documento**   | Fattura (Fatoorah)                                        |
| **Formato**             | XML UBL 2.1                                               |
| **Standard**            | ZATCA FATOORAH (ZATCA - Zakat, Tax and Customs Authority) |

ZATCA Fatoorah è lo standard saudita di fatturazione elettronica gestito dalla Zakat, Tax and Customs Authority. La Fase 1 (Generazione) è diventata obbligatoria a dicembre 2022, mentre la Fase 2 (Integrazione) richiede la comunicazione in tempo reale alla piattaforma ZATCA. Fatoorah è il formato standard di fattura fiscale utilizzato per le transazioni B2B di importo superiore a 1.000 SAR.
