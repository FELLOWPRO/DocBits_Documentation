# 🇸🇦 ZATCA FATOORAH

| 属性                 | 值                                                     |
| -------------------- | --------------------------------------------------------- |
| **国家 / 地区** | 沙特阿拉伯                                              |
| **文档类型**   | 发票（Fatoorah）                                        |
| **格式**         | UBL 2.1 XML                                               |
| **标准**         | ZATCA FATOORAH（ZATCA - 天课、税务和海关管理局） |

ZATCA Fatoorah 是由天课、税务和海关管理局运营的沙特阿拉伯电子发票标准。第 1 阶段（生成）于 2022 年 12 月起成为强制要求，第 2 阶段（集成）要求向 ZATCA 平台实时报告。Fatoorah 是 B2B 交易金额超过 SAR 1,000 时使用的标准税务发票格式。
