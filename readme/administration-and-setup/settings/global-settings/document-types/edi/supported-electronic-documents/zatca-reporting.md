# 🇸🇦 ZATCA REPORTING

<!-- edocs-country-scope -->

{% hint style="info" %}
Consulte la guía del país para conocer los límites de versión, la configuración que se está utilizando y el vídeo explicativo del país. [Arabia Saudí](countries/saudi-arabia.md). Estas etiquetas describen procesos y variantes de factura diferentes. Analizar el archivo no demuestra la firma, la autorización ni la comunicación a través de ZATCA.
{% endhint %}

| Propiedad            | Valor                                 |
| -------------------- | ------------------------------------- |
| **País / Región**    | Arabia Saudí                          |
| **Tipos de documento** | Factura notificada                  |
| **Formato**          | XML UBL 2.1                           |
| **Estándar**         | ZATCA Reporting (integración de la fase 2) |

ZATCA Reporting se refiere al modo de integración de la fase 2, en el que las facturas fiscales estándar se notifican a la plataforma de la ZATCA en un plazo de 24 horas desde su emisión. La factura notificada incluye un sello criptográfico, un código QR y un UUID asignado por el portal Fatoorah de la ZATCA.
