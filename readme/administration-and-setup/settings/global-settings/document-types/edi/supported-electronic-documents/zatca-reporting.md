# 🇸🇦 ZATCA REPORTING

<!-- edocs-country-scope -->

{% hint style="info" %}
Die Länderanleitung enthält Versionsgrenzen, die tatsächlich verwendete Konfiguration und das Erklärvideo zum Land. [Saudi-Arabien](countries/saudi-arabia.md). Diese Bezeichnungen beschreiben unterschiedliche Prozesse und Rechnungsvarianten. Das Einlesen belegt keine Signierung, Freigabe oder Meldung über ZATCA.
{% endhint %}

| Eigenschaft       | Wert                                  |
| ----------------- | ------------------------------------- |
| **Land / Region** | Saudi-Arabien                         |
| **Dokumenttypen** | Gemeldete Rechnung                    |
| **Format**        | UBL 2.1 XML                           |
| **Standard**      | ZATCA Reporting (Phase 2 Integration) |

ZATCA Reporting bezeichnet den Integrationsmodus der Phase 2, in dem Standard-Steuerrechnungen innerhalb von 24 Stunden nach Ausstellung an die ZATCA-Plattform gemeldet werden. Die gemeldete Rechnung enthält einen kryptografischen Stempel, einen QR-Code und eine UUID, die vom Fatoorah-Portal der ZATCA vergeben wird.
