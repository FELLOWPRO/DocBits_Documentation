# 🇸🇦 ZATCA SIMPLIFIED

<!-- edocs-country-scope -->

{% hint style="info" %}
Consulte la guía del país para conocer los límites de versión, la configuración que se está utilizando y el vídeo explicativo del país. [Arabia Saudí](countries/saudi-arabia.md). Estas etiquetas describen procesos y variantes de factura diferentes. Analizar el archivo no demuestra la firma, la autorización ni la comunicación a través de ZATCA.
{% endhint %}

| Propiedad            | Valor                        |
| -------------------- | ---------------------------- |
| **País / Región**    | Arabia Saudí                 |
| **Tipos de documento** | Factura fiscal simplificada |
| **Formato**          | XML UBL 2.1                  |
| **Estándar**         | ZATCA Simplified Tax Invoice |

La factura fiscal simplificada de ZATCA se utiliza en las transacciones B2C en Arabia Saudí cuyo importe total (IVA incluido) no supera los 1.000 SAR. A diferencia de las facturas fiscales estándar, las facturas simplificadas no requieren la identificación del comprador, pero deben incluir un código QR con la información del vendedor codificada en TLV, el importe del IVA y la marca de tiempo.
