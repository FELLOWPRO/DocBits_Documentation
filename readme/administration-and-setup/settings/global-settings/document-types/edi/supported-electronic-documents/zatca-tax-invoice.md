# 🇸🇦 ZATCA TAX INVOICE

<!-- edocs-country-scope -->

{% hint style="info" %}
Die Länderanleitung enthält Versionsgrenzen, die tatsächlich verwendete Konfiguration und das Erklärvideo zum Land. [Saudi-Arabien](countries/saudi-arabia.md). Diese Bezeichnungen beschreiben unterschiedliche Prozesse und Rechnungsvarianten. Das Einlesen belegt keine Signierung, Freigabe oder Meldung über ZATCA.
{% endhint %}

| Eigenschaft | Wert |
|---|---|
| **Land / Region** | Saudi Arabia |
| **Dokumenttypen** | Standard Tax Invoice |
| **Format** | UBL 2.1 XML |
| **Standard** | ZATCA Standard Tax Invoice |

Die ZATCA Tax Invoice ist das standardmäßige B2B-Steuerrechnungsformat im saudi-arabischen E-Invoicing-System. Sie erfordert die vollständige Identifikation von Käufer und Verkäufer (einschließlich der USt-Registrierungsnummern), detaillierte Rechnungspositionen mit Umsatzsteuerberechnung und muss über die ZATCA-Plattform freigegeben (Clearance) werden, bevor sie an den Käufer weitergegeben wird.
