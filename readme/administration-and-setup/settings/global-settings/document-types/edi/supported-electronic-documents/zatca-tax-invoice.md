# 🇸🇦 ZATCA TAX INVOICE

<!-- edocs-country-scope -->

{% hint style="info" %}
Consultate la guida del paese per i limiti delle versioni, la configurazione effettivamente utilizzata e il video esplicativo del paese. [Arabia Saudita](countries/saudi-arabia.md). Queste etichette descrivono processi e varianti di fattura diversi. L’analisi del file non dimostra la firma, l’autorizzazione fiscale o la comunicazione tramite ZATCA.
{% endhint %}

| Proprietà               | Valore                     |
| ----------------------- | -------------------------- |
| **Paese / Regione**     | Arabia Saudita             |
| **Tipi di documento**   | Fattura fiscale standard   |
| **Formato**             | XML UBL 2.1                |
| **Standard**            | ZATCA Standard Tax Invoice |

ZATCA Tax Invoice è il formato standard di fattura fiscale B2B nel sistema saudita di fatturazione elettronica. Richiede l'identificazione completa di acquirente e venditore (compresi i numeri di registrazione IVA), righe dettagliate con calcolo dell'IVA e deve essere autorizzata tramite la piattaforma ZATCA prima di essere condivisa con l'acquirente.
