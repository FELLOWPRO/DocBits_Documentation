# 🇩🇪 ZUGFERD 1.0 BASIC

| Eigenschaft | Wert |
|---|---|
| **Land / Region** | Germany |
| **Dokumenttypen** | Invoice, Credit Note |
| **Format** | CII (PDF/A-3 eingebettet) |
| **Standard** | ZUGFeRD 1.0, Basic-Profil |
| **Basiert auf** | ZUGFeRD 1.0 Spezifikation |

Das Basic-Profil von ZUGFeRD 1.0 enthält die wesentlichen Rechnungsfelder wie Rechnungsnummer, Datum, Verkäufer/Käufer, Rechnungspositionen und Steuersummen. Es liefert genügend strukturierte Daten für die automatisierte Verbuchung in den meisten ERP-Systemen.
