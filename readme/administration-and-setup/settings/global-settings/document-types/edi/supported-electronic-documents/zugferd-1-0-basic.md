# 🇩🇪 ZUGFERD 1.0 BASIC

<!-- edocs-country-scope -->

{% hint style="info" %}
Die Länderanleitung enthält Versionsgrenzen, die tatsächlich verwendete Konfiguration und das Erklärvideo zum Land. [Deutschland](countries/germany.md). Syntax, Veröffentlichungsversion und Profil sind unterschiedliche Auswahlmerkmale. Leiten Sie aus der gemeinsamen Kennung 1p0 keine Factur-X-Veröffentlichung ab.
{% endhint %}

| Eigenschaft | Wert |
|---|---|
| **Land / Region** | Deutschland |
| **Dokumenttypen** | Rechnung, Gutschrift |
| **Format** | CII (PDF/A-3 eingebettet) |
| **Standard** | ZUGFeRD 1.0, Basic-Profil |
| **Basiert auf** | ZUGFeRD 1.0 Spezifikation |

Das Basic-Profil von ZUGFeRD 1.0 enthält die wesentlichen Rechnungsfelder wie Rechnungsnummer, Datum, Verkäufer/Käufer, Rechnungspositionen und Steuersummen. Es liefert genügend strukturierte Daten für die automatisierte Verbuchung in den meisten ERP-Systemen.
