# 🇩🇪 ZUGFERD 1.0 BASIC

| Eigenschap | Waarde |
| ---------- | ------ |
| **Land / Regio** | Duitsland |
| **Documenttypen** | Factuur, Creditnota |
| **Formaat** | CII (PDF/A-3 ingebed) |
| **Standaard** | ZUGFeRD 1.0, Basic-profiel |
| **Gebaseerd op** | ZUGFeRD 1.0-specificatie |

Het Basic-profiel van ZUGFeRD 1.0 bevat essentiële factuurvelden zoals factuurnummer, datum, verkoper/koper, factuurregels en btw-totalen. Het biedt voldoende gestructureerde gegevens voor geautomatiseerd boeken in de meeste ERP-systemen.
