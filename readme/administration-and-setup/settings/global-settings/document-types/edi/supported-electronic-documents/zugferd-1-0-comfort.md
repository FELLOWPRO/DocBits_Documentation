# 🇩🇪 ZUGFERD 1.0 COMFORT

| Propiedad            | Valor                        |
| -------------------- | ---------------------------- |
| **País / Región**    | Alemania                     |
| **Tipos de documento** | Factura, Nota de crédito   |
| **Formato**          | CII (incrustado en PDF/A-3)  |
| **Estándar**         | ZUGFeRD 1.0, perfil Comfort  |
| **Basado en**        | Especificación ZUGFeRD 1.0   |

El perfil Comfort de ZUGFeRD 1.0 amplía el perfil Basic con campos adicionales para las condiciones de pago, la información de entrega y los desgloses de impuestos detallados. Permite un procesamiento de facturas totalmente automatizado, sin introducción manual de datos.

## Estado de soporte

| Componente           | Estado        |
| -------------------- | ------------- |
| Vista previa         | ✅ Compatible |
| Extracción de campos | ✅ Compatible |
| Transformación       | ✅ Compatible |
