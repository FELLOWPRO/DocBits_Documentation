# 🇩🇪 ZUGFERD 1.0 COMFORT

| Propriété              | Valeur                       |
| ---------------------- | ---------------------------- |
| **Pays / Région**      | Germany                      |
| **Types de documents** | Invoice, Credit Note         |
| **Format**             | CII (PDF/A-3 embedded)       |
| **Norme**              | ZUGFeRD 1.0, Comfort profile |
| **Basé sur**           | ZUGFeRD 1.0 specification    |

Le profil Comfort de ZUGFeRD 1.0 complète le profil Basic avec des champs supplémentaires pour les conditions de paiement, les informations de livraison et le détail de la TVA. Il permet un traitement entièrement automatisé des factures, sans saisie manuelle des données.

## Statut de prise en charge

| Composant             | Statut      |
| --------------------- | ----------- |
| Aperçu                | ✅ Supported |
| Extraction des champs | ✅ Supported |
| Transformation        | ✅ Supported |
