# 🇩🇪 ZUGFERD 1.0 EXTENDED

| Propiedad            | Valor                         |
| -------------------- | ----------------------------- |
| **País / Región**    | Alemania                      |
| **Tipos de documento** | Factura, Nota de crédito    |
| **Formato**          | CII (incrustado en PDF/A-3)   |
| **Estándar**         | ZUGFeRD 1.0, perfil Extended  |
| **Basado en**        | Especificación ZUGFeRD 1.0    |

El perfil Extended de ZUGFeRD 1.0 es el más completo y admite escenarios de negocio adicionales, como la contabilidad comercial, el factoring y la información logística detallada. Incluye todos los campos de los perfiles Basic y Comfort, además de extensiones específicas del sector.

## Estado de soporte

| Componente           | Estado        |
| -------------------- | ------------- |
| Vista previa         | ✅ Compatible |
| Extracción de campos | ✅ Compatible |
| Transformación       | ✅ Compatible |
