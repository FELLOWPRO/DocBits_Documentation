# 🇩🇪 ZUGFERD 2.2

| Eigenschaft | Wert |
|---|---|
| **Land / Region** | Germany |
| **Dokumenttypen** | Invoice, Credit Note |
| **Format** | CII (PDF/A-3 eingebettet) |
| **Standard** | ZUGFeRD 2.2 |
| **Basiert auf** | EN 16931 |

ZUGFeRD 2.2, veröffentlicht 2022, orientiert sich am europäischen Standard EN 16931 und entspricht Factur-X 1.0.06. Es verwendet die CII-D16B-XML-Syntax und unterstützt fünf Konformitätsprofile: Minimum, Basic WL, Basic, EN 16931 (Comfort) und Extended.
