# 🇩🇪 ZUGFERD 2.2

| Propriété | Valeur |
| -------------------- | ------------------------- |
| **Pays / Région** | Germany |
| **Types de documents** | Invoice, Credit Note |
| **Format** | CII (PDF/A-3 embedded) |
| **Norme** | ZUGFeRD 2.2 |
| **Basé sur** | EN 16931 |

ZUGFeRD 2.2, publiée en 2022, s'aligne sur la norme européenne EN 16931 et équivaut à Factur-X 1.0.06. Elle utilise la syntaxe XML CII D16B et prend en charge cinq profils de conformité : Minimum, Basic WL, Basic, EN 16931 (Comfort) et Extended.
