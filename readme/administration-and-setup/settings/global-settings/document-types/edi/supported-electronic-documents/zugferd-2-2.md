# 🇩🇪 ZUGFERD 2.2

| Proprietà               | Valore                       |
| ----------------------- | ---------------------------- |
| **Paese / Regione**     | Germania                     |
| **Tipi di documento**   | Fattura, Nota di credito     |
| **Formato**             | CII (incorporato in PDF/A-3) |
| **Standard**            | ZUGFeRD 2.2                  |
| **Basato su**           | EN 16931                     |

ZUGFeRD 2.2, pubblicato nel 2022, è allineato allo standard europeo EN 16931 ed equivale a Factur-X 1.0.06. Utilizza la sintassi XML CII D16B e supporta cinque profili di conformità: Minimum, Basic WL, Basic, EN 16931 (Comfort) ed Extended.
