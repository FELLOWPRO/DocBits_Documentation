# 🇩🇪 ZUGFERD 2.3.2

| Eigenschaft | Wert |
|---|---|
| **Land / Region** | Germany |
| **Dokumenttypen** | Invoice, Credit Note |
| **Format** | CII (PDF/A-3 eingebettet) |
| **Standard** | ZUGFeRD 2.3.2 |
| **Basiert auf** | EN 16931 |

ZUGFeRD 2.3.2, veröffentlicht im November 2024, entspricht Factur-X 1.0.07.2. Dieses Wartungsrelease enthält Korrekturen an den Schematron-Regeln, aktualisierte Codelisten und verfeinerte Geschäftsregelvalidierungen.
