# 🇩🇪 ZUGFERD 2.3.2

| Właściwość           | Wartość                  |
| -------------------- | ------------------------ |
| **Kraj/Region**      | Niemcy                   |
| **Typy dokumentów**  | Faktura, Nota kredytowa  |
| **Format**           | CII (osadzony w PDF/A-3) |
| **Standard**         | ZUGFeRD 2.3.2            |
| **Oparty na**        | EN 16931                 |

ZUGFeRD 2.3.2, wydany w listopadzie 2024 roku, odpowiada Factur-X 1.0.07.2. To wydanie serwisowe zawiera poprawki reguł Schematron, zaktualizowane listy kodów oraz dopracowane walidacje reguł biznesowych.
