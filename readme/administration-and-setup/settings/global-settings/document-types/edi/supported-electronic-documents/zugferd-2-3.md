# 🇩🇪 ZUGFERD 2.3

| Eigenschaft | Wert |
|---|---|
| **Land / Region** | Germany |
| **Dokumenttypen** | Invoice, Credit Note |
| **Format** | CII (PDF/A-3 eingebettet) |
| **Standard** | ZUGFeRD 2.3 |
| **Basiert auf** | EN 16931 |

ZUGFeRD 2.3, veröffentlicht im September 2024, entspricht Factur-X 1.0.07. Es aktualisiert das CII-XML auf die Spezifikation D22B, ergänzt verbesserte Validierungsregeln und führt die Unterstützung des XRechnung-Referenzprofils ein, um die deutschen B2G-Anforderungen zu erfüllen.
