# 🇩🇪 ZUGFERD 2.3

<!-- edocs-country-scope -->

{% hint style="info" %}
Consultez le guide du pays pour connaître les limites de version, la configuration effectivement utilisée et la vidéo explicative du pays. [Allemagne](countries/germany.md). La syntaxe, la version de publication et le profil sont des choix distincts. Ne déduisez pas une publication Factur-X du marqueur commun 1p0.
{% endhint %}

| Propriété | Valeur |
| -------------------- | ------------------------- |
| **Pays / Région** | Germany |
| **Types de documents** | Invoice, Credit Note |
| **Format** | CII (PDF/A-3 embedded) |
| **Norme** | ZUGFeRD 2.3 |
| **Basé sur** | EN 16931 |

ZUGFeRD 2.3, publiée en septembre 2024, équivaut à Factur-X 1.0.07. Elle met à jour le XML CII vers la spécification D22B, ajoute des règles de validation améliorées et introduit la prise en charge du profil de référence XRechnung afin de répondre aux exigences allemandes B2G.
