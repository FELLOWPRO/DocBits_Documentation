# 🇩🇪 ZUGFERD 2.3

| Propiedad                | Valor                       |
| ------------------------ | --------------------------- |
| **País / Región**        | Alemania                    |
| **Tipos de documento**   | Factura, Nota de crédito    |
| **Formato**              | CII (incrustado en PDF/A-3) |
| **Estándar**             | ZUGFeRD 2.3                 |
| **Basado en**            | EN 16931                    |

ZUGFeRD 2.3, publicado en septiembre de 2024, equivale a Factur-X 1.0.07. Actualiza el XML CII a la especificación D22B, añade reglas de validación mejoradas e incorpora compatibilidad con el perfil de referencia XRechnung para cumplir los requisitos alemanes B2G.

## Estado de compatibilidad

| Componente                 | Estado        |
| -------------------------- | ------------- |
| Vista previa               | ✅ Compatible |
| Extracción de campos       | ✅ Compatible |
| Transformación             | ✅ Compatible |
