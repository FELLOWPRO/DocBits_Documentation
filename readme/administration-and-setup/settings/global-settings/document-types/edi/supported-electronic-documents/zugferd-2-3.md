# 🇩🇪 ZUGFERD 2.3

<!-- edocs-country-scope -->

{% hint style="info" %}
Sprawdź w przewodniku krajowym ograniczenia wersji, faktycznie używaną konfigurację i film objaśniający dla kraju. [Niemcy](countries/germany.md). Składnia, wersja publikacji i profil to różne wybory. Nie wnioskuj o publikacji Factur-X na podstawie wspólnego znacznika 1p0.
{% endhint %}

| Właściwość           | Wartość                  |
| -------------------- | ------------------------ |
| **Kraj/Region**      | Niemcy                   |
| **Typy dokumentów**  | Faktura, Nota kredytowa  |
| **Format**           | CII (osadzony w PDF/A-3) |
| **Standard**         | ZUGFeRD 2.3              |
| **Oparty na**        | EN 16931                 |

ZUGFeRD 2.3, wydany we wrześniu 2024 roku, odpowiada Factur-X 1.0.07. Aktualizuje XML CII do specyfikacji D22B, dodaje ulepszone reguły walidacji i wprowadza obsługę profilu referencyjnego XRechnung, aby spełnić niemieckie wymagania B2G.
