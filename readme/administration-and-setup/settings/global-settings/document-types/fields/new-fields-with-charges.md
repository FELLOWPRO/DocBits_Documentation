# 新建费用字段

\


## 步骤 1：访问字段设置

1\. 前往字段：

• 在主仪表板中，点击侧边栏里的“Fields”（字段）选项。

• 这将打开“Field Settings”（字段设置）页面，您可以在此管理文档类型和识别设置。

2\. 选择文档类型：

• 在“DOCUMENT TYPES”（文档类型）部分中，选择要添加或修改字段的特定文档类型。

## 步骤 2：添加新字段

1\. 打开“Add Field”（添加字段）对话框：

• 点击相应部分（例如“Invoice Details”（发票详情）、“Payment Details”（付款详情）、“Purchase Order”（采购订单））中的“Create Field”（创建字段）按钮。

2\. 输入字段详情：

• 系统将显示标题为“Document field details”（文档字段详情）的对话框。

• 填写所需信息：

• Name（名称）：输入新字段的名称。

• Title（标题）：输入字段的描述性标题。

• Select field type（选择字段类型）：从下拉菜单中选择适当的字段类型。

3\. 启用费用元素：

• 如果此字段关联某项费用，请勾选“Enable charges element”（启用费用元素）框。

4\. 选择成本映射：

• 启用费用后，将显示一个下拉菜单。

• 从列表中选择适当的费用类型（例如 ADD ON - ORIGIN、FUEL SURCHARGE、TOTAL FREIGHT）。

\


## 步骤 3：保存新字段

1\. 保存设置：

• 点击“SAVE”（保存）按钮，添加带有所指定费用映射的新字段。

• 如果需要进行更改，请点击“BACK”（返回）按钮回到上一屏幕。

2\. 完成字段创建：

• 保存后，新字段将显示在指定文档类型下的列表中。

• 根据需要配置 OCR 和 Match Score（匹配分数）设置，以确保准确识别。

3\. 完成设置：

• 添加并配置所有所需字段后，点击“Field Settings”（字段设置）页面底部的“Save Settings”（保存设置）按钮以应用更改。

\


## 其他说明

• 必填字段：

• 如果字段为必填字段，请勾选字段名称旁边的“REQUIRED”（必填）框。

• 编辑现有字段：

• 要编辑现有字段，请点击字段名称，更新详情并保存更改。

• 重新分配字段组：

• 如有需要，请使用“Reassign Field Group”（重新分配字段组）选项更改字段分组。

• 主数据设置：

• 如需进行高级配置，请访问“Master Data Settings”（主数据设置），以管理整体字段和文档类型设置。
