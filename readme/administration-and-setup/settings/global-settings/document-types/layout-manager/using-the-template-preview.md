# Utilizzo dell'anteprima del template

## L'anteprima del template è uno strumento estremamente utile per controllare e regolare le impostazioni del layout in tempo reale prima di apportare modifiche a un documento o a un template.

### Ecco come puoi utilizzare l'anteprima del template:

<figure><img src="../../../../../.gitbook/assets/image (152).png" alt=""><figcaption></figcaption></figure>

#### Aprire l'anteprima del template:

* Di solito trovi l'opzione dell'anteprima del template nell'interfaccia dell'editor dei template.

<figure><img src="../../../../../.gitbook/assets/image (153).png" alt=""><figcaption></figcaption></figure>

#### Selezionare il template:

* Seleziona il template di cui vuoi controllare il layout.
* Può trattarsi di un template esistente che vuoi modificare o di un nuovo template che vuoi creare.

<figure><img src="../../../../../.gitbook/assets/Bildschirmfoto 2024-05-24 um 12.31.04.png" alt="" width="186"><figcaption></figcaption></figure>

#### Regolare le impostazioni del layout:

* Modifica le impostazioni del layout secondo le necessità. Puoi, ad esempio, aggiungere, rimuovere o regolare gruppi, campi, colonne, righe, caratteri e così via.

<figure><img src="../../../../../.gitbook/assets/image (155).png" alt="" width="271"><figcaption></figcaption></figure>

#### Anteprima in tempo reale:

* Mentre modifichi le impostazioni del layout, l'anteprima si aggiorna in tempo reale.
* Puoi vedere subito come le modifiche influiscono sull'aspetto e sulla struttura del template.

#### Personalizzazione interattiva:

* Sfrutta la possibilità di personalizzare il layout in modo interattivo spostando, ridimensionando o regolando in altro modo gli elementi, mentre controlli in tempo reale gli effetti nell'anteprima.

#### Testare diverse configurazioni:

* Sperimenta diverse configurazioni di layout per trovare il design più adatto alle tue esigenze.
* Usa l'anteprima del template per vedere come ogni modifica influisce sull'aspetto finale.

#### Salvare e confermare le modifiche:

* Quando sei soddisfatto del layout, salva le modifiche.
* A seconda del software, potresti trovare anche l'opzione per confermare direttamente le modifiche e aggiornare il template per l'uso in altri documenti o processi.

Utilizzando l'anteprima del template puoi assicurarti che il layout soddisfi le tue esigenze prima di confermare le modifiche. In questo modo puoi personalizzare in modo efficiente il design e la struttura dei tuoi documenti e garantire che rispettino gli standard visivi e funzionali desiderati.
