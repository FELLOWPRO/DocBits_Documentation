# Zarządzanie danymi treningowymi

## Zarządzaj istniejącymi danymi treningowymi, w tym dodawaniem, edytowaniem lub usuwaniem rekordów.



**Aby skutecznie zarządzać danymi treningowymi, możesz wykonać następujące kroki:**&#x20;

**Dodawanie nowych rekordów:**&#x20;

* Zbierz nowe dokumenty, które posłużą jako dane treningowe dla Twojego modelu.&#x20;
* Upewnij się, że dokumenty te stanowią reprezentatywną próbkę różnych typów danych, które model ma przetwarzać.&#x20;
* Prześlij nowe rekordy do swojego repozytorium danych treningowych.&#x20;

**Edytowanie istniejących rekordów**:&#x20;

* Regularnie przeglądaj istniejące dane treningowe i aktualizuj je w razie potrzeby. Może to obejmować edytowanie metadanych dokumentów, dodawanie dodatkowych etykiet albo usuwanie błędnych lub niereprezentatywnych rekordów.&#x20;

**Usuwanie rekordów:**&#x20;

* Zidentyfikuj rekordy przestarzałe, niedokładne lub niemające już znaczenia i usuń je ze zbioru danych treningowych.&#x20;
* Upewnij się, że masz jasno określony proces decydowania o tym, które rekordy usunąć, i udokumentuj ten proces.&#x20;

**Wersjonowanie danych treningowych:**&#x20;

* Wdróż system kontroli wersji dla danych treningowych, aby śledzić zmiany i prowadzić przejrzystą historię zmian zbioru danych. Dzięki temu w razie potrzeby możesz przywracać starsze wersje danych treningowych i śledzić zmiany.&#x20;

**Bezpieczeństwo danych treningowych:**&#x20;

* Zadbaj o odpowiednią ochronę danych treningowych, zwłaszcza jeśli zawierają informacje wrażliwe lub poufne. Wdróż kontrolę dostępu, aby tylko upoważnieni użytkownicy mieli dostęp do danych treningowych, oraz szyfruj dane podczas przesyłania i przechowywania.&#x20;

**Dokumentacja i śledzenie:**&#x20;

* Dokumentuj wszystkie zmiany w danych treningowych, w tym dodawanie, edytowanie i usuwanie zbiorów danych. Dzięki temu możesz śledzić historię danych treningowych i mieć pewność, że dysponujesz aktualnymi i istotnymi danymi do trenowania modelu.&#x20;

Regularnie zarządzając danymi treningowymi i je aktualizując, możesz zapewnić, że Twój model jest trenowany na aktualnych i reprezentatywnych danych oraz osiąga optymalną wydajność.
