# 审批

使用审批选项决定文档离开 DocBits 前如何进行检查。选项按文档类型配置，因此请从团队使用的类型开始，例如 **发票**。

1. 打开 **设置** → **文档类型**。
2. 选择文档类型并打开 **更多设置**。
3. 滚动到 **审批与拒绝**。更改任何选项前，请先检查这四个开关。

<figure><img src="../../../../../../.gitbook/assets/site-extra-approval-settings-zh.png" alt="发票文档类型的审批与拒绝设置。界面中的“出口前批准”指“导出前审批”，并非贸易出口；审批印章与审批历史记录为独立选项。"><figcaption><p>发票文档类型的审批与拒绝设置。界面中的“出口前批准”指“导出前审批”，并非贸易出口；审批印章与审批历史记录为独立选项。</p></figcaption></figure>

| 选项 | 用途 |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| **导出前审批**（界面误译为“出口前批准”） | 导出文档前必须先作出审批决定。 |
| **二次审批** | 当一个审批决定不足以满足流程要求时，添加另一个审批步骤。 |
| **审批印章** | 为已审批的文档添加审批标记。有关设置和下载选项，请参阅 [审批印章](approval-stamp.md)。 |
| **审批历史记录** | 保留审批决定的记录。有关该设置以及如何查看历史记录，请参阅 [审批历史记录](approval-history.md)。 |

选择流程所需的选项。然后，使用非客户文档和预期的审核者角色检查审批路径，再将其应用于实际文档。设置截图只展示配置入口，不能证明某份文档已完成审批、生成印章或导出。
