# PO 更新自动检查

### 查找位置

进入 **Settings** → **General Settings** → **Document Types** → **More Settings** → **Purchase Order Section** → **Auto Check for PO Updates**\
切换按钮以启用此设置。

<div align="center" data-full-width="false"><figure><img src="../../../../../../.gitbook/assets/image (411).png" alt=""><figcaption></figcaption></figure></div>

### 工作原理

启用后，只要采购订单有更新，系统就会在 **Purchase Order Matching** 屏幕中显示一个**视觉指示标志**。此图标表示应刷新采购订单，以确保用户在做出决定前使用的是最新信息。

<div align="left"><figure><img src="../../../../../../.gitbook/assets/image (414).png" alt=""><figcaption></figcaption></figure></div>

要刷新采购订单，请点击采购订单编号旁边的**刷新图标**（见下图）。
