# 布局构建器中的采购订单表

此设置用于控制**采购订单（PO）表**在**布局构建器**和**验证屏幕**中的可用性。

### **如何启用采购订单表**

启用此功能：

1. 前往 **Settings → General Settings → Document Types → More Settings → Purchase Order Section → PO Table in Layout Builder**。
2. 启用该设置，使**采购订单表**可见。

<figure><img src="../../../../../../.gitbook/assets/iScreen Shoter - Google Chrome - 250210131953.jpg" alt="More Settings页面，包含Purchase Order部分以及PO table in layout builder开关"><figcaption></figcaption></figure>

### **功能：**

* **启用时**：
  * **采购订单表**会显示在**布局构建器**的**表格部分**中。
  *   不会显示有关模块已禁用的通知。\\

      <figure><img src="../../../../../../.gitbook/assets/image (42).png" alt="Layout Builder的Table Section并排显示EXTRAHIERTE TABELLE和PO-TABELLEN卡片"><figcaption></figcaption></figure>
* **禁用时**：
  * 会显示提示，说明该模块已禁用。
  *   **PO 表**不会显示在**验证屏幕**中。\\

      <figure><img src="../../../../../../.gitbook/assets/image (41).png" alt="Layout Builder的Table Section，PO-TABELLE卡片显示提示Modul deaktiviert"><figcaption></figcaption></figure>

**如何访问布局构建器**

1. 前往 **Settings → General Settings → Document Types → Edit Layout**。

<figure><img src="../../../../../../.gitbook/assets/iScreen Shoter - Google Chrome - 250210135142.jpg" alt="Document Types页面，显示某一文档类型的Edit layout、Document Sub Types、Table columns和Fields标签页"><figcaption></figcaption></figure>

**将采购订单表添加回布局**

如果**PO 表**缺失或已被移除，请按以下步骤操作：

1. 打开**布局构建器**。
2. 在**Form Elements**下，选择**Extracted Tables**。
3. 将**PO 表**添加到布局中。

<div align="left"><figure><img src="../../../../../../.gitbook/assets/iScreen Shoter - Google Chrome - 250210135437.jpg" alt="布局生成器侧边面板，其中的表单元素包括Text、Label、Check Box、Table Of Checkboxes、Extracted Tables和Sub Group"><figcaption></figcaption></figure></div>

添加并启用后，当发票有可用的**采购订单**时，**PO 表**将在**布局构建器**和**验证屏幕**中显示。

<div align="center"><figure><img src="../../../../../../.gitbook/assets/iScreen Shoter - Google Chrome - 250210133655.jpg" alt="布局中的EXTRACTED TABLE卡片，其中显示采购订单表的列ORDERSTATUS、STATUS、LINE NUMBER和SUB LINE NUMBER"><figcaption></figcaption></figure></div>
