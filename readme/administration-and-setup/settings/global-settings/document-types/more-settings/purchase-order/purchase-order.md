# 采购订单

## 概述

此设置会启用[**采购订单匹配**](../../../../../../end-user-and-partner-section/end-user-section/purchase-order-matching/)部分，该部分在文档验证后即可访问。

<mark style="color:red;">**注意**</mark>：对于**发票**文档类型，还必须满足以下要求：

* 必须启用**采购订单**设置（如本页所述）
* 发票类型必须为**采购发票**
* 必须存在**已提取表格**

## 激活步骤 <a href="#activation-steps" id="activation-steps"></a>

1. 前往**设置** -> **全局设置** -> **文档类型**
2.  选择所需的文档类型，然后点击**更多设置**。

    <figure><img src="../../../../../../.gitbook/assets/po_settings_1.png" alt="文档类型列表，包含Invoice、Credit Note、Delivery Note和Order Confirmation行及其Activate开关"><figcaption></figcaption></figure>
3.  在**采购订单**部分中，找到**采购订单**选项。

    <figure><img src="../../../../../../.gitbook/assets/po_settings_po.png" alt="Purchase Order 更多设置面板，包含 PO tolerance、Auto check for PO updates 和 PO disable statuses 选项"><figcaption></figcaption></figure>

## **功能**

激活后，[**采购订单匹配**](../../../../../../end-user-and-partner-section/end-user-section/purchase-order-matching/)部分会在文档验证后变为可用。&#x20;

你还可以通过选择设置旁边下拉菜单中的一个选项，配置匹配时使用哪种 **Infor** 数量类型：

* **数量**
* **已收货数量**
* **已收货未结交货数量**
