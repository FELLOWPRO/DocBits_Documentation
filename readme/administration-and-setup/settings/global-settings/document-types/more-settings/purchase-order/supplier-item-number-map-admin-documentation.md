# 供应商物料编号映射 - 管理员文档

## **概述**

{% embed url="https://youtu.be/agxk8WQhtJA" %}

作为管理员，您可以查看和管理内部物料编号与供应商物料编号之间的映射。此功能可确保高效处理您的系统与供应商系统之间的差异。您可以检查、编辑和删除错误的映射，以保持数据准确性。

<figure><img src="../../../../../../.gitbook/assets/supplier_item_number_map_interface.png" alt="Supplier Item Number Map 表格，包含 SUPPLIER ID、ITEM_NUMBER、SUPPLIER ITEM NUMBER 和 ACTION 列"><figcaption></figcaption></figure>

**访问供应商物料编号映射**

1. **前往设置：**
   * 在管理后台中进入 **Settings**（设置）部分。
2. **访问文档类型：**
   * 在 **Settings**（设置）下，选择 **Document Types**（文档类型）。
3. **更多设置：**
   * 点击 **More Settings**（更多设置）以访问其他配置选项。
4. **供应商物料编号映射：**
   * 在 **More Settings**（更多设置）部分中，您会看到 **Supplier Item Number Map**（供应商物料编号映射）表。此表列出了内部物料编号与对应供应商物料编号之间的所有当前映射。

## **管理物料编号映射**

1. **查看映射：**
   * 表中显示以下列：
     * **Supplier ID：** 供应商的唯一标识符。
     * **Item Number：** 产品的内部物料编号。
     * **Supplier Item Number：** 供应商使用的对应物料编号。
     * **Action：** 管理映射的选项。
2. **删除错误的映射：**
   * 如果发现映射有误，可以点击 **Action**（操作）列中的垃圾桶图标（🗑）将其删除。
   * 系统会显示确认提示，以确认您是否要删除该映射。
3. **编辑映射：**
   * （如适用）您也可以选择编辑现有映射以更正差异。这可能需要点击物料编号或供应商编号进行修改。

## **示例工作流**

1. **发现差异：**
   * 定期检查 **Supplier Item Number Map**（供应商物料编号映射），以发现差异或错误映射。
2. **删除错误的映射：**
   * 对于任何错误映射，点击垃圾桶图标将其删除。
3. **重新录入正确的映射：**
   * 确保在下一笔交易中手动录入正确的映射，或者在系统支持时编辑现有条目。
