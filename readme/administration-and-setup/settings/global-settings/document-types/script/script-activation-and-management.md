# Aktywowanie skryptów i zarządzanie nimi

## Film instruktażowy: zarządzanie skryptami

{% embed url="https://docbits-videos.fra1.cdn.digitaloceanspaces.com/settings-assistant/doc-config-manage-scripts/v4/pl.mp4" %}
Zarządzanie skryptami typu dokumentu
{% endembed %}

Film pokazuje listę skryptów z filtrem i sortowaniem, aktywowanie i dezaktywowanie, kopiowanie, historię wersji oraz usuwanie z potwierdzeniem.

Otwórz typ dokumentu i zarządzanie skryptami. Lista udostępnia skrypty oraz działania edycji, kopiowania i statusu. Nazwy w przykładzie są ukryte.

<figure><img src="../../../../../.gitbook/assets/s150-docbits_edit_script_icon-pl.png" alt="Zarządzanie skryptami i działania edycji; nazwy są ukryte."><figcaption><p>Zarządzanie skryptami i działania edycji; nazwy są ukryte.</p></figcaption></figure>

Przefiltruj według statusu lub wyszukaj skrypt przed jego otwarciem. Sprawdź typ dokumentu, moment wykonania i kod przed zapisaniem.

Dostępne działania zależą od uprawnień. Przetestuj zamierzone zmiany na reprezentatywnych dokumentach przed użyciem w rzeczywistym przepływie.
