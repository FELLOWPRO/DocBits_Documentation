# Детекција сличних докумената (Векторска претрага)

{% hint style="info" %}
**Доступно од верзије 11.48.0** — Захтева `OPENSEARCH_ENABLED` лиценцу.
{% endhint %}

## Шта ради ова скрипта?

Користи претрагу сличности засновану на векторима за проналажење докумената семантички сличних тренутном. Ако се пронађе документ са више од 95% сличности, број фактуре се означава као потенцијално лажан или дупликат.

## Окидач

`AFTER_FORMATTING` на типу документа **INVOICE**

## Комплетна скрипта

```python
doc_id = document_json["doc_id"]
similar = vector_search(doc_id, k=5)

for doc in similar:
    if doc["similarity_percent"] > 95:
        set_field_as_invalid(
            document_data, "invoice_id",
            f"95%+ similar to: {doc['name']} (Score: {doc['similarity_percent']}%)"
        )
        break
```

## Објашњење корак по корак

1. **Добиј ID тренутног документа** из `document_json`
2. **Пронађи сличне документе** са `vector_search()` враћајући 5 најближих суседа
3. **Провери праг сличности**: Ако неки документ прелази 95% сличности, означи га
4. **Означи као неважеће** са називом сличног документа и оценом сличности

## Како функционише векторска претрага

OCR текст сваког документа се при индексирању конвертује у 384-димензионално векторско уграђивање. `vector_search()` проналази најближе суседе у овом векторском простору користећи k-NN (k-најближих суседа), враћајући документе чији је садржај семантички сличан — чак и ако се тачне речи разликују.

**Случајеви коришћења:**
- Детекција преваре (скоро идентичне фактуре од различитих "добављача")
- Детекција дупликата која превазилази тачно подударање текста
- Проналажење повезаних докумената у различитим форматима или језицима
