# Korzystanie z akcji

Oto przewodnik wyjaśniający, jak prawidłowo korzystać z akcji „Kopiuj" i „Usuń" w celu efektywnego zarządzania podtypami:

## **Kopiowanie podtypu:**  &#x20;

* Przejdź do ustawień zarządzania podtypami w swoim systemie zarządzania dokumentami.
* Wybierz podtyp, który chcesz skopiować, kliknij „Kopiuj" i w razie potrzeby wprowadź nową nazwę dla skopiowanego podtypu.
* Potwierdź akcję, a system utworzy kopię wybranego podtypu ze wszystkimi istniejącymi ustawieniami, polami, układami i skryptami.

## Usuwanie podtypu:

* Przejdź do ustawień zarządzania podtypami i wybierz podtyp, który chcesz usunąć.
* Kliknij ikonę kosza po prawej stronie menu akcji.
* Potwierdź akcję usunięcia, akceptując komunikat potwierdzający, jeśli się pojawi.
* Pamiętaj, że usunięcie podtypu może nieodwracalnie usunąć wszystkie powiązane z nim dokumenty i dane. Upewnij się, że podjąłeś wszystkie niezbędne środki ostrożności i sprawdź, czy podtyp nie jest już potrzebny, zanim go usuniesz.

Prawidłowe korzystanie z tych akcji pozwala usprawnić zarządzanie podtypami. Kopiowanie pozwala wykorzystać istniejące konfiguracje dla nowych podtypów, natomiast usuwanie umożliwia efektywne porządkowanie podtypów, które nie są już potrzebne. Należy jednak zachować ostrożność podczas usuwania, aby uniknąć utraty danych.\
