# Usando ações

Aqui está um guia sobre como usar corretamente as ações "Copy" e "Delete" para um gerenciamento eficiente de subtipos:

## **Copiando um subtipo:**  &#x20;

* Navegue até as configurações de gerenciamento de subtipos no seu sistema de gerenciamento de documentos.
* Selecione o subtipo que deseja copiar, clique em "Copy" e insira um novo nome para o subtipo copiado, se necessário.
* Confirme a ação e o sistema criará uma cópia do subtipo selecionado com todas as configurações, campos, layouts e scripts existentes.

## Excluindo um subtipo:

* Navegue até as configurações de gerenciamento de subtipos e selecione o subtipo que deseja excluir.
* Clique no ícone de lixeira à direita do menu de ações.
* Confirme a ação de exclusão aceitando uma mensagem de confirmação, se solicitado.
* Observe que excluir um subtipo pode remover de forma irreversível todos os documentos e dados associados a ele. Tome todas as precauções de segurança necessárias e verifique se o subtipo não é mais necessário antes de excluí-lo.

O uso adequado dessas ações permite simplificar o gerenciamento de subtipos. Copiar permite aproveitar configurações existentes para novos subtipos, enquanto excluir permite limpar com eficiência os subtipos que não são mais necessários. No entanto, é importante ter cuidado ao excluir para evitar a perda de dados.\
