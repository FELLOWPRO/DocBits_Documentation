# Utilizzo delle azioni

Ecco una guida su come utilizzare correttamente le azioni "Copia" ed "Elimina" per una gestione efficiente dei sottotipi:

## **Copia di un sottotipo:**  &#x20;

* Vai alle impostazioni di gestione dei sottotipi nel tuo sistema di gestione dei documenti.
* Seleziona il sottotipo che desideri copiare, fai clic su "Copia" e, se necessario, inserisci un nuovo nome per il sottotipo copiato.
* Conferma l'azione e il sistema creerà una copia del sottotipo selezionato con tutte le impostazioni, i campi, i layout e gli script esistenti.

## Eliminazione di un sottotipo:

* Vai alle impostazioni di gestione dei sottotipi e seleziona il sottotipo che desideri eliminare.
* Fai clic sull'icona del cestino a destra nel menu delle azioni.
* Conferma l'azione di eliminazione accettando il messaggio di conferma, se richiesto.
* Tieni presente che l'eliminazione di un sottotipo può rimuovere in modo irreversibile tutti i documenti e i dati ad esso associati. Assicurati di adottare tutte le precauzioni di sicurezza necessarie e di verificare che il sottotipo non sia più necessario prima di eliminarlo.

L'uso corretto di queste azioni ti consente di semplificare la gestione dei sottotipi. La copia ti permette di sfruttare le configurazioni esistenti per nuovi sottotipi, mentre l'eliminazione consente una pulizia efficiente dei sottotipi non più necessari. Tuttavia, è importante prestare attenzione durante l'eliminazione per evitare la perdita di dati.\
