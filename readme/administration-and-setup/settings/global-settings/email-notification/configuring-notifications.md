#### Para acessar as configurações de notificação por e-mail, siga estes passos:

* Navegue até a seção Global Settings na sua conta de usuário ou painel de administração.
* Procure a opção de notificações por e-mail
* Clique na opção apropriada para abrir as configurações de notificação por e-mail....
