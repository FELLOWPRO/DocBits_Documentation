# Grupos, Usuarios y Permisos

Estos ajustes responden a tres preguntas distintas: quién puede iniciar sesión, en qué suborganización trabaja y qué puede hacer su grupo.

| Si necesita… | Abra… |
| --- | --- |
| Agregar o editar la cuenta de una persona | **Ajustes** → **Usuarios**; luego lea [Usuarios](users/README.md). |
| Organizar el acceso entre unidades de la empresa | **Ajustes** → **Suborganizaciones**; luego lea [Suborganizaciones](sub-organizations/README.md). |
| Controlar el acceso por grupo | **Ajustes** → **Grupos y Permisos**; luego lea [Grupos y Permisos](groups-and-permissions/README.md). |

Si un usuario no puede ver un documento o una acción, revise primero su cuenta y su organización. Después revise los permisos del grupo correspondiente. Utilice una cuenta de prueba que no sea de administrador para confirmar el acceso que tendrá realmente un usuario normal antes de cambiar una organización real.
