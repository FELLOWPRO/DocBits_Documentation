## Para adicionar um novo grupo ou alterar as permissões de um grupo existente, você pode fazer o seguinte:

* **Navegue até Configurações do Grupo:** Faça login na sua conta de administrador e vá para Configurações do Grupo no painel de administração.

<figure><img src="../../../../../.gitbook/assets/groups_settings_overview.png" alt="Visão geral das configurações de grupos"><figcaption></figcaption></figure>

Esta janela será aberta:

<figure><img src="../../../../../.gitbook/assets/groups_list_overview.png" alt="Visão geral da lista de grupos"><figcaption></figcaption></figure>

* **Clique no botão + Novo:** Se você deseja adicionar um novo grupo, clique no botão + Novo para iniciar o processo de adição de um novo grupo.

<figure><img src="../../../../../.gitbook/assets/add_new_group_button.png" alt="Botão para adicionar novo grupo"><figcaption></figcaption></figure>

* **Preencha a tabela:** Forneça o nome do grupo e uma descrição do grupo.
* **Salve os detalhes:** Depois de preencher o nome e a descrição do grupo, clique no botão "Salvar".

<figure><img src="../../../../../.gitbook/assets/new_group_form_save.png" alt="Formulário de novo grupo com botão Salvar"><figcaption></figcaption></figure>

## Editando Grupos:

* **Editar Grupos:** Para editar grupos, clique em "editar", aqui você pode alterar o nome do grupo.

<figure><img src="../../../../../.gitbook/assets/edit_group_button.png" alt="Botão para editar grupo"><figcaption></figcaption></figure>

<figure><img src="../../../../../.gitbook/assets/edit_group_form.png" alt="Formulário de edição de grupo"><figcaption></figcaption></figure>

* **Ativar Grupos e permissões:** Para tornar o grupo visível, "Grupos e permissões" devem ser ativados.

<figure><img src="../../../../../.gitbook/assets/enable_groups_and_permissions_toggle.png" alt="Alternância para ativar Grupos e permissões"><figcaption></figcaption></figure>

* **Verifique os resultados:** Após salvar, revise os resultados para garantir que o grupo foi adicionado, editado ou atualizado com sucesso.
