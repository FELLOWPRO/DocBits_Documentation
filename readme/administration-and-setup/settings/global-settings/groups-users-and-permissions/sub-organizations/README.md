# Suborganizações

<figure><img src="../../../../../.gitbook/assets/sub_organizations.png" alt="Suborganizações"><figcaption><p>Página de Suborganizações</p></figcaption></figure>

As suborganizações permitem criar uma estrutura hierárquica no DocBits para gerir documentos, utilizadores e fluxos de trabalho em diferentes departamentos, equipas ou entidades.

## Principais vantagens

* **Organização estruturada**: agrupe utilizadores e documentos por departamento, localização ou unidade de negócio.
* **Permissões granulares**: controle quais utilizadores podem aceder aos documentos de cada suborganização.
* **Fluxos de trabalho separados**: cada suborganização pode ter as suas próprias regras e configurações de processamento de documentos.
* **Relatórios**: gere relatórios e análises por suborganização.

## Lista de suborganizações

A tabela apresenta todas as suborganizações existentes com:

| Coluna | Descrição |
|--------|-------------|
| **Nome** | O nome da suborganização. |
| **Descrição** | Uma breve descrição da finalidade da suborganização. |
| **Ações** | Menu com opções para gerir utilizadores, editar ou eliminar a suborganização. |

Utilize a barra de **pesquisa** para encontrar rapidamente suborganizações pelo nome.

## Criar uma nova suborganização

1. Clique no botão **+ Novo** no canto superior direito.
2. Introduza um **Nome** e, opcionalmente, uma **Descrição**.
3. Clique em **Guardar** para criar a suborganização.

## Opção «Mostrar organização cruzada» (Cross)

Quando ativada (interruptor na parte superior da página), os utilizadores podem aceder aos documentos de todas as suborganizações a partir de uma única vista.

### Como utilizar as suborganizações cruzadas

1. Aceda ao **painel (Dashboard)**.
2. No canto superior direito, onde é possível alternar entre suborganizações, selecione **Cross**.
3. A página é recarregada e apresenta os documentos de todas as suborganizações.
4. Para voltar à vista de uma única suborganização, desmarque a opção **Cross**.

Isto é útil para administradores que precisam de uma visão centralizada de todos os documentos da organização.
