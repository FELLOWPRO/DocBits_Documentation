# Wie man eine Unterorganisation erstellt

## Eine neue Unterorganisation erstellen:

<div data-full-width="false">

<figure><img src="../../../../../.gitbook/assets/sub_organizations_list_overview_2.png" alt="Übersicht der Unterorganisationen"><figcaption></figcaption></figure>

</div>

Klicken Sie auf die Schaltfläche `+ NEU`.

<figure><img src="../../../../../.gitbook/assets/sub_organization_new_button.png" alt="Schaltfläche Neue Unterorganisation" width="97"><figcaption></figcaption></figure>

Das folgende Menü wird angezeigt:

<figure><img src="../../../../../.gitbook/assets/create_sub_organization_form.png" alt="Formular zum Erstellen einer Unterorganisation" width="375"><figcaption></figcaption></figure>

Geben Sie die Details der zu erstellenden Unterorganisation ein – Name und Beschreibung – und klicken Sie anschließend auf die Schaltfläche `SPEICHERN`. Die neu erstellte Unterorganisation finden Sie danach am Ende der Liste der vorhandenen Unterorganisationen.

## Unterorganisationen bearbeiten

<figure><img src="../../../../../.gitbook/assets/edit_sub_organization_icon.png" alt="Menü zum Bearbeiten einer Unterorganisation" width="161"><figcaption></figcaption></figure>

**Benutzer verwalten:**

<figure><img src="../../../../../.gitbook/assets/manage_users_in_sub_organization.png" alt="Benutzer in einer Unterorganisation verwalten" width="375"><figcaption></figcaption></figure>

* **Benutzer hinzufügen:** Administratoren können neue Benutzerkonten erstellen und sie der passenden Unterorganisation zuweisen.
* **Rollen und Berechtigungen zuweisen:** Administratoren können die Rollen und Berechtigungen für Benutzer innerhalb einer Unterorganisation festlegen. Dazu gehört in der Regel die Vergabe von Zugriffsrechten auf bestimmte Dokumente, Ordner oder Funktionen im Dokumentenmanagementsystem.
* **Profildetails verwalten:** Administratoren können die Profildetails von Benutzern innerhalb der Unterorganisation bearbeiten, z. B. Kontaktinformationen oder die Abteilungszugehörigkeit. Dies ermöglicht eine aktuelle und korrekte Verwaltung der Benutzerdaten.

<figure><img src="../../../../../.gitbook/assets/add_user_to_sub_organization_modal.png" alt="Benutzer zu einer Unterorganisation hinzufügen" width="375"><figcaption></figcaption></figure>

Sie können der Organisation einen neuen Benutzer hinzufügen und dabei wählen, ob der Benutzer aus anderen Gruppen entfernt werden soll.

**Benutzer bearbeiten:**

<figure><img src="../../../../../.gitbook/assets/edit_user_in_sub_organization.png" alt="Benutzer in einer Unterorganisation bearbeiten" width="375"><figcaption></figcaption></figure>

* **Einstellungen der Unterorganisation bearbeiten:** Administratoren können die Einstellungen und Eigenschaften einer Unterorganisation bearbeiten, einschließlich Name, Beschreibung oder Hierarchieebene im System.
* **Benutzerdetails bearbeiten:** Administratoren können die Details einzelner Benutzer innerhalb einer Unterorganisation bearbeiten, beispielsweise um deren Zugriffsrechte anzupassen oder Kontaktinformationen zu aktualisieren.

**Benutzer löschen:**

* **Unterorganisationen löschen:** Administratoren können Unterorganisationen auch löschen, wenn diese nicht mehr benötigt werden oder eine Umstrukturierung erforderlich ist. Beim Löschen einer Unterorganisation müssen Administratoren sicherstellen, dass alle zugehörigen Benutzer und Daten ordnungsgemäß behandelt werden.

Diese Verwaltungsfunktionen ermöglichen es Administratoren, die Benutzerkonten und Organisationsstrukturen innerhalb eines Dokumentenmanagementsystems effektiv zu verwalten und an die sich ändernden Anforderungen und Prozesse des Unternehmens anzupassen.
