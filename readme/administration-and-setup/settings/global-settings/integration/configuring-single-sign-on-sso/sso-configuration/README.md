# Configuración SSO de Infor

Estas guías describen cómo conectar DocBits con el SSO de Infor OS según la versión del portal de su organización:

* [V1](v1.md): portal clásico de Infor OS.
* [V2](v2.md): Infor OS Portal V2, con tile de DocBits en el portal.
* [Azure SSO](azure-sso.md): inicio de sesión con Microsoft sin contraseña.

Los valores de DocBits para todos los pasos están en **Ajustes → Integración y SSO**, en la sección **Configuración del proveedor de servicios SSO**.
