# Konfiguracija Infor SSO

Ova uputstva opisuju kako da povežete DocBits sa Infor OS SSO prema verziji portala vaše organizacije:

* [V2](v2.md): Infor OS Portal V2, sa DocBits pločicom u portalu.

Sve DocBits vrednosti za korake nalaze se u **Podešavanja → Integracija i SSO**, u sekciji **Podešavanja SSO provajdera usluga**.
