# V1 : SSO Infor Ming.le Portal

Ce guide concerne **Infor Ming.le Portal V1** avec LN ou une interface M3 plus ancienne. Si votre locataire utilise un Infor OS Portal plus récent, demandez à votre administrateur Infor quelle procédure de fédération s'applique avant d'utiliser ces étapes. Vous devez disposer d'un accès administrateur à la fois à votre locataire Infor et à votre organisation DocBits. Conservez une connexion administrateur existante tant qu'un utilisateur de test ne peut pas se connecter via SSO.

## 1. Récupérer les valeurs du fournisseur de services DocBits

Connectez-vous à l'environnement et à l'organisation DocBits corrects. Ouvrez **Paramètres → Intégration et SSO → Paramètres du fournisseur de services SSO**. Copiez l'**ID d'entité**, l'**URL SSO** et l'**URL SLO** à l'aide des boutons situés à côté de chaque valeur. Utilisez **Télécharger le certificat** si Infor exige le certificat de signature DocBits. **Télécharger les métadonnées** exporte les métadonnées *fournisseur de services* de DocBits. Les URL Sandbox de cet exemple sont spécifiques à l'organisation de test ; ne les copiez pas dans un autre locataire.

![Paramètres actuels du fournisseur de services SSO DocBits dans l'organisation de test Sandbox, affichant l'ID d'entité, l'URL SSO, l'URL SLO et les boutons de téléchargement.](../../../../../../.gitbook/assets/dbdc-328-infor-v1-sso-settings-fr.png)

## 2. Enregistrer DocBits dans Infor

Dans votre locataire **Infor Ming.le Portal V1**, ouvrez **User Management → Security Administration → Service Provider**, puis ajoutez un fournisseur de services SAML pour DocBits. Votre administrateur Infor doit confirmer qu'il s'agit du bon écran et du bon type d'application pour votre locataire. Associez les valeurs comme suit :

| Champ du fournisseur de services Infor | Valeur provenant de DocBits |
| --- | --- |
| ID d'entité | ID d'entité |
| SSO Endpoint | URL SSO (point de consommation d'assertion) |
| SLO Endpoint | URL SLO (point de déconnexion) |
| Certificat de signature | Certificat obtenu via Télécharger le certificat, si requis |
| Format / correspondance Name ID | Adresse e-mail, après avoir confirmé que l'identifiant utilisateur Infor correspond à l'utilisateur DocBits |

**Ne collez pas l'URL SLO dans SSO Endpoint.** Ce sont des points de terminaison différents. Enregistrez le fournisseur de services. Le [guide de configuration des fournisseurs de services d'Infor](https://docs.infor.com/inforos/2026.09/en-us/useradminlib_cloud/minceag_cloud_osm/vxs1562872848076.html) décrit les rôles des champs et l'action **Export SAML Metadata**. Les menus et autorisations d'Infor peuvent varier selon le locataire et la version.

## 3. Importer les métadonnées du fournisseur d'identité Infor dans DocBits

Dans Infor, ouvrez le fournisseur de services DocBits enregistré, choisissez **View** pour **Identity Provider Information**, puis **Export SAML Metadata**. Ce fichier contient les détails du *fournisseur d'identité Infor*. Il est différent des métadonnées du fournisseur de services DocBits téléchargées à l'étape 1.

Dans DocBits, revenez à **Paramètres → Intégration et SSO → Paramètres du fournisseur de services d'identité**. Saisissez l'**ID du locataire** Infor, choisissez le fichier XML des métadonnées Infor sous **Téléverser un fichier**, puis sélectionnez **Configurer**. Confirmez l'identifiant du locataire et le XML avec votre administrateur Infor avant d'enregistrer ; la capture Sandbox ne représente pas votre locataire de production.

## 4. Vérifier la connexion

Attribuez un utilisateur Infor approprié à l'application DocBits dans Ming.le et testez la connexion avec cet utilisateur. Vérifiez que l'identifiant e-mail de l'utilisateur correspond à un utilisateur DocBits. Gardez la session administrateur d'origine ouverte pendant le test. Si la connexion ou la déconnexion échoue, comparez les points de terminaison du fournisseur de services, les métadonnées Infor, le certificat et la correspondance Name ID avec les deux administrateurs.

**Périmètre de vérification :** L'écran DocBits et la navigation ci-dessus ont été vérifiés dans l'organisation de test Sandbox. Aucun locataire Infor n'était disponible pour cette mise à jour, les écrans Infor, l'échange de métadonnées et la connexion réelle n'ont donc pas été testés. Les anciennes captures Infor ont été supprimées car leur état actuel n'a pas pu être vérifié ; utilisez la documentation Infor liée et l'administrateur de votre locataire pour son interface réelle.
