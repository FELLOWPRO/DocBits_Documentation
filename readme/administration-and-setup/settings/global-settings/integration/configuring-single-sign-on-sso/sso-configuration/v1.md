# V1

本指南适用于使用 LN 或较旧版 M3 界面的 **Infor Ming.le Portal V1**。如果您的租户使用较新版 Infor OS Portal，请先咨询 Infor 管理员，确认适用的联合身份验证流程，再执行以下步骤。您需要同时拥有 Infor 租户和 DocBits 组织的管理员访问权限。在测试用户能够通过 SSO 登录之前，请保持一个现有的管理员登录会话可用。

## 1. 获取 DocBits 服务提供商值

登录正确的 DocBits 环境和组织。打开 **Settings → Integration & SSO → SSO Service Provider Settings**。使用各值旁边的按钮复制 **Entity ID**、**SSO Url** 和 **SLO Url**。如果 Infor 要求提供 DocBits 签名证书，请使用 **Download Certificate**。**Download Metadata** 导出的是 DocBits _服务提供商_ 元数据。本示例中的 Sandbox URL 仅适用于测试组织；请勿将其复制到其他租户。

## 2. 在 Infor 中注册 DocBits

在您的 **Infor Ming.le Portal V1** 租户中，打开 **User Management → Security Administration → Service Provider**，然后为 DocBits 添加一个 SAML 服务提供商。Infor 管理员应确认该界面和应用程序类型适用于您的租户。按如下方式映射各项值：

| Infor 服务提供商字段 | DocBits 中的值 |
| ---------------------------- | ---------------------------------------------------------------------------------- |
| Entity ID                    | Entity ID                                                                          |
| SSO Endpoint                 | SSO Url（断言使用方端点）                                              |
| SLO Endpoint                 | SLO Url（注销端点）                                                          |
| Signing Certificate          | 如有要求，使用 Download Certificate 获取的证书                                 |
| Name ID Format / Mapping     | 电子邮件地址；请先确认 Infor 用户标识符与 DocBits 用户匹配 |

**请勿将 SLO Url 粘贴到 SSO Endpoint。** 这是两个不同的端点。保存服务提供商。Infor 的[服务提供商配置指南](https://docs.infor.com/inforos/2026.09/en-us/useradminlib_cloud/minceag_cloud_osm/vxs1562872848076.html)介绍了各字段的用途以及 **Export SAML Metadata** 操作。不同租户和版本的 Infor 菜单与权限可能有所不同。

## 3. 将 Infor 身份提供商元数据导入 DocBits

在 Infor 中打开已保存的 DocBits 服务提供商，对 **Identity Provider Information** 选择 **View**，然后选择 **Export SAML Metadata**。此文件包含 _Infor 身份提供商_ 的详细信息，与第 1 步下载的 DocBits 服务提供商元数据不同。

在 DocBits 中，返回 **Settings → Integration & SSO → Identity Service Provider Settings**。输入 Infor **Tenant ID**，在 **Upload file** 下选择 Infor 元数据 XML，然后选择 **Configure**。保存前，请与 Infor 管理员确认租户 ID 和 XML；Sandbox 截图不代表您的生产租户。

## 4. 检查登录

在 Ming.le 中将适当的 Infor 用户分配到 DocBits 应用程序，并使用该用户测试登录。检查用户的电子邮件标识符是否与 DocBits 用户匹配。测试期间请保持原有管理员会话打开。如果登录或注销失败，请与双方管理员一起核对服务提供商端点、Infor 元数据、证书和 Name ID 映射。

**验证范围：** 已在 English Sandbox 测试组织中检查上述 DocBits 界面和导航。本次更新期间无法使用 Infor 租户，因此未测试 Infor 界面、元数据交换和实际登录。由于无法验证此前 Infor 截图所示界面当前的状态，已将这些截图移除；有关 Infor 实时界面，请参阅链接的 Infor 文档并咨询您所在租户的管理员。
