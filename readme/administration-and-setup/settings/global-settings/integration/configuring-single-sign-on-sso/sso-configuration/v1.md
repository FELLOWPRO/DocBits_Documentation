# V1 : SSO Infor Ming.le Portal

Ce guide s'adresse à **Infor Ming.le Portal V1** avec LN ou une ancienne interface M3. Si votre tenant utilise un Infor OS Portal plus récent, demandez à votre administrateur Infor quelle procédure de fédération s'applique avant d'utiliser ces étapes. Vous avez besoin d'un accès administrateur à la fois à votre tenant Infor et à votre organisation DocBits. Gardez une connexion administrateur existante disponible jusqu'à ce qu'un utilisateur de test puisse se connecter via le SSO.

## 1. Obtenir les valeurs du fournisseur de services DocBits

Connectez-vous à l'environnement et à l'organisation DocBits corrects. Ouvrez **Paramètres → Intégration et SSO → Paramètres du fournisseur de services SSO**. Copiez l'**Entity ID**, l'**URL SSO** et l'**URL SLO** à l'aide des boutons situés à côté de chaque valeur. Utilisez **Télécharger le certificat** si Infor exige le certificat de signature de DocBits. **Télécharger les métadonnées** exporte les métadonnées du *fournisseur de services* DocBits. Les URL Sandbox de cet exemple sont propres à l'organisation de test ; ne les copiez pas dans un autre tenant.

## 2. Enregistrer DocBits dans Infor

Dans votre tenant **Infor Ming.le Portal V1**, ouvrez **User Management → Security Administration → Service Provider**, puis ajoutez un fournisseur de services SAML pour DocBits. Votre administrateur Infor doit confirmer qu'il s'agit bien de l'écran et du type d'application corrects pour votre tenant. Faites correspondre les valeurs comme suit :

| Champ du fournisseur de services Infor | Valeur issue de DocBits |
| --- | --- |
| Entity ID | Entity ID |
| SSO Endpoint | URL SSO (point de terminaison du consommateur d'assertions) |
| SLO Endpoint | URL SLO (point de terminaison de déconnexion) |
| Signing Certificate | Certificat obtenu via Télécharger le certificat, si nécessaire |
| Name ID Format / Mapping | Adresse e-mail, après avoir vérifié que l'identifiant utilisateur Infor correspond à l'utilisateur DocBits |

**Ne collez pas l'URL SLO dans SSO Endpoint.** Ce sont deux points de terminaison différents. Enregistrez le fournisseur de services. Le [guide de configuration du fournisseur de services](https://docs.infor.com/inforos/2026.09/en-us/useradminlib_cloud/minceag_cloud_osm/vxs1562872848076.html) d'Infor décrit le rôle de chaque champ et l'action **Export SAML Metadata**. Les menus et les autorisations d'Infor peuvent varier selon le tenant et la version.

## 3. Importer les métadonnées du fournisseur d'identité Infor dans DocBits

Dans Infor, ouvrez le fournisseur de services DocBits enregistré, choisissez **View** pour **Identity Provider Information**, puis **Export SAML Metadata**. Ce fichier contient les informations du *fournisseur d'identité Infor*. Il est différent des métadonnées du fournisseur de services DocBits téléchargées à l'étape 1.

Dans DocBits, retournez à **Paramètres → Intégration et SSO → Paramètres du fournisseur de services d'identité**. Saisissez le **Tenant ID** Infor, choisissez le fichier XML de métadonnées Infor sous **Charger un fichier**, puis sélectionnez **Configurer**. Confirmez le tenant ID et le fichier XML auprès de votre administrateur Infor avant d'enregistrer ; la capture d'écran Sandbox ne représente pas votre tenant de production.

## 4. Vérifier la connexion

Affectez un utilisateur Infor approprié à l'application DocBits dans Ming.le et testez la connexion avec cet utilisateur. Vérifiez que l'identifiant e-mail de l'utilisateur correspond à un utilisateur DocBits. Gardez la session administrateur d'origine ouverte pendant vos tests. Si la connexion ou la déconnexion échoue, comparez avec les deux administrateurs les points de terminaison du fournisseur de services, les métadonnées Infor, le certificat et le mappage du Name ID.

**Périmètre de vérification :** L'écran DocBits et la navigation ci-dessus ont été vérifiés dans l'organisation de test Sandbox en anglais. Aucun tenant Infor n'était disponible pour cette mise à jour ; les écrans Infor, l'échange de métadonnées et la connexion réelle n'ont donc pas été testés. Les anciennes captures d'écran d'Infor ont été supprimées car leur état actuel ne pouvait pas être vérifié ; utilisez la documentation Infor liée et l'administrateur de votre tenant pour son interface réelle.
