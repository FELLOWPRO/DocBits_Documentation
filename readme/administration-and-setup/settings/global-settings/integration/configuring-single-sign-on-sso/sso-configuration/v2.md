# V2: Infor OS Portal SSO

Use este guia se a sua organização inicia o DocBits a partir do **Infor OS Portal V2**. É necessário um administrador tanto do Infor quanto do DocBits. Mantenha uma sessão de administrador do DocBits aberta enquanto testa o SSO. Os nomes de menus e campos do Infor dependem da versão do tenant; confirme-os com o seu administrador do Infor.

## 1. Obtenha os valores SAML do DocBits

Na organização correta do DocBits, abra **Settings → Integration & SSO → SSO Service Provider Settings**. Copie **Entity ID**, **SSO Url** e **SLO Url**. Use **Download Certificate** se o formulário de service provider do Infor exigir o certificado de assinatura. **Download Metadata** é o XML do *service provider* do DocBits; ele não é o metadado do identity provider do Infor usado na etapa 3. As URLs na imagem do Sandbox pertencem apenas a esta organização de teste.

![Tela atual de Integration & SSO do DocBits na organização de teste Sandbox em inglês, com Entity ID, SSO Url e SLO Url do service provider e downloads de certificado/metadados.](../../../../../../.gitbook/assets/dbdc-182-infor-v2-sso-settings-en.png)

## 2. Adicione o DocBits como service provider no Infor

No Infor OS Portal, abra **OS → Security → Security Administration → Service Provider**, se esse for o caminho no seu tenant. Adicione um service provider SAML e use o seguinte mapeamento:

| Campo do Infor | Valor do DocBits |
| --- | --- |
| Entity ID | Entity ID |
| SSO Endpoint | SSO Url, o endpoint do assertion consumer |
| SLO Endpoint | SLO Url, o endpoint de logout |
| Signing Certificate | Download Certificate, se necessário |
| Name ID Format / Mapping | Endereço de e-mail, depois de verificar se ele corresponde ao usuário do DocBits |

O guia anterior orientava os usuários a colocar a **SLO Url** em **SSO Endpoint**. Isso está incorreto: cada URL vai no campo correspondente. Salve o service provider. O [guia de service provider](https://docs.infor.com/inforos/latest/en-us/useradminlib_cloud/inforos_security/jho1449385888462.html) da Infor explica a navegação e a função necessária; o [guia de campos SAML](https://docs.infor.com/inforos/2026.09/en-us/useradminlib_cloud/mineeag/min1772650388038.html) explica o papel de cada endpoint.

## 3. Importe os metadados do identity provider do Infor

Abra o service provider salvo no Infor e use **View → Export SAML Metadata** para o identity provider do Infor. De volta ao DocBits, abra **Settings → Integration & SSO → Identity Service Provider Settings**. Informe o **Tenant ID** do Infor, escolha o XML do Infor em **Upload file** e selecione **Configure**. Confirme o Tenant ID e os metadados com o seu administrador do Infor. Não faça aqui o upload do XML do service provider do DocBits da etapa 1.

## 4. Adicione um tile do DocBits no Infor OS Portal

No Infor OS Portal, abra **Portal → Applications → Add Application**. Registre o DocBits como uma aplicação não Infor para o seu tenant, informe um nome de exibição, um ícone e um Logical ID exclusivo, e defina a **URL da aplicação** como a sua URL normal de login ou de inicialização do DocBits. A URL da aplicação do portal abre a interface do usuário; ela **não** é o endpoint SAML SSO/ACS da etapa 2. Siga o [guia de aplicações não Infor](https://docs.infor.com/inforos/latest/en-us/useradminlib_cloud/inforospag/lsm1436532874794.html) da Infor para o formulário atual, as opções de navegação e as permissões. Conceda ao usuário de teste acesso à aplicação do portal.

## 5. Verifique com um usuário

Saia da sessão em uma sessão de navegador separada, abra o tile do DocBits a partir do Infor e confirme que o e-mail do usuário atribuído corresponde à conta e à organização corretas do DocBits. Verifique também o logout. Se um dos dois falhar, compare os metadados do Infor, as URLs de SSO/SLO, o certificado, o Name ID e a URL do tile do portal com os dois administradores. Mantenha a sessão original do administrador até o fim do teste.

**Escopo da verificação:** A tela do DocBits acima foi capturada na organização de teste Sandbox em inglês. Nenhum tenant do Infor estava disponível, portanto os menus do portal Infor, a importação de metadados, a criação do tile e o SSO real não foram testados nesta atualização. As antigas imagens da Infor hospedadas externamente, incluindo anexos de e-mail privados, foram removidas; use a documentação da Infor indicada e o administrador do seu tenant para essa interface.
