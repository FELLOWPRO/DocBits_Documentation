# V2: SSO Infor OS Portala

Koristite ovo uputstvo ako vaša organizacija pokreće DocBits iz **Infor OS Portal V2**. Potrebni su i Infor administrator i DocBits administrator. Tokom testiranja SSO-a držite otvorenu sesiju postojećeg DocBits administratora. Nazivi Infor menija i polja zavise od verzije tenanta; potvrdite ih sa svojim Infor administratorom.

## 1. Preuzmite DocBits SAML vrednosti

U tačnoj DocBits organizaciji otvorite **Podešavanja → Integracija i SSO → Podešavanja SSO provajdera usluga**. Kopirajte **ID entiteta**, **SSO URL** i **SLO URL**. Koristite **Preuzmi sertifikat** ako Infor obrazac za provajdera usluga zahteva sertifikat za potpisivanje. **Preuzmi metapodatke** je DocBits XML kao *provajder usluga*; to nisu metapodaci Infor provajdera identiteta koje koristite u koraku 3. URL adrese na slici iz Sandbox-a odnose se samo na ovu test organizaciju.

![Trenutni ekran Integracija i SSO u DocBits-u u engleskoj Sandbox test organizaciji, sa ID-om entiteta provajdera usluga, SSO URL-om, SLO URL-om i preuzimanjima sertifikata i metapodataka.](../../../../../../.gitbook/assets/dbdc-182-infor-v2-sso-settings-en.png)

## 2. Dodajte DocBits kao provajdera usluga u Infor-u

U Infor OS Portalu otvorite **OS → Security → Security Administration → Service Provider** ako je to putanja u vašem tenant-u. Dodajte SAML provajdera usluga i koristite sledeće mapiranje:

| Infor polje | DocBits vrednost |
| --- | --- |
| Entity ID | ID entiteta |
| SSO Endpoint | SSO URL, krajnja tačka za preuzimanje asercija |
| SLO Endpoint | SLO URL, krajnja tačka za odjavu |
| Signing Certificate | Preuzmi sertifikat, ako se traži |
| Name ID Format / Mapping | Imejl adresa, nakon provere da odgovara DocBits korisniku |

Prethodno uputstvo je naložilo korisnicima da unesu **SLO URL** u polje **SSO Endpoint**. To je netačno: svaki URL ide u svoje odgovarajuće polje. Sačuvajte provajdera usluga. Inforov [vodič za provajdere usluga](https://docs.infor.com/inforos/latest/en-us/useradminlib_cloud/inforos_security/jho1449385888462.html) objašnjava navigaciju i potrebnu ulogu; njegov [vodič za SAML polja](https://docs.infor.com/inforos/2026.09/en-us/useradminlib_cloud/mineeag/min1772650388038.html) objašnjava uloge krajnjih tačaka.

## 3. Uvezite metapodatke Infor provajdera identiteta

Otvorite sačuvanog provajdera usluga u Infor-u i izaberite **View → Export SAML Metadata** za Infor provajdera identiteta. U DocBits-u otvorite **Podešavanja → Integracija i SSO → Podešavanja provajdera identiteta**. Unesite Inforov **ID tenanta**, izaberite Infor XML pod **Otpremi fajl**, zatim izaberite **Konfiguriš**. Potvrdite ID tenanta i metapodatke sa svojim Infor administratorom. Ovde nemojte otpremati DocBits XML provajdera usluga iz koraka 1.

## 4. Dodajte DocBits pločicu u Infor OS Portal

U Infor OS Portalu otvorite **Portal → Applications → Add Application**. Registrujte DocBits kao ne-Infor aplikaciju za svoj tenant, navedite prikazni naziv, ikonicu i jedinstveni Logical ID i postavite **URL aplikacije** na uobičajeni DocBits URL za prijavu ili pokretanje. URL aplikacije portala otvara korisnički interfejs; on **nije** SAML SSO/ACS krajnja tačka iz koraka 2. Pratite Inforov [vodič za ne-Infor aplikacije](https://docs.infor.com/inforos/latest/en-us/useradminlib_cloud/inforospag/lsm1436532874794.html) za trenutni obrazac, opcije navigacije i dozvole. Dodelite test korisniku pristup aplikaciji portala.

## 5. Proverite sa jednim korisnikom

U zasebnoj pregledačkoj sesiji odjavite se, otvorite DocBits pločicu iz Infor-a i potvrdite da imejl dodeljenog korisnika vodi na tačan DocBits nalog i organizaciju. Proverite i odjavu. Ako nešto ne uspe, uporedite Infor metapodatke, SSO/SLO URL adrese, sertifikat, Name ID i URL pločice portala sa oba administratora. Zadržite originalnu sesiju administratora dok test nije završen.

**Obim provere:** Gornji DocBits ekran snimljen je u engleskoj Sandbox test organizaciji. Infor tenant nije bio dostupan, pa Infor portni meni, uvoz metapodataka, kreiranje pločice i stvarni SSO nisu testirani u ovom ažuriranju. Stare slike Infor-a hostovane na eksternim servisima, uključujući privatne mejl priloške, uklonjene su; za to sučelje koristite povezanu Infor dokumentaciju i administratora svog tenanta.
