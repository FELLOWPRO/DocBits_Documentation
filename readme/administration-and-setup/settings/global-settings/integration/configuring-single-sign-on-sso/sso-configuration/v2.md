# V2: SSO mit dem Infor OS Portal

Nutzen Sie dieses Handbuch, wenn Ihre Organisation DocBits aus dem **Infor OS Portal V2** aufruft. Erforderlich ist ein Administrator für Infor und DocBits. Halten Sie beim Testen des SSO eine bestehende DocBits-Administrator-Sitzung offen. Die Infor-Menüs und Feldbezeichnungen hängen vom Release des Mandanten ab; bestätigen Sie diese mit Ihrem Infor-Administrator.

## 1. DocBits-SAML-Werte abrufen

Öffnen Sie in der richtigen DocBits-Organisation **Einstellungen → Integration & SSO → SSO-Dienstanbieter-Einstellungen**. Kopieren Sie **Entitäts-ID**, **SSO Url** und **SLO Url**. Nutzen Sie **Zertifikat herunterladen**, falls das Infor-Diensteanbieter-Formular das Unterschriftszertifikat verlangt. **Metadaten herunterladen** ist die DocBits-XML des *Diensteanbieters*; es ist nicht die Infor-Metadaten des Identitätsdienstanbieters aus Schritt 3. Die URLs im Sandbox-Bild gehören nur zu dieser Testorganisation.

![Aktueller DocBits-Bildschirm „Integration & SSO“ in der englischen Sandbox-Testorganisation mit Diensteanbieter-Entitäts-ID, SSO Url, SLO Url sowie Zertifikats- und Metadaten-Download.](../../../../../../.gitbook/assets/dbdc-182-infor-v2-sso-settings-en.png)

## 2. DocBits als Diensteanbieter in Infor hinzufügen

Öffnen Sie im Infor OS Portal – sofern dies in Ihrem Mandanten der Pfad ist – **OS → Security → Security Administration → Service Provider**. Fügen Sie einen SAML-Diensteanbieter hinzu und nutzen Sie die folgende Zuordnung:

| Infor-Feld | DocBits-Wert |
| --- | --- |
| Entity ID | Entitäts-ID |
| SSO Endpoint | SSO Url, der Assertion-Consumer-Endpunkt |
| SLO Endpoint | SLO Url, der Abmelde-Endpunkt |
| Signing Certificate | „Zertifikat herunterladen“, falls erforderlich |
| Name ID Format / Mapping | E-Mail-Adresse, nachdem Sie geprüft haben, dass sie zum DocBits-Benutzer passt |

Die frühere Anleitung wies Benutzer an, die **SLO Url** in das Feld **SSO Endpoint** einzutragen. Das ist falsch: Jede URL gehört in das jeweils zugehörige Feld. Speichern Sie den Diensteanbieter. Infors [Handbuch zum Diensteanbieter](https://docs.infor.com/inforos/latest/en-us/useradminlib_cloud/inforos_security/jho1449385888462.html) erklärt die Navigation und die erforderliche Rolle; das [SAML-Feldhandbuch](https://docs.infor.com/inforos/2026.09/en-us/useradminlib_cloud/mineeag/min1772650388038.html) erklärt die Endpunktrollen.

## 3. Infor-Metadaten des Identitätsdienstanbieters importieren

Öffnen Sie den gespeicherten Diensteanbieter in Infor und nutzen Sie **View → Export SAML Metadata** für den Infor-Identitätsdienstanbieter. Öffnen Sie in DocBits **Einstellungen → Integration & SSO → Einstellungen des Identitätsdienstanbieters**. Geben Sie die Infor-**Tenant ID** ein, wählen Sie die Infor-XML unter **Datei hochladen** und wählen Sie dann **Konfigurieren**. Bestätigen Sie Tenant ID und Metadaten mit Ihrem Infor-Administrator. Laden Sie hier nicht die DocBits-Diensteanbieter-XML aus Schritt 1 hoch.

## 4. DocBits-Kachel im Infor OS Portal hinzufügen

Öffnen Sie im Infor OS Portal **Portal → Applications → Add Application**. Registrieren Sie DocBits als Nicht-Infor-Anwendung für Ihren Mandanten, geben Sie einen Anzeigenamen, ein Symbol und eine eindeutige Logical ID an, und setzen Sie die **Anwendungs-URL** auf Ihre normale DocBits-Anmelde- oder Aufruf-URL. Die Anwendungs-URL des Portals öffnet die Benutzeroberfläche; sie ist **nicht** der SAML-SSO/ACS-Endpunkt aus Schritt 2. Folgen Sie Infors [Handbuch zu Nicht-Infor-Anwendungen](https://docs.infor.com/inforos/latest/en-us/useradminlib_cloud/inforospag/lsm1436532874794.html) für das aktuelle Formular, die Navigationsoptionen und Berechtigungen. Erteilen Sie dem Testbenutzer Zugriff auf die Portal-Anwendung.

## 5. Mit einem Benutzer prüfen

Melden Sie sich in einer separaten Browser-Sitzung ab, öffnen Sie die DocBits-Kachel aus Infor und bestätigen Sie, dass die E-Mail des zugewiesenen Benutzers zum richtigen DocBits-Konto und zur richtigen Organisation führt. Prüfen Sie auch die Abmeldung. Falls eines fehlschlägt, vergleichen Sie Infor-Metadaten, SSO/SLO-URLs, Zertifikat, Name ID und die URL der Portal-Kachel mit den beiden Administratoren. Halten Sie die ursprüngliche Administrator-Sitzung bis zum Abschluss des Tests offen.

**Prüfumfang:** Der DocBits-Bildschirm oben wurde in der englischen Sandbox-Testorganisation aufgenommen. Es war kein Infor-Mandant verfügbar, daher wurden die Infor-Portal-Menüs, der Metadaten-Import, das Anlegen der Kachel und das Live-SSO für dieses Update nicht getestet. Alte extern gehostete Infor-Bilder einschließlich privater Mail-Anhänge wurden entfernt; nutzen Sie für diese Oberfläche die verlinkte Infor-Dokumentation und Ihren Mandanten-Administrator.
