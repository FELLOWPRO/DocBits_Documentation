# V2 : SSO Infor OS Portal

Utilisez ce guide si votre organisation lance DocBits depuis **Infor OS Portal V2**. Un administrateur d'Infor et de DocBits est nécessaire. Gardez une session administrateur DocBits existante ouverte pendant les tests du SSO. Les noms des menus et des champs d'Infor dépendent de la version du tenant ; confirmez-les auprès de votre administrateur Infor.

## 1. Obtenir les valeurs SAML de DocBits

Dans l'organisation DocBits correcte, ouvrez **Paramètres → Intégration et SSO → Paramètres du fournisseur de services SSO**. Copiez l'**Entity ID**, l'**URL SSO** et l'**URL SLO**. Utilisez **Télécharger le certificat** si le formulaire du fournisseur de services Infor exige le certificat de signature. **Télécharger les métadonnées** fournit le XML du *fournisseur de services* DocBits ; ce n'est pas le XML des métadonnées du fournisseur d'identité Infor utilisé à l'étape 3. Les URL de l'image Sandbox n'appartiennent qu'à cette organisation de test.

## 2. Ajouter DocBits comme fournisseur de services dans Infor

Dans Infor OS Portal, ouvrez **OS → Security → Security Administration → Service Provider** si c'est le chemin dans votre tenant. Ajoutez un fournisseur de services SAML et utilisez le mappage suivant :

| Champ Infor | Valeur DocBits |
| --- | --- |
| Entity ID | Entity ID |
| SSO Endpoint | URL SSO, le point de terminaison du consommateur d'assertions |
| SLO Endpoint | URL SLO, le point de terminaison de déconnexion |
| Signing Certificate | Télécharger le certificat, si nécessaire |
| Name ID Format / Mapping | Adresse e-mail, après avoir vérifié qu'elle correspond à l'utilisateur DocBits |

Le guide précédent indiquait de placer l'**URL SLO** dans **SSO Endpoint**. C'est incorrect : chaque URL va dans le champ qui lui correspond. Enregistrez le fournisseur de services. Le [guide du fournisseur de services](https://docs.infor.com/inforos/latest/en-us/useradminlib_cloud/inforos_security/jho1449385888462.html) d'Infor explique la navigation et le rôle requis ; son [guide des champs SAML](https://docs.infor.com/inforos/2026.09/en-us/useradminlib_cloud/mineeag/min1772650388038.html) explique le rôle de chaque point de terminaison.

## 3. Importer les métadonnées du fournisseur d'identité d'Infor

Ouvrez le fournisseur de services enregistré dans Infor puis **View → Export SAML Metadata** pour le fournisseur d'identité Infor. De retour dans DocBits, ouvrez **Paramètres → Intégration et SSO → Paramètres du fournisseur de services d'identité**. Saisissez le **Tenant ID** Infor, choisissez le XML Infor sous **Charger un fichier**, puis sélectionnez **Configurer**. Confirmez le tenant ID et les métadonnées auprès de votre administrateur Infor. Ne chargez pas ici le XML du fournisseur de services DocBits de l'étape 1.

## 4. Ajouter une tuile DocBits dans Infor OS Portal

Dans Infor OS Portal, ouvrez **Portal → Applications → Add Application**. Enregistrez DocBits comme application non-Infor pour votre tenant, indiquez un nom d'affichage, une icône et un Logical ID unique, et définissez l'**URL de l'application** sur votre URL habituelle de connexion ou de lancement de DocBits. L'URL de l'application du portail ouvre l'interface utilisateur ; ce **n'est pas** le point de terminaison SAML SSO/ACS de l'étape 2. Suivez le [guide des applications non-Infor](https://docs.infor.com/inforos/latest/en-us/useradminlib_cloud/inforospag/lsm1436532874794.html) d'Infor pour le formulaire actuel, les options de navigation et les autorisations. Accordez à l'utilisateur de test l'accès à l'application du portail.

## 5. Vérifier avec un utilisateur

Déconnectez-vous dans une session de navigateur distincte, ouvrez la tuile DocBits depuis Infor et vérifiez que l'e-mail de l'utilisateur affecté correspond au bon compte et à la bonne organisation DocBits. Vérifiez aussi la déconnexion. Si l'une des deux échoue, comparez avec les deux administrateurs les métadonnées Infor, les URL SSO/SLO, le certificat, le Name ID et l'URL de la tuile du portail. Gardez la session administrateur d'origine jusqu'à la fin du test.

**Périmètre de vérification :** L'écran DocBits ci-dessus a été capturé dans l'organisation de test Sandbox en anglais. Aucun tenant Infor n'était disponible ; les menus du portail Infor, l'import des métadonnées, la création de la tuile et le SSO réel n'ont donc pas été testés pour cette mise à jour. Les anciennes images Infor hébergées en externe, y compris des pièces jointes d'e-mails privés, ont été supprimées ; utilisez la documentation Infor liée et l'administrateur de votre tenant pour cette interface.
