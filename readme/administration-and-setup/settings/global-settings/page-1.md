**Passen Sie Ihren Filter an**

Navigieren Sie zum Bereich „Filter"

![](https://lh7-us.googleusercontent.com/aEOmeKPrkuBe0aSRJKDi5QZ1UBaTjuq0xdfRkJWv78k6XZ42QKYccjaTRXVjrNPmn86-vTeKSNWmWuReYvn-ieD3A6aMoi\_sVKTKSKMy992Dz-YXVmOSIHRsTTHeU50b4nwyLbwVWlG9F\_3D6fO-GPU)

Um einen benutzerdefinierten Filter zu erstellen, wählen Sie unter „Stil des Statusfilters" die Option CUSTOM aus.

Darunter können Sie die verschiedenen Status auswählen, die ein Dokument haben kann, um Ihren benutzerdefinierten Filter zu erstellen. Sobald Sie auf ANWENDEN klicken, ist dieser benutzerdefinierte Filter im Dashboard aktiv.
