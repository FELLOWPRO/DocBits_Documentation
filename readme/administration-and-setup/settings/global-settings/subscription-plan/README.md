# Plan subskrypcji

<figure><img src="../../../../.gitbook/assets/subscriptions_overview.png" alt="Plan subskrypcji"><figcaption><p>Strona Plan subskrypcji</p></figcaption></figure>

Strona **Plan subskrypcji** zapewnia pełny przegląd Twojej subskrypcji DocBits w jednym miejscu: sam plan, subskrypcje aplikacji i funkcji włączone dla Twojej organizacji oraz zużycie tokenów. Otwórz ją z **Ustawienia → Organizacja i dostęp → Plan subskrypcji**.

## Plan subskrypcji

Pierwsza karta przedstawia Twoją subskrypcję DocBits — liczbę pozostałych dni oraz daty rozpoczęcia i zakończenia — wraz z bieżącymi licznikami dla Twojej organizacji:

| Karta | Opis |
|------|-------------|
| **DocBits** | Pozostałe dni oraz data rozpoczęcia i zakończenia subskrypcji. |
| **Użytkownicy** | Liczba użytkowników w Twojej organizacji. |
| **Suborganizacja** | Liczba suborganizacji. |
| **Dostawcy** | Liczba dostawców. |

## Subskrypcje funkcji

<figure><img src="../../../../.gitbook/assets/subscriptions_feature_subscriptions.png" alt="Subskrypcje funkcji"><figcaption></figcaption></figure>

Ta sekcja wymienia każdą aplikację i funkcję DocBits oraz wskazuje, czy jest włączona dla Twojej organizacji.

| Kolumna | Opis |
|--------|-------------|
| **Aplikacja** | Aplikacja lub funkcja DocBits (np. AI Workforce, Operator, DocFlow, AI Search, BOD Ingestion, SQL BI Connector). |
| **Subskrypcja** | Wykupiony plan dla danej aplikacji. |
| **Status** | **Aktywna**, **Anulowanie** (aktywna do daty zakończenia, potem kończy się) lub **Brak**, gdy aplikacja nie jest subskrybowana. |
| **Początek / Koniec** | Okres subskrypcji. |
| **Pozostałe dni** | Dni do daty zakończenia. |
| **Akcje** | Menu akcji dla danej aplikacji. |

## Wykorzystanie subskrypcji

<figure><img src="../../../../.gitbook/assets/subscriptions_usage.png" alt="Wykorzystanie subskrypcji"><figcaption></figcaption></figure>

Monitoruj wykorzystanie tokenów i przepływów pracy w wybranym okresie. Użyj przycisku **Wybierz**, aby wybrać zakres dat.

| Kolumna | Opis |
|--------|-------------|
| **Typ** | Kategoria wykorzystania — Dokument, Przepływ pracy, Zaawansowany przepływ pracy lub DocNet. |
| **Od / Do** | Okres, którego dotyczy raportowane wykorzystanie. |
| **Wykorzystane tokeny** | Tokeny zużyte w okresie. |
| **Pozostałe tokeny** | Tokeny dostępne w okresie. |
