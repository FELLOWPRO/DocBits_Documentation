# 检查数据同步

找不到供应商、采购订单或其他主数据时，使用此概览检查当前组织各数据类型记录的同步时间。它不显示每条导入记录的内容。

## 操作步骤

1. 确认目标组织、相关子组织及 ERP 来源公司。
2. 打开**设置 → 活动日志 → 数据同步**。较旧界面将其放在日志设置下。
3. 在 **Data Type** 列找到相关类型，按自己的日期格式读取 **Last Synchronization Time**。最新记录排在前面。
4. 将该时间与来源中预期变更的时间比较。供应商刚更新，并不代表采购订单也已更新。
5. 在相应主数据或采购订单视图中查找缺失标识，核对公司、供应商/订单号及行标识。
6. 检查导入通道及日志，包括来源消息、目标组织、映射和响应。在对应集成中修复原因；本概览没有启动或重试同步的按钮。
7. 修正并更新后，刷新概览，重新打开相关查找或单据，同时确认时间和实际记录值。

## 如何判断

| 现象 | 下一步检查 |
| --- | --- |
| 没有记录 | 检查组织、导入配置及是否记录过同步。空列表不代表同步成功。 |
| 某一类型过旧 | 单独追踪该类型的数据流，不要以其他记录的新时间作判断。 |
| 显示数据过旧警告 | 当前警告可在列表为空或所有更新时间均超过两周时出现。业务可能要求远高于此标准的时效。 |
| 时间很新但记录缺失 | 检查来源范围、标识、消息内容、映射与响应。时间戳不能证明数据完整。 |

向支持人员提供环境、组织、数据类型、相关标识、预期变更时间、准确错误或跟踪 ID，以及经过必要脱敏的相关证据。
