# Find documentation with the Settings Assistant

The Settings Assistant helps you find the right DocBits help page while you work in **Settings**. You can ask about the page you are viewing or another setting. Its answers can include links to the relevant documentation, so you can check the full instructions yourself.

{% hint style="info" %}
The assistant appears only when it has been enabled for your organization. If you do not see it, ask your DocBits administrator.
{% endhint %}

## Ask about a setting

1. Open **Settings** and go to the area you want help with.
2. If the assistant is hidden, select **Show Assistant** in the settings sidebar.
3. Select one of the suggested questions for the current page, or write your own question in the message field and send it. For example: “Where can I change the invoice validation rules?”
4. Read the answer and open its documentation link for the full procedure. A linked page may contain screenshots and related steps.

If you are already chatting, **Help with this page** asks about the settings page currently open. You can move to another settings page and use it again without starting a new conversation. Close the panel with its close control or <kbd>Esc</kbd> when you need more space.

## Get a useful answer

Mention the setting or the task you want to complete. For example:

* “How do I add a user to this organization?”
* “Where do I configure email import for invoices?”
* “What does this document type setting change?”

If an answer has no useful source, try a more specific question or search [DocBits Documentation](https://docs.docbits.com) directly. For help with your organization's configuration, contact your administrator or DocBits support.

The assistant searches **public DocBits help pages**. It does not search your organization's uploaded invoices or other business documents. To search those, see [Fulltext Search](../document-processing/module/fulltext-search.md).

Learn more about [how the documentation search stays current](documentation-search.md).
