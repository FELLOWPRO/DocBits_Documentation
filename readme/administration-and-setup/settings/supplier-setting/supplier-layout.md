此页面列出供应商用户和供应商管理所用的布局。使用标题和文档名称找到相关布局，再打开布局编辑器调整字段、位置及必填信息。

**供应商字段**用于查看可用字段；**新的**用于开始创建布局。新建或保存会更改组织配置，请先确认要使用的文档类型。截图展示列表入口，未展示已完成的布局编辑。
