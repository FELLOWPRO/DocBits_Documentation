# Lieferantenberechtigungen

### Lieferantengruppe

<figure><img src="../../../.gitbook/assets/supplier_group.png" alt="Lieferantengruppe"><figcaption><p>Seite „Lieferantengruppe“</p></figcaption></figure>

Verwalten Sie Lieferantengruppen, um Lieferanten nach Typ, Region oder Rolle zu kategorisieren. Jede Gruppe hat einen **Group API Name** (für Integrationen) und einen **Group Name** (Anzeigename).

Klicken Sie auf **+ New**, um eine Gruppe anzulegen. Über das Dreipunkt-Menü in jeder Zeile können Sie sie bearbeiten oder löschen.

### Zuordnung von Benutzern zu Lieferantengruppen

<figure><img src="../../../.gitbook/assets/user_supplier_group_mapping.png" alt="Zuordnung von Benutzern zu Lieferantengruppen"><figcaption><p>Seite „Zuordnung von Benutzern zu Lieferantengruppen“</p></figcaption></figure>

Weisen Sie Benutzer Lieferantengruppen zu, um zu steuern, welche Mitarbeiter auf bestimmte Lieferanten zugreifen und diese verwalten dürfen. Jede Gruppe wird als aufklappbarer Bereich angezeigt, der die zugewiesenen Benutzer und die Anzahl der Mitglieder auflistet.

Klicken Sie innerhalb einer Gruppe auf **+ New**, um eine Benutzerzuordnung hinzuzufügen. Über das Dreipunkt-Menü können Sie eine Zuordnung entfernen.
