# Orientierung im neuen Layout

Diese Seite ist eine kurze Orientierung für das aktuelle DocBits-Layout — wo Sie was finden, wie die Navigation funktioniert und wie Sie die neuen Hilfe-Werkzeuge einsetzen. Nutzen Sie sie als Nachschlagewerk, wenn ein Bildschirm anders aussieht als gewohnt oder Sie eine Einstellung nicht sofort finden.

## Die Seitenleiste

Die Hauptseitenleiste listet jeden Bereich von DocBits, für den Sie eine Berechtigung haben. Es gibt zwei Möglichkeiten, sie zu steuern:

* **Mini-Modus** — klicken Sie oben in der Seitenleiste auf den Umschalter, um sie auf reine Symbole zu reduzieren. Fahren Sie mit der Maus über ein Symbol, um seine Bezeichnung zu lesen. Die Seitenleiste merkt sich, ob sie zuletzt aufgeklappt oder eingeklappt war.
* **Anpassen** — unten in der aufgeklappten Seitenleiste finden Sie den Eintrag **Anpassen**. Damit ordnen Sie das Menü um, blenden ungenutzte Einträge aus oder heften häufig geöffnete oben an.

Die vollständige Anleitung für Anordnen, Ausblenden und Anheften finden Sie unter [Anpassbare Seitenleiste](../../end-user-and-partner-section/end-user-section/customizable-sidebar.md).

## Wo Einstellungen jetzt liegen

Das Menü Einstellungen ist nach Absicht statt nach Datenmodell gruppiert. Wenn Sie eine Einstellung suchen, sich aber nicht erinnern, wo sie war, probieren Sie die passende Gruppe unten:

| Sie suchen … | Öffnen Sie Einstellungen → |
|---|---|
| Firmenname, Logo, Zeitzone, App-Farbe | Unternehmen & Benutzer → Unternehmensinformationen |
| Benutzer, Gruppen, Berechtigungen | Unternehmen & Benutzer → Gruppen, Benutzer & Berechtigungen |
| API-Schlüssel, ERP-Verbindungen, Export-Konfigurationen | Integration |
| Dokumenttypen, Felder, Skripte, EDI, Modelltraining | Dokumenttypen |
| OCR-Einstellungen, Entscheidungsbäume, Wertelisten, Regelmanager | Dokumentenverarbeitung |
| Zugriffs-Audit, Analyse, Volltextindex, Ereignisprotokoll | Logging & Suche |
| Lieferantenportal, Watchdog | Einrichtung |

Innerhalb jeder Gruppe sind die am häufigsten genutzten Seiten oben angeordnet.

## Lange Einstellungsseiten — Anker-Navigation

Einstellungsseiten mit vielen Abschnitten (etwa Globale Einstellungen oder die Konfiguration eines Dokumenttyps) zeigen im Seitenkopf eine Liste mit Anker-Links. Klicken Sie auf einen Anker, um zu diesem Abschnitt zu springen. Die URL aktualisiert sich beim Scrollen, sodass der Link zu einem bestimmten Abschnitt kopiert oder als Lesezeichen gespeichert werden kann.

## Dokumentation während der Arbeit — Hilfe-Symbole

Auf den meisten Einstellungsseiten, Dialogen und Werkzeug-Bildschirmen sehen Sie jetzt ein kleines **?**-Symbol im Kopfbereich.

<figure><img src="../../.gitbook/assets/ui-redesign-help-icon.png" alt="Hilfe-Symbol im Seitenkopf"><figcaption><p>Das Hilfe-Symbol öffnet die passende Dokumentationsseite in einem neuen Tab.</p></figcaption></figure>

Ein Klick öffnet die passende Seite auf `docs.docbits.com` in einem neuen Tab — ohne die Dokumentation nach der richtigen Seite durchsuchen zu müssen. Das Symbol berücksichtigt Ihre Oberflächensprache und öffnet die übersetzte Dokumentationsseite, sofern eine existiert; andernfalls weicht es auf Englisch aus.

## Anmelden

Der Anmeldebildschirm, das Zurücksetzen des Passworts und die SSO-Einstiege (Microsoft 365, Google, Infor OS) verwenden dasselbe Layout wie der Rest von DocBits. Fehler erscheinen direkt unter dem Feld, das sie ausgelöst hat; das Zurücksetzen des Passworts und der Hilfe-Link stehen unten im Formular. Der Ablauf ist unverändert — nur das Aussehen wurde aktualisiert.

## Wenn etwas zu fehlen scheint

Wenn eine Seite oder Einstellung umgezogen scheint und Sie sie nicht finden:

1. Öffnen Sie die [Globale Schnellsuche](../../end-user-and-partner-section/end-user-section/global-quick-search.md) mit <kbd>Cmd</kbd>/<kbd>Ctrl</kbd>+<kbd>K</kbd> und tippen Sie den Funktionsnamen — die Schnellsuche indexiert jede Seite in der Anwendung.
2. Öffnen Sie die [Sitemap](../../end-user-and-partner-section/end-user-section/sitemap.md) unter `/sitemap` für den vollständigen, filterbaren Katalog.
3. Verwenden Sie das Hilfe-Symbol auf der naheliegendsten Seite, um direkt in die Dokumentation einzusteigen.
