# Documenttypen

Documenttypen geven DocBits aan met welke soorten documenten uw organisatie werkt. Een beheerder vindt ze onder **Instellingen → Documenttypen** in het gedeelte **Documentverwerking** van het instellingenmenu.

De pagina toont eerst de **Standaarddocumenttypen**, die DocBits levert en die u niet kunt verwijderen, gevolgd door de **Aangepaste documenttypen** die voor uw organisatie zijn gemaakt. Elk type heeft een eigen kaart.

## Wat u op een kaart kunt doen

| Bedieningselement | Wat het doet |
| --- | --- |
| **Activeren** | Maakt dit documenttype beschikbaar of niet beschikbaar in uw organisatie. Een blauwe schakelaar staat aan; een grijze schakelaar staat uit. |
| **Extraction** | Kiest de extractiemodus: **Flex** wanneer aan of **Fix** wanneer uit. Het schakelt extractie niet simpelweg in of uit. Beweeg de muisaanwijzer over de schakelaar om de huidige modus te zien. |
| **Instellingen** (tandwiel) | Opent **Meer instellingen** voor dit type. Vouw daar een categorie uit om de opties te bekijken. De categorieën zijn afhankelijk van het documenttype. |
| **Indelingen** | Opent de indelingsconfiguratie. Zie [Layout Builder](layout-builder.md) voor de vervolgstappen. |
| **Velden** | Opent de veld- en herkenningsinstellingen voor dit type. Zie [Velden](../../settings/global-settings/document-types/fields/README.md) voor de configuratie. |
| **Tabellen** | Opent de configuratie van de tabelkolommen voor dit type. |
| **Scripts** | Opent verwerkingsscripts wanneer deze functie beschikbaar is. |
| **Modeltraining** | Opent de modeltraining voor dit type. |
| **E-Doc** | Opent de instellingen voor elektronische documenten wanneer het type die ondersteunt. |
| **Document-subtypen** | Opent de subtypen van dit documenttype. |

Afhankelijk van de functies van uw organisatie ziet u mogelijk meer links op de kaart, zoals **Validatieregels** of **Transformatieregels**. Kies de link van het type dat u wilt wijzigen.

## Velden en herkenningsinstellingen bewerken

Klik op een kaart op **Velden** om de veldgroepen te bekijken. Bovenaan die pagina stellen **OCR** en **Wedstrijdscore** de herkenningsdrempels in, zet **Standaardinstellingen herstellen** die drempels terug en zoekt **Zoeken op naam** een veld. Gebruik **Nieuwe groep maken** om velden te ordenen en **Veld maken** binnen een groep om een veld toe te voegen. **Mastergegevensinstellingen** opent de bijbehorende configuratie van stamgegevens.

Elke veldrij heeft bedieningselementen zoals **Vereist**, **Alleen Lezen**, **Verborgen**, **Force Validatie**, **Gebruik AI**, OCR, Wedstrijdscore en Formule. Raadpleeg de [handleiding Velden](../../settings/global-settings/document-types/fields/README.md) voordat u afzonderlijke waarden wijzigt. Klik op de pagina Velden op **Instellingen opslaan** om uw wijzigingen te bewaren.

## Een eigen documenttype maken

Scrol naar **Aangepaste documenttypen** en klik op **Nieuw**. Volg [Documenttypen toevoegen/bewerken](../../settings/global-settings/document-types/adding-editing-document-types.md) om het nieuwe type in te stellen.
