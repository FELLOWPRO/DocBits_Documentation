## **Accéder à l’éditeur de mise en page**

Tout d’abord, assurez-vous que la fonctionnalité Layout Builder est activée. Cela peut être fait en accédant à Paramètres → Traitement du document → Module → Type de document et assurez-vous que le curseur Layout Builder est activé, comme indiqué ci-dessous.

![Paramètres du type de document avec les sections Layout Builder, Models &amp; Labels, Doc Script et Doc Scan, la section Layout Builder ouverte et son curseur](https://lh7-us.googleusercontent.com/I0VvFiFftKLoCB47jCAoosfTyqIQgXBoggMFp1QAeIj9xW4yiiIzyk5eIEHZ7duA251Yc4\_ArUKA8e-LjDht13bckAnkAOHOvl1p5k1-Qj\_UkEp2cSZwxHz\_PXe8IQ4\_jglzCtjAJg5pd9m\_hNZEhXA)

Une fois cela fait, vous pouvez accéder au Layout Builder via Paramètres → Types de documents. Une fois sur cette page, vous pouvez sélectionner parmi les différents types de documents que vous avez créés et soit sélectionner “Edit Layout” comme indiqué ci-dessous.

![Barre d'onglets d'un type de document avec les entrées Labels, Edit layout, Document Sub Types, Table columns, Fields, Model Training, Regex et Scripts](https://lh7-us.googleusercontent.com/WMD8M0qugnc64ZuyLuEYH5P63qk-Vo86useg32-QyOsP63FJA\_Xh7UzwlwmUR3K9oTd19aXexSitZqQLVEKo26-i8hYWUS9CChzwAS8TgbWoqweFucJcNIgKBruzSd0mxn8zrh9i46lPxKMNDh-YEJ8)

ou si vous avez des types de sous-documents dans un type de document créé, vous pouvez sélectionner “Document Sub Types” et sélectionner “Edit Layout” pour la mise en page du type de sous-document que vous souhaitez modifier comme indiqué ci-dessous.

![Liste des types de document avec les colonnes NAME et ACTION et les lignes WARENRECHNUNG, KOSTENRECHNUNG, FRACHTRECHNUNG et Test, chaque ligne proposant Fields, Edit layout, Scripts et Copy](https://lh7-us.googleusercontent.com/KfmM8wMGnn5tzXRxF1yT0Efm7X6v0kYeGzgNG3RihERh\_P71tjEVkJh4POMwgqnsCBoE736xI7oHkmpYNUbtAShhE-wAHsnLuxljDtmhGQUyljF\_PmOF2y6c0gIdIk\_jUD3sVNsq5viT2sb236OBYSA)

Après avoir suivi les étapes précédentes, vous arriverez à une page comme celle présentée ci-dessous.

### **Importer un document d’exemple**

Pour téléverser un document vers le générateur de mise en page, naviguez simplement vers la droite sur l'écran.

![Page Layout Builder avec le panneau ELEMENTS à gauche, les groupes de document Invoice Details, Payment Details, PO number, VAT &amp; Amounts et Vendor Details et la zone de mise en page vide à droite](https://lh7-us.googleusercontent.com/I99BkFDTOloyKwwc0P8O3wf8FbKL3B5Zn5i3GfeRKSSkBdelQ\_HNfI2oJzaXQUi\_UU6R5Vr7jrgcAxIrDmmTKWgTZx90J7izOX0oczWt\_\_qt9VmD1HqafZvqH8vb7xnZMR1m5pjwzsbcnalErYo6dIc)

Cliquez sur le bouton “Upload Documents” ou faites glisser et déposez le document souhaité dans la zone prévue à cet effet.

![Page Layout Builder avec l'arborescence des éléments à gauche et la zone de mise en page à droite qui accepte un document par glisser-déposer](https://lh7-us.googleusercontent.com/GHqGYqvwFvN3z2ojFz\_i7ZLlZhy-A3vsKUmmzOC0NMkPd2-f6\_t\_0USF66W-N3XRqHlmx06QNSQ7U-VTPQPKWdzOhoNcN7LlMk45sKVC6bWN1O92G0r4dKyHQLlgmGZiINYjZ9vZnt89\_BjgzbON2MI)

### **Groupes**

Des groupes peuvent être créés en sélectionnant l'icône suivante.

![Page Layout Builder avec l'arborescence des éléments à gauche et le bouton Upload Documents dans la zone de mise en page](https://lh7-us.googleusercontent.com/eb4jnCmezPFKPwgUisJKvicBqMWuGHW69WIFdtpmQiY-\_78VWmMyMD4TqKMJXwjH1XDnS5RXX0DsJ2\_ur\_GG62L4F7OEzkLrpgwUkiuQjZQPJqQoHIBj6WM33zY0AkYXhI3mKLjZetbEQ2AlhPJ8KV8)

Les groupes vous permettent de créer différentes sections sur une mise en page, ce qui facilite la séparation de différents groupes de données ou d'informations pour rendre une mise en page plus facile à suivre. Vous pouvez créer un titre pour chaque groupe afin qu'un utilisateur puisse savoir quelles informations il trouvera dans ce groupe.

![Page Layout Builder avec le panneau ELEMENTS et la section Groups de l'arborescence des éléments](https://lh7-us.googleusercontent.com/lWqIEC-TCOp4rKytTbhn2fYWY618\_Yra2mjWHA9oMyWPqHXA5JKCLoZoEtM8xQHAkn4HFNTPYpbMePUYnQhQGL0KmgBfTEDWPDAMy7PjZinZl2s\_kHQlsLAGjYbzSINWTme3qRO9tHLcpVaDVvS\_8F4)

### **Éléments du formulaire**

![Panneau Elements avec les sections Groups et Fields et les éléments de formulaire Text, Label, Check Box, Multi Check Box, Horizontal Separator, Table Of Checkboxes, Button et Extracted Tables](https://lh7-us.googleusercontent.com/OFBRSGdol7loocu5uGVe4Q8URMDojvXTN0xj3TCgL-jb-wUgt1fjEqfXCyMPz\_HNh94LVVmg6ifQDhxvlQsgbbChRfrw2Ohx4ICOUwHix3iiAFY9hI3BPGBfcNABiHLhgXQJVZmGvEO\_niVWkIXz\_6g)

Il s'agit d'un ensemble de champs par défaut qui peuvent être glissés et déposés dans le générateur de mise en page et qui sont à votre disposition pour créer la mise en page souhaitée. Ceux-ci incluent :

* Texte – Il s'agit d'une zone de texte qui crée un champ dans la mise en page dans lequel du texte peut être saisi une fois sur l'écran de validation.
* Étiquette – Il s'agit d'un champ qui peut être utilisé pour créer du texte non modifiable, il pourrait être utilisé pour créer des sous-titres ou tout autre texte non modifiable souhaité lorsque vous êtes sur l'écran de validation.
* Case à cocher – Cela crée un champ de type booléen qui peut être coché ou décoché.
* Case à cocher multiple – Cela fonctionne de la même manière que le “Checkbox” mais peut être utilisé lorsque l'utilisateur sait qu'il ajoutera plusieurs cases à cocher dans une section.
* Séparateur horizontal – Cela crée une ligne horizontale sur la mise en page qui peut être utilisée pour diviser les sections au sein d'un groupe sur la mise en page.
* Tableau des cases à cocher – Cela permet à l'utilisateur de créer un tableau de cases à cocher composé de valeurs personnalisées des axes X et Y, par exemple.

![Tableau de cases à cocher avec l'en-tête Please mark with a cross au-dessus des colonnes A à H et les lignes Test 1 et Test 2](https://lh7-us.googleusercontent.com/lMZU68H4i8ELjgenpcNXeNhJ9iwzTWGRkjNMEdV3rqdGwnaRZ\_tvG9mbx2ogXQ2hMciGSp-9m1c5KS9VwGJWzuxcRiaioVDSLTLvh-csHUho4aX25LXrtjhGSfK6yTukufwrjQvZR-JliuhiaPCCxpw)

* Bouton : crée un bouton dans la mise en page de l’écran de validation. Il peut exécuter **Export**, **Export mit Sonderwunsch** (exportation avec une demande particulière) ou **Reject**.
* Tableaux extraits - Cela vous permet de placer une zone sur la mise en page du document qui illustre le tableau extrait du document. Pour plus d'informations, cliquez ici.
* Boutons de facture – Cet élément vous permet de glisser-déposer un ensemble de boutons optimisés pour les factures. Lorsque vous êtes sur l'écran de validation, lorsque vous sélectionnez le type de facture (coût ou achat), le rapprochement PO ou la comptabilité automatique disparaîtra en conséquence.

![Ligne de boutons de facture dans la vue de validation avec les entrées SAVE RULES, AUTO ACCOUNTING, PO MATCH et EXPORT](https://lh7-us.googleusercontent.com/-w5iTr9b\_pcc6Y39osFmuzKQGRa\_e4tAXvQOn1zN8T4HwcuTs\_FP9mFPAJJeABvYKTyiQr3xZALsRgueIDksbswhnY-E9ioT1AIaf8xwAblBckX1f8xzi5v9mLxBRRUZoViDntKK6Nd5fy5sd5Bq5LU)

* Champs de code QR – Cet élément vous permet de glisser-déposer un bloc qui affichera toutes les informations extraites d'un document lorsqu'un code QR est présent.

### **Créer des champs propres au document**

L'utilisateur peut créer ses propres groupes et champs personnalisés pour un type de document, cela peut être fait lors de la création initiale d'un type de document, mais également en sélectionnant “Fields” sur la page Types de documents dans Paramètres.

![Barre d'onglets d'un type de document avec les entrées Labels, Edit layout, Document Sub Types, Table columns, Fields, Model Training, Regex et Scripts](https://lh7-us.googleusercontent.com/N9i3KnGyXATf5jLVbPQGiPEG9rlz6WqHJ5c8FZnpw3EwmaMnl2cQhMwhug3d-A82caOS6Nxc7LgAVLMtBL404hKR7i39u2RfwzCnohqn1\_mbkMtjzNKThnjGu2ivaFNqKDuobzA6kUdD8gGiQ\_zs3z8)

### **Espaces vides**

#### **La règle des 100 pour cent**

![Groupe de mise en page avec le titre Group Title, le bouton DELETE GROUP et les deux champs Test 1 et Test 2 côte à côte](https://lh7-us.googleusercontent.com/TwNA3gZrgzhSvZrZOGywGYz92fRkUtjIsr6sDCxEzYgWcfJ9kXuzJKkqNiFyp3H5XXoqUz76TzZ72r86YY\_O3Vw\_rvDKczD\_hdMOIQOFWORr2bo8pGunrAtUklJ1ye7KEQJEjRNqNUNCnXM0boIICUA)

Afin de créer l'espace ci-dessus sur la mise en page, un “Label” des éléments de formulaire doit être utilisé d'une manière spéciale. La raison en est que le gestionnaire de mise en page fonctionne selon un système de 100 espaces par ligne dans la mesure où 1 espace représente 1 pour cent d'une ligne, cela signifie que les champs ne peuvent occuper que 100 espaces par ligne, comme indiqué ci-dessous.

![Mise en page avec un élément Label sélectionné, le groupe de mise en page intitulé Test 1 et le panneau de propriétés contenant l'entrée Element Width in Percentage](https://lh7-us.googleusercontent.com/YTqddzVQPWRuP5ylV6NnMc-KnEgCY0ZxZ8zn0In5d5dOxaWnwGDi4N2qohbobLNphLfVD61sMUE5QlmXJZ3e0tP7Y8no\_wVRy9WTF0nWIN5Tg3t-zLJhs9M-kVYPFV3CyerRZZoK-iMXLmKGcuSY\_Nw)

Cela signifie que l'utilisateur doit construire la mise en page ligne par ligne selon cette règle. Par exemple, disons que vous souhaitez ajouter les champs “Name” et “Date” sur la même ligne mais que vous souhaitez que le champ “Name” soit plus grand. Cela peut être fait en faisant glisser et en déposant le champ “Text” depuis la liste déroulante Éléments de champ et en nommant chaque champ “Name” et “Date” comme indiqué.

![Panneau de propriétés d'un champ de texte avec le champ Name, l'identifiant interne et la valeur 30 pour Element Width in Percentage](https://lh7-us.googleusercontent.com/2ru3pj0iD3V6ADqYBjeQPqDT3uvTH\_Al2MV0gpUUQ9MpX0TSFtnjYL6JN0YOkBk9afx2q2YcMo4gWE2jItUAGSEfX79O\_6sFgKwP5FGa98SwzgjGgee1G-2aO6NyqZusf27SbJoWoHmzu51Hx25kVmM)

Le problème existe maintenant : ils ont tous deux la même taille, 33 (c'est la taille par défaut de tous les champs glissés-déposés), mais vous souhaitez que le champ “Name” soit plus grand que le champ “Date” et que les deux champs occupent toute la ligne de la mise en page. Par conséquent, en suivant la règle des 100 pour cent, vous pouvez définir les champs “Name” et “Date” sur n'importe quelle combinaison de 100 que vous désirez. Cela dépend bien sûr de la taille que vous souhaitez pour chaque champ individuel, mais pour les besoins de cet exemple, nous définirons le champ “Name” à 70 et le champ “Date” à 30, les résultats sont :

![Mise en page avec les deux champs Name et Date sur une ligne à côté du panneau de propriétés du champ sélectionné](https://lh7-us.googleusercontent.com/m411QblkCfsQWllhX74QpANjuVEv3fgM1Nhg8cJjbkNQGcjym6v0JFHIrKyMOAu-MasQ4KH9ZPaxmqNWfhWmAuL6SOZE030NXebb7ERzYxF99hLJC6oGbM-YXp7bNdZuoTaPmsDt7EjpV5BOiflwA4g)

Cette même règle s’applique à tous les champs du Layout Builder.

#### **Créer des espaces vides**

Maintenant que cette règle a été expliquée, créer des espaces vides aura plus de sens. Comme mentionné précédemment, afin de créer un espace vide, vous devez utiliser un “Label” à partir des éléments du formulaire.

Par exemple, disons que vous souhaitez créer un espace vide entre ces deux champs.

![Groupe de mise en page avec le titre Test, le bouton DELETE GROUP et les deux champs séparés par un espace](https://lh7-us.googleusercontent.com/jOms6aTB3wCmX3L-MiUTrOb\_-q3AiFC3Y75TsHJe8QFLru10H9aZKzbE5MfHPZ0v9fqycQeddNPJp7pnRjv17crkrYUymNA8u9bF-3u9IfR6ru\_duavqrLCQocommljzLA00RXs\_lQA4gDH6l\_QvyTs)

La première étape consiste à glisser et déposer un “Label” entre ces deux champs, une fois ajouté, vous pouvez cliquer sur le champ “Label” que vous venez d'ajouter et sur la gauche les propriétés du champ vous seront présentées. Maintenant, de la même manière que vous créeriez ou modifieriez le nom d'un champ comme indiqué précédemment, vous supprimerez tout nom de la propriété “Label” comme ceci

![Panneau de propriétés d'un Label avec un nom affiché vide, l'identifiant interne input_8b7cc2b8 et la valeur 30 pour Element Width in Percentage](https://lh7-us.googleusercontent.com/0Mma4wYIIfAkOyRIFLZtjug7pbWltfaiPm3r\_WgbP5fCgKe2BGD6Qf5YJ5Ns7fBBTRfJ68NlOtmOQrvcOvjyWGxk9v\_XmDj-8moEQhcDUugh\_VO5DdrJLYYV08ftr8YdhuhEM0otWs\_ljew18j7XJFQ)

Le résultat de cette opération sera alors

![Groupe de mise en page avec le titre Test, le bouton DELETE GROUP et l'espace plus large entre les deux champs](https://lh7-us.googleusercontent.com/-HqoJUAbcHRCletgSg6gcKXpn6zto1Do8I5EmcEmPWL4qUrMREh-wZdhy7ZKtnbuGjypd7p2mjcIu6LbbfdjA3c1liT2reCQXWiP1VAji08eWc\_bbF\_a0Dd82rJRgCuD5yjdlXL\_DNheMcw-fm6pQnA)

Il existe désormais un écart entre les deux champs. Cet écart peut être prolongé ou raccourci selon la règle des 100 % évoquée précédemment, et avec ces fonctions, vous pouvez créer n'importe quelle disposition souhaitée.
