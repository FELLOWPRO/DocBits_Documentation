## **Zugriff auf den Layout Builder**

Stellen Sie zunächst sicher, dass die Funktion „Layout Builder“ aktiviert ist. Navigieren Sie dazu zu Settings → Document Processing → Module → Document Type und vergewissern Sie sich, dass der Schieberegler „Layout Builder“ wie unten gezeigt aktiviert ist.
