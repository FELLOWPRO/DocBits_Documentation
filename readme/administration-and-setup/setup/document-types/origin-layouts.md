# Origin Layouts

DocBits zeichnet sich darin aus, Dokumentlayouts an ihre geografische Herkunft anzupassen und gleichzeitig Elemente wie Währungsformate auf Basis der Browser-Einstellungen des Benutzers zu standardisieren. Sehen wir uns an, wie Sie den Layout Builder nutzen können, um Layouts für unterschiedliche Herkunftsländer anzupassen, etwa für die USA und Deutschland.
