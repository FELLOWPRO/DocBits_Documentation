# Supplier portal: previous guide

This previous guide has been replaced by the current documentation. Use the new introduction for administrator setup and the separate registration guide for suppliers.

## Find the current setting

Open **Settings → Module → Document Integration**, then expand **Shipping & Supplier** to find **Supplier Portal**. Check with an administrator before changing the setting for your organization.
