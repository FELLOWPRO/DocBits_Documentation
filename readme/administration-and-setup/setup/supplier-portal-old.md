#### Paramètres fournisseurs <a href="#supplier-settings" id="supplier-settings"></a>

Une fois la fonctionnalité Portail fournisseurs activée, une nouvelle zone de paramètres devient disponible. Si vous faites défiler la liste des paramètres jusqu'en bas, vous verrez ce qui suit.

<div align="left"><figure><img src="https://578966019-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FT2n2w4uDCJvv7CJ5zrdk%2Fuploads%2FqewBeZzPPENTEzJl9gJO%2F5_Supplier_Settings.png?alt=media&#x26;token=6d83028b-ec6f-4bea-9dbb-9de9d89fd795" alt="Page de paramètres de DocBits défilée vers le bas de la navigation avec les entrées Classification and Extraction, Master Data Lookup, List of Values, Export, Module et Supplier Portal" width="375"><figcaption></figcaption></figure></div>

Dans cette section, vous avez accès aux éléments suivants.

<div align="left"><figure><img src="https://578966019-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FT2n2w4uDCJvv7CJ5zrdk%2Fuploads%2Fw49U8RhmJH8ichVjB0zr%2F7_Supplier_Groups_1.png?alt=media&#x26;token=ee824fa5-45d6-4317-9841-8e87e6308910" alt="Table des groupes de fournisseurs dans les paramètres avec les colonnes Group API Name, Group Name et Actions et la ligne BROKER avec le nom d'API BKR" width="375"><figcaption></figcaption></figure></div>

**Autorisations fournisseurs**

C'est ici que vous pouvez gérer tous les fournisseurs en les regroupant, ce qui facilite leur gestion. Vous pouvez également affecter des utilisateurs aux différents groupes de fournisseurs que vous créez dans cette zone.

**Groupe de fournisseurs**

Pour faciliter la gestion de tous les fournisseurs, vous pouvez créer dans cette section des groupes et y affecter des fournisseurs selon leur situation géographique, leur type, etc. Le choix vous appartient !

<div align="left"><figure><img src="https://578966019-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FT2n2w4uDCJvv7CJ5zrdk%2Fuploads%2FVXzNmgtb3OBb8q1ttHK7%2F7_Supplier_Groups_1.png?alt=media&#x26;token=1b07283a-7190-485e-8473-5cd6f1639de1" alt="Table des groupes de fournisseurs dans les paramètres avec les colonnes Group API Name, Group Name et Actions et la ligne BROKER avec le nom d'API BKR" width="375"><figcaption></figcaption></figure></div>

Pour créer un nouveau groupe de fournisseurs, cliquez sur le bouton +New en haut à droite de votre écran.

<div align="left"><figure><img src="https://578966019-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FT2n2w4uDCJvv7CJ5zrdk%2Fuploads%2FcUx4VredlX84lxpO6ID1%2F8_Supplier_Groups_2.png?alt=media&#x26;token=bc4e0efb-b06f-4e37-a82e-6c02eff8ff80" alt="Table des groupes de fournisseurs dans les paramètres avec les colonnes Group API Name, Group Name et Actions et la ligne BROKER avec le menu d'actions ouvert" width="375"><figcaption></figcaption></figure></div>

Attribuez ensuite simplement à ce groupe un nom qui décrit précisément les fournisseurs qui y seront affectés.

<div align="left"><figure><img src="https://578966019-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FT2n2w4uDCJvv7CJ5zrdk%2Fuploads%2Fq9G7MzWkqzFzxQVoZpdp%2F9_Supplier_Groups_3.png?alt=media&#x26;token=230ba964-784c-4c2e-b611-addf95d9743e" alt="Boîte de dialogue Create new group avec le champ Group Name" width="375"><figcaption></figcaption></figure></div>

**Association utilisateurs et groupes de fournisseurs**

Tous les groupes de fournisseurs que vous avez créés sont affichés ici, car c'est à cet endroit que vous pouvez affecter des utilisateurs DocBits aux groupes de fournisseurs que vous créez.

<div align="left"><figure><img src="https://578966019-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FT2n2w4uDCJvv7CJ5zrdk%2Fuploads%2F0lYLkUtmUcZAcoBB3A62%2F10_Group_Mapping_1.png?alt=media&#x26;token=e86aae24-c36d-4103-9de9-bd6864d7dc73" alt="Page User And Supplier Group Mapping dans les paramètres avec le groupe BROKER, le nombre un et la table avec la colonne User et la ligne Amna Mazhar" width="375"><figcaption></figcaption></figure></div>

Pour affecter un nouvel utilisateur à un groupe de fournisseurs, cliquez sur le bouton +New et sélectionnez l'utilisateur que vous souhaitez affecter.

<div align="left"><figure><img src="https://578966019-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FT2n2w4uDCJvv7CJ5zrdk%2Fuploads%2FY6DHOi2Y4pV03VGuIZgm%2F11_Group_Mapping_2.png?alt=media&#x26;token=0fa1ac8c-8eb3-4a5b-8857-fb69c63953ef" alt="Boîte de dialogue User ouverte depuis la page User And Supplier Group Mapping avec la liste déroulante des utilisateurs et les boutons Cancel et Add" width="375"><figcaption></figcaption></figure></div>

Sélectionnez dans la liste déroulante l'utilisateur que vous souhaitez affecter au groupe de fournisseurs, puis cliquez sur Add pour l'affecter.

**Politique et déclaration de confidentialité**

C'est ici que vous pouvez charger votre politique et votre déclaration de confidentialité à destination des fournisseurs que vous inviterez via le portail fournisseurs. Pour charger un document, cliquez simplement sur Upload Document en haut à droite de votre écran.

<div align="left"><figure><img src="https://578966019-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FT2n2w4uDCJvv7CJ5zrdk%2Fuploads%2FIrN7krduOEKQVcpU0wyh%2F12_Policy_and_Privacy_Statement.png?alt=media&#x26;token=2d1fbdb6-51d6-4e10-8f4d-3cf2ac5ffb68" alt="Éditeur de texte avec le titre Terms and Conditions et le texte des conditions d'utilisation de Ruiz Food Products" width="375"><figcaption></figcaption></figure></div>

**Modèles d'e-mail**

Dans cette section, vous pouvez charger différents modèles d'e-mail, car ils constitueront la structure des e-mails reçus par le fournisseur lorsque vous l'invitez à rejoindre le portail fournisseurs. Les modèles requis sont : invitation, approbation, finalisation de l'inscription et rejet, car ce sont tous les e-mails qu'un fournisseur peut recevoir. Pour charger un modèle, cliquez sur +New.

<div align="left"><figure><img src="https://578966019-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FT2n2w4uDCJvv7CJ5zrdk%2Fuploads%2F61Erb9aVMRNmKKi1DCXj%2F13_Email_Templates.png?alt=media&#x26;token=6e554119-9677-4516-9f09-0304b021317d" alt="Table des modèles d'e-mail dans les paramètres avec les colonnes Name, Type, Subject, Last Modified At et Actions et les lignes Supplier Invitation Email, Supplier Approval Email, Supplier Registration Completion Email et Supplier Rejection Email" width="375"><figcaption></figcaption></figure></div>

**Mise en page fournisseur**

Vous pouvez personnaliser la mise en page du formulaire d'inscription que les fournisseurs invités verront lors de leur inscription au portail fournisseurs. Vous pouvez ainsi ajouter ou supprimer des champs selon ce que vous exigez des fournisseurs invités. Le générateur de mise en page fournisseur fonctionne exactement comme le générateur de mise en page des types de documents ; pour plus d'informations, cliquez ici.

Vous voyez ci-dessous que vous pouvez configurer plusieurs mises en page selon vos besoins.

<div align="left"><figure><img src="https://578966019-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FT2n2w4uDCJvv7CJ5zrdk%2Fuploads%2FQb8dR6FSHj0mml0JFzBp%2F14_Supplier_Layout_1.png?alt=media&#x26;token=2442ec68-3690-4ef1-8b7c-1fd44fe6e6b6" alt="Table des dispositions fournisseur dans les paramètres avec la page SUPPLIER FIELDS et les colonnes Title, Document Name et Actions ainsi que les lignes Supplier User et Supplier Management" width="375"><figcaption></figcaption></figure></div>

Dans la mise en page, vous pouvez ajouter des listes déroulantes qui peuvent être créées avec la fonctionnalité Liste de valeurs.

<div align="left"><figure><img src="https://578966019-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FT2n2w4uDCJvv7CJ5zrdk%2Fuploads%2FO2t4kgpui3Gebsyn1MkE%2F15_Supplier_Layout_2.png?alt=media&#x26;token=032b9665-425e-4d35-adce-de3d14a133de" alt="Disposition Supplier Management dans DocBits avec la page SUPPLIER LAYOUT, la liste des éléments à gauche avec supplier_details, les propriétés à droite et le formulaire avec les champs obligatoires Supplier Name, DBA Name, Country et Phone Number" width="375"><figcaption></figcaption></figure></div>

**À NOTER**

Seules les valeurs existant dans INFOR peuvent être utilisées dans ces listes afin que l'export fonctionne. Dans l'exemple ci-dessus, les valeurs sélectionnables pour le champ « Supplier Group » existent toutes dans INFOR. Le même principe s'applique à toutes les listes, qu'il s'agisse des conditions de paiement, des devises, etc. Pour éviter tout problème lors de l'export, consultez d'abord les valeurs enregistrées dans INFOR avant de configurer ces listes.

**Paramètres généraux fournisseurs**

C'est ici que vous pouvez charger le logo de votre entreprise ou un autre visuel, qui sera affiché dans l'en-tête de tous les modèles d'e-mail envoyés ainsi que sur l'écran de connexion DocBits lorsque les fournisseurs commencent leur inscription. Si ce champ reste vide, le logo DocBits standard est affiché.

Champs d'invitation supplémentaires du portail fournisseurs : cette option permet d'ajouter des champs supplémentaires à l'invitation que vous envoyez aux fournisseurs ; une liste de champs est mise à votre disposition, comme indiqué ci-dessous.
