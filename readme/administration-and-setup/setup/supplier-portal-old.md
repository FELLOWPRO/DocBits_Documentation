#### 供应商设置 <a href="#supplier-settings" id="supplier-settings"></a>

启用“供应商门户”功能后，设置中会出现一个新的区域。滚动到设置列表底部，即可看到以下内容。

<div align="left"><figure><img src="https://578966019-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FT2n2w4uDCJvv7CJ5zrdk%2Fuploads%2FqewBeZzPPENTEzJl9gJO%2F5_Supplier_Settings.png?alt=media&#x26;token=6d83028b-ec6f-4bea-9dbb-9de9d89fd795" alt="Settings 菜单列表,显示 classification and extraction、master data lookup、list of values 和 supplier settings" width="375"><figcaption></figcaption></figure></div>

在此部分，您可以访问以下内容。

<div align="left"><figure><img src="https://578966019-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FT2n2w4uDCJvv7CJ5zrdk%2Fuploads%2Fw49U8RhmJH8ichVjB0zr%2F7_Supplier_Groups_1.png?alt=media&#x26;token=ee824fa5-45d6-4317-9841-8e87e6308910" alt="供应商组设置表格,包含 group API name、group name 和操作列,列出经纪商组" width="375"><figcaption></figcaption></figure></div>

**供应商权限**

您可以在此处通过对供应商分组来统一管理所有供应商，从而简化管理。您还可以将用户分配到在此区域创建的各个供应商组。

**供应商组**

为了更轻松地管理所有供应商，您可以在此部分创建供应商组，并根据地理位置、供应商类型等将供应商分配到相应组中。分组方式由您决定！

<div align="left"><figure><img src="https://578966019-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FT2n2w4uDCJvv7CJ5zrdk%2Fuploads%2FVXzNmgtb3OBb8q1ttHK7%2F7_Supplier_Groups_1.png?alt=media&#x26;token=1b07283a-7190-485e-8473-5cd6f1639de1" alt="供应商组设置表格,包含 group API name、group name 和操作列,列出经纪商组" width="375"><figcaption></figcaption></figure></div>

如需创建新的供应商组，请点击屏幕右上角的 +New 按钮。

<div align="left"><figure><img src="https://578966019-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FT2n2w4uDCJvv7CJ5zrdk%2Fuploads%2FcUx4VredlX84lxpO6ID1%2F8_Supplier_Groups_2.png?alt=media&#x26;token=bc4e0efb-b06f-4e37-a82e-6c02eff8ff80" alt="供应商组设置表格,包含 group API name、group name、操作列和一个 New 按钮" width="375"><figcaption></figcaption></figure></div>

然后，为该组指定一个名称，准确描述将分配到该组的供应商。

<div align="left"><figure><img src="https://578966019-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FT2n2w4uDCJvv7CJ5zrdk%2Fuploads%2Fq9G7MzWkqzFzxQVoZpdp%2F9_Supplier_Groups_3.png?alt=media&#x26;token=230ba964-784c-4c2e-b611-addf95d9743e" alt="Create new group 对话框,包含 group API name 和 group name 输入框以及 cancel 和 save 按钮" width="375"><figcaption></figcaption></figure></div>

**用户与供应商组映射**

您创建的所有供应商组都会显示在此处，您可以在这里将 DocBits 用户分配到相应的供应商组。

<div align="left"><figure><img src="https://578966019-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FT2n2w4uDCJvv7CJ5zrdk%2Fuploads%2F0lYLkUtmUcZAcoBB3A62%2F10_Group_Mapping_1.png?alt=media&#x26;token=e86aae24-c36d-4103-9de9-bd6864d7dc73" alt="用户和供应商组映射页面,显示经纪商组、用户操作和一个已分配的用户" width="375"><figcaption></figcaption></figure></div>

如需将新用户分配到供应商组，请点击 +New 按钮，然后选择要分配的用户。

<div align="left"><figure><img src="https://578966019-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FT2n2w4uDCJvv7CJ5zrdk%2Fuploads%2FY6DHOi2Y4pV03VGuIZgm%2F11_Group_Mapping_2.png?alt=media&#x26;token=0fa1ac8c-8eb3-4a5b-8857-fb69c63953ef" alt="用户和供应商组映射视图,包含经纪商组、用户操作列和一个用户条目" width="375"><figcaption></figcaption></figure></div>

从下拉列表中选择要分配到供应商组的用户，然后点击 Add 将该用户分配到该组。

**政策和隐私声明**

您可以在此处上传将通过供应商门户邀请的供应商所需查看的政策和隐私声明。要上传文档，只需点击屏幕右上角的 Upload Document。

<div align="left"><figure><img src="https://578966019-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FT2n2w4uDCJvv7CJ5zrdk%2Fuploads%2FIrN7krduOEKQVcpU0wyh%2F12_Policy_and_Privacy_Statement.png?alt=media&#x26;token=2d1fbdb6-51d6-4e10-8f4d-3cf2ac5ffb68" alt="条款和条件页面,显示接受使用条款的文本,呈现为已上传的政策文档" width="375"><figcaption></figcaption></figure></div>

**电子邮件模板**

在此部分，您可以上传不同的电子邮件模板，这些模板将作为邀请供应商加入供应商门户时所发送邮件的结构。所需模板包括：邀请、审批、注册完成和拒绝，因为这些涵盖了供应商可能收到的所有邮件类型。要上传模板，请点击 +New。

<div align="left"><figure><img src="https://578966019-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FT2n2w4uDCJvv7CJ5zrdk%2Fuploads%2F61Erb9aVMRNmKKi1DCXj%2F13_Email_Templates.png?alt=media&#x26;token=6e554119-9677-4516-9f09-0304b021317d" alt="电子邮件模板列表,包含邀请、批准、注册完成和拒绝邮件,显示类型、主题和修改日期" width="375"><figcaption></figcaption></figure></div>

**供应商布局**

您可以自定义供应商注册供应商门户时看到的注册表单布局。这意味着您可以根据受邀供应商需要提供的信息添加或移除字段。供应商布局构建器的使用方式与文档类型布局构建器完全相同。有关更多信息，请点击此处。

下方展示了如何根据需要配置多个布局。

<div align="left"><figure><img src="https://578966019-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FT2n2w4uDCJvv7CJ5zrdk%2Fuploads%2FQb8dR6FSHj0mml0JFzBp%2F14_Supplier_Layout_1.png?alt=media&#x26;token=2442ec68-3690-4ef1-8b7c-1fd44fe6e6b6" alt="供应商布局设置,列出 supplier user 和 supplier management 布局,包含标题、文档名称和操作" width="375"><figcaption></figcaption></figure></div>

在布局中，您可以添加下拉列表，并使用“值列表”功能创建这些列表。

<div align="left"><figure><img src="https://578966019-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FT2n2w4uDCJvv7CJ5zrdk%2Fuploads%2FO2t4kgpui3Gebsyn1MkE%2F15_Supplier_Layout_2.png?alt=media&#x26;token=032b9665-425e-4d35-adce-de3d14a133de" alt="supplier management 布局生成器,显示 supplier details 元素,包含属性面板、下拉选项和国家选择" width="375"><figcaption></figcaption></figure></div>

**请注意**

只有 Infor 中已存在的值才能用于这些列表，否则导出将无法正常工作。在上方示例中，“Supplier Group”字段中可选的值都存在于 Infor 中。付款条件、货币等所有其他列表也遵循同一原则。为确保导出正常，请先确认 Infor 中存储的值，再配置这些列表。

**供应商常规设置**

您可以在此处上传公司徽标或其他替代图像。该图像将显示在所有电子邮件模板的页眉中，也会显示在供应商开始注册流程后看到的 DocBits 登录屏幕上。如果留空，则会显示标准 DocBits 徽标。

供应商门户的其他邀请字段：此选项可让您在发送给供应商的邀请中添加其他字段。系统会提供一组字段，如下所示。

<figure><img src="https://578966019-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FT2n2w4uDCJvv7CJ5zrdk%2Fuploads%2FLdyOv43jUPchvBTBKI1g%2Fsupplier-portal2.png?alt=media&#x26;token=73b1d4bd-06d0-408a-9abe-975a5a4af5c2" alt="其他邀请字段选择,列出 payment term 和 supplier group 以及 assigned user 选项" width="315"><figcaption></figcaption></figure>
