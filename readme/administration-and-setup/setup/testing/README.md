# Tests

Prüfen Sie, ob DocBits so arbeitet, wie Ihre Organisation es eingerichtet hat.

* Das **[Testing-Modul](testing-module/README.md)** (**Einstellungen → Testing**) führt wiederholbare Prüfungen in
  Ihrem eigenen Browser aus, von Hand, über einen KI-Assistenten oder aus Ihrer Testautomatisierung, und protokolliert jeden Lauf.
* Die folgenden Anleitungen beschreiben manuelle Prüfungen einzelner Funktionen nach der Einrichtung:
  [Bestellabgleich](po-matching.md) und [Automatische Kontierung](auto-accounting/README.md).
