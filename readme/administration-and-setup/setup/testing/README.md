# Tests

Vérifiez que DocBits fonctionne comme votre organisation l'a configuré.

* Le **[module Testing](testing-module/README.md)** (**Paramètres → Testing**) exécute des contrôles reproductibles dans votre
  propre navigateur, à la main, depuis un assistant IA ou depuis votre automatisation de tests, et conserve un journal de chaque exécution.
* Les guides ci-dessous décrivent des contrôles manuels de fonctionnalités précises après leur configuration :
  [Rapprochement des commandes fournisseur](po-matching.md) et [Tester la comptabilité automatique](auto-accounting/README.md).
