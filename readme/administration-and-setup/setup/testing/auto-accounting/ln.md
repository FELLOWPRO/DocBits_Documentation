# LN

Po zatwierdzeniu i wyeksportowaniu dokumentu zaloguj się do INFOR. Ze strony głównej LN przejdź do opcji Finanse → Zobowiązania procesowe → Pulpit zobowiązań z tytułu procesu.

![Strona główna Infor LN z polem wyszukiwania LN i menu nawigacyjnym od Master Data do Purchase Invoices](https://lh7-us.googleusercontent.com/7fLK1plDBSQjBwad8yGVJMJQuVJoXcN2B-KtFKI-lnA7P7B1E7QV-RCsLWih57lcKKEJJlowolkLsSmXGEaOr7MLUWbrYrMmdMYUPzgIF0lRVoo\_vwrgxE081oFB04qfZ3mF5Z29vbTMIPi1I8PfQoM)

Naciśnij następującą ikonę, aby wyświetlić poszczególne pozycje faktury.

![Przegląd Invoices w Infor LN z pozycją Supplier Invoice o numerze 2302421 na liście](https://lh7-us.googleusercontent.com/pbvFiudy0xpItlMyi2h047J3edFK7Vmz5zxJqk5q82XVwT42EHnCdscu-P0I-Yg4L9Fv7iA9dIipiJY5FlUMFxsXHNTftgodKWiXRRLeQoAcTfxkfySVWxqBzMvrJfx\_eFijHC-Mnz7laYSrr3utkSI)
