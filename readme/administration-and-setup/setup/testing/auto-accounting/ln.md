# LN

Une fois que vous avez validé et exporté un document, connectez-vous à INFOR. Depuis la page d'accueil de LN, accédez à Finances → Traiter les fournisseurs → Traiter les comptes fournisseurs.

![Page d'accueil d'Infor LN avec la zone de recherche LN et le menu de navigation de Master Data à Purchase Invoices](https://lh7-us.googleusercontent.com/7fLK1plDBSQjBwad8yGVJMJQuVJoXcN2B-KtFKI-lnA7P7B1E7QV-RCsLWih57lcKKEJJlowolkLsSmXGEaOr7MLUWbrYrMmdMYUPzgIF0lRVoo\_vwrgxE081oFB04qfZ3mF5Z29vbTMIPi1I8PfQoM)

Appuyez sur l'icône suivante pour afficher les lignes de détail individuels de la facture.

![Vue d'ensemble Invoices d'Infor LN avec une entrée Supplier Invoice numérotée 2302421 dans la liste](https://lh7-us.googleusercontent.com/pbvFiudy0xpItlMyi2h047J3edFK7Vmz5zxJqk5q82XVwT42EHnCdscu-P0I-Yg4L9Fv7iA9dIipiJY5FlUMFxsXHNTftgodKWiXRRLeQoAcTfxkfySVWxqBzMvrJfx\_eFijHC-Mnz7laYSrr3utkSI)

Ici, vous pouvez confirmer les lignes de détail avec ce que vous avez exporté à l'aide de la comptabilité automatique.
