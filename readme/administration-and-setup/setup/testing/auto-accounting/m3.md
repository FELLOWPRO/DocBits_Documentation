Dopo aver convalidato ed esportato un documento, accedi a INFOR e digita il comando APS450.

![Finestra di Cloudsuite Infor M3 con Filter Options e l'elenco aperto delle fatture fornitore con le colonne Supplier invoice no, Inv batch type e Supplier name](https://lh7-us.googleusercontent.com/zvHZ3f9eVk04gFXYvmCFJZH4zXY9HnuK5BwU-iO7aemf9fVXWDa7Yy6j9F6fIuN0Nx5mlBsRBVbYexe4D547kkgWMMWfEx1sjjEmfORq6cf1gel94LchPvBdPP6htbcCe0bveKRIUlQjr13HPXn49yM)
