# M3

Une fois que vous avez validé et exporté un document, connectez-vous à INFOR et saisissez la commande APS450.

![Panneau Infor M3 avec la ORDER CONFIRMATION TABLE et une note Calculate in indiquant que les correspondances de la regex Material Surcharge sont additionnées dans MTZ](https://lh7-us.googleusercontent.com/i4iRIFS78R3roSyp5i6TK8VCp3\_GLgdet13ZyWRgUJjaTkLnl4Kfm-fv\_xky2Pu-LHmvrjLHhv1es\_MpBZAQV0fZPmYa7fsEye9IyNGkLsJNwPIRlSWKZ8BOitnImB6szvGZfaqu-gzVL8vbBhsmpHA)

Vous serez redirigé vers la page suivante où vous verrez le document que vous venez d'exporter.

![Fenêtre Cloudsuite Infor M3 avec Filter Options et la liste ouverte des factures fournisseur affichant les colonnes Supplier invoice no, Inv batch type et Supplier name](https://lh7-us.googleusercontent.com/zvHZ3f9eVk04gFXYvmCFJZH4zXY9HnuK5BwU-iO7aemf9fVXWDa7Yy6j9F6fIuN0Nx5mlBsRBVbYexe4D547kkgWMMWfEx1sjjEmfORq6cf1gel94LchPvBdPP6htbcCe0bveKRIUlQjr13HPXn49yM)

Une fois que vous avez trouvé votre document, faites un clic droit sur le document et sélectionnez “Related” puis l'option “Lines”.

![Liste ouverte des factures fournisseurs dans Infor M3 affichant les colonnes Netamount, Itemnumber, Elemnt, Vedi et Ponetp sub](https://lh7-us.googleusercontent.com/BTIGc1czaZLPysu1BMTr1hUL\_u0RlnuP0wV7xghtfpyw4L1VEDukpVPJt2VYyD88\_-dQGJ5zaYn4mPKbmJal52-9TwkGzJNBCZ7bgWStiJrWHAIsTGp-BM9TCY328ysf1LJINXKVEOBkdCPFXPxLrzI)

Vous serez redirigé vers le menu qui affiche tous les lignes de détail de la facture que vous avez exportée, en vous assurant que tous les lignes de détail sont là et sont corrects. Enfin, assurez-vous que tous ces lignes de détail sont classés comme type 8, cela peut être vu en consultant la colonne suivante du tableau.
