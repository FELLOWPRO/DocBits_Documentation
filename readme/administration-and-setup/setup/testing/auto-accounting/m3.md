# M3

Una vez que haya validado y exportado un documento, inicie sesión en INFOR y escriba el comando APS450.

Verá la página donde aparece el documento que acaba de exportar. Cuando encuentre su documento, haga clic derecho sobre él y seleccione "Related" y luego la opción "Lines".

Se abrirá el menú que muestra todas las líneas de posición de la factura que exportó; asegúrese de que todas las líneas de posición estén presentes y sean correctas. Por último, asegúrese de que todas estas líneas de posición estén clasificadas como Type 8, lo que puede comprobarse en la siguiente columna de la tabla.
