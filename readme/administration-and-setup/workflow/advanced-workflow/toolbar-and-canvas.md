# Traka sa alatkama i platno

Traka sa alatkama naprednog toka rada prostire se duž dna platna i daje vam sve što vam je potrebno za izgradnju, navigaciju i upravljanje tokom.

## Kontrole trake sa alatkama

- **+ Add** — otvara meni čvorova za dodavanje čvora (pogledajte [Čvorove](nodes.md)).
- **Undo / Redo** — korak unazad ili unapred kroz vaše promene.
- **Zoom in / Zoom out** — menja nivo uvećanja platna.
- **Workflow name** — imenujte tok rada na licu mesta.
- **Edit description** — dodajte opis za tok rada.
- **Variables** — otvara panel [Promenljivih](variables.md).
- **Help** — otvara dijalog tasterskih prečica i pomoći.
- **Validate / Test** — proverite i pokrenite tok (pogledajte [Validaciju i testiranje](validation-and-testing.md)).
- **Snap to grid** — uključuje/isključuje prianjanje čvorova uz mrežu radi urednog rasporeda.
- **Mini-map** — uključuje/isključuje malu preglednu mapu za navigaciju velikim grafovima.
- **Save** — sačuvajte tok rada. Indikator **auto-save** prikazuje kada je tok poslednji put automatski sačuvan.

## Tasterske prečice

Pritisnite <kbd>?</kbd> na platnu da biste u bilo kom trenutku otvorili dijalog prečica i pomoći.

<figure><img src="../../../.gitbook/assets/workflow_advanced_shortcuts.png" alt="Dijalog tasterskih prečica i pomoći"><figcaption><p>Dijalog tasterskih prečica i pomoći — prečice, isticanje putanje izvršavanja i boje veza.</p></figcaption></figure>

| Prečica | Akcija |
|---|---|
| <kbd>Cmd/Ctrl</kbd> + <kbd>S</kbd> | Sačuvaj tok rada |
| <kbd>Cmd/Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>V</kbd> | Validiraj tok rada |
| <kbd>Cmd/Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>T</kbd> | Testiraj tok rada |
| <kbd>Cmd/Ctrl</kbd> + <kbd>Z</kbd> / <kbd>Shift</kbd> + <kbd>Z</kbd> | Opozovi / Ponovi |
| <kbd>Cmd/Ctrl</kbd> + <kbd>C</kbd> / <kbd>V</kbd> / <kbd>D</kbd> | Kopiraj / Nalepi / Dupliraj izabrane čvorove |
| <kbd>Cmd/Ctrl</kbd> + <kbd>A</kbd> | Izaberi sve čvorove |
| <kbd>Shift</kbd> + Prevuci | Izaberi čvorove (prevlačenjem) |
| <kbd>Cmd/Ctrl</kbd> + Levi klik | Dodaj/ukloni čvor iz izbora |
| Desni klik | Meni za dodavanje čvora |
| <kbd>Del</kbd> | Obriši izabrani čvor |
| <kbd>?</kbd> | Prikaži ovu pomoć |

## Sledeći koraci

- Izgradite tok pomoću [Čvorova](nodes.md) i [Promenljivih](variables.md).
