# Variables

**Variables** let you store values once and reuse them across the nodes of an Advanced Workflow — for example a threshold, a fixed recipient, or a value you read from the document and pass to a later node. Open the variables panel from the **variables** button (the `{ }` icon) in the toolbar.

<figure><img src="../../../.gitbook/assets/workflow_advanced_variables.png" alt="Variables panel grouped by type with a New Variable button"><figcaption><p>The Variables panel — variables grouped by type, with search and <strong>New Variable</strong>.</p></figcaption></figure>

## Variable types

Variables are grouped by their type:

- **Text** — a string value (e.g. a description or a fixed label).
- **Yes/No** — a boolean flag (Yes / No).
- **Document** — a reference to a document or document field.

Use the search box to find a variable quickly when the list grows.

## Creating a variable

Click **New Variable**, give it a name and a type, and set its value. The variable then becomes available to reference from the cards on your nodes, so you can keep configuration in one place and change it without editing every node.
