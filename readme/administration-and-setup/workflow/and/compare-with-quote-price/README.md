# Comparer avec le prix du devis

Les cartes de cette catégorie, telles qu'elles apparaissent dans la bibliothèque **Add Card** du Workflow Builder :

Les cartes de cette catégorie comparent les postes d'un document aux données de prix des articles fournisseurs que DocBits a trouvées pour le fournisseur du document et ses numéros d'article fournisseur. Selon la carte, il peut s'agir du numéro d'article fournisseur, du numéro d'article, du prix géré ou du dernier prix payé, de l'unité de mesure ou du type de fournisseur. La version 3 de la carte Unit of Measure peut également effectuer la comparaison avec les lignes du bon de commande rapproché.
