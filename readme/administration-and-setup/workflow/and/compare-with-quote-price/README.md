# Vergelijk met offerteprijs

De kaarten van deze categorie, zoals ze in de **Add Card**-bibliotheek van de Workflow Builder worden weergegeven:

De kaarten van deze categorie vergelijken de regelitems van een document met de prijsgegevens van leveranciersartikelen die DocBits voor de leverancier van het document en diens leveranciersartikel-ID's heeft gevonden. Afhankelijk van de kaart kan dat de leveranciersartikel-ID zijn, het artikelnummer, de beheerde prijs of de laatst betaalde prijs, de maateenheid of het leverancierstype. Versie 3 van de kaart Unit of Measure kan ook vergelijken met de regels van de gematchte inkooporder.
