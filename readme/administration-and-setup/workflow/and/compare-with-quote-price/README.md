# Comparar con precio de cotización

Las tarjetas de esta categoría, que se muestran en la biblioteca **Add Card** del Workflow Builder:

Las tarjetas de esta categoría comparan las líneas de artículo de un documento con los datos de precios de artículos del proveedor que DocBits ha encontrado para el proveedor del documento y sus ID de artículo del proveedor. Según la tarjeta, puede tratarse del ID de artículo del proveedor, el número de artículo, el precio gestionado o el último precio pagado, la unidad de medida o el tipo de proveedor. La versión 3 de la tarjeta Unit of Measure también puede comparar con las líneas de la orden de compra emparejada.
