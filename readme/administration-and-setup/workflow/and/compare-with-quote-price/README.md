# Comparar com preço de cotação

Os cartões desta categoria, apresentados na biblioteca **Add Card** do Workflow Builder:

Os cartões desta categoria comparam os itens de linha de um documento com os dados de preços de itens de fornecedor que o DocBits encontrou para o fornecedor do documento e para os respetivos IDs de item do fornecedor. Consoante o cartão, pode tratar-se do ID do item do fornecedor, do número do item, do preço gerido ou do último preço pago, da unidade de medida ou do tipo de fornecedor. A versão 3 do cartão Unit of Measure pode também comparar com as linhas da ordem de compra associada.
