# Card SDK

De **Card SDK** stelt partners en ontwikkelaars in staat om aangepaste workflow-kaarten voor DocFlow te bouwen. U verpakt een kaart als een partner-app en uploadt deze, of importeert hem rechtstreeks vanuit GitHub.

<figure><img src="../../.gitbook/assets/workflow_card_sdk.png" alt="Card SDK-tabblad met Upload ZIP, GitHub Import en Submissions"><figcaption><p>De Card SDK — upload een partner-app-ZIP, importeer vanuit GitHub of bekijk uw inzendingen.</p></figcaption></figure>

## Hoe het werkt

- **Download SDK Template** — begin met de officiële template die de verwachte structuur bevat.
- **Upload ZIP** — de ZIP moet `app.json` en een `.docflowcompose/flow/`-map met de kaartdefinities bevatten (max. 10 MB). Upload &#x26; Validate controleert het pakket voordat het wordt geaccepteerd.
- **GitHub Import** — importeer een kaartdefinitie rechtstreeks uit een GitHub-repository.
- **Submissions** — volg de status van kaarten die u hebt ingediend.

Zodra ze zijn gevalideerd en geaccepteerd, verschijnen uw aangepaste kaarten in de **Add Card**-bibliotheek naast de ingebouwde kaarten.
