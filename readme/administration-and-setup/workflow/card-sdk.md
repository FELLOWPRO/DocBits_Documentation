# Card SDK

**Card SDK**, iş ortaklarının ve geliştiricilerin DocFlow için özel iş akışı kartları oluşturmasına olanak tanır. Bir kartı iş ortağı uygulaması olarak paketleyip yükler veya doğrudan GitHub'dan içe aktarırsınız.

<figure><img src="../../.gitbook/assets/workflow_card_sdk.png" alt="Upload ZIP, GitHub Import ve Submissions ile Card SDK sekmesi"><figcaption><p>Card SDK — bir iş ortağı uygulaması ZIP'i yükleyin, GitHub'dan içe aktarın veya gönderimlerinizi inceleyin.</p></figcaption></figure>

## Nasıl çalışır

- **Download SDK Template** — beklenen yapıyı içeren resmi şablondan başlayın.
- **Upload ZIP** — ZIP, `app.json` ve kart tanımlarını içeren bir `.docflowcompose/flow/` klasörü içermelidir (en fazla 10 MB). Upload &#x26; Validate, paketi kabul edilmeden önce kontrol eder.
- **GitHub Import** — bir kart tanımını doğrudan bir GitHub deposundan içe aktarın.
- **Submissions** — gönderdiğiniz kartların durumunu izleyin.

Doğrulanıp kabul edildikten sonra, özel kartlarınız yerleşik kartların yanında **Add Card** kütüphanesinde görünür.
