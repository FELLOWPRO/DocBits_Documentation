# Cards

Las tarjetas son los bloques de construcción de cada flujo de trabajo. Las combina en los grupos **When / And / Then** para describir cuándo se ejecuta un flujo de trabajo y qué hace. Esta sección explica las tarjetas disponibles y qué hace cada una.

## Grupos de tarjetas

- **When** — las tarjetas de disparador que inician un flujo de trabajo (p. ej. tipo de documento, tipo de documento uno de).
- **And** — tarjetas de condición que también deben cumplirse antes de que se ejecuten las acciones. Incluyen condiciones de *Compare with Purchase Order* (coincidencia de PO), comparaciones de *Document Field*, *Date & Time*, *Logic*, *Status*, *Table* y *Assignee*.
- **Then** — tarjetas de acción que realizan el trabajo: establecer campos, aprobar/rechazar, cambiar el estado, exportar, crear tareas, asignar documentos, manipular tablas y ejecutar acciones (Call API, Send HTTPS request, Run Workflow, cálculos de IA).
