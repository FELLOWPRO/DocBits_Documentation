# 比较总费用

<figure><img src="../../../../../.gitbook/assets/workflow_card_condition_compare_charge_field_with_po_v2-zh-cn.png" alt="比较总费用, 版本 2" width="634"><figcaption><p>版本 2</p></figcaption></figure>

## **用途：**

此工作流卡片会将文档字段中的总费用与采购订单中的对应费用进行比较。该卡片有助于确保文档中的费用与采购订单中的费用一致，并考虑指定的容差范围。如果发现差异，比较结果可以触发相应操作，例如标记差异以供审核或相应调整费用。

## **卡片组件：**

1. **字段名称：**
   * **说明**：指定包含总费用值的文档字段，这些值将与采购订单中的费用进行比较。
   * **详情**：此字段中的值表示文档（例如发票）中计入的总费用，并将与采购订单费用进行比较。
2. **运算符：**
   * **说明**：定义文档总费用与采购订单费用之间比较时使用的条件。
   * **选项**：
     * **等于 (=)**：验证文档中的总费用是否与采购订单费用相同。
     * **不等于 (≠)**：确保文档中的总费用与采购订单费用不同。
     * **大于 (>)**：验证文档中的总费用是否大于采购订单费用。
     * **大于或等于 (≥)**：验证文档中的总费用是否大于或等于采购订单费用。
     * **小于 (<)**：验证文档中的总费用是否小于采购订单费用。
     * **小于或等于 (≤)**：验证文档中的总费用是否小于或等于采购订单费用。
3. **容差金额**
   * **说明**：指定比较总费用时使用的容差阈值。
   * **详情**：此数值表示文档与采购订单之间允许的费用差额。
4. **容差类型：**
   * **说明**：指定要应用的容差类型。
   * **选项**：
     * **百分比**：按采购订单费用的百分比应用容差。
     * **数值**：按固定数值金额应用容差。
5. **分隔符：**
   * **说明**：指定用于分隔字段名称末尾费用 ID 的分隔符。
   * **详情**：分隔符用于将费用字段与唯一费用 ID 分开，该 ID 将用于将文档费用关联到采购订单中的对应费用。

## **功能：**

* **条件评估：**系统根据运算符和容差，将文档字段中的总费用与采购订单中的对应费用进行比较。系统会应用容差，以判断两项费用之间的差额是否处于可接受范围内。
* **执行操作：**
  * **条件为真**：如果费用（考虑容差后）相符且条件为真，工作流将继续执行定义的操作，例如审批文档或进行后续处理。
  * **条件为假**：如果条件为假（即费用未能在容差范围内满足比较条件），工作流将不会继续。

## **设置和配置：**

* 用户首先选择包含总费用值的文档字段。接下来，选择运算符以定义如何将该费用与采购订单费用进行比较。然后，设置容差金额和容差类型（百分比或绝对值）。最后，指定用于比较的分隔符和费用 ID。

## **示例场景：**

发票的“总费用”字段中列出一笔 500 美元的费用。采购订单中的对应费用为 480 美元，容差设置为 20 美元（绝对容差）。卡片会将文档费用与采购订单费用进行比较：

* 文档中的总费用与采购订单费用之间的差额在 20 美元容差范围内，工作流将顺利继续。
* 如果费用差额超出容差范围，工作流会将差异标记出来以供审核。

## **结论：**

“比较总费用”工作流卡片会在考虑指定容差范围的情况下，确保文档中的费用与采购订单中的费用一致。这有助于组织自动执行验证流程、及早发现差异，并更好地控制与费用相关的流程。
