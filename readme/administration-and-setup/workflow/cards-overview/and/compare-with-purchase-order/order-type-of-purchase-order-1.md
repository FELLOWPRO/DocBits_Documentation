# 采购订单类型

<figure><img src="../../../../../.gitbook/assets/image (104).png" alt=""><figcaption></figcaption></figure>

## **用途**：

此 DocBits 卡片可验证采购订单的订单类型，确保其符合指定条件。

## **功能**：

* **订单类型比较**：此卡片会将采购订单的订单类型与指定值进行比较，以便用户验证订单类型是否满足特定条件。
* **任意/全部选择**：用户可以选择将比较应用于指定订单类型中的**任意**一项（至少一项所选订单类型匹配）或**全部**订单类型（所有所选订单类型均匹配）。
* **运算符**：用户可以设置比较采购订单中订单类型的条件。可用运算符包括：
  * **等于 (=)**：确认采购订单中的订单类型与指定类型匹配。
  * **不等于 (≠)**：确保采购订单中的订单类型与指定类型不匹配。

## **用途场景**：

此卡片对需要准确分类和安排订单优先级的采购团队、库存规划人员和运营经理尤其有用。通过确保订单类型与预期分类一致，用户可以简化订单处理、优化资源分配，并遵守服务级别协议。

## **示例场景**：

* 某采购订单被归类为“IGR”。系统使用“等于”运算符验证此订单类型是否符合处理所需的分类。

使用“与采购订单比较：订单类型”卡片，组织可以自动验证订单类型，确保处理优先级一致，并减少人工分类错误。
