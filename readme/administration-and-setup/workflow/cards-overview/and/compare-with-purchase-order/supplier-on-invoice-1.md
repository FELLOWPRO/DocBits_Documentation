# 发票上的供应商

<figure><img src="../../../../../.gitbook/assets/image (1) (1).png" alt=""><figcaption></figcaption></figure>

## **用途**

此 DocBits 卡片可详细比较发票上的供应商与订单确认中的供应商。系统应确保开具发票的供应商与订单确认中的供应商相同。

## **功能：**

* **发票上的供应商与采购订单上的供应商：** 此卡片用于检查发票上的供应商是否与订单确认中的供应商相同。
* **运算符值：** 用户可以设置特定条件，例如：开具发票的供应商是否与采购订单中的供应商相同。可用运算符包括：
  * **是 (=)：** 检查发票上的供应商是否与订单确认中的供应商一致。
  * **不是 (≠)：** 确保开具发票的供应商与订单确认中的供应商相同。

## **用法：**

此卡片有助于确保整个流程由同一供应商处理，并确保各项内容相互匹配。如果存在差异，系统会提醒用户检查这些差异，避免向与订单及订单确认无关的错误供应商支付发票。

## **示例场景：**

* 下达订单后，会收到订单确认，随后开具发票。整个订购流程都由同一家供应商完成。如果实际情况并非如此，此卡片可以立即发现供应商之间的差异，从而确保不会发生错误付款，并且只向参与整个流程的供应商开具发票。

使用“发票上的供应商 … 采购订单上的供应商”卡片，企业可以自动验证发票开具供应商及其对应的订单确认。
