# 单价与字段值组合

<figure><img src="../../../../../.gitbook/assets/image (63).png" alt="" width="563"><figcaption></figcaption></figure>

## **用途：**

此工作流卡用于评估单价与指定字段值（例如数量、折扣或额外费用）组合后，是否满足定义的条件。卡片会将单价和字段值与指定阈值进行比较，以确保定价符合预期。此比较可以根据特定条件触发操作，例如标记差异，或在采购或收货工作流中自动执行审批流程。

## **卡片组件：**

1. **字段名称**
   * **说明：** 指定包含要与单价组合的值的文档字段。
   * **详情：** 此处必须与文档中第一个字段的确切标识符一致。
2. **运算符**
   * **说明：** 定义将用于比较组合值与指定值的条件。
   * **选项：**
     * **等于 (=)：** 检查单价与字段值的组合值是否等于指定值。
     * **不等于 (≠)：** 确保单价与字段值的组合值不同于指定值。
     * **大于 (>)：** 检查组合值是否大于指定值。
     * **大于或等于 (≥)：** 检查组合值是否大于或等于指定值。
     * **小于 (<)：** 检查组合值是否小于指定值。
     * **小于或等于 (≤)：** 检查组合值是否小于或等于指定值。
3. **值**
   * **说明：** 指定用于比较单价与字段值组合值的值。
   * **详情：** 此值必须为数值。

## **功能：**

* **条件评估：** 系统会根据所选运算符评估单价与字段值的组合，并将其与指定值进行比较。评估结果决定条件为真还是为假。
* **执行操作：**
  * **条件为真：** 如果比较结果为真（例如，组合值超过指定值），工作流将沿条件为真的分支继续执行。这可能会触发审批、文档路由或应用处理规则等操作。
  * **条件为假：** 如果比较结果为假（例如，组合值不满足条件），工作流将沿条件为假的分支继续执行。这可能会触发通知、将文档送交人工审核，或停止工作流。

## **设置与配置：**

* 用户首先选择包含要与单价组合的值的文档字段。选择字段后，再选择合适的运算符，以定义如何将组合值与指定值进行比较。然后可以设置该值。

## **示例场景：**

* 某张发票列出一种产品，共 50 件，每件 20 美元，总计 1000 美元。相关文档中有一个数量字段，其值为 10。使用“大于”运算符时，卡片会将单价（20 美元）与数量（10）组合进行比较，结果为 200 美元。卡片会检查组合值是否大于 150 美元（指定值）。由于组合值 200 美元大于 150 美元的阈值，工作流将触发该文档的审批。

## **结论：**

“单价与字段值组合”工作流卡通过评估单价与指定字段值的组合值，确保定价条件得到满足。通过自动执行此比较，组织可以确保定价或数量的一致性，并在进入审批流程前标记差异，从而简化采购和财务流程。
