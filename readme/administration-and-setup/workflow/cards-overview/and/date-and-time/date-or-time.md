## **用途：**

此 DocBits 卡片用于检查指定的日期/时间值是否在定义的范围内。它可以根据是否满足条件来继续或停止工作流，因此适用于有时效要求的操作或日程安排工作流。

## **功能：**

* **日期/时间验证：** 此卡片使用以下条件检查给定的日期/时间是否在指定范围内：
  * **是：** 检查日期/时间是否在定义的起始值和结束值范围内（含边界值）。
  * **不是：** 确保日期/时间在定义的范围之外。

**日期/时间范围：** 用户指定起始和结束日期/时间值，以定义用于比较的范围。

## **用法：**

此卡片适用于日程安排、合规性检查或在工作流中验证基于时间的条件。例如，可用于确保仅在预定义的时间段内执行任务，或核实截止日期。

## **示例场景：**

* 用户配置此卡片，检查发票的**提交日期**是否**介于** **"2024-11-01"** 和 **"2024-11-30"** 之间。如果提交日期在此范围内，工作流将继续进入付款处理；否则，工作流会触发通知，以便进一步审核。

使用“日期/时间范围验证”卡片，组织可以确保日程安排准确、提升合规性，并通过遵守预定义的时间限制来简化工作流。
