# 比较字段并设置容差

<figure><img src="../../../../../.gitbook/assets/workflow_card_condition_docfield_operator_value_tolerances_v2-zh-cn.png" alt="比较字段并设置容差, 版本 2" width="634"><figcaption><p>版本 2</p></figcaption></figure>

## 何时使用此卡片

此条件用于将单据中的数值字段与固定参考值进行比较，并允许指定的偏差。例如，参考值为 100 时，总金额与其相差不超过 5 即可视为匹配。

## 在哪里找到此卡片

在标准工作流设计器的 **和** 部分添加卡片，打开 **文档字段**，选择将一个字段与参考值进行容差比较的卡片。以下示例使用版本 2。

## 设置

使用组织中已配置的数值字段。字段值、参考值和容差均按数值计算，三者的单位应保持一致。

| 设置 | 含义 |
| --- | --- |
| 字段名称 | 已配置的单据字段，例如 `total_amount`。 |
| 运算符 | 比较方式：`eq`、`neq`、`gt`、`ge`、`lt` 或 `le`。 |
| 参考值 | 用于与字段值比较的固定数值。 |
| 容差 | 允许的数值偏差。 |
| 容差类型 | `value` 表示绝对数值偏差；**百分比** (`percent`) 表示相对偏差。 |

界面目前将 `value` 显示为 **价值**。此处表示绝对数值偏差，与经济价值无关。

例如，正参考值为 200、百分比容差为 5 时，允许的偏差为 10。绝对容差为 5 时，允许的偏差为 5。请根据所选运算符和数值检查相应的边界情况。

## 容差如何影响比较

参考值为 **100**、绝对容差为 **5** 时，下限为 **95**，上限为 **105**。

| 运算符 | 满足条件的字段值 |
| --- | --- |
| `eq` (=) | 介于 95 和 105 之间，包含两个边界值。 |
| `neq` (≠) | 小于 95 或大于 105。 |
| `gt` (>) | 大于 105。 |
| `ge` (≥) | 大于或等于 95。 |
| `lt` (<) | 小于 95。 |
| `le` (≤) | 小于或等于 105。 |

此卡片返回条件判断结果。后续步骤取决于工作流的触发条件、其他条件和已配置的操作。

## 实用示例

1. 选择已配置的数值字段 **总金额** (`total_amount`)。
2. 选择 **等于** (`eq`)。
3. 输入参考值 **100** 和容差 **5**。
4. 选择绝对容差类型 `value`，界面当前显示为 **价值**。

| 字段值 | 与 100 的绝对差值 | 预期结果 |
| --- | --- | --- |
| 103 | 3 | 满足条件。 |
| 110 | 10 | 不满足条件。 |
| 95 或 105 | 5 | 满足条件：相等比较包含容差边界。 |

以上是示例配置的预期计算结果。本示例未执行工作流。

## 启用规则之前

使用适当的测试数据，检查匹配、不匹配和边界情况。对字段缺失、非数值和配置错误分别进行排查。在执行日志中检查实际使用的数值、运算符、容差及结果。

如果两个金额都来自单据字段，请使用单独的[两个字段容差比较卡片](compare-two-fields-with-tolerance.md)。
