## **用途：**

此工作流卡片用于评估指定字段中的国家/地区是否属于某个贸易或政治区域（欧盟、申根区或 NAFTA）。根据评估结果，工作流可以通过 true 或 false 条件继续运行，从而在系统中执行后续操作。它特别适用于自动化区域特定的业务规则、确保合规，或根据地理归属触发特定工作流。

## **卡片组件：**

1. **字段名称**
   * **说明：** 指定存储国家/地区名称或代码的文档字段。
   * **详情：** 此字段应与文档中国家/地区数据的确切字段标识符一致。
2. **运算符**
   * **说明：** 指定所选字段中的国家/地区是否应与所选区域或协定匹配。
   * **选项：**
     * **是：** 若要使条件为 true，该国家/地区必须属于所选协定（欧盟、申根区或 NAFTA）。
     * **不是：** 若要使条件为 true，该国家/地区不得属于所选协定。
3. **国家/地区比较**
   * **说明：** 定义是否将字段中的国家/地区与特定政治或贸易协定进行比对。
   * **选项：**
     * **欧盟：** 卡片会检查该国家/地区是否为欧盟成员。
     * **申根区：** 卡片会检查该国家/地区是否属于申根区。
     * **NAFTA：** 卡片会检查该国家/地区是否为 NAFTA 协定成员。
4. **布尔值**
   * **说明：** 定义比较结果。如果该国家/地区符合条件，工作流将按指定的布尔值继续运行。
   * **选项：**
     * **真实情况：** 条件匹配时，工作流继续运行。
     * **False：** 条件不匹配时，工作流继续运行。

## **功能：**

* **条件评估：**
  * 系统会根据所选运算符，评估字段中指定的国家/地区是否属于所选区域或协定（欧盟、申根区或 NAFTA）。评估时会将国家/地区名称或代码与各组预定义的成员列表进行比对。
* **执行操作：**
  * **True 条件：** 如果字段中的国家/地区与所选区域匹配（根据运算符判断），工作流将按指定的 true 条件继续运行。这可以触发后续操作，例如路由文档、应用特殊处理规则，或启用区域特定功能。
  * **False 条件：** 如果该国家/地区与所选区域不匹配（根据运算符判断），工作流将按指定的 false 条件继续运行，以便根据系统设置执行其他操作或终止工作流。

## **设置和配置：**

* 用户通过选择包含国家/地区的文档字段并指定区域（欧盟、申根区或 NAFTA）来配置此卡片。然后，从下拉列表中选择运算符，以定义该国家/地区必须属于还是不得属于所选区域。最后，用户设置继续条件（true 或 false），以决定工作流的下一步。

## **结论：**

“字段中的国家/地区比较”工作流卡片是自动化地理规则相关流程的重要工具，例如确保遵守贸易协定或政治归属规则。通过将国家/地区数据与欧盟、申根区或 NAFTA 等特定区域进行比对，此卡片可确保系统应用正确的处理逻辑，从而提高效率，并确保工作流根据地理条件准确执行。

## 实际例子

**何时使用：** 按国家/地区分隔文档。

**配置：** 选择包含`DE`的文档国家/地区字段，选择包含德国的区域并将延续选项设置为`true`。

**预期结果及反例：** 德国国家代码满足所选地区。该区域之外的代码则不会；当您需要反向分支时，请单独测试延续选项。

这是说明性配置和预期结果。使用测试组织中配置的字段、用户和组；这并不是说这个例子已经被执行了。
