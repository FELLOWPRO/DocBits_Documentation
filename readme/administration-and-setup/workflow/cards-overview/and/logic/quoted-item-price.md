# 报价商品价格

<figure><img src="../../../../../.gitbook/assets/image (46).png" alt="" width="563"><figcaption></figcaption></figure>

## **用途：**

此 DocBits 卡片用于比较商品的报价价格与合同价格，让工作流根据两者相同或不同来触发操作。它有助于确保价格一致，并遵守合同条款。

## **功能：**

* **价格比较：** 此卡片会评估商品报价是否符合相对于合同价格的指定条件。
* **运算符：** 可应用以下条件：
  * **等于 (=)：** 检查报价价格是否与合同价格相同。
  * **不等于 (≠)：** 确保报价价格与合同价格不同。

## **用途场景：**

此卡片特别适用于采购、销售或合同管理工作流。在继续审批或处理订单之前，验证报价是否符合约定的合同条款至关重要。

## **示例场景：**

* 用户将卡片配置为检查**报价价格是否等于 (=)** **合同价格**。如果价格相同，工作流将继续审批；如果不同，则会触发通知，以便人工审核并解决差异。

通过使用“报价商品价格与合同价格”卡片，组织可以执行价格政策、确保遵守合同，并减少财务交易中的错误。
