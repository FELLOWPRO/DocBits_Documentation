## 何时使用此卡

使用此操作请求为当前单据配置的 MTZ/ETZ 材料和能源附加费计算。首先准备好您组织所需的文档数据和计算服务配置。

## 实际配置

显示的卡片没有成本增加系数、基本成本字段或附加费字段输入。它将计算委托给配置的服务。不要寻找这些不存在的卡控件或从卡名称中假设固定的百分比公式。

## 结果与验证

成功的服务响应标志着该卡成功。超时或不成功的响应会产生卡错误。检查卡日志和文件产生的附加费数据；仅通话成功并不能记录具体金额。

在卡测试模式下，将跳过调用并模拟成功。这对于测试工作流结构很有用，但并不能证明服务已运行或计算了任何附加费。
