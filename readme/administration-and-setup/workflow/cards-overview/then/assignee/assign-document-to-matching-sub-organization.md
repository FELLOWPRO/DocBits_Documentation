# 将文档分配给匹配的子组织

<figure><img src="../../../../../.gitbook/assets/image (376).png" alt="" width="563"><figcaption></figcaption></figure>

## **用途：**

**“根据字段将文档分配给匹配的子组织”**工作流卡片会根据文档中的指定字段，动态地将文档分配给子组织。如果未找到匹配的子组织，卡片会使用预先设定的备用子组织。

## **卡片组件：**

1. **字段名称**
   * **说明：**指定用于确定匹配子组织的文档字段。
   * **详情：**卡片会查找指定字段中的值，并将其与可用子组织进行匹配。
2. **子组织（备用）**
   * **说明：**定义在指定字段中未找到匹配项时使用的备用子组织。
   * **详情：**如果字段值与任何子组织都不匹配，文档将被分配给所选的备用子组织。

## **功能：**

* **条件评估：**\
  只有当 **“Where”** 和 **“And Sections”** 的评估结果均为 true 时，卡片才会执行操作。
* **动态分配：**\
  卡片会检查指定字段的值，并将文档分配给与该值匹配的子组织。
* **备用机制：**\
  如果未找到匹配的子组织，文档将被分配给备用子组织。

## **设置和配置：**

* **选择字段名称：**\
  选择文档中包含待匹配子组织值的字段。
* **选择备用子组织：**\
  选择在文档字段中未找到匹配项时使用的子组织。

## **结论：**

**“根据字段将文档分配给匹配的子组织”**工作流卡片可以灵活地将文档动态路由到相应的子组织，并提供备用选项，确保每份文档都能分配到子组织。
