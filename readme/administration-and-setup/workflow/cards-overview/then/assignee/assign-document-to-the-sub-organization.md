# 将文档分配给子组织

<figure><img src="../../../../../.gitbook/assets/image (375).png" alt="" width="563"><figcaption></figcaption></figure>

## **用途：**

**“将文档分配给子组织”**工作流卡片会将文档分配给系统中的特定子组织，确保文档被路由到相应的组织单元进行处理。

## **卡片组成部分：**

1. **子组织**
   * **说明：**指定要将文档分配到的子组织。
   * **详情：**系统会提供可用子组织的下拉列表，供用户选择目标子组织。

## **功能：**

* **条件评估：**\
  只有当 **“Where”** 和 **“And Sections”** 均评估为真时，卡片才会执行操作。
* **文档分配：**\
  卡片会将文档分配给从下拉列表中选择的子组织。

## **设置和配置：**

* **选择子组织：**\
  从下拉列表中选择要分配文档的适当子组织。

## **结论：**

**“将文档分配给子组织”**工作流卡片可确保文档被路由到正确的子组织，并根据组织结构分配责任，从而简化文档管理流程。
