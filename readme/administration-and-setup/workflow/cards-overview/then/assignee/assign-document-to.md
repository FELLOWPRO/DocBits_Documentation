# 分配文档至

<figure><img src="../../../../../.gitbook/assets/image (379).png" alt="" width="563"><figcaption></figcaption></figure>

## 用途：

**“根据决策表将文档分配给[用户/组]”**工作流卡片会根据**决策表**的结果，动态地将文档分配给用户或组。此功能可根据预定义条件高效、一致地处理文档分配。

## 卡片组件：

1. **用户/组**
   * **说明：**指定接收文档的**用户**或**组**。
   * **详情：**根据**决策表**的结果进行选择。
2. **决策表**
   * **说明：**使用**决策表**确定接收文档的适当**用户**或**组**。
   * **详情：**使用 **“and”** 部分中定义的决策表。

## 功能：

* **条件评估：**只有当 **“Where”** 和 **“And Sections”** 均评估为 true 时，此卡片才会执行操作。
* **动态分配文档：**文档将分配给由**决策表**确定的**用户**或**组**。

## 设置和配置：

* **定义决策表：**设置**决策表**，其中包含用于确定目标**用户**或**组**的条件。
* **将文档分配给用户/组：**系统将根据决策表的结果动态分配文档。

## 结论：

**“根据决策表将文档分配给[用户/组]”**工作流卡片可根据决策逻辑动态分配文档。它会自动将文档发送给适当的**用户**或**组**，从而提升工作流自动化，并确保处理准确、高效。
