# 顺序分配给组

## **用途**

“**按顺序将文档分配给组**”工作流卡片可将文档依次分配给一个或多个选定的组。优先级值决定分配顺序，数值越小，优先级越高。

## **卡片组件**

1. **组**
   * **描述**：指定将接收文档分配的组。
   * **详情**：一个下拉菜单，可选择一个或多个组来接收分配的文档。
2. **优先级（值）**
   * **描述**：一个数字输入字段，可用于设置组的优先级。
   * **详情**：数值越小，优先级越高，从而确保文档按照优先级升序分配给各组。

## **功能**

* **文档分配**：\
  此卡片根据所选组的优先级值，依次将文档分配给这些组。\
  如果多个组的优先级相同，则按照选择这些组的顺序分配文档。

## **设置和配置**

1. 将 **按顺序分配文档** 卡片添加到工作流中。
2. 配置 **组** 字段：
   * 从下拉菜单中选择一个或多个组。
3. 配置 **优先级（值）** 字段：
   * 输入数字以设置分配优先级。
4. 保存并激活工作流以应用配置。

## **结论**

“按顺序将文档分配给组”工作流卡片可根据优先级，高效地将文档分配给一个或多个组。此功能支持在多个团队或部门之间灵活、有序地处理文档。

## 实际例子

**何时使用：** 优先将文档分配给审核团队。

**配置：** 选择已配置的演示组并设置所需的优先级，例如`10`。

**预期结果和反例：**文档以该优先级接收选定的组分配。当各组必须占据不同阶段时，单独测试第二优先级。
