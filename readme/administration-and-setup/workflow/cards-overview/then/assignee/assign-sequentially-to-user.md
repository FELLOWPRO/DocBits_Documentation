## **用途**

“**依次分配给用户**”工作流卡片会按照顺序将文档分配给所选用户。优先级值决定分配顺序，数值越小，优先级越高。

## **卡片组件**

1. **用户**
   * **说明**：根据工作流顺序，将文档分配给所选用户。
   * **详情**：下拉菜单，列出所有可供分配的用户。
2. **优先级（值）**
   * **说明**：用于设置用户优先级的数字输入字段。
   * **详情**：数值越小，优先级越高。文档按优先级从低到高的顺序分配给用户。

## **功能**

* **文档分配**：\
  此卡片会考虑优先级，依次将文档分配给所选用户。\
  如果多个用户的优先级相同，则按照他们在下拉菜单中的显示顺序分配文档。

## **设置和配置**

1. 将 **依次分配文档** 卡片添加到工作流中。
2. 配置 **用户** 字段：
   * 从下拉菜单中选择一个用户。
3. 配置 **优先级（值）** 字段：
   * 输入数字以设置分配优先级。
4. 保存并启用工作流以应用配置。

## **总结**

“依次分配给用户”工作流卡片会按照优先级顺序分配文档，确保文档分配井然有序。这有助于改进任务管理并减少处理延迟。

## 实际例子

**何时使用：** 将用户添加到优先文档审批序列中。

**配置：**选择`Demo Reviewer A`和优先级`10`。当需要稍后的审阅者时，添加优先级为 `20` 的单独作业。
