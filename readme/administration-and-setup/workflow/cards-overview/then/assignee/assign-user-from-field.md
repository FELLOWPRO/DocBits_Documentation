# 根据字段分配用户

<figure><img src="../../../../../.gitbook/assets/image (372).png" alt="" width="563"><figcaption></figcaption></figure>

## **用途：**

**“使用备用用户根据字段分配用户”**工作流卡片会根据指定文档字段中的值动态分配用户。如果该字段中没有有效用户，系统会从预定义的可用用户列表中选择一名备用用户，以确保任务或操作得到妥善分配。

## **卡片组件：**

1. **字段名称**
   * **描述：**指定包含待分配用户信息的**文档字段**。
   * **详细说明：**系统会评估此字段，以确定应分配给哪位用户。如果字段中包含有效用户，该用户将获得此任务。如果字段为空或无效，则会分配给备用用户。
2. **用户（备用）**
   * **描述：**指定在文档字段中没有有效用户时要分配的**备用用户**。
   * **详细说明：**系统会提供包含所有可用用户的下拉列表供选择。如果文档字段为空或不包含有效用户，则会分配给此用户。

## **功能：**

* **条件评估：**\
  仅当 **“Where”** 和 **“And Sections”** 的评估结果均为 true 时，卡片才会执行操作。
* **基于字段分配用户：**\
  卡片会先尝试将任务或操作分配给 **Field Name** 中指定的用户。
* **分配备用用户：**\
  如果字段中没有有效用户（或字段为空），卡片会将任务分配给从 **User (Fallback)** 下拉列表中选择的备用用户。

## **设置和配置：**

* **选择字段名称：**\
  选择用于指定待分配用户的**文档字段**。
* **选择备用用户：**\
  从下拉列表中选择**备用用户**。如果文档字段中没有有效用户，系统会将任务分配给此用户。

## **结论：**

**“使用备用用户根据字段分配用户”**工作流卡片可确保任务或操作始终分配给有效用户。如果文档字段中的用户不可用，系统会自动分配给备用用户，从而提供灵活性并确保任务完成。
