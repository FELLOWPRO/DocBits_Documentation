# 将复选框设为

<figure><img src="../../../../../.gitbook/assets/image (355).png" alt="" width="563"><figcaption></figcaption></figure>

## **用途：**

此工作流卡片旨在根据 **“Where”** 和 **“And”** 部分中定义的条件，将复选框字段设为指定值（true 或 false）。当满足特定条件时，它可以简单有效地自动更新复选框，从而简化文档处理流程。

## **卡片组成部分：**

1. **字段名称：**
   * **说明**：指定要设置复选框的字段。
   * **详细信息**：通过字段名称标识需要更新的复选框字段。
2. **布尔值**
   * **说明**：当 **Where** 和 **And 部分**中的条件均为 true 时，定义复选框字段要设置的值。
   * **选项**：
     * **True**：满足条件时，复选框将设为 **true**。
     * **False**：满足条件时，复选框将设为 **false**。

## **功能：**

* **条件评估**：系统会评估 **“Where”** 和 **“And”** 中的条件。
* **执行操作**：如果 **“Where”** 和 **“And 部分”**的评估结果均为 true，复选框字段将更新为指定值（true 或 false）。如果任一条件为 false，则不会执行任何操作，复选框保持原样。

## **设置和配置：**

要配置此卡片，用户需要：

1. **指定目标复选框字段**，条件满足时该字段将设为 true 或 false。
2. **选择要设置的值（true 或 false）**，以便在评估条件后应用于复选框。
3. 仅当 **“Where”** 和 **“And 部分”**中的条件评估结果均为 true 时，卡片才会执行操作。

## **结论：**

**“Set Checkbox”** 工作流卡片是一种简单有效的自动化工具，可根据特定条件更新复选框字段。确保 **“Where”** 和 **“And 部分”**均满足条件后，它便能帮助用户自动化流程、减少人工干预，使文档处理更加顺畅高效。
