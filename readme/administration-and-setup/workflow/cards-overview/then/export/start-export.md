# 开始导出

<figure><img src="../../../../../.gitbook/assets/image (361).png" alt="" width="563"><figcaption></figcaption></figure>

## **用途：**

**“Start Export”（开始导出）**工作流卡片用于启动文档导出流程。此卡片在工作流中充当触发器：当前置部分的条件满足后，它会顺利启动导出操作。

## **卡片组件：**

1. **操作**
   1. **说明**：启动文档导出流程。
   2. **详细信息**：此卡片使用系统中配置的导出设置来处理并导出文档。

## **功能：**

* **条件评估**：系统会评估工作流中 **“Where”** 和 **“And Sections”** 部分设置的条件。所有条件均为真时，导出流程便会开始。
* **文档导出**：系统使用默认导出配置或先前定义的导出配置来处理并导出文档。

## **设置和配置：**

此卡片使用系统中已定义的导出设置，因此无需进行特定配置。用户需要确保：

1. 正确配置 **“Where”** 和 **“And Sections”** 条件，因为只有这些条件的评估结果均为真时，此卡片才会执行。
2. 系统中已为该文档关联有效的导出配置。

## **结论：**

**“Start Export”（开始导出）**工作流卡片提供了一种简化且自动化的方式来触发导出流程。它依托预先配置的设置和条件评估，确保高效、准确地处理文档。
