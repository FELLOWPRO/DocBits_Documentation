## **用途：**

**“Change Entries in Table”（更改表中的条目）**工作流卡用于更新指定数据库表中的条目。您可以选择一个**表**和一个**列**，然后使用指定的值对该列中的数值执行数学运算（加法、减法、乘法或除法）。

## **卡片组件：**

1. **表名称**
   * **说明：**指定要更新条目的**表**。
   * **详细信息：**系统会提供可用**表**的下拉列表，供您选择要更新条目的目标表。
2. **列名称**
   * **说明：**指定所选表中要更新的**列**。
   * **详细信息：**系统会提供所有可用**列**的列表供您选择。
3. **运算**
   * **说明：**定义要对**列**中的数值执行的数学运算。
   * **选项：**
     * **加法 (+)：**将指定的**值**加到所选列中的当前值上。
     * **减法 (-)：**从所选列中的当前值中减去指定的**值**。
     * **乘法 (\*)：**将所选列中的当前值乘以指定的**值**。
     * **除法 (/)：**将所选列中的当前值除以指定的**值**。
4. **值**
   * **说明：**指定所选运算要使用的**值**。
   * **详细信息：**这是要与所选列中的条目相加、相减、相乘或相除的数值。

## **功能：**

* **条件评估：**\
  仅当 **“当”** 和 **“且”** 的评估结果均为 true 时，此卡片才会执行操作。
* **更新表条目：**\
  此卡片会使用指定的**值**，对所选**表**中所选**列**的数值执行所选运算（**+**、**-**、**\*** 或 **/**）。

## **设置和配置：**

* **选择表：**\
  选择要应用更改的**表**。
* **选择列：**\
  选择表中要更新的**列**。
* **选择运算：**\
  选择要应用于所选列中数值的数学运算（**+**、**-**、**\***、**/**）。
* **输入值：**\
  输入所选运算要使用的**值**。

## **结论：**

**“Change Entries in Table”（更改表中的条目）**工作流卡可通过选择**表**、**列**和所需的**数学运算**，自动更新数据库条目。此卡片对于在数据库中执行批量数据修改或计算至关重要。
