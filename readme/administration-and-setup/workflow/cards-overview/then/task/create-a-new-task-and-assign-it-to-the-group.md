# 创建新任务并分配给群组

<figure><img src="../../../../../.gitbook/assets/image (365).png" alt="" width="563"><figcaption></figcaption></figure>

## **用途：**

**“Create Group Task or Notification”（创建群组任务或通知）**工作流卡片可为指定群组创建任务或通知，确保沟通和任务管理高效进行。较新版本增强了决策树功能，可动态确定分配的群组或方式，从而简化操作。

## **卡片组件：**

1. **标题**
   * **说明**：指定任务或通知的标题。
   * **详情**：作为已创建任务或通知的标识。
2. **描述**
   * **说明**：描述任务或通知的背景或详情。
   * **详情**：阐明其用途。
3. **优先级**
   * **说明**：设置任务的重要程度。
   * **选项**：
     * **High（高）**：需要立即处理。
     * **Medium（中）**：较重要，但紧急程度较低。
     * **Low（低）**：可以稍后处理。
4. **分配群组**
   * **说明**：指定负责该任务或通知的群组。
   * **详情**：从可用群组的下拉列表中选择。
5. **电子邮件通知**
   * **说明**：启用向已分配的群组发送电子邮件通知。
   * **选项**：
     * **True（是）**：发送电子邮件通知。
     * **False（否）**：不发送电子邮件通知。

## **Version 3 和 Version 4 中的其他组件**

1. **决策树（仅限 Version 3）**
   * **说明**：启用决策树以动态创建任务。
   * **选项**：
     * **True（是）**：启用决策树处理。
     * **False（否）**：禁用决策树处理。
2. **任务/通知选项** **（仅限 Version 4）**
   * **说明**：允许创建任务或通知。
   * **选项**：
     * **Task（任务）**：为所选群组创建任务。
     * **Notification（通知）**：发送通知，而不是创建任务。

## **功能：**

* **条件评估**：\
  仅当 **“Where”** 和 **“And Sections”** 均为 true 时，才执行卡片操作。
* **创建任务或通知**：
  * 为所选群组创建任务，并设置指定的标题、描述和优先级。
  * 在 Version 4 中，该卡片可以创建通知，而不是任务。
* **动态分配（仅限 Version 3）**：\
  如果启用，决策树会动态确定目标群组。
* **电子邮件通知**：\
  如果电子邮件选项设为 true，则向群组发送电子邮件通知。

## **设置和配置：**

1. **定义任务或通知详情**：输入标题、描述和优先级。
2. **分配给群组**：从下拉列表中选择一个群组，以分配任务或通知。
3. **启用电子邮件通知**：指定是否应通过电子邮件通知该群组。
4. **使用决策树（仅限 Version 3）**：启用决策树以动态分配群组。
5. **选择输出类型（仅限 Version 4）**：选择该卡片创建任务还是通知。

## **结论：**

**“Create Group Task or Notification”（创建群组任务或通知）**工作流卡片通过直接面向群组简化了任务和通知管理。决策树启用的动态分配功能提升了灵活性，而电子邮件通知则确保沟通及时。Version 3 和 Version 4 增加了高级功能，使其成为高效执行工作流的多用途工具。
