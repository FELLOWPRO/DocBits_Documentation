## **用途：**

**“创建带备用用户的任务”**工作流卡片可将任务分配给特定角色（调度员或采购员），并通过备用机制避免任务分配失败，从而高效地分派任务。此卡片提升了工作流在动态场景中的可靠性和适应性。

## **卡片组件：**

1. **标题**
   * **说明**：指定要创建的任务标题。
   * **详情**：为任务提供简洁的标识。
2. **描述**
   * **说明**：描述任务的目的或背景。
   * **详情**：明确任务的具体内容。
3. **优先级**
   * **说明**：设置任务的紧急程度。
   * **选项**：
     * **高**：需要立即处理。
     * **中**：很重要，但不紧急。
     * **低**：可以稍后处理。
4. **分配角色**
   * **说明**：指定任务主要分配给哪个角色。
   * **选项**：
     * **调度员**：将任务分配给调度员。
     * **采购员**：将任务分配给采购员。
5. **电子邮件通知**
   * **说明**：启用后，可通过电子邮件通知被分配的用户。
   * **选项**：
     * **True**：向用户发送电子邮件通知。
     * **False**：不发送电子邮件通知。
6. **备用用户**
   * **说明**：如果未找到接收人角色，则提供备用任务分配选项。
   * **详情**：可从下拉列表中选择用户，以确保任务能够分派。

## **功能：**

* **条件评估**：\
  仅当满足**“当”**和**“且”**中的条件时，此卡片才会执行。
* **任务分配**：
  * 将任务分配给所选角色（调度员或采购员）。
  * 如果未找到指定角色，则将任务分配给备用下拉列表中的用户。
* **电子邮件通知**：\
  如果启用了电子邮件通知，则向被分配的用户发送电子邮件。

## **设置和配置：**

1. **指定任务详情**：输入任务标题、描述和优先级。
2. **选择主要角色**：选择任务的分配对象角色（调度员或采购员）。
3. **配置备用用户**：从下拉列表中选择备用用户，以便在未找到主要角色时仍能分配任务。
4. **启用电子邮件通知**：指定是否向被分配的用户发送电子邮件通知。

## **结论：**

**“创建带备用用户的任务”**工作流卡片通过整合备用机制，确保任务能够顺利分派。该卡片根据角色分配任务，并提供备用用户选项，从而提升任务管理流程的可靠性和灵活性。
