# 低于最高金额

<figure><img src="../../../../.gitbook/assets/Bildschirmfoto 2024-05-03 um 14.48.55.png" alt="工作流，Document type 为 Invoice，条件为 Total Amount Less Or Equals Approver Max Amount，并从 Approver Name 分配用户"><figcaption></figcaption></figure>

此标题表明，所设置的规则或条件用于处理总金额小于或等于指定最高金额的发票。

#### 规则配置：

1. **当……**
   * **文档类型为发票**：此条件用于检查正在处理的文档是否为发票。这对于确保规则仅适用于发票，而不适用于其他类型的文档，至关重要。
2. **并且……**
   * **文档状态为待审批**：这指定发票必须处于“待审批”（"Pending Approval"）状态。此状态检查可确保规则仅适用于等待审批的发票。
   * **比较两个字段：总金额小于或等于审批人最高金额**：此条件将发票的总金额与审批人获授权的最高金额进行比较。如果发票总金额小于或等于该最高金额，规则将继续执行下一步。这可能包含一个容差范围，允许在指定限度内存在细微偏差。

#### 操作（那么……）：

* **从字段审批人姓名分配用户，用户作为备用用户**：如果满足指定条件，系统会自动将发票分配给姓名由某个字段指定的审批人。如果此字段为空或不可用，则会分配默认用户（可能是管理员或其他指定员工）作为备用用户来处理审批。

#### 界面元素：

* **添加卡片**：此按钮可能允许用户为规则添加更多条件或操作，从而提高工作流的灵活性和针对性。
* **保存**：将配置好的规则保存到系统中。

#### 此规则的用途：

此设置旨在简化发票审批流程，根据金额自动将发票转给相应的审批人，并确保只有金额处于特定限额内的发票才会按此方式自动处理。它有助于管理财务控制，并通过减少对每张发票的人工检查来加快工作流。
