# Assign document to

<figure><img src="../../../../.gitbook/assets/image (306).png" alt="" width="563"><figcaption></figcaption></figure>

## Propósito:

O cartão de fluxo de trabalho **"Assign document to \[User/group] based on decision table"** atribui dinamicamente documentos a utilizadores ou grupos com base no resultado de uma **decision table**. Esta funcionalidade assegura que a atribuição de documentos é tratada de forma eficiente e consistente com base em condições predefinidas.

## Componentes do cartão:

1. **User/Group**
   * **Descrição:** Especifica o **utilizador** ou **grupo** ao qual o documento será atribuído.
   * **Detalhe:** Selecionado com base no resultado da **decision table**.
2. **Decision Table**
   * **Descrição:** Uma **decision table** é utilizada para determinar o **utilizador** ou **grupo** adequado para a atribuição do documento.
   * **Detalhe:** Utiliza a decision table definida na secção **"and"**.

## Funcionalidade:

* **Avaliação da condição:** O cartão só executa a sua ação se tanto a secção **"Where"** como as **"And Sections"** forem avaliadas como verdadeiras.
* **Atribuição dinâmica de documentos:** O documento é atribuído ao **utilizador** ou **grupo** determinado pela **decision table**.

## Configuração:

* **Definir a Decision Table:** Configure a **decision table** para incluir as condições para determinar o **utilizador** ou **grupo** de destino.
* **Atribuir documento a utilizador/grupo:** O documento será atribuído dinamicamente com base no resultado da decision table.

## Conclusão:

O cartão de fluxo de trabalho **"Assign document to \[User/group] based on decision table"** oferece capacidades de atribuição dinâmica de documentos com base em lógica de decisão. Isto assegura um processamento preciso e eficiente ao direcionar automaticamente os documentos para o **utilizador** ou **grupo** adequado, reforçando a automação do fluxo de trabalho.
