**展开一次执行**

展开工作流行。高级执行在左侧显示流程图，右侧显示消息。标准工作流显示卡片序列。可用数据描述的是当时的执行，可能与当前设计器中的配置不同。

**选择节点查看证据**

平移或缩放流程图，然后点击节点。卡片日志显示节点消息。Wait ALL 和 Wait ANY 等控制节点也可能显示节点级消息。阅读时同时核对所选节点和执行时间戳。

**区分不同结果**

绿色表示成功，橙色表示条件不成立，红色表示错误，灰色表示跳过。被跳过的节点没有执行。修改之前，先检查是否选择了其他分支，或合并节点是否缺少必要输入。

**从首次偏差开始跟踪**

从入口沿实际路径追踪。金额条件不成立时查看橙色路径；发生错误时阅读消息并查看红色路径。错误处理动作可能成功，但整次执行仍会报告原始错误。

**检查合并依据**

对于 Wait ALL，检查每个源节点及其连接的结果。对于 ANY 或 OR，找到匹配的源节点。同一源节点的两个输出并不是两次独立审批。橙色条件结果也可能符合设计。

**修正、测试并验证**

记录工作流名称、文档引用、时间戳、节点和完整消息。修正配置或数据，再测试可重复的场景。保存并检查激活状态。比较新旧执行。旧日志仍然描述当时的行为。

</details>

## **概述**

**工作流日志**允许用户分析某个文档执行了哪些工作流、了解执行结果，并深入查看条件级别的详细信息，以便进行调试或验证。

## **访问工作流日志**

要访问工作流日志：

1. 前往**仪表板**。
2. 点击所需文档旁的**操作菜单**（三点图标）。
3. 从菜单中选择**工作流日志**。
   * <mark style="color:red;">**注意**</mark>：必须启用工作流功能才能访问此选项。
4.  将打开一个**侧边面板**，显示已执行工作流的摘要。\\

## **工作流日志面板的组成部分**

#### **1. 工作流摘要计数器**

位于日志面板顶部：

* **蓝色**：已执行工作流的总数。
* **红色**：以**错误**结束的工作流。
* **黄色**：因条件不匹配而**未完成**的工作流。
* **绿色**：已成功**执行**的工作流。

#### **2. 工作流执行表**

表格中的每一行代表一次工作流执行，包含：

* **工作流名称**
* **时间戳**（创建时间）
* **运行时间**（秒）
* **结果图标**：
  * 绿色勾号：工作流已成功执行。
  * 红色叉号：工作流执行时发生错误。
  * 橙色短横线：由于未满足条件，执行已停止

点击每行左侧的**箭头**可展开**工作流详细信息视图**。

### **工作流详细信息视图**

点击某个工作流行会打开其**详细执行日志**，其中显示：

#### **条件评估**

* **When...** 区块：初始条件。
* **And...** 区块：附加条件。
* **Then...** 区块：所有条件均满足时执行的操作。

每个条件行会显示：

* **绿色勾号**：条件已满足。
* **橙色短横线**：条件未满足。
* **红色叉号**：条件因**错误而失败**

### **重要行为说明**

如果工作流中的某个条件**未满足**，系统会**停止评估该工作流中的所有后续工作流卡片**。此行为可避免不必要的处理\
作为视觉提示，**未满足其条件**的卡片会显示为**灰色**，同一工作流中的所有**后续卡片**也会显示为**灰色**，表示它们**尚未执行**。
