# Den Lernspeicher eines KI-Agenten prüfen

Der Lernspeicher enthält wiederverwendbare Erkenntnisse eines AI-Workforce-Agenten. Prüfen Sie ihn bei wiederholtem falschem oder veraltetem Verhalten. Er ist von Prompt, Zusatzanweisungen, Werkzeugen und Freigabemodus getrennt.

## Erkenntnisse prüfen

1. Öffnen Sie **AI Workforce → Agenten** und den gewünschten Agenten.
2. Suchen Sie im Profil den Bereich mit seinen gelernten Erkenntnissen. Prüfen Sie Agent und Organisation.
3. Lesen Sie Inhalt und Quelle: Nutzerfeedback, Selbstreflexion oder einzelne Erfahrungen. Die Quelle belegt keine Richtigkeit.
4. Prüfen Sie Konfidenz, Nutzungszahl und Tags. Hohe Konfidenz oder häufige Nutzung ersetzen keine fachliche Prüfung.
5. Filtern Sie nach verfügbarer Quelle oder laden Sie weitere Einträge. Vergleichen Sie fragliche Erkenntnisse mit Mission, Aufgabe und Geschäftsregel.

## Bewerten oder entfernen

1. Bewerten Sie hilfreiche Erkenntnisse mit **Daumen hoch**, unbrauchbare mit **Daumen herunter**. Warten Sie auf die Antwort und prüfen Sie die Bewertung.
2. Halten Sie vor einer Entfernung die fachliche Begründung intern fest und prüfen Sie Ihre Berechtigung.
3. Wählen Sie das **Löschsymbol** der betreffenden Erkenntnis. Es entfernt den Eintrag und öffnet keinen Editor. Verlassen Sie sich nicht auf eine zweite Rückfrage.
4. Laden Sie das Profil neu und prüfen Sie, ob der richtige Eintrag fehlt. Frühere Agentenaktionen und Missionsverlauf werden dadurch nicht rückgängig gemacht.
5. Testen Sie einen neuen unkritischen Fall. Bleibt das Verhalten bestehen, prüfen Sie auch Prompt, Zusatzanweisungen, Werkzeuge und Eingangsdaten.

Ein leerer Bereich kann bedeuten, dass keine Erkenntnisse vorliegen. Ein Ladefehler ist ein anderer Zustand: Lesen Sie die Meldung und laden Sie das Profil erneut.

Siehe [AI Workforce](ai_workforce/README.md) für Agenteneinstellungen, Missionen und Freigaben.
