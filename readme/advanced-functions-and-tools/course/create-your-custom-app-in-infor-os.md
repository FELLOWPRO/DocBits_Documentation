{% hint style="warning" %}
Wenn Ihre benutzerdefinierte App die DocBits-API-Spezifikation importiert, verwenden Sie die **Swagger-2.0**-Spezifikation (`/openapi-swagger2.json`), nicht die OpenAPI-3.0-Spezifikation. Das ältere swagger-ui von Infor OS benötigt den 2.0-Dialekt, um Datei-Uploads korrekt aufzubauen – andernfalls schlagen Uploads mit `400 — Missing boundary in multipart` fehl. Die vollständige Erklärung und wie Sie die URL kopieren, finden Sie unter [Infor OS mit DocBits-API-Integration](infor-os-with-docbits-api-integration.md).
{% endhint %}
