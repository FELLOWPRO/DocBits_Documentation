{% hint style="warning" %}
Wanneer uw eigen app de DocBits API-specificatie importeert, gebruik dan de **Swagger 2.0**-specificatie (`/openapi-swagger2.json`) en niet de OpenAPI 3.0-specificatie. De oudere swagger-ui van Infor OS heeft het 2.0-dialect nodig om bestandsuploads correct op te bouwen. Anders mislukken uploads met `400 — Missing boundary in multipart`. Zie [Infor OS met DocBits API-integratie](infor-os-with-docbits-api-integration.md) voor de volledige uitleg en hoe u de URL kopieert.
{% endhint %}
