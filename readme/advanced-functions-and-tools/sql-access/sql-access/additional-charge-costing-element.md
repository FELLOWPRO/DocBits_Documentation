## 表文档：`public.additional_charge_costing_element`

### 简介

`public.additional_charge_costing_element` 表用于管理和存储组织内各种附加费用成本要素的信息。数据包括费用类型、费用分配方式，以及创建和修改等管理元数据。该表可能用于组织的财务和运营管理，重点是需要跟踪和分析的附加成本。

### 列说明

#### id

* **含义**：此列存储表中每条记录的唯一标识符。
* **作用**：主键。
* **典型内容**：用于标识每条成本要素记录的唯一字母数字字符串。

#### org\_id

* **含义**：成本要素所属组织的标识符。
* **作用**：外键。
* **典型内容**：表示该组织的 UUID。

#### costing\_element

* **含义**：成本要素的标识符或代码。
* **作用**：描述性字段。
* **典型内容**：表示具体成本要素的字母数字字符串。

#### description

* **含义**：成本要素的文本描述。
* **作用**：描述性字段。
* **典型内容**：对成本要素的简短文本说明。

#### charge\_type

* **含义**：与此成本要素关联的费用类型。
* **作用**：描述性字段。
* **典型内容**：表示费用类型的代码或简短文本。

#### distribution\_method

* **含义**：费用的分配方式。
* **作用**：描述性字段。
* **典型内容**：表示分配方式的代码或简短文本。

#### distribution\_type

* **含义**：费用的分配类型。
* **作用**：描述性字段。
* **典型内容**：表示分配类型的代码或简短文本。

#### created\_by

* **作用**：管理字段。
* **典型内容**：表示用户 ID 的整数。

#### created\_on

* **含义**：记录的创建时间戳。
* **作用**：管理字段。
* **典型内容**：包含时区信息的时间戳。

#### last\_modified\_on
