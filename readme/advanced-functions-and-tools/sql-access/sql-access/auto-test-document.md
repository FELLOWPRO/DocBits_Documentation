# 自动测试文档

## 列

* `id`：内部字段
* `org_id`：组织 ID
* `doc_id`：内部字段
* `doc_type`：文档类型
* `extracted_data`：文本
* `created_by`：整数
* `created_on`：带时区的时间戳
* `last_modified_on`：带时区的时间戳
* `is_deleted`：布尔值
* `filename`：内部字段

## 分析与描述

```markdown
# 表文档：`public.auto_test_document`

## 简介

`public.auto_test_document` 表用于存储组织内文档处理的元数据和提取结果。该表记录文档、文档类型以及从文档中提取的数据。表中包含文档标识、处理元数据和状态标记等字段，这些信息对于管理文档工作流和确保数据完整性至关重要。

## 字段说明

### id
- **含义**：表中每条文档记录的唯一标识符。
- **作用**：主键。
- **典型内容**：UUID 字符串。
- **备注**：作为记录的唯一标识符，确保每条记录都不重复。

### org_id
- **含义**：与该文档关联的组织标识符。
- **作用**：外键。
- **典型内容**：UUID 字符串。
- **备注**：将文档关联到系统中的特定组织。

### doc_id
- **含义**：正在处理的文档标识符。
- **作用**：外键。
- **典型内容**：UUID 字符串。
- **备注**：用于将提取的数据与原始文档关联起来。

### doc_type
- **含义**：文档的类型或类别。
- **作用**：描述性字段。
- **典型内容**：字符串，例如 "MEDI_ORDER"。
- **备注**：有助于对文档进行分类，以便处理和分析。

### extracted_data
- **含义**：包含从文档中提取的详细数据的 JSON 结构。
- **作用**：数据字段。
- **典型内容**：包含字段、值和提取元数据的 JSON 文本。
- **备注**：存储文档数据提取流程的结果。

### created_by
- **含义**：创建该文档记录的用户标识符。
- **作用**：描述性字段。
- **典型内容**：表示用户 ID 的整数。
- **备注**：记录是哪位用户发起了该文档记录在系统中的创建。

### created_on
- **含义**：指示文档记录创建时间的时间戳。
- **作用**：技术字段。
- **典型内容**：包含时区信息的日期和时间。
- **备注**：便于审计和跟踪文档的生命周期。

### last_modified_on
- **含义**：指示文档记录最后一次修改时间的时间戳。
- **作用**：技术字段。
- **典型内容**：包含时区信息的日期和时间。
- **备注**：有助于跟踪文档记录的变更和更新。

### is_deleted
- **含义**：指示文档记录是否已标记为删除的标记。
- **作用**：状态字段。
- **典型内容**：布尔值。
- **备注**：支持对记录进行软删除，以便在需要时恢复。

### filename
- **含义**：与文档关联的文件名。
- **作用**：描述性字段。
- **典型内容**：字符串，例如 "7.pdf"。
- **备注**：提供指向与该文档记录关联的物理文件的引用。
```
