## `public.electronic_document_extraction_attributes` 技术文档

### 简介

`public.electronic_document_extraction_attributes` 表用于管理与电子文档提取相关的属性。它会存储有关电子文档类型、处理方法及相关组织的各种特征和元数据。该表似乎支持文档类型识别、转换、预览和结构描述等功能，这些功能对于有效处理电子文档至关重要。

### 列说明

#### id

* **含义**：表中每条记录的唯一标识符。
* **作用**：主键。
* **典型内容**：唯一标识每条文档提取属性记录的 UUID 字符串。
* **说明**：作为每一行的唯一引用。

#### org\_id

* **含义**：与文档属性相关的组织标识符。
* **作用**：外键。
* **典型内容**：用于关联相应组织的 UUID 字符串。
* **说明**：将文档提取属性关联到特定组织。

#### doc\_type\_key

* **含义**：表示文档类型的键。
* **作用**：用于对文档进行分类的标识符。
* **典型内容**：表示文档类型的字符串，例如 'INVOICE' 或 'ORDER\_CONFIRMATION'。
* **说明**：用于确定文档所属的类别。

#### sub\_doc\_type\_key

* **含义**：表示主文档类型子类别的键。
* **作用**：用于进一步分类的标识符。
* **典型内容**：空值或特定的子类型字符串。
* **说明**：有助于更细致地对文档进行分类。

#### electronic\_document\_type

* **含义**：电子文档的格式或标准。
* **作用**：用于描述文档格式的字段。
* **典型内容**：例如 'EDI' 或 'FACTURX' 的字符串。
* **说明**：表示文档采用的标准或格式。

#### attribute\_name

* **含义**：与文档提取过程相关的属性名称。
* **作用**：描述性字段。
* **典型内容**：例如 'PREVIEW' 或 'TRANSFORMATION' 的字符串。
* **说明**：描述与文档处理相关的具体属性。

#### attribute\_type

* **含义**：与文档提取相关的属性类型。
* **作用**：描述性字段。
* **典型内容**：例如 'XSLT' 或 'JSON' 的字符串。
* **说明**：指定属性使用的数据格式或方法。

#### created\_by

* **含义**：创建记录的用户 ID。
* **作用**：外键。
* **典型内容**：表示用户 ID 的整数。
* **说明**：记录最初创建该记录的用户。

#### created\_on

* **含义**：记录创建时间。
* **作用**：技术字段。
* **典型内容**：UTC 日期和时间。
* **说明**：表示记录的创建时间。

#### last\_modified\_on

* **含义**：记录上次修改的时间。
* **作用**：技术字段。
* **典型内容**：UTC 日期和时间；如果未修改，则为空值。
* **说明**：记录最近一次更新的时间。

#### is\_deleted

* **含义**：表示记录是否已标记为删除。
* **作用**：技术字段。
* **典型内容**：布尔值 `True` 或 `False`。
* **说明**：用于处理软删除。

#### deleted\_on

* **含义**：记录标记为删除的时间。
* **作用**：技术字段。
* **典型内容**：UTC 日期和时间；如果未删除，则为默认的远古日期。
* **说明**：用于追踪记录的删除时间。

#### last\_modified\_by

* **含义**：上次修改记录的用户 ID。
* **作用**：外键。
* **典型内容**：UUID 字符串；如果未修改，则为空值。
* **说明**：标识负责上次修改的用户。

#### deleted\_by

* **含义**：将记录标记为删除的用户 ID。
* **作用**：外键。
* **典型内容**：UUID 字符串；如果未删除，则为空值。
* **说明**：追踪执行删除操作的用户。
