## 技术文档：`public.rest_api_lookup_configurations` 表

### 简介

`public.rest_api_lookup_configurations` 表用于存储组织内 REST API 查找的配置。此表包含执行 API 请求所需的重要信息，包括端点、身份验证方法以及请求和响应配置。它似乎用于动态构建 API 调用并解析其结果。

### 列说明

#### id

* **含义**：每个配置条目的唯一标识符。
* **作用**：主键。
* **典型内容**：类似 `5e9b3637-79a1-4535-99cf-9247dfa48960` 的 UUID 字符串。
* **备注**：用于标识特定 API 查找配置的唯一键。

#### org\_id

* **含义**：拥有该配置的组织的标识符。
* **作用**：外键。
* **典型内容**：表示组织 ID 的 UUID 字符串。
* **备注**：将配置关联到某个组织。

#### sub\_org\_id

* **含义**：主组织内子组织的标识符。
* **作用**：外键。
* **典型内容**：表示子组织 ID 的 UUID 字符串。
* **备注**：支持在组织内进行更细粒度的区分。

#### data\_key

* **含义**：用于标识数据或 API 端点的标签或键。
* **作用**：描述性字段。
* **典型内容**：类似 `bank_codes` 的描述性文本。
* **备注**：用于区分不同类型的数据或端点。

#### url

* **含义**：要调用的 API 端点的 URL。
* **作用**：描述性字段。
* **典型内容**：类似 `/M3/m3api-rest/v2/execute/CRS692MI/LstByID` 的 URL 字符串。
* **备注**：表示发送 HTTP 请求的目标端点。

#### method

* **含义**：API 请求使用的 HTTP 方法。
* **作用**：描述性字段。
* **典型内容**：常见的 HTTP 方法，例如 `GET`。
* **备注**：决定要执行的 HTTP 请求类型。

#### params

* **含义**：要包含在 API 请求中的参数。
* **作用**：配置字段。
* **典型内容**：JSON 或键值对（通常在未使用时为 `None`）。
* **备注**：包含请求的动态参数。

#### headers

* **含义**：要包含在请求中的 HTTP 标头。
* **作用**：配置字段。
* **典型内容**：JSON 或文本数据（通常在未使用时为 `None`）。
* **备注**：用于在请求中包含其他元数据。

#### body

* **含义**：HTTP 请求的正文。
* **作用**：配置字段。
* **典型内容**：JSON 数据或其他序列化数据（通常在未使用时为 `None`）。
* **备注**：包含 POST/PUT 请求的负载。

#### body\_type

* **含义**：指定请求正文的格式。
* **作用**：描述性字段。
* **典型内容**：类似 `application/json` 的 MIME 类型。
* **备注**：表示正文的内容类型。

#### authentication\_type

* **含义**：API 请求使用的身份验证类型。
* **作用**：描述性字段。
* **典型内容**：类似 `ionapi` 的身份验证方法。
* **备注**：决定请求的身份验证方式。

#### authentication\_json

* **含义**：JSON 格式的身份验证配置详细信息。
* **作用**：配置字段。
* **典型内容**：包含身份验证信息的 JSON 字符串。
* **备注**：包含身份验证所需的凭据和端点详细信息。

#### data\_base\_path

* **含义**：API 响应中用于提取数据的路径。
* **作用**：配置字段。
* **典型内容**：类似 `$[results][0][records]` 的 JSON 路径表达式。
* **备注**：用于解析 API 响应数据。

#### column\_paths

* **含义**：将数据字段映射到用于提取的列。
* **作用**：配置字段。
* **典型内容**：将 API 响应字段映射到列名的 JSON 字符串。
* **备注**：便于从 API 响应中提取数据。

#### created\_by

* **含义**：创建该配置的用户的标识符。
* **作用**：技术字段。
* **典型内容**：类似 `1` 的整数 ID。
* **备注**：记录配置条目的创建者。

#### created\_on

* **含义**：创建配置时的时间戳。
* **作用**：技术字段。
* **典型内容**：类似 `2024-01-24T09:14:24.788788Z` 的时间戳。
* **备注**：表示创建日期和时间。

#### last\_modified\_on

* **含义**：上次修改的时间戳。
* **作用**：技术字段。
* **典型内容**：时间戳（如果未修改，通常为 `None`）。
* **备注**：记录上次更新时间。

#### is\_deleted

* **含义**：表示配置是否已标记为删除的标志。
* **作用**：技术字段。
* **典型内容**：类似 `False` 的布尔值。
* **备注**：用于软删除配置。

#### deleted\_on

* **含义**：配置标记为删除时的时间戳。
* **作用**：技术字段。
* **典型内容**：时间戳（如果未删除，通常为占位值）。
* **备注**：记录配置标记为删除的时间。

#### is\_template

* **含义**：表示该配置是否用作模板。
* **作用**：描述性字段。
* **典型内容**：类似 `True` 的布尔值。
* **备注**：用于标识可重复使用的模板。

#### is\_dynamic

* **含义**：指定该配置是否为动态配置。
* **作用**：描述性字段。
* **典型内容**：类似 `False` 的布尔值。
* **备注**：决定配置是否会随数据变化而调整。
