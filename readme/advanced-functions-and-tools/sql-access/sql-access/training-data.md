### 分析与说明

## `public.training_data` 表技术文档

### 简介

`public.training_data` 表似乎用于存储各种与文档相关的数据，可能用于训练处理和分析文档内容的模型或系统。该表包含文档类型、来源、语言、供应商详情，以及记录的创建和修改时间戳等信息。该表似乎尤其关注发票和医疗收据，这表明它可能用于财务或医疗保健数据处理应用。

### 列说明

#### id

* **含义**：表中每条记录的唯一标识符。
* **作用**：主键。
* **典型内容**：字符格式的通用唯一标识符（UUID）。
* **说明**：对于唯一标识每条记录至关重要。

#### org\_id

* **含义**：与文档关联的组织标识符。
* **作用**：用于关联组织记录的外键。
* **典型内容**：代表组织的 UUID。
* **说明**：有助于将文档与特定组织关联起来。

#### doc\_type

* **含义**：记录中存储的文档类型。
* **作用**：描述性字段。
* **典型内容**：例如 'INVOICE' 或 'MEDICAL\_RECEIPT'。
* **说明**：可用于对文档进行分类。

#### doc\_origin

* **含义**：文档来源国家/地区的代码。
* **作用**：描述性字段。
* **典型内容**：国家/地区代码，例如德国的 'DE'。
* **说明**：表示文档的地理来源。

#### doc\_locale

* **含义**：文档的区域设置信息。
* **作用**：描述性字段。
* **典型内容**：区域代码，例如 'en\_DE'。
* **说明**：结合语言和地区信息，用于本地化。

#### doc\_language

* **含义**：文档使用的语言。
* **作用**：描述性字段。
* **典型内容**：语言代码，例如 'en' 或 'de'。
* **说明**：表示文档使用的主要语言。

#### first\_page\_content

* **含义**：文档第一页的内容。
* **作用**：描述性字段。
* **典型内容**：包含文档首页内容的文本数据。
* **说明**：可用于文本分析或处理。

#### supplier\_name

* **含义**：与文档关联的供应商名称。
* **作用**：描述性字段。
* **典型内容**：文本格式的供应商名称。
* **说明**：对于识别文档来源或创建者很重要。

#### supplier\_vat

* **含义**：供应商的增值税识别号。
* **作用**：描述性字段。
* **典型内容**：增值税识别号，例如 'DE 129375678'。
* **说明**：可用于财务和税务相关流程。

#### doc\_created\_on

* **含义**：文档创建时的时间戳。
* **作用**：描述性字段。
* **典型内容**：UTC 格式的日期和时间。
* **说明**：为文档创建提供时间背景。

#### is\_training\_sample

* **含义**：标识该记录是否用作训练样本。
* **作用**：技术字段。
* **典型内容**：布尔值（`True` 或 `False`）。
* **说明**：标识专门标记为训练用途的记录。

#### sample\_doc\_id

* **含义**：样本文档的标识符。
* **作用**：描述性字段或可能的外键。
* **典型内容**：关联到另一份文档的 UUID。
* **说明**：可能引用用于抽样的相关文档或原始文档。

#### sample\_file\_name

* **含义**：与文档样本关联的文件名。
* **作用**：描述性字段。
* **典型内容**：文本格式的文件名。
* **说明**：可用于文件管理或检索流程。

#### created\_on

* **含义**：记录创建时的时间戳。
* **作用**：技术字段。
* **典型内容**：UTC 格式的日期和时间。
* **说明**：表示记录添加到数据库的时间。

#### last\_modified\_on

* **含义**：记录最后修改时的时间戳。
* **作用**：技术字段。
* **典型内容**：UTC 格式的日期和时间。
* **说明**：追踪记录最后更新的时间。

#### is\_deleted

* **含义**：标识记录是否已标记为删除。
* **作用**：技术字段。
* **典型内容**：布尔值（`True` 或 `False`）。
* **说明**：支持软删除功能。

#### is\_table\_training\_sample

* **含义**：标识该记录是否为表格专用训练样本。
* **作用**：技术字段。
* **典型内容**：布尔值（`True` 或 `False`）。
* **说明**：将此类样本与常规训练样本区分开来，重点用于表格数据。
