# Boas práticas

- Guarde uma vista pessoal para trabalho recorrente.
- Confirme organização, pessoa atribuída e estado antes de agir.
- Partilhe vistas apenas com os destinatários previstos; mantêm-se as permissões dos documentos.
- Verifique a seleção antes de ações em lote e atualize a lista antes de repetir uma ação.

O [guia do painel](README.md) descreve pesquisa, ações e vistas guardadas.
