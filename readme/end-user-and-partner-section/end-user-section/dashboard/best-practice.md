# Bonnes pratiques

- Enregistrez une vue personnelle pour le travail récurrent.
- Vérifiez organisation, responsable et statut avant toute action.
- Partagez les vues uniquement avec les personnes prévues ; les droits sur les documents restent applicables.
- Vérifiez la sélection avant les actions groupées et actualisez la liste avant de répéter une action.

Le [guide du tableau de bord](README.md) présente la recherche, les actions et les vues enregistrées.
