# Buone pratiche

- Salva una vista personale per il lavoro ricorrente.
- Controlla organizzazione, assegnatario e stato prima di agire.
- Condividi le viste solo con i destinatari previsti; i permessi sui documenti restano validi.
- Controlla la selezione prima delle azioni collettive e aggiorna la lista prima di ripetere un’azione.

La [guida alla dashboard](README.md) descrive ricerca, azioni e viste salvate.
