# Documentkolommen wijzigen

1. Open het tandwiel naast het zoekvak.
2. Open de kolominstellingen.
3. Zoek in de verborgen of zichtbare kolommen. Selecteer kolommen en verplaats ze met de pijlen.
4. Versleep de handgrepen van zichtbare kolommen om ze te ordenen.
5. Voeg zo nodig velden toe door een documenttype en de gewenste velden te kiezen.
6. Kies **Gereed** om de configuratie toe te passen.

Sla bij een eigen opgeslagen dashboard ook de wijzigingen op vóór een tabelexport. De geëxporteerde kolommen komen uit de opgeslagen weergave. Sluit of annuleer het venster om zonder wijzigingen te vertrekken. Beschikbare kolommen hangen af van documenttype en organisatieconfiguratie.
