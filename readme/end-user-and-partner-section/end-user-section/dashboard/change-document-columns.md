# Alterar colunas dos documentos

1. Selecione a engrenagem **Configurações avançadas** à direita da barra de pesquisa do painel.
2. Selecione o botão **Configurações de colunas** no menu.
3. Pesquise nas listas de colunas ocultas ou visíveis. Selecione colunas e mova-as com as setas.
4. Arraste as pegas das colunas visíveis para as ordenar.
5. Se necessário, adicione campos escolhendo um tipo de documento e os campos pretendidos.
6. Escolha **Feito** para aplicar a configuração.

Num painel guardado que lhe pertença, guarde também as alterações antes de exportar a tabela. As colunas exportadas vêm da vista guardada. Feche ou cancele a janela para sair sem aplicar alterações. As colunas disponíveis dependem do tipo de documento e da configuração da organização.
