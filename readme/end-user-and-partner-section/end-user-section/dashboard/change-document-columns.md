# Change Document Columns

**From the Dashboard, click on the Advanced Settings icon as shown below:**

<figure><img src="../../../.gitbook/assets/change-document-colums1.png" alt="Advanced Settings Icon"><figcaption></figcaption></figure>

The following menu will then be displayed:

<figure><img src="../../../.gitbook/assets/a-dashboard-change-document-columns-menu-en-20261006.png" alt="Dashboard toolbar with the Advanced settings menu open."><figcaption><p>The advanced settings menu.</p></figcaption></figure>

Select the button labeled “Set dashboard columns for organization” and a list of all the column names will be shown.

From this menu, you can select the column names and use the arrows to add and remove the columns you desire.

<figure><img src="../../../.gitbook/assets/a-dashboard-change-document-columns-dialog-en-20261006.png" alt="Columns settings dialog with Hidden columns and Visible columns lists and arrows to move columns."><figcaption><p>Move columns between hidden and visible columns.</p></figcaption></figure>

<div data-full-width="true"><figure><img src="../../../.gitbook/assets/dashboard_column_ordering.png" alt="Reordering Dashboard Columns"><figcaption></figcaption></figure></div>

You can set the order of the columns by clicking on the dots next to the column name and dragging them to the appropriate position.

Another option also allows you to add fields of a document type:

<figure><img src="../../../.gitbook/assets/add_document_type_field_button.png" alt="Add Document Type Field Button" width="243"><figcaption></figcaption></figure>

<figure><img src="../../../.gitbook/assets/select_document_type_field_window.png" alt="Select Document Type Field Window" width="563"><figcaption><p>Select document type field window</p></figcaption></figure>

Here you can choose from the different document types:

<figure><img src="../../../.gitbook/assets/document_type_selection_dropdown.png" alt="Document Type Selection Dropdown" width="254"><figcaption></figcaption></figure>

For each document type there are different fields that you can add:

<figure><img src="../../../.gitbook/assets/document_type_fields_list.png" alt="List of Available Document Type Fields" width="518"><figcaption><p>Select document type field window</p></figcaption></figure>

Select the fields you need and click "Add to visible Columns", they will then appear in the column settings.

<figure><img src="../../../.gitbook/assets/visible_columns_after_addition.png" alt="Updated Visible Columns List" width="281"><figcaption></figcaption></figure>
