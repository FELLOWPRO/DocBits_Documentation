# 更改文档列

**在仪表板中，点击下方所示的高级设置图标：**

<figure><img src="../../../.gitbook/assets/change-document-colums1.png" alt="高级设置图标"><figcaption></figcaption></figure>

随后将显示以下菜单：

![高级设置菜单](https://lh7-us.googleusercontent.com/wWt5QbmwZf44enmOoLcofh6SvyYPiHTav9OiEog_m2xtnty6X73pFlhfdM9aglx89_pfbiACZx5BejagV-wAKwlDTuGoGNu5jgbcZ5djrZ_h1IgGp-8uaq8UHY-umjrs96hb4FZOzHFzdLasg2F_ftw)

选择标有“Set dashboard columns for organization”（为组织设置仪表板列）的按钮，即可显示所有列名。

在此菜单中，你可以选择列名，并使用箭头添加或移除所需的列。

![仪表板列设置](https://lh7-us.googleusercontent.com/cXnnrIR-y4TRDnRE9irGvvjnmkN-HSGEQTh7FiwsjRHzXF7FNjd-_gLO-m55fLlv6lVjk-VvThgdW5JWgqIVZSm5tfk3hC7xrj68uRE5OgIPMtYIrpxOhhYzk4OMibyDBqvHQ0VZaDAysZohlH8dxm8)

<div data-full-width="true"><figure><img src="../../../.gitbook/assets/dashboard_column_ordering.png" alt="重新排列仪表板列"><figcaption></figcaption></figure></div>

点击列名旁边的圆点并将其拖动到适当位置，即可设置列的顺序。

你还可以添加文档类型的字段：

<figure><img src="../../../.gitbook/assets/add_document_type_field_button.png" alt="添加文档类型字段按钮" width="243"><figcaption></figcaption></figure>

<figure><img src="../../../.gitbook/assets/select_document_type_field_window.png" alt="选择文档类型字段窗口" width="563"><figcaption><p>选择文档类型字段窗口</p></figcaption></figure>

在这里，你可以从不同的文档类型中进行选择：

<figure><img src="../../../.gitbook/assets/document_type_selection_dropdown.png" alt="文档类型选择下拉菜单" width="254"><figcaption></figcaption></figure>

每种文档类型都包含可供添加的不同字段：

<figure><img src="../../../.gitbook/assets/document_type_fields_list.png" alt="可用文档类型字段列表" width="518"><figcaption><p>选择文档类型字段窗口</p></figcaption></figure>

选择所需字段并点击“Add to visible Columns”（添加到可见列），这些字段随后会显示在列设置中。

<figure><img src="../../../.gitbook/assets/visible_columns_after_addition.png" alt="更新后的可见列列表" width="281"><figcaption></figcaption></figure>
