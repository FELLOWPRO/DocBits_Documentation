# 仪表板工具

工具位于仪表板搜索框旁。将鼠标悬停在图标上可查看名称。在较窄的桌面窗口中，打开**更多**查看其他操作。

| 工具 | 用途 |
| --- | --- |
| 刷新 | 重新加载列表和状态。更改提示表示有较新的数据可用。 |
| 高级设置（齿轮） | 打开**更多设置**、**键盘快捷键**参考、**导入日志**和**列设置**对话框。整个组织的设置需要管理员权限。 |
| 扫描文档 | 启用扫描并连接兼容扫描仪后，可打开扫描对话框。开始前选择设备和扫描设置。 |
| 分析 | 显示状态统计，并选择状态类别缩小列表范围。 |
| 启动邮件导入 | 使用现有邮箱配置启动导入。此操作不会配置邮箱。 |
| 导出表格 | 启用后可请求 CSV 或 Excel 导出。请先保存个人视图的列更改，因为导出读取已保存配置。 |
| 上传 | 选择或拖入文件，可选指定文档类型，然后开始上传。 |
| 助手（灯泡） | 打开仪表板旁的**助手**面板，用于询问数据状态。 |

邮件导入日志可用于检查导入情况。按主题或发件人筛选，并查看可用的导入信息。表格导出请求成功只表示任务已提交，并不表示文档已导出到 ERP。

## 询问数据状态

工具栏中的灯泡图标会在仪表板旁打开**助手**面板。您可以用日常语言提问，例如：

* 我的采购订单数据是否同步？
* 我的文档为什么处理时间这么长？
* 我的 BOD 数据何时导入？

选择其中一条建议问题，或在**询问您的数据……**中输入自己的问题，再点右侧箭头发送。

<figure><img src="../../../.gitbook/assets/core6852-dashboard-assistant-zh.png" alt="仪表板旁的助手面板，显示建议的问题与输入框。"><figcaption><p>助手面板在仪表板旁打开，并提供可直接点选的问题。</p></figcaption></figure>

{% hint style="info" %}
只有当您的组织启用了助手时，才会显示灯泡图标。如果没有看到，请联系管理员。
{% endhint %}
