# Outils du tableau de bord

Les outils se trouvent à côté de la recherche. Survolez une icône pour afficher son libellé. Dans les fenêtres de bureau plus étroites, ouvrez **Plus**.

| Outil | Utilisation |
| --- | --- |
| Actualiser | Rechargez la liste et les statuts. Un indicateur signale la disponibilité de données plus récentes. |
| Paramètres avancés (engrenage) | Ouvrez les paramètres des colonnes, les raccourcis et le journal d’import des courriels. Les paramètres de l’organisation nécessitent des droits d’administration. |
| Numériser un document | Ouvrez la boîte de dialogue si la numérisation est activée et un scanner compatible est disponible. Choisissez l’appareil et les paramètres avant de commencer. |
| Analyse | Affichez les statistiques de statut et sélectionnez une catégorie pour filtrer la liste. |
| Démarrer l’import de courriels | Lancez un import avec la configuration de messagerie existante. Cette action ne configure pas de boîte mail. |
| Exporter le tableau | Demandez un CSV ou un fichier Excel si l’option est activée. Enregistrez d’abord les changements de colonnes de votre vue personnelle : l’export lit la configuration enregistrée. |
| Télécharger des fichiers | Choisissez ou déposez des fichiers, précisez éventuellement leur type et lancez l’importation. |

<figure><img src="../../../.gitbook/assets/dashboard-upload-fr.png" alt="Importez des fichiers et choisissez leur type de document avant l’importation si nécessaire."><figcaption><p>Importez des fichiers et choisissez leur type de document avant l’importation si nécessaire.</p></figcaption></figure>

Le journal aide à vérifier les imports de courriels. Filtrez par objet ou expéditeur et consultez les informations disponibles. La confirmation d’une demande d’export du tableau signifie que la demande a été soumise ; elle ne signifie pas qu’un document a été exporté vers l’ERP.

Le [guide du tableau de bord](README.md) présente la recherche, les actions et les vues enregistrées.
