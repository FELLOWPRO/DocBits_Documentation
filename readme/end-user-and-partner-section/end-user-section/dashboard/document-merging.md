# Unir documentos

1. Selecione entre dois e cinco documentos relacionados nas caixas, pela ordem pretendida.
2. Abra o menu de ações em lote no cabeçalho e escolha unir, se disponível.
3. Leia a confirmação: o primeiro documento selecionado é o principal. Os restantes são unidos a ele pela ordem de seleção. Cancele se a seleção ou a ordem estiverem erradas.
4. Confirme apenas documentos que pertencem ao mesmo conjunto. Verifique o resultado após a atualização da lista.

Unir altera os documentos e exige permissões de edição. Utilize esta ação para partes do mesmo documento. Mantenha separadas as faturas independentes; unir não cria um resumo contabilístico.

O [guia do painel](README.md) descreve pesquisa, ações e vistas guardadas.
