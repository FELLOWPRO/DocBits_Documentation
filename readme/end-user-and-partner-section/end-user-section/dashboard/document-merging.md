# Document Merging

1. Select two to five related documents using their checkboxes, in the intended order.
2. Open the bulk-action menu in the table header and choose the merge action, if available.
3. Read the confirmation: the first selected document is the primary document. The others are merged into it in selection order. Cancel if the selection or order is wrong.
4. Confirm only when the documents belong together. Check the resulting document after the list reloads.

Merging changes documents and requires edit permissions. Use it for related parts of one document. Keep independent invoices separate; merging is not a way to produce an accounting summary.

For searching, document actions and saved views, return to the [dashboard guide](README.md).
