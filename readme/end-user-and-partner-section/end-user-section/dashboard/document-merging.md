# Dokumente zusammenführen

1. Wählen Sie zwei bis fünf zusammengehörige Dokumente über die Kontrollkästchen in der gewünschten Reihenfolge.
2. Öffnen Sie das Sammelaktionsmenü im Tabellenkopf und wählen Sie die Aktion zum Zusammenführen, sofern verfügbar.
3. Lesen Sie die Bestätigung: Das zuerst ausgewählte Dokument ist das primäre Dokument. Die übrigen werden in der Auswahlreihenfolge darin zusammengeführt. Brechen Sie bei falscher Auswahl oder Reihenfolge ab.
4. Bestätigen Sie nur zusammengehörige Dokumente. Prüfen Sie das Ergebnis nach dem Neuladen der Liste.

Zusammenführen verändert Dokumente und erfordert Bearbeitungsrechte. Verwenden Sie es für zusammengehörige Teile eines Dokuments. Lassen Sie eigenständige Rechnungen getrennt; das Zusammenführen erstellt keine buchhalterische Zusammenfassung.

Suche, Dokumentaktionen und gespeicherte Ansichten erklärt die [Dashboard-Anleitung](README.md).
