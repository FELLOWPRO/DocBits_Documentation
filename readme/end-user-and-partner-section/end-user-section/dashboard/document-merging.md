# Fusionner des documents

1. Sélectionnez deux à cinq documents liés avec les cases, dans l’ordre souhaité.
2. Ouvrez le menu d’actions groupées de l’en-tête et choisissez la fusion, si elle est disponible.
3. Lisez la confirmation : le premier document sélectionné est le document principal. Les autres y sont fusionnés dans l’ordre de sélection. Annulez si la sélection ou l’ordre est incorrect.
4. Confirmez uniquement si les documents vont ensemble. Vérifiez le résultat après le rechargement de la liste.

La fusion modifie les documents et exige des droits de modification. Utilisez-la pour les parties d’un même document. Gardez les factures indépendantes séparées ; la fusion ne produit pas de récapitulatif comptable.

Le [guide du tableau de bord](README.md) présente la recherche, les actions et les vues enregistrées.
