# 文档状态

如果你使用 DocBits 软件处理文档，了解文件可能具有的不同状态至关重要。以下是 DocBits 中所有可能的文档状态：

* WatchDog Start：Watchdog 模块正在启动。
* WatchDog Split：正在 Watchdog 中拆分文档。
* WatchDog Upload：正在 Watchdog 中上传文档。
* Upload：正在上传文档。
* OCR：正在对文档运行光学字符识别（OCR）。
* Classification：正在对文档进行分类。
* Zugferd import：正在导入 Zugferd 文档。
* Ready for Validation：文档已准备好进行验证。
* Zugferd export：正在导出 Zugferd 文档。
* Workflow：此文档正在运行工作流。
* Pending approval：文档需要审批。
* Pending second approval：文档需要进行第二次审批。
* Auto Accounting：正在运行自动记账。
* Export：正在导出文档。
* Error：文档发生错误。
