# Filtrar documentos

No painel, selecione o ícone **Filtros** (três barras deslizantes) no extremo direito da barra de pesquisa. Pode limitar a lista por **Status**, **Atribuído a** ou **Reinicialização necessária**.

<figure><img src="../../../.gitbook/assets/prior-i005-pt.png" alt="Filtros do painel por atribuição e reinício necessário."><figcaption><p>Filtros do painel por atribuição e reinício necessário.</p></figcaption></figure>

Escolha o estado ou a pessoa responsável pretendida e selecione **Aplicar**. Limpe os filtros para remover as restrições. As opções de data dependem da configuração e da vista. Verifique os filtros ativos antes de interpretar a contagem de documentos.
