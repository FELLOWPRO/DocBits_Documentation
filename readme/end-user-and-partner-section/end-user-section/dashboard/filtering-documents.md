# Filtrowanie dokumentów

Otwórz filtry obok paska wyszukiwania w panelu. Listę można ograniczyć według statusu, przypisania lub wymaganego ponownego uruchomienia.

<figure><img src="../../../.gitbook/assets/prior-i005-pl.png" alt="Filtry panelu dotyczące przypisania i wymaganego ponownego uruchomienia."><figcaption><p>Filtry panelu dotyczące przypisania i wymaganego ponownego uruchomienia.</p></figcaption></figure>

Wybierz status lub osobę odpowiedzialną i zastosuj filtry. Wyczyść filtry, aby usunąć ograniczenia. Opcje dat zależą od konfiguracji i widoku. Sprawdź aktywne filtry przed interpretacją liczby dokumentów.
