# Documenten filteren

Kies in het dashboard het pictogram **Filters** (drie schuifbalken) aan het rechteruiteinde van de zoekbalk. U kunt de lijst beperken op **Status**, **Toegewezen aan** of **Opnieuw opstarten vereist**.

<figure><img src="../../../.gitbook/assets/prior-i005-nl.png" alt="Dashboardfilters voor toewijzing en vereiste herstart."><figcaption><p>Dashboardfilters voor toewijzing en vereiste herstart.</p></figcaption></figure>

Kies de bedoelde status of verantwoordelijke en kies **Toepassen**. Wis de filters om de beperkingen op te heffen. Datumopties hangen af van configuratie en weergave. Controleer de actieve filters voordat u het aantal documenten interpreteert.
