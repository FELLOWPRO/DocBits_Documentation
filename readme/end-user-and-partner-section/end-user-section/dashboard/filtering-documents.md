# Filtrar documentos

Abra el panel y seleccione el control de filtros junto a la búsqueda. Puede limitar la lista por estado, asignación o necesidad de reinicio.

<figure><img src="../../../.gitbook/assets/prior-i005-es.png" alt="Filtros del panel por asignación y necesidad de reinicio."><figcaption><p>Filtros del panel por asignación y necesidad de reinicio.</p></figcaption></figure>

1. Seleccione el estado o responsable previsto.
2. Marque **Reinicio necesario** si solo quiere revisar esos documentos.
3. Seleccione **Aplicar** para usar los filtros.
4. Use **Borrar filtros** para quitar las restricciones seleccionadas.

Las opciones de fecha dependen de la configuración y de la vista. Compruebe los filtros activos antes de interpretar el número de documentos.
