# Filtrer les documents

Dans le tableau de bord, ouvrez les filtres près de la recherche. Vous pouvez limiter la liste par statut, affectation ou nécessité de redémarrage.

<figure><img src="../../../.gitbook/assets/prior-i005-fr.png" alt="Filtres du tableau de bord par affectation et besoin de redémarrage."><figcaption><p>Filtres du tableau de bord par affectation et besoin de redémarrage.</p></figcaption></figure>

Choisissez le statut ou responsable prévu, puis appliquez les filtres. Effacez les filtres pour retirer les restrictions. Les options de date dépendent de la configuration et de la vue. Vérifiez les filtres actifs avant d’interpréter le nombre de documents.
