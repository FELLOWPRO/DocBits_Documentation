# Tastenkürzel

Verwenden Sie unter Windows/Linux Strg und unter macOS Cmd. Tastenkürzel des Browsers oder Betriebssystems können Vorrang haben.

| Tastenkürzel | Aktion |
| --- | --- |
| Strg/Cmd + K | Globale Schnellsuche öffnen. |
| Strg/Cmd + Q | Dashboard-Liste aktualisieren. |
| Strg/Cmd + H | Dokumentation/Hilfe öffnen. |

Öffnen Sie das Menü **Erweiterte Einstellungen** und wählen Sie das Tastatursymbol für die Übersicht der Tastenkürzel in der App. Das Fragezeichen am rechten Ende der Suchleiste öffnet die Hilfe zu Feldern und Suchsyntax.
