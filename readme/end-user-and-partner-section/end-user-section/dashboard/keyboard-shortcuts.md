# Atalhos de teclado

Use Ctrl em Windows/Linux e Cmd em macOS. Os atalhos do navegador ou sistema podem ter prioridade.

| Atalho | Ação |
| --- | --- |
| Ctrl/Cmd + K | Abrir a pesquisa rápida global. |
| Ctrl/Cmd + Q | Atualizar a lista do painel. |
| Ctrl/Cmd + H | Abrir documentação/ajuda. |

Abra o menu da engrenagem **Configurações avançadas** e aí **Atalhos de teclado** para consultar os atalhos na aplicação. O botão com o ponto de interrogação no extremo direito da barra de pesquisa abre a ajuda de campos e sintaxe.
