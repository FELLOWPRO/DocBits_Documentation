# Tableaux de bord personnels

Enregistrez une liste de travail récurrente avec ses filtres, son tri et ses colonnes visibles. Un tableau de bord enregistré est une vue des documents existants.

## Créer et partager une vue

1. Configurez recherche, filtres, type de document, tri et colonnes.
2. Ouvrez le bouton bleu de vue sous la recherche.
3. Créez un nouveau tableau de bord et donnez-lui un nom clair.
4. Choisissez une visibilité privée, tous les utilisateurs ou des groupes et utilisateurs précis.
5. Choisissez **Enregistrer**.

La visibilité détermine qui peut utiliser la vue. Chaque personne ne voit toujours que les documents autorisés par ses droits.

## Changer, modifier ou retirer une vue

Sélectionnez un tableau de bord enregistré ou revenez à la vue par défaut depuis le bouton de vue. Après avoir modifié votre propre vue, enregistrez les changements lorsque l’action est disponible. Elle est désactivée sans modification ou lorsqu’une autre personne vous a partagé la vue.

Utilisez le contrôle d’édition d’une vue qui vous appartient pour modifier son nom ou son partage. Utilisez la suppression et confirmez uniquement pour retirer la vue enregistrée. Les documents sont conservés. Pour adapter la vue partagée d’une autre personne, créez votre propre vue.
