# Persönliche Dashboards

Speichern Sie eine wiederkehrende Arbeitsliste mit Filtern, Sortierung und sichtbaren Spalten. Ein gespeichertes Dashboard ist eine Ansicht vorhandener Dokumente.

## Eine Ansicht erstellen und teilen

1. Stellen Sie Suche, Filter, Dokumenttyp, Sortierung und Spalten ein.
2. Öffnen Sie die blaue Ansichts-Schaltfläche unter dem Suchfeld.
3. Wählen Sie **Neues Dashboard erstellen** und vergeben Sie einen eindeutigen Namen.
4. Wählen Sie private Sichtbarkeit, alle Benutzer oder bestimmte Gruppen und Benutzer.
5. Wählen Sie **Speichern**.

Die Sichtbarkeit legt fest, wer die Ansicht verwenden kann. Jede Person sieht weiterhin nur Dokumente, für die sie berechtigt ist.

## Ansichten wechseln, ändern oder entfernen

Wählen Sie über die Ansichts-Schaltfläche ein gespeichertes Dashboard oder kehren Sie zur Standardansicht zurück. Nach Änderungen an Ihrer eigenen Ansicht wählen Sie **Dashboard-Änderungen speichern**, sobald die Aktion verfügbar ist. Ohne Änderungen oder bei einer mit Ihnen geteilten Ansicht bleibt sie deaktiviert.

Über das Bearbeitungssymbol einer eigenen Ansicht ändern Sie Namen oder Freigabe. Verwenden Sie das Löschsymbol und bestätigen Sie nur, wenn Sie die gespeicherte Ansicht entfernen möchten. Ihre Dokumente bleiben erhalten. Wenn Sie eine fremde geteilte Ansicht anpassen möchten, erstellen Sie eine eigene Ansicht.
