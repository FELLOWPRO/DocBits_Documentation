# Paneles personales

Guarde una lista de trabajo recurrente con filtros, orden y columnas visibles. Un panel guardado es una vista de documentos existentes.

## Crear y compartir una vista

1. Configure búsqueda, filtros, tipo de documento, orden y columnas.
2. Abra el botón azul de vista bajo el buscador.
3. Elija **Crear nuevo panel** e introduzca un nombre claro.
4. Seleccione visibilidad privada, todos los usuarios o grupos y usuarios concretos.
5. Elija **Guardar**.

La visibilidad determina quién puede usar la vista. Cada persona sigue viendo únicamente los documentos que permiten sus permisos.

## Cambiar, actualizar o quitar una vista

Seleccione un panel guardado o vuelva a la vista predeterminada desde el botón de vista. Tras modificar una vista propia, guarde sus cambios cuando la opción esté habilitada. Está deshabilitada si no hay cambios o si otra persona compartió la vista con usted.

Use el control de edición de una vista propia para modificar nombre o uso compartido. Use el control de eliminación y confirme solo para quitar la vista guardada. Los documentos no se eliminan. Para adaptar una vista compartida de otra persona, cree su propia vista.
