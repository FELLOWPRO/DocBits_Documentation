# Compteur de tâches

L’indicateur facultatif de documents en attente montre aux administrateurs la file de traitement de l’organisation. Il ne compte pas les documents qui vous sont assignés. Pour votre travail, filtrez par responsable et statut et vérifiez l’organisation active.

Le [guide du tableau de bord](README.md) présente la recherche, les actions et les vues enregistrées.
