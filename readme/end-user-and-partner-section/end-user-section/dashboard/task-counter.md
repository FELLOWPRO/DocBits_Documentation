# Aufgabenzähler

Die optionale Anzeige ausstehender Dokumente zeigt Administratoren die Verarbeitungswarteschlange der Organisation. Sie zählt nicht die Ihnen zugewiesenen Dokumente. Filtern Sie für Ihre eigene Arbeit nach zuständiger Person und Status und prüfen Sie die aktive Organisation.

Suche, Dokumentaktionen und gespeicherte Ansichten erklärt die [Dashboard-Anleitung](README.md).
