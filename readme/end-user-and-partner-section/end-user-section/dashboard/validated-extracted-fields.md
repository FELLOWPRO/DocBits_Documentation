# Walidacja wyodrębnionych pól

Otwórz wiersz dokumentu, aby przejść do walidacji. Porównaj wyodrębnione pola z oryginałem i popraw wartości, jeśli pozwalają na to uprawnienia. Zakończ walidację po sprawdzeniu wymaganych pól i komunikatów. Pola i działania zależą od typu dokumentu, stanu przetwarzania i konfiguracji.

Wyszukiwanie, działania i widoki opisuje [przewodnik po pulpicie](README.md).
