# Validierte extrahierte Felder

Der Validierungsbildschirm ermöglicht es Ihnen, alle importierten Dokumente zu überprüfen, zu bearbeiten und zu validieren. Sie sehen den Namen des Dokuments, aus wie vielen Seiten es besteht, das Datum, an dem es importiert wurde, und seinen Status. Über die Schaltfläche „Aktionen" können Sie das Dokument zuweisen, neu starten, validieren oder löschen.
