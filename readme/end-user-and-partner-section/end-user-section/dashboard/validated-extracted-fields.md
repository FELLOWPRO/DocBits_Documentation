# Valider les champs extraits

Ouvrez une ligne pour accéder à la validation. Comparez les champs extraits avec le document original et corrigez les valeurs si vos droits le permettent. Terminez la validation après avoir vérifié les champs obligatoires et les messages. Les champs et actions dépendent du type de document, de l’état et de la configuration.

Le [guide du tableau de bord](README.md) présente la recherche, les actions et les vues enregistrées.
