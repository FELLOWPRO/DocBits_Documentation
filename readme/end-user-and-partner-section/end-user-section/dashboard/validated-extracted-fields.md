# Geëxtraheerde velden valideren

Open een documentrij om naar validatie te gaan. Vergelijk geëxtraheerde velden met het originele document en verbeter waarden als uw rechten dit toelaten. Voltooi de validatie nadat u verplichte velden en meldingen hebt gecontroleerd. Velden en acties hangen af van documenttype, verwerkingsstatus en instellingen.

De [dashboardhandleiding](README.md) beschrijft zoeken, documentacties en opgeslagen weergaven.
