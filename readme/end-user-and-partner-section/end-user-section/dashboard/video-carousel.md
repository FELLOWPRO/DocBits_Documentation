# Video Karusel

Mala oblast na Kontrolnoj tabli za pripremu koja pušta kratke savete o funkcijama DocBits-a — korisne stvari za probu, mesta gde možda niste pogledali.

## Gde se nalazi

Video Karusel pojavljuje se na Kontrolnoj tabli za pripremu dok se dokumenti uvoze. Na širokim ekranima nalazi se desno od trake napretka. Na malim ekranima je skriven.

## Korišćenje

Saveti se reprodukuju jedan za drugim sa kratkim natpisom ispod. Kliknite na tačke ispod videa da pređete na konkretan savet. Nema zvuka — pročitajte natpis da vidite o čemu se radi svaki savet.
