# Karuzela Wideo

Niewielki obszar na Pulpicie Przygotowania, który odtwarza krótkie wskazówki o funkcjach DocBits — przydatne rzeczy do wypróbowania, miejsca, do których być może nie zaglądałeś.

## Gdzie ją znaleźć

Karuzela Wideo pojawia się na Pulpicie Przygotowania, podczas gdy dokumenty są importowane. Na szerokich ekranach umieszcza się po prawej stronie paska postępu. Na małych ekranach jest ukryta.

## Korzystanie

Wskazówki odtwarzają się jedna po drugiej z krótkim podpisem pod spodem. Kliknij punkty pod filmem, aby przejść do konkretnej wskazówki. Nie ma dźwięku — przeczytaj podpis, aby dowiedzieć się, czego dotyczy każda wskazówka.
