# Globale Schnellsuche

Die Globale Schnellsuche ist ein über die Tastatur aufrufbarer Starter, der Seiten, Einstellungen, Dashboards und Funktionen innerhalb von Seiten von überall in DocBits findet. Sie ersetzt das Durchklicken der Seitenleiste, wenn Sie bereits wissen, wohin Sie möchten.

## Aufrufen

Drücken Sie <kbd>Cmd</kbd> + <kbd>K</kbd> unter macOS oder <kbd>Ctrl</kbd> + <kbd>K</kbd> unter Windows und Linux. Die Tastenkombination funktioniert von jedem Bildschirm aus.

## Suchen

Beginnen Sie zu tippen, um den Katalog aus Seiten und Funktionen zu filtern. Die Schnellsuche verwendet unscharfes Matching, sodass auch unvollständige Wörter und kleine Tippfehler den richtigen Eintrag finden. Die obersten acht Ergebnisse werden nach Relevanz sortiert angezeigt.

Jedes Ergebnis zeigt:

* Den Namen der Funktion oder Seite.
* Die zugehörige Kategorie (Einstellungen, Dashboard, Validierung und so weiter).
* Ein kleines Abzeichen für den Eintragstyp — Seite, Dialog, Seitenleiste, Bereich, Menü oder Aktion.

Verwenden Sie die Pfeiltasten oben und unten, um ein Ergebnis zu markieren, und drücken Sie dann <kbd>Enter</kbd>, um es zu öffnen. Drücken Sie <kbd>Esc</kbd>, um das Fenster zu schließen.

<mark>Es werden nur Einträge angezeigt, für die Sie eine Berechtigung haben. Einträge, die nur für Administratoren bestimmt sind, sind für andere Benutzer ausgeblendet.</mark>

## Letzte Suchen

Wenn das Suchfeld leer ist, zeigt die Schnellsuche Ihre fünf zuletzt verwendeten Suchanfragen an, sodass Sie häufige Ziele mit einem einzigen Tastendruck wieder erreichen. Die letzten Suchen werden pro Browser gespeichert und nicht über Geräte hinweg synchronisiert.

## Auswahlmodus für Dokumente

Manche Ziele benötigen zusätzliche Informationen — etwa "Dokument nach ID öffnen", das die Dokument-ID braucht, bevor es navigieren kann. Wenn Sie einen solchen Eintrag wählen, wechselt die Schnellsuche in den **Auswahlmodus**:

* Für Dokument-IDs geben Sie die ID ein oder fügen Sie sie ein und drücken <kbd>Enter</kbd>.
* Für Dokumenttypen wählen Sie den Typ aus der eingeblendeten Liste.

Der Auswahlmodus respektiert die Berechtigungen des Dashboards, sodass Sie nur Dokumente sehen, die Sie öffnen dürfen.

## Alle Ergebnisse anzeigen

Wenn die acht sichtbaren Ergebnisse nicht ausreichen, klicken Sie unten im Fenster auf den Link **Alle Ergebnisse anzeigen**, um die [Sitemap](sitemap.md) mit dem aktuellen Suchbegriff vorgefiltert zu öffnen.

## Tastaturreferenz

| Taste | Aktion |
|---|---|
| <kbd>Cmd</kbd>/<kbd>Ctrl</kbd> + <kbd>K</kbd> | Schnellsuche von überall öffnen |
| <kbd>↑</kbd> / <kbd>↓</kbd> | Zwischen Ergebnissen wechseln |
| <kbd>Enter</kbd> | Markiertes Ergebnis öffnen |
| <kbd>Esc</kbd> | Fenster schließen |
