# Globalne Szybkie Wyszukiwanie

Globalne Szybkie Wyszukiwanie to dostępny z klawiatury moduł startowy, który znajduje strony, ustawienia, pulpity i funkcje wewnątrz stron z dowolnego miejsca w DocBits. Zastępuje przewijanie paska bocznego, gdy już wiesz, dokąd chcesz przejść.

## Jak otworzyć

Naciśnij <kbd>Cmd</kbd> + <kbd>K</kbd> w macOS lub <kbd>Ctrl</kbd> + <kbd>K</kbd> w Windows i Linux. Skrót działa z każdego ekranu.

## Wyszukiwanie

Zacznij pisać, aby przefiltrować katalog stron i funkcji. Szybkie Wyszukiwanie używa dopasowania przybliżonego, więc częściowe słowa i drobne literówki nadal znajdują właściwy wpis. Wyświetlane jest osiem najlepszych wyników uporządkowanych według trafności.

Każdy wynik pokazuje:

* Nazwę funkcji lub strony.
* Kategorię, do której należy (Ustawienia, Pulpit, Walidacja itd.).
* Niewielką etykietę wskazującą typ wpisu — Strona, Okno dialogowe, Pasek boczny, Panel, Menu lub Akcja.

Używaj strzałek góra/dół, aby zaznaczyć wynik, następnie naciśnij <kbd>Enter</kbd>, aby go otworzyć. Naciśnij <kbd>Esc</kbd>, aby zamknąć okno.

<mark>Na liście wyników widoczne są tylko wpisy, do których masz uprawnienia. Wpisy zarezerwowane dla administratorów są ukryte przed pozostałymi użytkownikami.</mark>

## Ostatnie wyszukiwania

Gdy pole wyszukiwania jest puste, Szybkie Wyszukiwanie pokazuje pięć ostatnich zapytań, dzięki czemu możesz wrócić do częstych miejsc jednym naciśnięciem. Ostatnie wyszukiwania są zapisywane na poziomie przeglądarki i nie synchronizują się między urządzeniami.

## Tryb wyboru dla dokumentów

Niektóre cele wymagają dodatkowych informacji — na przykład „Otwórz dokument po ID" potrzebuje identyfikatora, zanim nawiguje. Po wybraniu takiego wpisu Szybkie Wyszukiwanie przechodzi w **tryb wyboru**:

* Dla identyfikatorów dokumentu wpisz lub wklej ID i naciśnij <kbd>Enter</kbd>.
* Dla typów dokumentu wybierz typ z osadzonej listy.

Tryb wyboru respektuje uprawnienia statusu pulpitu, więc widzisz tylko dokumenty, które wolno ci otworzyć.

## Zobacz wszystkie wyniki

Jeśli osiem widocznych wyników nie wystarcza, kliknij łącze **Zobacz wszystkie wyniki** w stopce, aby otworzyć [Mapę Witryny](sitemap.md) wstępnie przefiltrowaną według bieżącego wyszukiwania.

## Skróty klawiaturowe

| Klawisz | Działanie |
|---|---|
| <kbd>Cmd</kbd>/<kbd>Ctrl</kbd> + <kbd>K</kbd> | Otwórz Szybkie Wyszukiwanie z dowolnego miejsca |
| <kbd>↑</kbd> / <kbd>↓</kbd> | Przejdź między wynikami |
| <kbd>Enter</kbd> | Otwórz zaznaczony wynik |
| <kbd>Esc</kbd> | Zamknij okno |
