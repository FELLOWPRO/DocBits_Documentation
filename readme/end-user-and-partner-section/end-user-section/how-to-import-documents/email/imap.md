# IMAP

{% embed url="https://www.youtube.com/watch?v=CIGk-f4x4ZE" %}

Hier müssen Sie nur die erforderlichen Informationen Ihres E-Mail-Anbieters eingeben: Protokoll, Verschlüsselung, Servername, Port, Benutzername, E-Mail-Adresse und Passwort sowie den E-Mail-Ordner.

## Zu beachten

* Geben Sie alle erforderlichen Informationen in die Benutzeroberfläche ein. Die übrigen Informationen, wie Server und Port, hängen vom Anbieter ab (eine kurze Websuche hilft weiter).
* Ordner und Move-Imported haben hier dieselbe Funktion. Der Ordner kann nicht deaktiviert werden; bleibt er leer, wird standardmäßig Inbox verwendet.
