# IMAP

{% embed url="https://www.youtube.com/watch?v=CIGk-f4x4ZE" %}

Vous devez simplement saisir ici les informations requises de votre fournisseur de messagerie : protocole, cryptage, nom du serveur, port, nom d'utilisateur, adresse e-mail et mot de passe, ainsi que le dossier de messagerie.

## Remarques

* Saisissez toutes les informations requises dans l'interface. Les autres informations, comme le serveur et le port, dépendent de votre hébergeur (une recherche web rapide devrait suffire).
* Dossier et Move-Imported ont ici la même fonction. Le dossier ne peut pas être désactivé ; s'il est laissé vide, c'est la boîte de réception qui est utilisée par défaut.
