# Purchase Order

This section offers a detailed overview of all purchase orders. It includes a search bar with various filters that you can select to quickly narrow down the results. Additionally, you can customize the arrangement of the column headers by using the drag-and-drop functionality for a more tailored viewing experience. To review a single purchase order in detail, open the [Purchase Order Detail](purchase-order-detail.md) page with the view action in the row of the purchase order.
