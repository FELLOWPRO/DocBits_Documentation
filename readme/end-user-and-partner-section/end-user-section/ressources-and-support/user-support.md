# 用户支持

### 用户支持 <a href="#ikpwh4qbrq82" id="ikpwh4qbrq82"></a>

如果您在使用 DocBits 时遇到任何问题或有任何疑问，请查阅本用户手册，或联系我们的支持团队寻求帮助。我们致力于为所有用户提供顺畅的使用体验。只需点击 DocBits 应用中的支持按钮，即可创建支持工单。

<figure><img src="../../../.gitbook/assets/support_button_location.png" alt="支持按钮位置"><figcaption></figcaption></figure>

<figure><img src="../../../.gitbook/assets/support_ticket_creation_form.png" alt="支持工单创建表单"><figcaption></figcaption></figure>

您也可以通过我们的 FELLOWPRO 页面联系我们：

{% embed url="https://fellowpro.com/de/fellow/kontakt-fellowpro-ag/" %}

在验证界面中，您可以直接为相关文档创建工单，并附上问题截图。只需点击“Create ticket”按钮，支持窗口便会打开，您可以立即开始操作。
