# Angebotspositionen und Preise prüfen

Die Angebotsansicht gilt für entsprechend konfigurierte Dokumente. Dokumenttyp, Layout, Rechte und Workflow bestimmen die sichtbaren Felder und Aktionen. Die Ansicht ist vom Bestellabgleich getrennt.

## Positionen bearbeiten

1. Öffnen Sie das richtige Angebot. Vergleichen Sie Lieferant, Referenz, Datum und Währung mit dem Original.
2. Prüfen Sie Artikelnummern, Beschreibungen, Mengen, Einheiten, Preise und Beträge. Eine passende Artikelnummer belegt weder gleichen Preis noch gleiche Einheit.
3. Wählen Sie eine Position aus. Ihre Detailfelder erscheinen unter der Tabelle.
4. Verwenden Sie einen konfigurierten Stammdaten-Lookup, sofern vorhanden. Prüfen Sie Auswahl und übernommene Werte; klären Sie Lookup-Warnungen.
5. Korrigieren Sie die Position und wählen Sie **Speichern** oder **Speichern und weiter**. **Abbrechen** schließt den Positionseditor ohne Übermittlung dieser Änderungen.
6. Übernehmen Sie Standardwerte mit **Speichern und weiter – Standardwerte kopieren** nur, wenn sie für die nächste Position passen. Prüfen Sie die kopierten Werte.
7. Öffnen Sie Beleg und Position erneut und kontrollieren Sie gespeicherte Werte. Lesen Sie bei einer abgelehnten Position den verfügbaren Hinweis und klären Sie den fachlichen Grund.

## Sonderfälle

**Position hinzufügen** erzeugt bei vorhandenen Rechten eine manuelle Position. Vergleichen Sie diese mit dem Original und füllen Sie Pflichtfelder. Das Entfernen einer manuellen Position ist eine separate Aktion; löschen Sie keine echte Position, damit Summen passen.

Prüfen Sie bei schreibgeschützten Belegen Rechte, Sperre und Verarbeitungsstufe. Bei fehlenden Positionen sind Original, Extraktion und Layout zu untersuchen.

Automatische Prüfungen gegen verwaltete, letzte oder vereinbarte Preise werden über [Angebotsvergleichskarten](../../administration-and-setup/workflow/cards-overview/quote-comparison-guide.md) konfiguriert. Das Speichern belegt weder deren Ausführung noch Freigabe oder abgeschlossenen ERP-Export.
