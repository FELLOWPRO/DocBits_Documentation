# 发货订单仪表板

本节详细概述所有发货订单。其中包含一个搜索栏和各种筛选器，您可以选择这些筛选器来快速缩小搜索范围。此外，您可以使用拖放功能自定义列标题的排列方式，从而获得更符合个人偏好的查看体验。

## 视频：查找发货记录并核对数据

本中文视频演示管理员如何按物料编号查找示例记录，核对订单和交货编号，以及发货数量、状态和仓库。随后，他清空搜索条件并重新加载列表。

三条记录均使用专为本演示创建的虚构数据。搜索 **DEMO-INSERT-40** 后，可以看到交货编号 **DEMO-9F2416-DL-102**、订单编号 **DEMO-9F2416-PO-202**、发货数量 **600** 和仓库 **DEMO-WH-9F2416**。状态来自导入的示例数据。发货数量本身并不能证明货物已全部收齐。本视频演示如何查找和核对已有发货数据，不会创建 ASN、打开关联的采购订单记录或执行收货入库。
