# Créer un ticket

Il s'agit d'un outil disponible pour vous, sur l'écran de validation, en cas de problème lors de la validation de votre document dans DocBits. Pour savoir comment vérifier un document, consultez l'[écran de validation](../validation-screen/README.md).

Cette fonctionnalité se trouve dans le menu au-dessus de la zone d'aperçu du document, comme ci-dessous

<figure><img src="../../../.gitbook/assets/a-technical-support-in-docbits-create-a-ticket-menu-fr-20261009.png" alt="Écran de validation avec le curseur sur le bouton Créer un ticket dans la barre d'actions de droite."><figcaption><p>Le bouton « Créer un ticket » dans la barre d'actions de l'écran de validation.</p></figcaption></figure>

Une fois cliqué, le formulaire de ticket suivant vous sera affiché.

<figure><img src="../../../.gitbook/assets/a-technical-support-in-docbits-create-a-ticket-form-fr-20261009.png" alt="Écran de validation avec le formulaire Ticket d'assistance ouvert : Nom, E-mail, Sujet, Priorité, Message, Capture d'écran et Téléverser un fichier."><figcaption><p>Le formulaire « Ticket d'assistance ».</p></figcaption></figure>

C'est ici que vous remplirez vos coordonnées ainsi que décrirez l'erreur. Vous pouvez également, si applicable, joindre une capture d'écran du problème et attacher un fichier pertinent.
