# Crea un ticket

Questo è uno strumento disponibile per te, nella schermata di convalida, nel caso si verifichi qualche tipo di problema durante la convalida del tuo documento in DocBits. Per sapere come verificare un documento, consulta la [schermata di convalida](../validation-screen/README.md).

Questa funzionalità si trova nel menu sopra l'area di anteprima del documento, come mostrato di seguito

<figure><img src="../../../.gitbook/assets/a-technical-support-in-docbits-create-a-ticket-menu-it-20261009.png" alt="Schermata di convalida con il cursore sul pulsante Creare un biglietto nella barra delle azioni a destra."><figcaption><p>Il pulsante «Creare un biglietto» nella barra delle azioni della schermata di convalida.</p></figcaption></figure>

Una volta cliccato, ti verrà mostrato il seguente modulo di ticket.

<figure><img src="../../../.gitbook/assets/a-technical-support-in-docbits-create-a-ticket-form-it-20261009.png" alt="Schermata di convalida con il modulo Biglietto di supporto aperto: Nome, Posta elettronica, Oggetto, Priorità, Messaggio, Schermata e Caricare il file."><figcaption><p>Il modulo «Biglietto di supporto».</p></figcaption></figure>

Qui dovrai compilare i tuoi dettagli e descrivere l'errore. Puoi anche, se applicabile, allegare uno screenshot del problema e un file rilevante.
