# Créer un ticket

{% embed url="https://youtu.be/fQUIrp-qz9c" %}
DocBits Tutoriel sur les tickets d'assistance : signaler des bogues, joindre des fichiers et obtenir de l'aide plus rapidement
{% endembed %}


Il s'agit d'un outil disponible pour vous, sur l'écran de validation, en cas de problème lors de la validation de votre document dans DocBits.

Cette fonctionnalité se trouve dans le menu au-dessus de la zone d'aperçu du document, comme ci-dessous

![Menu au-dessus de la zone d'aperçu du document sur l'écran de validation avec l'outil de création de ticket](https://lh7-us.googleusercontent.com/wgH8UDoDmtxAwaFoO3NUQM9NIQyINnNenBFMe4b\_mKfnx7LrJA\_8dPbKLoTNvHhHNyznEyy2JDLzoOHW39n1GnTIoBIUgUTCvMVKMPGMYJrFTU6JnqFxjc67j-idDupjbGfMqEwoSgrBPt3mvor1Tds)

Une fois cliqué, le formulaire de ticket suivant vous sera affiché.

![Boîte de dialogue de ticket de support avec les champs Name, E-Mail, Priority et Message et l'option Upload file](https://lh7-us.googleusercontent.com/DxlkEirrpbtGXs8R6gHD9MtaUqd5mY9L1ya1PdGIwZIHnuoj0wflDML6ZjYzrHxqXos-0uwhMAJI69\_zhO92dNWrwAmYpPwAe2C8sHvo0Tf8f8PG7SktBv4JiY6QfxxDNtO55S3xmQsze48ZophpDPc)

C'est ici que vous remplirez vos coordonnées ainsi que décrirez l'erreur. Vous pouvez également, si applicable, joindre une capture d'écran du problème et attacher un fichier pertinent.
