# Ticket erstellen

Dies ist ein Werkzeug, das Ihnen auf dem Validierungsbildschirm zur Verfügung steht, falls beim Validieren Ihres Dokuments in DocBits eine Art von Problem auftritt. Wie Sie ein Dokument im [Validierungsbildschirm](../validation-screen/README.md) prüfen, ist dort beschrieben.

Diese Funktion befindet sich im Menü oberhalb des Dokumentvorschaubereichs, wie unten dargestellt

<figure><img src="../../../.gitbook/assets/a-technical-support-in-docbits-create-a-ticket-menu-de-20261009.png" alt="Validierungsbildschirm mit dem Mauszeiger über der Schaltfläche Ticket erstellen in der rechten Aktionsleiste."><figcaption><p>Die Schaltfläche „Ticket erstellen“ in der Aktionsleiste des Validierungsbildschirms.</p></figcaption></figure>

Nach dem Klicken wird Ihnen das folgende Ticket-Formular angezeigt.

<figure><img src="../../../.gitbook/assets/a-technical-support-in-docbits-create-a-ticket-form-de-20261009.png" alt="Validierungsbildschirm mit geöffnetem Formular Support-Ticket: Name, E-Mail, Thema, Priorität, Nachricht, Screenshot und Datei hochladen."><figcaption><p>Das Formular „Support-Ticket“.</p></figcaption></figure>

Hier tragen Sie Ihre Angaben ein und beschreiben den Fehler. Sie können außerdem, falls zutreffend, einen Screenshot des Problems sowie eine relevante Datei anhängen.
