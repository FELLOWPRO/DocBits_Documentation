# Ticket erstellen

Dies ist ein Werkzeug, das Ihnen auf dem Validierungsbildschirm zur Verfügung steht, falls beim Validieren Ihres Dokuments in DocBits eine Art von Problem auftritt.

Diese Funktion befindet sich im Menü oberhalb des Dokumentvorschaubereichs, wie unten dargestellt

![](https://lh7-us.googleusercontent.com/wgH8UDoDmtxAwaFoO3NUQM9NIQyINnNenBFMe4b\_mKfnx7LrJA\_8dPbKLoTNvHhHNyznEyy2JDLzoOHW39n1GnTIoBIUgUTCvMVKMPGMYJrFTU6JnqFxjc67j-idDupjbGfMqEwoSgrBPt3mvor1Tds)

Nach dem Klicken wird Ihnen das folgende Ticket-Formular angezeigt.

![](https://lh7-us.googleusercontent.com/DxlkEirrpbtGXs8R6gHD9MtaUqd5mY9L1ya1PdGIwZIHnuoj0wflDML6ZjYzrHxqXos-0uwhMAJI69\_zhO92dNWrwAmYpPwAe2C8sHvo0Tf8f8PG7SktBv4JiY6QfxxDNtO55S3xmQsze48ZophpDPc)

Hier tragen Sie Ihre Angaben ein und beschreiben den Fehler. Sie können außerdem, falls zutreffend, einen Screenshot des Problems sowie eine relevante Datei anhängen.


## Video: Supportanfrage vorbereiten und verwerfen

Dieses deutsche Video zeigt das Supportformular über den Eintrag **Support** in der Seitenleiste. Ein Administrator gibt fiktive Kontaktdaten und eine nachvollziehbare Beispielnachricht ein, wählt die Priorität **Niedrig** und verwirft den Entwurf mit **Abbrechen**. Danach öffnet er das Formular erneut: Die Nachricht ist leer und die Priorität steht wieder auf **Mittel**.

[Video mit deutschen Untertiteln und Transkript öffnen](https://docbits-videos.fra1.cdn.digitaloceanspaces.com/settings-assistant/support-request-draft-admin/v1/de.html).

Das Video demonstriert die Vorbereitung und das Verwerfen einer Anfrage. Es wird kein Ticket gesendet und keine Eingangsbestätigung gezeigt. Die Beispieladresse `demo.support@example.invalid` dient ausschließlich der Demonstration.
