# Probleemoplossing

Als een waarde op het validatiescherm ontbreekt, controleert u eerst of de tekst in het document zichtbaar is en of DocBits deze heeft herkend. Zo kunt u een leesprobleem onderscheiden van een veld- of regelprobleem.

1. Open het betreffende document in **Validation**.
2. Vergelijk het originele document met de **OCR view**. Controleer dezelfde pagina en hetzelfde gebied waar de waarde zou moeten staan.
3. Als de tekst in de OCR view ontbreekt, volgt u [Missing Text in OCR Extraction](missing-text-in-ocr-extraction.md).
4. Als de tekst wel in de OCR view staat maar het veld leeg blijft, vraagt u een beheerder om de veldconfiguratie van het documenttype te controleren. Vermeld het documenttype, de veldnaam, de pagina en een veilig testvoorbeeld.
