# Risoluzione dei problemi

Se un valore manca nella schermata di validazione, controlla prima se il testo è visibile nel documento e se DocBits lo ha riconosciuto. Ti aiuta a distinguere un problema di lettura da un problema di campo o di regola.

1. Apri il documento interessato in **Validazione**.
2. Confronta il documento originale con la **Vista OCR**. Controlla la stessa pagina e la stessa area in cui il valore dovrebbe comparire.
3. Se il testo manca nella Vista OCR, segui [Testo mancante nell'estrazione OCR](missing-text-in-ocr-extraction.md).
4. Se il testo è presente nella Vista OCR ma il campo resta vuoto, chiedi a un amministratore di verificare la configurazione dei campi del tipo di documento. Indica il tipo di documento, il nome del campo, la pagina e un esempio di prova sicuro.
