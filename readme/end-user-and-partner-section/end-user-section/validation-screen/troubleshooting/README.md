# Rozwiązywanie problemów

Jeśli na ekranie walidacji brakuje wartości, najpierw sprawdź, czy tekst jest widoczny w dokumencie i czy DocBits go rozpoznał. Pozwala to odróżnić problem z odczytem od problemu z polem lub regułą.

1. Otwórz dany dokument w **Validation**.
2. Porównaj oryginalny dokument z **OCR view**. Sprawdź tę samą stronę i ten sam obszar, w którym wartość powinna się pojawić.
3. Jeśli tekstu brakuje w OCR view, postępuj zgodnie z instrukcją [Brakujący tekst w ekstrakcji OCR](missing-text-in-ocr-extraction.md).
4. Jeśli tekst jest widoczny w OCR view, ale pole pozostaje puste, poproś administratora o sprawdzenie konfiguracji pól typu dokumentu. Podaj typ dokumentu, nazwę pola, stronę i bezpieczny przykład testowy.
