# Rozwiązywanie problemów

Jeśli na ekranie walidacji brakuje wartości, sprawdź najpierw, czy tekst jest widoczny w dokumencie i czy DocBits go rozpoznał. Pomaga to odróżnić problem z odczytem tekstu od problemu z polem lub regułą.

1. Otwórz odpowiedni dokument na ekranie walidacji.
2. Porównaj oryginalny dokument z **Widokiem OCR**. Sprawdź tę samą stronę i ten sam obszar, w którym powinna pojawić się wartość.
3. Jeśli tekstu brakuje w widoku OCR, postępuj zgodnie z instrukcją [Brakujący tekst w ekstrakcji OCR](missing-text-in-ocr-extraction.md).
4. Jeśli tekst jest widoczny w widoku OCR, ale pole pozostaje puste, poproś administratora o sprawdzenie ustawień pól typu dokumentu. Podaj typ dokumentu, nazwę pola, stronę i bezpieczny przykład testowy.

Nie umieszczaj dokumentów klientów ani danych osobowych na zrzucie ekranu do zgłoszenia. W [przeglądzie ekranu walidacji](../README.md) opisano najważniejsze elementy tego ekranu, jeśli widzisz go po raz pierwszy.
