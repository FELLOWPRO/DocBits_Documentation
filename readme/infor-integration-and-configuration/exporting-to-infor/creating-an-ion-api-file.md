# Creazione di un file ION API

## Ottenere un file ION API esistente o crearne uno nuovo

Questo viene creato in INFOR ION API → App autorizzate e dovrebbe essere mostrata un'app come quella seguente

![Pagina Authorized Apps di Infor ION API che elenca un'app esistente disponibile per il file ION API](https://lh7-us.googleusercontent.com/Lpl5VZkrSk9u04C7SWTmfDVbQpRTxSMEE3i2S2Ry\_TDZ9mYJMt6UkzTPw5ApaVIEhzpUmpnffntqXowMlhib8LqIRWgpEYlepZlPyqGFNTTn7z--owAFltp9YfD1Si1SbAAX0c0EHvKrIkb0kK1GboQ)

In caso contrario, è necessario creare una nuova app autorizzata. Questo può essere fatto facendo clic sul segno più

![Pagina Authorized Apps di Infor ION API con il pulsante di aggiunta utilizzato per creare una nuova Authorized App](https://lh7-us.googleusercontent.com/y0G9v9WfKlQWCkMy7wmNp59PpUr9AOecJy5zThtVJ5rh09eyH1WkheONuNciZ1pj7-nHKpFSSUjuzYcCe3xE9qrZZcl3IEKeqUWn9h0LSQIF4WJhNDwM9xLaSYskDO4ci2qi3zXPLLl\_nPX8GL2UTK4)

Una volta inserito il Nome (DocBits\_\*Ambiente\*) e il Tipo (caso specifico) della nuova App Autorizzata, verrai indirizzato a una pagina in cui il Client ID e il Segreto sono stati generati automaticamente.

Le informazioni inserite dovrebbero essere simili a quanto mostrato sopra, è importante abilitare lo slider “Issue Refresh Tokens” nella parte inferiore della pagina.

![Pagina New Authorized App in Infor ION API con Client ID e Secret generati e il cursore Issue Refresh Tokens abilitato](https://lh7-us.googleusercontent.com/FevNa7kQ-rCicUxacuCe7m4XHsLOsYYCRq4JAQ3xDTYPxfq3mg5m2BwWF8iz7ASdNS93sgc1t8gJvnNupCDzQPbUu1NpCu4MHxKGBi6OtyDs7ep2TrsaP3gEXHgMsKzHVQ6JbNc2exbdJ41l\_0a7SCA)

Fare clic su “Download Credentials” per scaricare il file di mappatura ION.

![Pagina dei dettagli della Authorized App in Infor ION API per DocBits-Sandbox con nome, descrizione, campi della coppia di chiavi e il pulsante Download Credentials](https://lh7-us.googleusercontent.com/rf0BjR-d15LYj98tRJbMClAqtKAqhQdChgsxKS2Ndl-qhquZELEK66WjREvqDcCCj2UlZYK1i-ntNMtzrN\_Kpv1572tqMvWEld8tBDlAzuqz9ocXssiGXFCRnbyH2baWOiBH\_27cpVV3vFUP\_5CJ1xI)

## Caricamento del file in DocBits

Una volta scaricato il file ION API da Infor, puoi caricarlo andando su Impostazioni → Elaborazione documento → Esporta come di seguito

![Pagina delle impostazioni di esportazione di DocBits che mostra i campi di caricamento di ION Mapping File](https://lh7-us.googleusercontent.com/ONyqYFVhCO3PTyBM6Y-OLrwdXGSQgYBoq4M-7Uof7XKjNhYvemhbjtjcgT4mKZ2-dVc4TWkesSgOWwXGf\_a4xLj0X27Y7ZloQSwTD0ey1yIUBNkkvcTX8rf6l24ljltClVoVCJlUWsyVxmzMhWdLDnI)
