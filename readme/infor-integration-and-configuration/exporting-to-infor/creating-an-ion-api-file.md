# Crear un archivo de ION API

## Obtener un archivo de ION API existente o crear uno nuevo

Esto se crea en INFOR ION API → Aplicaciones autorizadas y se debe mostrar una aplicación como la siguiente

![Página Authorized Apps de Infor ION API que enumera una aplicación existente disponible para el archivo ION API](https://lh7-us.googleusercontent.com/Lpl5VZkrSk9u04C7SWTmfDVbQpRTxSMEE3i2S2Ry\_TDZ9mYJMt6UkzTPw5ApaVIEhzpUmpnffntqXowMlhib8LqIRWgpEYlepZlPyqGFNTTn7z--owAFltp9YfD1Si1SbAAX0c0EHvKrIkb0kK1GboQ)

De lo contrario, deberá crear una nueva aplicación autorizada. Esto se puede hacer haciendo clic en el signo más.

![Página Authorized Apps de Infor ION API con el botón de añadir usado para crear una nueva Authorized App](https://lh7-us.googleusercontent.com/y0G9v9WfKlQWCkMy7wmNp59PpUr9AOecJy5zThtVJ5rh09eyH1WkheONuNciZ1pj7-nHKpFSSUjuzYcCe3xE9qrZZcl3IEKeqUWn9h0LSQIF4WJhNDwM9xLaSYskDO4ci2qi3zXPLLl\_nPX8GL2UTK4)

Una vez que haya ingresado el Nombre (DocBits\_\*Entorno\*) y el Tipo (caso específico) de la nueva Aplicación autorizada, accederá a una página donde el Cliente ID y el secreto se generaron automáticamente.

La información que complete debe ser similar a la que se muestra arriba; es importante habilitar el control deslizante “Issue Refresh Tokens” en la parte inferior de la página.

![Página New Authorized App en Infor ION API con el Client ID y Secret generados y el control deslizante Issue Refresh Tokens activado](https://lh7-us.googleusercontent.com/FevNa7kQ-rCicUxacuCe7m4XHsLOsYYCRq4JAQ3xDTYPxfq3mg5m2BwWF8iz7ASdNS93sgc1t8gJvnNupCDzQPbUu1NpCu4MHxKGBi6OtyDs7ep2TrsaP3gEXHgMsKzHVQ6JbNc2exbdJ41l\_0a7SCA)

Haga clic en “Download Credentials” para descargar el archivo de mapeo ION.

![Página de detalles de Authorized App en Infor ION API para DocBits-Sandbox con nombre, descripción, campos de par de claves y el botón Download Credentials](https://lh7-us.googleusercontent.com/rf0BjR-d15LYj98tRJbMClAqtKAqhQdChgsxKS2Ndl-qhquZELEK66WjREvqDcCCj2UlZYK1i-ntNMtzrN\_Kpv1572tqMvWEld8tBDlAzuqz9ocXssiGXFCRnbyH2baWOiBH\_27cpVV3vFUP\_5CJ1xI)

## Carga del archivo en DocBits

Una vez que haya descargado el archivo ION API de Infor, puede cargarlo yendo a Configuración → Procesamiento de documentos → Exportar como se muestra a continuación.

![Página de ajustes de Export de DocBits que muestra los campos de carga de ION Mapping File](https://lh7-us.googleusercontent.com/ONyqYFVhCO3PTyBM6Y-OLrwdXGSQgYBoq4M-7Uof7XKjNhYvemhbjtjcgT4mKZ2-dVc4TWkesSgOWwXGf\_a4xLj0X27Y7ZloQSwTD0ey1yIUBNkkvcTX8rf6l24ljltClVoVCJlUWsyVxmzMhWdLDnI)
