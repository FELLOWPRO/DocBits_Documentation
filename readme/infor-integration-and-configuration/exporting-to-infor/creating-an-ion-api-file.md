# Een ION-API-bestand maken

## Een bestaand ION-API-bestand ophalen of een nieuw bestand maken

Deze wordt aangemaakt in INFOR ION API → Geautoriseerde apps en een app zoals hieronder zou moeten worden getoond

![](https://lh7-us.googleusercontent.com/Lpl5VZkrSk9u04C7SWTmfDVbQpRTxSMEE3i2S2Ry_TDZ9mYJMt6UkzTPw5ApaVIEhzpUmpnffntqXowMlhib8LqIRWgpEYlepZlPyqGFNTTn7z--owAFltp9YfD1Si1SbAAX0c0EHvKrIkb0kK1GboQ)

Als dit niet het geval is, moet u een nieuwe geautoriseerde app maken. Dit kunt u doen door op het plusteken te klikken

![](https://lh7-us.googleusercontent.com/y0G9v9WfKlQWCkMy7wmNp59PpUr9AOecJy5zThtVJ5rh09eyH1WkheONuNciZ1pj7-nHKpFSSUjuzYcCe3xE9qrZZcl3IEKeqUWn9h0LSQIF4WJhNDwM9xLaSYskDO4ci2qi3zXPLLl_nPX8GL2UTK4)

Nadat u de Naam (DocBits\_\*Omgeving\*) en het Type (zaakspecifiek) van de nieuwe Geautoriseerde App heeft ingevoerd, wordt u naar een pagina geleid waar de client-ID en het Geheim automatisch zijn gegenereerd.

De informatie die u invult moet vergelijkbaar zijn met wat hierboven wordt weergegeven, het is belangrijk om de schuifregelaar “Issue Refresh Tokens” onderaan de pagina in te schakelen.

![](https://lh7-us.googleusercontent.com/FevNa7kQ-rCicUxacuCe7m4XHsLOsYYCRq4JAQ3xDTYPxfq3mg5m2BwWF8iz7ASdNS93sgc1t8gJvnNupCDzQPbUu1NpCu4MHxKGBi6OtyDs7ep2TrsaP3gEXHgMsKzHVQ6JbNc2exbdJ41l_0a7SCA)

Klik op “Download Credentials” om het ION-toewijzingsbestand te downloaden.

![](https://lh7-us.googleusercontent.com/rf0BjR-d15LYj98tRJbMClAqtKAqhQdChgsxKS2Ndl-qhquZELEK66WjREvqDcCCj2UlZYK1i-ntNMtzrN_Kpv1572tqMvWEld8tBDlAzuqz9ocXssiGXFCRnbyH2baWOiBH_27cpVV3vFUP_5CJ1xI)
