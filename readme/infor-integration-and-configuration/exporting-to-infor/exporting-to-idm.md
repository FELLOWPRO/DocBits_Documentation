# Exportar para o IDM

Se apenas precisar de exportar o documento para o IDM, a gestão documental da Infor, a configuração é semelhante à exportação para IDM + LN/M3. Não é necessário um ficheiro de mapeamento BOD, porque não existe exportação para LN/M3.

Selecione a opção seguinte para exportar.

![Diálogo Select Integration listando Webhook, SFTP, SMB, Flow, ZUGFeRD, Infor ION, Infor IDM + ION BOD, Infor IDM + LN e Infor IDM + M3](https://lh7-us.googleusercontent.com/ELtWrfGudPjyRoKqvszlrAlLX83byrejUsmJh0Z7VjBOQ2VNrVJ-B-o\_\_NoziePWk8HCMIBL2cvGo\_ORL\_oS6LluvfIUdNHuVOKzUQB\_HgxyPNgrjnIb3P5N24KvXiavFL7aBPQZ1gIimSyaxosm47c)

Carregue um ficheiro da API ION e um ficheiro de mapeamento IDM.

![Diálogo de configuração de exportação com campo Title, menus suspensos Sub-Organizations e Document Type e caixas de seleção para ION-Mapping File e IDM Mapping File](https://lh7-us.googleusercontent.com/AVoWKz3ocf-1KTrXCGmUmxQzY8brTeR0aIaBAvaB6rV5Otb\_BjYOCm0rzoAXV-ZNxcs\_95yZARY\_MiKPm8-FXDU9oOSQslpc\_JmtiF6dLaaPTQ8TwslL8xySiz2FefX1op73oOQHOfEs\_Yq-RKcmdv4)

A obtenção destes ficheiros é descrita anteriormente nesta documentação: ficheiro da API ION e ficheiro de mapeamento IDM.
