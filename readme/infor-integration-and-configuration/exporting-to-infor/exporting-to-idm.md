# Esportazione in IDM

Se richiedi solo che il tuo documento venga esportato in IDM o Gestione documenti in INFOR, la configurazione è simile a quella dell'esportazione in IDM + LN/M3 ma non richiede alcun file di mappatura BOD poiché non è richiesta l'esportazione in LN/M3.

Seleziona la seguente opzione per l'esportazione.

![Finestra di dialogo Select Integration che elenca Webhook, SFTP, SMB, Flow, ZUGFeRD, Infor ION, Infor IDM + ION BOD, Infor IDM + LN e Infor IDM + M3](https://lh7-us.googleusercontent.com/ELtWrfGudPjyRoKqvszlrAlLX83byrejUsmJh0Z7VjBOQ2VNrVJ-B-o\_\_NoziePWk8HCMIBL2cvGo\_ORL\_oS6LluvfIUdNHuVOKzUQB\_HgxyPNgrjnIb3P5N24KvXiavFL7aBPQZ1gIimSyaxosm47c)

Ti verrà richiesto di caricare un file ION API e un file di mappatura IDM.

![Finestra di dialogo di configurazione dell'esportazione con campo Title, menu a discesa Sub-Organizations e Document Type e caselle di controllo per ION-Mapping File e IDM Mapping File](https://lh7-us.googleusercontent.com/AVoWKz3ocf-1KTrXCGmUmxQzY8brTeR0aIaBAvaB6rV5Otb\_BjYOCm0rzoAXV-ZNxcs\_95yZARY\_MiKPm8-FXDU9oOSQslpc\_JmtiF6dLaaPTQ8TwslL8xySiz2FefX1op73oOQHOfEs\_Yq-RKcmdv4)

Come ottenerli è stato discusso in precedenza in questa documentazione. File ION API e file di mappatura IDM.
