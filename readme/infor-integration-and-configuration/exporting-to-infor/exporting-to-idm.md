# 导出到 IDM

如果您只需要将文档导出到 INFOR 中的 IDM 或文档管理系统，配置与导出到 IDM + LN/M3 的配置类似，但无需 BOD Mapping 文件，因为不需要导出到 LN/M3。

选择以下导出选项。

![Select Integration对话框，列出Webhook、SFTP、SMB、Flow、ZUGFeRD、Infor ION、Infor IDM + ION BOD、Infor IDM + LN和Infor IDM + M3](https://lh7-us.googleusercontent.com/ELtWrfGudPjyRoKqvszlrAlLX83byrejUsmJh0Z7VjBOQ2VNrVJ-B-o\_\_NoziePWk8HCMIBL2cvGo\_ORL\_oS6LluvfIUdNHuVOKzUQB\_HgxyPNgrjnIb3P5N24KvXiavFL7aBPQZ1gIimSyaxosm47c)

您需要上传 ION API 文件和 IDM Mapping 文件。

![导出配置对话框，包含Title字段、Sub-Organizations和Document Type下拉框以及ION-Mapping File和IDM Mapping File复选框](https://lh7-us.googleusercontent.com/AVoWKz3ocf-1KTrXCGmUmxQzY8brTeR0aIaBAvaB6rV5Otb\_BjYOCm0rzoAXV-ZNxcs\_95yZARY\_MiKPm8-FXDU9oOSQslpc\_JmtiF6dLaaPTQ8TwslL8xySiz2FefX1op73oOQHOfEs\_Yq-RKcmdv4)

如何获取这些文件已在本文档前文中介绍：ION API 文件和 IDM Mapping 文件。
