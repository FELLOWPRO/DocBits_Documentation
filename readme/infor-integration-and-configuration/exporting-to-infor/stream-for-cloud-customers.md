# Stream para clientes en la nube

#### Para activar la configuración de Stream en DocBits <a href="#to-enable-stream-settings-in-docbits" id="to-enable-stream-settings-in-docbits"></a>

Vaya a _Configuración → Módulo → BOD Flujo de conexión_

<figure><img src="../../.gitbook/assets/image (223).png" alt="Entrada de configuración de módulos BOD Connection Stream con su interruptor activado"><figcaption></figcaption></figure>

Al activarlo, se generará automáticamente un nombre de Stream. Ahora debe dirigirse a Infor _→ OS  → ION  → Data Flows._ Allí debe configurar un nuevo flujo de datos. Debería tener un aspecto similar al siguiente:

<figure><img src="../../.gitbook/assets/image (225).png" alt="Diagrama de Infor ION Data Flow que muestra la conexión de flujo de DocBits a la izquierda entrando en ION y terminando en un nodo End"><figcaption></figcaption></figure>
