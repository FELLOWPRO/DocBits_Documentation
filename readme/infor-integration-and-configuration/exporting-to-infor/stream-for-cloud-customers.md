# Stream per i clienti Cloud

#### Per abilitare le impostazioni Stream in DocBits <a href="#to-enable-stream-settings-in-docbits" id="to-enable-stream-settings-in-docbits"></a>

Vai su _Impostazioni → Modulo → BOD Connection Stream_

<figure><img src="../../.gitbook/assets/image (223).png" alt="Voce delle impostazioni dei moduli BOD Connection Stream con il relativo interruttore attivato"><figcaption></figcaption></figure>

L'attivazione di questa opzione genera automaticamente un nome Stream. Ora devi passare a Infor _→ OS → ION → Data Flows._ Qui devi configurare un nuovo data flow. Dovrebbe avere un aspetto simile al seguente:

<figure><img src="../../.gitbook/assets/image (225).png" alt="Diagramma Infor ION Data Flow che mostra la connessione di flusso DocBits a sinistra che entra in ION e termina in un nodo End"><figcaption></figcaption></figure>
