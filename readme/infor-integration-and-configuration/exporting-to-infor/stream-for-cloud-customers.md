# Stream für Cloud-Kunden

#### Stream-Einstellungen in DocBits aktivieren <a href="#to-enable-stream-settings-in-docbits" id="to-enable-stream-settings-in-docbits"></a>

Gehen Sie zu _Settings → Module → BOD Connection Stream_

<figure><img src="../../.gitbook/assets/image (223).png" alt="Moduleinstellungseintrag BOD Connection Stream mit aktiviertem Schalter"><figcaption></figcaption></figure>

Wenn Sie dies aktivieren, wird automatisch ein Stream-Name generiert. Wechseln Sie nun zu Infor _→ OS  → ION  → Data Flows._ Dort müssen Sie einen neuen Data Flow einrichten. Er sollte etwa wie folgt aussehen:

<figure><img src="../../.gitbook/assets/image (225).png" alt="Infor ION Data Flow-Diagramm mit der DocBits-Stream-Verbindung links, die in ION einfließt und an einem End-Knoten endet"><figcaption></figcaption></figure>
