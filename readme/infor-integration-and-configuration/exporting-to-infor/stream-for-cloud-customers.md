# Stream para Clientes na Nuvem

#### Para ativar as configurações de Stream no DocBits <a href="#to-enable-stream-settings-in-docbits" id="to-enable-stream-settings-in-docbits"></a>

Acesse _Configurações → Módulo → BOD Connection Stream_

<figure><img src="../../.gitbook/assets/image (223).png" alt="Entrada das configurações de módulos BOD Connection Stream com o respetivo interruptor ativado"><figcaption></figcaption></figure>

Ao ativar essa opção, um nome de Stream é gerado automaticamente. Em seguida, acesse Infor _→ OS  → ION  → Data Flows._ Nessa tela, é necessário configurar um novo fluxo de dados (data flow). Ele deve ter uma aparência semelhante à seguinte:

<figure><img src="../../.gitbook/assets/image (225).png" alt="Diagrama Infor ION Data Flow a mostrar a ligação de fluxo DocBits à esquerda a entrar no ION e a terminar num nó End"><figcaption></figcaption></figure>
