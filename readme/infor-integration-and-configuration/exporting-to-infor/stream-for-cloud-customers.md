# Strumień dla klientów chmurowych

#### Aby włączyć ustawienia strumienia w DocBits <a href="#to-enable-stream-settings-in-docbits" id="to-enable-stream-settings-in-docbits"></a>

Przejdź do _Ustawienia → Moduł → BOD Connection Stream_

<figure><img src="../../.gitbook/assets/image (223).png" alt=""><figcaption></figcaption></figure>

Po włączeniu tej opcji automatycznie zostanie wygenerowana nazwa strumienia (Stream Name). Następnie należy przejść do Infor _→ OS → ION → Data Flows_ i skonfigurować nowy przepływ danych. Powinien wyglądać mniej więcej tak:

<figure><img src="../../.gitbook/assets/image (225).png" alt=""><figcaption></figcaption></figure>
