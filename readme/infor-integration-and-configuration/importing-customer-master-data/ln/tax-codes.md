# Codici d’imposta

## **Creare punti di connessione DocBits**

Apri ION Desk → Connetti → Punti di connessione

![Pagina iniziale di ION Desk con il menu Connect aperto e le voci Connection Points, Data Flows, API Flows, Mappings e File Templates](https://lh7-us.googleusercontent.com/QLQB17W\_hywZWBqme8Wio-orbdOdFHXLv5zTd89B3EkeS0WCuuo5Pv1CndLRQ2rFUefvQYM95U2Unhrl3YU3WAR23Ij\_tDw\_TOEVenWjyCh-9H8CPFSezF2gmED7u5QTR7q9WV4CSXRvDqkmKJYPqAI)

Avrai bisogno di 4 punti di connessione per questo flusso dati, 3 punti di connessione API per le diverse categorie di codici tributo (aliquota ordinaria, aliquota ridotta ed esente) e un punto di connessione Applicazione che rappresenta la tua azienda LN.

Per creare nuovi punti di connessione selezionare il pulsante “+ADD””

![Pagina Connection Points di ION Desk con l'elenco dei punti di connessione esistenti e il pulsante +ADD](https://lh7-us.googleusercontent.com/cECLuIswRSK3WWhUMi1n3tm2AIcrksZdpz7ZCO6-H\_MzaKe9CDT0w1b7GKJ8GtT\_d6nvvDe4ukLJfWcMocbHZ5dSSCw25Ky7-JUdrYb893GYYyaHL9tTjG1ZniORJPLSu1zJxL3c-1VQRw4IC0LpYuA)

Seleziona “API” in fondo all'elenco delle opzioni

![Elenco dei tipi di punto di connessione con Infor LN e IMS via API Gateway sotto Infor Technology e API in fondo all'elenco](https://lh7-us.googleusercontent.com/bpeLxdmi8b10LLMGy02vMRXuLoic9kFLywnpd6SSYV0fNv82dQahyvaA85mC1PEVScNW4m63fOw89vkhQr0-ou8VWOSjkwGWG5GnP7GQl77THtjXWP3YNo8LUzAstpCs0Q5fOjxaoT\_\_ZKM4jciHA5I)

Verrai indirizzato alla pagina seguente

![Modulo vuoto di un punto di connessione API in ION Desk con la data dell'ultima modifica e la sezione Connection Documents](https://lh7-us.googleusercontent.com/4pcN0B7aibjn\_Qn8nMgkzRc\_NiXev-c1wJudDKo2V5r0ORuajVzfzAWnWu0Wt68hKMKSLYkieUhOYChkcZuCZDWkg-F22Rq2WvVqgPweSg3by2TGrrJHweKWTlf\_DK1X2pCkoNU4yoGo3DyHsoqcGjg)

Qui è dove inserirai tutti i dettagli del punto di connessione TaxCode. Per ciascuno dei tre punti di connessione che creerai, procedi come segue

* Enter a Name: TaxCodeFull, TaxCodeReduced, TaxCodeFree
* Descrizione: può essere uguale al Nome o simile
* Importa un account di servizio che hai creato.

Passa alla scheda “Documents” e seleziona l'icona PLUS per aggiungere il BOD di cui abbiamo bisogno, come di seguito

![Barra dello scenario del punto di connessione API con le icone Get from API, Send to API e Trigger](https://lh7-us.googleusercontent.com/byhA18LzkcY9ZyfnzyDlru5qBx88E8U1yggMNNkoHGsYVCbNkflNFXGVvJwMvE\_104VCjoYOM0SQIJVniyBBdn5UKasVR0uat6UvmCmpzz9ZYsY2Wv14B4ElOwqcg2qklxYAQVU84UOG70l3fMLRrwo)

Cerca BOD

![Scheda Document del punto di connessione con le sotto-schede Input Document, ION API Request Parameters, Request Body e Settings](https://lh7-us.googleusercontent.com/DAKzvEsjCmk1jy7L6GwrVY2DWg3\_InluNftWnR7hGlnyeBxSDW6XTDPBMLqtJuUc9Lq3Nga6-EKS4tZpOjE09h5FUJaTm\_E70UdA4l17jWGQ6BSr121lC3LzhffUXi6Bsk5EZEz4XHyjekk1Njb3H4I)

Cerca il BOD chiamato “Sync.LnTaxCode”, cliccaci sopra e premi “OK” per aggiungere il BOD.

![Finestra Select Document Type con il testo di filtro sync.lntax e la voce Sync.LnTaxCode nell'elenco dei risultati](https://lh7-us.googleusercontent.com/7BLwrq8kr9OTHleI2anmAr2-4ChksQ0pptddwm1quFHquGfnMBEW32RFx31ETGbrxf0KGVr-VzlZC9h9heD3ymTq9L5NZEV1b9E67IIR0is18UGBCoJ5j7KIMmF533EDMvZzgi4LXqAkV9zgCyl0\_Lk)

Passa alla sezione ION API. Sotto API Call Name puoi usare il nome di BOD, Sync.LnTaxCode

Press the “SELECT” button

![Scheda ION API Request Parameters con API Call Name Sync.LnTaxCode e Product LN](https://lh7-us.googleusercontent.com/7MukO6oUAzVBFMPhFepwMvugqnhDDMhX9j7wZRU7BU0OusW3CKpMgqQNC7uNlehPp6eFniVxrX3DxjgsGZ\_Tmt\_cQOWGGiBfXAQfCC85amOGp1VY8RGo3nPABCiwzaIkYmnQF6t3FPVZ1fPV6fLazNc)

Seleziona l’API che hai configurato per l'ambiente con cui stai lavorando e cerca il seguente API. Una volta selezionato, premere “OK”.

![Finestra Search ION API Operation con Product DocBits-Demo, il filtro import_xml e le operazioni import_xml corrispondenti](https://lh7-us.googleusercontent.com/IpUUqJaXF0MmIeR6gtE9GDCccLfNsQLZ-RSHhQGVwJEj8WJwI-twgiHpFomBKhbnTUUKrhxJ0EUZ7F\_21MCSBjNS2VQq3azprekoxctRJZ-NJUHhb4J9rHUSRDoR\_OCzDHTG5q5KTwWMHOR5qNoNd38)

Successivamente, passa alla scheda Corpo della richiesta.

Qui è dove ci sarà un leggero cambiamento per ogni punto di connessione, questo è visibile nelle mappature dei campi che assegnerai a ciascun codice d’imposta poiché differiscono leggermente.

![Scheda Request Body con formato multipart/form-data e le righe di tipo di dato per data_type, field_mappings e file](https://lh7-us.googleusercontent.com/f4c-1M9mgCci2jjxkhaCDFX9bRWzMDaRwVv4XiaUH7BpHchPklvMnWoP\_ILSm6VB7GoFJNJzHsEPzk3eCFyLm1Kc3QI8OufjQ1mr7PqowjzViFDWc2opiNE1ODICtI9yEyUOi\_d\_hzN8CGo8gu6Ec84)

Nella riga field\_mappings, sotto valore, inserirai le mappature dei campi specifici per lo specifico punto di connessione del codice d’imposta che stai creando (aliquota ordinaria, aliquota ridotta o esente). Queste mappature sono disponibili su https://docbits.com/doc/field-mappings/.

Il risultato finale dovrebbe essere uguale o simile all'immagine sopra. Fatto ciò, fai clic sull'opzione SAVE che si trova qui.

![Punto di connessione API DocBits-Stage-Import-LnTaxCodeFull con lo scenario Send to API, API Call Name Sync.LnTaxCode e documento da inviare Sync.LnTaxCode](https://lh7-us.googleusercontent.com/LSYrbElw6BgQbbIdSstbakfwLENZ\_09WQcQhjO7kbb2U3jSK\_\_wFnr43tIj2hTHYegQ9lrSZBuJ9N7MNewr2W3yjPCrrVLeP9UAZjvrKKBzeY9h-q6FrVd5gPtlH0iP0GpMcvhGxjAnHN7BlY8CmT3c)
