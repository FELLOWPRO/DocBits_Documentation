# Códigos de impuestos

## **Crear puntos de conexión de DocBits**

Abra ION Desk → Conectar → Puntos de conexión

![Infor ION Desk con el menú Connect abierto en la vista general de Connection Points](https://lh7-us.googleusercontent.com/QLQB17W\_hywZWBqme8Wio-orbdOdFHXLv5zTd89B3EkeS0WCuuo5Pv1CndLRQ2rFUefvQYM95U2Unhrl3YU3WAR23Ij\_tDw\_TOEVenWjyCh-9H8CPFSezF2gmED7u5QTR7q9WV4CSXRvDqkmKJYPqAI)

Necesitará 4 puntos de conexión para este flujo de datos, 3 puntos de conexión API para las diferentes categorías de códigos impositivos (completo, reducido y exento) y un punto de conexión de la Aplicación que represente su empresa LN.

Para crear nuevos puntos de conexión, seleccione el botón “+ADD””

![Página Connection Points en ION Desk con el botón Add en la barra de herramientas](https://lh7-us.googleusercontent.com/cECLuIswRSK3WWhUMi1n3tm2AIcrksZdpz7ZCO6-H\_MzaKe9CDT0w1b7GKJ8GtT\_d6nvvDe4ukLJfWcMocbHZ5dSSCw25Ky7-JUdrYb893GYYyaHL9tTjG1ZniORJPLSu1zJxL3c-1VQRw4IC0LpYuA)

Seleccione “API” en la parte inferior de la lista de opciones

![Menú de tipos de punto de conexión con la opción API en la parte inferior](https://lh7-us.googleusercontent.com/bpeLxdmi8b10LLMGy02vMRXuLoic9kFLywnpd6SSYV0fNv82dQahyvaA85mC1PEVScNW4m63fOw89vkhQr0-ou8VWOSjkwGWG5GnP7GQl77THtjXWP3YNo8LUzAstpCs0Q5fOjxaoT\_\_ZKM4jciHA5I)

Serás llevado a la siguiente página.

![Página de nuevo punto de conexión API en ION Desk con los campos Name, Description y cuenta de servicio](https://lh7-us.googleusercontent.com/4pcN0B7aibjn\_Qn8nMgkzRc\_NiXev-c1wJudDKo2V5r0ORuajVzfzAWnWu0Wt68hKMKSLYkieUhOYChkcZuCZDWkg-F22Rq2WvVqgPweSg3by2TGrrJHweKWTlf\_DK1X2pCkoNU4yoGo3DyHsoqcGjg)

Aquí es donde ingresarás todos los detalles del punto de conexión TaxCode. Para cada uno de los tres puntos de conexión que creará, haga lo siguiente

* Ingrese un nombre: TaxCodeFull, TaxCodeReduced, TaxCodeFree
* Descripción: Puede ser igual que el Nombre o similar
* Importe una cuenta de servicio que haya creado.

Cambie a la pestaña “Documents” y seleccione el ícono PLUS para agregar el BOD que necesitamos, como se muestra a continuación

![Pestaña Documents del punto de conexión con el icono más y las opciones de dirección BOD Get from API, Send to API y Trigger API](https://lh7-us.googleusercontent.com/byhA18LzkcY9ZyfnzyDlru5qBx88E8U1yggMNNkoHGsYVCbNkflNFXGVvJwMvE\_104VCjoYOM0SQIJVniyBBdn5UKasVR0uat6UvmCmpzz9ZYsY2Wv14B4ElOwqcg2qklxYAQVU84UOG70l3fMLRrwo)

Busque el BOD

![Diálogo Input Document foreground process para la solicitud de la ION API con las pestañas Request Parameters, Request Body y Settings](https://lh7-us.googleusercontent.com/DAKzvEsjCmk1jy7L6GwrVY2DWg3\_InluNftWnR7hGlnyeBxSDW6XTDPBMLqtJuUc9Lq3Nga6-EKS4tZpOjE09h5FUJaTm\_E70UdA4l17jWGQ6BSr121lC3LzhffUXi6Bsk5EZEz4XHyjekk1Njb3H4I)

Busca el BOD llamado “Sync.LnTaxCode”, haz clic en él y presiona “OK” para agregar el BOD.

![Lista de selección de BOD con Sync.LnTaxCode seleccionado y el botón OK](https://lh7-us.googleusercontent.com/7BLwrq8kr9OTHleI2anmAr2-4ChksQ0pptddwm1quFHquGfnMBEW32RFx31ETGbrxf0KGVr-VzlZC9h9heD3ymTq9L5NZEV1b9E67IIR0is18UGBCoJ5j7KIMmF533EDMvZzgi4LXqAkV9zgCyl0\_Lk)

Continúe en la sección ION API. En API Call Name puede utilizar el nombre del BOD: Sync.LnTaxCode.

Presione el botón “SELECT”

![Página del punto de conexión con la sección ION API, el campo API Call Name y el botón SELECT](https://lh7-us.googleusercontent.com/7MukO6oUAzVBFMPhFepwMvugqnhDDMhX9j7wZRU7BU0OusW3CKpMgqQNC7uNlehPp6eFniVxrX3DxjgsGZ\_Tmt\_cQOWGGiBfXAQfCC85amOGp1VY8RGo3nPABCiwzaIkYmnQF6t3FPVZ1fPV6fLazNc)

Seleccione el API que configuró para el entorno con el que está trabajando y busque el siguiente API. Una vez que lo hayas seleccionado, presiona “OK”.

![Diálogo ION API Operation que enumera las operaciones de búsqueda de datos maestros de DocBits como Import Xml File e Import Xml Data](https://lh7-us.googleusercontent.com/IpUUqJaXF0MmIeR6gtE9GDCccLfNsQLZ-RSHhQGVwJEj8WJwI-twgiHpFomBKhbnTUUKrhxJ0EUZ7F\_21MCSBjNS2VQq3azprekoxctRJZ-NJUHhb4J9rHUSRDoR\_OCzDHTG5q5KTwWMHOR5qNoNd38)

A continuación, cambie a la pestaña Cuerpo de la solicitud.

Aquí es donde habrá un ligero cambio para cada punto de conexión, esto se ve en las asignaciones de campos que asignará a cada código fiscal, ya que difieren ligeramente.

![Pestaña Request Body con el cuerpo JSON y la entrada field_mappings para el código de impuestos](https://lh7-us.googleusercontent.com/f4c-1M9mgCci2jjxkhaCDFX9bRWzMDaRwVv4XiaUH7BpHchPklvMnWoP\_ILSm6VB7GoFJNJzHsEPzk3eCFyLm1Kc3QI8OufjQ1mr7PqowjzViFDWc2opiNE1ODICtI9yEyUOi\_d\_hzN8CGo8gu6Ec84)

En la fila field\_mappings, debajo del valor, es donde colocará las asignaciones de campos específicos para el punto de conexión del código tributario específico que está creando (completo, reducido o exento). Estas asignaciones están disponibles en https://docbits.com/doc/field-mappings/.

El resultado final debe verse igual o similar a la imagen de arriba. Una vez hecho esto, haga clic en la opción SAVE ubicada aquí.

![Menú en ION Desk con la opción SAVE para el punto de conexión](https://lh7-us.googleusercontent.com/LSYrbElw6BgQbbIdSstbakfwLENZ\_09WQcQhjO7kbb2U3jSK\_\_wFnr43tIj2hTHYegQ9lrSZBuJ9N7MNewr2W3yjPCrrVLeP9UAZjvrKKBzeY9h-q6FrVd5gPtlH0iP0GpMcvhGxjAnHN7BlY8CmT3c)
