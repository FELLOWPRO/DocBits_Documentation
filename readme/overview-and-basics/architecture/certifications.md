# Certificeringen

DocBits wordt geëxploiteerd door **Fellowpro AG** onder een uitgebreid programma voor informatiebeveiliging, privacy en interne controles. De onderstaande certificeringen worden jaarlijks onafhankelijk geaudit; klanten kunnen de officiële auditrapporten rechtstreeks vanaf deze pagina downloaden.

{% hint style="info" %}
Heb je een certificaat nodig voor je inkoop-, security- of complianceteam? Elk rapport op deze pagina is het ondertekende auditor-document — geen NDA vereist. Voor vragen over scope, controles of komende audits, neem contact op met **compliance@fellowpro.com**.
{% endhint %}

## 1. ISO/IEC 27001

<figure><img src="../../.gitbook/assets/ISO27001.png" alt=""><figcaption></figcaption></figure>

Deze internationale norm definieert de vereisten voor het opzetten, implementeren, onderhouden en continu verbeteren van een Information Security Management System (ISMS). Het helpt organisaties om data op een systematische en kosteneffectieve manier te beschermen, inclusief processen voor risicobeheer en informatiebeveiligingscontroles.

**Impact voor klanten:** Zorgt ervoor dat DocBits de hoogste normen voor informatiebeveiliging hanteert, wat vertrouwen geeft dat gevoelige data goed beschermd is.

**Laatste audit:** Toezichtsaudit SA1, 2025 — ISMS van Fellowpro AG.

{% file src="../../.gitbook/assets/FELLOWPRO-ISO27001-Client-Report-2025.pdf" %}

## 2. SOC 1 (Service Organization Control 1)

<figure><img src="../../.gitbook/assets/SOC1.png" alt=""><figcaption></figcaption></figure>

SOC 1-rapporten zijn ontworpen voor organisaties die de effectiviteit van interne controles over financiële verslaggeving moeten aantonen. Dit is vooral relevant voor serviceproviders die de financiële verslaggeving van hun klanten beïnvloeden.

**Relevantie voor DocBits:** Toont onze toewijding aan het handhaven van strikte interne controles over financiële data, wat klanten zekerheid biedt over de betrouwbaarheid van onze processen.

**Laatste audit:** SOC 1 Type II — rapportageperiode 2025.

{% file src="../../.gitbook/assets/FELLOWPRO-SOC1-Type2-Report-2025.pdf" %}

## 3. SOC 2 (Service Organization Control 2)

<figure><img src="../../.gitbook/assets/SOC2.png" alt=""><figcaption></figcaption></figure>

SOC 2 richt zich op de controles van een serviceorganisatie die relevant zijn voor beveiliging, beschikbaarheid, verwerkings­integriteit, vertrouwelijkheid en privacy van data. Het is cruciaal voor technologie- en cloudbedrijven die met gevoelige informatie omgaan.

**Waarde voor klanten:** Biedt onafhankelijke validatie dat DocBits effectieve controles heeft geïmplementeerd om klantdata te beschermen, wat de betrouwbaarheid van onze software en diensten garandeert.

**Laatste audit:** SOC 2 Type II — rapportageperiode 2026.

{% file src="../../.gitbook/assets/FELLOWPRO-SOC2-Type2-Report-2026.pdf" %}

## 4. GDPR (General Data Protection Regulation) Compliance

<figure><img src="../../.gitbook/assets/GDPR.png" alt=""><figcaption></figcaption></figure>

De AVG (GDPR) is een verordening in het EU-recht over gegevensbescherming en privacy in de Europese Unie en de Europese Economische Ruimte. Ze behandelt ook de doorgifte van persoonsgegevens buiten de EU en de EER.

**Zekerheid voor klanten:** Naleving van de AVG zorgt ervoor dat DocBits persoonsgegevens verwerkt in overeenstemming met de EU-regelgeving, de privacy van gebruikers beschermt en zich houdt aan strikte richtlijnen voor gegevens­verwerking.

**Laatste audit:** Onafhankelijk GDPR-auditrapport, 2025.

{% file src="../../.gitbook/assets/FELLOWPRO-GDPR-Audit-Report-2025.pdf" %}
