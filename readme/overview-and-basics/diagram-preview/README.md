# Diagram Preview

Preview pages for diagrams generated with Archify. Each page shows the same diagram in three variants so the rendering in GitBook can be compared:

1. **SVG** — one file for both themes; switches with the operating-system dark mode.
2. **PNG, theme-aware** — separate light and dark PNG, switched by the reader's color scheme.
3. **PNG light / PNG dark** — the two raster files shown side by side for comparison.
