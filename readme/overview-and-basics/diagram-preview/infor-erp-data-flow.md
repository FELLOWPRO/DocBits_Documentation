# Infor ERP 数据流

主数据如何通过 ION Desk 从 Infor ERP（LN/M3）传入 DocBits，以及经过验证的文档如何返回 Infor：PDF 传至 IDM，此外还可通过 ION Messaging 中的 Sync.CaptureDocument，或直接调用 M3/LN API。详情请参阅[架构](../architecture/README.md)。
