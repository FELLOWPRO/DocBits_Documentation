## **So testen Sie auf der Sandbox**

1. **Zugriff auf die Sandbox**:
   * Melden Sie sich mit Ihren vorhandenen Zugangsdaten an der Sandbox-Umgebung an.
   * Stellen Sie sicher, dass Sie die richtige URL für die Sandbox verwenden.
2. **Testrichtlinien**:
   * Folgen Sie den Schritten, die für jede Funktion oder Korrektur angegeben sind.
   * Melden Sie Probleme, unerwartetes Verhalten oder Feedback über [support.fellowpro.com](https://support.fellowpro.com)
3. **Testprotokolle**:
   * Überwachen Sie die Systemprotokolle auf relevante Testergebnisse oder Fehler.
   * Dokumentieren Sie Ihren Testablauf und die Ergebnisse zur Überprüfung.

***
