# Mesclagem de Documentos

A mesclagem de documentos permite combinar vários documentos.

Primeiro, você precisa selecionar os documentos que deseja mesclar. Isso pode ser feito marcando as caixas de seleção dos documentos. Depois de selecionar os documentos, clique no ícone com três pontos.

Em seguida, um menu será exibido; selecione a opção "Mesclar", que se encontra na parte inferior.
