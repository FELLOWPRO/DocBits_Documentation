# IMAP

Tutaj wystarczy, że wprowadzisz wymagane informacje dotyczące Twojego dostawcy poczty e-mail: szyfrowanie, nazwę serwera, port, nazwę użytkownika, adres e-mail, hasło, a także folder poczty.

Na co zwrócić uwagę

* Wprowadź wszystkie potrzebne informacje w interfejsie. Pozostałe dane, takie jak serwer, port itp., zależą od dostawcy (szybkie wyszukiwanie w Google powinno pomóc).
* Folder oraz Przenieś zaimportowane pełnią tutaj tę samą funkcję. Folderu nie można wyłączyć, ale jeśli pozostanie pusty, domyślnie zostanie użyta Skrzynka odbiorcza.
