# IMAP



Protokol olarak IMAP’i seçin ve e-posta sağlayıcınızın bilgilerini girin: sunucu adı, bağlantı noktası, şifreleme, kullanıcı adı, e-posta adresi ve şifre. Sonraki adımlarda seçenekleri ve e-posta klasörünü belirlersiniz.

Dikkat edilecekler

* Gerekli tüm bilgileri arayüze girin. Sunucu, bağlantı noktası gibi diğer bilgiler sağlayıcıya bağlıdır (hızlı bir internet araması yardımcı olur).
* Klasör ve İçe aktarılanları taşı burada aynı işleve sahiptir. Klasör devre dışı bırakılamaz; boş bırakılırsa varsayılan olarak Gelen Kutusu kullanılır.
