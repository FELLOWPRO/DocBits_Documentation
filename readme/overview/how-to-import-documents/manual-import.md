# Importação Manual

Se você deseja importar documentos manualmente para o DocBits, siga estas etapas simples:

* Clique no botão Upload no Painel do DocBits.
* Uma janela aparecerá onde você pode enviar seus documentos por meio do navegador de arquivos ou arrastando e soltando. Você pode enviar até 10 documentos de uma vez.
* Para enviar documentos pelo navegador de arquivos, clique no botão Upload Documents e selecione os arquivos que deseja enviar. Depois de selecionar os arquivos, clique em Confirm para iniciar o processo de upload.
* Como alternativa, você pode arrastar e soltar seus arquivos na janela de importação do DocBits.
* Após o envio, os arquivos terão o status inicial de "Em execução". Durante esse período, o upload está sendo processado e não é possível editar o arquivo. O tempo de processamento pode variar dependendo do tamanho e da complexidade do arquivo.
* Depois que o arquivo for processado, ele receberá o status de "Pronto para Validação". Agora você pode iniciar o processo de validação.
