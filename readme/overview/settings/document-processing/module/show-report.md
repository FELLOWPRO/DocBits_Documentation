# Show Report

### Pregled

Podešavanje **Show Report** dodaje stavku **Report** u glavni meni za navigaciju. Daje vašem timu pristup jednim klikom stranici izveštaja, gde možete da pregledate izveštaje o obradi vaših dokumenata.

Ovo podešavanje je **podrazumevano isključeno**.

### Šta radi?

* **Uključeno** — U bočnom meniju se pojavljuje stavka **Report** koja vodi do stranice izveštaja. Korisnici mogu da je otvore da bi videli izveštaj.
* **Isključeno** — Stavka Report se uklanja iz menija.

### Prednosti

* **Uvid**: Dođite do izveštaja o obradi svojih dokumenata direktno iz menija.
* **Brz pristup**: Izveštaj je na jedan klik kada vam zatreba.
* **Uredan interfejs**: Održavajte meni fokusiranim skrivanjem izveštaja za timove koji ga ne koriste.

### Kako se koristi

1. Idite na **Podešavanja**.
2. Izaberite **Obrada dokumenata**.
3. Izaberite **Modul**.
4. Otvorite odeljak **Tip dokumenta**.
5. Pronađite **Show Report** i uključite prekidač.
6. U meniju za navigaciju organizacije se zatim pojavljuje stavka **Report**.

### Kada koristiti ovu funkciju

* **Praćenje i nadzor**: Kada rukovodioci ili administratori žele brz pristup izveštajima.
* **Redovni pregledi**: Kada je izveštaj deo rutine vašeg tima.
* **Ostavite isključeno** ako izveštaj nikome nije potreban, kako biste navigaciju održali fokusiranom.
