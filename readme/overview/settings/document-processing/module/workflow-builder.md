# Workflow Builder

### Pregled

Podešavanje **Workflow Builder** aktivira **DocFlow** za vašu organizaciju. DocFlow je mehanizam tokova rada koji automatizuje ono što se dešava sa vašim dokumentima — usmeravanje, korake odobravanja, uslove i naknadne radnje. Kada je ovo podešavanje uključeno, dizajner tokova rada DocFlow-a postaje dostupan i dokumenti prolaze kroz tokove koje kreirate.

Ovo je funkcija **zasnovana na pretplati** i **podrazumevano je isključena**.

### Šta radi?

Uključivanje prekidača ne menja samo podešavanje — ono pokreće **pretplatu na DocFlow**. Pojavljuje se dijalog u kojem birate svoj DocFlow plan (DocFlow Standard i opciono DocFlow Advanced). Podešavanje se aktivira tek nakon potvrde pretplate.

* **Uključeno** — DocFlow je aktiviran za organizaciju. Dokumenti se usmeravaju kroz vaše tokove rada, a dizajner Workflow Builder-a je dostupan za njihovo kreiranje i uređivanje.
* **Isključeno** — DocFlow se isključuje, a odgovarajuća pretplata se otkazuje. Dokumenti više ne prolaze kroz tokove rada.

{% hint style="info" %}
**Workflow Builder je glavni prekidač koji uključuje ili isključuje DocFlow za celu organizaciju.** Pošto upravlja pretplatom, uključivanje otvara dijalog za izbor plana, a isključivanje otkazuje aktivnu DocFlow pretplatu.
{% endhint %}

### Prednosti

* **Automatizacija**: Zamenite ručne predaje automatizovanim koracima (usmeravanje, odobrenja, uslovi).
* **Doslednost**: Svaki dokument prati isti definisani proces.
* **Vidljivost**: Tokovi rada se projektuju i njima se upravlja na jednom mestu.

### Kako se koristi

1. Idite na **Podešavanja**.
2. Izaberite **Obrada dokumenata**.
3. Izaberite **Modul**.
4. Otvorite odeljak **Tip dokumenta**.
5. Pronađite **Workflow Builder** i uključite prekidač.
6. U dijalogu izaberite svoj DocFlow plan (Standard, opciono Advanced) i potvrdite. DocFlow se aktivira čim se pretplata kreira.
7. Zatim projektujte svoje tokove rada za dokumente u DocFlow-u — pogledajte odeljak **Workflow** za to kako da ih kreirate.

### Kada koristiti ovu funkciju

* **Automatizovani procesi dokumenata**: Kada dokumenti treba da prođu kroz definisane korake kao što su pregled, odobrenje ili usmeravanje.
* **Timski tokovi rada**: Kada je više osoba ili uloga uključeno u obradu dokumenta.
* **Ostavite isključeno** ako vaša organizacija ne koristi DocFlow / tokove rada za dokumente (isključivanje takođe otkazuje DocFlow pretplatu).
