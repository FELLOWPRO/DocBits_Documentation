# Plan pretplate

<figure><img src="../../../.gitbook/assets/subscriptions_overview.png" alt="Plan pretplate"><figcaption><p>Stranica Plan pretplate</p></figcaption></figure>

Stranica **Plan pretplate** pruža potpun pregled vaše DocBits pretplate na jednom mestu: sam plan, pretplate na aplikacije i funkcije omogućene za vašu organizaciju i potrošnju tokena. Otvorite je preko **Podešavanja → Organizacija i pristup → Plan pretplate**.

## Plan pretplate

Prva kartica prikazuje vašu DocBits pretplatu — broj preostalih dana i datume početka i završetka — zajedno sa aktuelnim brojačima za vašu organizaciju:

| Kartica | Opis |
|------|-------------|
| **DocBits** | Preostali dani i datum početka i završetka vaše pretplate. |
| **Korisnici** | Broj korisnika u vašoj organizaciji. |
| **Podorganizacija** | Broj podorganizacija. |
| **Dobavljači** | Broj dobavljača. |

## Pretplate na funkcije

<figure><img src="../../../.gitbook/assets/subscriptions_feature_subscriptions.png" alt="Pretplate na funkcije"><figcaption></figcaption></figure>

Ovaj odeljak navodi svaku DocBits aplikaciju i funkciju i pokazuje da li je omogućena za vašu organizaciju.

| Kolona | Opis |
|--------|-------------|
| **Aplikacija** | DocBits aplikacija ili funkcija (npr. AI Workforce, Operator, DocFlow, AI Search, BOD Ingestion, SQL BI Connector). |
| **Pretplata** | Pretplaćeni plan za tu aplikaciju. |
| **Status** | **Aktivno**, **Otkazivanje** (aktivno do datuma završetka, zatim se završava) ili **Nijedno** kada aplikacija nije pretplaćena. |
| **Početak / Završetak** | Period pretplate. |
| **Preostali dani** | Dani do datuma završetka. |
| **Radnje** | Meni radnji po aplikaciji. |

## Korišćenje pretplate

<figure><img src="../../../.gitbook/assets/subscriptions_usage.png" alt="Korišćenje pretplate"><figcaption></figcaption></figure>

Pratite svoje korišćenje tokena i radnih tokova tokom izabranog perioda. Koristite dugme **Izaberi** da biste izabrali opseg datuma.

| Kolona | Opis |
|--------|-------------|
| **Tip** | Kategorija korišćenja — Dokument, Radni tok, Napredni radni tok ili DocNet. |
| **Od / Do** | Period za koji se prijavljuje korišćenje. |
| **Iskorišćeni tokeni** | Tokeni potrošeni u periodu. |
| **Preostali tokeni** | Tokeni dostupni za period. |
